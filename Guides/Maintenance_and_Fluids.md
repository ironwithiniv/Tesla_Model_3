# Обслуживание и жидкости: Tesla Model 3 LR AWD (2021–2023, справочно 2024+)

Источники:
- **[OM]**: Owner's Manual Model 3 2017–2023, North America, ПО 2026.38.3 ([PDF](../Owner-Manual/Model3_2017-2023_Owners_Manual_NA_sw2026.38.3.pdf)), раздел «Maintenance Service Intervals», стр. 180–181; «Tire Care», стр. 184–187; «Cabin Air Filter», стр. 200; «Specifications», стр. 217–222. Номер страницы печатный, в PDF он на 2 больше.
- **[SM]**: Service Manual Model 3 2017–2023 (service.tesla.com), скачан 2026-11-24. Страницы указаны ссылками.
- **[SM24]**: Service Manual Model 3 2024+.

Регламент Tesla «по состоянию», а не по пробегу: жёстких ТО-10/20 тыс. км нет. При ~10 тыс. км/год для вас почти всё определяется **временем**, а не пробегом.

## 1. Регламент Tesla

| Работа | Интервал по Tesla | Источник | Для вас (~10 тыс. км/год, Тбилиси) |
|---|---|---|---|

По SM: если полоска не темнее образца 30 PPM, повторить проверку **через 4 года**; если темнее 100 PPM, прокачка/замена | [OM] стр. 180; [SM: Brake Fluid Check](https://service.tesla.com/docs/Model3/ServiceManual/en-us/GUID-AA717A3B-2077-43B4-B5AF-AF2E3CC9539A.html) | Проверить при покупке (история неизвестна), дальше раз в 2 года: жарко, горы. Tesla оговаривает, что при торможении на спусках в жарком климате проверять нужно чаще ([OM] стр. 180) |

## 2. Жидкости (допуски)

Источник: [SM: Fluids and Capacities](https://service.tesla.com/docs/Model3/ServiceManual/en-us/GUID-E7469E86-090D-4A12-842C-7AAD00446096.html), редакция страницы от 2026-03-09.

| Система | Что заливать (Tesla P/N) | Примечания |
|---|---|---|
| Тормозная жидкость | **DOT 4 BASF Hydraulan 404** (1012041-10-C) | На крышке бачка написано «DOT 3»: это **минимальное** требование. Жидкость только из запечатанной тары |
| Охлаждающая жидкость | Этиленгликоль без фосфатов и нитратов, 50/50: NA 1029320-00-A; **EMEA: G48, 1119779-00-A** (готовая 50/50, воду не добавлять) | Концентрация гликоля не ниже 50 % и не выше 60 %. Гарантию Tesla даёт только на G-48 |
| Кондиционер, хладагент | R134a (1012403-00-B) **или** R1234yf (2006643-00-A), в зависимости от рынка | Тип указан на наклейке под капотом. Американские машины обычно на R1234yf, это стоит проверить на конкретной машине |
| Кондиционер, масло | Компрессор Hanon или Sanden: **RB100EV** (1994534-00-A / 1031093-01-A). Denso: **ND-11** (1031093-00-A / 1108849-00-A) | **Не смешивать.** Плотность обоих 0,98 г/мл |
| Редукторы | 3DU до MY2023: ATF-9 (1135241-00-A) или EDF2 (1616951-00-A), в итоге **KAF1 (V1.2)** (1646886-02-B / -04-B). 3DU с MY2024: KAF1 (1646886-02-A / -04-A). 4DU: KAF1 (V1.2) | KAF1 совместима со старыми жидкостями. **SK 212, ATF-9 и EDF2 не смешивать между собой.** Если неизвестно, что залито, доливать только KAF1 |
| Омыватель | на этаноле, одобренный Tesla | — |
| Электрические соединения | Penetrox A-13 (1089974-00-A) | Для HV-шин |

> Для Грузии: дилерских жидкостей Tesla здесь нет. Аналоги по спецификации: DOT 4 с низкой вязкостью, этиленгликоль OAT без фосфатов и нитратов, масло для компрессора нужного типа (не PAG для обычных машин). Конкретные бренды-аналоги Tesla не одобряет, используются на свой риск ([SM], CAUTION на той же странице).

## 3. Объёмы (заводская заправка)

Источник: [SM: Fluids and Capacities](https://service.tesla.com/docs/Model3/ServiceManual/en-us/GUID-E7469E86-090D-4A12-842C-7AAD00446096.html). Цифры **совпадают** в [SM24](https://service.tesla.com/docs/Model3/ServiceManual/2024/en-us/index.html), кроме кондиционера (у 2024+ тепловой насос всегда).

| Система | Объём |
|---|---|
| Хладагент: **с тепловым насосом** (ваш случай, 2021+) | **1020 г** (1000–1040 г) |
| Хладагент: без теплового насоса (до ~2020) | 660 г (640–680 г) |
| Масло кондиционера: с тепловым насосом | 256 г (250–262 г) |
| Масло кондиционера: без теплового насоса | 140–160 г |
| Охлаждающая жидкость (с сухой системы) | **AWD 2170 E1: 16,7 л**; AWD 2170 E3: 18,4 л; RWD 2170 E1: 16,3 л; RWD SR LFP60: 14,6 л |
| Передний редуктор (3DU) | 1300 мл (замена) |
| Задний редуктор 3DU | 2100 мл (замена) |
| Задний редуктор 4DU | 2300 мл (замена) |
| Тормозная жидкость | 750 мл (не Performance), 770 мл (Performance) |

> «E1» и «E3» — варианты батареи 2170, не путать с типами ячеек. Какой вариант у конкретной машины, видно в Service Mode / Scan My Tesla. Это ⏳: уточнить в [Battery_Health.md](Battery_Health.md).

## 4. 12V / LV батарея

- По [OM] стр. 219: «Battery – Low Voltage: 33 Ah or higher, negative ground». Это формулировка для свинцово-кислотной АКБ.
- В [OM] стр. 181 есть ссылка «Replacing the Low Voltage Lead-Acid Battery … on some vehicles», то есть замену своими руками описывают только для машин со свинцовой АКБ.
- В EPC (parts.tesla.com) для Model 3 2017–2023 есть **две** группы: «12V Battery and Fittings» и «LV Battery» (литий-ионная 16V). Номера и цены в [../Parts-Catalog/](../Parts-Catalog/README.md).
- Какие VIN и даты получили литиевую 16V АКБ, проверяется по SM (разделы 1701) и TSB. См. [Buying_Checklist.md](Buying_Checklist.md).

## 6. Что сделать сразу после покупки

1. Посмотреть Controls > Service > Maintenance и записать, что и когда делали.
2. Проверить тормозную жидкость тест-полоской (BrakeStrip, Tesla P/N 1510075-00-A, [SM](https://service.tesla.com/docs/Model3/ServiceManual/en-us/GUID-AA717A3B-2077-43B4-B5AF-AF2E3CC9539A.html)). Для машины после аукциона разумно просто заменить жидкость: 750 мл DOT 4.
3. Заменить салонный фильтр (номер детали в [../Parts-Catalog/](../Parts-Catalog/README.md), группа «Heater Assembly and Pollen Filter»).
4. Обслужить суппорты: почистить и смазать направляющие (особенно после стоянки на аукционе).
5. Ротация, проверить развал-схождение (спецификации в [Tolerances_and_Specs.md](Tolerances_and_Specs.md)).
6. Проверить, на каком хладагенте машина (R134a или R1234yf). В Грузии R1234yf дороже и его найти сложнее. ⏳ уточнить у сервисов Тбилиси.
