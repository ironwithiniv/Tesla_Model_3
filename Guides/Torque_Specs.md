# Моменты затяжки Tesla Model 3

Источник: страницы «Torque Specifications – <узел>» официального Service Manual (service.tesla.com), скачано 2026-11-24. Таблицы собраны скриптом из HTML без ручного ввода цифр. Ссылка у каждой строки ведёт на страницу-источник.

- **2017–2023** = [Service Manual Model 3](../Service-Manual/2017-2023_en-us/) (ваш кузов LR AWD 2021–2023).
- **2024+** = [Service Manual Model 3 2024+](../Service-Manual/2024+_Highland_en-us/) (Highland).
- Полные данные: [data/torque_2017-2023.csv](data/torque_2017-2023.csv) и [data/torque_2024+.csv](data/torque_2024+.csv). Колонки: узел, процедура, описание, момент, инструмент, повторное использование крепежа, примечания, URL.

> ⚠️ Для одного и того же болта Tesla иногда даёт разные моменты в разных процедурах или для разных ревизий деталей (пример: болт shear plate заднего подрамника 125 и 130 Nm; болт нижнего поперечного рычага 135 Nm для NA, PN 1109912-00-B, и 190 Nm для EMEA/APAC, PN 2123635-00-A). Перед затяжкой открывайте страницу процедуры и сверяйте номер детали. «Replace» означает, что крепёж одноразовый: болт или гайку менять.
