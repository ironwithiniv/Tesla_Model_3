# Каталог запчастей Tesla (EPC): Model 3 2017–2023

**Источник:** официальный каталог https://parts.tesla.com, регион **United States**, каталог «Model 3 Jun 2017 – Dec 2023», цены в **USD**. Собрано **2026-11-24** через обычный интерфейс сайта в браузере.

Файл: [EPC_Model3_2017-2023_US.csv](EPC_Model3_2017-2023_US.csv). Это 485 позиций из 48 групп по 11 категориям. Мелкий крепёж (болты, гайки, клипсы, шайбы) отфильтрован, кроме нескольких позиций с нестандартными названиями.

Колонки: категория, группа (схема), позиция на схеме, название, номер детали, цена USD, `price_check`, примечание Tesla (обрезано до 90 символов).

> ⚠️ **`price_check = verify`**: в примечании к позиции есть строка «*.» с другой деталью, и цена могла относиться к ней. Пример: «O RING … 1936.64» — это явно цена бочки жидкости EDF, а не кольца. Такие цены не используйте без проверки на сайте.
>
> Цены розничные, по Tesla US, без налога, работы и доставки. Многие крупные узлы помечены «Sold by Tesla; Requires VIN»: их продают только по VIN через сервис Tesla, частнику в Грузию напрямую их не заказать. «Dangerous Goods» (подушки, пиропатроны, HV и LV батареи) — с ограничениями на пересылку.

## Чего нет и что ещё не собрано

- **Бамперы (накладки, fascia):** в группах «Front/Rear Bumper Fascia» видны только кронштейны и нижняя часть заднего бампера, самих крашеных накладок нет. ⏳ проверить поиском по номеру или по цвету.
- **MCU в сборе** Tesla публично не продаёт. Замена или апгрейд только через сервис Tesla. Цены для гайда [Repair_Costs](../Guides/Repair_Costs.md) нужно брать из других источников.
- **Highland 2024+** (каталог «Model 3 Jan 2024») ещё не собран.
- Цены в Грузии и на б/у запчасти — это отдельная задача для `Repair_Costs.md`.

## Как обновить

1. Открыть https://parts.tesla.com, вкладка **Model**, страна **United States**, Model 3, поколение «Jun 2017 – Dec 2023», нажать Search Catalogue.
2. Категория → группа → таблица деталей с ценами.
3. По VIN (вкладка VIN) каталог фильтруется под конкретную машину. Это полезно для кандидатов: [../Candidates/](../Candidates/).
