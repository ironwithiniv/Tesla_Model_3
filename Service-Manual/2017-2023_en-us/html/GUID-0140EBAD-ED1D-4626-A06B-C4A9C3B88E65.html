Actuator - Upper Mode (Heat Pump) (Remove and Replace)

Correction code 18102612 0.48 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-10-26: Added steps to run the HVAC Test Case routine.
  • 2023-10-16: Reorganized the procedure.
Parent topic: 1810 - Cabin HVAC

Remove

  1. Remove the glove box. See Glove Box - With Knee Airbags (Heat Pump) (Remove and Replace).
  2. Disconnect RH upper duct thermistor from RH air wave duct
    Note
    1x connector
  3. Remove the RH air wave duct. See Duct - Air Wave - RH (LHD) (Remove and Replace).
  4. Release the IP harness clip next to the RH upper mode actuator.
  5. Disconnect the upper mode actuator connector.
  6. Remove the bolts (x2) that attach the upper mode actuator to the HVAC assembly.
    Tip
    Use of the following tool(s) is recommended:
    • 6 mm socket
    • 4 in extension
    • Flex head ratchet/flex head torque wrench
  7. Remove the upper mode actuator from the HVAC assembly.

Install

  1. Position the upper mode actuator to the HVAC assembly for installation.
    Note
    Align the guide and push the upper mode actuator toward the HVAC assembly.
  2. Install the bolts (x2) that attach the upper mode actuator to the HVAC assembly.
    1.2 Nm (.9 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 6 mm socket
    • 4 in extension
    • Flex head ratchet/flex head torque wrench
  3. Connect the upper mode actuator connector.
  4. Install the IP harness clip next to the RH upper mode actuator.
  5. Remove the RH air wave duct. See Duct - Air Wave - RH (LHD) (Remove and Replace).
  6. Connect the RH upper duct thermistor to the RH air wave duct.
    Note
    1x connector
  7. Install the glove box. See Glove Box - With Knee Airbags (Heat Pump) (Remove and Replace).
  8. Connect a laptop with Toolbox to the vehicle. See Toolbox (Connect and Disconnect).
  9. Select “Actions” and search for “Actuator”.
  10. Run the routine: TEST-SELF_VCRIGHT_X_HVAC-CASE-ACTUATORSvia Toolbox:(link)
  11. Disconnect the laptop from the vehicle.
  12. Exit Service Mode Plus. See Service Mode Plus.
  13. Raise the front windows and close the front doors.
