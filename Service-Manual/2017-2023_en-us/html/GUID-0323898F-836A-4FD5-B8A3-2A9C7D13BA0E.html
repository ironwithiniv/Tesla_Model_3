Harness - Seat - Driver (Remove and Replace)

Correction code 17101802 0.84 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1133787-00-A Key, Seat Belt Release, Model 3
  • 1082447-07-A Torx Plus T45
Note
The below procedure describes the removal of the driver's seat harness on a LHD model. The procedure for RHD models is similar while illustrations may be mirror-imaged.
Parent topic: 1710 - Harnesses

Remove

  1. Open all four doors.
    Note
    If vehicle is being powered down, Latch rear doors to prevent accidental closure.
  2. Lower all four windows.
  3. Move the front seats forward.
  4. Remove the 2nd row seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  5. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  6. Remove the LH front seat from the vehicle. See Seat Assembly - 1st Row - LH (Remove and Replace).
  7. Install the outboard headrest release tool.
    Note
    Depress the material around the headrest post to expose the release clip, Ensure both tangs of the release tool engage the retaining spring, The release tool is rotated into position, Images show headrest removed for clarity.
  8. Install the inboard headrest release tool.
    Note
    Depress the material around the headrest post to expose the release clip, Ensure both tangs of the release tool engage the retaining spring, The release tool is rotated into position, Images show headrest removed for clarity.
  9. Remove the headrest from the seat.
    Note
    2x locking clips. Remove by pulling straight up, out of the seat.
  10. Remove the inboard headrest release tool.
    Note
    Rotate the release tool out of position. Do not pull straight up or out.
  11. Remove the outboard headrest release tool.
    Note
    Rotate the release tool out of position. Do not pull straight up or out.
  12. Unhook the straps securing the lower seat back section, then move the seat back flap away from the underside of the seat.
  13. Remove the seat back from the LH front seat.
    Note
    8x clips. Start at the top of the seat and pull the shell away from the frame. When the side clips are free, pull the bottom and carefully roll the bottom tabs out of the slots. If pulled straight out, the clips on the seat back can break off. Release remaining clips from underneath seat assembly. Move seat as needed for access.
  14. Remove the upper flap covering the outboard corner of the seat back frame.
    Note
    Pull the upper flap straight up to release from tabs.
  15. Remove the lower flap covering the outboard corner of the seat back frame.
    Note
    Pull the lower section of trim away from the retaining tab to release, then pull the trim straight up off of the upper retaining tab.
  16. Remove the outer clips securing the seat upholstery to the seat back frame.
    Note
    2x clips. To release, rotate the clips off of the frame from the inside out.
  17. Pull the seat upholstery away from the air bag to gain access to the air bag electrical connector.
  18. Disconnect driver seat air bag.
    Note
    1x connector. Pull both of the orange tabs down to release the connector.
  19. Remove the harness clip securing the airbag pigtail to the seat back frame.
    Note
    1x fir tree clip.
  20. Disconnect the recliner motor.
    Note
    1x connector
  21. Disconnect the lumbar valve pack and ECU.
    Note
    1x connector
  22. Disconnect the lumbar pump.
    Note
    1x connector
  23. Remove the seat harness from seat back frame.
    Note
    3x clips
  24. Remove screw securing outer side cover to the seat.
    Note
    1x screw, T20, 4 Nm. Ensure the front of the seat is high enough to access the T20 screw.
  25. Release the outer side cover clip from the seat, but do not remove it.
    Note
    1x clip, Do not fully remove, possible damage to the trim/switch pack/harness
  26. Silde the cover downward to release the outer side cover rear tab from the LH front seat.
    Note
    Do not fully remove to avoid damaging the trim, switch pack, or harness.
  27. Disconnect the LH front seat switch connector.
    Note
    1x connector
    Note
    Use of the following tool(s) is recommended:
    • Pick Miniature Soft Grip, 90 degree tip, 6 in
  28. Remove the outer trim from the LH front seat.
    Note
    Pull the rear of the trim outward, then lift it off the seat, ensuring clearing the cushion and the pretensioner.
  29. Slide outer cover rearward to release clip from frame and lift up over pretensioner to remove the LH front seat outboard side shield.
    Note
    1x clip
  30. Disconnect the seat belt pretensioner.
    Note
    1x connector. Pull both of the orange tabs down to release the connector.
  31. Release seat belt pretensioner harness clips.
    Note
    3x clips. Use 90 pick to release harness clips from seat track rail.
  32. Remove clips securing seat switch harness to seat cushion frame.
    Note
    2x fir tree clips
  33. Rotate the seat to gain access to the underside of the seat.
  34. Use a clip prytool to remove the harness retaining clip under the tilt motor.
    Note
    1x retaining clip
  35. Disconnect the tilt motor connector.
    Note
    1x connector
  36. Route the seat belt pretensioner leg of the seat harness away from the seat.
    Note
    Route the harness leg from behind the tilt motor and away from the bottom of the seat.
  37. Disconnect the seat back heater connector.
    Note
    1x connector, Green
  38. Disconnect the seat cushion heat pad.
    Note
    1x connector
  39. Remove the clip securing the harness to the under side of the seat, next to the seat heater connectors.
    Note
    1x retaining clip
  40. Disconnect the seat occupancy sensor and set the sensor harness pigtail aside.
    Note
    1x connector
  41. Remove and discard the retaining clip that secures the seat occupancy sensor connector to the seat bottom.
    Note
    The new harness comes with the retaining clip installed on the harness connector.
  42. Remove the retaining clip under the main seat harness junction.
    Note
    1x retaining clip
  43. Disconnect the height motor connector.
  44. Remove the clip securing the harness to the seat cushion frame under the lift motor.
    Note
    1x retaining clip
  45. Disconnect the LH front seat track motor connector.
    Note
    1x connector
  46. Disconnect the seat track position sensor connector.
    Note
    1x connector. If this connector is not configured on the vehicle, skip this step.
  47. Remove the inner side shield from the seat.
    Note
    3 x clips. Release the side clips from the seat bottom frame, then pull up on rear of the trim to remove it.
  48. Disconnect the LH front seat buckle connector.
  49. Release the clip that attaches the seat belt buckle connector to the seat cushion frame.
    Note
    1x fir tree clip
  50. Remove the clips securing the seat belt buckle connector harness to the seat cushion frame.
    Note
    2x fir tree clips
  51. Route the seat belt buckle leg of the harness away from the seat to allow the seat harness to be removed.
    Note
    Route the seat belt buckle leg around the lift motor and away from the seat, The harness will be completely free from the seat at this point.

Install

  1. Position the new seat harness for installation.
    Note
    Route the harness under the lift motor and tilt motor placing the harness legs in the correct locations, Harness clips will be installed later
  2. Install the clips securing the seat belt buckle connector harness to the seat cushion frame.
    Note
    2x fir tree clips
  3. Install the clip that attaches the seat belt buckle connector to the seat cushion frame.
    Note
    1x fir tree clip
  4. Connect the LH front seat buckle connector.
  5. Install LH inner side shield to driver seat
    Note
    3x clips, Slide the trim onto the seat from the opening for the buckle, then slide forward into position
  6. Connect the seat track position sensor connector.
    Note
    If this connector is not configured on the vehicle, skip this step.
  7. Install the harness clips to the seat track motor.
  8. Connect the LH front seat track motor connector.
    Note
    1x connector
  9. Connect the height motor connector.
  10. Install the retaining clip under the main seat harness junction.
    Note
    Depending on the harness build date, it may be a tri-clip style or a single clip.
  11. Connect the seat occupancy sensor and install the clip to the seat bottom.
    Note
    1x connector, 1x retaining clip. Ensure the harness is not routed between cushion and frame to avoid friction.
  12. Install the clip securing the harness to the under side of the seat, next to the seat heater connectors.
    Note
    1x retaining clip
  13. Connect the heat pad connector.
    Note
    1x connector
  14. Connect the seat back heater connector.
    Note
    1x connector
  15. Connect the tilt motor connector.
    Note
    1x connector
  16. Install clips securing the seat switch harness to the seat cushion frame.
    Note
    2x fir tree clips
  17. Install seat belt pretensioner harness clips.
    Note
    3x clips. Position seat belt pretensioner harness clips to seat track rail and press down on each clip to secure.
  18. Connect the LH front seat belt pretensioner connector.
    Note
    1x connector
  19. Position the outer side cover to LH front seat and slide forward to secure the rear tab.
    Note
    Apply light pressure to the rear of the outer trim to fully seat it onto the seat frame. A fully installed trim should show no visible metal from the frame and must align with the contour of the seat back.
  20. Connect seat switch connector.
    Note
    1x connector
  21. Secure the outer side cover clip to the LH front seat.
    Note
    Apply pressure to the outer seat trim to fully seat the trim clip. The trim should sit flush against the seat cushion.
  22. Install the screw securing outer side cover to the LH front seat.
    Note
    1x screw, T20, 4 Nm
  23. Rotate the seat to normal upright position.
  24. Install the seat harness to seat back frame.
    Note
    3x clips
  25. Connect the lumbar pump connector.
    Note
    1x connector
  26. Connect the lumbar valve pack and the ECU connector.
    Note
    1x connector
  27. Connect the recliner motor.
    Note
    1x connector
  28. Install the harness clip securing the airbag pigtail to the seat back frame.
  29. Pull the seat upholstery away from the air bag to gain access to the air bag electrical connector.
  30. Connect LH front seat side air bag.
    Note
    1x connector
  31. Install the outer clips securing the seat upholstery to the seat back frame.
    Note
    2x clips
  32. Install the lower flap covering the outboard corner of the seat back frame.
    Note
    Pull the flap over the metal tangs to secure.
  33. Install the upper flap covering the outboard corner of the seat back frame.
    Note
    Pull the flap over the metal tangs to secure.
  34. Install the seat back shell base assembly to seat back frame.
    Note
    6x clips. Install the lower clips first and rotate the shell up into place, Light pressure may need to be applied to the shell to ensure it's fully seated, The headrest posts will engage the seat back when installed.
  35. Hook the strap clips for the seat back shell onto the seat suspension.
    Note
    2x clips, Ensure the straps are tight for proper fit and installation.
  36. Install the headrest into passenger seat.
    Note
    2x locking clips, Ensure the headrest is fully seated, An audible click will be heard when installing the headrest, Ensure the headrest is seated by tugging up on the headrest.
  37. Install the LH front seat into the vehicle. See Seat Assembly - 1st Row - LH (Remove and Replace).
  38. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  39. Remove the 2nd row seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  40. Move LH front seat to original position.
  41. Move RH front seat to original position.
  42. Connect a laptop with Toolbox to the vehicle. See Toolbox (Connect and Disconnect).
  43. Unlock the vehicle gateway. See Gateway (Unlock).
  44. Run the routine to calibrate seat through Toolbox or Service Mode: PROC_VCLEFT_SEAT-CALIBRATEvia Service Mode:Low Voltage ➜ Seats ➜ Calibrate Seatvia Toolbox:(link)
  45. Disconnect the laptop from the vehicle. See Toolbox (Connect and Disconnect).
  46. Raise all windows and close all four doors.
    Note
    Unlatch rear doors before closing.
