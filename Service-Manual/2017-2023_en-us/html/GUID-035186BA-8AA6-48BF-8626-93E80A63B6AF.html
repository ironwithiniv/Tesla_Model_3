Hub - Front - LH (RWD) (Remove and Replace)

Correction code 31010602 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-10-27: Added note to refer to the Collision Repair Manual to verify whether the steering gear must be replaced.
  • 2025-04-02: Updated steps to remove and install the brake rotor.
CAUTION
If performing this procedure as a result of a collision, see the Collision Repair Manual to verify whether the steering gear must be replaced as well.
Equipment:
  • 1062500-00-A Card, Magnetic Field Viewer
  • 1082171-00-A S-Hook
Parent topic: 3101 - Front Suspension (Including Hubs)

Torque Specifications

Table 1. Torque Specifications: Hub - Front - LH (RWD) (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts that attach the LH front hub to the knuckle
85 Nm (62.7 lbs-ft)
  • 18 mm socket
 Reuse

Remove

  1. Remove LH front wheel. See Wheel Assembly (Remove and Install).
  2. Remove the bolt that attaches the LH front brake hose bracket to the LH front knuckle.
    5 Nm (3.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  3. Remove and discard the bolts that attach the LH front caliper to the LH front knuckle, remove the caliper from the knuckle, and allow the caliper to hang from an S-hook.
    94 Nm (69.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • External Torx E18
    Note
    If needed, use the caliper spreader tool to push the caliper pistons to the fully open position.
  4. Remove the bolt that attaches the brake rotor to the hub, and then remove the brake rotor from the hub.
    5 Nm (3.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  5. Remove the bolts that attach the LH front hub to the knuckle, and then remove the hub from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • 18 mm socket

Install

  1. Check the tone ring on the LH front hub prior to installation: Use a magnetic field viewing card to make sure that the magnetic field on the tone ring is not damaged.
  2. Position the LH front hub on the knuckle, and then install the bolts that attach the hub to the knuckle.
    85 Nm (62.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 18 mm socket
  3. Position the brake rotor onto the hub, and then install the bolt that attaches the rotor to the hub.
    5 Nm (3.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  4. Position the LH front caliper onto the LH front knuckle, and then install new bolts that attach the caliper to the knuckle.
    94 Nm (69.3 lbs-ft)
    CAUTION
    Make sure the brake caliper and hoses are not twisted when hanging the caliper or during reinstallation, as this can damage the brake hose.
    Tip
    Use of the following tool(s) is recommended:
    • External Torx E18
    Note
    If needed, use the caliper spreader tool to push the caliper pistons to the fully open position.
  5. Position the LH front brake hose bracket to the LH front knuckle, and then install the bolt that attaches the bracket to the knuckle.
    5 Nm (3.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  6. Install LH front wheel. See Wheel Assembly (Remove and Install).
  7. Refer to the Alignment Requirement tables to determine whether an EPAS alignment check (EC) or four wheel alignment check (AC) is necessary. If performed, add the alignment check/adjust correction code as a separate activity to the SV. See Alignment Requirement - Suspension.
