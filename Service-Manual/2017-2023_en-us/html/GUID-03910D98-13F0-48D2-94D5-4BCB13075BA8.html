Bracket - Corner - Active Hood - LH (Remove and Replace)

Correction code 20302102 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 2030 - Pedestrian Protection System

Remove

  1. Open the LH front door and lower the LH front window.
  2. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  3. Release the LH active hood corner bracket from the vehicle.
    Note
    If necessary, use IPA wipes to clean the double-sided tape from the fender.

Install

  1. Remove the double sided tape backing, and then install the LH active hood corner bracket into the vehicle.
  2. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  3. Raise the LH front window and close the LH front door.
