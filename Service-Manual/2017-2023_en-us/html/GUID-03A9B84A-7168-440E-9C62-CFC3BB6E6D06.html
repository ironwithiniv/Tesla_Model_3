Striker - Hood (Remove and Replace)

Correction code 11352902 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1135 - Latches Strikers and Pinch Sensors

Torque Specifications

Table 1. Torque Specifications: Striker - Hood (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts that attach the striker to the hood
18 Nm (13.3 lbs-ft)
  • Torx T40 socket
 Reuse Do not torque until vehicle is within gap and flush specification

Remove

  1. Open the hood.
  2. Use masking tape to mark the location of the hood striker on the hood assembly.
  3. Use a T40 socket to remove the bolts that attach the hood striker to the hood, and then remove the striker from the hood.

Install

  1. Install the striker on to the hood, but do not fully torque the bolts.
    Note
    Use the masking tape and hood indentations as a guide.
  2. Close the hood and use the gap and flush tool to verify alignment is within specification.
  3. Open the hood and adjust the striker position as necessary.
  4. Repeat step 2 and step 3 until alignment is satisfactory.
  5. Fully tighten the bolts.
    18 Nm (13.3 lbs-ft)
  6. Remove the masking tape, and then close the hood.
