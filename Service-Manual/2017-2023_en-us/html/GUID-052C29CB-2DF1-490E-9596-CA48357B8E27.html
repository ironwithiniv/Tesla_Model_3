Tie Rod - Inner - LH (Remove and Replace)

Correction code 32013202 FRT 0.48 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-05-21: Added recommended tooling.
  • 2025-12-16: Released new procedure.
CAUTION
If performing this procedure as a result of a collision, see the Collision Repair Manual to verify whether the steering gear must be replaced as well.
Equipment:
  • 2162868-00-A (Plier Inner Tie Rod Replacement tooling)
Parent topic: 3201 - Steering Rack and Lower Column

Remove

  1. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift
  2. Open LH front door
  3. Lower LH front window
  4. Remove the LH front wheel arch liner. See Wheel Arch Liner - Rear - LH (Remove and Replace)
  5. Remove and discard the nut that secures the LH front tie rod end to the LH front knuckle.
    Note
    Use of the following tool(s) is recommended:
    • 22 mm socket
    180 Nm (132.7 lbs-ft)
  6. Remove the LH front tie rod end from the LH front knuckle.
    Tip
    Move the rotor back and forth for easier removal.
  7. Remove and discard the large clamp from the bellows.
  8. Remove the seal clip from the bellows.
  9. Slide the bellows toward the LH outer tie rod end to access the ball joint.
  10. Remove the LH tie rod assembly from the pinion housing.
    Note
    Use of the following tool(s) is recommended:
    • 38 mm 6-point flare nut crowfoot socket (mount at 90 degrees) (see Using Crowsfoot or Offset Extensions on Torque Wrenches)
    • Breaker bar
    • Extension
    88 Nm (64.9 lbs-ft)

Install

  1. Turn the jam nut on the new tie rod to adjust the length and match the old tie rod before installation.
    Tip
    Count the threads on the removed tie rod, then adjust to the same count on the new one. This will make alignment adjustment easier.
    Note
    Use of the following tool(s) is recommended:
    • 21 mm 12 pt combination wrench
    • 14 mm 12 pt combination wrench
    • Extension
  2. Install the LH inner tie rod assembly onto the pinion housing.
    Note
    Use of the following tool(s) is recommended:
    • 38 mm 6-point flare nut crowfoot socket (mount at 90 degrees) (see Using Crowsfoot or Offset Extensions on Torque Wrenches)
    • Breaker bar
    • Extension
    88 Nm (64.9 lbs-ft)
  3. Slide the bellows into the clamping position.
  4. Secure the large bellows clamp onto the bellows.
    Tip
    Use of the following tool(s) is recommended:
    • 2162868-00-A (Plier Inner Tie Rod Replacement tooling)
  5. Secure the bellows seal clip onto the bellows.
  6. Position the LH front tie rod end to the LH front knuckle.
  7. Install a new nyloc nut to secure the LH tie rod end to the LH front knuckle
    Note
    Use of the following tool(s) is recommended:
    • 22 mm socket
    180 Nm (132.7 lbs-ft)
  8. Remove the LH front wheel arch liner. See Wheel Arch Liner - Rear - LH (Remove and Replace)
  9. Remove the vehicle from the lift. See Raise Vehicle - 2 Post Lift
  10. Raise the windows and close the doors.
  11. Review the wheel alignment requirements and add correction code as needed. See Alignment Requirement - Suspension
