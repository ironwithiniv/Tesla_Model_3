Hall Sensor - Exterior Release - Door - Rear - LH (Remove and Replace)

Correction code 11455102 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1145 - Exterior Door Handles

Remove

  1. Remove the rear LH door trim panel. See Panel - Door Trim - Rear - LH (Remove and Install).
  2. Remove the LH rear door inner belt seal. See Seal - Inner Belt - Rear Door - LH (Remove and Replace).
  3. Remove the rear LH door glass. See Glass - Door - LH - Rear (Remove and Replace).
  4. Remove the LH rear window motor/regulator assembly. See Window Regulator - Rear - LH (Remove and Replace).
  5. Remove the LH rear door exterior release handle. See Handle - Exterior Release - Door - Rear - LH (Remove and Replace).
  6. Remove the screws that attach the hall sensor to the LH rear door exterior handle, and then remove the sensor from the handle.

Install

  1. Install the screws (x2) that attach the new hall sensor to the door handle.
    1.2 Nm (.9 lbs-ft)
  2. Install the LH rear door exterior release handle. See Handle - Exterior Release - Door - Rear - LH (Remove and Replace).
  3. Position the LH rear window motor/regulator assembly onto the door for installation.
  4. Install the bolts that attach the LH rear window motor/regulator assembly to the door.
    4 Nm (2.9 lbs-ft)
    Note
    Hand start the bolts to avoid stripping the threads.
  5. Install the clips (x2) that attach the manual latch release cable to the window regulator panel.
  6. Position the window glass onto the door for installation.
  7. Install the new bolts that attach the window glass to the regulator isolator clamps.
    12 Nm (8.8 lbs-ft)
  8. Install the clips (x6) that attach the inner belt seal to the door.
  9. Connect the window switch special tool.
  10. Connect the electrical connector to the LH rear door puddle light.
  11. Raise the window fully and close the LH rear door.
  12. Adjust the gap and flush of the door glass, if necessary. See Glass - Door - LH - Rear (Adjust).
  13. Disconnect the window switch special tool.
  14. Connect the LH rear window motor/regulator assembly electrical connector.
  15. Install the plugs (x2) that cover the LH rear window motor/regulator assembly bolts.
  16. Disconnect the electrical connector from the LH rear door puddle light.
  17. Install the rear LH door trim panel. See Panel - Door Trim - Rear - LH (Remove and Install).
  18. Connect a laptop with Toolbox 3 to the vehicle.
  19. Get into the driver seat, and then close the LH front door.
  20. In Toolbox, type "window" in the search field.
    Note
    Make sure "Actions" is selected, if not already.
  21. Click on the Play button next to TEST-SELF_VCLEFT_REAR-L_CALIBRATE-WINDOWvia Toolbox:(link), and then select Run.
  22. Press the LH rear window switch down to the lowest position to activate the auto-lower function, and allow the window to lower completely.
    Note
    If the window does not lower completely, repeat step 20 and step 21.
  23. Pull on the switch to the highest position to activate the auto-raise function, and allow the window to raise completely.
    Note
    If the window does not raise completely, repeat step 20 and step 21.
