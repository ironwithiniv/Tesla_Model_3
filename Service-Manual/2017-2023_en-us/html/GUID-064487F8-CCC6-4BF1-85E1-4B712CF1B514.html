Charge Port Lubrication (China)

Correction code 44019566 0.66 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1450424-00-A Mini Ratchet Bit Set
Parent topic: 4401 - Charge System Inlet

Remove

  1. Remove the charge port latch pin. See Latch Pin - AC - Charge Port (China) (Remove and Replace).

Install

  1. Inspect AC and DC pins, replace the charge port assembly it if the pin is bent, Please replace.
  2. Apply efficient amount of lubricant to lubricate the AC latch stick and the o-ring.
  3. Install the charge port latch pin. See Latch Pin - AC - Charge Port (China) (Remove and Replace).
