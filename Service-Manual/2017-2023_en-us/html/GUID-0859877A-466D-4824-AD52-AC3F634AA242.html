Check Base - Sun Visor - LH (Remove and Replace)

Correction code 15051052 0.06 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1080559-20-A TOOL, TORQUE SCREWDRIVER, 0.8-2.0NM (NA, APAC)
  • 1080559-21-A TOOL, TORQUE SCREWDRIVER, 0.8-2.0NM (EMEA)
Parent topic: 1505 - Interior Mirror and Sun Visors

Torque Specifications

Table 1. Torque Specifications: Check Base - Sun Visor - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolt that attaches the sun visor check base to the body
0.8 Nm (7 lbs-in)
  • Torx T15 socket
 Reuse

Remove

  1. Release the sun visor from the check base.
  2. If the vehicle is equipped with a newer type magnetic check base, use a plastic trim tool to remove the check base. For the bolt-on version, proceed with the next steps.
  3. Carefully release the clips that attach the sun visor check cover to the check base, and then remove the cover from the vehicle.
  4. Remove the bolt that attaches the sun visor check base to the body, and then remove the check base from the vehicle.
    0.8 Nm (7 lbs-in)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T15 socket
    CAUTION
    To avoid damage, ensure this torque specification is followed and power tools are not used during installation.

Install

Installation procedure is the reverse of removal.

CAUTION
To avoid damage, do not forcefully pull on or twist the check base to confirm that it is secured to the headliner.
Note
For the bolt-on version: make sure the fastener used in installation is part number 1120162-00-B or later. The torque specification is different on older fasteners.
