Tesla Badge - Front (Remove and Replace)

Correction code 12050502 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  1. 2025-01-30: Updated procedure with newer version of T-badge jig and added additional pictures.
Special tools required for this procedure:
Equipment:
  • 1453028-00-A KIT, BADGE REMOVAL
  • 1600744-00-B M3Y FRONT BADGE JIG
  1. 2025-01-30: Updated tool info, revised procedure and added pictures.
Parent topic: 1205 - Badges and Films

Remove

Note
The badge cannot be reinstalled if removed. If the badge is removed for any reason, it must be replaced with a new part.
  1. Prepare the badge removal tool with approximately 60 centimeters of monofilament line.
  2. With the hood closed, position the badge removal tool so that the monofilament line cuts under a corner of the front Tesla badge.
  3. Move the badge removal tool in a sawing motion to separate the front Tesla badge from the hood.
  4. Use IPA wipes to clean all adhesive residue and debris from the hood surface.

Install

  1. Open the hood.
  2. Install the groove of the front T-badge jig onto the hood striker.
  3. Put a folded shop towel over the latch to prevent the hood from closing, and then lower the hood.
  4. Peel the adhesive backing from the hood badge, align the holes in the badge protective film with the datums on the T-badge jig, and then press the badge to the hood.
  5. Wet out the T-badge using a seam roller, and the remove the protective film from the T-badge.
  6. Remove the T-badge jig from the hood.
  7. Remove the shop towel from the latch, and then close the hood.
  8. Use an IPA wipe to clean the badge and any remaining debris.
    Note
    Make sure that all edges of the badge are securely affixed to the hood surface.
