Harness - Airbag - Driver (Remove and Replace)

Correction code 20013102 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
Make sure 12V/LV power has been disconnected for at least 1 minute before disconnecting the electrical harness from Supplementary Restraint System (SRS) components, such as Restraint Control Module, sensors, airbags, etc. Disconnect the 12V/LV battery and the First Responder Loop. Failure to do so can result in unintended safety system behaviors. For more information on SRS precautions, see Airbag and Supplementary Restraint System (SRS) Precautions.
Warning
Supplementary restraint system (SRS) components can be hazardous if not handled properly. See Airbag and Supplementary Restraint System (SRS) Precautions.
Parent topic: 2001 - Airbags

Remove

  1. Remove the driver air bag. See Airbag - Driver (Remove and Replace).
  2. Cover the entire driver-facing side of the airbag with protective tape.
  3. Place the driver air bag on a clean working surface.
  4. Release the locking tabs (x3) that attach the driver airbag harness to the airbag.
  5. Disconnect the electrical harness connectors (x3) from the driver airbag.

Install

  1. Connect the driver airbag harness connectors to the driver airbag, and then install the locking tabs (x3).
    Note
    The 3 connectors are color coded. Match the color on the harness connector to the same color connector on the airbag.
  2. Remove the protective tape from the airbag.
  3. Install the driver airbag. See Airbag - Driver (Remove and Replace).
