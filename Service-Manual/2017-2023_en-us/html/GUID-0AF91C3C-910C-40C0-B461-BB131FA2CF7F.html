Switch - Interior Door Release - Front - LH (Remove and Replace)

Correction code 15131602 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1513 - Door Trim

Remove

  1. Remove the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace) .
  2. Release the NVH pad from the tabs (X4), then remove the pad from the LH door panel.
  3. Carefully pry on the door trim panel to remove the bolt that attaches the interior door release handle switch to the door trim panel.
    6 Nm (4.4 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • Torx T20 socket
      CAUTION
      Pry carefully and do not damage the plastic rivets. Damage to the rivets could compromise the integrity of the door trim panel.
  4. Use a pin drag kit to separate the pins (x3) from the interior door release switch electrical connector.
    Note
    Mark the position of pins and the electrical connector.
    Note
    Separate the pins and plug to ensure that they can pass through the narrow trim panel space.
  5. Apply masking tape around the work area to protect the door trim panel.
  6. Use a trim tool to separate the front portion of the interior door handle from the interior release switch.
  7. Release the tabs (x2), and then remove the interior door release switch from the door trim panel.

Install

  1. Use a pin drag kit to separate the pins from the new connector.
    Note
    Mark the position of pins and the electrical connector.
  2. Install the tabs (x2) that attach the interior door release switch to the door trim panel.
  3. Secure the pins to the connector.
  4. Attach the front portion of the interior door handle to the interior release switch.
  5. Gently pry on the door trim panel to install the bolt that attaches the interior door release handle switch to the door trim panel.
    6 Nm (4.4 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • Torx T20 socket
    CAUTION
    Pry carefully and do not damage the plastic rivets. Damage to the rivets could compromise the integrity of the door trim panel.
    CAUTION
    Replace the door trim panel if the plastic rivets are damaged during service.
  6. Secure the NVH pad onto the tabs (X4), then install the NVH pad from the LH door panel.
  7. Install the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace) .
