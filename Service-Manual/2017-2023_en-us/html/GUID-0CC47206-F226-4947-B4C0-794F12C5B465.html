Software Reinstall - Toolbox

Correction code 00020008 0.06 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2023-06-08: Updated Li-Ion instructions: Vehicle software version 2023.12 or newer is required, and consolidated "contactors closed" and "contactors open" procedures.
Note
This procedure describes how to reinstall the currently installed vehicle software using a laptop with Toolbox 3 locally connected. The package will not be downloaded from Tesla servers.
The software reinstall process varies depending on whether the vehicle is equipped with a lead acid or li-ion battery.
  • Firmware Redeploy (Lead Acid Battery)
  • Software Reinstall (Li-Ion Battery)
Parent topic: 0002 - Firmware Service

Firmware Redeploy (Lead Acid Battery)

  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Connect a LV battery maintainer to make sure power is not lost during the software reinstall.
    CAUTION
    If using a 50A or 80A maintainer, make sure the maintainer is set to "Lead Acid" or "Half Power" mode. Failure to do so could damage the LV battery.
  3. Connect a laptop with Toolbox 3 to the vehicle. See Toolbox (Connect and Disconnect).
    Note
    Locally connecting the vehicle to Toolbox 3 will automatically enable Service Mode Plus.
  4. In Toolbox, select the Actions/Autodiag tab, and then search for "redeploy".
  5. Run the UPDATE_CAN-REDEPLOYvia Service Mode Plus:
    • Drive Inverter Replacement ➜ Drive Inverter DIRE1L Replacement ➜ CAN Redeploy
    • Drive Inverter Replacement ➜ Drive Inverter DIRE1R Replacement ➜ CAN Redeploy
    • Drive Inverter Replacement ➜ Drive Inverter DIRE2 Replacement ➜ CAN Redeploy
    • Drive Inverter ➜ Front Drive Inverter Replacement ➜ CAN Redeploy
    • Drive Inverter ➜ Rear Drive Inverter Replacement ➜ CAN Redeploy
    • Drive Inverter ➜ Rear Left Drive Inverter Replacement ➜ CAN Redeploy
    • Drive Inverter ➜ Rear Right Drive Inverter Replacement ➜ CAN Redeploy
    • Drive Unit ➜ Front Drive Unit Replacement ➜ CAN Redeploy
    • Drive Unit ➜ Rear Drive Unit Replacement ➜ CAN Redeploy
    • HVAC Blower ➜ HVAC Blower Replacement ➜ Firmware Redeploy
    • Thermal ➜ HVAC ➜ CAN Redeploy
    • chassis ➜ DPB Post Replacement ➜ CAN Redeploy
    • chassis ➜ ESP Post Replacement ➜ CAN Redeploy
    • chassis ➜ IDB Post Replacement ➜ CAN Redeploy
    • chassis ➜ RCU Post Replacement ➜ CAN Redeploy
    • chassis ➜ ESP Replacement Panel ➜ CAN Redeploy
    • chassis ➜ IBST Replacement Panel ➜ CAN Redeploy
    via Toolbox:(link)     routine and wait for the reinstallation to complete. Reinstallation status can be monitored on the vehicle touchscreen.
    Tip
    "UPDATE_CAN-REDEPLOY" is a partial software reinstallation that reinstalls the currently installed software package to all module, ECU, and component replacements, with the exception of the car computer.
  6. Once the reinstallation is complete, check that the release notes appear on the touchscreen, indicating a successful reinstallation.
  7. Disconnect the LV battery maintainer.
  8. Disconnect the laptop from the vehicle. See Toolbox (Connect and Disconnect).
  9. Disable Service Mode. See Service Mode.
  10. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).

Software Reinstall (Li-Ion Battery)

CAUTION
Vehicle software version 2023.12 or newer is required in order to perform this procedure.
  1. Connect the LV maintainer to the vehicle, but do not disconnect the LV battery. See LV Maintainer (Connect and Disconnect).
    Note
    It is OK for the LV maintainer and LV battery to both be connected while performing this procedure.
  2. Connect a laptop with Toolbox 3 to the vehicle. See Toolbox (Connect and Disconnect).
    Note
    Locally connecting the vehicle to Toolbox 3 will automatically enable Service Mode Plus.
  3. In Toolbox, select the Actions/Autodiag tab, and then search for "redeploy".
  4. Run the UPDATE_CAN-REDEPLOYvia Service Mode Plus:
    • Drive Inverter Replacement ➜ Drive Inverter DIRE1L Replacement ➜ CAN Redeploy
    • Drive Inverter Replacement ➜ Drive Inverter DIRE1R Replacement ➜ CAN Redeploy
    • Drive Inverter Replacement ➜ Drive Inverter DIRE2 Replacement ➜ CAN Redeploy
    • Drive Inverter ➜ Front Drive Inverter Replacement ➜ CAN Redeploy
    • Drive Inverter ➜ Rear Drive Inverter Replacement ➜ CAN Redeploy
    • Drive Inverter ➜ Rear Left Drive Inverter Replacement ➜ CAN Redeploy
    • Drive Inverter ➜ Rear Right Drive Inverter Replacement ➜ CAN Redeploy
    • Drive Unit ➜ Front Drive Unit Replacement ➜ CAN Redeploy
    • Drive Unit ➜ Rear Drive Unit Replacement ➜ CAN Redeploy
    • HVAC Blower ➜ HVAC Blower Replacement ➜ Firmware Redeploy
    • Thermal ➜ HVAC ➜ CAN Redeploy
    • chassis ➜ DPB Post Replacement ➜ CAN Redeploy
    • chassis ➜ ESP Post Replacement ➜ CAN Redeploy
    • chassis ➜ IDB Post Replacement ➜ CAN Redeploy
    • chassis ➜ RCU Post Replacement ➜ CAN Redeploy
    • chassis ➜ ESP Replacement Panel ➜ CAN Redeploy
    • chassis ➜ IBST Replacement Panel ➜ CAN Redeploy
    via Toolbox:(link)     routine and wait for the reinstallation to complete. Reinstallation status can be monitored on the vehicle touchscreen.
    Tip
    "UPDATE_CAN-REDEPLOY" is a partial software reinstallation that reinstalls the currently installed software package to all module, ECU, and component replacements, with the exception of the car computer.
  5. Once the reinstallation is complete, check that the release notes appear on the touchscreen, indicating a successful reinstallation.
  6. Disconnect the LV maintainer from the vehicle. See LV Maintainer (Connect and Disconnect).
  7. Disconnect the laptop from the vehicle. See Toolbox (Connect and Disconnect).
  8. Disable Service Mode. See Service Mode.
  9. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
