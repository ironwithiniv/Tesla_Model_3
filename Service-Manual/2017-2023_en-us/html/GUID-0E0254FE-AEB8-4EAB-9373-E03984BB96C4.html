Valve Body - EXV - Supermanifold (Heat Pump) (Remove and Replace)

Correction code 18401302 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-05-14: Added the step of checking the refrigerant system pressure, and removed the first responder loop steps and Thermal/HVAC performance test steps.
  • 2025-04-10: Added Note to separately adding correction code 18200102 for refrigerant recovery/recharge and updated steps related to running ODIN routines.
  • 2023-04-04: Updated A/C oil type to be used with reference to Fluids and Capacities for A/C oil specifications.
Note
This procedure requires the A/C Refrigerant (Recovery and Recharge) procedure to be performed. If not already automatically added to the Service Visit, add correction code 18200102 as a separate correction within the same activity to the Service Visit.

This procedure is to remove and replace any of the electronic expansion valves.

Parent topic: 1840 - Supermanifold

Remove

  1. Set up A/C machine .
  2. Open the LH front door and lower the LH front window.
  3. Perform the routine using Service Mode or Toolbox: PROC_VCFRONT_X_START-THERMAL-FILL-DRAIN-REFRIGERANTvia Toolbox:(link)
    Note
    Via Service Mode: Thermal ➜ Refrigerant System ➜ Start Refrigerant Fill/Drain
    Note
    Select "X" at top right of window to close once complete, Thermal Fluid Fill/Drain routine has a 5 hour time limit, After 5 hours EXV's will close and routine must be performed again, Verify EXV positions are open VIA Garage >Thermal > Refrigerant loop EXV, Verify LCC, CC Left, Evap, CC Right, Chiller are all at ~100%. Recirc is at ~20%, LCC Solenoid is OPENED
  4. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  5. Recover the refrigerant from the vehicle. See A/C Refrigerant (Recovery and Recharge).
  6. On the touchscreen, make sure that the refrigerant system pressure is at atmospheric level (approx. 1 bar).
    Note
    On the touchscreen, touch Service Mode > Thermal > Refrigerant System.
  7. On the touchscreen, tap Safety > Power Off to power off the vehicle.
  8. Remove A/C hoses from the vehicle.
  9. Carefully depress the Schrader valves (x2) to level out any pressure difference between the A/C system pressure and the actual ambient atmospheric pressure.
    CAUTION
    Make sure to depress both Schrader valves. Failure to do so may result in injury.
  10. Remove the bolt that attaches the supermanifold-to-compressor A/C line to the supermanifold.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  11. Remove the supermanifold-to-compressor A/C line from the supermanifold, and then hang it on the underhood storage unit support beam using an s-hook.
    Note
    Carefully hang the line so that oil does not drip out.
  12. Release the connector locks, and then disconnect the electrical connectors leading up to the desired EXV. Follow the disconnect order in the example image.
    CAUTION
    DO NOT push down on the red locking tab. Pull the tab away from the connector until the connector is unlocked, and then continue pulling the main body of the connector to fully disconnect it.
    Note
    The disconnect order is for ease of access.
  13. Release the locking tab, and then disconnect the electrical connector from the desired EXV.
    CAUTION
    DO NOT push down on the red locking tab. Pull the tab away from the connector until the connector is unlocked, and then continue pulling the main body of the connector to fully disconnect it.
  14. Remove the supermanifold harness from the supermanifold.
  15. Use a pick to pull the locking tab downward, and then pull toward the front of the vehicle to remove the EXV coil.
  16. Remove the EXV valve body from the supermanifold.
    Tip
    Use of the following tool(s) is recommended:
    • 1588745-00-A - Expansion Valve Socket, 28mm, 1/2" Drive

Install

  1. Lubricate the EXV threads and O-rings with the appropriate A/C oil. See Fluids and Capacities for A/C oil specifications. Then hand-start the valve into the supermanifold.
  2. Fully torque the EXV on the supermanifold.
    19 Nm (14.0 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 1588745-00-A - Expansion Valve Socket, 28mm, 1/2" Drive
  3. Install the EXV coil onto the EXV.
    Note
    Align the locking tab on the connector assembly with the recess in the EXV.
  4. Connect the electrical connectors that were disconnected during removal, and then engage the connector locks.
  5. Install new seal washers on the supermanifold side of the supermanifold-to-compressor A/C line, and then lubricate the washers with a small amount of the appropriate A/C oil. See Fluids and Capacities for A/C oil specifications..
  6. Position the supermanifold-to-compressor A/C line on the supermanifold, and then hand tighten the bolt that attaches the A/C line to the supermanifold.
  7. Tighten the bolt that attaches the A/C line to the supermanifold.
    22 Nm (16.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  8. Perform A/C vacuum test, and then recharge the refrigerant. See A/C Refrigerant (Recovery and Recharge).
  9. Unlock the vehicle gateway. See Gateway (Unlock).
  10. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): TEST-SELF_VCFRONT_X_HEAT-PUMP-COMMISSIONINGvia Service Mode:Thermal ➜ Refrigerant System ➜ Commission Heat Pumpvia Service Mode Plus:Drive Inverter ➜ Front Drive Inverter Replacement ➜ Heatpump commissioningvia Toolbox:(link)
    Note
    If this routine is not run after entering Thermal Drain/Fill mode, the AC compressor operation will be blocked, Select "X" at top right of window to close once complete
  11. Exit Service Mode. See Service Mode.
  12. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
