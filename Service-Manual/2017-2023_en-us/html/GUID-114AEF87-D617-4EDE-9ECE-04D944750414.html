Module - Cooling Fan (Remove and Install)

Correction code 18201301 1.20 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-10-16: Added post-repair routine.
  • 2026-07-02: Added thermal performance test and note that correction code for refrigerant recovery/recharge must be separately added.
  • 2025-09-17: Updated part information.
  • 2023-11-20: Added suction/liquid line and discharge line O-ring images and part numbers.
Note
This procedure services the cooling fan module on pre-heat pump vehicles. To perform this procedure on heat pump vehicles, go here.
Note
This procedure requires the A/C Refrigerant (Recovery and Recharge) procedure to be performed. If not already automatically added to the Service Visit, add correction code 18200102 as a separate correction within the same activity to the Service Visit.
Parent topic: 1820 - Refrigerant System

Remove

  1. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  2. Remove the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  3. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  4. Remove the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  5. Remove the outer HVAC plenum duct. See Plenum - Inlet - HVAC (Remove and Replace).
  6. Remove the hood latch cover. See Cover - Hood Latch (Remove and Replace).
  7. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  8. Perform the A/C refrigerant recovery. See A/C Refrigerant (Recovery and Recharge).
  9. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  10. Disconnect the active grille shutter electrical connector.
  11. Remove the bolts that attach the underhood storage unit reinforcement bracket to the cooling fan, and then slide the reinforcement bracket aside for clearance.
  12. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  13. Remove the front fascia valance. See Valance - Front Fascia (Remove and Replace).
  14. Disconnect the electrical harness from the cooling fan module connector.
  15. Place coolant drain container underneath the LH front side of the vehicle.
  16. Release the clip that attaches the radiator inlet hose to the cooling fan module, remove the hose, and then plug the hose.
  17. Place coolant drain container underneath the RH front side of the vehicle.
  18. Release the clip that attaches the radiator outlet hose from the cooling fan module, remove the hose, and then plug the hose.
  19. Remove the coolant drain container from underneath the vehicle.
  20. Make sure that the refrigerant has fully recovered before continuing this procedure.
  21. Remove the nut that attaches the suction/liquid line to the cooling fan module, and then disconnect the A/C suction line.
  22. Remove and discard the O-ring from the suction/liquid line.
  23. Remove the nut that attaches the discharge line to the cooling fan module, and then disconnect the discharge line.
  24. Remove and discard the O-ring from the discharge line.
  25. Remove the bolts that attach the lower LH and RH of the cooling fan module to the ankle catcher.
    Note
    Lift up on the cooling fan module to ease the removal of the bolts.

Install

  1. With an assistant, put the cooling fan module into position from below the vehicle, and then hand-tighten the bolts that attach the bottom of the cooling fan module to the ankle catcher.
    Note
    Make sure that the lower seal from the cooling fan module and lower active shutter grille are sitting flush against each other.
  2. Tighten the LH and RH bolts that attach the lower portion of the cooling fan module to the ankle catcher.
    10 Nm (7.4 lbs-ft)
  3. Install a new o-ring (part number 1111738-00-A) onto the discharge line, and then install the discharge line into the cooling fan module.
  4. Install the nut that attaches the discharge line to the cooling fan module.
    22 Nm (16.2 lbs-ft)
  5. Install a new o-ring (part number 1111737-00-A) onto the suction/liquid line, and then install the suction line into the cooling fan module.
  6. Install the nut that attaches the suction/liquid line to the cooling fan module.
    22 Nm (16.2 lbs-ft)
  7. After installing the suction/liquid line, recharge the refrigerant. See A/C Refrigerant (Recovery and Recharge).
    Note
    Perform installation of components removed concurrently with refrigerant recharge.
  8. Position the coolant drain underneath the RH side of the vehicle.
  9. Remove the hose plug, and then install the radiator outlet hose to the cooling fan module. Secure the hose with clip.
  10. Position the coolant drain underneath the LH side of the vehicle.
  11. Remove the hose plug, and then install the radiator inlet hose to the cooling fan module. Secure the hose with clip.
  12. Remove the coolant drain container from underneath the vehicle.
  13. Connect the electrical harness to the cooling fan connector.
  14. Install the front valance. See Valance - Front Fascia (Remove and Replace).
  15. Install the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  16. Lower the vehicle fully.
  17. Slide the underhood reinforcement bracket onto the top of the cooling fan module.
    Note
    The cooling fan module tab must be inserted into the isolator so that the trailing tab touches the isolator rubber and the chamfered edge is clearly visible when looking from above.
    Note
    The trailing edge of the cooling fan module mount must contact the lower tunnel of the isolator.
  18. Install the bolts that attach the underhood reinforcement bracket to the body.
    16 Nm (11.8 lbs-ft)
    Note
    Make sure that there is space between the cooling fan module and the isolator bar to avoid vibration.
  19. Loosen the bolts that attach the LH side cooling fan module isolator.
  20. Push the LH side of the cooling fan module isolator towards the front of the vehicle until the isolator bottoms out at the top.
  21. Tighten the bolts that attach the LH side cooling fan module isolator.
    6 Nm (4.4 lbs-ft)
  22. Repeat step 19 through step 21 for the RH side cooling fan module isolator.
  23. Check the coolant level at the superbottle and add coolant to the full line, if needed.
  24. Connect the active grille shutter electrical connector.
  25. Connect 12V power. See 12V/LV Power (Disconnect and Connect).
  26. After the A/C refrigerant recharge has fully completed, verify the operation of the A/C system.
  27. Perform the cooling system vacuum refill. See Cooling System (Vacuum Refill).
  28. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): TEST-SELF_VCFRONT_X_THERMAL-PERFORMANCEvia Service Mode:Thermal ➜ Actions ➜ Test Thermal Performancevia Service Mode Plus:
    • Drive Inverter ➜ Front Drive Inverter Replacement ➜ Thermal System Test
    • Drive Inverter ➜ Rear Drive Inverter Replacement ➜ Thermal System Test
    • Drive Inverter ➜ Rear Left Drive Inverter Replacement ➜ Thermal System Test
    • Drive Inverter ➜ Rear Right Drive Inverter Replacement ➜ Thermal System Test
    • Drive Unit ➜ Front Drive Unit Replacement ➜ Thermal System Test
    • Drive Unit ➜ Rear Drive Unit Replacement ➜ Thermal System Test
    via Toolbox:(link)
    Note
    Select the "X" at the top right of the window to close once the routine is complete.
  29. Exit Service Mode. See Service Mode.
  30. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  31. Install the hood latch cover. See Cover - Hood Latch (Remove and Replace).
  32. Install the outer HVAC plenum duct. See Plenum - Inlet - HVAC (Remove and Replace).
  33. Install the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  34. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
