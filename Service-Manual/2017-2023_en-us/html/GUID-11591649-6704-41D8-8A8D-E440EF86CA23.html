Extrusion - Bumper Beam - Active Hood- Front (Remove and Replace)

Correction code 10011602 0.66 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1001 - Bumper / Fascia

Remove

  1. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  2. Remove the front fascia. See Fascia - Front (Remove and Install).
  3. Disconnect the electrical harness from the LH and RH ped pro pressure tube sensor connectors.
    Note
    Pull the red tab, and then pull the red tab again to disconnect the connector.
  4. Remove the LH and RH front bumper impact accelerometer sensors. See Sensor - Impact Accelerometer - Front Bumper - LH (Remove and Replace).
  5. Remove the center front bumper impact accelerometer sensor. See Sensor - Impact Accelerometer - Front Bumper - Center (Remove and Replace).
  6. Remove the front bumper beam foam from the front bumper beam.
  7. Remove the bolts (x4) that attach the front bumper beam to the LH and RH crush cans.
  8. Use a pry bar to separate the front bumper beam from the LH and RH crush cans, and then remove the bumper beam from the vehicle.
    Note
    Lightly tap the bumper beam with a dead blow hammer to assist with removal, as needed.

Install

  1. Install the front bumper beam into the LH and RH crush cans.
    Note
    Lightly tap the bumper beam with a dead blow hammer to assist with removal, as needed.
  2. Install the bolts (x4) that attach the front bumper beam to the LH and RH crush cans.
  3. Install the front bumper beam foam from the front bumper beam.
  4. Install the center front bumper impact accelerometer sensor. See Sensor - Impact Accelerometer - Front Bumper - Center (Remove and Replace).
  5. Install the LH and RH front bumper impact accelerometer sensors. See Sensor - Impact Accelerometer - Front Bumper - LH (Remove and Replace).
  6. Connect the electrical harness from the LH and RH ped pro pressure tube sensor connectors.
    Note
    Push the red tab in to secure the connector.
  7. Install the front fascia. See Fascia - Front (Remove and Install).
  8. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
