Carrier - Side Shield - Inboard - Driver Seat (Remove and Replace)

Correction code 13070032 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Note
Depending on build location, some vehicles may not be equipped with this part. For vehicles equipped with diamond covers, see Diamond Cover - Seat Side - 1st Row - RH (Remove and Replace).
Parent topic: 1307 - Front Seat Covers Pads and Trims

Remove

  1. Remove the LH front seat assembly. See Seat Assembly - 1st Row - LH (Remove and Replace).
  2. Remove the driver seat inboard side shield. See Side Shield - Inboard - Driver Seat (Remove and Replace)
  3. Use the screwdriver to disconnect the LH front seat buckle connector, and then push the connector rearward to release it from the connector clip.
  4. Release the seat belt buckle harness clip from the seat bottom frame.
  5. Remove the inboard side shield carrier clips (x2) from the LH front seat.
  6. Partially lift the side shield carrier upper shroud.
    Note
    Don't use too much force to prevent damage to the carrier and the trim.
  7. Release the clips (x2) at the front end of the inboard side shield carrier, and then lift the carrier up and pull it rearward to release the clips at the rear end. Then remove the carrier from the LH front seat.

Install

  1. Align the clips at the rear end of the inboard side shield carrier to the seat frame, and then push the carrier forward to seat them into position. Then install the clips (x2) at the front end of the carrier.
  2. Install the inboard side shield carrier clips (x2) to the LH front seat.
  3. Install the seat belt buckle harness clip to the seat bottom frame.
  4. Install the LH 1st row buckle electrical connector into the connector clip, and then connect it.
  5. Install the driver seat inboard side shield. See Side Shield - Inboard - Driver Seat (Remove and Replace)
  6. Install the LH front seat assembly. See Seat Assembly - 1st Row - LH (Remove and Replace).
