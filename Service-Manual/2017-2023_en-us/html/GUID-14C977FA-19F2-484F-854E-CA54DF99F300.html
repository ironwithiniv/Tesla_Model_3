Actuator - Latch - Hood (Single Actuator System) (Remove and Replace)

Correction code 11350402 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1135 - Latches Strikers and Pinch Sensors

Torque Specifications

Table 1. Torque Specifications: Actuator - Latch - Hood (Single Actuator System) (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolt that attaches the hood latch actuator to the front end carrier
5 Nm (3.7 lbs-ft)
  • 10 mm socket
 Reuse

Remove

Note
If the hood latch does not open electronically, use the manual front trunk tool specified below to open the hood.
Equipment:
  • 1130534-00-A, TOOL, FRUNK RELEASE, MANUAL
  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Remove the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  3. Remove the hood latch cover. See Cover - Hood Latch (Remove and Replace).
  4. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  5. Release the hood latch actuator cable from the hood latch.
    Note
    Release the clip before removing the actuator cable from the latch arm.
  6. Disconnect the electrical connector from the hood latch actuator.
  7. Remove the bolts that attach the hood latch actuator to the front end carrier, and then remove the actuator from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket

Install

  1. Install the bolts that attach the hood latch actuator to the front end carrier.
    5 Nm (3.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  2. Connect the electrical connector to the hood latch actuator.
  3. Install the hood latch actuator cable to the hood latch.
    Note
    Secure the cable end to the latch arm, and then attach the clip.
  4. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  5. Install the hood latch cover. See Cover - Hood Latch (Remove and Replace).
  6. Install the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  7. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
