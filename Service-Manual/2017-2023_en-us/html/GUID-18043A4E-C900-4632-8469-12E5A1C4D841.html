Bushing - Rear Drive Unit - Rear (3DU) (Remove and Replace)

Correction code 40012602 3.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1137785-00-A Kit, Drive Unit Bushing R&R, Model 3
  • 2024-04-18: Added Note to aid the installation of the new bushing.
Parent topic: 4001 - Rear Drive Unit Assembly

Remove

  1. Remove the rear drive unit. See Drive Unit - Rear (3DU) (Remove and Install).
  2. Install the drive unit bushing tool onto the rear bushing.
    Note
    Mark the position of the old bushing on the rear drive unit body before removal, so that the exact position of the new bushing is known upon installation.
  3. Turn the nut on the thrust washer to remove the bushing from the drive unit.
  4. Separate the bushing tool, and then remove it from the drive unit.

Install

  1. Set up the bushing tool to press in the new bushing.
  2. Turn the nut on the thrust washer to press the new bushing into the drive unit.
  3. Separate the bushing tool, and then remove it from the drive unit.
  4. Install the rear drive unit. See Drive Unit - Rear (3DU) (Remove and Install).
  5. Check the vehicle wheel alignment, and adjust if necessary. See Four Wheel Alignment Check.
