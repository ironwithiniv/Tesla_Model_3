Hinge - Rear Door - Upper - LH (Remove & Replace)

Correction code 11336802 11336902 FRT 0.48 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
  • 2025-12-01: Released new procedure.
  1. Open all four doors
    Note
    If vehicle is being powered down, Latch rear doors to prevent accidental closure
  2. Lower all four windows
  3. Remove LH IP end cap
    Note
    3x clips
  4. Remove LH mid A-pillar assembly
    Note
    1x clip, 1x tab, Release the upper clip then pull mid A-pillar upward to remove
  5. Remove clip for LH lower A-pillar trim
    Note
    1x push clip
  6. Remove LH lower A-pillar trim
    Note
    2x clips, 3 guide tabs, Pull rear of lower A-pillar upward to release clip then pull outward to release front tabs from carpet
  7. Move LH front seat forward
  8. Move RH front seat forward
  9. Remove 2nd row seat cushion
    Note
    2x tabs, 2x connectors, Slide locking tabs to left of vehicle while lifting up seat bench. Newer models have connectors on both sides of bench, Older models have 2x connectors on one side of bench
  10. Fold 60 seat in down position
    Note
    Protect the seat cushion
  11. Remove LH side bolster
    Note
    1x clip, 2x location pins, Pull outward then slightly upward to remove
  12. Remove and discard bolster plastic bracket from LH side
    Note
    2x clips, If necessary, depress the clips from behind, This bracket may come out with bolster, Discard after removal
  13. Fold 60 seat into vertical position
    Note
    Remove seat protection
  14. Remove LH rear door sill trim panel
    Note
    3x clips, 1x guide tab, Pull upward at the lower corner of sill trim to release clip from lower B-pillar, Then remove the remaining clips by pulling away from the body
  15. Release clips securing the LH upper B-pillar assembly and move aside
    Note
    4x clips, Pull the bottom of the upper B-pillar toward inside of the car, then pull the top to release the remaining clips
  16. Remove the LH lower B-pillar assembly
    Note
    1x push clip, 6x clips, Remove the front push clip from lower B-pillar, then pull the top of B-pillar to release top clips then work your way to bottom clips
  17. Apply tape to LH door side upper hinge location
    Note
    This will mark where the hinge should align on install
  18. Apply tape to LH body side upper hinge location
    Note
    This will mark where the hinge should align on install
  19. Support LH rear door
    Note
    Rest door at first detent, Use soft material to protect painted surface
  20. Remove fasteners securing LH rear upper door hinge to the LH rear door
    Note
    2x bolts, 10mm, 27 Nm
  21. Remove fasteners securing LH rear upper door hinge to body
    Note
    2x nuts, 13mm, 27 Nm, Support door hinge to ensure it does not fall in the door jam
  22. Remove LH rear upper door hinge from vehicle
    Note
    Shift upper section of door outward slightly to create space to remove studs from body
  23. Install LH rear upper door hinge to vehicle
    Note
    Shift upper section of door outward slightly to create space to remove studs from body
  24. Install fasteners securing LH rear upper door hinge to body hand tight
    Note
    2x nuts, 13mm, 27 Nm, Support door hinge to ensure it does not fall in the door jam, Align hinge with previously applied tape on body
  25. Install fasteners securing LH rear upper door hinge to the LH rear door hand tight
    Note
    2x bolts, 10mm, 27 Nm, Align hinge with previously applied tape on door
  26. Torque fasteners securing LH rear upper door hinge to body
    Note
    2x nuts, 13mm, 27 Nm
  27. Torque fasteners securing LH rear upper door hinge to the LH rear door
    Note
    2x bolts, 10mm, 27 Nm
  28. Remove support from LH rear door
    Note
    Rest door at first detent, Use soft material to protect painted surface
  29. Close the LH rear door to check for gap/flushness
    Note
    Adjust the LH rear door if necessary
  30. Remove tape from LH body side upper hinge location
  31. Remove tape from LH door side upper hinge location
  32. Clean hinge bolts with IPA
    Note
    Allow 1 minute dry time
  33. Apply touch up paint to bolt heads as needed
    Note
    Make sure to shake touch up paint before applying, Refer to label for dry time instructions
  34. Install LH lower B-pillar assembly
    Note
    1x push clip, 6x clips, Align the bottom guide tab to its slot then press the bottom clips, Work your way to top clips, Install the front push clip then make sure the seal correctly overlaps the trim
  35. Install the LH upper B-pillar assembly
    Note
    4x clips, Lower the seat belt slider to align it with the B-pillar panel, Insert top portion of upper B-pillar under the headliner to align the clips, Press the bottom to fully seat upper B-pillar to lower B-pillar, Make sure the seal correctly overlaps the trim
  36. Install LH rear door sill trim panel
    Note
    3x clips, 1x guide tab, Align the guiding tab to slot, Then push downward to install the clips after aligning them, Make sure the seal sits overlapping the trim. Newer vehicles may not be equipped with metal bracket and a foam insert will be present the bottom of trim piece
  37. Fold 60 seat in down position
    Note
    Protect the seat cushion if necessary
  38. Install bolster plastic bracket to LH side bolster
    Note
    2x tabs, Install new bolster bracket
  39. Install LH side bolster
    Note
    1x clip, 2x location pins, Align the bottom tab then push inward to install
  40. Fold 60 seat into vertical position
    Note
    Remove seat cushion protection, Be careful not to pinch the seat belt
  41. Connect 2nd row seat cushion harness and install 2nd row seat cushion
    Note
    2x connectors, 2x clips, Insert the seat belt buckles through the holes, Slide rear cushion inward then align front guide tabs to locking tabs, Make sure cushion is fully seated with push pull test near clips
  42. Move RH front seat to original position
  43. Move LH front seat to original position
  44. Install LH lower A-pillar trim
    Note
    2x clips, 3 guide tabs, Align the 2 front tabs then align the slot with harness bracket and then push rear clip to secure to lower B-pillar, fully seat seal along trim
  45. Install clip for LH lower A-pillar trim
    Note
    1x push clip
  46. Install LH mid A pillar assembly
    Note
    1x clip, 1x tab, Align the bottom tab then push the top clip to fully seat mid A pillar, Pull seal over trim
  47. Install LH IP end cap
    Note
    3x clips
  48. Raise all four windows
  49. Close all four doors
