Brake Lines - Rear - LH to Sill (Remove and Replace)

Correction code 33035202 0.96 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1079041-00-A Flare nut crowfoot set
Parent topic: 3303 - Brake Pipes and Hoses

Remove

  1. CAUTION

    Brake fluid dissolves paint. Have clean towels and plenty of water standing by to wash spilled brake fluid off painted surfaces.

    Note

    Dispose of used brake fluid in a manner consistent with local environmental codes.

  2. Remove the LH rear wheel arch liner. See Wheel Arch Liner - Rear - LH (Remove and Replace).
  3. Position the oil drain under the brake line junction block.
  4. Remove the brake line tube nut from the junction block, and allow the fluid to drain.
  5. Position the oil drain under the rear LH brake hose.
  6. Remove the brake line tube nut from the brake hose at the jounce hose bracket, and allow the fluid to drain.
  7. Release the clips that attach the brake line to the body, and then remove the brake line from the vehicle.

Install

  1. Install the brake line to the body, and then fasten the clips that attach the brake line to the body.
  2. Insert the brake line into the brake hose at the jounce hose bracket, and then use a crowfoot extension to install the brake line tube nut into the brake hose.
    16 Nm (11.8 lbs-ft)
  3. Insert the brake line into the junction block, and then use a crowfoot extension to install the brake line tube nut into the junction block.
    16 Nm (11.8 lbs-ft)
  4. Bleed the brake line for the rear LH caliper. See Brake Fluid Bleed - One Caliper.
  5. Install the LH rear wheel arch liner. See Wheel Arch Liner - Rear - LH (Remove and Replace).
