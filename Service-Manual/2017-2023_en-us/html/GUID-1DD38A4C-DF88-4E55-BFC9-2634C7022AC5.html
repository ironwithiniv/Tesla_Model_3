Recline Button - Switch - Driver Seat (Remove and Replace)

Correction code 13017102 0.06 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1301 - Front Seat Tracks and Motors

Remove

  1. Open the LH front door and fully lower the LH front window.
  2. Use a trim tool to carefully release the clips that attach the driver seat recline switch button to the seat assembly, and then remove the button from the assembly.
    CAUTION
    Be careful not to damage the button and seat trim.
    Tip
    Pry in a twisting motion.

Install

  1. Install the driver seat recline switch button to the seat assembly.
  2. Raise the LH front window and close the LH front door.
