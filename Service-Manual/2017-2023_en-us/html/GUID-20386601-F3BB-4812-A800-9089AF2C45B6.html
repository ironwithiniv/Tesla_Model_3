SIM Card - Car Computer (Info-Ryzen) (Retrofit)

Correction code 210624120.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Perform this procedure if local regulations require the use of a physical SIM card instead of the embedded E-SIM module.
Parent topic: 2115 - Car Computer

Procedure

  1. Disconnect 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  2. Remove the passenger footwell cover. See Cover - Footwell - Passenger (LHD) (Remove and Replace).
  3. Install the new SIM card into the car computer slot with the notch up and the gold pads facing away from the bulkhead.
    Note
    Use a flashlight and inspection mirror to aid installation.
    CAUTION
    Make sure that the SIM card goes into the slot, before releasing your grip of the SIM card.
  4. Carefully press the SIM card fully into the slot, so that the catch engages.
    CAUTION
    If using a thin tool to press the SIM card in, use the tool as shown.
  5. Install the passenger footwell cover. See Cover - Footwell - Passenger (LHD) (Remove and Replace).
  6. Connect 12V power. See 12V/LV Power (Disconnect and Connect).
  7. Enable the external SIM card using Toolbox 3:
    1. Connect a laptop with Toolbox 3 to the vehicle. See Toolbox (Connect and Disconnect).
    2. Select the Actions tab and search for "Toggle SIM Card".
    3. Select the ODIN routine PROC_ICE_X_ENABLE-DISABLE-SIM-CARDvia Service Mode Plus:Infotainment ➜ Connectivity ➜ Toggle SIMvia Toolbox:(link), and then click the link of the routine.
    4. Uncheck Enable_Onboard_Sim to disable the on-board SIM card.
    5. Click RUN, and allow the routine to complete.
    6. Disconnect the laptop from the vehicle. See Toolbox (Connect and Disconnect).
  8. Perform a functional check of the LTE service.
    Note
    For China only, after installation, make sure to authenticate the new SIM card.
