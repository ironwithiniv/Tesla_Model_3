Superbottle (RWD) (Remove and Replace)

Correction code 18301502 1.26 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-08-05: Added step to update the superbottle pump configuration.
  • 2025-11-19: Deleted reference to Toolbox article 105200.
  • 2023-09-06: Removed redundant recharge step.
  • 2023-5-2: Information on how to install dual pump in place of single pump
  • 2023-4-14: Introduced thermal test routines using the touchscreen.
  • 2023-6-7: Updated the Toolbox article link.
Equipment:
  • 1135762-00-A Kit, Svc Plug, Cooling Hose, Model 3
Note
This procedure requires the A/C Refrigerant (Recovery and Recharge) procedure to be performed. If not already automatically added to the Service Visit, add correction code 18200102 as a separate correction within the same activity to the Service Visit.
Parent topic: 1830 - Cooling System

Remove

  1. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  2. Open all four doors and lower all four windows.
  3. Set up the A/C machine and perform a hose flush.
  4. Put the vehicle in Service Mode. See Service Mode.
  5. On the touchscreen, touch Service Mode > Thermal > Refrigerant System, select Start Thermal Fill Drain (Coolant & Refrigerant) and then click Run.
  6. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  7. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  8. Remove the 12V/LV battery. See 12V/LV Battery (Remove and Replace).
  9. Remove the HVAC inlet plenum. See Plenum - Inlet - HVAC (Remove and Replace).
  10. Recover the A/C refrigerant. See A/C Refrigerant (Recovery and Recharge).
    Note
    Perform the A/C refrigerant recovery procedure while continuing this procedure.
  11. Remove the superbottle cap.
  12. Remove the front aero shield. See Panel - Aero Shield - Front (Remove and Replace).
  13. Position a coolant drain container under the superbottle.
  14. Release the clip and disconnect the powertrain supply hose at the lower LH side of the superbottle.
    Note
    Allow the coolant to drain from the superbottle.
  15. Release the clip and disconnect the battery return hose from the rear left of the superbottle.
  16. Release the clip that attaches the battery return hose to the superbottle.
  17. Disconnect the electrical harness from the powertrain pump to sill hose coolant temperature sensor connector.
  18. Release the clip and disconnect the powertrain pump to sill connector hose from the rear right of the superbottle.
  19. Disconnect the superbottle level sensor connector.
  20. Disconnect the 5-way valve actuator connector.
  21. Release the clip that attaches the electrical harness to the lower LH side of the superbottle.
  22. Disconnect the electrical harness from the chiller and EXV assembly hose coolant temperature sensor connector.
  23. Release the clip that attaches the electrical harness to the chiller and EXV assembly hose, and then remove the electrical harness from the hose.
  24. Release the clip that attaches the battery vent hose to the chiller and EXV assembly hose, and then remove the battery vent hose from the chiller and EXV assembly hose.
  25. Release the clip and disconnect the coolant hose from the chiller and EXV assembly.
  26. Release the clip and disconnect the radiator inlet hose from the front left of the superbottle.
  27. Release the clip and disconnect the radiator outlet hose from the front right of the superbottle.
  28. Disconnect the HV battery coolant pump connector.
  29. Release the clip that attaches the electrical harness to the suction liquid line.
  30. Disconnect the powertrain coolant pump connector.
  31. Disconnect the chiller and EXV assembly connector.
  32. Disconnect the low pressure transducer connector.
  33. Remove the bolt that attaches the suction/liquid line bracket to the shock tower brace, and then separate the bracket from the brace.
  34. Note
    Make sure that the refrigerant has fully recovered before continuing to the next step.
  35. Remove the bolt that attaches the suction/liquid line to the chiller and EXV assembly, and then remove the line from the chiller and EXV assembly.
  36. Remove and discard the o-rings from the suction/liquid line fitting.
  37. Release the clip that attaches the suction/liquid lines to the superbottle.
  38. Release the clip that attaches the electrical harness to the superbottle.
  39. Remove the bolt that attaches the superbottle to the shock tower brace.
  40. Remove the nuts that attach the superbottle to the shock tower brace, and then remove the superbottle from the vehicle.

Install

  1. Install the superbottle to the shock tower brace, and then install the nuts that attach the superbottle to the shock tower brace.
    8 Nm (5.9 lbs-ft)
  2. Install the bolt that attaches the superbottle to the shock tower brace.
    8 Nm (5.9 lbs-ft)
  3. Fasten the clip that attaches the electrical harness to the superbottle.
  4. Install the clip that attaches the suction/liquid lines to the superbottle.
  5. Install new o-rings onto the suction/liquid line fitting, install the suction/liquid line fitting into the chiller and EXV assembly, and then install the bolt that attaches the suction/liquid line to the chiller and EXV assembly.
    22 Nm (16.2 lbs-ft)
  6. After installing the assembly, recharge the refrigerant. See A/C Refrigerant (Recovery and Recharge).
    Note
    Perform installation of components removed concurrently with refrigerant recharge.
  7. Install the suction/liquid line bracket onto the shock tower brace, and then install the bolt that attaches the bracket to the brace.
    5.5 Nm (4.1 lbs-ft)
  8. Connect the electrical harness to the low pressure transducer connector.
  9. Connect the electrical harness to the chiller and EXV assembly connector.
  10. Connect the electrical harness to the power train coolant pump connector.
  11. Fasten the clip that attaches the electrical harness to the liquid suction line.
  12. Connect the electrical harness to the HV battery coolant pump connector.
  13. Connect the radiator outlet hose to the front right of the superbottle, and then fasten the clip.
  14. Connect the radiator inlet hose to the front left of the superbottle, and then fasten the clip.
  15. Connect the coolant hose from the chiller and EXV assembly, and then fasten the clip.
  16. Install the battery vent hose to the chiller and EXV assembly hose, and then fasten the clip that attaches the battery vent hose to the chiller and EXV assembly hose.
  17. Install the electrical harness to the chiller and EXV assembly hose, and then fasten the clip that attaches the electrical harness to the hose.
  18. Connect the electrical harness to the chiller and EXV assembly hose coolant temperature sensor connector.
  19. Fasten the clip that attaches the electrical harness to the lower LH side of the superbottle.
  20. Connect the electrical harness to the 5-way valve actuator connector.
  21. Connect the electrical harness to the superbottle level sensor connector.
  22. Connect the powertrain pump to sill connector hose to the rear right of the superbottle, and then fasten the clip.
  23. Connect the electrical harness to the powertrain pump to sill hose coolant temperature sensor connector.
  24. Fasten the clip that attaches the battery return hose to the superbottle.
  25. Connect the battery return hose to the rear left of the superbottle, and then fasten the clip.
  26. Connect the powertrain supply hose at the lower LH side of the superbottle, and then fasten the clip.
  27. Remove the coolant drain from under the vehicle.
  28. Install the front aero shield. See Panel - Aero Shield - Front (Remove and Replace).
  29. Install the 12V/LV battery. See 12V/LV Battery (Remove and Replace).
  30. Connect 12V power. See 12V/LV Power (Disconnect and Connect).
    Note
    Do not install the rear underhood apron at this time.
  31. On the touchscreen, touch START at "Start Thermal Fill Drain (Coolant and Refrigerant)".
  32. Perform a cooling system vacuum refill. See Cooling System (Vacuum Refill).
  33. On the touchscreen, touch Thermal > Actions > Thermal Configurations > coolantPumpType > DUAL_MIX to update the "Coolant Pump Type (86)" configuration to "DUAL_MIX".
  34. On the touchscreen, touch START at "Start Coolant Air Purge".
  35. Inspect coolant level in superbottle, top off as necessary and then install the superbottle cap.
    Note
    Fluid level in superbottle should be 5 mm above the MAX line.
  36. Install the HVAC inlet plenum. See Plenum - Inlet - HVAC (Remove and Replace).
  37. On the touchscreen, touch Thermal > Actions > Test HVAC Performance and select Run.
  38. On the touchscreen, touch Service Mode > Thermal > Actions > Test Thermal Performance, and then touch Run.
  39. Exit Service Mode. See Service Mode.
  40. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  41. Raise all four windows and close all four doors.
  42. Remove the vehicle from the lift.
