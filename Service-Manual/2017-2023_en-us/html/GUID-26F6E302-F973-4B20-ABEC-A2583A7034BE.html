Thermistor - Duct - RH (Heat Pump) (Remove and Replace)

Correction code 18101202 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1810 - Cabin HVAC

Torque Specifications

Table 1. Torque Specifications: Airbag - Knee - Front Passenger (Remove and Replace)/Thermistor - Duct - RH (Heat Pump) (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x2) that attach the front passenger knee airbag to the instrument panel
2 Nm (1.5 lbs-ft)
  • Torx T20 socket
Bolts (x4) that attach the front passenger knee airbag to the instrument panel
8 Nm (5.9 lbs-ft)
  • Torx T20 socket
or
  • External Torx E10

Remove

  1. Remove the passenger footwell cover. See Cover - Footwell - Passenger (LHD) (Remove and Replace).
  2. If the vehicle is equipped with a front passenger knee airbag, perform the following steps. Otherwise, skip this step.
    1. Remove the bolts (x2) that attach the front passenger knee airbag to the instrument panel.
      2 Nm (1.5 lbs-ft)
      Tip
      Use of the following tool(s) is recommended:
      • Torx T20 socket
    2. While supporting the front passenger knee airbag, remove and discard the bolts (x4) that attach the front passenger knee airbag to the instrument panel.
      8 Nm (5.9 lbs-ft)
      or
      8 Nm (5.9 lbs-ft)
      Tip
      Use of the following tool(s) is recommended:
      For Torx T20, use:
      • Torx T20 socket
      For Torx E10, use:
      • External Torx E10
    3. Disconnect the electrical connector from the front passenger knee airbag.
  3. Disconnect the electrical harness from the RH upper duct thermistor.
  4. Use a pry tool to release the tabs (x2) that attach the thermistor to the RH instrument panel air wave duct, and then remove the thermistor from the vehicle.

Install

  1. Position the RH upper duct thermistor on the RH instrument panel air wave duct, making sure that the mounting tabs are engaged.
  2. Connect the electrical harness to the RH upper duct thermistor.
  3. If the vehicle is equipped with a front passenger knee airbag, perform the following steps. Otherwise, skip this step.
    1. Connect the electrical connector to the front passenger knee airbag.
    2. While supporting the front passenger knee airbag, install new bolts (x4) that attach the front passenger knee airbag to the instrument panel.
      8 Nm (5.9 lbs-ft)
      or
      8 Nm (5.9 lbs-ft)
      Tip
      Use of the following tool(s) is recommended:
      For Torx T20, use:
      • Torx T20 socket
      For Torx E10, use:
      • External Torx E10
    3. Install the bolts (x2) that attach the front passenger knee airbag to the instrument panel.
      2 Nm (1.5 lbs-ft)
      Tip
      Use of the following tool(s) is recommended:
      • Torx T20 socket
  4. Install the passenger footwell cover. See Cover - Footwell - Passenger (LHD) (Remove and Replace).
