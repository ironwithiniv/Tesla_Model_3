Support Bracket - Trunk Side Trim (Remove and Replace)

Correction code 15110902 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1511 - Trunk Trim

Torque Specifications

Table 1. Torque Specifications: Support Bracket - Trunk Side Trim (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Fasteners (x3) that secure the side trim support bracket
10 Nm (7.4 lbs-ft)
  • 10 mm socket
 Reuse

Remove

  1. Remove the trunk sill trim. See Trim - Sill - Trunk (Remove and Replace).
  2. Partially release the RH trunk side trim (3x push clips, 2x Velcro attachment, 1x clip, 1x connector).
  3. Remove the fasteners (x3) that secure the side trim support bracket, and remove the bracket from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket

Install

  1. Install the fasteners (x3) that secure the side trim support bracket.
    10 Nm (7.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  2. Install the RH trunk side trim (3x push clips, 2x Velcro attachment, 1x clip, 1x connector).
    Note
    Make sure the seal if fully seated along the carpet.
  3. Install the trunk sill trim. See Trim - Sill - Trunk (Remove and Replace).
