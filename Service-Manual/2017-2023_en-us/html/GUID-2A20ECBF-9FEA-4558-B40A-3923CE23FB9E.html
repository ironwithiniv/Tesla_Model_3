Applique - A-Pillar - Mirror - Door - LH (Remove and Replace)

Correction code 12201102 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1220 - Exterior Trim

Remove

  1. Open the LH front door, and then lower LH front window.
  2. Remove the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
  3. Remove the LH front door puddle light. See Puddle Light - Front Door - LH (Remove and Replace).
  4. Remove the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Install).
  5. Remove the LH door mirror. See Mirror - Door - LH (Remove and Replace).
  6. Release the tabs (x3) that attach the LH door mirror A-Pillar applique to the LH door mirror, and then remove the applique from the mirror.

Install

  1. Position the LH door mirror A-Pillar applique on the LH door mirror, and then install the tabs (x3) that attach the applique to the mirror.
  2. Install the LH door mirror. See Mirror - Door - LH (Remove and Replace).
  3. Install the LH front door puddle light. See Puddle Light - Front Door - LH (Remove and Replace).
  4. Install the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Install).
  5. Install the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
