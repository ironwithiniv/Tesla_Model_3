Pump - Windshield Washer (Remove and Replace)

Correction code 17501002 0.72 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1750 - Wipers and Washers

Remove

  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Remove the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  3. Remove the hood latch cover. See Cover - Hood Latch (Remove and Replace).
  4. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  5. Remove the LH and RH wiper arms. See Wiper Arms (Remove and Replace).
  6. Remove the cowl screen panel. See Panel - Cowl Screen (Remove and Replace).
  7. Remove the wiper motor. See Wiper Module (Remove and Replace).
  8. Release the clip that attaches the electrical harness to the windshield washer reservoir.
  9. Disconnect the electrical harness from the windshield washer reservoir connector.
  10. Remove the LH front wheel. See Wheel Assembly (Remove and Install).
  11. Remove the LH front wheel arch liner. See Wheel Arch Liner - Front - LH (Remove and Replace).
  12. Remove the lower bolt that attaches the windshield washer reservoir to the body.
    3 Nm (2.2 lbs-ft)
  13. Lower the vehicle until the tires just touch the ground.
  14. Remove the upper bolt that attaches the windshield washer reservoir to the body.
    3 Nm (2.2 lbs-ft)
  15. Remove the windshield washer reservoir from the vehicle, and then recover any fluid from the reservoir.
  16. Disconnect the electrical harness from the windshield washer pump connector.
  17. Remove the washer hose from the windshield washer reservoir, and then remove the windshield washer pump from the grommet in the reservoir.
  18. Remove the windshield washer hose from the windshield washer pump.

Install

  1. Install the windshield washer hose onto the windshield washer pump.
  2. Insert the tip of the windshield washer pump into the grommet in the windshield washer reservoir, install the pump into the reservoir, and then install the washer hose into the reservoir.
  3. Connect the electrical harness to the windshield washer pump connector and level sensor connector.
  4. Install the windshield washer reservoir into the vehicle, and then install the upper bolt that attaches the windshield washer reservoir to the body.
    3 Nm (2.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
  5. Raise the vehicle to a working height, and then install the lower bolt that attaches the windshield washer reservoir to the body.
    3 Nm (2.2 lbs-ft)
  6. Install the LH front wheel arch liner. See Wheel Arch Liner - Front - LH (Remove and Replace).
  7. Install the LH front wheel. See Wheel Assembly (Remove and Install).
  8. Fill the windshield washer reservoir with fluid.
  9. Connect the electrical harness to the windshield washer reservoir connector.
  10. Fasten the clip that attaches the electrical harness to the windshield washer reservoir.
  11. Install the wiper motor. See Wiper Module (Remove and Replace).
  12. Install the cowl screen panel. See Panel - Cowl Screen (Remove and Replace).
  13. Install the LH and RH wiper arms. See Wiper Arms (Remove and Replace).
  14. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  15. Install the hood latch cover. See Cover - Hood Latch (Remove and Replace).
  16. Install the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  17. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  18. Verify operation of the windshield wipers and washer.
