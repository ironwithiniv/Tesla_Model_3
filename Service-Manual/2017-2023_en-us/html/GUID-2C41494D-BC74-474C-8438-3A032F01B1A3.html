Heater - PTC (Remove and Replace)

Correction code 18106302 1.32 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1810 - Cabin HVAC

Remove

  1. Raise and support the vehicle on a 2 post lift. See Raise Vehicle - 2 Post Lift.
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Remove the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  4. Remove the LH center console side panel carpet. See Side Panel - Center Console - LH (Remove and Replace).
  5. Remove the RH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  6. Remove the RH middle A-pillar trim. See Trim - A-Pillar - Middle - LH (Remove and Replace).
  7. Remove the RH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  8. Remove the RH center console side panel carpet. See Side Panel - Center Console - LH (Remove and Replace).
  9. Remove the RH footwell cover. See Cover - Footwell - Passenger (LHD) (Remove and Replace).
  10. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  11. Perform the vehicle electrical isolation procedure. See Vehicle HV Disablement Procedure.
  12. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  13. Disconnect the HV harness connector from the PTC heater.
    Note
    Release the bracket from the body for better access to the connector.
  14. Release the clips that attach the PTC heater electrical connector to the body.
  15. Lower the vehicle.
  16. Remove the front passenger knee airbag. See Airbag - Knee - Front Passenger (Remove and Replace).
  17. Remove the RH footwell duct. See Duct - Footwell - RH (LHD) (Remove and Replace).
  18. Release the clips that attach the front RH carpet to the vehicle, and then fold the front RH carpet rearwards.
  19. Disconnect the LV electrical connector from the LH lower side of the PTC heater.
  20. Release the clip that attaches the PTC heater electrical harness to the HVAC assembly.
  21. Remove the bolts that attach the LH side of the PTC heater to the HVAC assembly.
  22. Remove the clips that attach the PTC heater electrical harness to the HVAC assembly.
  23. Remove the nut that attaches the instrument panel harness ground strap to the PTC heater.
  24. Remove the grommet, and then carefully pull the HV cable through the bulkhead.
    CAUTION
    Do not damage the HV cable while feeding through the bulkhead.
  25. Remove the bolts that attach the RH side of the PTC heater to the HVAC assembly, and then lower the PTC heater from the HVAC assembly.
  26. Inspect the HVAC assembly to see if a service panel (1107677-00-A) has been installed or not.
    • If a service panel is not installed, perform step 27 and then skip 28.
    • If a service panel is installed, skip step 27.
  27. If a service panel is not installed, use a razor blade to carefully cut the inner edge of the side cover, and then remove and discard the side cover. A service panel will be installed after replacing the PTC heater.
    Warning
    Wear cut-resistant gloves when performing this step.
    CAUTION
    Use caution when cutting the side cover. Avoid contact with the PTC heater.
    Tip
    Consider using tools from the glazing kit instead of a razor blade.
  28. If a service panel is installed, remove the bolts that attach the service panel to the standoffs on the HVAC assembly. Remove the service panel.
  29. Slide the PTC heater out of the HVAC assembly, and then remove the PTC heater from the vehicle.
  30. Remove the sealing plate from the PTC heater.
    Note
    The sealing plate must be retained for the replacement PTC heater.

Install

  1. Inspect the condition of the PTC heater sealing plate, and replace if damaged.
  2. Install the sealing plate onto the new PTC heater.
    CAUTION
    Failure to transfer the sealing plate has the potential of introducing air or water leakage.
  3. Slide the PTC heater into the HVAC assembly, and then push the PTC heater up to install it.
  4. Install the bolts that attach the RH side of the PTC heater to the HVAC assembly.
    2.9 Nm (2.1 lbs-ft)
  5. Position the service panel for installation, and then install the bolts that attach the service panel to the standoffs on the HVAC assembly.
    1.2 Nm (.9 lbs-ft)
  6. Push the HV cable through the bulkhead, and then install the grommet.
    CAUTION
    Do not damage the HV cable while feeding through the bulkhead.
    Note
    Apply lubricant to the HV cable, if necessary.
  7. Install the nut that attaches the instrument panel harness ground strap to the PTC heater.
    5 Nm (3.7 lbs-ft)
  8. Install the clips that attach the PTC heater electrical harness to the HVAC assembly.
  9. Instal the bolts that attach the LH side of the PTC heater to the HVAC assembly.
    2.9 Nm (2.1 lbs-ft)
  10. Install the clip that attaches the PTC heater electrical harness to the HVAC assembly.
  11. Connect the 12V electrical connector to the PTC heater.
  12. Unfold the front RH carpet forward, and then install the clips that attach the front RH carpet to the vehicle.
  13. Install the RH footwell duct. See Duct - Footwell - RH (LHD) (Remove and Replace).
  14. Install the front passenger knee airbag. See Airbag - Knee - Front Passenger (Remove and Replace).
  15. Raise the vehicle fully.
  16. Install the clips that attach the PTC heater electrical connector to the body.
  17. Connect the HV harness connector to the PTC heater.
    Note
    Install the bracket to the body.
  18. Install the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  19. Lower the vehicle fully.
  20. Reconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  21. Install the RH footwell cover. See Cover - Footwell - Passenger (LHD) (Remove and Replace).
  22. Install the RH center console side panel carpet. See Side Panel - Center Console - LH (Remove and Replace).
  23. Install the RH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  24. Install the RH middle A-pillar trim. See Trim - A-Pillar - Middle - LH (Remove and Replace).
  25. Install the RH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  26. Install the LH center console side panel carpet. See Side Panel - Center Console - LH (Remove and Replace).
  27. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  28. Install the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  29. Reinstall the software through the touchscreen. See Software Reinstall - Touchscreen.
  30. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): TEST-SELF_VCRIGHT_X_PTC-COMPROMISED-ROD-DETECTIONvia Service Mode Plus:Thermal ➜ PTC Heater ➜ Start Compromised Rod Detectionvia Toolbox:(link)
  31. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): TEST-SELF_VCRIGHT_X_HVAC-PERFORMANCEvia Service Mode:
    • Thermal ➜ Actions ➜ Test HVAC Performance
    • Thermal ➜ HVAC ➜ HVAC Performance Test
    • Thermal ➜ Actions ➜ Test HVAC Performance
    via Toolbox:(link)
  32. Exit Service Mode. See Service Mode.
