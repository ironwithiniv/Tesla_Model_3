Light - Fog / Reverse - Rear - LH (Remove and Replace)

Correction code 17402702 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Description Torque Value Recommended Tools Reuse/Replace Notes
Nut that attaches the rear fog/reverse light to the deck lid
3.2 Nm (2.4 lbs-ft)
  • 8 mm deep socket
 Reuse

Remove

  1. Remove the trunk lid trim. See Trim - Lid - Trunk (Remove and Replace).
  2. Disconnect the electrical wiring harness connector from the LH rear fog/reverse light.
  3. Remove the nut that attaches the LH rear fog/reverse light to the trunk lid.
    3.2 Nm (2.4 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • 8 mm deep socket
  4. Remove the LH rear fog/reverse light from the trunk lid.
    Note
    Carefully pry on the exterior of the LH rear fog/reverse light to release it.
  5. Apply masking tape in the LH rear construction area.
    Note
    Whenever possible, use thicker tape or apply multiple layers to prevent damage to the paint.
  6. Remove and discard the grommets from the trunk lid.
    Note
    Place a towel under the tool to prevent paint damage and liftgate deformation.
  7. If the fog/reverse light is to be reinstalled, remove the gaskets from around the threaded mounting stud and the light connector.

Install

Installation procedure is the reverse of removal, except for the following:

  • Install new grommets into the trunk lid where the light installs.
    Note
    Upper grommet: 1104335-00-B; Lower grommet: 1104926-00-B
  • Remove masking tape in the LH rear construction area.
    Note
    Use IPA wipes to clean the area.
  • If the fog/reverse light is to be reinstalled, install new gaskets around the threaded mounting stud and light connector.
    Note
    Liftgate lamp connector gasket: 1453384-00-A; Liftgate lamp double-ended stud gasket: 1453383-00-A
