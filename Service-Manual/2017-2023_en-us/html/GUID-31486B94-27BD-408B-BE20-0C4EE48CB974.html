Radiator (Heat Pump) (Remove and Replace)

Correction code 18301022 1.26 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-08-28: Added routine to reset the radiator health value.
  • 2024-08-22: Updated linked to procedure to Cooling Fan Module to correct missing steps.
Parent topic: 1830 - Cooling System

Remove

  1. Open the LH front door and lower the LH front window.
  2. Raise and support the vehicle.
  3. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  4. Connect a laptop with Toolbox to the vehicle. See Toolbox (Connect and Disconnect).
  5. Enable Service Mode through the touchscreen. See Service Mode.
  6. Access the thermal system routines on the touchscreen: Touch Quick Controls > Service Mode > Diagnostics > Thermal.
    Note
    Authorize routines by holding the turn signal stalk full up (right hand turn) while applying brake with the key in the vehicle.
  7. Touch Start Thermal Fill Drain (Coolant Only) on the touchscreen.
    Note
    Touch the X at the top left of window to close once completed.
    Note
    Verify the indicator displays green and the vehicle is ready for the coolant fill/drain.
    Note
    Thermal "Fill Drain" routine has a 5 hour time limit. After 5 hours, the routine must be performed again.
  8. Disconnect the LV power. See 12V/LV Power (Disconnect and Connect).
  9. Remove the cooling fan module assembly. See Module - Cooling Fan (Heat Pump) (Remove and Install).
  10. Remove the active grille shutter. See Active Grille Shutter (Remove and Replace).
  11. Release the locking tabs that attach the radiator to the cooling fan and shroud assembly, and then remove the radiator from the fan and shroud assembly.
  12. Remove the stone guard. See Stone Guard（Heat Pump) (Remove and Replace).
    Note
    Perform this step only if the following conditions are met:
    • the old radiator is equipped with a stone guard.
    • the new radiator does not include a stone guard.

Install

  1. If removed, install the stone guard. See Stone Guard（Heat Pump) (Remove and Replace).
  2. Install the radiator to the cooling fan and shroud assembly, and then fasten the locking tabs that attach the radiator to the fan and shroud assembly.
  3. Install the active grille shutter. See Active Grille Shutter (Remove and Replace).
  4. Install the cooling fan module assembly. See Module - Cooling Fan (Heat Pump) (Remove and Install).
  5. Perform the routine PROC_VC_X_RESET-RADIATOR-UA-INDEXvia Toolbox:(link)
    Note
    Perform this step for firmware versions develop/2026.14.3 and later.
  6. Perform the routine using Service Mode or Toolbox: TEST-SELF_VCFRONT_X_THERMAL-PERFORMANCEvia Service Mode:Thermal ➜ Actions ➜ Test Thermal Performancevia Service Mode Plus:
    • Drive Inverter ➜ Front Drive Inverter Replacement ➜ Thermal System Test
    • Drive Inverter ➜ Rear Drive Inverter Replacement ➜ Thermal System Test
    • Drive Inverter ➜ Rear Left Drive Inverter Replacement ➜ Thermal System Test
    • Drive Inverter ➜ Rear Right Drive Inverter Replacement ➜ Thermal System Test
    • Drive Unit ➜ Front Drive Unit Replacement ➜ Thermal System Test
    • Drive Unit ➜ Rear Drive Unit Replacement ➜ Thermal System Test
    via Toolbox:(link)
  7. Disconnect the laptop with Toolbox from the vehicle. See Toolbox (Connect and Disconnect).
  8. Exit Service Mode Plus.
  9. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  10. Raise the LH front window and close the LH front door.
  11. Remove the vehicle from the lift.
