Coolant Pump - Powertrain (Heat Pump) (Remove and Replace)

Correction code 18308122 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Note
If the coolant pump has been replaced twice, escalate a Toolbox session before proceed.

Torque Specifications

Table 1. Torque Specifications: Coolant Pump - Powertrain (Heat Pump) (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x4) that attach the powertrain coolant pump to the supermanifold
1.8 Nm (1.3 lbs-ft)
  • T20 socket
Reuse

Remove

  1. Open the LH front door and fully lower the LH front window.
  2. Place the vehicle in Service Mode. See Service Mode.
  3. Remove the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  4. Remove the fresh intake duct. See Duct - Fresh Intake (Remove and Replace).
  5. Unlock the vehicle gateway. See Gateway (Unlock).
  6. On the touchscreen, touch Service Mode > Thermal > Coolant System > Coolant Fill Drain and select Run, and allow the routine to complete.
  7. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  8. Place an absorbent material underneath the coolant pump.
    Note
    Make sure the material covers the front drive unit 12V connector, steering rack, and is positioned to catch fluid from the heat exchanger coolant outlet.
  9. Release the locking tab, and then disconnect the electrical harness from the powertrain coolant pump connector.
    CAUTION
    DO NOT push down on the red locking tab. Pull the tab away from the connector until the connector is unlocked, and then continue pulling the main body of the connector to fully disconnect it.
  10. Remove the bolts (x4) that attach the powertrain coolant pump to the supermanifold, and then remove the pump from the supermanifold.
    CAUTION
    Make sure the inner and outer O-rings are removed with the coolant pump.
    Tip
    Use of the following tool(s) is recommended:
    • T20 socket

Install

  1. Remove and discard any o-rings or debris in the supermanifold where the coolant pump will install.
  2. Make sure that new o-rings are installed onto the new coolant pump.
  3. Lubricate the o-rings with Silicone lubricant.
  4. Position the outlet of the coolant pump in the up position, and then insert the coolant pump into the supermanifold.
    CAUTION
    Make sure that the coolant pump is fully seated in the supermanifold.
  5. Hand-tighten the bolts (x4) to attach the coolant pump to the supermanifold.
  6. Tighten the coolant pump bolts (x4) in a cross-pattern.
    1.8 Nm (1.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • T20 socket
  7. Connect the electrical harness to the coolant pump connector, and then engage the locking tab.
    CAUTION
    Push the red locking tab towards the connector to engage the locking mechanism. DO NOT push down or pull up on the red locking tab.
  8. Remove the coolant drain material from under the vehicle.
  9. Install the fresh intake duct. See Duct - Fresh Intake (Remove and Replace).
  10. Perform a cooling system vacuum refill. See Cooling System (Vacuum Refill).
  11. Connect 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  12. Unlock the vehicle gateway. See Gateway (Unlock).
  13. On the touchscreen, tap the Service Mode "wrench" (at the bottom of the touchscreen UI), and then tap Thermal > Stop Thermal Fill Drain, and allow the routine to complete.
  14. Place the vehicle in Service Mode Plus. See Service Mode Plus.
  15. Tap Thermal > Actions > Thermal Configurations > coolantPumpType to inspect the current coolant pump configuration. If the configuration is not DUAL_MIX, change it to DUAL_MIX.
  16. Tap Coolant System > Run Coolant Pumps Identification > Run, and close once the routine is passed.
  17. Tap Coolant System > Coolant Purge > Run, and close once the routine is passed.
  18. Inspect the coolant level and make sure the fluid level is at the Max line.
  19. Install the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  20. On the touchscreen, press and hold the Exit Service Mode button to exit Service Mode Plus.
