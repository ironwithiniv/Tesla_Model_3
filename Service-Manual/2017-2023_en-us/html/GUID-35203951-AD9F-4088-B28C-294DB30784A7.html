Buckle - 1st Row - LH (Remove and Replace)

Correction code 20054702 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-11-13: Added steps to make sure that the seat belt buckle harness is routed properly.
  • 2026-10-27: Added SRS safety note. Added note to refer to Collision Repair Manual for list of components to inspect or replace after a collision.
  • 2024-11-26: Add a note to ensure to engage the pin on the buckle with the slot in the seat track.

Torque Specifications

Description Torque Value Recommended Tools Reuse/Replace Notes
Patchbolt that attaches the buckle to the seat track
40 Nm (29.5 lbs-ft)
  • Torx T50 socket
 Replace 1117250-00-A

Remove

  1. Remove the inboard side shield. See Side Shield - Inboard - Driver Seat (Remove and Replace).
  2. Disconnect the electrical connector from the LH 1st row buckle.
  3. Release the harness clip from the seat bottom frame.
  4. Remove and discard the patch bolt that attaches the buckle to the seat track, and then remove the buckle.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket

Install

  1. Reroute the LH front seat buckle harness.
    Note
    Route the cable upwards along the bottom side, and then attach it with a tie wrap. Make sure the tie wrap lock is on the bottom side.
  2. Install the patch bolt that comes with the new seat belt buckle to attach the buckle to the seat track.
    40 Nm (29.5 lbs-ft)
    CAUTION
    Make sure to engage the pin on the buckle with the slot in the seat track.
    CAUTION
    Make sure that the harness is not trapped between the buckle and the lower frame.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket
  3. Connect the electrical connector to the LH 1st row buckle.
  4. Raise the seat to its highest position while inspecting the seat belt buckle harness with a flashlight to make sure its not catching on anything.
  5. With the seat still at its highest position, install the LH front seat buckle harness clip to the side shield carrier.
  6. Adjust the tension of the seat buckle harness.
    Note
    Make sure that the harness is extended as far forward as possible to eliminate slack on the back side of the clip. Install new tie wrap, if needed.
  7. Fully raise and lower the seat, inspecting the seat belt buckle harness with a flashlight to make sure it is not straining or catching on anything.
  8. Install the inboard side shield. See Side Shield - Inboard - Driver Seat (Remove and Replace).
