Check Strap - Door - Rear - LH (Remove and Replace)

Correction code 10106552 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1454796-00-A TOOLKIT, WINDOW SWITCH
Parent topic: 1010 - Body Panels

Remove

  1. Remove rear window motor/regulator assembly. See Window Regulator - Rear - LH (Remove and Replace).
  2. Using a T40 bit, remove the bolt that attaches the LH rear door check strap to the A-pillar body.
    24 Nm (17.7 lbs-ft)
    CAUTION
    Unbolting the door check allows the door to swing freely beyond opening limits.
  3. Using a 10 mm deep socket, remove the nuts (x2) that attach the check strap to the door.
    10 Nm (7.4 lbs-ft)
  4. Reach inside the door opening and remove the check strap from the vehicle.

Install

Installation procedure is the reverse of removal, except for the following:

  • Make sure to adjust and calibrate the window.
