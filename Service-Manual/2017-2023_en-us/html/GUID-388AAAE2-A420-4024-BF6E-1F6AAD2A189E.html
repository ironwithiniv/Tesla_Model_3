Liner Stiffener- Front Wheel House - LH (Remove and Replace)

Correction code 10018802 0.06 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1001 - Bumper / Fascia

Remove

  1. Turn steering wheel fully to the right.
  2. Remove push clips (x3) that attach LH front wheel arch liner to vehicle.
  3. Pull front portion of LH wheelhouse liner away from front fascia.
  4. Remove the LH front wheel housing liner reinforcement from the front fascia.

Install

  1. Install the LH front wheel housing liner reinforcement from the front fascia.
  2. Move LH wheelhouse liner back into installed position.
  3. Install the push clips (x3) that attach LH front wheel arch liner to vehicle.
  4. Turn steering wheel fully to center.
