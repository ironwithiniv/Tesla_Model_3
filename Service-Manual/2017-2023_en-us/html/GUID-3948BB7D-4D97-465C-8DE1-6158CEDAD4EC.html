Visor - Car Computer (Info-Ryzen) (Remove and Replace)

Correction code 21151022 1.20 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
Parent topic: 2115 - Car Computer

Remove

  1. Open all four doors
    Note
    If vehicle is being powered down, Latch rear doors to prevent accidental closure
  2. Lower all four windows
  3. Move RH front seat backward
  4. Open hood
  5. Remove rear apron
    Note
    12x clips, only store the rear apron visible face upwards
  6. Power off vehicle from center display
    Note
    Via Controls > Safety & Security > Vehicle Power > Power Off, Confirm power off at warning dialogue box
  7. Disconnect LV battery
    Note
    2x connectors, Lift up and release green locking tab, Pull black connector lock outwards to release connection
  8. Disconnect service disconnect
    Note
    1x connector, Release locking tab
  9. Remove RH IP end cap
    Note
    3x clips
  10. Remove RH mid A-pillar assembly
    Note
    1x clip, 1x tab, Release the upper clip then pull mid A-pillar upward to remove
  11. Remove clip for RH lower A-pillar trim
    Note
    1x push clip
  12. Remove RH lower A-pillar trim
    Note
    1x clip, 2 guide tabs, Pull rear of lower A-pillar upward to release clip then pull rearward to release front tabs from carpet
  13. Remove RH front floor mat
  14. Remove RH console side panel carpet
    Note
    12x clips, Use trim tool starting at rear edge to release upper clips, Pull bottom to release remaining clips
  15. Remove clips securing RH footwell assembly
    Note
    4x push clips
  16. Disconnect RH foot well assembly connectors and remove from vehicle
    Note
    2x electrical connectors
  17. Remove the fasteners securing passenger knee airbag to vehicle
    Note
    4x patch bolts, T30, 8 Nm, Discard after removal, 2x screws, T20, 2 Nm, Newer vehicles have 4x patch bolts, E10, Discard after removal, Support the knee air bag while lowering, The connector / harness length is very short
  18. Remove the passenger knee air bag from vehicle
    Note
    1x connector, Release locking tab, Connector release may vary
  19. Remove main decor assembly
    Note
    15x clips, Entire decor does not need to come off for glove box removal, If you lift RH side of decor then you will have access to 3x torx screws securing top of glove box, Replace securing clips as needed
  20. Remove screws securing glove box assembly to IP carrier
    Note
    6x screws, T20, 2.3 Nm
  21. Disconnect glove box assembly connectors
    Note
    3x electrical connectors
  22. Disconnect glove box USB cable from car computer
    Note
    1x connector, Depress latch on top of USB cable to release internal latches, then release from car computer
  23. Remove the glove box from IP carrier
    Note
    3x clips
  24. Remove the passenger footwell air duct
    Note
    1x push clip
  25. Remove the RH IP air wave duct
    Note
    2x push clips
  26. Remove clips securing RH front main cabin carpet to footwell area
    Note
    3x push clips, Number of clips may vary on older vehicles
  27. Fold the RH front main cabin carpet aside for access
    Note
    2x clips, Lift the center piece and pull the carpet back, Release seat harness from clips to allow the carpet to fold back more
  28. Remove the nuts securing RH carpet locator bracket
    Note
    2x nuts, 10mm, 2.5 Nm, Newer vehicles may use clips instead of nuts
  29. Remove the RH carpet locator bracket from vehicle
  30. Place absorbent material beneath car computer to catch any spilled coolant
  31. Remove cabin intake upper duct assembly
    Note
    3x clips, Older vehicles may be equipped with 4x clips
  32. Remove the close out panel from frunk assembly
    Note
    4x clips, 1x connector, Frunk safety switch, 3x guide tabs, Grab the closeout panel from the bottom then pull it upward to release clips
  33. Remove frunk assembly carpet
  34. Remove fasteners securing the frunk assembly
    Note
    7x bolts, 10mm, 5 Nm, Lift up the RBN covers to access the upper fasteners, Newer vehicles may not be equipped with covers
  35. Remove frunk assembly from vehicle
    Note
    12x clips, Replace any clips if broken or missing, Number of clips may vary on older vehicles
  36. Remove HVAC plenum duct
  37. Place absorbent material below car computer coolant hose connection points to collect any spilled coolant
  38. Release coolant hoses from car computer
    Note
    2x spring clips
  39. Install coolant plugs into coolant outlets of car computer that is being removed from vehicle
  40. Install coolant plugs in hoses
    Note
    2x plugs, Do not need to engage spring clips
  41. Remove and discard nuts securing car computer to bulkhead
    Note
    6x nyloc nuts, 7.1 Nm, Discard nuts after removal
  42. Disconnect connectors for passenger air bag assembly
    Note
    3x connectors, 2x connectors for regions other than North America, Connector release may vary
  43. Remove bolts securing passenger air bag assembly to cross car beam
    Note
    4x patch bolts, T30, 8 Nm, Newer vehicles have 4x E10 patch bolts, Discard after removal
  44. Remove car computer from bulkhead
    Note
    With right hand on top of car computer, and left hand under car computer use back of right hand to help push air bag assembly up and towards back of vehicle. Take care to not damage air bag connections, or wiring harnesses.
  45. Remove visor from car computer
    Note
    4xclips Pull tab on left side of computer away from computer and lift visor up and way.

Install

  1. Install visor on computer
    Note
    4x clips, Align coolant pipe clips over coolant pipes and lower visor until all clips are secured.
  2. Lift computer into position on bulkhead
    Note
    With right hand on top of computer and left hand under computer, use right hand to help push airbag up and towards the rear of the vehicle to provide clearance for visor.
  3. Install nuts securing car computer to the bulkhead
    Note
    6x nyloc nuts, 13mm 7.1Nm Install new nyloc nuts
  4. Remove plugs from hoses
    Note
    2x plugs, Engage spring clips after removal
  5. Remove coolant plugs from car computer
    Note
    2x plugs
  6. Install coolant hoses to car computer
    Note
    2x hose connectors. Ensure clips seated properly in car computer detents.
  7. Remove coolant bottle cap
  8. Fill coolant bottle to base of neck as indicated
  9. Remove absorbent material from below car computer coolant hose connection points
  10. Remove absorbent material from beneath car computer
  11. Secure airbag to cross car beam.
    Note
    4x patch bolts, T30, 8 Nm, Newer vehicles have 4x E10 patch bolts,
  12. Connect connectors for passenger air bag assembly
    Note
    3x connectors, 2x connectors for regions other than North America, Connector release may vary
  13. Install the RH carpet locator bracket into vehicle
  14. Install the nuts securing RH carpet locator bracket
    Note
    2x nuts, 10mm, 2.5 Nm, Newer vehicles may use clips instead of nuts
  15. Fold the RH front main cabin carpet back to original position
    Note
    Move front edge down and slide back section up to ease positioning, Install seat harness into clips
  16. Install clips securing passenger side of cabin main carpet to footwell area
    Note
    3x push clips
  17. Install the RH IP air wave duct
    Note
    2x push clips
  18. Install the passenger footwell air duct
    Note
    1x push clip
  19. Connect glove box assembly connectors
    Note
    3x connectors, New puddle lamp harness routing prevent blocking movement of pawls, Make sure harness is routed properly above passenger footwell air duct before connecting
  20. Install the glove box into IP carrier
    Note
    3x clips
  21. Install screws securing glove box assembly to IP carrier
    Note
    6x screws, T20, 2.3 Nm
  22. Install main decor assembly
    Note
    15x clips, 1x center clip
  23. Install the passenger knee air bag into vehicle
    Note
    1x connector, Use caution not to damage the connector/harness, Support the knee air bag while connecting the connector
  24. Install fasteners securing passenger knee air bag to vehicle
    Note
    4x patch bolts, E10, 8 Nm, Install new patch bolts, 2x screws, T20, 2 Nm, 1x push clip, If vehicle equipped with T30 bolts, update to E10
  25. Install clips securing RH footwell assembly
    Note
    4x push clips
  26. Install RH lower A-pillar trim
    Note
    1x clip, 2 guide tabs, Align the 2 front tabs then align the slot with harness bracket and then push rear clip to secure to lower B-pillar
  27. Install clip for RH lower A-pillar trim
    Note
    1x push clip
  28. Install RH mid A-pillar assembly
    Note
    1x clip, 1x tab, Align the bottom tab then push the top clip to fully seat mid A-pillar, Make sure the seal seat on top of the trim
  29. Install RH IP end cap
    Note
    3x clips
  30. Reconnect service disconnect
    Note
    1x connector secure locking tab
  31. Connect LV battery connector
    Note
    Push connector down while pushing slide lock in, Seat e-CPA after lock is fully secured
  32. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): TEST-SELF_VCFRONT_X_THERMAL-PERFORMANCEvia Service Mode:Thermal ➜ Actions ➜ Test Thermal Performancevia Service Mode Plus:
    • Drive Inverter ➜ Front Drive Inverter Replacement ➜ Thermal System Test
    • Drive Inverter ➜ Rear Drive Inverter Replacement ➜ Thermal System Test
    • Drive Inverter ➜ Rear Left Drive Inverter Replacement ➜ Thermal System Test
    • Drive Inverter ➜ Rear Right Drive Inverter Replacement ➜ Thermal System Test
    • Drive Unit ➜ Front Drive Unit Replacement ➜ Thermal System Test
    • Drive Unit ➜ Rear Drive Unit Replacement ➜ Thermal System Test
    via Toolbox:(link)
    Note
    Coolant pumps will be audible, Test lasts approximately 10 mins, Putting vehicle into drive state will stop this routine, Monitor levels as required, Select ‘X’ at top left of window to close once complete
  33. Inspect coolant level and top off as necessary
    Note
    Ensure that the fluid level is at the Max line
  34. Install coolant bottle cap
  35. Install frunk assembly to vehicle
    Note
    12x clips, Make sure frunk assembly is fully seated onto the clips, Number of clips may vary on older vehicles
  36. Install fasteners securing the frunk assembly
    Note
    7x bolts, 10mm, 5 Nm, Lower the RBN covers after installing upper fasteners, Newer vehicles may not be equipped with covers
  37. Install frunk assembly carpet
  38. Install frunk close out panel
    Note
    4x clips, 1x connector, Frunk safety switch, 3x guide tabs, Align the 3x tabs then push downward to secure clips
  39. Press and hold park button to release EPB service mode
    Note
    Remove wheel chocks if necessary
  40. Install cabin intake upper duct assembly
    Note
    3x clips, Older vehicles may be equipped with 4x clips
  41. Install rear apron
    Note
    12x clips, If present untuck cut loop label and make sure it is still visible after apron is installed, Later builds may not have label
  42. Close hood
  43. Raise all the windows
  44. Close all four doors
    Note
    Unlatch rear doors before closing
