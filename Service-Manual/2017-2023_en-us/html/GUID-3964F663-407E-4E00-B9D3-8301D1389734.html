USB Hub - Center Console - Rear (Remove and Replace)

Correction code 21260602 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-10-12: Added steps to remove and install the tabs that secure the rear air vent into the air vent panel.
Parent topic: 2126 - Audio System - USB Media Port

Torque Specifications

Table 1. Torque Specifications: USB Hub - Center Console - Rear (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Screws (x2) that attach the vent unit to the center console air vent panel
1.6 Nm (1.2 lbs-ft)
  • Torx T20 bit
 Reuse
Screws (x2) that attach the rear center console USB hub to the center console air vent
1.1 Nm (.8 lbs-ft)
  • Torx T10 bit
 Reuse

Remove

  1. Remove the center console air vent panel. See Assembly - Rear Vent - Center Console (Remove and Replace).
  2. Remove the screws (x2) that attach the vent unit to the center console air vent panel.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 bit
  3. Pry to release the left tabs (x2), the right tabs (x2), and the hidden tabs (x4) on the bottom, then remove the rear air vent from the panel.
    Note
    Use of the following tool(s) is recommended:
    • Pick Miniature Soft Grip, 90 degree tip, 6 in
  4. Remove the screws (x2) that attach the rear center console USB hub to the center console air vent, and remove the USB hub from the vent.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T10 bit

Install

  1. Position the rear center console USB hub onto the rear air vent pan, and then install the screws (x2) that attach the rear center console USB hub to the center console air vent.
    1.1 Nm (.8 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T10 bit
  2. Secure the tabs (x8) to install the rear air vent to the panel.
  3. Install the screws (x2) that attach the vent unit to the center console air vent panel.
    1.6 Nm (1.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 bit
  4. Install the center console air vent panel. See Assembly - Rear Vent - Center Console (Remove and Replace).
