Wiper Arms (Remove and Replace)

Correction code 17501802 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1058696-00-A Wiper Arm Removal Tool
Parent topic: 1750 - Wipers and Washers

Torque Specifications

Table 1. Torque Specifications: Wiper Arms (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Nut that attaches the LH wiper arm to the wiper motor assembly
25 Nm (18.4 lbs-ft)
  • 15 mm socket
 Reuse
Nut that attaches the RH wiper arm to the wiper motor assembly
25 Nm (18.4 lbs-ft)
  • 15 mm socket
 Reuse

Remove

  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Remove the wiper arm nut covers.
  3. Release the LH and RH wiper arm hoses from the Y-tube.
  4. Release the clips (x2 for each arm) that attach the LH and RH wiper arm hoses to the vehicle.
  5. Remove the nuts that attach the wiper arms to the wiper motor assembly.
  6. Place the base of the wiper arm removal tool under the wiper arm and position the set screw so that it is centered and touching the wiper arm stud, and then tighten the set screw until the wiper arm is released.
    CAUTION
    Removing the wiper arm without the wiper arm removal tool can result in damage to the wiper arm or wiper motor.
  7. Remove the wiper arms from the vehicle.

Install

  1. Position the LH and RH wiper arms onto the vehicle.
    Note
    Make sure to route the hoses behind the wiper arm pivot joint.
  2. Install and hand-tighten the nuts that attach the wiper arms to the wiper motor assembly.
  3. Align the tip of the RH wiper blade between the two arrows on the windshield.
  4. Tighten the nut to attach the RH wiper arm.
    25 Nm (18.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm socket
  5. Align the tip of the LH wiper blade between the two arrows on the windshield.
    Note
    The LH wiper blade should be approximately 5 - 10mm from, and parallel to, the front edge of the windshield.
  6. Tighten the nut to attach the LH wiper arm.
    25 Nm (18.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm socket
  7. Connect the LH and RH wiper arm hoses to the Y-tube fitting.
  8. Connect the clips (x2 for each arm) that attach the LH and RH wiper arm hoses to the vehicle.
  9. Install the wiper arm nut covers.
  10. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
