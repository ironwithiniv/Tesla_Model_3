Latch - Hood (Remove and Replace)

Correction code 11352002 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1135 - Latches Strikers and Pinch Sensors

Remove

Note
If the hood latch does not open electronically, use the manual front trunk release tool to open the hood.
  • 1130534-00-ATOOL, FRUNK RELEASE, MANUAL, MODEL 3
CAUTION
When using the manual front trunk release tool in Mobile Service, raise the vehicle using mini ramps and verify stability of the vehicle.
  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Remove the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  3. Remove the hood latch cover. See Cover - Hood Latch (Remove and Replace).
  4. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  5. Release the primary hood latch actuator cable from the hood latch.
    Note
    Release the clip before removing the primary latch actuator cable from the hood latch arm.
  6. Release the secondary hood latch actuator cable from the hood latch.
    Note
    Release the clip before removing the secondary latch actuator cable from the hood latch arm.
  7. Disconnect the electrical connector from the hood latch connector.
  8. Mark the location of the hood latch with masking tape.
  9. Remove the bolts that attach the hood latch to the front end carrier, and then remove the latch from the vehicle.
    8 Nm (5.9 lbs-ft)

Install

Installation procedure is the reverse of removal.
