Glove Box - With Knee Airbags (Non-Heat Pump) (Remove and Replace)

Correction code 14051002 0.54 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1405 - Instrument Panel

Torque Specifications

Table 1. Torque Specifications: Glove Box - With Knee Airbags (Non-Heat Pump) (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Screws (x6) that attach the glove box to the IP carrier
2.3 Nm (1.7 lbs-ft)
  • Torx T20 socket
  • ¼ in std ratchet
  • ¼ in torque wrench (installation only)
  • 4 in extension
Reuse

Remove

  1. Remove and secure the customer's belongings from the glove box, if needed.
  2. Remove the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  3. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  4. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  5. Remove the LH and RH instrument panel end caps. See End Cap - Instrument Panel - LH (Remove and Replace).
  6. Remove the RH middle A-pillar trim. See Trim - A-Pillar - Middle - LH (Remove and Replace).
  7. Remove the RH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  8. Remove the passenger footwell cover. See Cover - Footwell - Passenger (LHD) (Remove and Replace).
  9. Remove the front passenger knee airbag. See Airbag - Knee - Front Passenger (Remove and Replace).
  10. Remove the main instrument panel decor trim. See Decor Trim - Instrument Panel - Main (Remove and Replace).
  11. Remove the screws (x6) that attach the glove box to the IP carrier.
    Note
    Use of the following tools is recommended:
    • Torx T20 socket
    • ¼ in std ratchet
    • ¼ in torque wrench (installation only)
    • 4 in extension
  12. Release the clips that attach the glove box to the IP carrier.
  13. Disconnect the electrical harness from the glove box solenoid connector, the damper connector, and the puddle light connector.
    Note
    2 of the electrical connectors are accessed from the bottom of the instrument panel.
  14. Remove the glove box from the vehicle.

Install

  1. Bring the glove box into the vehicle, and then connect the electrical harness to the glove box solenoid connector, the damper connector, and the puddle light connector.
    Note
    2 of the electrical connectors are accessed from the bottom of the instrument panel.
    Note
    Route the puddle lamp electrical harness as illustrated.
  2. Make sure that the glove box damper pin is fully seated.
    CAUTION
    Do not bump the glove box damper when installing the glove box.
  3. Fasten the clips that attach the glove box to the IP carrier.
  4. Install the screws (x6) that attach the glove box to the IP carrier.
    2.3 Nm (1.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
    • ¼ in std ratchet
    • ¼ in torque wrench (installation only)
    • 4 in extension
  5. Install the main instrument panel decor trim. See Decor Trim - Instrument Panel - Main (Remove and Replace).
  6. Install the front passenger knee airbag. See Airbag - Knee - Front Passenger (Remove and Replace).
  7. Install the passenger footwell cover. See Cover - Footwell - Passenger (LHD) (Remove and Replace).
  8. Install the RH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  9. Install the RH middle A-pillar trim. See Trim - A-Pillar - Middle - LH (Remove and Replace).
  10. Install the LH and RH instrument panel end caps. See End Cap - Instrument Panel - LH (Remove and Replace).
  11. Connect 12V power. See 12V/LV Power (Disconnect and Connect).
  12. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  13. Install the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  14. Verify that the glove box door opens normally through the touchscreen.
  15. Return the customer's belongings in the glove box, if needed.
