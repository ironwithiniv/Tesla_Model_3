BLE TPMS (Retrofit)

Correction code 34040006 1.56 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 3404 - Tire Pressure Monitoring System (TPMS)

Retrofit

  1. Remove the TPMS sensor from the wheel. See Sensor - TPMS (Remove and Replace).
  2. Use an IPA wipe to thoroughly clean the inside and outside of the TPMS sensor mounting hole.
  3. Install the BLE TPMS sensor so that it fits closely to the wheel.
    Note
    Prior to installation, use an IPA wipe to thoroughly clean the inside and outside of the TPMS sensor mounting hole.
    Note
    Verify that the TPMS seal is fully seated against the base; failure to do so could cause damage to the seal during installation.
  4. Install the nut that secures the BLE TPMS sensor to the wheel.
    8 Nm (5.9 lbs-ft)
  5. Release the upper bead roller, and allow the bead to seat against the wheel.
  6. Inflate the tire to seat the bead.
  7. Install the valve stem core, and then remove the wheel from the tire changer.
  8. Rebalance the wheel. See Tire - Front - LH (Balance).
  9. Reinstall the wheel. See Wheel Assembly (Remove and Install).
  10. Repeat steps 1 through 9 for all wheels.
  11. Update the Vehicle Configuration. See BLE TPMS (Update Configuration).
  12. Test drive the vehicle to at least 15 mph (24 kph) for 1-3 minutes to reconnect the TPMS sensors.
  13. Confirm on the vehicle touchscreen that all 4 TPMS sensors are providing tire pressure readings.
