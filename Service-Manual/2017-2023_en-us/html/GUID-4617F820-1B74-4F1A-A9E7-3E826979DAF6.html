Clean the Blower Motor

Correction code 18103205 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1810 - Cabin HVAC

Remove

  1. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  2. Remove the fresh air intake assembly. See Duct - Fresh Intake (Remove and Replace).
  3. Turn the HVAC on, then off to open the fresh air inlet duct and gain access to the blower.
  4. Remove any loose debris from the fresh air inlet seal.
  5. Use an air gun to blow shop air into the HVAC module assembly to remove dust particles from the blower.
  6. Remove the cabin filter. See Filter - Cabin (Remove and Replace).

Install

  1. Install the cabin filter. See Filter - Cabin (Remove and Replace).
  2. Install the fresh air intake assembly. See Duct - Fresh Intake (Remove and Replace).
  3. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
