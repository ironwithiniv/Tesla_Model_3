Vent - Front - RH (Remove and Replace)

Correction code 14053202 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. Reuse

Remove

  1. Remove the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  2. Remove the LH and RH air wave end caps. See End Cap - Air Wave - LH (Remove and Replace).
  3. Remove the main instrument panel decor trim. See Decor Trim - Instrument Panel - Main (Remove and Replace).
  4. Remove the vent finisher. See Finisher - Vent (Remove and Replace).
  5. Remove the screw that attaches the RH front vent to the instrument panel, and then pull the RH side of the RH front vent to release it from the instrument panel.
    2.3 Nm (1.7 lbs-ft)
  6. Disconnect the electrical connector from the RH front vent, and then remove the RH front vent from the vehicle.

Install

Installation procedure is the reverse of removal, except for the following:

Note
If the vehicle is RHD, make sure not to dislodge the foam block in the cavity where the front RH vent installs.
  1. Connect a laptop with Toolbox to the vehicle. See Toolbox (Connect and Disconnect).
  2. Select Actions and search for "Actuator".
  3. Run the ODIN routine: TEST-SELF_VCRIGHT_X_HVAC-CASE-ACTUATORSvia Toolbox:(link)
  4. Run the ODIN routine: TEST-SELF_VCRIGHT_R_HVAC-VANE-ACTUATORvia Toolbox:(link)
  5. Remove the laptop from the vehicle and exit the service mode.
