Harness - Main Front (LHD) (Remove and Replace)

Correction code 17100702 4.32 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-04-29: Corrected torque figures for the bolts that attach the shock tower brace to the vehicle.
  • 2023-08-25: Updated EPB Service Mode reference.
  • 2023-06-21: Added note to check brake pedal feel and bleed brakes if needed.
  • 2023-03-21:Revised procedure
Parent topic: 1710 - Harnesses

Remove

  1. Open all four doors and lower all four windows.
  2. Enable the EPB Service Mode. See Parking Brake - Caliper - Rear - LH (Release)
  3. Move LH front seat forward
  4. Move RH front seat forward
  5. Remove 2nd row seat cushion and disconnect harness
    Note
    2x tabs, 2x connectors, Slide locking tabs to left of vehicle while lifting up seat bench. Newer models have connectors on both sides of bench, Older models have 2x connectors on one side of bench
  6. Move LH front seat backward
  7. Move RH front seat backward
  8. Open hood
    Note
    Press "Open" button on the touchscreen to release the latch, Lift the lid manually

    Note
    12x clips, Only store rear apron visible face upwards

    Note
    Via Controls > Safety > Power Off, Select Power Off button at warning dialogue box

    1x nut, 10mm, 6 Nm, Ensure the vehicle is in park, climate control system is off, and vehicle is not charging before disconnecting 12V

    1x cap

Install

  1. Position the front harness to vehicle for installation
    Note
    Make sure to route RH branch underneath A/C compressor HV harness
  2. Route the front harness around the brake booster area and push the LH side of the harness into driver side compartment
    Note
    4x clips, Make sure to install grommet in proper orientation
  3. Route the front harness around the HVAC plenum duct area and push the RH side of the harness into passenger side compartment
    Note
    4x clips, Route harness underneath A/C HV harness, Make sure to install grommet in proper orientation
  4. Route the RH side of the front harness toward the RH side of the front fascia area
    Note
    Make sure plastic housing is properly oriented with clips facing frame rail, Feed harness down behind fascia
  5. Route the RH side of the front harness from frunk to RH wheel liner area
  6. Route HVIL connectors down along bulkhead
  7. Route the LH side of the front harness toward the LH side front fascia area
    Note
    Make sure plastic housing is properly oriented with clips facing frame rail, Feed harness down behind fascia
  8. Route the LH side of the front harness from frunk to LH wheel liner area
  9. Install the front harness clips around LH frame rail area
    Note
    3x clips, Number of clips may vary on newer vehicles
  10. Install the front harness clips around the RH front frame rail area

    3x clips, Number of clips on new vehicles may vary
