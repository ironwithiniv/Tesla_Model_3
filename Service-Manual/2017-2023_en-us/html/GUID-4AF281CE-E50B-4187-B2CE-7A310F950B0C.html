Jumper Harness - Windshield (Retrofit)

Correction code 17105316 0.06 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1782284-00-A ASY, HARN, GCL WINDSHIELD, JUMPER, M3
Parent topic: 1710 - Harnesses

Retrofit

  1. If not already performed for another service operation, disconnect the windshield heater connector.
  2. Connect the windshield jumper harness to the windshield heater connector and the main front harness connector.
  3. Use a cable tie to secure the windshield jumper harness connector and the windshield heater connector to the main front harness. Cut excessive tie from the cable tie.
  4. If necessary, return to the service procedure in progress before this retrofit was performed.
