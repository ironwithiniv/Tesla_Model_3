Fluid Coupling (90 Degrees) - Front Drive Unit (Remove and Replace)

Correction code 39014012 2.82 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 3901 - Front Drive Unit Assembly

Remove

  1. Remove the front subframe assembly. See Subframe Assembly - Front (Dual Motor) (Remove and Install).
  2. Release the clip that attaches the front drive unit inlet hose to the 90 degrees fluid coupling, and then disconnect the hose.
    Note
    Use a foldable funnel as required.
  3. Remove and discard the bolts that attach the LH front drive unit mount to the front drive unit, and then remove the mount from the front drive unit.
  4. Remove and discard the fastener that attaches the 90 degrees fluid coupling to the drive inverter, and then remove the 90 degrees fluid coupling from the inverter.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket
    • Flex head ratchet/flex head torque wrench

Install

  1. Lubricate the fluid coupling O-ring(s) with coolant.
  2. Position the 90 degrees fluid coupling to the drive inverter, and then install new fastener.
    6 Nm (4.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket
    • Flex head ratchet/flex head torque wrench
  3. Perform a coolant pressure test:
    1. Install the coolant pressure test plug adapter to the straight fluid coupling.
    2. Install the coolant pressure adapter to the 90 degrees fluid coupling.
    3. Attach the coolant pressure adapter to the compressed air line.
    4. Set pressure to 50 psi, and then slowly open the valve on the pressure regulator. Allow the pressure to reach 50 psi.
    5. Wait 15 seconds for the pressure to settle, and then record the pressure reading.
    6. Wait for another 12 seconds, and then record the reading.
      Note
      Pressure may not have dropped by more than 0.1 psi. If pressure test fails, confirm that fluid couplings are fully seated, and then redo the pressure test.
    7. Remove the coolant pressure test components from the inverter.
  4. Install the LH front drive unit mount to the front drive unit, and then install new bolts that attach the mount to the front drive unit.
    35 Nm (25.8 lbs-ft) + 55 degrees
    Note
    Bolt PN: 1111864-00-B
  5. Install the front drive unit inlet hose to the 90 degrees fluid coupling.
  6. Install the front subframe assembly. See Subframe Assembly - Front (Dual Motor) (Remove and Install).
