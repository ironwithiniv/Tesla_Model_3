Hose - Inverter to Heat Exchanger - Rear Drive Unit (3DU) (Remove and Replace)

Correction code 18300192 2.16 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-04-02:Simplified procedure by referencing to sub-procedures.
  • 2023-08-25: Updated EPB Service Mode reference.
Parent topic: 1830 - Cooling System

Remove

  1. Remove the rear subframe. See Subframe Assembly - Rear (Remove and Install)
  2. Release the RDU inverter to oil cooler hose.
  3. Release the clips (x4) that attach the RDU inverter to oil cooler hose from the RDU assembly.
    Note
    4x clips
  4. Disconnect the RDU inverter coolant hose from the heat exchanger and remove the hose.

Install

  1. Install the RDU inverter to oil cooler hose onto the heat exchanger.
  2. Attach the clips that hold the inverter to coolant hose to the RDU.
    Note
    4x clips
  3. Install the inverter to cooler hose to the inverter.
    Note
    Perform a push-pull-push test to make sure that the hose is fully engaged.
  4. Install the rear subframe. See Subframe Assembly - Rear (Remove and Install).
  5. Perform a coolant air purge. See Cooling System (Partial Refill and Bleed).
  6. Since the subframe was removed and reinstalled: Refer to the Alignment Requirement tables to determine whether an EPAS alignment check (EC) or four wheel alignment check (AC) is necessary. If performed, add the alignment check/adjust correction code as a separate activity to the SV. See Alignment Requirement - Suspension.
