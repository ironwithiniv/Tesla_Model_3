Underhood Storage Unit (Remove and Replace)

Correction code 15240702 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Torque Specifications

Table 1. Torque Specifications: Underhood Storage Unit (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Underhood storage unit to body fasteners
5 Nm (3.7 lbs-ft)
  • 10 mm socket
 Reuse

Remove

  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Remove the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  3. Remove the hood latch cover. See Cover - Hood Latch (Remove and Replace).
  4. Remove the underhood storage unit carpet.
  5. Remove the bolts that attach the underhood storage unit to the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  6. Release the clips (x10) that attach the underhood storage unit to the vehicle, and then remove the underhood storage unit from the vehicle.
    Note
    Replace any broken or missing clips, if reinstalling the same underhood storage unit.
  7. Inspect the HVIL harness branch of the A/C compressor HV harness.
    1. Make sure that the harness does not rest on the shock tower brace where it crosses over to the connector on the LH shock tower.
    2. Inspect the condition of the HVIL harness that it has not been crushed and insulation worn to expose the bare wire.
    3. If a wire has been damaged, perform an electrical harness repair as a separate activity. Refer to the Service Documents page for more information.
      CAUTION
      Make sure there is sufficient slack in the repaired harness so that there is no stress in the connector on the LH shock tower.
  8. If the same underhood storage unit is to be reinstalled, this procedure is finished. If a new underhood storage unit is be installed, continue to the next step.
  9. Remove the tow hook from the underhood storage unit.
  10. Remove the reinforcement clips (x2) attached to the rear of the underhood storage unit.

Install

  1. If the same underhood storage unit removed is being installed, skip to step 4. If a new underhood storage unit is being installed, continue to the next step.
  2. Install the reinforcement clips (x2) to the rear of the underhood storage unit.
  3. Install the tow hook into the underhood storage unit.
  4. Make sure that the HVIL harness branch of the A/C compressor HV harness is properly routed away from and does not rest upon the shock tower brace.
  5. Install the underhood storage unit into the vehicle, and then fasten the clips (x10) that attach the underhood storage unit to the vehicle.
    Note
    Make sure that all clips for the underhood storage unit are engaged.
  6. Install the bolts (x7) that attach the underhood storage unit to the vehicle.
    5 Nm (3.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  7. Use a light to inspect the inside of the hood latch housing for any foreign object that may have dropped in. If any object is found, remove it and confirm that the hood latch is operating as intended.
  8. Install the underhood storage unit carpet.
  9. Install the hood latch cover. See Cover - Hood Latch (Remove and Replace).
    CAUTION
    Prior to installation of the hood latch cover, inspect the clips (x4) that attach the cover to the vehicle body for any damage. If damage is found or when any clip is dislodged or missing, replace the hood latch cover with a new one since the hood latch panel clips are non serviceable parts.
  10. Install the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  11. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
