Trailer Hitch - Rear Energy Absorber (Retrofit)

Correction code 10017652 0.96 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2023-05-02: Rearranged procedure steps and added configuration instructions.
Parent topic: 1001 - Bumper / Fascia

Remove

  1. Remove the rear fascia. See Fascia - Rear (Remove and Install).
  2. Remove the rear bumper beam. See Bumper Beam - Rear (Remove and Replace).

Install

  1. Install the trailer hitch onto the vehicle and secure the LH and RH fasteners.
  2. Install the rear center bracket assembly, connect the rear BLE and fasten the rear center bracket harness clips.
  3. Install the trailer hitch ECU.
  4. Connect trailer hitch ECU to vehicle.
  5. Feed trailer jumper harness through bracket and connect to trailer hitch ECU.
  6. Secure trailer jumper harness clip to trailer hitch.
  7. Secure trailer jumper harness to trailer hitch.
  8. Install the rear fascia. See Fascia - Rear (Remove and Install).
  9. Connect a laptop with Toolbox 3 to the vehicle. See Toolbox (Connect and Disconnect).
  10. Select the Dashboards tab, and then select the Infotainment Dashboard and Vehicle Configuration.
  11. Select Read Config, and then click RUN to load the configuration values.
  12. Scroll down to "towPackage" and select "Tesla Rev 1" from the drop-down menu.
  13. Select Apply Changes, and then click RUN to save the updated configuration.
  14. Disconnect the laptop from the vehicle. See Toolbox (Connect and Disconnect).
