Reuse

Remove

  1. Open the LH front door, and fully lower all windows.
  2. Center the steering wheel, and make sure that the front wheels are pointing straight.
  3. Remove the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  4. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  5. Disconnect 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  6. Remove the driver airbag. See Airbag - Driver (Remove and Replace).
  7. Remove the steering wheel. See Steering Wheel (Remove and Install).
  8. Release the clips that attach the steering column upper shroud to the lower shroud, and then pull the upper shroud up.
  9. Remove the upper screws that attach the steering column lower shroud to the steering column.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
    • Wiha TorqueVario-S 0.8 Nm - 2.0 Nm screwdriver (installation only)
  10. Remove the lower screw that attaches the steering column lower shroud to the steering column, and then remove the lower shroud from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
    • Wiha TorqueVario-S 0.8 Nm - 2.0 Nm screwdriver (installation only)
  11. Remove and discard the retaining clip from the steering column control module connector, and then disconnect the electrical harness from the steering column control module connector.
    CAUTION
    Check for broken clip pieces on the connector, and remove if present.
  12. Make sure that the clockspring tape indicator is visible in the inspection window in the upper left of the steering column control module.
  13. Remove the bolt that attaches the steering column control module to the steering column.
    Tip
    Use of the following tool(s) is recommended:
    • 5 mm hex ball end bit
  14. Remove the steering column control module from the steering column.
    Note
    If the steering column control module removed will be re-installed, make sure not to disturb the splined collar in the center of the module.

Install

  1. Make sure that the clockspring tape indicator is visible in the inspection window in the upper left of the steering column control module.
    Note
    Make sure the ribbon is not loose.
    Note
    Do not remove red tab.
  2. Carefully install the steering column control module onto the steering column, and then install the bolt that attaches the steering column control module to the steering column.
    9 Nm (6.6 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 5 mm hex ball end bit
  3. Install an orange plastic retaining clip (1028053-00-A) into the electrical harness connector for the steering column control module.
  4. Connect the electrical harness to the steering column control module connector.
  5. Perform a push-pull-push test to make sure that the steering column control module electrical connector is seated properly.
  6. Install the lower screw that attaches the steering column lower shroud to the steering column.
    1.5 Nm (1.1 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
    • Wiha TorqueVario-S 0.8 Nm - 2.0 Nm screwdriver (installation only)
  7. Install the upper screws that attach the steering column lower shroud to the steering column.
    1.5 Nm (1.1 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
    • Wiha TorqueVario-S 0.8 Nm - 2.0 Nm screwdriver (installation only)
  8. Install the clips that attach the steering column upper shroud to the lower shroud.
  9. Remove the red locking tab from the new steering column control module by lifting it off.
  10. Install the steering wheel. See Steering Wheel (Remove and Install).
  11. Install the driver airbag. See Airbag - Driver (Remove and Replace).
  12. Connect 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  13. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  14. Enter Service Mode. See Service Mode.
  15. Update the vehicle firmware. See Software Update.
  16. Install the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  17. Exit Service Mode. See Service Mode.
  18. Raise all windows and close the LH front door.
