Reservoir - Windshield Washer (Remove and Install)

Correction code 17501101 0.66 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1750 - Wipers and Washers

Torque Specifications

Table 1. Torque Specifications: Reservoir - Windshield Washer (Remove and Install)
Description Torque Value Recommended Tools Reuse/Replace Notes
Lower/upper bolt that attaches the windshield washer reservoir to the body
3 Nm (2.2 lbs-ft)
  • 10 mm socket
 Reuse

Remove

  1. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  2. Remove the LH and RH wiper arms. See Wiper Arms (Remove and Replace).
  3. Remove the cowl screen panel. See Panel - Cowl Screen (Remove and Replace).
  4. LHD models only: remove the wiper motor. See Wiper Module (Remove and Replace).
  5. Release the clip that attaches the electrical harness to the windshield washer reservoir.
  6. Disconnect the electrical harness from the windshield washer pump connector and level sensor connector.
  7. Remove the LH front wheel. See Wheel Assembly (Remove and Install).
  8. Partially remove LH front wheel liner.
    Note
    6x clips, and 1x bolt, newer vehicles may be equipped with 2x push clips securing lower portion of liner to body.
  9. Remove the lower bolt that attaches the windshield washer reservoir to the body.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  10. Lower the vehicle until the tires just touch the ground.
  11. Remove the upper bolt that attaches the windshield washer reservoir to the body.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  12. Remove the windshield washer reservoir from the vehicle.

Install

  1. Install the windshield washer reservoir into the vehicle, and then install the upper bolt that attaches the windshield washer reservoir to the body.
    3 Nm (2.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  2. Raise the vehicle to a working height, and then install the lower bolt that attaches the windshield washer reservoir to the body.
    3 Nm (2.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  3. Install LH front wheel liner to vehicle.
    5 Nm (3.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  4. Install the LH front wheel. See Wheel Assembly (Remove and Install).
  5. Fill the windshield washer reservoir with fluid.
  6. Connect the electrical harness to the windshield washer pump connector and level sensor connector.
  7. Fasten the clip that attaches the electrical harness to the windshield washer reservoir.
  8. LHD models only: Install the wiper motor. See Wiper Module (Remove and Replace).
  9. Install the cowl screen panel. See Panel - Cowl Screen (Remove and Replace).
  10. Install the LH and RH wiper arms. See Wiper Arms (Remove and Replace).
  11. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  12. Verify operation of the windshield wipers and washer.
