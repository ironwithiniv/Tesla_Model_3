Remove (For Vehicles with 16V Batteries)

  1. Open the LH front door and lower all the windows.
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Remove the clips that attach the cabin intake upper duct assembly to the vehicle, and then remove the intake duct from the vehicle.
    Note
    Older vehicles may be equipped with 4 clips.
  4. Remove the 12V/LV battery. See 12V/LV Battery (Remove and Replace).
  5. Release the cowl screen from the support bracket.
  6. Release the cowl screen using the inflatable air bag.
  7. Remove the bolt that attaches the ground cable to the front controller.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  8. Disconnect the thermal sub-harness from the front body controller module.
    Note
    Press the locking tab, and then rotate to release.
  9. Remove the bolts (x2) that attach the front body controller module shield assembly to the front body controller, and then remove the shield assembly from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  10. Disconnect the front body controller harness connectors (x5), and then release the harness guide.
  11. Remove the bolts (x3) that attach the front body controller module to the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  12. Tilt the front body controller module forward for access to the ground cable, then remove the edge clip.
  13. Release the harness guide, and then remove the front body controller module from the vehicle.

Install (For Vehicles with 16V Batteries)

  1. Position the front body controller module into the vehicle for installation.
  2. Secure the edge clip to install the ground cable to the backside of front controller.
  3. Install the harness guide, and then tilt the front controller backward for installation.
  4. Install the bolts (x3) that attach the front body controller module to the vehicle.
    10 Nm (7.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  5. Secure the harness guide, and then connect the front body controller module harness connectors (x4).
  6. With the X010 connector disconnected, move the gray locking lever fully into the unlocked position, use the black connector body to fully seat the X010 connector into the front body controller module, and then secure the locking lever.
    CAUTION
    Do not try to seat the connector with the locking lever closed.
    Tip
    Apply alternating firm pressure on the top and bottom of the black connector housing to fully seat the connector before securing the connector lock.
    Note
    The locking lever should easily click into position when the connector is properly seated.
  7. Install the bolts (x2) that attach the front body controller module shield assembly to the front body controller.
    8.5 Nm (6.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  8. Connect the thermal sub-harness to the front body controller module.
    Note
    Press the locking tab, and then rotate to release.
  9. Remove the inflatable air bag.
    Note
    Deflate the inflatable air bag prior removal.
  10. Secure the push clips (x2) to install the cowl screen assembly.
  11. Install the bolt that attaches the ground cable to the front controller.
    8.5 Nm (6.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  12. Install the 12V/LV battery. See 12V/LV Battery (Remove and Replace).
    Note
    Connect a LV maintainer after installing the LV battery cable stand off.
  13. Reinstall the vehicle software. See Software Reinstall - Toolbox
  14. Remove the LV battery maintainer.
  15. Finish the remaining steps of installing the 12V/LV battery. See 12V/LV Battery (Remove and Replace).
    Note
    No need to reinstall the firmware again.
  16. Position the cabin intake upper duct assembly into the vehicle, and then install the clips that attach the intake duct to the vehicle.
    Note
    Older vehicles may be equipped with 4 clips.
  17. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  18. Place the vehicle in Service Mode Plus.
    1. Enter the last six digits of VIN into the Vehicle Ops mobile app.
    2. Select vehicle from the list.
    3. Swipe to the left, and then select Enable Service Mode Plus.
  19. Tap Vehicle Configurations > coolantPumpType to inspect the current coolant pump configuration. If the configuration is not DUAL_MIX, change it to DUAL_MIX.
  20. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): PROC_VCFRONT_X_POST-REPLACEMENT-PROCEDUREvia Service Mode Plus:low-voltage ➜ Front Controller Post-Replacement ➜ Front Controller Post-Replacement Procedurevia Toolbox:(link)
  21. Perform the headlights adjust procedure. See:
    • Headlights - Adjust - NA (Wall Method)
    • Headlights - Adjust - NA (Tool Method)
    • Headlights - Adjust - EMEA (Wall Method)
    • Headlights - Adjust - EMEA (Tool Method)
  22. Raise all the windows and close the LH front door.

Remove (For Vehicles with 12V Batteries)

  1. Open the LH front door and lower all the windows.
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Remove the clips that attach the cabin intake upper duct assembly to the vehicle, and then remove the intake duct from the vehicle.
    Note
    Older vehicles may be equipped with 4 clips.
  4. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  5. Remove the LH and RH wiper arms. See Wiper Arms (Remove and Replace).
  6. Remove the LH and RH shock tower covers. See Cover - Shock Tower - LH (Remove and Replace).
  7. Remove the cowl screen panel. See Panel - Cowl Screen (Remove and Replace).
  8. Disconnect 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  9. Remove the 12V/LV battery. See 12V/LV Battery (Remove and Replace).
  10. Remove the battery tie down strap. See Strap - 12V Battery (Remove and Replace).
  11. Remove the edge clip from the front body controller module.
  12. Disconnect the thermal sub-harness from the front body controller module.
    Note
    Press the locking tab, and then rotate to release.
  13. Remove bolts (x2) that attach the front body controller module shield assembly to the front body controller, and then remove the shield assembly from the vehicle.
    8.5 Nm (6.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  14. Disconnect the front body controller harness connectors (x5), and then release the harness guide.
  15. Remove the bolts (x3) that attach the front body controller module to the vehicle.
    10 Nm (7.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  16. Tilt the front body controller module forward for access to the ground cable, and then remove the tab, edge clip, and bolt that attaches the ground cable to the module.
    8.5 Nm (6.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  17. Remove the 12V negative harness clip from the front body controller module.
  18. Release the harness guide, and then remove the front body controller module from the vehicle.
    Note
    1x tab

Install (For Vehicles with 12V Batteries)

  1. Position the front body controller module into the vehicle for installation.
  2. Install the 12V negative harness clip to the front body controller module.
  3. Position the ground cable onto the front body controller module, and then install the tab, edge clip, and bolt that attaches the ground cable to the module.
    8.5 Nm (6.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  4. Install the bolts (x3) that attach the front body controller module to the vehicle.
    10 Nm (7.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  5. Secure the harness guide, and then connect the front body controller module harness connectors (x4).
  6. With the X010 connector disconnected, move the gray locking lever fully into the unlocked position, use the black connector body to fully seat the X010 connector into the front body controller module, and then secure the locking lever.
    CAUTION
    Do not try to seat the connector with the locking lever closed.
    Tip
    Apply alternating firm pressure on the top and bottom of the black connector housing to fully seat the connector before securing the connector lock.
    Note
    The locking lever should easily click into position when the connector is properly seated.
  7. Position the front body controller module shield assembly to the front body controller, and then install the bolts (x2) that attach the shield assembly to the vehicle.
    8.5 Nm (6.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  8. Connect the thermal sub-harness to the front body controller module.
    Note
    Press the locking tab, and then rotate to release.
  9. Install the edge clip to the front body controller module.
  10. Install the battery tie down strap. See Strap - 12V Battery (Remove and Replace).
  11. Install the 12V/LV battery. See 12V/LV Battery (Remove and Replace).
  12. Connect 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  13. Reinstall the vehicle software. See Software Reinstall - Toolbox
  14. Install the cowl screen panel. See Panel - Cowl Screen (Remove and Replace).
  15. Install the LH and RH shock tower covers. See Cover - Shock Tower - LH (Remove and Replace).
  16. Install the LH and RH wiper arms. See Wiper Arms (Remove and Replace).
  17. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  18. Position the cabin intake upper duct assembly into the vehicle, and then install the clips that attach the intake duct to the vehicle.
    Note
    Older vehicles may be equipped with 4 clips.
  19. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  20. Place the vehicle in Service Mode Plus.
    1. Enter the last six digits of VIN into the Vehicle Ops mobile app.
    2. Select vehicle from the list.
    3. Swipe to the left, and then select Enable Service Mode Plus.
  21. Tap Vehicle Configurations > coolantPumpType to inspect the current coolant pump configuration. If the configuration is not DUAL_MIX, change it to DUAL_MIX.
  22. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): PROC_VCFRONT_X_POST-REPLACEMENT-PROCEDUREvia Service Mode Plus:low-voltage ➜ Front Controller Post-Replacement ➜ Front Controller Post-Replacement Procedurevia Toolbox:(link)
  23. Perform the headlights adjust procedure. See:
    • Headlights - Adjust - NA (Wall Method)
    • Headlights - Adjust - NA (Tool Method)
    • Headlights - Adjust - EMEA (Wall Method)
    • Headlights - Adjust - EMEA (Tool Method)
  24. Raise all the windows and close the LH front door.
