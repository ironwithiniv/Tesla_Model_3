Rail - 2nd Row - Inner - LH (Remove and Replace)

Correction code 13052202 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1305 - 2nd Row Seat Assemblies and Hardware

Remove

  1. Remove the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  2. Remove the 2nd row buckle assembly:
    • LH: See Buckle - 2nd Row - LH (Remove and Replace).
    • RH and center: See Buckle - 2nd Row - Center (Remove and Replace).
  3. Remove the bolts that attach the LH inner 2nd row rail to the ancillary bay cover and the body, and then remove the rail from the vehicle.

Install

  1. Hand-tighten the exposed adjustable elements on the ancillary bay cover counter-clockwise so that they are fully engaged.
    CAUTION
    Hand-tighten only.
  2. Install the LH inner 2nd row rail to the body, and then install the bolts that attach the rail to the ancillary bay cover and the body.
    24 Nm (17.7 lbs-ft)
    24 Nm (17.7 lbs-ft)
  3. If installing the LH inner 2nd row rail, follow these additional steps to install the LH 2nd row seat buckle.
    Note
    This video shows how to properly stack the 2nd row LH seat buckle onto the 2nd row center seat belt anchor:
    1. Set the 2nd row center seat belt anchor onto the 2nd row LH inner ancillary bay rail, with the belt to the RH side.
    2. Make sure that the belt is not twisted, and lays flat against the 2nd row seatback.
    3. Set the guide pin of the 2nd row LH seat buckle bracket into the hole of the 2nd row LH inner ancillary bay rail, and pivot the bracket down onto the anchor, aligning the guide pin to the slot in the anchor.
    4. Install a new bolt to attach the seat buckle bracket, the seat belt anchor, and the inner ancillary bay rail to the body.
      40 Nm (29.5 lbs-ft)
    5. Verify the stacking.
      Callout Description
      1 LH 2nd Row Buckle on Top
      2 Center 2nd Row Seatbelt Anchor in the Middle
      3 LH Inner Ancillary Bay Rail at the Bottom
    6. Install the plastic bracket that attaches the female side of the electrical connector to the body studs.
    7. Connect the electrical harness to the LH rear seat belt buckle connector.
  4. If installing the RH inner 2nd row rail, install the center 2nd row buckle assembly. See Buckle - 2nd Row - Center (Remove and Replace).
  5. Install the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
