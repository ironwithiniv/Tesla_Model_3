IP Carrier (LHD) (Remove and Replace)

Correction code 14052102 2.16 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2024-07-30: Added information about how to handle the replacement between different versions of IP carrier.

Reuse
Parent topic: 1405 - Instrument Panel

Remove

  1. Remove the instrument panel carrier. See IP Carrier (Remove and Install).
  2. Remove the front passenger air bag. See Airbag - Front Passenger (Remove and Install).
  3. Remove the bolts (x2) that attach the LH and RH window defroster ducts to the instrument panel carrier, and remove the ducts.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
    • 2 in extension
    • Ratchet/torque wrench
  4. Remove the LH and RH defrost covers. See GUID-45447BB4-B5CB-45D8-8793-0DB5A4E4435B.html.
    Note
    4 tabs for the LH side and 5 tabs for the RH side.

Install

  1. Model 3 built before August 22, 2017 only: Refer to Toolbox Article 39237 to determine if felt tape should be applied to prevent NVH issues with the top pad.
  2. If the new instrument panel carrier does not have tweeter holes, the tweeter connectors must be taped back to the harness before the replacement instrument panel carrier is installed.
    CAUTION
    Do NOT cut holes into the new instrument panel carrier as an attempt to retrofit the tweeters.
    CAUTION
    Failure to tape back the existing tweeter connector may result in NVH issues.
    Note
    Use black tape. The yellow tape used in the picture is for demonstration purpose only.
  3. If the new instrument panel carrier has tweeter holes while the replaced one does not, the tweeter hole must be covered before the replacement instrument panel carrier is installed.
    Note
    Cut a piece of butyl to cover the hole. Make sure the butyl does not cover the IP clips or interfere with the speaker perimeter.
  4. Install the LH and RH defrost covers. See GUID-45447BB4-B5CB-45D8-8793-0DB5A4E4435B.html.
    Note
    4 tabs for the LH side and 5 tabs for the RH side.
  5. Install the bolts (x2) that attach the LH and RH window defroster ducts to the instrument panel carrier.
    2.3 Nm (1.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
    • 2 in extension
    • Ratchet/torque wrench
  6. Install the front passenger air bag. See Airbag - Front Passenger (Remove and Install).
  7. Install the instrument panel carrier. See IP Carrier (Remove and Install).
