Warning

Only technicians who have completed all required certification courses are permitted to perform this procedure. Tesla recommends third party service provider technicians undergo equivalent training before performing this procedure. For more information on Tesla Technician requirements, or descriptions of the subject matter for third parties, see HV Certification Requirements. Proper personal protective equipment (PPE) and insulating HV gloves with a minimum rating of class 0 (1000V) must be worn at all times a high voltage cable, busbar, or fitting is handled. Refer to Tech Note TN-15-92-003, High Voltage Awareness Care Points for additional safety information.

CAUTION
Model 3 thermal management components operate under very tight specifications and can malfunction if Service procedures are not carefully followed. DO NOT rely on past experience with other thermal management systems; read through the Service Manual and do not deviate from the instructions.
Note
This procedure requires the A/C Refrigerant (Recovery and Recharge) procedure to be performed. If not already automatically added to the Service Visit, add correction code 18200102 as a separate correction within the same activity to the Service Visit.

Remove

  1. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  2. Place the vehicle in Service Mode by using the touchscreen. See Service Mode.
  3. Unlock the vehicle gateway. See Gateway (Unlock).
  4. On the touchscreen, touch the Service Mode "wrench" icon, and then touch Thermal > Refrigerant System > Start Thermal Fill Drain (Refrigerant only) > Run, and allow the routine to complete.
  5. Perform Vehicle HV Disablement Procedure. See Vehicle HV Disablement Procedure.
  6. Recover the A/C refrigerant. See A/C Refrigerant (Recovery and Recharge).
    Note
    Recover the refrigerant while continuing this procedure.
  7. Remove the LV battery. See 12V/LV Battery (Remove and Replace).
  8. After refrigerant recovery is complete, carefully depress the Schrader valves (x2) to level out any pressure difference between the A/C system pressure and the actual ambient atmospheric pressure.
  9. Remove the desiccant, see Desiccant (Heat Pump) (Remove and Replace)
  10. Install a new cap into the accumulator, and then install a new snap ring into the accumulator.
  11. Remove the nut that attaches the low pressure fitting to the A/C compressor.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm deep socket
  12. Remove the nut that attaches the high pressure fitting to the A/C compressor, and then set the hose assembly aside.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm deep socket
  13. Install A/C flush adapters onto the A/C manifold to compressor line.
  14. Connect A/C machine hoses to A/C flush adapters.
  15. On the A/C machine touchscreen, select Menu > Flushing Kit, and enter 25 mins vacuum time. and then follow the machine guide to start the flush, and then allow the process to complete.
    Note
    system flush procedure runs for approximately 90 minutes.
  16. Remove the compressor bracket. See Bracket - Compressor (Heat Pump) (Remove and Replace).
  17. Note the part numbers and serial numbers of the old and new A/C compressors.

Install

CAUTION
The new A/C compressor is pre-filled with oil. DO NOT add any additional oil to the new A/C compressor.
  1. Install the NVH acoustic cover onto the new compressor.
  2. Install the new compressor with compressor bracket to the vehicle. See Bracket - Compressor (Heat Pump) (Remove and Replace).
  3. Replace the O-rings on the high pressure and low pressure supermanifold to A/C compressor hose fittings.
    Note
    O-ring for high pressure line: 1111737-00-A WASHER, 3/8,STL ZN, SEAL.
    Note
    O-ring for low pressure line: 1111740-00-A WASHER, 3/4,STL ZN, SEAL.
    Note
    Lubricate O-rings with ND-11 oil prior to installation.
  4. Remove the transport plugs from the new compressor.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  5. Position the supermanifold to A/C compressor high pressure fitting on the A/C compressor, and then install the nut that attaches the fitting to the A/C compressor.
    22 Nm (16.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm deep socket
  6. Position the supermanifold to A/C compressor low pressure fitting on the A/C compressor, and then install the nut that attaches the fitting to the A/C compressor.
    22 Nm (16.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm deep socket
  7. Install a new desiccant. See Desiccant (Heat Pump) (Remove and Replace).
  8. Perform an A/C vacuum leak test and recharge the refrigerant. See A/C Refrigerant (Recovery and Recharge).
  9. Install the LV battery. See 12V/LV Battery (Remove and Replace).
  10. Reconnect LV power. See 12V/LV Power (Disconnect and Connect).
  11. Connect a LV maintainer. See LV Maintainer (Connect and Disconnect).
  12. Enable Service Mode Plus. See Service Mode Plus.
  13. On the touchscreen, touch Controls > Thermal > Thermal Configurations > compressorType, and select and save the correct type.
    Note
    Refer to Toolbox article 5696900 for details on compressor configuration.
    Note
    Check the compressorType and make sure it shows as intended.
  14. Configure the compressor type: on the touchscreen, touch Thermal > Actions > Thermal Configurations, and then select the correct compressor type from the drop down list. Touch Run, and close once the routine has passed.
  15. Reinstall the software. See Software Reinstall - Touchscreen.
  16. Disconnect the LV maintainer. See LV Maintainer (Connect and Disconnect).
  17. On the touchscreen, touch Thermal > Refrigerant System > Reset Compressor P-Metric > Run, and close once the routine has passed.
  18. Perform the routine using Toolbox or Service Mode: TEST-SELF_VCFRONT_X_HEAT-PUMP-COMMISSIONINGvia Service Mode:Thermal ➜ Refrigerant System ➜ Commission Heat Pumpvia Service Mode Plus:Drive Inverter ➜ Front Drive Inverter Replacement ➜ Heatpump commissioningvia Toolbox:(link)
  19. Tap Thermal > Actions > Test Thermal Performance > Run, and close once the routine has passed.
  20. Tap Thermal > Actions > Test HVAC Performance > Run, and close once the routine has passed.
  21. Exit Service Mode. See Service Mode.
  22. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  23. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  24. Install the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
