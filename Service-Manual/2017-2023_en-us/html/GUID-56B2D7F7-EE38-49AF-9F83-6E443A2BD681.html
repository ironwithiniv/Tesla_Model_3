Speaker - Pedestrian Warning (Remove and Replace)

Correction code 17541002 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2023-09-12: Optimized the procedure to improve efficiency.
Parent topic: 1754 - Pedestrian Warning Speaker

Remove

  1. Remove the RH front wheel. See Wheel Assembly (Remove and Install).
  2. Remove the clips (x9) that hold the RH front wheel liner to fascia, and move the wheel liner aside for access.
  3. Remove the clip that attaches the harness to the pedestrian warning speaker assembly.
  4. Release the locking tab by sliding it away from the connector, then depress the grey locking tab to release the pedestrian warning speaker connector.
    Note
    The connector access may vary depending on the version of the super horn audio speaker installed on the vehicle. You may need to use a pocket screwdriver or a miniature pick to release the red locking tab, which is covered by an anti-tampering feature.
  5. Remove the screws (x3) that attach the pedestrian warning speaker assembly to the front fascia, and then remove the pedestrian warning speaker from the fascia.
    1.8 Nm (1.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Flex head ratchet/flex head torque wrench
    • 2 in extension
    • Torx T25 socket
    • Ratchet/torque wrench

Install

  1. Install the screws (x3) that attach the pedestrian warning speaker assembly to the front fascia.
    1.8 Nm (1.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 2 in extension
    • Torx T25 socket
    • Ratchet/torque wrench
  2. Engage the locking tab to connect the pedestrian warning speaker connector.
  3. Install the clip that attaches the harness to the pedestrian warning speaker assembly.
  4. Install the clips (x9) that hold the RH front wheel liner to fascia.
  5. Install the RH front wheel. See Wheel Assembly (Remove and Install).
