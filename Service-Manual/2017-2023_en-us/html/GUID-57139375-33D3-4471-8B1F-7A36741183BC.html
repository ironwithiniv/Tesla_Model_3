Beam - 12V Battery (RWD) (Remove and Replace)

Correction code 17012702 0.72 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1701 - 12V Battery and Fuses

Remove

  1. Remove the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Remove the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  4. Remove the hood latch cover. See Cover - Hood Latch (Remove and Replace).
  5. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  6. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  7. Remove the 12V auxiliary battery. See 12V/LV Battery (Remove and Replace).
  8. Remove the 12V battery bracket. See Bracket - 12V Battery (RWD) (Remove and Replace).
  9. Release the clips that attach the coolant hoses and electrical harnesses to the 12V battery bracket beam.
  10. Remove the bolts that attach the front controller to the 12V battery bracket beam.
  11. Remove the bolts that attach the 12V battery bracket beam to the body.
  12. Remove the 12V battery bracket beam from the vehicle.
    Note
    Maneuver the 12V battery bracket beam to ease removal from the vehicle.

Install

  1. Install the 12V battery bracket beam on the vehicle.
    CAUTION
    Keep the 12V battery ground terminal away to avoid catching between the beam and the bracket.
  2. Install the bolts that attach the 12V battery bracket beam to the body.
    9 Nm (6.6 lbs-ft)
  3. Install the bolts that attach the front controller to the 12V battery bracket beam.
    10 Nm (7.4 lbs-ft)
  4. Install the clips that attach the coolant hoses and electrical harnesses to the 12V battery bracket beam.
  5. Install the 12V battery bracket. See Bracket - 12V Battery (RWD) (Remove and Replace).
  6. Install the 12V auxiliary battery. See 12V/LV Battery (Remove and Replace).
  7. Reconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  8. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  9. Install the hood latch cover. See Cover - Hood Latch (Remove and Replace).
  10. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  11. Install the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
