ABS Modulator (Non-Heat Pump) (Remove and Replace)

Correction code 33100102 2.52 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-04-29: Corrected torque figures for the bolts that attach the shock tower brace to the vehicle.
  • 2023-12-05: Updated brake stiffness routine.
  • 2023-06-15: Added a video at Step 8 in install part to illustrate how to install the master cylinder brake lines.
Parent topic: 3310 - ABS Traction and Stability Control

Remove

  1. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  2. Remove the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  3. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  4. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  5. Remove all wheels. See Wheel Assembly (Remove and Install).
  6. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  7. Lower the vehicle.
  8. Remove the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  9. Remove the hood latch cover. See Cover - Hood Latch (Remove and Replace).
  10. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  11. Remove the 12V auxiliary battery. See 12V/LV Battery (Remove and Replace).
  12. Remove the 12 battery bracket. See Bracket - 12V Battery (RWD) (Remove and Replace).
  13. Remove the bolts that attach G098 and G099 to the body.
  14. Release the white clip that attaches the main front harness to the body.
  15. Release the black clip that attaches the main front harness to the body.
  16. Disconnect the electrical connector from the ABS modulator.
  17. Release the clips that attach the main front harness near the LH frame rail.
  18. Place the oil drain under the ABS modulator.
  19. Remove the RH front brake line pipe nut from the ABS modulator.
  20. Remove the LH rear brake line pipe nut from the ABS modulator.
  21. Remove the RH rear brake line pipe nut from the ABS modulator.
  22. Remove the LH front brake line pipe nut from the modulator.
  23. Remove the master cylinder secondary pipe nut from the ABS modulator.
  24. Remove the master cylinder primary pipe nut from the ABS modulator.
  25. Release the clip that attaches the master cylinder brake lines to the 4 tube bundle.
  26. Release the clip that attaches the chiller-to-battery coolant hose to the bracket, and move the hose aside.
  27. Remove the bolts that attach the ABS modulator to the frame rail.
  28. Release the tabs (x2) that attach the ABS modulator to the body, slide the ABS modulator towards the 12V battery area, and then remove the ABS modulator from the vehicle.
  29. Loosen the nut that attach the ABS modulator to the bracket, and then pry the ABS modulator from the bracket.

Install

  1. Install the ABS modulator into the bracket.
  2. Tighten the nuts (x2) that attach the ABS modulator to the bracket.
    8 Nm (5.9 lbs-ft)
  3. Remove the tapes that cover the orifices of the new ABS modulator
  4. Position the ABS modulator into the vehicle for installation. Align the bracket into the body, and then attach the tabs (x2).
  5. Move the ABS modulator into position within the vehicle for installation.
  6. Install the bolts that attach the ABS modulator to the LH frame rail.
    10 Nm (7.4 lbs-ft)
  7. Fasten the clip that attaches the master cylinder brake lines to the bracket.
  8. Install the master cylinder brake lines to the 4 tube bundle clip.
  9. Install the master cylinder primary pipe nut to the ABS modulator.
    16 Nm (11.8 lbs-ft)
  10. Install the master cylinder secondary pipe nut to the ABS modulator.
    16 Nm (11.8 lbs-ft)
  11. Install the LH front brake pipe nut to the ABS modulator.
    16 Nm (11.8 lbs-ft)
  12. Install the RH rear brake pipe nut to the ABS modulator.
    16 Nm (11.8 lbs-ft)
  13. Install the LH rear brake pipe nut to the ABS modulator.
    16 Nm (11.8 lbs-ft)
  14. Install the RH front brake pipe nut to the ABS modulator.
    16 Nm (11.8 lbs-ft)
  15. Remove the oil pan from underneath the vehicle.
  16. Install the clips that attach the main front harness to the LH frame rail area.
  17. Connect the electrical connector to the ABS modulator.
  18. Install the black and white clips (x2) that attach the main front harness to the body.
  19. Install the bolts that attach G098 and G099 to the body.
    10 Nm (7.4 lbs-ft)
  20. Install the 12 battery bracket. See Bracket - 12V Battery (RWD) (Remove and Replace).
  21. Install the 12V auxiliary battery, but do not connect the negative battery terminal at this time. See 12V/LV Battery (Remove and Replace).
  22. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  23. Install the hood latch cover. See Cover - Hood Latch (Remove and Replace).
  24. Install the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  25. Reconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  26. Install the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  27. Redeploy the vehicle firmware. See Software Reinstall - Toolbox.
  28. Bleed the entire brake system. See Brake Fluid Bleed/Flush.
  29. Using Toolbox 3:
    1. Select the Actions tab and search for "Stiffness".
    2. Select the ODIN routine TEST_BRAKE_X_STIFFNESS-TEST-SERVICEvia Service Mode:Chassis ➜ Brakes ➜ Brake Stiffness Testvia Service Mode Plus:chassis ➜ ESP Replacement Panel ➜ Stiffness Testvia Toolbox:(link), and then click the link of the routine.
    3. If brake pads or rotors have been replaced, select UNBURNISHED under "Action_Type". In all other cases, select BURNISHED.
    4. Click RUN, and allow the routine to complete.
      Note
      Do not press the brake pedal during the test.
  30. Install the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  31. Install all wheels. See Wheel Assembly (Remove and Install).
  32. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  33. Remove the vehicle from the lift.
  34. Perform a road test to make sure that brake pedal feel and brake performance are as expected.
