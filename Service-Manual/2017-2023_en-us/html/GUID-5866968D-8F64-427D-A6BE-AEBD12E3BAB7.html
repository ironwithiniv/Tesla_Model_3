Reuse

Remove

  1. Open all doors and lower all windows.
    Note
    Latch the rear doors with the doors open using a small flat blade screwdriver to prevent an accidental lockout.
  2. Move the driver seat and front passenger seat fully rearward and to the lowest position.
  3. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  4. Open the center console armrest fully.
  5. Remove the LH and RH center console decor trims. See Decor Trim - Center Console - LH (Remove and Replace).
  6. Remove the screws and release the tabs that attach the LH bright strip to the center console, and then remove the strip from the console. Repeat this step to remove the RH bright strip.
  7. Release the clips (x6) that attach the cup holder decor panel to the cup holder assembly, and then separate the cup holder decor panel from the center console assembly.
  8. Disconnect the electrical connector from the security body controller module, and then remove the cup holder decor panel from the vehicle.
  9. Remove the screws (x2) that attach the security body controller module to the cup holder decor panel, and then remove the security body controller module from the panel.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
    • Wiha TorqueVario-S 0.80Nm - 2.0Nm

Install

  1. Install the screws (x2) that attach the security body controller module to the cup holder decor panel.
    1.6 Nm (1.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
    • Wiha TorqueVario-S 0.80Nm - 2.0Nm
  2. Connect the electrical connector to the security body controller module.
  3. Attach the clips (x6) that attach the cup holder decor panel to the center console assembly.
  4. Install the RH bright strips: Start with the corner nearest to the IP carrier, and then continue towards the rear. Repeat this step on the LH bright strip.
  5. Install the screws (x7) that attach the RH bright strip to the center console assembly. Repeat this step on the LH bright strip.
    1.6 Nm (1.2 lbs-ft)
  6. Install the RH center console decor trim, and then repeat this step on the LH center console decor trim. See Decor Trim - Center Console - LH (Remove and Replace).
  7. Close the center console armrest.
  8. Reconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  9. Restore the driver seat and front passenger seat back to their original position.
  10. Reinstall the vehicle firmware. See Software Reinstall - Touchscreen.
  11. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): PROC_VCSEC_X_POST-REPLACEMENT-PROCEDUREvia Service Mode:Low Voltage ➜ Keys ➜ VCSEC Post Replacementvia Service Mode Plus:low-voltage ➜ VCSEC Post Replacement ➜ VCSEC Post Replacement Procedurevia Toolbox:(link)
  12. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): PROC_VCSEC_C_PAIR-NFC-CARD-V2via Service Mode:Low Voltage ➜ Keys ➜ Pair Keyvia Toolbox:(link)
  13. Place the NFC card(s) on the NFC card reader in the center console, and check the function of the programmed NFC keys.
  14. Exit Service Mode. See Service Mode.
  15. Raise all windows and close all doors.
  16. Inform the customer that the new security body controller will not recognize any previously paired phone key. The customer must delete and re-pair their phone key to the vehicle, if they were previously using this feature. Instructions are available in the Owners Manual, and at the DIY web pages.
