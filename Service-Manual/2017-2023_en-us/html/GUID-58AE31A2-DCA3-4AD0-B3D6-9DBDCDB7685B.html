Link - Stabilizer Bar - Front - LH (Remove and Replace)

Correction code 31012002 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

CAUTION
If performing this procedure as a result of a collision, see the Collision Repair Manual to verify whether the steering gear must be replaced as well.
Parent topic: 3101 - Front Suspension (Including Hubs)

Remove

  1. Remove the LH front wheel. See Wheel Assembly (Remove and Install).
  2. Remove and discard the nuts that attach the front LH stabilizer bar link to the stabilizer bar and damper, and then remove the link from the vehicle.
    98 Nm (72.3 lbs-ft)

Install

Installation procedure is the reverse of removal, except for the following:

Replace all nyloc nuts.
