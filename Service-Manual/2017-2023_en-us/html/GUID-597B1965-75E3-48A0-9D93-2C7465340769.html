Bracket - Rear Wing - LH (Remove and Replace)

Correction code 10016102 0.66 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Note
When replacing the LH and RH Rear Wing Brackets at the same time, use correction code 10016302 - Bracket - Rear Wing - Pair (Remove & Replace).
Parent topic: 1001 - Bumper / Fascia

Remove

  1. Remove the rear fascia. See Fascia - Rear (Remove and Install).
  2. Remove the LH taillight bracket. See Bracket - Taillight - LH (Remove and Replace).
  3. Remove the bolts that attach the LH rear wing bracket to the vehicle.
    3.5 Nm (2.6 lbs-ft)

Install

Installation procedure is the reverse of removal.
