Harness - Main Front - Active Hood (Remove and Replace)

Correction code 171034023.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
Parent topic: 1710 - Harnesses

Remove

  1. Open the front LH and front RH doors.
  2. Open the hood.
  3. Place wheel chocks on both rear wheels.
  4. Put vehicle in Neutral.
  5. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  6. Disconnect first responder loop.
  7. Remove the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  8. Release the clips that attach the footrest.
  9. Remove the RH knee airbag. See Airbag - Knee - Driver (Remove and Replace).
  10. Remove the main instrument panel decor. See Decor Trim - Instrument Panel - Main (Remove and Replace).
  11. Remove the glove box. See Glove Box - With Knee Airbags (Non-Heat Pump) (Remove and Replace).
  12. Remove the RH footwell duct. See Duct - Footwell - RH (LHD) (Remove and Replace).
  13. Remove the RH air wave duct. See Duct - Air Wave - RH (LHD) (Remove and Replace).
  14. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  15. Remove the 12V auxiliary battery. See12V/LV Battery (Remove and Replace).
  16. Remove the nut that attaches the 12V battery rear hook tie down.
  17. Remove the wiper motor assembly. See Wiper Module (Remove and Replace).
  18. Remove the bolt that attaches the thermal harness cover to the front body controller module, and then remove the cover from the module.
  19. Disconnect the thermal harness from the front body controller module connector.
  20. Remove the bolts that attach the front body controller module cover to the front body controller module, and then remove the cover.
  21. Disconnect the main front harness from the front body controller module connectors.
  22. Remove the ground bolt from 12V negative terminal.
  23. Remove 12v negative harness clip from front controller.
  24. Remove upper ground strap from the vehicle body.
  25. Remove the bolts that attach the front body controller module to the body.
  26. Remove bolts securing front controller.
  27. Release harness guide and remove the front controller from vehicle.
  28. Remove fresh air intake assembly.
    Note
    2x studs, Remove from bulkhead studs.
  29. Remove and discard nuts securing car computer to the bulkhead.
    Note
    4x nyloc nuts, 13mm, 7.1 Nm.
  30. Remove power cable from right body controller.
    Note
    1x connector, release locking tab.
  31. Disconnect 12V connector from vehicle.
    Note
    1x connector.
  32. Release the clip that attaches the inline electrical harness connector to the RH body controller module, and then disconnect the electrical connector.
    Note
    1x connector, 1x clip.
  33. Disconnect frunk connector from right controller.
    Note
    1x connector, J8.
  34. Slide car computer inward to allow access to connectors and harness clips.
    Note
    Be careful not to strain harness and connectors.
  35. Remove the front harness clips from car computer.
    Note
    2x clips.
  36. Disconnect the LH front harness connector from car computer.
    Note
    1x connector.
  37. Disconnect the RH front harness connectors from car computer.
    Note
    5x connectors.
  38. Push the RH side of the front harness through the bulkhead.
    Note
    4x clips.
  39. Disconnect harness connector for windshield heater from underhood area.
    Note
    1x connector.
  40. Secure the windshield harness out of the way to avoid damage.
    Note
    Secure using tape.
  41. Remove the front end harness windshield connector from the body.
    Note
    1x clip.
  42. Release clips securing harness behind RH shock tower.
    Note
    2x clips.
  43. Remove front harness clip from washer tank.
    Note
    1x clip.
  44. Disconnect front harness connectors from brake booster area.
    Note
    2x connectors, Brake fluid level sensor, Brake booster.
  45. Disconnect brake booster lower connector.
    Note
    1x connector.
  46. Disconnect the hydraulic control unit connector.
    Note
    1x connector, Disengage locking tab and pull up on connector to release.
  47. Remove front harness clips around LH front frame rail area.
    Note
    5x clips.
  48. Remove the front harness ground terminals at LH front shock tower.
    Note
    4x bolts, 10mm, 8 Nm,Inspect bolts: if they are self tapping tri-lobular bolts (1128269-00-A) then discard, If they are normal bolts (1447438-00-A) they can be reused.
  49. Disconnect LH front headlamp connector.
    Note
    1x connector.
  50. Disconnect the steering gear assembly connectors.
    Note
    5x connectors, Two stage connectors, Do not push down on red tab, Pull red tab to disengage lock, Pull again to release connector.
  51. Remove AC compressor ground strap.
    Note
    1x bolt, T25, 7 Nm.
  52. Remove horse clips from steering gear harness bracket.
    Note
    1x clip.
  53. Remove steering gear harness bracke clip and remove from vehicle.
    Note
    2x clips.
  54. Disconnect the FDU logic connector at the LH frame rail.
    Note
    1x connector, 2 stage connector, Release the grey locking tab then press on the tab to release the connector.
  55. Disconnect RH headlamp connector.
    Note
    1x connector, Do not push down on Red tab, Pull red tab to disengage lock, Pull again to release connector.
  56. Remove the front harness ground terminals at RH front shock tower.
    Note
    1x bolt, 10mm, 8 Nm,1x connector,Inspect bolts: if they are self tapping tri-lobular bolts (1128269-00-A) then discard, If they are normal bolts (1447438-00-A) they can be reused.
  57. Remove the front harness clip around RH front frame rail area.
    Note
    3x clips.
  58. Remove the wheel chocks.
  59. With an assistant, move the vehicle to a lift.
    CAUTION
    The vehicle is safely pushed for only a very short distance and at a very slow speed.
  60. Remove the front LH and front RH wheels. See Wheel Assembly (Remove and Install).
  61. Remove the front LH and front RH arch liners. See Wheel Arch Liner - Front - LH (Remove and Replace).
  62. Remove lower bolt securing washer tank to vehicle.
    Note
    1x bolt, 10mm, 3 Nm.
  63. Loosen forward bolts securing LH corner of front fascia to fender.
    Note
    2x bolts, 10mm, 4 Nm.
  64. Remove bolt securing LH corner of fascia to fender.
    Note
    1x bolt, 10mm, 3 Nm.
  65. Disconnect the front harness connector for the LH front carrier harness.
    Note
    1x locking connector.
  66. Disconnect the front harness from the LH acceleration sensor.
    Note
    1x locking connector.
  67. Remove the front harness clips from the outer LH rail area.
    Note
    2x clips.
  68. Disconnect the front harness from CFM.
    Note
    1x connector.
  69. Disconnect the LH front wheel speed sensor and body height sensor.
    Note
    2x connectors.
  70. Remove the front harness clips around LH front wheel liner area.
    Note
    3x clips, North American region vehicles have 2x clips.
  71. Remove the front harness clip for the LH side repeater and camera harness.
    Note
    1x clip.
  72. Disconnect the front harness connectors for the LH side repeater and camera.
    Note
    2x connectors.
  73. Disconnect pyrotechnic actuator connector.
    Note
    1x locking connector, release the locking by sliding it away from the connector.
  74. Loosen forward bolts securing RH front corner of front fascia to fender.
    Note
    2x bolts, 10mm, 4 Nm.
  75. Remove bolt securing RH front corner of front fascia to fender.
    Note
    1x bolt, 10mm, 3 Nm.
  76. Disconnect 12V harness for front fascia.
    Note
    1x locking connector, Release the locking tab by sliding it away from the connector, Then depress the grey lock to release the connector.
  77. Remove the clip securing harness to pedestrian warning speaker assembly.
    Note
    1x clip.
  78. Disconnect pedestrian warning speaker.
    Note
    1x connector, Release the locking tab by sliding it away from the connector, then depress the grey locking tab to release.
  79. Remove front harness clip from the RH front fascia mounting bracket.
    Note
    1x clip.
  80. Disconnect front harness from front end module harness.
    Note
    1x locking connector.
  81. Disconnect the front harness from the RH acceleration sensor.
    Note
    1x locking connector.
  82. Remove the front harness clips from the outer RH rail area.
    Note
    2x clips.
  83. Disconnect the RH front wheel speed sensor.
    Note
    1x connector.
  84. Remove the front harness clips around front of RH front wheel liner for the wheel speed sensor.
    Note
    2x clips.
  85. Remove the front harness clip at the rear of RH front wheel liner area for the side repeater and camera harness.
    Note
    1x clip.
  86. Disconnect the front harness connectors for the RH side repeater and camera.
    Note
    2x connectors.
  87. Disconnect RH pyrotechnic actuator connector.
    Note
    1x locking connector, release the locking by sliding it away from the connector.
  88. Raise vehicle fully and lower lift onto locks.
    Note
    Set vehicle to comfortable working height, Make sure there's an audible click of the locks on both sides before lowering, otherwise vehicle may tilt to the side, Verify doors are clear of surrounding objects.
  89. Remove the front aero shield. See Panel - Aero Shield - Front (Remove and Replace)
  90. Remove push clips securing lower valance to front sway bar brackets.
    Note
    2x push clips, the number of clips on newer vehicles may vary.
  91. Remove LH harness bracket clip and remove from vehicle.
    Note
    2x clips.
  92. Lower the vehicle.
  93. Release front fascia, see Fascia - Front (Remove and Replace) .
  94. Disconnect the low and high tone horn connector.
    Note
    2x connectors.
  95. Disconnect LH front ped pro pressure tube sensor.
    Note
    1x connector, Do not push down on Red tab, Pull red tab to disengage lock, Pull again to release connector.
  96. Disconnect RH front ped pro pressure tube sensor.
    Note
    1x connector, Do not push down on Red tab, Pull red tab to disengage lock, Pull again to release connector.
  97. Remove upper bolt securing washer tank to vehicle.
    Note
    1x bolt, 10mm, 3 Nm.
  98. Disconnect washer pump and level sensor connectors.
    Note
    2x connectors.
  99. Remove washer tank from vehicle.
    Note
    2x connectors, keep washer tank upright to keep contents from spilling.
  100. Remove the front harness clips from the body under the washer tank area.
    Note
    4x clips.
  101. Remove thermal sub-harness clip from front harness bracke and moved to the side.
    Note
    1x clip.
  102. Remove AC Compressor harness clip from front harness bracket.
    Note
    1x clip.
  103. Remove bolt securing front harness bracket from vehicle.
    Note
    2x bolts,10mm,9 Nm.
  104. Route the LH side of the electrical harness from the wheel liner, through the underhood storage unit area, and to the front body controller module area.
  105. Route the RH side of the electrical harness from the wheel liner, through the underhood storage unit area, and to the front body controller module area.
  106. Remove the electrical harness from vehicle.

Install

  1. Position the front harness to vehicle for installation.
    Note
    Make sure to route RH branch underneath A/C compressor HV harness.
  2. Route the front harness around the brake booster area and push the LH side of the harness into driver side compartment.
    Note
    4x clips, make sure to install grommet in proper orientation.
  3. Route the front harness around the HVAC plenum duct area and push the RH side of the harness into passenger side compartment.
    Note
    4x clips, Route harness underneath A/C HV harness, Make sure to install grommet in proper orientation.
  4. Route the RH side of the front harness toward the RH side of the front fascia area.
    Note
    Make sure plastic housing is properly oriented with clips facing frame rail, Feed harness down behind fascia.
  5. Route the RH side of the front harness from frunk to RH wheel liner area.
  6. Route the LH side of the front harness toward the LH side front fascia area.
    Note
    Make sure plastic housing is properly oriented with clips facing frame rail, Feed harness down behind fascia.
  7. Route the LH side of the front harness from frunk to LH wheel liner area.
  8. Install front harness clips under the washer tank area.
    Note
    4x clips.
  9. Connect the hydraulic control unit connector.
    Note
    1x connector, Gently push connector downward, Engage locking tab.
  10. Connect brake booster lower connector.
    Note
    1x connector.
  11. Connect washer pump and level sensor connectors.
    Note
    2x connectors.
  12. Install washer tank into position.
  13. Install upper bolt securing washer tank to vehicle.
    Note
    1x bolt, 10mm, 3 Nm.
  14. Connect harness near brake booster area.
    Note
    2x connectors, engage locking tabs.
  15. Install front harness clips around LH front frame rail area.
    Note
    5x clips.
  16. Install the front harness ground terminals to LH front shock tower.
    Note
    4x bolts, 10mm, 8 Nm, install new bolt if original was a self tapping tri-lobular bolt, New bolt (1447438-00-A) can be reused.
  17. Connect the front harness connector to LH headlamp.
    Note
    1x connector.
  18. Connect the steering gear assembly connectors.
    Note
    5x connectors, Engage locking tabs.
  19. Install AC compressor ground strap.
    Note
    1x bolt, T25, 7 Nm.
  20. Connect the FDU logic connector at the LH frame rail.
    Note
    1x connector, Engage locking tab.
  21. Connect the front harness to RH headlamp.
    Note
    1x connector, engage locking tab.
  22. Install the front harness clip around RH front frame rail area.
    Note
    3x clips.
  23. Install the front harness ground terminals to RH front shock tower.
    Note
    2x bolts, 10mm, 8 Nm,install new bolt if original was a self tapping tri-lobular bolt, New bolt (1447438-00-A) can be reused.
  24. Secure harness clips behind RH shock tower.
    Note
    2x clips.
  25. Install the windshield harness heater connector to the body.
    Note
    1x clip.
  26. Removed the tape from the windshield heater harness and windshield.
  27. Connect the windshield heater harness.
    Note
    1x connector.
  28. Install harness guide and tilt backward for installation.
    Note
    1x tab.
  29. Install bolts securing front controller.
    Note
    3x bolts, 10mm, 10 Nm.
  30. Install front controller harness connectors.
    Note
    5x connectors, 1x harness guide.
  31. Install front controller upper ground strap to body.
    Note
    1x bolt, 10mm, 10 Nm.
  32. Install the ground bolt to 12V negative terminal.
    Note
    1x bolt, 10mm, 6 Nm.
  33. Install 12V negative harness clip to VC front.
    Note
    1x edge clip.
  34. Install front controller shield to the front controller.
    Note
    2x bolts, 10mm, 8.5 Nm.
  35. Connect thermal sub-harness to front controller.
    Note
    1x connector, rotate fully to secure locking tab.
  36. Install bolt securing front harness bracke from vehicle.
    Note
    2x bolts,10mm,9 Nm.
  37. Install AC Compressor harness clip to front harness bracket.
    Note
    1x clip.
  38. Connect LH front ped pro pressure tube sensor.
    Note
    1x connector, Engage locking tab.
  39. Connect RH front ped pro pressure tube sensor.
    Note
    1x connector, engage locking tab.
  40. Connect the low and high tone horn connector.
    Note
    2x connectors.
  41. Install the front fascia. See Fascia - Front (Remove and Replace).
  42. Raise vehicle fully and lower lift onto locks.
  43. Install LH harness bracke clip to vehicle.
    Note
    2x clips.
  44. Install push clips securing lower valance to front sway bar brackets.
    Note
    2x push clips, the number of clips on newer vehicles may vary.
  45. Install the aero shield. See Panel - Aero Shield - Front (Remove and Replace).
  46. Lower vehicle partially and set onto locks.
  47. Install lower bolt securing washer tank to vehicle.
    Note
    1x bolt, 10mm, 3 Nm.
  48. Connect the front harness connectors for the LH side repeater and camera.
    Note
    2x connectors.
  49. Connect pyrotechnic actuator connector.
    Note
    1x locking connector, Engage locking tab.
  50. Install the front harness clip around rear of LH front wheel liner area for the side repeater and camera.
    Note
    1x clip.
  51. Install the front harness clips around front of LH front wheel liner area for the wheel speed sensor.
    Note

  52. Connect the LH front wheel speed sensor and body height sensor.
    Note
    2x connectors.

    2x clips.

    Note
    2x connectors.

    Note
    1x locking connector, Engage locking tab.
  59. Install the front harness clip around rear of RH front wheel liner area.
    Note
    1x clip.
  60. Install the front harness clips around front of RH front wheel liner area.
    Note
    2x clips.
  61. Connect the RH front wheel speed sensor harness connector.
    Note
    1x connector.
  62. Install the harness clips at outer side of RH rail.
    Note
    2x clips.

  90. Install the RH footwell duct. See Duct - Footwell - RH (LHD) (Remove and Replace).
  91. Install the glove box. See Glove Box - With Knee Airbags (Non-Heat Pump) (Remove and Replace).
  92. Install clips securing RH footwell assembly.
    Note
    4x push clips.
  93. Install the RH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  94. Install the main instrument panel decor. See Decor Trim - Instrument Panel - Main (Remove and Replace).
