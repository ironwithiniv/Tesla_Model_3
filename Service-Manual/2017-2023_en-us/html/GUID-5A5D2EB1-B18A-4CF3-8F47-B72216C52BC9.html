Clip - Seat Cushion- Lower- 2nd Row -LH (Remove and Replace)

Correction code 13056902 0.06 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  1. Remove the 2nd row seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  2. Press the upper locking tabs to removal LH seat cushion clip.
Parent topic: 1305 - 2nd Row Seat Assemblies and Hardware

Install

  1. Install the seat cushion clip LH.
    Note
    Make sure the locking tabs are in place.
  2. install 2nd row seat cushion. SeeSeat Cushion - Lower - 2nd Row (Remove and Replace).
