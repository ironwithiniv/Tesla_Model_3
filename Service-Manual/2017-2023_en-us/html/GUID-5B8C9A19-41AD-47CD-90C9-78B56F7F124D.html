Module - HomeLink Transmitter (Remove and Replace)

Correction code 17154202 0.48 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-07-14: Updated post-replacement routine instructions.
Parent topic: 1715 - Electronic Control Modules

Remove

  1. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
    CAUTION
    Perform the 12V disconnect procedure exactly as detailed to avoid unexpected functionality of the homelink transmitter and touchscreen icon.
  2. Remove the front fascia. See Fascia - Front (Remove and Install).
  3. Disconnect the electrical connector from the HomeLink transmitter module.
  4. Release the tab, and then slide the HomeLink transmitter module to the right to remove it from the vehicle.

Install

  1. Install the HomeLink transmitter module on the bracket.
  2. Connect the electrical connector to the HomeLink transmitter module.
  3. Install the front fascia. See Fascia - Front (Remove and Install).
  4. Reconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  5. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): TEST-SELF_VCFRONT_X_HOMELINKvia Service Mode:Low Voltage ➜ Accessories ➜ Test HomeLinkvia Toolbox:(link)
