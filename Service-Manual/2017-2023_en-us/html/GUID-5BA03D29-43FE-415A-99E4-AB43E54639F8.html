Remove and Clean Radiator (Non-Heat Pump) (Maintenance)

Correction code 18301300 1.62 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
  • 2026-04-21: Released new procedure.
  1. Raise and support vehicle
  2. Open all four doors
    Note
    If vehicle is being powered down, Latch rear doors to prevent accidental closure
  3. Lower all four windows
  4. Move LH front seat forward
  5. Move RH front seat forward
  6. Open hood
    Note
    Press "Open" button on touchscreen to release latch, Lift lid manually
  7. Remove 2nd row seat cushion
    Note
    2x tabs, 2x connectors, Slide locking tabs to left of vehicle while lifting up seat bench. Newer models have connectors on both sides of bench, Older models have 2x connectors on one side of bench
  8. Remove rear apron
    Note
    12x clips, Only store rear apron visible face upwards
  9. Remove cabin intake upper duct assembly
    Note
    3x clips, Some configurations may come with 4x clips
  10. Remove closeout panel from frunk assembly
    Note
    4x clips, 1x connector, Frunk safety switch, 3x guide tabs, Grab closeout panel from bottom then pull it upward to release clips, Disconnect switch
  11. Remove frunk assembly carpet
    Note
    Note: Not all Model 3 vehicles have a frunk carpet installed
  12. Remove bolts securing frunk assembly
    Note
    7x bolts, 10mm, 5 Nm
  13. Remove frunk assembly from vehicle
    Note
    12x clips, Replace any clips if broken or missing, Number of clips may vary on older vehicles
  14. Power off vehicle from center display
    Note
    Via Controls > Safety > Power Off, Select Power Off button at warning dialogue box
  15. Disconnect 12V negative terminal
    Note
    1x nut, 10mm, 6 Nm, Ensure vehicle is in park, Climate control system is off, and vehicle is not charging before disconnecting 12V
  16. Remove Second Row Ancillary Bay 12V Cap
    Note
    1x foam cap
  17. Disconnect HVC logic connector and install logic cap
    Note
    1x connector, 1x cap, Release locking tab then push the handle downward to release connector
  18. Disconnect active grille shutter actuator connector
    Note
    1x connector, Disengage locking tab
  19. Remove bolts securing frunk reinforcement bracket
    Note
    2x bolts, 10mm, 16 Nm
  20. Remove frunk reinforcement bracket from fan assembly
    Note
    Set aside after removal for clearance
  21. Raise vehicle fully and lower lift onto locks
    Note
    Set vehicle to comfortable working height, Ensure an audible click of locks on both sides is heard before lowering, Vehicle may tilt to the side if both locks are not engaged
  22. Remove outer fasteners securing front aero shield
    Note
    9x bolts, 10mm, 5 Nm
  23. Remove front aero shield
    Note
    2x nuts, 15mm, 5 Nm
  24. Remove push clips securing lower valance to front sway bar brackets
    Note
    2x push clips, Number of clips on newer vehicles may vary
  25. Remove clips securing LH front wheel liner to lower valance
    Note
    3x push clips
  26. Remove nut securing lower valance to LH side of inner fascia
    Note
    1x nut, 10mm, 3 Nm
  27. Remove clips securing RH front wheel liner to lower valance
    Note
    3x push clips
  28. Remove nut securing lower valance to RH side of inner fascia
    Note
    1x nut, 10mm, 3 Nm
  29. Remove push clips securing front lower valance to fascia, slide front lower valance away from fascia and remove
    Note
    10x push clips, 7x tabs, Start from the middle and work your way out, Support valance to avoid bending/damaging
  30. Disconnect cooling fan module connector
    Note
    1x connector
  31. Place coolant drain container below LH front of vehicle
  32. Disconnect radiator inlet hose from condenser fan assembly
    Note
    1x spring clip
  33. Place coolant drain container below RH front of vehicle
  34. Disconnect radiator outlet hose from condenser fan assembly
    Note
    1x spring clip
  35. Remove coolant drain container from underneath vehicle
  36. Remove LH bolt securing bottom of condenser fan module to ankle catcher
    Note
    1x bolt, 8mm, 10 Nm, Lift CFM up to ease removal of bolt
  37. Remove RH bolt securing bottom of condenser fan module to ankle catcher and remove condenser fan module from vehicle
    Note
    1x bolt, 8mm, 10 Nm, Hold condenser fan module to ease removal of bolt
  38. Release side clips securing active grille shutter to condenser fan module
    Note
    2x tabs
  39. Release lower clips securing active grille shutter assembly to condenser fan module
    Note
    6x clips, Make sure active grille shutter assembly is pushed up and away from CFM
  40. Release upper clips securing active grille shutter to condenser fan module
    Note
    6x clips
  41. Lift active grille shutter up and remove from condenser fan module
  42. Remove bolts securing radiator to condenser assembly
    Note
    2x bolts, 5.5mm, 10 Nm, Some configurations may come no bolt
  43. Release side tab securing radiator to cooling fan, slide out and remove radiator
    Note
    2x guide tabs，1x clip
  44. Clean debris from radiator
    Note
    Vacuum both sides of radiator, Do not damage fins of radiator
  45. Clean radiator with compressed air
    Note
    Clean both sides of radiator with compressed air, Do not damage fins of radiator
  46. Position radiator onto condenser, slide into fan assembly and engage tab to secure
    Note
    2x guide tabs, 1x clip
  47. Install bolts securing radiator to condenser assembly
    Note
    2x bolts, 5.5mm, 10 Nm，Some configurations may come no bolt
  48. Position active grille shutter assembly onto condenser fan module
  49. Secure lower tabs holding active grille shutter assembly to condenser fan module
    Note
    6x tabs
  50. Secure side tabs from active grille shutter to condenser fan module
    Note
    2x tabs
  51. Secure upper clips securing active grille shutter to condenser fan module
    Note
    6x tabs
  52. Install condenser fan module onto vehicle
    Note
    2x bolt, 8mm, 10 Nm, Torque at later step, Recommend assistance, Position the condenser fan module from underneath the vehicle. Hand-start the bolts to secure the bottom of the condenser fan module to the ankle catcher.
  53. Torque bolt at bottom LH of condenser fan module to ankle catcher
    Note
    1x bolt, 8mm, 10 Nm, Gently lift condenser fan module to position into place and install bolt
  54. Torque bolt at bottom RH of condenser fan module to ankle catcher
    Note
    1x bolt, 8mm, 10 Nm, Gently lift condenser fan module to position into place and install bolt
  55. Position coolant drain container below RH front of vehicle
  56. Connect radiator outlet hose from condenser fan assembly
    Note
    1x spring clip
  57. Position coolant drain container below LH front of vehicle
  58. Connect radiator inlet hose from condenser fan assembly
    Note
    1x spring clip
  59. Remove coolant drain container from underneath vehicle
  60. Connect cooling fan module connector
    Note
    1x connector
  61. Install valance to front fascia
    Note
    10x push clips, 7x tabs, Verify push clips are fully engaging lower valance to fascia, If not remove push clip and try again
  62. Install nut securing lower valance to RH side of inner fascia
    Note
    1x nut, 10mm, 3 Nm
  63. Install clips securing RH front wheel liner to lower valance
    Note
    3x push clips
  64. Install nut securing lower valance to LH side of inner fascia
    Note
    1x nut, 10mm, 3 Nm
  65. Install clips securing LH front wheel liner to lower valance
    Note
    3x push clips
  66. Install push clips securing lower valance to front sway bar brackets
    Note
    2x push clips, Number of clips on newer vehicles may vary
  67. Position front aero shield to vehicle and install nuts
    Note
    2x nuts, 15mm, 5 Nm
  68. Apply Loctite 222 onto front aero shield bolts and install outer fasteners to front aero shield
    Note
    9x bolts, 10mm, 5 Nm
  69. Lower vehicle fully
    Note
    Raise lift off locks, then hold lock release lever to keep locks free while vehicle is lowered
  70. Position frunk reinforcement bracket onto top of condenser fan module
  71. Install bolts securing frunk reinforcement bracket
    Note
    2x bolts, 10mm, 16 Nm, Verify clearance between cooling fan module and isolator bracket to avoid vibration
  72. Break bolts loose securing LH side cooling fan module isolator
    Note
    2x bolts, 10mm, 6 Nm, Photo shows reinforcement bracket removed and flipped for clarity
  73. Install LH cooling fan module isolator
    Note
    Push LH side cooling fan module isolator towards front of vehicle until the isolator bottoms out at the stop, Ensure cooling fan module is seated properly in isolator
  74. Fully secure LH side cooling fan module isolator
    Note
    2x bolts, 10mm, 6 Nm
  75. Break bolts loose securing RH side cooling fan module isolator
    Note
    2x bolts, 10mm, 6 Nm, Photo shows reinforcement bracket removed and flipped for clarity
  76. Install LH cooling fan module isolator
    Note
    Push RH side cooling fan module isolator towards front of vehicle until the isolator bottoms out at the stop. Ensure cooling fan module is seated properly in isolator
  77. Fully secure RH side cooling fan module isolator
    Note
    2x bolts, 10mm, 6 Nm
  78. Inspect coolant level and top off as necessary
    Note
    (*Use this step for Model 3 Superbottle vehicles) Ensure that the fluid level is 5mm above the Max line
  79. Connect active grille shutter actuator connector
    Note
    1x connector
  80. Connect HVC logic connector
    Note
    1x connector, 1x cap, Remove logic cap, Align connector then pull the handle to locking position get connector fully seated
  81. Install Second Row Ancillary Bay 12V Cap
    Note
    1x foam cap
  82. Connect 12V negative terminal
    Note
    1x nut, 10mm, 6 Nm
  83. Connect 2nd row seat cushion harness and install 2nd row seat cushion
    Note
    2x connectors, 2x clips, Insert the seat belt buckles through the holes, Slide rear cushion inward then align front guide tabs to locking tabs, Make sure cushion is fully seated with push pull test near clips
  84. Move RH front seat to original position
  85. Move LH front seat to original position
  86. Connect to vehicle using Toolbox
    Note
    Vehicle connection is integrated into drivers footwell cover, Navigate to https://toolbox.teslamotors.com and establish connection to vehicle, Select connection status icon at top right corner then select connect locally, Icon will turn green when connected, Successful connection will automatically unlock vehicle gateway and place UI in Service Mode Plus, If RJ45 ethernet diagnostic connector present connect directly from laptop using an RJ45 Ethernet cable, For local connection issues with Toolbox refer to https://toolbox.teslamotors.com/articles/43695
  87. Select ‘Actions/Autodiag’ and search for ‘Thermal’
  88. Perform "Start Thermal Fluid Fill/Drain (Coolant only)" in Toolbox
    Note
    Click "Run" and allow routine to complete. Select ‘X’ at top right of window to close once complete, Verify vehicle is in Series via Garage > Vitals > Thermal tab > Coolant loops, Thermal Fluid Fill/Drain routine has a 5 hour limit, After 5 hours routine must be performed again
  89. Remove HVAC inlet plenum
    Note
    2x clips
  90. Remove coolant bottle cap
    Note
    (*Use this step for Model 3 Superbottle vehicles)
  91. Fill container with at least 15L of coolant
  92. Place filled coolant container into front storage area
    Note
    (*Use step for Model 3 Heat Pump vehicles)
  93. Place refill hose inside filled coolant container
    Note
    Make sure hose end is fully submerged into coolant
  94. Install coolant reservoir adapter cap onto coolant Superbottle assembly
    Note
    (*Use step for Model 3 non-Heat Pump vehicles)
  95. Setup coolant Vacuum Refill Tool
    Note
    Verify all valves on refill tool are in the closed position, See image for clarity
  96. Place overflow hose into empty container
  97. Connect shop air supply to coolant refill tool
    Note
    If not already done, Verify refill valve is set to off
  98. Slowly open refill valve to draw coolant into system
    Note
    Valve lever is inline with hose when fully open, Make sure end of refill hose is fully submerged in container during entire process, Coolant will be transferred through hose from container to vehicle coolant reservoir, Vacuum gauge needle will move towards zero as it fills
  99. Open air inlet valve to draw a vacuum, Once gauge stabilizes, Fully close valve
    Note
    Gauge stabilizes roughly (60-70 cmHg), Vacuum should not drop after the valves are closed
  100. Once gauge reads zero, close coolant refill valve
  101. Monitor gauge for 30 seconds to verify a vacuum is maintained in cooling system
  102. Slowly open refill valve to draw coolant into system
    Note
    Valve lever is inline with hose when fully open, Make sure end of refill hose is fully submerged in container during entire process, Coolant will be transferred through hose from container to vehicle coolant reservoir, Vacuum gauge needle will move towards zero as it fills
  103. When gauge reaches zero, close coolant refill valve
  104. Remove coolant overflow hose from waste coolant container
  105. Disconnect shop air from Vacuum Refill tool.
  106. Remove both coolant containers from inside underhood area
    Note
    (*Use this step for Model 3 vehicle procedures)
  107. Select "Actions/Autodiag" tab and search for "vcfront"
  108. Run ODIN routine TEST-RESET_VCFRONTvia Toolbox:(link)
  109. Run ODIN routine TEST_VCFRONT_X_THERMAL-COOLANT-AIR-PURGEvia Service Mode:
    • Thermal ➜ Actions ➜ Coolant Purge Stop or Coolant Purge Start
    • Thermal ➜ Coolant System ➜ Coolant Purge Start
    via Service Mode Plus:
    • Drive Inverter ➜ Front Drive Inverter Replacement ➜ Coolant Air Purge
    • Drive Inverter ➜ Rear Drive Inverter Replacement ➜ Coolant Air Purge
    • Drive Inverter ➜ Rear Left Drive Inverter Replacement ➜ Coolant Air Purge
    • Drive Inverter ➜ Rear Right Drive Inverter Replacement ➜ Coolant Air Purge
    • Drive Unit ➜ Front Drive Unit Replacement ➜ Coolant Air Purge
    • Drive Unit ➜ Rear Drive Unit Replacement ➜ Coolant Air Purge
    via Toolbox:(link)
  110. Inspect coolant level and top off as necessary
    Note
    (*Use this step for Model 3 Superbottle vehicles) Ensure that the fluid level is 5mm above the Max line
  111. Install coolant bottle cap
    Note
    (*Use this step for Model 3 Superbottle vehicles)
  112. Install HVAC inlet plenum
    Note
    2x clips, Align tab at bottom of duct before securing clips
  113. Connect charge cable to vehicle
  114. Select ‘TEST-SELF_VCFRONT_X_THERMAL-PERFORMANCE’, click ‘Run’, and allow routine to complete
    Note
    Select ‘X’ at top right of window to close once complete
  115. Remove charge cable from vehicle
  116. Perform the routine: PROC_VC_X_RESET-RADIATOR-UA-INDEXvia Toolbox:(link)
  117. Disconnect Toolbox from vehicle and remove laptop and diagnostics adapter ethernet harness
    Note
    If RJ45 ethernet diagnostic connector present media converter box not required disconnect directly from laptop using an RJ45 Ethernet cable or from OBDII connection
  118. Install frunk assembly to vehicle
    Note
    12x clips, Make sure frunk assembly is fully seated onto clips, Number of clips may vary on older vehicles, Ensure A/C compressor HVIL harness is not pinched between frunk assembly and thermal beam, replace any damaged clips
  119. Install bolts securing frunk assembly
    Note
    7x bolts, 10mm, 5 Nm
  120. Install frunk assembly carpet
  121. Install frunk close out panel
    Note
    4x clips, 1x connector, Frunk safety switch, 3x guide tabs, Align 3x tabs then push downward to secure clips
  122. Install cabin intake upper duct assembly
    Note
    3x clips, Some configurations may come with 4x clips
  123. Install rear apron
    Note
    12x clips
  124. Close hood
  125. Raise all four windows
  126. Close all four doors
  127. Remove vehicle from lift
    Note
    Lower rack arms fully and remove from under vehicle
