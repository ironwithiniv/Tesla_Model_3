Motor - Seat Track - Driver Seat (Remove and Replace)

Correction code 13011202 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2023-11-29: Re-write the procedure according to the latest validation.
  • 2023-12-07: Removed the steps about the driver seat outer side cover according to the latest validation.

Warning
Seat base edges are sharp and can cause personal injury. Wear cut resistant gloves when removing the seat from the vehicle, and while performing procedures that involve work on or near the seat base.
Parent topic: 1301 - Front Seat Tracks and Motors

Remove

  1. Open all doors and lower all windows.
  2. Remove the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  3. Remove the LH middle A-pillar trim. See Trim - A-Pillar - Middle - LH (Remove and Replace).
  4. Release the bottom half of the LH front door seal.
  5. Remove the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  6. Use a clip prytool to release the LH front seat harness from the sill trim clips (x3).
  7. Pull the LH front seat harness from under the LH front cabin carpet.
  8. Move the LH front seat forward, and then remove and discard the LH front seat rear fasteners (x2).
    Tip
    Use of the following tool(s) is recommended:
    • Torx Plus T45 socket
  9. Move the LH front seat backward, and then remove and discard the LH front seat front fasteners (x2).
    Tip
    Use of the following tool(s) is recommended:
    • Torx Plus T45 socket
  10. Tilt the LH front seat rearward.
    Note
    It is not necessary to disconnect the LH seat harness from the body controller. Take care when moving the seat. Ensure the carpet is not damaged.
  11. Remove and discard the bolts (x2) that attach the driver seat track bridge to the seat cushion frame.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 Bit Stubby
  12. Use a clip prytool to remove the harness clip from the seat track motor.
  13. Disconnect the electrical harness from the driver seat track motor connector.
  14. Release the outboard track from the track motor bridge.
    Note
    Pry up on the track motor bridge tab and slide the outboard track away to release.
  15. Release the track motor bridge from the inboard track.
    Note
    Pry up on the track motor bridge tab and slide the track motor bridge away from the inboard track.

Install

  1. Install the track motor bridge to the inboard seat track.
    Note
    The track motor cable is keyed square and must be aligned with the inboard track. Turn the cable by hand to align as needed. Slide the track motor bridge into the inboard track till it is fully and securely seated.
  2. Install the outboard seat track to the track motor bridge.
    Note
    The track motor cable is keyed square and must be aligned with the inboard track. Turn the cable by hand to align as needed. Slide the track motor bridge into the inboard track till it is fully and securely seated.
  3. Install new bolts (x2) to attach the driver seat track bridge to the seat cushion frame.
    23 Nm (17.0 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 Bit Stubby
  4. Connect the electrical harness to the driver seat track motor connector.
  5. Install the harness clip to the seat track motor.
  6. Reposition the LH front seat.
    Note
    Take care when moving the seat. Ensure the carpet is not damaged.
  7. Secure the LH front seat harness under the LH front cabin carpet.
  8. Install the LH front seat harness to the sill trim clips (x3).
  9. Move the LH front seat backward, and install the LH front seat front fasteners (x2).
    33.5 Nm (24.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx Plus T45 socket
  10. Move the LH front seat forward, and install the LH front seat rear fasteners (x2).
    33.5 Nm (24.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx Plus T45 socket
  11. Install the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  12. Install the LH middle A-pillar trim. See Trim - A-Pillar - Middle - LH (Remove and Replace).
  13. Install the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  14. On the touchscreen, tap Service > Driver Seat, Steering, & Mirrors Calibration > START, and allow the routine to complete.
  15. Move the LH front seat to original position.
  16. Raise all windows and close all doors.
