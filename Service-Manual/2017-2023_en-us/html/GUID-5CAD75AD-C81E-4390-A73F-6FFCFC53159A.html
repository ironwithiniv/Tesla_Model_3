Speaker - Pedestrian Warning (Retrofit)

Procedure

  1. Remove the RH front wheel. See Wheel Assembly (Remove and Install).
  2. Remove the clips (x9) that hold the RH front wheel liner to fascia, and move the wheel liner aside for access.
  3. Look underneath the RH front corner of the vehicle and locate the breakout harness for the pedestrian warning speaker electrical connector.
    Note
    If the vehicle is not equipped with the pedestrian warning speaker electrical connector, then the vehicle cannot be retrofitted with the pedestrian warning speaker. Reinstall the components that were removed for access and stop this procedure.
  4. Use a retractable blade knife or similar tool to carefully remove the tape that secures the pedestrian warning speaker electrical connector to the main front harness bundle.
  5. Install the screws (x3) that attach the pedestrian warning speaker assembly to the front fascia.
    1.8 Nm (1.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket
  6. Install the clip that attaches the harness to the pedestrian warning speaker assembly.
  7. Engage the locking tab to connect the pedestrian warning speaker connector.
  8. Install the clips (x9) that hold the RH front wheel liner to fascia.
  9. Install the RH front wheel. See Wheel Assembly (Remove and Install).
  10. Locally connect a laptop with Toolbox 3 to the vehicle. See Toolbox (Connect and Disconnect).
  11. Run ODIN routine PROC_ICE_X_SET-PEDESTRIAN-WARNING-SPEAKER-CONFIGvia Toolbox:(link)
  12. In Toolbox, run the pws-equipped action to enable the speaker.
  13. Disconnect the laptop.
  14. Reinstall the vehicle firmware. See Software Reinstall - Touchscreen.
  15. Exit Service Mode. See Service Mode.
  16. Raise the LH front window and close the LH front door.
