Brake Hose - Flexible - Rear - LH (Remove and Replace)

Correction code 33030502 0.54 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1079041-00-A Flare nut crowfoot set
Warning
Upon installation, make sure that the flexible brake hose is not twisted and can bend forward. The flexible brake hose must not make contact with the wheel arch liner when the vehicle is lowered.
CAUTION
Brake fluid dissolves paint. Have clean towels and plenty of water standing by to wash spilled brake fluid off painted surfaces.
Note
This procedure is applicable to both Performance and non-Performance rear brakes.
Note
Dispose of used brake fluid in a manner consistent with local environmental codes.
  • 2026-02-19: Added a warning.
  • 2025-09-29: Fixed incorrectly ordered steps. Added steps to adjust vehicle on lift and burnish brakes on install.
Parent topic: 3303 - Brake Pipes and Hoses

Remove

  1. Disconnect 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  2. Remove the rear LH wheel. See Wheel Assembly (Remove and Install).
  3. Position the oil drain under the rear LH brake hose.
  4. Remove the brake line tube nut from the brake hose at the jounce hose bracket, and allow the fluid to drain.
  5. Release the clip that attaches the brake hose to the jounce hose bracket, and then remove the hose from the bracket.
  6. Position the oil drain under the brake caliper.
  7. Remove the bolt that attaches the flexible brake hose to the brake caliper, and then remove the hose from the vehicle.
    Note
    The bolt and washers (x2) are captive and cannot be reused. Replace the hose assembly if the bolt is loosened or removed.

Install

  1. Position the LH rear flexible brake hose into the vehicle, and then install the bolt that attaches the hose to the LH rear brake caliper.
    42 Nm (31.0 lbs-ft)
    Warning
    Upon installation, make sure that the flexible brake hose is not twisted and can bend forward. The flexible brake hose must not make contact with the wheel arch liner when the vehicle is lowered.
    Note
    The bolt and washers are captive in the new hose assembly.
    Note
    Install one washer on each side of the brake line. Do not double stack washers.
    Note
    Mark the fastener with a paint pen after torquing.
  2. Install the brake hose into the jounce hose bracket, and then fasten the clip that attaches the hose in the bracket.
  3. Insert the brake line into the brake hose at the jounce hose bracket, and then use a crowfoot extension to install the brake line tube nut into the brake hose.
    16 Nm (11.8 lbs-ft)
  4. Remove the oil drain from under the vehicle.
  5. Partially lower the vehicle and set onto locks. See Raise Vehicle - 2 Post Lift.
  6. Bleed the brake caliper for the brake hose that was serviced. See Brake Fluid Bleed - One Caliper.
  7. Install the rear LH wheel. See Wheel Assembly (Remove and Install).
  8. Connect 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  9. Perform a road test and burnish the brake pads. See Brake Pads - Burnishing.
    Note
    Ensure proper brake pedal feel and brake performance.
    Note
    Add correction code 33013000 as a separate activity to the SV.
