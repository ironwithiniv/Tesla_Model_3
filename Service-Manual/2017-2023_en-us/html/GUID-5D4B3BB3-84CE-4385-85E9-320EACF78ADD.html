Light - Brake - Center High Mounted (Remove and Replace)

Correction code 17402502 0.72 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1740 - Exterior Lights

Remove

  1. Remove the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  2. Remove the LH side rail trim. See Trim - Side Rail - LH (Remove and Install).
  3. Remove the LH upper C-pillar trim. See Trim - C-Pillar - Upper - LH (Remove and Replace).
  4. Remove the RH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  5. Remove the RH side rail trim. See Trim - Side Rail - LH (Remove and Install).
  6. Remove the RH upper C-pillar trim. See Trim - C-Pillar - Upper - LH (Remove and Replace).
  7. Remove the package tray trim. See Trim - Package Tray (Remove and Replace).
  8. Disconnect the center high mounted brake light electrical connector.
  9. Remove the screws that attach the center high mounted brake light to the package tray.
  10. Release the clips that attach the center high mounted brake light to the package tray, and then remove the brake light from the vehicle.

Install

  1. Install the center high mounted brake light on the package shelf and secure it with clips.
  2. Install the screws that attach the center high mounted brake light to the package tray.
    0.5 Nm (4 lbs-in)
  3. Connect the center high mounted brake light electrical connector.
  4. Install the package tray trim. See Trim - Package Tray (Remove and Replace).
  5. Install the RH upper C-pillar trim. See Trim - C-Pillar - Upper - LH (Remove and Replace).
  6. Install the RH side rail trim. See Trim - Side Rail - LH (Remove and Install).
  7. Install the RH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  8. Install the LH upper C-pillar trim. See Trim - C-Pillar - Upper - LH (Remove and Replace).
  9. Install the LH side rail trim. See Trim - Side Rail - LH (Remove and Install).
  10. Install the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  11. Install the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
