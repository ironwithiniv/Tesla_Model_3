NVH Pad - Glove Box (Remove and Replace)

Correction code 14051302 0.36 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1405 - Instrument Panel

Remove

CAUTION
This procedure applies to models without knee airbags.
Note
The procedure describes the NVH pad replacement on a RHD vehicle. The procedure for LHD vehicles is similar/mirrored.
  1. Open the front doors.
  2. Remove the LH and RH instrument panel end caps. See End Cap - Instrument Panel - LH (Remove and Replace).
  3. Remove the LH and RH air wave bezel caps. See End Cap - Air Wave - LH (Remove and Replace).
  4. Remove the main instrument panel decor trim. See Decor Trim - Instrument Panel - Main (Remove and Replace).
  5. Remove the LH middle A-Pillar trim. See Trim - A-Pillar - Middle - LH (Remove and Replace).
  6. Remove the LH lower A-Pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  7. Remove the glove box. See Glove Box - Without Knee Airbags (Remove and Replace).
  8. Peel the NVH pad from the glove box.
  9. Use IPA wipes to remove remaining adhesive residue from the glove box, and then allow one minute for the IPA to dry.

  1. Install a new NVH pad onto the glove box assembly.
  2. Install the glove box. See Glove Box - Without Knee Airbags (Remove and Replace).
  3. Install the LH lower A-Pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  4. Install the LH middle A-Pillar trim. See Trim - A-Pillar - Middle - LH (Remove and Replace).
  5. Install the main instrument panel decor trim. See Decor Trim - Instrument Panel - Main (Remove and Replace).
  6. Install the LH and RH air wave bezel caps. See End Cap - Air Wave - LH (Remove and Replace).
  7. Install the LH and RH instrument panel end caps. See End Cap - Instrument Panel - LH (Remove and Replace).
  8. Close the front doors.
