Kit - Cooling Fan Module Isolator - Air Conditioning Condenser (Remove and Replace)

Correction code 18308224 0.5NOTE: Unless otherwise explicitly stated in the procedure, the above correction code and FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so.NOTE: See Flat Rate Times to learn more about FRTs and how they are created. To provide feedback on FRT values, email LaborTimeFeedback@tesla.com. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure.

Parent topic: 1830 - Cooling System

Remove

  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Remove the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  3. Remove the hood latch cover. See Cover - Hood Latch (Remove and Replace).
  4. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace)
  5. Release the clip that attaches the front harness to the front underhood storage unit reinforcement bracket.
  6. Remove the bolts (x2) that attach the underhood storage unit reinforcement bracket to the cooling fan, and then remove the frunk reinforcement bracket.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
    • 2 in extension
  7. Remove the bolts (x4) that attach the upper cooling fan module isolator to the reinforcement bracket.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
    • 2 in extension
  8. Raise vehicle fully and lower lift onto locks.
  9. Remove the front aero shield. SeePanel - Aero Shield - Front (Remove and Replace)
  10. Remove the front valance from front fascia. SeeValance - Front Fascia (Remove and Replace)
  11. Remove the bolts that attach the lower LH and RH sides of the cooling fan module to the ankle catcher.
    Note
    With assistance, lift up on the cooling fan module to ease the removal of the bolts.
    Tip
    Use of the following tool(s) is recommended:
    • 8 mm socket
  12. Remove the lower cooling fan module isolator from the cooling fan.

Install

  1. Install the lower cooling fan module isolator to the cooling fan.
  2. Gently lift the fan module and ensure it is in place, and then loosely install the bolts that attach the module assembly to the vehicle.
  3. Torque the bolts that attach the LH and RH of the cooling fan module to the vehicle.
    10 Nm (7.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 8 mm socket
  4. Install the front valance from front fascia. SeeValance - Front Fascia (Remove and Replace)
  5. Install the front aero shield. SeePanel - Aero Shield - Front (Remove and Replace)
  6. Lower vehicle fully.
  7. Install the bolts (x4) that attach the upper cooling fan module isolator to the reinforcement bracket.
    6 Nm (4.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
    • 2 in extension
  8. Position the underhood storage unit reinforcement bracket onto the cooling fan, and then install the bolts (x2) that attach the bracket to the cooling fan.
    16 Nm (11.8 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  9. Install the clip that attaches the front harness to the front underhood storage unit reinforcement bracket.
  10. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace)
  11. Install the hood latch cover. See Cover - Hood Latch (Remove and Replace).
  12. Install the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  13. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
