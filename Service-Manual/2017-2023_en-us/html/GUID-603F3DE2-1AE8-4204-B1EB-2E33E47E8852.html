O-ring - Filler Neck - Reservoir - Windshield Washer (RHD) (Remove and Replace)

Correction code 17504102 0.06 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1750 - Wipers and Washers

Remove

  1. Remove the windshield washer reservoir filler neck. See Filler Neck - Reservoir - Windshield Washer (RHD) (Remove and Replace).
  2. Use a flathead screwdriver to remove the O-ring from the filler neck.

Install

Installation procedure is the reverse of removal.
