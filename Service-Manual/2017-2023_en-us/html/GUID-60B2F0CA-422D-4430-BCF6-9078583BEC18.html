Parent topic: 3301 - Brake Discs and Calipers

Procedure

Note
This is an additional procedure, to prevent NVH issues. This procedure is only applicable to the EMEA market.
Note
Add this correction code as an extra activity to the service visit, combined with the correction code for Brake Pads (Remove and Install or Remove and Replace).
  1. Clean the back side of the front brake pads (x4) and the surfaces of the brake caliper pistons (x8) using brake cleaner.
  2. Using a cotton swab, apply adhesion promotor, and then allow 5 minutes to dry.
  3. Align the pre-cut NVH sticker to the back side of the front brake pads (x4), and then apply pressure on the stickers to adhere them to the brake pads.
  4. Remove the protective cover from the NVH sticker applied to the brake pads (x4).
  5. Clean the brake caliper retaining pins (x4) using a hand brush and soapy water, and then apply an even layer of Silaramic lubricant to the brake caliper retaining pins.
  6. Proceed with the installation of the front brake pads.
