Module - TPMS (Remove and Replace)

Correction code 34043002 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2024-01-24: Added reference for Tesla TPMS module which is integrated in VCSEC.
Note
This procedure is only for Conti Gen 2 TPMS module. Tesla TPMS module is integrated in VCSEC. Refer toModule - Body Controller - Security (Remove and Replace) or Module - Body Controller - Security (2nd Generation) (Remove and Replace) as needed.
Parent topic: 3404 - Tire Pressure Monitoring System (TPMS)

Remove

  1. Remove the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  2. Remove the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  3. Remove the LH side rail trim. See Trim - Side Rail - LH (Remove and Install).
  4. Remove the LH upper C-pillar trim. See Trim - C-Pillar - Upper - LH (Remove and Replace).
  5. Remove the RH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  6. Remove the RH side rail trim. See Trim - Side Rail - LH (Remove and Install).
  7. Remove the RH upper C-pillar trim. See Trim - C-Pillar - Upper - LH (Remove and Replace).
  8. Remove the package tray trim. See Trim - Package Tray (Remove and Replace).
  9. Disconnect the TPMS module electrical connector.
  10. Release the tab and slide the TPMS module towards the front of the vehicle, and then remove the module from the vehicle.

Install

  1. Install the TPMS module on the vehicle by sliding the TPMS module towards the rear of the vehicle until the tab is attached.
  2. Connect the TPMS module electrical connector.
  3. Install the package tray trim. See Trim - Package Tray (Remove and Replace).
  4. Install the RH upper C-pillar trim. See Trim - C-Pillar - Upper - LH (Remove and Replace).
  5. Install the RH side rail trim. See Trim - Side Rail - LH (Remove and Install).
  6. Install the RH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  7. Install the LH upper C-pillar trim. See Trim - C-Pillar - Upper - LH (Remove and Replace).
  8. Install the LH side rail trim. See Trim - Side Rail - LH (Remove and Install).
  9. Install the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  10. Install the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  11. Update the vehicle firmware. See Software Update.
  12. Perform the TPMS module sensor ID learn procedure. See TPMS (Sensor ID Tool Learn).
