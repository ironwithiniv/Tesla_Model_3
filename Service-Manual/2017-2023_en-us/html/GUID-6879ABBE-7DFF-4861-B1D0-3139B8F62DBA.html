Striker - Door - Front - LH (Remove and Replace)

Correction code 11353002 0.06 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1135 - Latches Strikers and Pinch Sensors

Torque Specifications

Table 1. Torque Specifications: Striker - Door - Front - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts that attach the front door striker to the body
26 Nm (19.2 lbs-ft)
  • T45 socket
 Reuse

Remove

  1. Open the LH front door.
  2. Mark the position of the LH front door striker using masking tape.
  3. Remove the bolts that attach the LH front door striker to the body.
    Note
    Use of the following tool(s) is recommended:
    • T45 socket
  4. Remove the LH front door striker from the vehicle.

Install

  1. Hand-tighten the bolts that attach the LH front door striker to the body.
    Note
    Use of the following tool(s) is recommended:
    • T45 socket
  2. Close the LH front door and verify the door position; adjust the position of the striker and verify fitment, if necessary.
  3. Tighten the bolts that attach the LH front door striker to the body.
    26 Nm (19.2 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • T45 socket
  4. Remove the masking tape from the body.
  5. Close the LH front door.
