Coax Cable - Side Repeater - Front - LH (Overlay) (Remove and Replace)

Correction code 17403012 FRT 2.16 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
  • 2026-07-09: Released new procedure.
  1. Raise and support vehicle
    Note
    remove charging equipment
  2. Open both front doors and lower both front windows.
  3. Move RH front seat backward
  4. Remove the washer reservoir. See Reservoir - Windshield Washer (Remove and Install).
  5. Disconnect front harness connectors for LH side repeater and camera
    Note
    2x connectors
  6. Power off vehicle from center display
    Note
    Via Controls > Safety > Power Off, Select Power Off button at warning dialog box
  7. Disconnect LV battery
    Note
    2x connectors, Lift up and release green locking tab, Pull black connector lock outwards to release connection
  8. Disconnect service disconnect
    Note
    1x connector, Release locking tab
  9. Release positive jump post
    Note
    1x bolt, 10mm, 5 Nm
  10. Remove LV battery cable stand off
    Note
    1x clip
  11. Release LV battery
    Note
    3x bolts, 10mm, 6 Nm, Move battery cables clear of the LV battery
  12. Lift LV battery straight up and remove out of vehicle
  13. Remove ground cable from front controller
    Note
    1x bolt, 10mm, 8.5 Nm
  14. Disconnect thermal sub-harness from front controller
    Note
    1x connector, Depress locking tab and rotate to release
  15. Remove bolts securing front controller shield assembly and remove from vehicle
    Note
    2x bolts, 10mm, 8.5 Nm
  16. Disconnect front controller harness connectors
    Note
    5x connectors, 1x harness guide, depress locking tab if equipped
  17. Remove bolts securing front controller
    Note
    3x bolts, 10mm, 10 Nm
  18. Tilt front controller forward for access
  19. Remove ground cable from backside of front controller
    Note
    1x edge clip
  20. Release harness guide and remove the front controller from vehicle
    Note
    1x tab
  21. Remove fresh air intake assembly
    Note
    2x studs, Lift cowl as needed
  22. Remove LH IP end cap
    Note
    3x clips
  23. Remove LH air wave bezel cap from main decor assembly
    Note
    2x clips, Newer vehicles are equipped with solid bezel.
  24. Remove RH IP end cap
    Note
    3x clips
  25. Remove RH air wave bezel cap from main decor assembly
    Note
    2x clips, Newer vehicles are equipped with solid bezel.
  26. Remove main decor assembly
    Note
    15x clips, Entire decor does not need to come off for glove box removal, If you lift RH side of decor then you will have access to 3x torx screws securing top of glove box, Replace securing clips as needed
  27. Release RH footwell assembly from IP
    Note
    4x push clips
  28. Remove RH footwell assembly
    Note
    2x connectors
  29. Remove bolts securing passenger knee air bag onto vehicle
    Note
    4x patch bolts, T30, 8 Nm, Discard after removal, 2x screws, T20, 2 Nm, 1x push clip, Newer vehicles have 4x E10 patch bolts
  30. Remove passenger knee air bag from vehicle
    Note
    1x connector, Release locking tab, Connector release may vary
  31. Remove screws securing glove box assembly to IP carrier
    Note
    6x screws, T20, 2.3 Nm
  32. Disconnect glove box assembly connectors
    Note
    3x electrical connectors
  33. Remove glove box from IP carrier
    Note
    3x clips
  34. Disconnect glove box USB cable from car computer
    Note
    1x connector, Depress latch on top of USB cable to release internal latches, Then release from car computer
  35. Remove clip securing passenger footwell air duct and rotate for access
    Note
    1x push clip, With glovebox installed there is not sufficient room to fully remove passenger footwell duct
  36. Disconnect RH upper duct thermistor from RH IP air wave duct
    Note
    1x connector
  37. Remove RH IP air wave duct
    Note
    2x push clips
  38. Release windshield heater connecter
    Note
    1x connector
  39. Release RH grommet from body
  40. Remove electrical tape securing harness bundle to rubber dust boot
    Note
    Use a razor blaze, carefully cut electrical tape away to expose rubber dust boot
  41. Remove locking pin from connector
    Note
    Carefully pry pin out of connector and fully remove locking pin
  42. Remove coax cable needed for the side repeater overlay M3 terminal 1 (LHS)
    Note
    Inspect all components for damage
  43. Apply harness tape onto LH coax overlay cable before installation
    Note
    Use Anti-abrasion tape and wrap the entire length of the coax cable to protect the cable for damage when it is in the vehicle
  44. Release frunk harness cover
    Note
    3x tabs
  45. Position M3 LH coax overlay cable into place, Place through LH wheel liner
    Note
    Pull till you have roughly 12 inches of cable towards the interior of the vehicle
  46. Pull LH coax overlay cable through frunk harness
    Note
    Pull harness towards car computer, Route under brake booster lower connector
  47. Tape coax overlay onto fish nylon tape
  48. Pull LH coax overlay cable through bulkhead and into interior cabin
  49. Remove nylon fish tape
    Note
    Remove tape the pull nylon fish tape out of vehicle
  50. Disconnect side repeater cameras connector from car computer
    Note
    1x locking connector
  51. Remove locking pin from side repeater cameras connector
    Note
    Carefully pry pin out of connector and fully remove locking pin
  52. Remove coax terminal 1 (LHS) cable from connector
    Note
    Inspect all components for damage
  53. Insert new side repeater coax terminal 1 (LHS) cable onto side repeater cameras connector
    Note
    Ensure both coax cables are fully seated into connector, Audible locking and flush mounting to confirm
  54. Secure locking pin to connector
    Note
    Align tabs of lock in connector housing, Ensure flush installation of locking pin to connector housing
  55. Connect side repeater cameras connector onto car computer
    Note
    1x locking connector
  56. Position LH coax overlay cable onto frunk main harness, Secure cable onto harness using zip ties
    Note
    7x zip-ties, Trim off excess material after harness has been secured
  57. Cut off the vehicle side repeater coax terminal and tape to vehicle harness
    Note
    Cut the coax connector only
  58. Connect front harness connectors for LH side repeater and camera
    Note
    2x connectors
  59. Secure RH grommet from body
    Note
    Use electrical tape to wrap the end of the dust boot
  60. Secure frunk harness cover
    Note
    3x tabs
  61. Secure windshield heater connector
    Note
    1x connector
  62. Place front controller into vehicle for installation
  63. Install ground cable to backside of front controller
    Note
    1x edge clip
  64. Install harness guide and tilt front controller backward for installation
    Note
    1x tab
  65. Install bolts securing front controller
    Note
    3x bolts, 10mm, 10 Nm
  66. Install front controller harness connectors
    Note
    5x connectors, 1x harness guide, secure locking tab if equipped
  67. Install front controller shield to the front controller
    Note
    2x bolts, 10mm, 8.5 Nm
  68. Connect thermal sub-harness to front controller
    Note
    1x connector, Rotate fully to secure locking tab
  69. Install ground cable to front controller
    Note
    1x bolt, 10 mm, 8.5 Nm
  70. Install LV battery into bracket and bolt into place
    Note
    3x bolts, 10mm, 6 Nm
  71. Secure positive jump post
    Note
    1x bolt, 10mm, 5 Nm
  72. Install battery cable standoff
    Note
    1x clip
  73. Install the washer reservoir. See Reservoir - Windshield Washer (Remove and Install).
  74. Connect glove box USB cable to car computer
    Note
    1x connector
  75. Re-position and secure the passenger footwell air duct
    Note
    1x push clip
  76. Install RH IP air wave duct
    Note
    2x push clips
  77. Connect RH upper duct thermistor to RH IP air wave duct
    Note
    1x connector
  78. Connect glove box assembly connectors
    Note
    3x connectors, New puddle lamp harness routing prevent blocking movement of pawls, Make sure harness is routed properly above passenger footwell air duct before connecting
  79. Install glove box into IP carrier
    Note
    3x clips
  80. Install screws securing glove box assembly to IP carrier
    Note
    6x screws, T20, 2.3 Nm
  81. Install main decor assembly
    Note
    15x clips, 1x center clip
  82. Install LH air wave bezel cap to main decor assembly
    Note
    2x clips, Newer vehicles are equipped with solid bezel.
  83. Install LH IP end cap
    Note
    3x clips
  84. Install RH air wave bezel cap to main decor assembly
    Note
    2x clips, Newer vehicles are equipped with solid bezel.
  85. Install RH IP end cap
    Note
    3x clips
  86. Install passenger knee air bag onto vehicle
    Note
    1x connector, Use caution not to damage connector and harness, Support knee air bag while connecting connector
  87. Install bolts securing passenger knee air bag to vehicle
    Note
    4x patch bolts, E10, 8 Nm, Install new patch bolts, 2x screws, T20, 2 Nm, 1x push clip, If vehicle equipped with T30 bolts update to E10
  88. Install RH footwell cover assembly
    Note
    2x connectors
  89. Install RH footwell assembly onto IP
    Note
    4x push clips
  90. Connect first responder loop and LV battery
    Note
    2x connectors, Secure FRL first, Seat LV battery connection and push black connector lock inwards to secure, Engage green locking tab when fully seated
  91. Install rear apron
    Note
    12x clips
  92. Close hood
  93. Move RH front seat to original position
  94. Verify operation of windshield washers and wipers
  95. Clear DAS Calibration through UI
    Note
    Controls > Service > Camera Calibration, Select Clear Calibration, Verify calibration was cleared successfully, Wait for prompt to disappear automatically before continuing, Calibration in Progress message and progress icon will appear during the next drive cycle
  96. Vehicle will need to be driven by customer to complete the calibration procedure. During this time DAS functions will be completely unavailable
