Actuator - Intake (Remove and Replace)

Correction code 18102002 4.44 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1810 - Cabin HVAC

Remove

  1. Remove the HVAC assembly. See HVAC Assembly (Non-Heat Pump) (Remove and Replace).
  2. Disconnect the electrical harness from the intake actuator connector.
  3. Remove the screws (x2) that attach the intake actuator to the HVAC module, and then remove the actuator from the HVAC module.
    1.2 Nm (.9 lbs-ft)

Install

Installation procedure is the reverse of removal, except for the following:

  1. Connect a laptop with Toolbox to the vehicle. See Toolbox (Connect and Disconnect).
  2. Run the routine: TEST-SELF_VCRIGHT_X_HVAC-CASE-ACTUATORSvia Toolbox:(link)
  3. Disconnect the laptop from the vehicle.
  4. Press and hold the "Exit Service Mode" button to exit Service Mode Plus.
