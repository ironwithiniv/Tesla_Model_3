Charge Port Components (Harness Type to Busbar Type) (Retrofit)

Correction code 44010006 0.84 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Note
This procedure can only be used in conjunction with the appropriate HV battery (Remove and Replace) procedure. Use this code as an add-on code. Do not use it individually.
Parent topic: HV Battery Replacement - Add-On Procedures

Remove

  1. Open the trunk lid.
  2. Remove the 2nd row LH seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  3. Remove the trunk garnish. See Garnish - Trunk (Remove and Replace).
  4. Remove the trunk load floor. See Trim - Floor - Trunk (Remove and Replace).
  5. Remove the trunk sill trim. See Trim - Sill - Trunk (Remove and Replace).
  6. Remove the LH trunk side trim. See Trim - Side - Trunk - LH (Remove and Replace).
  7. Protect the seat cushion.
  8. Remove and discard the charge port ECU. See ECU - Charge Port (Remove and Replace).
  9. Pull the manual release cable off of the hold down clip.
    Note
    Pull the cable up and away from the hold down clip or pull up vertically away from the charge port assembly.
  10. Release the LV harness clip from the charge port closeout panel.
  11. Remove and discard the charge port closeout panel (7x tabs).
    Note
    Work around perimeter with plastic trim tool to disengage the tabs. May need to pry.
  12. Remove and discard the harness-type charge port assembly and the jumper harness. See:
    • Charge Port (GB) (Remove and Replace)
    • Charge Port (Busbar Type) (NACS) (Remove and Replace)
    • Charge Port (Busbar Type) (CCS) (Remove and Replace)
  13. Remove the charge port to HV battery HV harness. See HV Harness Assembly - Charge Port to HV Battery (Three-Phase) (Remove and Replace).

Install

  1. Install the new charge port ECU and install new charge port jumper harness to ECU. See ECU - Charge Port (Remove and Replace).
  2. Install the new busbar-type charge port assembly. See:
    • Charge Port (GB) (Remove and Replace)
    • Charge Port (Busbar Type) (NACS) (Remove and Replace)
    • Charge Port (Busbar Type) (CCS) (Remove and Replace)
  3. Install the new busbar assembly. See:
    • Busbars - Charge Port to HV Battery (NACS) (Remove and Replace)
    • Busbars - Charge Port to HV Battery (CCS) (Remove and Replace)
    • Busbars - Charge Port to HV Battery (GB) (Remove and Replace)
  4. Install a new charge port safety cap. See Safety Cap - Busbar - Charge Port to HV Battery (Remove and Replace).
  5. Install the LH trunk side trim. See Trim - Side - Trunk - LH (Remove and Replace).
  6. Install the trunk sill trim. See Trim - Sill - Trunk (Remove and Replace).
  7. Install the trunk load floor. See Trim - Floor - Trunk (Remove and Replace).
  8. Install the trunk garnish. See Garnish - Trunk (Remove and Replace).
  9. Install the 2nd row LH seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  10. Close the trunk lid.
