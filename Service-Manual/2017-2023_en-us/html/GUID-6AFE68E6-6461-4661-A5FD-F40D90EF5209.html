Brake Pads and Rotors - Front - Set (Remove and Replace)

Correction code 33010905 1.02 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-02-12: Updated steps to move caliper off of the knuckle. Full removal is not required.
  • 2025-07-01: Added correct step for brake burnishing.
  • 2023-10-12: Reorganized the procedure.
Parent topic: 3301 - Brake Discs and Calipers

Remove

  1. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Place absorbent material under the brake booster and reservoir area.
  4. Remove the LH and RH wheel caps. See Cap - Wheel (Remove and Replace).
  5. Remove the LH and RH wheels. See Wheel Assembly (Remove and Install).
  6. Remove the LH and RH front brake pad kits. See Brake Pad Kit - Front (Base Brakes) (Remove and Replace) or Brake Pad Kit - Front (Sport Brakes) (Remove and Replace).
  7. Remove the bolt that secures the LH front brake hose to the knuckle.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  8. Remove and discard the bolts (x2) that secure the LH front brake caliper to the front knuckle.
    Tip
    Use of the following tool(s) is recommended:
    • External Torx E18
  9. Gently hang the caliper off to the side with an S-hook.
    CAUTION
    Make sure the brake caliper and hoses are not twisted when hanging the caliper or during reinstallation, as this can damage the brake hose.
  10. Remove the LH and RH front rotors. See Brake Rotor - Front - LH (Remove and Replace).

Install

  1. Install the LH and RH front rotors. See Brake Rotor - Front - LH (Remove and Replace).
  2. Mount the LH front brake caliper onto the front knuckle. Install and torque new bolts (x2).
    Tip
    Use of the following tool(s) is recommended:
    • External Torx E18
    94 Nm (69.3 lbs-ft)
  3. Install and torque the bolt that secures the LH front brake hose to the knuckle.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
    5 Nm (3.7 lbs-ft)
  4. Install the LH and RH front brake pad kits. See Brake Pad Kit - Front (Base Brakes) (Remove and Replace) or Brake Pad Kit - Front (Sport Brakes) (Remove and Replace).
  5. Install the LH and RH wheel caps. See Cap - Wheel (Remove and Replace).
  6. Repeatedly press the brake pedal until firm.
  7. Inspect the brake fluid level and top off as necessary.
  8. Remove the absorbent material from under the brake booster and reservoir area.
  9. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  10. Remove the vehicle from the 2 post lift. See Raise Vehicle - 2 Post Lift.
  11. Burnish the brakes. See Brake Pads - Burnishing.
    Note
    During vehicle driving, make sure that proper brake pedal feel and performance is achieved.
    Note
    Add the correction code for brake pad burnishing 33013000 as a separate correction within the same activity to the Service Visit.
