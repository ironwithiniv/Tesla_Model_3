Actuator - Latch - Hood - Primary (Remove and Replace)

Correction code 11355202 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1135 - Latches Strikers and Pinch Sensors

Remove

Note
If the hood latch does not open electronically, use the manual front trunk tool to open the hood. Refer to the 1130534-00-A Tool Profile for details.
  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Remove the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  3. Remove the hood latch cover. See Cover - Hood Latch (Remove and Replace).
  4. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  5. Release the primary hood latch actuator cable from the hood latch.
    Note
    Release the clip before removing the primary latch actuator cable from the hood latch arm.
  6. Disconnect the electrical harness from the primary hood latch actuator connector.
  7. Release the clip that attaches the primary hood latch actuator electrical connector to the body.
  8. Remove the bolts that attach the primary hood latch actuator to the front end carrier, and remove the actuator from the vehicle.
    5 Nm (3.7 lbs-ft)

Install

Installation procedure is the reverse of removal.
