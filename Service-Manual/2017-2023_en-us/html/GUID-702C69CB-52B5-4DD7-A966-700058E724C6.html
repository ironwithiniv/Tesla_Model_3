Noise Absorber - Motor Bay - Front (Remove and Replace)

Correction code 12010102 2.76 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1133569-00-A Pliers, Clip Removal
  • 2025-01-08: Updated LH front door harness link to main front harness and added connector image for clarity.
Parent topic: 1201 - Wheel Arch Liners

Remove

  1. Remove the brake booster. See Electromechanical Brake Booster Assembly (Non-Heat Pump) (LHD) (Remove & Replace).
  2. Remove the windshield washer reservoir. See Reservoir - Windshield Washer (Remove and Replace).
  3. Remove the steering column control module. See Module - Steering Column Control (Remove and Replace).
  4. Release coolant hoses from car computer. See GUID-994B4C5E-5DBE-4BAB-A037-D142FE9AF2FF.html.
  5. Release the black connector from the right body controller and disconnect. See GUID-514D8D56-A8EC-47C0-8BE1-D862251DB817.html.
  6. Remove the front dash noise absorber from the vehicle.

Install

  1. Install the front dash noise absorber from the vehicle.
  2. Connect black connector from right body controller and disconnect. See Harness - Door - Front - LH (Remove and Replace).
  3. Connect coolant hoses from car computer. See GUID-994B4C5E-5DBE-4BAB-A037-D142FE9AF2FF.html.
  4. Install the steering column control module. See Module - Steering Column Control (Remove and Replace).
  5. Install the windshield washer reservoir. See Reservoir - Windshield Washer (Remove and Replace).
  6. Install the brake booster. See Electromechanical Brake Booster Assembly (Non-Heat Pump) (LHD) (Remove & Replace).
