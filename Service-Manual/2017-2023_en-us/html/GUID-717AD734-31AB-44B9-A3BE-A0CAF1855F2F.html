Coax Cable - Side Repeater - Front - RH (Overlay) (Remove and Replace)

Correction code 17403112 FRT 1.68 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.

Parent topic: 1710 - Harnesses

Overlay

  1. Raise and support vehicle
    Note
    remove charging equipment
  2. Open both front doors and lower both front windows.
  3. Move RH front seat backward
  4. Open hood
    Note
    Press "Open" button on touchscreen to release latch, Lift lid manually
  5. Remove rear apron
    Note
    12x clips, Only store rear apron visible face upwards
  6. Remove cabin intake upper duct assembly
    Note
    3x clips, Some configurations may come with 4x clips
  7. Remove closeout panel from frunk assembly
    Note
    4x clips, 1x connector, Frunk safety switch, 3x guide tabs, Grab closeout panel from bottom then pull it upward to release clips, Disconnect switch
  8. Remove frunk assembly carpet
    Note
    Note: Not all Model 3 vehicles have a frunk carpet installed
  9. Remove bolts securing frunk assembly
    Note
    7x bolts, 10mm, 5 Nm
  10. Remove frunk assembly from vehicle
    Note
    12x clips, Replace any clips if broken or missing, Number of clips may vary on older vehicles
  11. Remove the cowl screen. See Panel - Cowl Screen (Remove and Replace).
  12. Remove RH front wheel center cap
    Note
    1x cap
  13. Loosen RH front wheel
    Note
    5x nuts, 21mm, 175 Nm
  14. Raise vehicle partially and lower lift onto locks
    Note
    Set vehicle to comfortable working height, Make sure there's an audible click of the locks on both sides before lowering, Otherwise vehicle may tilt to the side
  15. Remove RH front wheel
    Note
    5x nuts, 21mm, 175 Nm
  16. Partially remove RH front wheel liner
    Note
    6x clips, 1x bolt, 10mm, 5 Nm, Newer vehicles may be equipped with 2x push clips securing lower portion of liner to body
  17. Disconnect front harness connectors for RH side repeater and camera
    Note
    2x connectors
  18. Power off vehicle from center display
    Note
    Via Controls > Safety > Power Off, Select Power Off button at warning dialog box
  19. Disconnect LV battery
    Note
    2x connectors, Lift up and release green locking tab, Pull black connector lock outwards to release connection
  20. Disconnect service disconnect
    Note
    1x connector, Release locking tab
  21. Remove fresh air intake assembly
    Note
    2x studs, Lift cowl as needed
  22. Remove LH IP end cap
    Note
    3x clips
  23. Remove LH air wave bezel cap from main decor assembly
    Note
    2x clips, Newer vehicles are equipped with solid bezel.
  24. Remove RH IP end cap
    Note
    3x clips
  25. Remove RH air wave bezel cap from main decor assembly
    Note
    2x clips, Newer vehicles are equipped with solid bezel.
  26. Remove main decor assembly
    Note
    15x clips, Entire decor does not need to come off for glove box removal, If you lift RH side of decor then you will have access to 3x torx screws securing top of glove box, Replace securing clips as needed
  27. Release RH footwell assembly from IP
    Note
    4x push clips
  28. Remove RH footwell assembly
    Note
    2x connectors
  29. Remove bolts securing passenger knee air bag onto vehicle
    Note
    4x patch bolts, T30, 8 Nm, Discard after removal, 2x screws, T20, 2 Nm, 1x push clip, Newer vehicles have 4x E10 patch bolts
  30. Remove passenger knee air bag from vehicle
    Note
    1x connector, Release locking tab, Connector release may vary
  31. Remove screws securing glove box assembly to IP carrier
    Note
    6x screws, T20, 2.3 Nm
  32. Disconnect glove box assembly connectors
    Note
    3x electrical connectors
  33. Remove glove box from IP carrier
    Note
    3x clips
  34. Disconnect glove box USB cable from car computer
    Note
    1x connector, Depress latch on top of USB cable to release internal latches, Then release from car computer
  35. Remove clip securing passenger footwell air duct and rotate for access
    Note
    1x push clip, With glovebox installed there is not sufficient room to fully remove passenger footwell duct
  36. Disconnect RH upper duct thermistor from RH IP air wave duct
    Note
    1x connector
  37. Remove RH IP air wave duct
    Note
    2x push clips
  38. Release windshield heater connecter
    Note
    1x connector
  39. Release RH grommet from body
  40. Remove electrical tape securing harness bundle to rubber dust boot
    Note
    Use a razor blaze, carefully cut electrical tape away to expose rubber dust boot
  41. Remove locking pin from connector
    Note
    Carefully pry pin out of connector and fully remove locking pin
  42. Remove coax cable needed for the side repeater overlay terminal 2 (RHS)
    Note
    Inspect all components for damage
  43. Apply harness tape onto RH coax overlay cable before installation
    Note
    Use Anti-abrasion tape and wrap the entire length of the coax cable to protect the cable for damage when it is in the vehicle
  44. Position RH coax overlay cable into place, Place through RH wheel liner
    Note
    Pull till you have roughly 6 inches of cable towards the interior of the vehicle
  45. Pull RH coax overlay cable through RH grommet harness
    Note
    Pull harness toward car computer under RH grommet main harness
  46. Tape coax overlay onto fish nylon tape
  47. Pull RH coax overlay cable through bulkhead and into interior cabin
  48. Remove nylon fish tape
    Note
    Remove tape the pull nylon fish tape out of vehicle
  49. Disconnect side repeater cameras connector from car computer
    Note
    1x locking connector
  50. Remove locking pin from side repeater cameras connector
    Note
    Carefully pry pin out of connector and fully remove locking pin
  51. Remove coax terminal 2 (RHS) cable from connector
    Note
    Inspect all components for damage
  52. Insert new side repeater coax terminal 2 (RHS) cable onto side repeater cameras connector
    Note
    Ensure both coax cables are fully seated into connector, Audible locking and flush mounting to confirm
  53. Secure locking pin to connector
    Note
    Align tabs of lock in connector housing, Ensure flush installation of locking pin to connector housing
  54. Connect side repeater cameras connector onto car computer
    Note
    1x locking connector
  55. Position RH coax overlay cable onto frunk main harness grommet, Secure cable onto harness using zip ties
    Note
    3x zip-ties, Trim off excess material after harness has been secured
  56. Cut off the vehicle side repeater coax terminal and tape to vehicle harness
    Note
    Cut the coax connector only
  57. Connect front harness connectors for RH side repeater and camera
    Note
    2x connectors
  58. Secure RH grommet from body
    Note
    Use electrical tape to wrap the end of the dust boot
  59. Secure windshield heater connector
    Note
    1x connector
  60. Install RH front wheel liner to vehicle
    Note
    6x clips, 1x bolt, 10mm, 5 Nm, Newer vehicles may be equipped with 2x push clips securing lower portion of liner to body
  61. Install RH front wheel
    Note
    5x nuts, 21mm, 175 Nm, Start lug nuts by hand before using power tool, Torque at later step
  62. Lower vehicle until tires are touching ground
    Note
    Raise lift off locks, then hold lock release lever to keep locks free while vehicle is lowered
  63. Torque RH front wheel
    Note
    5x nuts, 21mm, 175 Nm
  64. Install RH front wheel center cap
    Note
    1x cap, Verify emblem is aligned with valve stem
  65. Install the cowl screen. See Panel - Cowl Screen (Remove and Replace).
  66. Install fresh air intake assembly
    Note
    2x studs, Lift cowl as needed
  67. Install frunk assembly to vehicle
    Note
    12x clips, Make sure frunk assembly is fully seated onto clips, Number of clips may vary on older vehicles, Ensure A/C compressor HVIL harness is not pinched between frunk assembly and thermal beam, replace any damaged clips
  68. Install bolts securing frunk assembly
    Note
    7x bolts, 10mm, 5 Nm
  69. Install frunk assembly carpet
  70. Install frunk close out panel
    Note
    4x clips, 1x connector, Frunk safety switch, 3x guide tabs, Align 3x tabs then push downward to secure clips
  71. Install cabin intake upper duct assembly
    Note
    3x clips, Some configurations may come with 4x clips
  72. Connect glove box USB cable to car computer
    Note
    1x connector
  73. Re-position and secure the passenger footwell air duct
    Note
    1x push clip
  74. Install RH IP air wave duct
    Note
    2x push clips
  75. Connect RH upper duct thermistor to RH IP air wave duct
    Note
    1x connector
  76. Connect glove box assembly connectors
    Note
    3x connectors, New puddle lamp harness routing prevent blocking movement of pawls, Make sure harness is routed properly above passenger footwell air duct before connecting
  77. Install glove box into IP carrier
    Note
    3x clips
  78. Install screws securing glove box assembly to IP carrier
    Note
    6x screws, T20, 2.3 Nm
  79. Install main decor assembly
    Note
    15x clips, 1x center clip
  80. Install LH air wave bezel cap to main decor assembly
    Note
    2x clips, Newer vehicles are equipped with solid bezel.
  81. Install LH IP end cap
    Note
    3x clips
  82. Install RH air wave bezel cap to main decor assembly
    Note
    2x clips, Newer vehicles are equipped with solid bezel.
  83. Install RH IP end cap
    Note
    3x clips
  84. Install passenger knee air bag onto vehicle
    Note
    1x connector, Use caution not to damage connector and harness, Support knee air bag while connecting connector
  85. Install bolts securing passenger knee air bag to vehicle
    Note
    4x patch bolts, E10, 8 Nm, Install new patch bolts, 2x screws, T20, 2 Nm, 1x push clip, If vehicle equipped with T30 bolts update to E10
  86. Install RH footwell cover assembly
    Note
    2x connectors
  87. Install RH footwell assembly onto IP
    Note
    4x push clips
  88. Connect first responder loop and LV battery
    Note
    2x connectors, Secure FRL first, Seat LV battery connection and push black connector lock inwards to secure, Engage green locking tab when fully seated
  89. Install rear apron
    Note
    12x clips
  90. Close hood
  91. Move RH front seat to original position
  92. Clear DAS Calibration through UI
    Note
    Controls > Service > Camera Calibration, Select Clear Calibration, Verify calibration was cleared successfully, Wait for prompt to disappear automatically before continuing, Calibration in Progress message and progress icon will appear during the next drive cycle
  93. Vehicle will need to be driven by customer to complete the calibration procedure. During this time DAS functions will be completely unavailable
