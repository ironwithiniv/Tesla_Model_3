Duct - Footwell - RH (LHD) (Remove and Replace)

Correction code 18108702 0.36 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1810 - Cabin HVAC

Remove

  1. Remove the passenger knee airbag. See Airbag - Knee - Front Passenger (Remove and Replace).
  2. Use a trim tool to release the push clip that attaches the RH footwell duct to the HVAC module, and then remove the RH footwell duct from the vehicle.

Install

Installation procedure is the reverse of removal.
