Bracket - Radar - Front (Remove and Replace)

17201802 0.78 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1720 - Radar Sensor

Torque Specifications

Table 1. Torque Specifications: Bracket - Radar - Front (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts that attach the front radar bracket to the front end carrier
8 Nm (5.9 lbs-ft)
  • External Torx Plus EP10
 Reuse
  • 2026-09-18: Updated the tool required to remove the x2 bolts (EP10, 8 Nm) securing the FEM radar bracket to the vehicle.

Remove

  1. Remove the front radar sensor. See Sensor - Radar - Front (Remove and Replace)
  2. Remove the bolts that attach the front radar bracket to the front end carrier, and then remove the radar bracket from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • External Torx Plus EP10

Install

  1. Install the bolts that attach the front radar bracket to the front end carrier.
    8 Nm (5.9 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • External Torx Plus EP10
  2. Install the front radar sensor. See Sensor - Radar - Front (Remove and Replace)
