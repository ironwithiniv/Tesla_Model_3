ECU - Headlight - LH (Remove and Replace)

Correction code 17400812 0.65 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1740 - Exterior Lights

Remove

  1. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  2. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  3. Remove the LH and RH front wheels. See Wheel Assembly (Remove and Install).
  4. Remove the front fascia. See Fascia - Front (Remove and Install).
  5. Remove the LH headlight assembly. See Headlight - LH (Remove and Replace).
  6. Remove the screws (x3) that attach the headlight ECU to the LH headlight assembly.
  7. Release the electrical connector that connects the headlight ECU to the LH headlight assembly, and then remove the headlight ECU from the LH headlight assembly.
    Note
    If necessary, remove the seal from the headlight assembly.
    Note
    Release the locking tab, and then pry the electrical connector with a flat head screwdriver.

Install

  1. Connect the LH headlight ECU connector, and then position the ECU onto the headlight.
    Note
    Position the seal to the headlight ECU, if necessary.
    Note
    Align the electrical connector to the headlight ECU, and then close the locking tab while pushing the connector into the headlight ECU.
    Note
    Make sure that the electrical connector and locking tab are fully seated.
    Note
    Press the headlight ECU downward, and then turn it to align the fastener holes and anti-rotating guides.
  2. Install the screws (x3) that attach the headlight ECU to the LH headlight assembly.
    2 Nm (1.5 lbs-ft)
  3. Install the LH headlight assembly. See Headlight - LH (Remove and Replace).
  4. Install the front fascia. See Fascia - Front (Remove and Install).
  5. Install the LH and RH front wheels. See Wheel Assembly (Remove and Install).
  6. Reinstall the vehicle firmware. See Software Reinstall - Touchscreen.
  7. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  8. Install the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  9. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  10. Adjust the headlights:
    • Headlights - Adjust - NA (Tool Method)
    • Headlights - Adjust - NA (Wall Method)
    • Headlights - Adjust - EMEA (Tool Method)
    • Headlights - Adjust - EMEA (Wall Method)
    • Headlights - Adjust - Global (Tool Method)
    • Headlights - Adjust - Global (Wall Method)
