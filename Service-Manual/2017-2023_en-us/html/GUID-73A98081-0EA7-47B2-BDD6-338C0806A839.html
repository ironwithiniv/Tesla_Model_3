Seal - Secondary - Rear Door - LH (Remove and Replace)

Correction code 11705402 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2023-08-30: Added a note to discard the old seal.
Parent topic: 1170 - Seals Body Closures

Remove

  1. Open the LH rear door.
  2. Release the LH rear glass run seal clips (x4) to fully access the LH rear door secondary seal.
  3. Use narrow-width tape to carefully mark the location of the secondary seal around the door.
    CAUTION
    Make sure that the edge of the tape accurately follows the edge of the seal.
  4. Release the ends of the door secondary seal from the ends of the inner belt seal.
  5. Slowly peel the length of the secondary seal from the perimeter of the rear door.
    Note
    Discard the seal as it can not be reused.
  6. Clean any remaining adhesive or residue from the rear door.
    Note
    If needed, carefully use the following tools to clean adhesive or residue:
    • 1071510-00-AWHEEL, STRIPE OFF
    • 1076972-00-A4 Piece Non-Marring Scraper Set
    • 2151853-00-A3M PN38180 Glue Cleaner_230G
    • 2150371-00-AIPA Wipers

Install

  1. Use IPA wipes to clean the LH rear door secondary seal installation path.
    Note
    Allow 1 minute of dry time.
  2. Peel a short section of seal backing and insert the end of the seal into the rear of the inner belt seal.
    Note
    Make sure that the open edge of the seal is facing the inside of the door.
  3. Peel the seal backing and carefully position the edge of the seal to the edge of the marking tape while working around the rear door.
    Note
    Do not stretch the seal as it is applied to the door.
  4. Insert the end of the seal into the front of the inner belt seal.
    Note
    Make sure the drain holes on the seal are at the bottom of the door.
  5. Use a seam roller to attach the seal to the rear door.
  6. Remove the marking tape from the rear door.
  7. Install the LH rear glass run seal clips (x4) to fully access the LH rear door secondary seal.
