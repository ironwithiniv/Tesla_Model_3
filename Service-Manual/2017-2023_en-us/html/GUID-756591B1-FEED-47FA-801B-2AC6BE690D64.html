Connectivity Board - Car Computer (HW3) (Remove and Replace)

Correction code 21152902 1.08 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-06-06: Released new procedure.
Parent topic: 2115 - Car Computer

Remove

  1. Open the doors and lower the windows.
  2. Remove 2nd row seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  3. Remove the rear apron. See Underhood Apron - Rear (Remove and Replace).
  4. Remove the fresh intake duct. See Duct - Fresh Intake (Remove and Replace).
  5. Remove and discard nuts that attach the car computer to the bulkhead.
  6. Place absorbent material below the car computer coolant hose connections to collect any spilled coolant.
  7. Disconnect 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  8. Remove the main instrument panel decor trim. See Decor Trim - Instrument Panel - Main (Remove and Replace).
  9. Remove the RH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  10. Release the passenger footwell cover. See Cover - Footwell - Passenger (LHD) (Remove and Replace).
  11. Remove the glove box. See Glove Box - Without Knee Airbags (Remove and Replace), Glove Box - With Knee Airbags (Non-Heat Pump) (Remove and Replace) or Glove Box - With Knee Airbags (Heat Pump) (Remove and Replace).
  12. Remove the passenger footwell air duct.
    Note
    1x push clip
  13. Remove the RH instrument panel air wave duct.
    Note
    2x push clips.
  14. Put on an ESD wrist strap and connect it to vehicle ground.
  15. Disconnect the connectors (x2) of the passenger air bag assembly.
  16. Release the harness clips (x4) from the car computer.
  17. Disconnect the connectors (x4) from the top cover of the car computer.
  18. Slide the car computer inward to allow access to the connectors and harness clips.
  19. Remove the car computer shroud, if equipped.
  20. Remove the fasteners (x4) that attach the car computer cover to the car computer body.
  21. Remove the lower port cover and fastener.
    Note
    Discard screw after removal
  22. Remove and discard the top cover fasteners (x3).
  23. Lift the lower portion of the cover up and slide the cover out.
  24. Remove and discard the connectivity board mounting screws (x5).
  25. Slide the connectivity board out to separate it from the PCB connector and remove the board from the car computer.

Install

  1. Slide the connectivity board in to the PCB connector
    Note
    1x connector
  2. Install new mounting screws (x5) to secure the connectivity board.
    0.7 Nm (6 lbs-in)
  3. Slide the top cover onto the car computer assembly.
    Note
    Top cover must be underneath top gasket seal
  4. Install new top cover mounting screws (x3).
    1.4 Nm (1.0 lbs-ft)
  5. Install a new screw to attach the lower port cover.
    1.4 Nm (1.0 lbs-ft)
  6. Install new nyloc nuts that attach the car computer cover to the car computer body bracket.
    3.5 Nm (2.6 lbs-ft)
  7. Install the car computer shroud onto the car computer.
  8. Slide the car computer into position on bulkhead.
  9. Install the connectors (x4) to the top cover of the car computer.
  10. Attach the harness clips (x2) to the car computer
  11. Install the passenger air bag connectors (x2).
  12. Disconnect the ESD wrist strap from vehicle ground and remove it from your wrest.
  13. Remove the absorbent material underneath the car computer coolant lines.
  14. Install new nyloc nuts (x4) to attach the car computer to the bulkhead.
    7.1 Nm (5.2 lbs-ft)
  15. Connect 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  16. Connect a laptop with Toolbox 3 to the vehicle.
  17. Select the"Actions" tab and search for "Modem Health Check"
    Note
    In tab 'PING-BASH_MODEM_HEALTH_CHECK' Click ''Run''
  18. Allow the routine to complete. Once the routine has completed, select "Pass" then select ''stdout''.
    Note
    Review its output and search Modem Version, If the Version is B233, the Modem needs to be flashed before continuing. If the Version is B040 or above, continue to the next step. Ensure the vehicle FW is above Version 2020.40.9
  19. Disconnect Toolbox 3 from the vehicle.
  20. Check function of LTE.
    Note
    Ensure vehicle connects to LTE. If connected to WiFi, tap the WiFi indicator on the touchscreen and switch to LTE.
  21. Install the RH IP air wave duct.
  22. Install the passenger footwell air duct.
  23. Install the glove box. See Glove Box - Without Knee Airbags (Remove and Replace), Glove Box - With Knee Airbags (Non-Heat Pump) (Remove and Replace) or Glove Box - With Knee Airbags (Heat Pump) (Remove and Replace).
  24. Install the passenger knee airbag cover.
  25. Install the passenger knee airbag cover screws (x2).
    2 Nm (1.5 lbs-ft)
  26. Install the passenger footwell cover. See Cover - Footwell - Passenger (LHD) (Remove and Replace).
  27. Install the RH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  28. Install the main instrument panel decor trim. See Decor Trim - Instrument Panel - Main (Remove and Replace).
  29. Install the fresh intake duct. See Duct - Fresh Intake (Remove and Replace).
  30. Install the rear apron. See Underhood Apron - Rear (Remove and Replace).
  31. Install 2nd row seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
