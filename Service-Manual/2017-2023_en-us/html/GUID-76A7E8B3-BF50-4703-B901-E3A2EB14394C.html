Bolt - Steering Wheel to Upper Column (Remove and Replace)

Correction code 32051842 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-03-13: Released new procedure to support Toolbox article 8743800 on steering column lateral play.
Parent topic: 3205 - Upper Column, Steering Wheel

Remove

  1. Remove the driver airbag. See Airbag - Driver (Remove and Replace).
  2. Remove and discard the bolt that attaches the steering wheel to the steering column.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm hex

Install

  1. Install a new bolt (1036655-00-A) that attaches the steering wheel to the steering column.
    80 Nm (59.0 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm hex
  2. Install the driver airbag. See Airbag - Driver (Remove and Replace).
