Bushing - Rear Drive Unit - RH (3DU) (Remove and Replace)

Correction code 40012402 4.08 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1137785-00-A Kit, Drive Unit Bushing R&R, Model 3
Parent topic: 4001 - Rear Drive Unit Assembly

Remove

  1. Remove the rear drive unit. See Drive Unit - Rear (3DU) (Remove and Install).
  2. Position the rear drive unit above an empty rear drive unit crate.
    Note
    Use a pallet if no crate is available.
  3. Install the bushing removal tool on the RH bushing.
    Note
    Use cups "A", "C", and "D" when assembling the special tool, as shown.
  4. Turn the bearing-side bushing removal tool nut with a wrench while holding the other nut in place.
  5. When the bushing has been pushed out of the drive unit, separate the bushing removal tool, and then remove it from the drive unit.

Install

  1. Set up the bushing tool to press in the new bushing.
    Note
    Use cups "D" and "E" when assembling the special tool, as shown.
  2. Turn the nut on the thrust washer to press the new bushing into the drive unit.
  3. Separate the bushing tool, and then remove it from the drive unit.
  4. Install the rear drive unit. See Drive Unit - Rear (3DU) (Remove and Install).
  5. Check the vehicle wheel alignment, and adjust if necessary. See Four Wheel Alignment Check.
