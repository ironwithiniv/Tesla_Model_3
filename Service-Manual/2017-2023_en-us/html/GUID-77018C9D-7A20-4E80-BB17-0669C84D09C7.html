IP Carrier (Remove and Install)

Correction code 140521011.86 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2023-08-08: Deleted step to remove the driver and front passenger seats.
Parent topic: 1405 - Instrument Panel

Torque Specifications

Table 1. Torque Specifications: IP Carrier (Remove and Install)
Description Torque Value Recommended Tools Reuse/Replace Notes
Front passenger airbag to cross car beam bolt
8 Nm (5.9 lbs-ft)
  • External Torx E10 or Torx T30 socket
  • 4 in extension
  • ¼ in std ratchet
  • ¼ in torque wrench (installation only)
Replace
IP carrier to cross car beam screws
2.3 Nm (1.7 lbs-ft)
  • Torx T20 socket
  • 4 in extension
  • ¼ in std ratchet
  • ¼ in torque wrench (installation only)
Reuse

Remove

  1. Open all doors and lower all windows.
  2. Remove the center console. See Center Console (Remove and Install)
  3. Remove the LH and RH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  4. Remove the LH and RH upper A-pillar trims. See Trim - A-Pillar - Upper - LH (Remove and Replace).
  5. Disconnect LV power. See 12V/LV Power (Disconnect and Connect).
  6. Remove the touchscreen. See Touchscreen (Remove and Replace).
  7. Remove the passenger footwell duct. See Duct - Footwell - RH (LHD) (Remove and Replace).
  8. Remove the RH air wave duct. See Duct - Air Wave - RH (LHD) (Remove and Replace).
  9. Remove the driver footwell duct. See Duct - Footwell - LH (LHD) (Remove and Replace).
  10. Remove the steering column control module. See Module - Steering Column Control (Remove and Replace).
  11. Remove the LH front vent. See Vent - Front - LH (Remove and Replace).
  12. Remove the RH front vent. See Vent - Front - RH (Remove and Replace).
  13. Remove the LH and RH dash speakers. See Speaker - Dash - LH (Remove and Replace).
  14. Remove the center dash speaker. See Speaker - Dash - Center (Remove and Replace).
  15. If equipped, remove the dash tweeter. See Tweeter - Dash (Remove and Replace).
  16. Disconnect the electrical wiring harness from the front passenger airbag connectors (x3).
    Note
    Vehicles in regions other than North America have only 2 connectors.
  17. Remove and discard the bolts (x4) that attach the front passenger airbag to the cross car beam.
    Tip
    Use of the following tool(s) is recommended:
    • External Torx E10 or Torx T30 socket
    • 4 in extension
    • ¼ in std ratchet
    • ¼ in torque wrench (installation only)
  18. Remove the screws (x2) that attach the instrument panel carrier to the cross car beam at the front passenger airbag.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
    • 4 in extension
    • ¼ in std ratchet
    • ¼ in torque wrench (installation only)
  19. Remove the screws (x11) that attach the instrument panel carrier to the cross car beam.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
    • 4 in extension
    • ¼ in std ratchet
    • ¼ in torque wrench (installation only)
  20. Move the electrical wiring harness for the touchscreen through the instrument panel carrier.
  21. Remove the instrument panel carrier from the cross car beam, and then remove the instrument panel carrier from the vehicle.

Install

  1. With assistance, install the instrument panel carrier onto the cross car beam.
    Note
    Slide the mounting tabs on the instrument panel carrier into the brackets on the vehicle. Be cautious to clear the harness clipped at top center of HVAC assembly.
  2. Install the screws (x11) that attach the instrument panel carrier to the cross car beam.
    2.3 Nm (1.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
    • 4 in extension
    • ¼ in std ratchet
    • ¼ in torque wrench (installation only)
  3. Install the screws (x2) that attach the instrument panel carrier to the cross car beam at the front passenger airbag.
    2.3 Nm (1.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
    • 4 in extension
    • ¼ in std ratchet
    • ¼ in torque wrench (installation only)
  4. Install the bolts (x4) that attach the front passenger airbag to the cross car beam.
    8 Nm (5.9 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • External Torx E10 or Torx T30 socket
    • 4 in extension
    • ¼ in std ratchet
    • ¼ in torque wrench (installation only)
  5. Connect the electrical wiring harness to the front passenger airbag connectors (x3).
    Note
    Vehicles in regions other than North America have only 2 connectors.
  6. Install the LH and RH dash speakers. See Speaker - Dash - LH (Remove and Replace).
  7. If equipped, install the dash tweeter. See Tweeter - Dash (Remove and Replace).
  8. Install the center dash speaker. See Speaker - Dash - Center (Remove and Replace).
  9. Install the RH front vent. See Vent - Front - RH (Remove and Replace).
  10. Install the LH front vent. See Vent - Front - LH (Remove and Replace).
  11. Install the steering column control module. See Module - Steering Column Control (Remove and Replace).
  12. Install the driver footwell duct. See Duct - Footwell - LH (LHD) (Remove and Replace).
  13. Install the RH air wave duct. See Duct - Air Wave - RH (LHD) (Remove and Replace).
  14. Install the passenger footwell duct. See Duct - Footwell - RH (LHD) (Remove and Replace).
  15. Install the touchscreen. See Touchscreen (Remove and Replace).
  16. Install the LH and RH upper A-pillar trims. See Trim - A-Pillar - Upper - LH (Remove and Replace).
  17. Install the LH and RH lower A-pillar trims. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  18. Connect LV power. See 12V/LV Power (Disconnect and Connect).
  19. Install the center console. See Center Console (Remove and Install)
