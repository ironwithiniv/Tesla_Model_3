Headliner (Non-Heat Pump) (Remove and Replace)

Correction code 152031020.66 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2023-05-19: Added installation sequence and headliner shipping bag installation tip.
Parent topic: 1520 - Headliner

Remove

  1. Remove the headliner. See Headliner (Non-Heat Pump) (Remove and Install).
  2. Release the clips that attach the LH and RH headliner tweeter covers to the headliner, and remove the tweeter covers from the headliner.
  3. Disconnect the electrical harness from the front overhead console connector.
  4. Release the clips that attach the front overhead console to the headliner, and then remove the console from the headliner.
  5. Disconnect the electrical harness from the rear overhead console connector.
  6. Release the clips that attach the rear overhead console to the headliner, and then remove the console from the headliner.
  7. Release the clips that attach the LH coat hook bezel to the LH coat hook assembly, and then remove the LH coat hook assembly from the headliner.
  8. Release the clips that attach the RH coat hook bezel to the RH coat hook assembly, and then remove the RH coat hook assembly from the headliner.

Install

  1. Install the LH coat hook bezel to the LH coat hook assembly, and then fasten the clips that attach the coat hook bezel to the coat hook assembly.
  2. Install the RH coat hook bezel to the RH coat hook assembly, and then fasten the clips that attach the coat hook bezel to the coat hook assembly.
  3. Install the rear overhead console to the headliner, and then fasten the clips that attach the overhead console to the headliner.
  4. Connect the electrical harness to the rear overhead console connector.
  5. Install the front overhead console to the headliner, and then fasten the clips that attach the overhead console to the headliner.
  6. Connect the electrical harness to the front overhead console connector.
  7. Install the LH and RH headliner tweeter covers to the headliner, and then fasten the clips that attach the tweeter covers to the headliner.
  8. Install the headliner. See Headliner (Non-Heat Pump) (Remove and Install).
    Tip
    The headliner shipping bag might be useful as a "third hand" for installation.
    1. Lay the shipping bag flat with the opening toward you.
    2. Use scissors to cut both the top and bottom sides of the bag up the middle, until there is about 12 in (30 cm) left. The bag will look like a pair of pants.
    3. Open the vehicle front/rear (as appropriate) doors, set the bag on the vehicle roof, and then bring the "legs" of the bag through each doorway into the cabin.
    4. Tie the very ends of the legs together to make a very loose loop out of the cabin, over the roof, and back into the cabin. If the loop is too tight, cut a little more up the middle.
    5. Use the loop to support the headliner during installation. If the loop is too loose, tie an additional knot to reduce slack.
