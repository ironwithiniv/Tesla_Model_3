Steering Rack (Dual Motor) (RHD) (Remove and Replace)

Correction code 32012212 3.15 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-02-03: Condensed procedure by adding cross references to sub-procedures.
  • 2023-06-06: Revised procedure
Parent topic: 3201 - Steering Rack and Lower Column

Remove

  1. Prepare the vehicle for lifting, but do not raise it at this time.
  2. Open all doors and lower the windows.
  3. Move the LH and RH front seats forward.
  4. Perform the vehicle HV disablement procedure. See Vehicle HV Disablement Procedure.
  5. Remove LH front wheel center cap
  6. Loosen LH front wheel lug nuts.
  7. Loosen the nut that attaches the LH front halfshaft to the LH front hub assembly.
  8. Remove the RH front wheel center cap.
  9. Loosen RH front wheel lug nuts.
  10. Loosen the nut that attaches the RH front halfshaft to the RH front hub assembly.
  11. Set the steering wheel straight ahead and lock it in position.
  12. Remove the cabin intake upper duct assembly.
    Note
    3x clips, older vehicles may be equipped with 4x clips.
  13. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  14. Remove the bolt that attaches the steering gear assembly to the electric steering column.
  15. Slide the electric steering column upward to remove it from the steering gear assembly.
    Note
    May need to wiggle or use dead blow hammer to help separate the steering column from the steering gear assembly.
  16. Disconnect the steering gear assembly connectors (x2).
  17. Disconnect the logic connectors(x2) at the steering gear area.
  18. Remove the bolts (x6) that attach the upper portion of the front fascia to the vehicle.
  19. Remove the LH front wheel.
  20. Remove and discard the LH halfshaft nut and washers.
  21. Remove RH front wheel
  22. Remove and discard the RH front halfshaft nut and washers
    Note
    1x nut, 32mm, 245 Nm, The washers are attached to the nut, Discard after removal
  23. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  24. Remove the LH and RH wheel arch liner. See Wheel Arch Liner - Front - LH (Remove and Replace).
  25. Remove the front fascia. See Fascia - Front (Remove and Install).
  26. Remove and discard the nyloc nut that attaches the LH tie rod end to the knuckle.
  27. Remove the LH front tie rod end from the LH front knuckle.
  28. Remove and discard the nyloc nut that attaches the front stabilizer bar link to LH front stabilizer bar.
    Note
    Counter hold the ball joint with T40.
  29. Move the LH front stabilizer bar link assembly aside.
    Note
    You may need to move the stabilizer bar up/down to get the correct angle needed to remove the end link.
  30. Repeat steps 26 to 29 on the RH side of the vehicle.
  31. Install the hydraulic hub puller onto the LH front wheel studs.
    Note
    5x nuts, hand-tighten.
  32. Separate the LH front halfshaft from the LH front hub assembly and move the halfshaft aside.
  33. Install hydraulic hub puller onto RH front wheel studs
    Note
    5x nuts, hand-tighten.
  34. Separate the RH front halfshaft from the RH front hub assembly and move the halfshaft aside.
  35. Remove the front subframe. See Subframe Assembly - Front (Dual Motor) (Remove and Replace).
  36. Remove the front left bolt that attaches the steering gear assembly to the front subframe
  37. Remove the front right bolt that attaches the steering gear assembly to the front subframe.
  38. Remove the rear left bolt that attaches the steering gear assembly to the front subframe.
  39. Remove the rear right bolt that attaches the steering gear assembly to the front subframe.
  40. Remove the steering gear assembly from the front subframe.

Install

  1. Position the new steering gear assembly onto the front subframe for installation.
  2. Loosely install the rear LH and RH bolts that attach the steering gear assembly to the front subframe.
  3. Install and torque the front LH and RH bolts that attach the steering gear assembly to the front subframe (torque 47 Nm if bolt is 15 mm, torque 27 Nm if bolt is 13 mm).
    Note
    1x bolt, 15mm, 47 Nm (older version: 13mm, 27 Nm)
  4. Torque the inner bolts (x2) that attach the steering gear assembly to the front subframe (torque 75 Nm).
  5. Install the front subframe. See Subframe Assembly - Front (Dual Motor) (Remove and Install).
  6. Apply Molykote M-77 to the outboard side of the halfshafts.
    Note
    Clean if necessary. Do not apply more than 1 gram to each halfshaft.
  7. Loosely install a new nut that attaches the RH front halfshaft to the RH front hub assembly.
  8. Loosely install a new nut that attaches the LH front halfshaft to the LH front hub assembly.
  9. Loosely install the bolts (x2) that attach the RH front lower lateral link to the front subframe.
  10. Install the RH front lower compliance link to front subframe.
  11. Install the bolt and nut that attach the RH front lower compliance link to the front subframe (torque 115 Nm).
  12. Install the RH front lower lateral link and loosely install the bolt and nut that attach the RH strut to the lower control arm.
  13. Torque the bolts (x2) that attach the RH front lower lateral link to the front subframe (torque 115 Nm).
  14. Loosely install the bolts that attach the LH front lower lateral link to the front subframe.
  15. Install the LH front lower compliance link to the front subframe.
  16. Install the bolt and nut that attach the LH front lower compliance link to the front subframe (torque 115 Nm).
  17. Install the LH front lower lateral link and loosely install the bolt and nut that attach the LH strut to the lower lateral link.
  18. Torque the bolts (x2) that attach the LH front lower lateral link to the front subframe (torque 115 Nm).
  19. Install FDU ground strap and bolt to the HV battery (torque 10 Nm)
  20. Install the FDU ground strap harness clip to the FDU.
  21. Install the bolt that attaches the FDU ground strap to the FDU (torque 6 Nm).
  22. Install the FDU HV harness connector to the FDU.
    Note
    Make sure that the connector is installed far enough on the FDU manifold so the manifold alignment tooth is making contact with the connector lever.
  23. Connect the FDU HV harness connector and lock the release lever.
    Note
    Apply slight pressure to the connector as the lever is rotated into position. Move the lever to the closed position slowly and ensure the lever teeth and manifold teeth are properly meshed. There should only be a very small gap between the manifold and the connector when fully seated.
  24. Install the bolt that attaches the FDU HV harness to the FDU (torque 10 Nm).
  25. Position a coolant drain container underneath the RH front of the HV battery.
  26. Remove the plugs and connect the FDU coolant inlet hose at the RH side of the vehicle.
  27. Install the hose retaining clip for the RH side coolant hose.
    Note
    1x clip
  28. Remove coolant drain container from underneath the vehicle.
  29. Position the RH front stabilizer bar link assembly to front stabilizer bar.
  30. Install a new nyloc nut that attaches the front stabilizer bar to the RH front stabilizer bar link assembly (torque 98 Nm).
    Note
    Counter hold ball joint with T40. Mark torqued nut with a paint pen.
  31. Connect the horn connectors (x2).
  32. Position the LH front stabilizer bar link assembly to the front stabilizer bar.
  33. Install a new nyloc nut that attaches the front stabilizer bar link to LH front stabilizer bar (torque 98 Nm).
    Note
    Counter hold ball joint with T40. Mark torqued nut with a paint pen
  34. Position the LH front tie rod end to the LH front knuckle.
  35. Install a new nyloc nut that attaches the LH tie rod end to the LH front knuckle (torque 180 Nm).
  36. Position the RH front tie rod end to the RH front knuckle.
  37. Install a new nyloc nut that attaches the RH tie rod end to the RH front knuckle (torque 180 Nm).
  38. Install the front fascia. See Fascia - Front (Remove and Install).
  39. Install the LH and RH front wheel liners. See Wheel Arch Liner - Front - LH (Remove and Replace).
  40. Install the push clips for the RH front wheel liner
  41. Install the LH and RH front wheels.
  42. Raise vehicle fully and lower lift onto locks
  43. Install the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  44. Connect the logic connectors (x2) at the steering gear area.
  45. Connect the steering gear assembly connectors (x2).
  46. Connect the FDU logic connector at the LH frame rail.
  47. Remove the plugs and connect coolant hose to heat exchanger.
  48. Connect the coolant hose for the FDU heat exchanger to the superbottle.
  49. Connect 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  50. Reinstall the firmware. See Software Reinstall - Touchscreen
  51. Select the clock on the center display, or go to the Software tab, then select install now to start firmware update
  52. Once firmware redeploy is complete, Verify release notes are present on center display
  53. Slide the intermediate shaft assembly downward to install it to the steering gear assembly.
    Note
    Make sure that the intermediate shaft is aligned and fully seated.
  54. Install the bolt that attaches the intermediate shaft assembly to the steering gear assembly (torque 18 Nm).
  55. Torque the LH and RH front wheel lug nuts to 175 Nm.
  56. Torque the LH and RH front halfshaft nuts to 245 Nm).
  57. Torque LH front halfshaft nut
  58. Remove the clips (x2) that attaches the HVAC plenum outer duct.
    Note
    2x clips
  59. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  60. Perform a coolant vacuum refill. See Cooling System (Vacuum Refill).
  61. Select TEST-RESET_VCFRONTvia Toolbox:(link), click "Run", and allow routine to complete
  62. Select ‘TEST_VCFRONT_X_THERMAL-COOLANT-AIR-PURGEvia Service Mode:
    • Thermal ➜ Actions ➜ Coolant Purge Stop or Coolant Purge Start
    • Thermal ➜ Coolant System ➜ Coolant Purge Start
    via Service Mode Plus:
    • Drive Inverter ➜ Front Drive Inverter Replacement ➜ Coolant Air Purge
    • Drive Inverter ➜ Rear Drive Inverter Replacement ➜ Coolant Air Purge
    • Drive Inverter ➜ Rear Left Drive Inverter Replacement ➜ Coolant Air Purge
    • Drive Inverter ➜ Rear Right Drive Inverter Replacement ➜ Coolant Air Purge
    • Drive Unit ➜ Front Drive Unit Replacement ➜ Coolant Air Purge
    • Drive Unit ➜ Rear Drive Unit Replacement ➜ Coolant Air Purge
    via Toolbox:(link)     ’, click ‘Run’, and allow routine to complete_x000A__x000A_
  63. Inspect coolant level and top off as necessary.
    Note
    Ensure that the fluid level is 5mm above the Max line.
  64. Install superbottle cap.
  65. Install the clips (x2) that attach the HVAC plenum outer duct.
    .
  66. Install the clips that attach the cabin intake upper duct assembly.
    Note
    3x clips. Older vehicles may be equipped with 4x clips.
  67. Install the rear underhood apron.
  68. Connect 2nd row seat cushion harness connectors (x2) and install the 2nd row seat cushion.
  69. Move the LH and RH front seats to their original position.
  70. Remove the steering wheel holder.
  71. Refer to the Alignment Requirement tables to determine whether an EPAS alignment check (EC) or four wheel alignment check (AC) is necessary. If performed, add the alignment check/adjust correction code as a separate activity to the SV. See Alignment Requirement - Suspension.
