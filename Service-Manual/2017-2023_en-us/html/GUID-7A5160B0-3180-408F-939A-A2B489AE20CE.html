Thermistor - Duct - LH (Heat Pump) (Remove and Replace)

Correction code 18101102 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1810 - Cabin HVAC

Remove

  1. Disconnect LV power. See 12V/LV Power (Disconnect and Connect).
  2. Remove the pedal assembly. See Brake Pedal (Remove and Replace).
  3. Disconnect the electrical harness from the LH upper duct thermistor.
  4. Use a pry tool to release the tabs (x2) that attach the thermistor to the upper HVAC duct, and then remove the thermistor from the vehicle.

Install

  1. Position the LH upper duct thermistor on the upper HVAC duct, making sure that the mounting tabs are engaged.
  2. Connect the electrical harness to the LH upper duct thermistor.
  3. Install all components that were removed for access. See Brake Pedal (Remove and Replace).
