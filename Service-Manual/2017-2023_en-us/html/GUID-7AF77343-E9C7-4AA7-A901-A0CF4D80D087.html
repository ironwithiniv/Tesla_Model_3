Headlights and Fog Lights (Check Aiming)

  • Tesla uses different types of headlights on Model 3/Model Y. See below image for headlight identification. The SAE/ECE headlight (1) has a different reflector and lens design compared to the Global headlight (2).
  • Tesla's factory specification for headlight and fog light inclination is -1%. Check local regulations for individual country's tolerance on this value. The factory headlight aiming specification Is stamped onto the headlight/fog light housing, but not always easy to see. See images below for reference.
  • When checking headlight/fog light aiming, do not set the vehicle to the Adjust Headlights mode through the touchscreen. Doing so via Controls > Service > Adjust Headlights creates a non standard headlight beam pattern. This function should not be used for the aiming check and should only be used by trained personnel for aiming adjustment.
  • When checking headlight aiming, make sure to use the alignment markers on the headlight for vertical and horizontal alignment.
