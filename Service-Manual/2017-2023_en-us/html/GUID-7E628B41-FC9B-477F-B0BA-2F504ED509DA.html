Grub Screws - Upper Steering Column (Rework)

Correction code 32051918 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-03-11: Added tool info for vehicles built after 21 September 2021.
  • 2025-12-30: Added steps to calibrate the steering column.
  • 2025-12-08: Updated measurement method.
  • 2025-03-13: Released new procedure to support Toolbox article 8743800 on steering column lateral stiffness.

Special tools required for this procedure:

  • 1064697-00-B KIT - BRAKE ROTOR RUN OUT
  • 1080978-00-B KIT - FORCE GAUGE MARK-10
  • 2185305-00-A SKT - 3/8" DR, HEX BIT, T60 TORX (for vehicles built through 21 September 2021)
  • 2279656-00-A - 1/4" DR, SHORT BIT, T60 TORX (for vehicles built after 21 September 2021)
Parent topic: 3205 - Upper Column, Steering Wheel

Rework Procedure

  1. Move LH front seat backward.
  2. Disconnect 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  3. Remove the steering wheel. See Steering Wheel (Remove and Install).
  4. Remove the steering column upper shroud. See Shroud - Upper - Steering Column (Remove and Replace)
  5. Remove the steering column lower shroud. See Shroud - Lower - Steering Column (Remove and Replace).
  6. Locate the steering column grub screws and tighten both grub screws to 4 Nm.
  7. Re-torque the upper grub screw at the steering column.
    1. Loosen the upper grub screw by 360° (1 turn).
    2. Torque the upper grub screw to 2.4 Nm.
  8. Re-torque the lower grub screw at the steering column.
    Note
    For vehicles built through 21 September 2021, use 2185305-00-A SKT - 3/8" DR, HEX BIT, T60 TORX. For vehicles built after 21 September 2021, use 2279656-00-A - 1/4" DR, SHORT BIT, T60 TORX.
    1. Loosen the lower grub screw by 360° (1 turn).
    2. Torque the lower grub screw to 2.4 Nm.
  9. Use IPA wipes to clean the steering column area around the grub screws.
  10. Apply a piece of butyl tape on both grub screws.
    Note
    Make sure that the butyl patches make contact with both the steering column and the grub screws. Thoroughly wet out the adhesive. If needed, use a pressure roller.
  11. Install the steering column lower shroud. See Shroud - Lower - Steering Column (Remove and Replace).
  12. Install the steering column upper shroud. See Shroud - Upper - Steering Column (Remove and Replace)
  13. Install the steering wheel. See Steering Wheel (Remove and Install).
  14. Install the driver airbag. See Airbag - Driver (Remove and Replace).
  15. Connect 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  16. Install the brake rotor run-out tool onto the LH front window and steering wheel.
    Note
    Install the suction cup onto the LH front window. Apply masking tape onto the suction cup for protection, then install the brake run-out tool onto the LH front window. Align the tool horizontally with the tape on the steering wheel at the 9 o'clock position.
    Note
    Make sure that the indicator rod is properly depressed and allows travel in both directions without bottoming out. Set dial to zero.
  17. Install a zip tie onto the steering wheel.
    Note
    Apply tape around the 3 o'clock position of the steering wheel for protection and install the zip tie around to enable a lateral pull movement. Do not fully tighten the zip tie.
  18. Inspect for steering column lateral stiffness.
    1. Make sure the gauge is set to Newtons (N).
    2. Zero out the gauge.
    3. Apply a pull force of 50 N on the steering wheel in the LH lateral direction.
    4. Record the value at which the dial indicator stabilizes.
    5. Apply a push force of 50 N on the steering wheel in the RH lateral direction.
    6. Record the value at which the dial indicator stabilizes.
    7. Calculate the difference between the two values.
      • If the calculated difference is 1.5 mm or less, the steering column lateral stiffness is within the specified tolerance. Continue to the next step.
      • If the calculated difference is more than 1.5 mm, the steering column will need to be replaced to have the lateral stiffness fall within the specified tolerance.
  19. Remove the brake rotor run out tool from the LH front window and the steering wheel.
  20. Remove the zip tie and tape from the steering wheel.
  21. Remove the fender cover from the center console.
  22. Enable Service Mode. See Service Mode.
  23. Unlock the vehicle Gateway. See Gateway (Unlock).
  24. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): PROC_STEERING_COLUMN_CALIBRATIONvia Service Mode:Chassis ➜ Steering ➜ Calibrate Steering Columnvia Toolbox:(link)
  25. Exit Service Mode. See Service Mode,
  26. Add correction code 32051918 as a separate activity to the Service Visit.
