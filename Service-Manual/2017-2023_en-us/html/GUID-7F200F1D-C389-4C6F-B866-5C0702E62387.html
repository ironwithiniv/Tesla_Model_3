Glare Shield (Remove and Replace)

Correction code 15051302 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1080559-20-A TOOL, TORQUE SCREWDRIVER, 0.8-2.0NM (NA, APAC)
  • 1080559-21-A TOOL, TORQUE SCREWDRIVER, 0.8-2.0NM (EMEA)
Parent topic: 1505 - Interior Mirror and Sun Visors

Torque Specifications

Table 1. Torque Specifications: Glare Shield (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Front camera glare shield to windshield bracket fasteners
1 Nm (.7 lbs-ft)
  • Wiha TorqueVario-S 0.8 Nm - 2.0 Nm screwdriver (installation only)
  • T10 blade attachment
 Replace Fasteners have patch material

Remove

  1. Remove the lower quad camera cover. See Quad Camera Cover - Lower (Remove and Replace).
  2. Remove the rear view mirror. See Mirror - Rear View (Remove and Replace).
  3. Release the clips that attach the upper quad camera cover, disconnect the interior camera connector, and then remove the upper quad camera cover and interior camera assembly from the vehicle.
  4. Remove and discard the patch screws (x2) that attach the front camera glare shield, and then remove the glare shield from the vehicle.

Install

  1. Use glass cleaner and a clean towel to thoroughly clean the windshield area in front of the camera.
  2. Use the alignment pins to place the front camera glare shield in the correct location on the windshield bracket.
  3. Install new patch screws (x2) that attach the front camera glare shield to the windshield bracket.
    1 Nm (.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Wiha TorqueVario-S 0.8 Nm - 2.0 Nm screwdriver (installation only)
    • T10 blade attachment
  4. Connect the interior camera connector, and then install the clips that attach the upper quad camera cover to the vehicle.
  5. Install the rear view mirror. See Mirror - Rear View (Remove and Replace).
  6. Install the lower quad camera cover. See Quad Camera Cover - Lower (Remove and Replace).
