Motor - Seat Height - Driver Seat (Remove and Replace)

Correction code 13011602 0.48 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
Seat base edges are sharp and can cause personal injury. Wear cut resistant gloves when removing the seat from the vehicle, and while performing procedures that involve work on or near the seat base.
  • 2026-08-31: Revise the front passenger seat steps to allow the work to be completed without removing the seat assembly.
  • 2026-02-02: Updated the torque of the seat height motor bolts from T40 to T45/T50.
  • 2023-05-03: Added step for front passenger seat calibration and OCS calibration.

Correction code for the front passenger seat:

  • Motor - Seat Height - Front Passenger Seat (Remove & Replace), Correction code13013602, FRT0.66

Remove

  1. If performing this procedure on the front passenger seat, check firmware version: The installed firmware package must be 2023.2.11 or above for the configuration routine to populate. If it is below the target package, proceed with an OTA update.
  2. Open all four doors and lower all four windows.
  3. Remove the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
    Note
    If performing this procedure on the front passenger seat, skip this step.
  4. Remove the driver seat. See Seat Assembly - 1st Row - LH (Remove and Replace).
    Note
    If performing this procedure on the front passenger seat, skip this step.
  5. With assistance, place the driver seat on its back on a protected surface.
    Note
    If performing this procedure on the front passenger seat, skip this step.
  6. If performing this procedure on the front passenger seat, remove the front passenger seat outboard side shield. See Side Shield - Outboard - Driver Seat (Remove and Replace).
    Note
    During removal, certain steps require extra care. See the animation(s) for detailed guidance.
    Note
    LH shown, RH similar
  7. Disconnect the height motor electrical connector.
  8. Remove and discard the rear bolt that secures the LH seat height motor.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T45 socket
  9. Remove and discard the front bolt that secures the LH seat height motor, and then remove the motor from the assembly.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket

Install

  1. Install the driver seat height motor to the seat frame, and then install a new front bolt that secures the LH seat height motor.
    23 Nm (17.0 lbs-ft)
    Note
    Make sure the under seat harnesses are clear.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket
  2. Install a new rear bolt that secures the LH seat height motor.
    18 Nm (13.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T45 socket
  3. Connect the height motor electrical connector.
  4. If performing this procedure on the front passenger seat, install the front passenger seat outboard side shield. See Side Shield - Outboard - Driver Seat (Remove and Replace).
  5. Install the driver seat. See Seat Assembly - 1st Row - LH (Remove and Replace).
    Note
    If performing this procedure on the front passenger seat, skip this step.
  6. Install the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
    Note
    If performing this procedure on the front passenger seat, skip this step.
  7. If servicing the front passenger seat in a North American vehicle:
    1. Remove all objects from the front passenger seat before beginning calibration.
    2. On the vehicle touchscreen, touch Controls (Vehicle Icon) > Software and check the vehicle firmware version. If the vehicle firmware is 2023.2.11 or newer, perform a software reinstall. See Software Reinstall - Touchscreen. If the vehicle firmware is not 2023.2.11 or newer, update the vehicle firmware. See Software Update.
    3. Locally connect a laptop with Toolbox 3 to the vehicle. See Toolbox (Connect and Disconnect).
    4. Unlock the vehicle gateway. See Gateway (Unlock).
    5. In Toolbox, click on the Actions tab, and then search for "OCS".
    6. Run the PROC_OCS1P_SELF-CALIBRATIONvia Service Mode Plus:Safety & Restraints ➜ Seats ➜ OCS1P Self Capacitance Calibrationvia Toolbox:(link) routine.
    7. Click on the Actions tab, and then search for "Seat calibration".
    8. Run the PROC_VCRIGHT_SEAT-CALIBRATEvia Service Mode:Low Voltage ➜ Seats ➜ Calibrate Seatvia Toolbox:(link) routine.
    9. Disconnect Toolbox and remove the laptop from the vehicle.
  8. On the laptop, tap Controls > Service > Driver Seat, Steering & Mirrors Calibration > START to calibrate the seat.
  9. Move the seats back to the original positions, raise all four windows and close all four doors.
