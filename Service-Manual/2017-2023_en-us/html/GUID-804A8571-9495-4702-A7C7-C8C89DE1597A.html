Ancillary Bay Coolant (Drain and Refill)

Correction code 16202000 0.90 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-11-19: Removed unnecessary HV bay open path and replaced drain/refill tooling with dual-direction PCS blow-through, vacuum refill, and Service UI thermal routines.
  • 2024-07-10: Added caution for hose reconnection.
  • 2023-07-06: Updated procedure with images and standardized instructions.
Equipment:
  • 1053600-00-C Drive Unit Pressure Test Fixture
  • 1132185-00-B Kit, Coolant Leak Test Adapters, Model 3
  • 1133843-00-A Kit, Coolant Drain & Fill Adapters, M3
  • 1135762-00-A Kit, Svc Plug, Cooling Hose, Model 3
  • 1065131-00-A Kit, Battery Coolant Drain and Fill
Parent topic: 1620 - HV Battery Cooling System

Procedure

  1. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  2. Open all four doors and lower all four windows.
  3. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  4. Remove the cabin intake air duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  5. Remove the 2nd row seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  6. Enable Service Mode and unlock the vehicle gateway. See 0005 - Service Modes.
  7. On the touchscreen, select Thermal > Coolant System > Coolant Fill/Drain and select Run to run the routine. Close once the routine is completed.
    Note
    Thermal Fill Drain routine has a 5 hour time limit. If the run time exceeds 5 hours, the routine must be performed again.
  8. Disconnect the LV power. See 12V/LV Power (Disconnect and Connect).
  9. Raise the vehicle fully and lower lift onto locks.
  10. Remove the rear aero shield panel. See Panel - Aero Shield - Rear (Remove and Replace).
  11. Remove the rear HV battery skid plate. See Skid Plate - HV Battery - Rear (Remove and Replace).
  12. Position a coolant drain under the rear LH side of the HV battery.
  13. Disconnect the rear drive unit inverter inlet tube from PCS outlet hose coupling.
    Note
    Plug hose connections as needed. Coolant loss greater than 1 L will require a vacuum fill.
    Note
    If the battery is returned to Reman, please remove the special tool plug.
  14. Attach the coolant drain hose adapter to PCS outlet hose coupling.
    Note
    Use adapter with 90 degree angle. Make sure the locking tab is fully seated and the valve is open.
  15. Connect the waste coolant container hose to the drain and fill adapter.
    Note
    Push until an audible click is heard, then perform a push-pull-push test to verify the connection is fully seated.
  16. Position the coolant drain container underneath RH rear of vehicle.
  17. Disconnect rear powertrain supply hose from PCS inlet hose coupling.
    Note
    1x spring clip. Plug hose connections as needed. Coolant loss greater than 1 L will require vacuum fill.
  18. Connect the coolant leak test adapter to the PCS inlet hose coupling.
    Note
    Remove the rubber plug from the coupler if installed. Make sure the locking clip is fully seated.
  19. Connect the coolant leak test fixture outlet hose to leak test adapter.
  20. Connect the outlet hose to the leak test fixture tool.
  21. Close both valves on the coolant leak test fixture tool.
  22. Connect compressed air to coolant leak test fixture tool.
    Note
    Air supply source should be above 50 psi.
  23. Turn the inlet valve on leak test fixture tool clockwise to open it, turn on the digital gauge and set to "psi", and then adjust the regulator to 50 psi.
    Note
    Turn the regulator knob clockwise to increase pressure and counterclockwise to decrease pressure.
    CAUTION
    Use caution as coolant may spill. Make sure to wear safety glasses.
  24. Set the timer to 2 minutes.
  25. Slowly open the outlet valve on the leak test fixture tool until the valve knob is inline with the airline.
    CAUTION
    Use caution as coolant may spill. Make sure to wear safety glasses.
  26. Start the 2-minute timer. Once the timer is complete, select Stop Reset.
  27. Close both valves on the coolant leak test fixture tool.
  28. Disconnect the coolant leak test adapter with hose from the PCS inlet hose coupling, and disconnect the coolant drain and fill adapter with hose from the PCS outlet hose coupling.
  29. Attach coolant leak test adapter with hose to PCS outlet hose coupling.
    Note
    1x spring clip. Make sure the locking tab is fully seated.
  30. Attach coolant drain and fill adapter with extension hose to PCS inlet hose coupling.
    Note
    1x spring clip. Make sure the locking tab is fully seated.
  31. Repeat step 23 to step 27.
  32. Disconnect compressed air from the leak test fixture tool.
  33. Disconnect waste coolant container from the drain and fill adapter.
  34. Disconnect coolant drain and fill adapter from the PCS inlet hose coupling.
    Note
    Install plug to inlet hose coupling. If the battery is returned to Reman, remove the special tool plugs.
  35. Position the coolant drain container underneath RH rear of vehicle.
  36. Connect rear powertrain supply hose to the PCS inlet hose coupling.
    Note
    Remove the plug, and perform push-pull-push test to make sure hose is fully seated.
  37. Disconnect the coolant leak test fixture outlet hose from the leak test adapter.
  38. Disconnect the coolant leak test adapter from the PCS outlet hose coupling.
    Note
    1x spring clip
  39. Position coolant drain container underneath LH rear of the vehicle.
  40. Connect the RDU inverter inlet tube to PCS outlet hose coupling.
    Note
    Remove plugs and perform push-pull-push test to make sure hose is fully engaged.
  41. Remove the coolant drain container from underneath vehicle.
  42. Install the rear HV battery skid plate. See Skid Plate - HV Battery - Rear (Remove and Replace).
  43. Install the rear aero shield panel. See Panel - Aero Shield - Rear (Remove and Replace).
  44. Perform a vacuum refill of the cooling system. See Cooling System (Vacuum Refill).
  45. Exit Service Mode. See 0005 - Service Modes.
  46. Install the cabin intake air duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  47. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  48. Raise all four windows and close all four doors.
  49. Remove the vehicle from the lift.
