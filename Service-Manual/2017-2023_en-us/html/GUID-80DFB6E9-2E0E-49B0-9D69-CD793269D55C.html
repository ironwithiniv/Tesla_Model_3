Carpet - Interior Complete (Remove and Replace)

Correction code 15302102 1.08 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1530 - Carpeting and Mats

Remove

  1. Remove the front passenger seat. See Seat Assembly - 1st Row - LH (Remove and Replace).
  2. Remove the front LH carpet. See Carpet - Front - LH (Remove and Replace).
  3. Remove the front RH carpet. See Carpet - Front - RH (Remove and Replace).
  4. Remove clips (X4) and release Velcro that secure the rear main cabin carpet to vehicle boddy, then remove the rear main cabin carpet from vehicle.

Install

  1. Install the clips (X4) and Velcro that secure the rear main cabin carpet to vehicle boddy.
  2. Install the front RH carpet. See Carpet - Front - RH (Remove and Replace).
  3. Install the front LH carpet. See Carpet - Front - LH (Remove and Replace).
  4. Install the front passenger seat. See Seat Assembly - 1st Row - LH (Remove and Replace).
