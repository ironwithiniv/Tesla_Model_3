Oil Pump - Rear Drive Unit (3DU) (Remove and Replace)

Correction code 40304602 0.78 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2024-08-15: Added instruction to perform software reinstall before running oil pump-related Toolbox routines.
  • 2024-04-05: Updated gearbox fluid information with link.
  • 2024-02-27: Updated gearbox fluid to KAF 1.
  • 2023-11-10: Added tools info.
Parent topic: 4030 - Rear Gearbox and Halfshafts

Remove

  1. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  2. Drain the gearbox fluid from the rear drive unit. See Gearbox Fluid - Rear Drive Unit (3DU) (Drain and Refill).
  3. Remove the bolts that attach the oil pump to the rear drive unit, and then remove the pump from the rear drive unit.
    Tip
    Use of the following tool(s) is recommended:
    • EPL10 socket
    • 4 in extension
  4. Use a pry tool to lever against the rear drive unit to loosen the oil pump.
  5. Remove the oil pump from the rear drive unit assembly.

Install

  1. Lightly coat the oil pump O-rings with clean gearbox fluid.
    Note
    Refer to Fluids and Capacities to determine which gearbox fluid is applicable.
  2. Install the oil pump into the rear drive unit, and then install the bolts that attach the oil pump to the rear drive unit.
    5 Nm (3.7 lbs-ft) + 20 degrees
    Tip
    Use of the following tool(s) is recommended:
    • EPL10 socket
    • 4 in extension
  3. Refill the gearbox fluid for the rear drive unit. See Gearbox Fluid - Rear Drive Unit (3DU) (Drain and Refill).
    Note
    Immediately before running any oil pump-related Toolbox routines, reinstall the vehicle software. See Software Reinstall - Touchscreen.
  4. Install all components that were removed for access.
