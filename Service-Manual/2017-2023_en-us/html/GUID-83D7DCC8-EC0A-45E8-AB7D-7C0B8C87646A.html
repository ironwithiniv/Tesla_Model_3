Switch - Window - Driver (Remove and Replace)

Torque Specifications

Table 1. Torque Specifications: Switch - Window - Driver (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolt that attaches the lower bolt cover to the LH front door trim panel
6 Nm (4.4 lbs-ft)
  • Torx T30 socket
 Reuse

Remove

  1. Remove the LH front door trim. See Panel - Door Trim - Front - LH (Remove and Install).
  2. Release the LH front door NVH pad from the tabs (x4).
  3. Release the clips (x7) that attach the bolt cover to the LH front door trim panel, and then pivot the bolt cover down and off of the door trim panel.
  4. Release the LH front window switch harness from the harness clips (x3) and release the connector from the tabs (x4), and move the harness and the connector to one side.
  5. Use a window switch removal tool (1988906-00-A) to release the tabs that attach the driver window switch to the LH front door trim panel, and then remove the switch from the vehicle.
    CAUTION
    Replace door trim if any tabs are broken during removal.
    Note
    Pull up on the manual release handle for easy access to the special tool. Push up on the special tool to release the 4 tabs, and use your thumb to push down on the switch to release it from the left front door panel.

Install

  1. Secure the tabs (x4) that attach the driver window switch to the door trim panel.
  2. Install the LH front window switch harness to the harness clips (x3) and install the connector to the tabs (x4).
  3. Hook the front edge of the bolt cover to the door panel, move the puddle light harness into the door panel, and then pivot the bolt cover up and secure the clips (x7).
  4. Install the LH front door NVH pad to the tabs (x4).
  5. Raise the LH front window and close the LH front door.
  6. Install the LH front door trim. See Panel - Door Trim - Front - LH (Remove and Install).
