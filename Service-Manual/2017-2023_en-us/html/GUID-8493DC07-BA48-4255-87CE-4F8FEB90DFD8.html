Hose - Outlet - Radiator (Heat Pump) (Remove and Replace)

Correction code 18302712 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1830 - Cooling System

Remove

  1. Open the LH front door and lower the LH front window.
  2. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  3. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  4. Remove the cabin intake upper duct assembly. See Duct - Upper - Cabin Intake (Remove and Replace).
  5. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  6. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  7. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  8. Lower the vehicle fully.
  9. Position a fluid catcher underneath the front of the vehicle.
  10. Release the clip that attaches the radiator outlet hose to the RH side of the vehicle.
  11. Release the spring clip, disconnect the radiator outlet hose from the radiator, allow the coolant to drain, and then plug both fittings.
  12. Release the spring clip, disconnect radiator outlet hose from the Supermanifold, plug both fittings, and then remove the hose from the vehicle.

Install

  1. Remove the hose plugs, connect the radiator outlet hose to the Supermanifold, and then install the spring clip.
    Note
    Perform a push-pull-push test to make sure the hose is fully seated.
  2. Remove the plugs, connect the radiator outlet hose to radiator, and then install the spring clip.
    Note
    Perform a push-pull-push test to make sure the hose is fully seated.
  3. Install the clip that attaches the radiator outlet hose to the RH side of the vehicle.
  4. Remove the fluid catcher from underneath the vehicle.
  5. Install the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  6. Remove the coolant bottle cap.
  7. Fill the coolant to the "Max" level.
  8. Connect 12V power. See 12V/LV Power (Disconnect and Connect).
  9. Connect a laptop with Toolbox 3.0 to the vehicle.
  10. Click the Actions/Autodiag tab, and then search for "Purge".
  11. Click TEST_VCFRONT_X_THERMAL-COOLANT-AIR-PURGEvia Service Mode:
    • Thermal ➜ Actions ➜ Coolant Purge Stop or Coolant Purge Start
    • Thermal ➜ Coolant System ➜ Coolant Purge Start
    via Service Mode Plus:
    • Drive Inverter ➜ Front Drive Inverter Replacement ➜ Coolant Air Purge
    • Drive Inverter ➜ Rear Drive Inverter Replacement ➜ Coolant Air Purge
    • Drive Inverter ➜ Rear Left Drive Inverter Replacement ➜ Coolant Air Purge
    • Drive Inverter ➜ Rear Right Drive Inverter Replacement ➜ Coolant Air Purge
    • Drive Unit ➜ Front Drive Unit Replacement ➜ Coolant Air Purge
    • Drive Unit ➜ Rear Drive Unit Replacement ➜ Coolant Air Purge
    via Toolbox:(link)    , click Run, and allow the routine to complete.
    Note
    Select the "X" at the top right of the window to close once the routine is complete.
  12. Disconnect Toolbox and remove the laptop from the vehicle.
  13. Inspect the coolant level and top off as necessary.
    Note
    Ensure that the coolant is filled to the "Max" line.
  14. Install the coolant bottle cap.
  15. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  16. Install the cabin intake upper duct assembly. See Duct - Upper - Cabin Intake (Remove and Replace).
  17. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  18. Remove the vehicle from the lift. See Raise Vehicle - 2 Post Lift.
  19. Raise the LH front window and close the LH front door.
