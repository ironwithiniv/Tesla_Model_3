Harness - USB - Car Computer To Glove Box (LHD) (Remove and Replace)

Correction code 17106802 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
Parent topic: 1710 - Harnesses

Remove

  1. Open LH front door
  2. Lower LH front window
  3. Open hood
    Note
    Press "Open" button on touchscreen to release latch, Lift lid manually
  4. Open glove box through UI
    Note
    via Controls > Glovebox
  5. Remove flash drive from glove box USB port
  6. Remove rear apron
    Note
    12x clips, Only store rear apron visible face upwards
  7. Move LH front seat backward
  8. Open RH front door
  9. Lower RH front window
  10. Move RH front seat backward
  11. Power off vehicle from center display
    Note
    Via Controls > Safety > Power Off, Select Power Off button at warning dialogue box
  12. Disconnect 12V negative terminal
    Note
    1x nut, 10mm, 6 Nm, Ensure vehicle is in park, climate control system is off, and vehicle is not charging before disconnecting 12V
  13. Disconnect first responder loop
    Note
    1x connector, Release locking tab
  14. Remove LH IP end cap
    Note
    3x clips
  15. Remove LH air wave bezel cap from main decor assembly
    Note
    2x clips, Newer vehicles are equipped with solid bezel.
  16. Remove RH IP end cap
    Note
    3x clips
  17. Remove RH air wave bezel cap from main decor assembly
    Note
    2x clips, Newer vehicles are equipped with solid bezel.
  18. Remove RH mid A-pillar assembly
    Note
    1x clip, 1x tab, Release upper clip then pull mid A-pillar upward to remove from vehicle
  19. Remove clip from RH lower A-pillar trim
    Note
    1x push clip
  20. Remove RH lower A-pillar trim
    Note
    1x clip, 2 guide tabs, Pull rear of lower A-pillar upward to release clip then pull rearward to release front tabs from carpet
  21. Release RH footwell assembly from IP
    Note
    4x push clips
  22. Remove RH footwell assembly
    Note
    2x connectors
  23. Remove bolts securing passenger knee air bag onto vehicle
    Note
    4x patch bolts, T30, 8 Nm, Discard after removal, 2x screws, T20, 2 Nm, 1x push clip, Newer vehicles have 4x E10 patch bolts
  24. Remove passenger knee air bag from vehicle
    Note
    1x connector, Release locking tab, Connector release may vary
  25. Remove main decor assembly
    Note
    15x clips, Entire decor does not need to come off for glove box removal, If you lift RH side of decor then you will have access to 3x torx screws securing top of glove box, Replace securing clips as needed
  26. Disconnect glove box USB cable from car computer
    Note
    1x connector, Depress latch on top of USB cable to release internal latches, then release from car computer
  27. Remove screws securing glove box assembly to IP carrier
    Note
    6x screws, T20, 2.3 Nm
  28. Remove glove box from IP carrier
    Note
    3x clips
  29. Disconnect glove box assembly connectors
    Note
    3x electrical connectors
  30. Peel back NVH pad near USB harness clips
  31. Remove USB harness clips from glovebox
    Note
    2x clips
  32. Remove glove box USB cable from glove box
    Note
    2x screws, T20, 1 Nm

Install

  1. Install glove box USB cable to glove box
    Note
    2x screws, T20, 1 Nm
  2. Secure USB harness clips to glove box
    Note
    2x clips
  3. Secure NVH pad near USB harness clips
  4. Connect glove box assembly connectors
    Note
    3x connectors, New puddle lamp harness routing prevent blocking movement of pawls, Make sure harness is routed properly above passenger footwell air duct before connecting
  5. Install glove box into IP carrier
    Note
    3x clips
  6. Install screws securing glove box assembly to IP carrier
    Note
    6x screws, T20, 2.3 Nm
  7. Connect glove box USB cable to car computer
    Note
    1x connector
  8. Install main decor assembly
    Note
    15x clips, 1x center clip
  9. Install passenger knee air bag onto vehicle
    Note
    1x connector, Use caution not to damage connector and harness, Support knee air bag while connecting connector
  10. Install bolts securing passenger knee air bag to vehicle
    Note
    4x patch bolts, E10, 8 Nm, Install new patch bolts, 2x screws, T20, 2 Nm, 1x push clip, If vehicle equipped with T30 bolts update to E10
  11. Position RH footwell assembly
    Note
    2x connectors
  12. Install RH footwell assembly onto IP
    Note
    4x push clips
  13. Install RH front floor mat
  14. Install RH lower A-pillar trim
    Note
    1x clip, 2 guide tabs, Align 2 front tabs then align slot with harness bracket and then push rear clip to secure to lower B-pillar
  15. Install clip for RH lower A-pillar trim
    Note
    1x push clip
  16. Install RH mid A-pillar assembly
    Note
    1x clip, 1x tab, Align bottom tab then push on top clip to fully seat mid A-pillar, Make sure seal seat on top of trim
  17. Install RH air wave bezel cap to main decor assembly
    Note
    2x clips, Newer vehicles are equipped with solid bezel.
  18. Install RH IP end cap
    Note
    3x clips
  19. Install LH air wave bezel cap to main decor assembly
    Note
    2x clips, Newer vehicles are equipped with solid bezel.
  20. Install LH IP end cap
    Note
    3x clips
  21. Connect first responder loop
    Note
    1x connector, Engage locking tab, Connect FRL before connecting 12V to avoid damage to car computer
  22. Connect 12V negative terminal
    Note
    1x nut, 10mm, 6 Nm
  23. Install rear apron
    Note
    12x clips
  24. Close hood
  25. Move RH front seat to original position
  26. Install flash drive to glove box USB port
  27. Close glove box
  28. Raise RH front window
  29. Close RH front door
  30. Move LH front seat to original position
  31. Raise LH front window
  32. Close LH front door
