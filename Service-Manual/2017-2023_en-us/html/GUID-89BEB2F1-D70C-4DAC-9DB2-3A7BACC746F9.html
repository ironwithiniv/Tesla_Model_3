Check Strap - Door - Front - LH (Remove and Replace)

Correction code 10106052 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1454796-00-A TOOLKIT, WINDOW SWITCH
Parent topic: 1010 - Body Panels

Torque Specifications

Table 1. Torque Specifications: Check Strap - Door - Front - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolt that attaches the check strap to the A-pillar
24 Nm (17.7 lbs-ft)
  • 13 mm socket
 Reuse
Nuts that attach the check strap to the door
10 Nm (7.4 lbs-ft)
  • 10 mm socket
 Reuse

Remove

  1. Remove the front LH door trim panel. See Panel - Door Trim - Front - LH (Remove and Install).
  2. Connect the window switch tool to the door harness and fully raise the front LH door window.
  3. Remove the front door speaker. See Speaker - Front Door - LH (Remove and Replace).
  4. Remove the bolt that attaches the LH front door check strap to the A-pillar.
    24 Nm (17.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
    CAUTION
    Unbolting the door check allows the door to swing freely beyond opening limits.
  5. Use a plastic trim tool to release the clips (x3) that attach the check strap seal to the door.
  6. Remove the nuts (x2) that attach the check strap to the door.
    10 Nm (7.4 lbs-ft)
    • 10 mm socket
  7. Reach inside the speaker bracket opening and remove the check strap from the vehicle.

Install

Installation procedure is the reverse of removal, except for the following:

  • Maneuver the check strap seal onto the check strap prior to torquing the fasteners.
