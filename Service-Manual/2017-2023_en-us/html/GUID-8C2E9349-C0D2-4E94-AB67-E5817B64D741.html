Switch - Back Rest and Cushion Adjust - Front Passenger Seat (Rework)

Correction code 13015203 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1301 - Front Seat Tracks and Motors

Retrofit

  1. Remove the front passenger seat switch. See Switch - Back Rest and Cushion Adjust - Driver Seat (Remove and Replace).
  2. Using clip tool to remove the lumbar button cap.
  3. Remove the rectangular plastic gimbal using pliers or side cutters.
    Note
    Ensure both knob detents are present and no debris present.
  4. Install the new lumbar button cap.
