Switch - Trunk - Exterior (Remove and Replace)

Correction code 11355602 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1135 - Latches Strikers and Pinch Sensors

Torque Specifications

Table 1. Torque Specifications: Switch - Trunk - Exterior (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Screws (x2) that attach the rear facing camera to the exterior trunk switch
1 Nm (.7 lbs-ft)
  • SET, 1/2" CUT BIT. (78 PCS DOUBLE END MINI RATCHET)
  • Digital Torque Screwdriver 0.10Nm - 2.0Nm
 Reuse

Remove

  1. Remove the trunk exterior switch and camera assembly. See Switch and Camera Assembly - Exterior Release - Trunk (Remove and Replace).
  2. Remove the screws (x2) that attach the rear facing camera to the exterior trunk switch.
    Tip
    Use of the following tool(s) is recommended:
    • SET, 1/2" CUT BIT. (78 PCS DOUBLE END MINI RATCHET)
    • Digital Torque Screwdriver 0.10Nm - 2.0Nm

Install

  1. Install the screws (x2) that attach the rear facing camera to the exterior trunk switch.
    1 Nm (.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • SET, 1/2" CUT BIT. (78 PCS DOUBLE END MINI RATCHET)
    • Digital Torque Screwdriver 0.10Nm - 2.0Nm
  2. Install the trunk exterior switch and camera assembly. See Switch and Camera Assembly - Exterior Release - Trunk (Remove and Replace).
