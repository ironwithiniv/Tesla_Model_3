Accelerator (Remove and Replace)

Correction code 17551002 0.48 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1755 - Accelerator Pedal

Remove

  1. Remove the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Disconnect 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  4. Remove the driver knee airbag. See Airbag - Knee - Driver (Remove and Install).
  5. Remove the LH footwell duct. See Duct - Footwell - LH (LHD) (Remove and Replace).
  6. Disconnect the electrical connector from the accelerator.
    CAUTION
    If the connector locking tab is red, pull the red locking tab away from the pedal housing.
  7. Remove the bolt that attaches the accelerator to the body.
  8. Slide the accelerator downwards, and then remove the accelerator from the vehicle.

Install

  1. Slide the accelerator up, and then install the accelerator into the bracket.
  2. Install the bolt that attaches the accelerator to the body.
    7 Nm (5.2 lbs-ft)
  3. Connect the accelerator electrical connector.
    Note
    If the connector locking tab is red: push the red locking tab towards the pedal housing.
  4. Install the LH footwell duct. See Duct - Footwell - LH (LHD) (Remove and Replace).
  5. Install the driver knee airbag. See Airbag - Knee - Driver (Remove and Install).
  6. Reconnect 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  7. Connect a laptop with Toolbox 3 to the vehicle.
  8. Run the following Toolbox routines to confirm pedal operation:
    • TEST-SELF_DI_X_ACCEL-PEDALvia Toolbox:(link)
    • PING-TP_PMRvia Toolbox:(link)
    • TEST-SELF_PMR_X_CAN-COMMSvia Toolbox:(link)
  9. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  10. Install the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
