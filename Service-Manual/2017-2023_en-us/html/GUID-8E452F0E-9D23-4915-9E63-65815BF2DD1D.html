Track - Inner - Front Passenger Seat (Remove and Replace)

Correction code 13013102 0.66 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
Seat base edges are sharp and can cause personal injury. Wear cut resistant gloves when removing the seat from the vehicle, and while performing procedures that involve work on or near the seat base.
Parent topic: 1301 - Front Seat Tracks and Motors

Remove

  1. Check that the firmware is version 2023.2.11 or above. If the firmware version is not 2023.2.11 or above, update the vehicle firmware.
  2. Remove the front passenger seat from the vehicle. See Seat Assembly - 1st Row - LH (Remove and Replace).
  3. Remove the front passenger seat inboard side shield from the seat assembly. See Side Shield - Inboard - Driver Seat (Remove and Replace).
  4. Remove the front passenger seat buckle. See Buckle - 1st Row - LH (Remove and Replace).
  5. Lay the seat on its seat back to gain access to the underside of the seat cushion.
    CAUTION
    Protect the seat cushion from damage as necessary.
  6. Remove and discard the bolts (x2) that attach the front passenger seat inboard track to the seat assembly.
    23 Nm (17.0 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket
  7. Release the front passenger front seat inner seat track from the track bridge assembly.
    Note
    Pry up on bridge tack motor tab, and then slide the inner seat track away to release it.
  8. Roll the sides of the seat covers outwards to unlock the plastic trim from the rail, and pull the covers from the seat rail.

Install

  1. Line up the seat track covers (x2) to the front edge of the seat rail, slide the covers onto the seat rail until they are secure.
  2. Install the front passenger seat inner track onto the track bridge assembly.
    Note
    The track motor cable is keyed square and must be aligned with inner track. Turn cable by hand to align as needed. Slide the track motor bridge into the inner track until is fully seated.
  3. Install new bolts (x2) that attach the front passenger seat inner track to the seat assembly.
    23 Nm (17.0 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket
  4. Return the seat to the upright position.
  5. Install the front passenger seat buckle. See Buckle - 1st Row - LH (Remove and Replace).
  6. Install the front passenger seat inboard side shield from the seat assembly. See Side Shield - Inboard - Driver Seat (Remove and Replace).
  7. Install the front passenger seat into the vehicle. See Seat Assembly - 1st Row - LH (Remove and Replace).
  8. If servicing the front passenger seat in a North American vehicle:
    1. Remove all objects from the front passenger seat before beginning calibration.
    2. On the vehicle touchscreen, touch Controls (Vehicle Icon) > Software and check the vehicle firmware version. If the vehicle firmware is 2023.2.11 or newer, perform a software reinstall. See Software Reinstall - Touchscreen. If the vehicle firmware is not 2023.2.11 or newer, update the vehicle firmware. See Software Update.
    3. Locally connect a laptop with Toolbox 3 to the vehicle. See Toolbox (Connect and Disconnect).
    4. Unlock the vehicle gateway. See Gateway (Unlock).
    5. In Toolbox, click on the Actions tab, and then search for "OCS".
    6. Run the PROC_OCS1P_SELF-CALIBRATIONvia Service Mode Plus:Safety & Restraints ➜ Seats ➜ OCS1P Self Capacitance Calibrationvia Toolbox:(link) routine.
    7. Click on the Actions tab, and then search for "Seat calibration".
    8. Run the PROC_VCRIGHT_SEAT-CALIBRATEvia Service Mode:Low Voltage ➜ Seats ➜ Calibrate Seatvia Toolbox:(link) routine.
    9. Disconnect Toolbox and remove the laptop from the vehicle.
