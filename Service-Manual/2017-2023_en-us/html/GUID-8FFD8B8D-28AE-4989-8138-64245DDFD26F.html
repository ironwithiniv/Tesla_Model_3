Knuckle - Suspension - Front - LH (RWD) (Remove and Replace)

Correction code 31010102 0.54 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

CAUTION
If performing this procedure as a result of a collision, see the Collision Repair Manual to verify whether the steering gear must be replaced as well.
Parent topic: 3101 - Front Suspension (Including Hubs)

Remove

  1. Remove the LH front brake dust shield. See Shield - Dust - Brake - Front - LH (Remove and Replace).
  2. Remove the bolts that attach the LH front ABS wheel speed sensor electrical harness to the LH front suspension knuckle.
    5 Nm (3.7 lbs-ft)
  3. Release the clip that attaches the LH front ABS wheel speed sensor electrical harness to the LH front suspension knuckle.
  4. Remove and discard the nut that attaches the LH tie rod end to the LH front suspension knuckle.
    180 Nm (132.7 lbs-ft)
  5. Remove the LH tie rod end from the vehicle.
  6. Remove the bolt and nut that secure the LH upper control arm to the LH front suspension knuckle.
    56 Nm (41.3 lbs-ft)
    56 Nm (41.3 lbs-ft)
  7. Remove and discard the nut that attaches the LH front lower compliance link to the front suspension knuckle.
    180 Nm (132.7 lbs-ft)
  8. Remove and discard the nut that attaches the LH front lower lateral link to the LH front suspension knuckle.
    180 Nm (132.7 lbs-ft)
  9. Remove the front suspension knuckle and hub assembly from the vehicle.
  10. Remove LH front wheel speed sensor harness bracket from knuckle.
    5 Nm (3.7 lbs-ft)
  11. Separate the front hub from the front suspension knuckle.

Install

Installation procedure is the reverse of removal, except for the following:

  • Replace all nyloc nuts.
  • Refer to the Alignment Requirement tables to determine whether an EPAS alignment check (EC) or four wheel alignment check (AC) is necessary. If performed, add the alignment check/adjust correction code as a separate activity to the SV. See Alignment Requirement - Suspension.
