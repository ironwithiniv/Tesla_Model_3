USB Hub - Center Console - Front (2.0) (Remove and Replace)

Correction code 21260412 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created.   • 2023-06-20: Added step to release clips through slots with pick.

Torque Specifications

Table 1. Torque Specifications: USB Hub - Center Console - Front (Remove and Replace) / USB Hub - Center Console - Front (2.0) (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Screws that attach the USB hub to the center console
1.1 Nm (.8 lbs-ft)
  • Torx T20 socket
 Reuse

Remove

  1. Open the sliding bin lid of the center console.
  2. Release the clips (x2) through the slots with a pick, and then release the rest of the clips (x3) that attach the bottom of the USB hub to the center console.
  3. Disconnect the electrical harness from the USB hub connectors (x2), and then remove the USB hub from the center console.
  4. Remove the screws (x3) that attach the USB hub to the USB panel, and then remove the hub from the panel.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket

Install

  1. Install the USB hub to the USB panel, and then install the screws that attach the hub to the panel.
    1.1 Nm (.8 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  2. Position the USB hub into the center console storage bin, and then connect the electrical harness to the USB hub connectors (x2).
  3. Move the USB hub to the rear of the center console, and then fasten the clips (x5) that attach the USB hub to the rear of the center console.
  4. Close the storage bin lid of the center console.
