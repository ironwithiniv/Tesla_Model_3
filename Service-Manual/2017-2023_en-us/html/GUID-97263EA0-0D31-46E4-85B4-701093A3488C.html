Solenoid - Glove Box (Remove and Replace)

Correction code 14051102 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1405 - Instrument Panel

Remove

  1. Remove the glove box. See Glove Box - With Knee Airbags (Non-Heat Pump) (Remove and Replace).
  2. Remove and discard the NVH pad from the glove box.
    Note
    The NVH pad is one time use only.
  3. Release the clips that attach the glove box solenoid electrical harness to the glove box.
  4. Remove the bolts that attach the glove box solenoid to the glove box, and then remove the solenoid from the glove box.
    Note
    The solenoid plunger has a right angle bend into the link rod.

Install

  1. Install the glove box solenoid to the glove box.
    Note
    Align the glove box solenoid with the link rod, and then push down to install.
  2. Install the screws that attach the glove box solenoid to the glove box.
    0.8 Nm (7 lbs-in)
  3. Install the clips that attach the glove box solenoid electrical harness to the glove box.
  4. Install a new NVH pad onto the glove box.
  5. Install the glove box. See Glove Box - With Knee Airbags (Non-Heat Pump) (Remove and Replace).
