End Panel - Center Console (Remove and Replace)

Correction code 15195002 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1519 - Center Console

Torque Specifications

Table 1. Torque Specifications:End Panel - Center Console (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts that attach the center console end panel to the center console
1.1 Nm (.8 lbs-ft)
  • Torx T20 socket
 Reuse

Remove

  1. Remove the center console lower rear panel. See Panel - Lower Rear - Center Console (Remove and Replace).
  2. Remove the center console air vent panel. See Assembly - Rear Vent - Center Console (Remove and Replace).
  3. Remove the bolts (x2) and release the clips (x6) that attach the center console end panel to the center console, and then remove the end panel from the console.
    1.1 Nm (.8 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket

Install

Installation procedure is the reverse of removal.
