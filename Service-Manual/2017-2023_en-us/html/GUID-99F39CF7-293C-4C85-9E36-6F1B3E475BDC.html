Diamond Cover - Seat Side - 1st Row - RH (Remove and Replace)

Correction code 13072502 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Note
Depending on build location, some vehicles may not be equipped with this part. For vehicles equipped with side shield carriers, see Carrier - Side Shield - Inboard - Driver Seat (Remove and Replace).
Parent topic: 1307 - Front Seat Covers Pads and Trims

Remove

  1. Open all doors and lower all windows.
  2. Move the LH front seat to the most rearward and lowest position.
  3. Release the clips (x5) that attach the rear end of the LH front seat inboard side shield cover to the seat.
  4. Use the clip tool to separate the diamond cover from seat frame, and then rotate counter-clockwise and remove it from the LH front seat.

Install

  1. Install the diamond cover downward and engage the clip to the LH front seat.
  2. Install the clips (x5) that attach the rear end of the LH front seat inboard side shield cover to the seat.
  3. Move the LH front seat to its original position.
  4. Raise all windows and close all doors.
