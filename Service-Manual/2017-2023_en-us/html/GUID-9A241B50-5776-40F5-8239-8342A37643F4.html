Speaker - Headliner - LH (Remove and Replace)

Correction code 21214502 0.78 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-05-13: Added notes for the removal and installation of the glued speakers with 3 aligning pins.
Parent topic: 2121 - Audio System - Speakers Subwoofer Amplifier

Torque Specifications

Table 1. Torque Specifications: Speaker - Headliner - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Screws (x3) that attach the LH front headliner speaker to the headliner assembly
0.5 Nm (4 lbs-in)
    • Torx T10 driver
 Reuse

Remove

  1. Remove the headliner from the vehicle. See Headliner (Heat Pump) (Remove and Install).
  2. Remove the soundproof foam from the LH front headliner speaker.
  3. Disconnect the LH front headliner speaker electrical connector.
  4. Remove the screws (x3) that attach the LH front headliner speaker to the headliner assembly.
    Note
    Some headliners come with glued speakers with 3 aligning pins. Remove the glue by peeling it with a screwdriver and clean all residual adhesive.
    Tip
    Use of the following tool(s) is recommended:
      • Torx T10 driver

Install

  1. Position the LH front headliner speaker onto the headliner assembly, and then install the screws (x3) that attach the speaker to the headliner assembly.
    0.5 Nm (4 lbs-in)
    Note
    Some headliners come with glued speakers with 3 aligning pins. Use a hot glue gun to re-glue the tips of the aligning pins, install the speaker and wait till the glue gets hard. Make sure the speaker does not vibrate.
    Tip
    Use of the following tool(s) is recommended:
      • Torx T10 driver
  2. Connect the LH front headliner speaker electrical connector.
  3. Install the soundproof foam to the LH front headliner speaker.
  4. Install the headliner from the vehicle. See Headliner (Heat Pump) (Remove and Install).
