Reinforcement - Front Fascia - LH (Remove and Replace)

Correction code 10015102 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1001 - Bumper / Fascia

Remove

  1. Remove the front fascia. See Fascia - Front (Remove and Replace).
  2. Release the tab (x1) that lock the fascia reinforcement to the front end of carrier, then pull to remove the fascia reinforcement .

Install

  1. Lock the tab (x1) to install the fascia reinforcement to the front end of carrier .
  2. Install the front fascia. See Fascia - Front (Remove and Replace).
