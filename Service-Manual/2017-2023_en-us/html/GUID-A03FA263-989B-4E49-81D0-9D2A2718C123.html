Harness - HVAC Assembly (Heat Pump) (Remove and Replace)

Correction code 17104102 3.66 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Note
This procedure requires the A/C Refrigerant (Recovery and Recharge) procedure to be performed. If not already automatically added to the Service Visit, add correction code 18200102 as a separate correction within the same activity to the Service Visit.
Parent topic: 1710 - Harnesses

Torque Specifications

Table 1. Torque Specifications: GUID-5EC2FB18-9ACA-4FDD-A89C-C60DD9945A7F.html
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x4) that attach the LH and RH bleed actuators to the HVAC assembly
2.3 Nm (1.7 lbs-ft)
  • 6 mm socket
 Reuse

Remove

  1. Remove the HVAC assembly. See HVAC Assembly (Heat Pump) (Remove and Replace).
  2. Disconnect the intake actuator connector.
  3. Disconnect the upper mode actuator connector.
  4. Disconnect the RH lower duct thermistor connector.
  5. Disconnect the lower mode actuator connector.
  6. Disconnect the RH bleed actuator connector.
  7. Disconnect the LH bleed actuator connector.
  8. Disconnect the LH evaporator thermistor connector.
  9. Disconnect the LH lower duct thermistor connector.
  10. Remove the bolts (x4) that attach the LH and RH bleed actuators to the HVAC assembly.
    Tip
    Use of the following tool(s) is recommended:
    • 6 mm socket
  11. Release the clips (x3) on the RH side of the HVAC assembly.
  12. Release the HVAC harness from the RH holding tabs (x3).
  13. Release the HVAC harness from the upper holding tabs (x2).
  14. Release the HVAC harness from the LH holding tabs (x4) and remove the HVAC harness from the HVAC assembly.

Install

  1. Position the HVAC harness onto the HVAC assembly and connect the LH evaporator thermistor.
  2. Connect the LH lower duct thermistor connector.
  3. Install the HVAC harness into the LH holding tabs (x4).
  4. Install the HVAC harness into the upper holding tabs (x2).
  5. Install the clips (x3) on the RH side of the HVAC assembly.
  6. Install the HVAC harness into the RH holding tabs (x3).
  7. Connect the lower mode actuator connector.
  8. Connect the upper mode actuator connector.
  9. Connect the intake actuator connector.
  10. Connect the RH lower duct thermistor connector.
  11. Install the bolts (x4) that attach the LH and RH bleed actuators to the HVAC assembly.
    2.3 Nm (1.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 6 mm socket
  12. Connect the RH bleed actuator connector.
  13. Connect the LH bleed actuator connector.
  14. Install the HVAC assembly. See HVAC Assembly (Heat Pump) (Remove and Replace).
