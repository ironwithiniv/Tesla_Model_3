Fender Assembly - Front - LH (Remove and Install)

Correction code 101030010.90 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

    This procedure assumes the cowl screen carrier bracket, headlight grommet, and underhood storage unit clips on the fender assembly being replaced are undamaged. Inspect these components and if necessary, replace with new parts.
    Parent topic: 1010 - Body Panels

    Remove

    1. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
    2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
    3. Remove the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
    4. Remove the hood latch cover. See Cover - Hood Latch (Remove and Replace).
    5. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
    6. Remove the LH shock tower cover. See Cover - Shock Tower - LH (Remove and Replace).
    7. Remove the front wheels. See Wheel Assembly (Remove and Install).
    8. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
    9. Remove the front fascia. See Fascia - Front (Remove and Install).
    10. Remove the LH headlight. See Headlight - LH (Remove and Replace).
    11. Disconnect the electrical connectors (2x) from the front side repeater light.
    12. Release the two leftmost clips on the cowl screen panel from the LH front fender bracket.
    13. Remove the bolts that attach the upper LH front fender to the vehicle.
    14. Remove the bolt that attaches the lower LH front fender to the vehicle.
    15. Remove the bolt that attaches the rear LH front fender to the vehicle.
    16. Remove the bolt and nut that attach the lower LH front fender to the vehicle.
    17. Inspect the area between the upper LH front fender and the vehicle body for foam sealant. If present, carefully cut the sealant with a blade, and then separate the upper fender from the body with a plastic trim tool.
    18. Remove the LH front fender from the vehicle.
    19. Use a flat scraper blade and isopropyl alcohol (IPA) to remove the foam sealant from the LH outer shotgun panel. Any remaining sealant should be flush with the shotgun panel.
    20. Apply primer to the LH outer shotgun panel, completely covering the previous foam application area.

    Install

    Tip
    For instructions on how to align the fender, refer to Fender Alignment.
    1. Load urethane into a caulking gun, and then cut an opening that is 3.5 mm wide and 1.5 mm tall.
    2. Apply a dollop of urethane on top of the primed surface of the LH outer shotgun panel.
    3. Position the LH front fender on the vehicle.
    4. Install the bolt and nut that attach the lower LH front fender to the vehicle.
      9.8 Nm (7.2 lbs-ft)
      9.8 Nm (7.2 lbs-ft)
    5. Install the bolt that attaches the rear LH front fender to the vehicle.
      9.8 Nm (7.2 lbs-ft)
    6. Install the bolt that attaches the lower LH front fender to the vehicle.
      9.8 Nm (7.2 lbs-ft)
    7. Install the bolts that attach the upper LH front fender to the vehicle.
      9.8 Nm (7.2 lbs-ft)
    8. Install the cowl screen panel clips (2x) on the LH front fender bracket.
    9. Connect the electrical connectors (2x) to the front side repeater light.
    10. Install the LH headlight. See Headlight - LH (Remove and Replace).
    11. Install the front fascia. See Fascia - Front (Remove and Install).
    12. Install the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
    13. Install the front wheels. See Wheel Assembly (Remove and Install).
    14. Install the LH shock tower cover. See Cover - Shock Tower - LH (Remove and Replace).
    15. For China, Japan and Korea only: Install a new motor ID label on the fender.
    16. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
    17. Install the hood latch cover. See Cover - Hood Latch (Remove and Replace).
    18. Install the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
    19. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
    20. Remove the vehicle from the lift.
