Bracket - Manual Release Cable - Charge Port (Remove & Replace)

Correction code 44012142 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 4401 - Charge System Inlet

Remove

  1. Remove the trunk garnish. See Garnish - Trunk (Remove and Replace).
  2. Disconnect the LH trunk light. See Light - Trunk (Remove and Replace).
  3. With a small flat head screwdriver, pull the manual release cable off from the hold down clip.
  4. Use a small flat head screwdriver to release the tab.
  5. Remove the charge port manual release bracket from the vehicle.

Install

  1. Install the tab that attaches the charge port manual release bracket to the vehicle.
  2. Push down the manual release cable into the locking tab.
  3. Connect the LH trunk light. See Light - Trunk (Remove and Replace).
  4. Install the trunk garnish. See Garnish - Trunk (Remove and Replace).
