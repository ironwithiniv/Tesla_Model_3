Reinforcement Bracket - Underhood Storage Unit (Remove and Replace)

Correction code 15244674 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2024-04-19: Added steps of separating the cooling fan module isolation bracket from the old frunk reinforcement assembly and installing it to the new frunk reinforcement assembly.
Parent topic: 1524 - Luggage Compartment Trim

Torque Specifications

Table 1. Torque Specifications: Reinforcement Bracket - Underhood Storage Unit (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x2) that secure the underhood reinforcement bracket
16 Nm (11.8 lbs-ft)
  • 10 mm socket
 Reuse
Bolts (x4) that attach the cooling fan module isolation brackets to the frunk reinforcement assembly
6 Nm (4.4 lbs-ft)
  • 10 mm 12-point deep socket
 Reuse

Remove

  1. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  2. Remove the bolts (x2) that secure the underhood reinforcement bracket.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  3. Release the harness clip, and then remove the underhood reinforcement bracket from the fan assembly.
  4. Remove the bolts (x4) that attach the cooling fan module isolation brackets to the frunk reinforcement assembly, and set the upper isolation brackets aside for re-installation to the new frunk reinforcement assembly.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm 12-point deep socket

Install

  1. Install the bolts (x4) to attach the cooling fan module isolation brackets to the new frunk reinforcement assembly.
    6 Nm (4.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm 12-point deep socket
  2. Install the underhood reinforcement bracket to the fan assembly, and install the harness clip.
  3. Install the bolts(x2) that secure the underhood reinforcement bracket.
    16 Nm (11.8 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  4. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
