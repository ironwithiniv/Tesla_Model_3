Damper - Glove Box (Remove and Replace)

Correction code 14051202 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1405 - Instrument Panel

Remove

  1. Remove the glove box. See Glove Box - With Knee Airbags (Non-Heat Pump) (Remove and Replace).
  2. Remove the pin that attach the glove box damper to the glove box using needle nose pliers.
  3. Fully open the glove box.
    Note
    When the glove box is closed, the glove box damper will not clear for removal.
  4. Turn the glove box damper 90 degrees counterclockwise, and then remove the glove box damper from the glove box.

Install

  1. Position the glove box damper onto the glove box by turning it 90 degrees clockwise.
  2. Close the glove box so that the glove box damper engages with the glove box lid.
  3. Install the pin that attaches the glove box damper to the glove box.
    Note
    Make sure that the glove box damper pin is fully seated, and not to bump the glove box damper, when installing the glove box.
  4. Install the glove box. See Glove Box - With Knee Airbags (Non-Heat Pump) (Remove and Replace).
