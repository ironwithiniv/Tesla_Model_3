Latch - Hood (Single Actuator System) (Remove and Replace)

Correction code 11350302 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1135 - Latches Strikers and Pinch Sensors

Torque Specifications

Table 1. Torque Specifications: Latch - Hood (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts that attach the hood latch to the front end carrier
8 Nm (5.9 lbs-ft)
  • 10 mm socket
 Reuse

Remove

Note
If the hood latch does not open electronically, use the manual front trunk release tool to open the hood.
  • 1130534-00-ATOOL, FRUNK RELEASE, MANUAL, MODEL 3
CAUTION
When using the manual front trunk release tool in Mobile Service, raise the vehicle using mini ramps and verify stability of the vehicle.
  1. Remove the hood latch cover. See Cover - Hood Latch (Remove and Replace).
  2. Release the hood latch actuator cable from the hood latch.
    Note
    Release the clip before removing the actuator cable from the latch arm.
  3. Disconnect the electrical harness from the hood latch connector.
    CAUTION
    DO NOT push down on the red locking tab. Pull the tab away from the connector until the connector is unlocked, and then continue pulling the main body of the connector to fully disconnect it.
  4. Mark the location of the hood latch with a paint pen or masking tape.
  5. Remove the bolts that attach the hood latch to the front end carrier, and then remove the latch from the vehicle.
    8 Nm (5.9 lbs-ft)
    Use of the following tool(s) is recommended:
    • 10 mm socket

Install

When connecting the electrical harness to the hood latch: Push the red locking tab towards the connector to engage the locking mechanism. DO NOT push down or pull up on the red locking tab.

  1. Install the bolts that attach the hood latch to the front end carrier, and then install the latch to the vehicle.
    8 Nm (5.9 lbs-ft)
    Use of the following tool(s) is recommended:
    • 10 mm socket
  2. Connect the electrical harness to the hood latch connector.
    CAUTION
    DO NOT push down on the red locking tab. Pull the tab away from the connector until the connector is unlocked, and then continue pulling the main body of the connector to fully disconnect it.
  3. Install the hood latch actuator cable to the hood latch.
    Note
    Engage cable clips and install cable end to latch arm.
  4. Install the hood latch cover. See Cover - Hood Latch (Remove and Replace).
  5. Place vehicle into Service Mode Plus. See Service Mode Plus.
  6. SelectClosures > Frunk > Frunk Latch Metric Reset > Confirm, and click Run and allow the routine to complete.
  7. Exit vehicle into Service Mode Plus. See Service Mode Plus.
  8. Close LH front door.
