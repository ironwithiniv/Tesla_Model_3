Seal - Axle - Rear Drive Unit - LH (Remove and Replace)

Correction code 40301002 0.90 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2023-11-07: Modified last step in Installation section to refer to Alignment Requirement tables to define what type of alignment is required.
Special tools required for this procedure:
  • 1454928-00-ATOOL, SEAL PULLER, ADJUSTABLE, MS/MX/M3
  • 1131206-00-A Install Tool, Output Seal, Model 3
Parent topic: 4030 - Rear Gearbox and Halfshafts

Remove

  1. Remove the LH rear drive unit halfshaft. See Halfshaft - Rear Drive Unit - LH (Remove and Replace).
  2. Use the adjustable seal puller tool to remove the LH output seal from the rear drive unit.

Install

  1. Use the seal install tool to install the new seal into the rear drive unit.
    Note
    Fully tap around the seal install tool to install the new seal. Make sure that the seal is fully flush with the rear drive unit casting.
  2. Install the LH rear drive unit halfshaft. See Halfshaft - Rear Drive Unit - LH (Remove and Replace).
  3. Refer to the Alignment Requirement tables to determine whether an EPAS alignment check (EC) or four wheel alignment check (AC) is necessary. If performed, add the alignment check/adjust correction code as a separate activity to the SV. See Alignment Requirement - Suspension.
