Chiller (Heat Pump) (Remove and Replace)

Correction code 18401602 1.02 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2024-03-10: Re-organized the procedure and updated the routines.
  • 2023-04-04: Updated A/C oil type to be used with reference to Fluids and Capacities for A/C oil specifications.
Equipment:
  • 1065131-00-A KIT, BATTERY COOLANT DRAIN & FILL
Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
Note
This procedure requires the A/C Refrigerant (Recovery and Recharge) procedure to be performed. If not already automatically added to the Service Visit, add correction code 18200102 as a separate correction within the same activity to the Service Visit.
Parent topic: 1840 - Supermanifold

Remove

  1. Set up the A/C machine.
  2. Open the LH front door and lower the LH front window.
  3. Raise and support the vehicle.
  4. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  5. Enable Service Mode. See Service Mode.
  6. On the touchscreen, touch Service Mode > Thermal > Refrigerant System > Start Thermal Fill Drain (Coolant & Refrigerant) and select Run, and then allow the routine to complete.
  7. Disconnect 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  8. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  9. Recover the A/C refrigerant. See A/C Refrigerant (Recovery and Recharge).
  10. Place the fluid catcher underneath the front of the vehicle.
  11. Use the battery coolant drain & fill kit to evacuate the coolant from the coolant bottle.
    Note
    Place the evacuation hose in the left front corner of the coolant bottle to evacuate as much coolant as possible.
  12. Disconnect the powertrain bypass hose from the Supermanifold.
    Note
    This will drain the coolant reservoir.
  13. Disconnect the radiator outlet hose from the Supermanifold.
  14. Disconnect the radiator inlet hose from the Supermanifold.
  15. Install three male plugs into the coolant ports at the front of the Supermanifold.
  16. Remove the bolt that attaches the supermanifold-to-compressor A/C line to the supermanifold.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  17. Remove the supermanifold-to-compressor A/C line from the supermanifold, and then hang it on the underhood storage unit support beam using an s-hook.
    Note
    Carefully hang the line so that oil does not drip out.
  18. Release the connector lock, and then disconnect the electrical connector of the EXV chiller.
    CAUTION
    DO NOT push down on the red locking tab. Pull the tab away from the connector until the connector is unlocked, and then continue pulling the main body of the connector to fully disconnect it.
  19. Use a pick to pull the locking tab downward, and then pull toward the front of the vehicle to remove the EXV coil.
  20. Remove the bolts (x4) that attach the chiller to the supermanifold.
    Tip
    Use of the following tool(s) is recommended:
    • 8 mm socket
    • 4 in extension
    • Flex head ratchet/flex head torque wrench
  21. Slightly release the right side of the chiller and allow the coolant to drain.
  22. Remove the chiller from the vehicle.
  23. Remove and discard the chiller gasket from the supermanifold.

Install

  1. Install a new chiller gasket (1551724-00-A) to the supermanifold.
  2. Lubricate the EXV threads and O-rings with the appropriate A/C oil. See Fluids and Capacities for A/C oil specifications. Then hand-start the valve into the supermanifold.
  3. Tighten the bolts (x4) that attach the chiller to the supermanifold. Follow the sequence below in the example image to torque the 4 bolts.
    8 Nm (5.9 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 8 mm socket
    • 4 in extension
    • Flex head ratchet/flex head torque wrench
  4. Install the EXV chiller coil.
    Note
    Align the locking tab on the connector assembly with the recess in the EXV.
    Note
    Perform push-pull-push test to make sure coil is fully seated.
  5. Connect the chiller EXV connector.
  6. Install new seal washers on the supermanifold side of the supermanifold-to-compressor A/C line, and then lubricate the washers with a small amount of the appropriate A/C oil. See Fluids and Capacities for A/C oil specifications.
  7. Position the supermanifold-to-compressor A/C line on the supermanifold, and then hand tighten the bolt that attaches the A/C line to the supermanifold.
  8. Tighten the bolt that attaches the A/C line to the supermanifold.
    22 Nm (16.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  9. Install the radiator outlet hose to the Supermanifold.
    Note
    Perform a push-pull-push test to make sure the hose is fully seated. Do not wiggle the hose at the connection.
  10. Install the radiator inlet hose to the Supermanifold.
    Note
    Perform a push-pull-push test to make sure the hose is fully seated. Do not wiggle the hose at the connection.
  11. Install the powertrain bypass hose to the Supermanifold.
    Note
    Perform a push-pull-push test to make sure the hose is fully seated. Do not wiggle the hose at the connection.
  12. Perform a coolant vacuum refill. SeeCooling System (Vacuum Refill).
  13. Remove the fluid catcher from underneath the vehicle.
  14. Install the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  15. Perform the vacuum leak test and refill A/C refrigerant. See A/C Refrigerant (Recovery and Recharge).
  16. Connect 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  17. Unlock the vehicle gateway. See Gateway (Unlock).
  18. On the touchscreen, tap the Service Mode "wrench" (at the bottom of the touchscreen UI), and then tap Thermal > Stop Thermal Fill Drain, and allow the routine to complete.
  19. Tap Coolant System > Coolant Purge > Run, and close once the routine is passed.
  20. Inspect the coolant level and make sure the fluid level is at the Max line.
  21. Tap Sensors and Valves > Run Heat Pump Commissioning > Run, and close once the routine is passed.
  22. Tap Actions > Test Thermal Performance > Run, and close once the routine is passed.
  23. Tap Actions > Test HVAC Performance > Run, and close once the routine is passed.
  24. Exit Service Mode. See Service Mode.
  25. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  26. Raise the LH front window and close the LH front door.
