Stop - Trunk - LH (Remove and Replace)

Correction code 11330902 0.06 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-09-10: Update title from Liftgate Stop to Trunk Stop.
Equipment:
  • 1588903-00-A Body Gap and Flush Tool
Parent topic: 1133 - Closure Assist Mechanisms and Hinges

Remove

  1. Use the body gap and flush tool to measure the gap of liftgate and record the value.
  2. Open trunk from exterior switch.
  3. Remove the LH liftgate stop.

Install

  1. Install the LH liftgate stop.
  2. Close trunk from exterior switch.
  3. Verify gap/flush of liftgate, and adjust it if necessary.
