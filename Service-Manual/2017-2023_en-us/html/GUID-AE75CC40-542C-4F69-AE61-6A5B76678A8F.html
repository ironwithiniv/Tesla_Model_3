Ground Strap - Rear Drive Unit (Remove and Replace)

Correction code 40012202 1.80 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-12-04: Added steps to lower subframe.
Parent topic: 4001 - Rear Drive Unit Assembly

Remove

  1. Disconnect the rear subframe assembly and lower it approximately 8 cm from the vehicle. See Subframe Assembly - Rear (Remove and Install).
    CAUTION
    Do not fully lower or remove the subframe. Doing so will damage surrounding components which are still attached.
  2. Release the clip that attaches the rear drive unit ground strap to the subframe.
  3. Remove the bolt that attaches the rear drive unit ground strap to the rear drive unit assembly.
    Tip
    Use of the following tool(s) is recommended:
    • 10mm socket
    • 4 in extension

Install

  1. Install the bolt that attaches the rear drive unit ground strap to the rear drive unit assembly.
    6 Nm (4.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10mm socket
    • 4 in extension
  2. Install the clip that attaches the rear drive unit ground strap to the subframe.
  3. Install the rear subframe assembly. See Subframe Assembly - Rear (Remove and Install).
