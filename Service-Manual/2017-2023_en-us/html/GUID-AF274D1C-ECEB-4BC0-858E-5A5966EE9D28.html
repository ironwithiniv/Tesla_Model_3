Chime - Power Trunk (Remove and Replace)

Correction code 21214302 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. Torque Specifications

Description Torque Value Recommended Tools Reuse/Replace Notes
Screws that attach the chime to the power trunk lid trim
2.3 Nm (1.7 lbs-ft)
  • Torx T20 socket
 Reuse

Remove

  1. Remove the power trunk lid trim and place the trim on a clean working surface. See Trim - Lid - Power Trunk (Remove and Replace).
  2. Disconnect the electrical harness from the power chime.
  3. Remove the screws that attach the power trunk chime to the power trunk lid trim, and then remove the chime from the trim.
    2.3 Nm (1.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket

Install

Installation procedure is the reverse of removal, except for the following:

Remove the protective cover from the tape on the back of the new chime.
