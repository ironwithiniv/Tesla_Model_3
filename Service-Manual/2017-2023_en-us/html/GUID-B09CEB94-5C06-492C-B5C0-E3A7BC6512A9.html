Sensor - Level - Windshield Washer (Remove and Replace)

Correction code 17501902 0.66 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1750 - Wipers and Washers

Remove

  1. Open the LH front door and lower the LH front window.
  2. Turn the steering wheel fully to the left.
  3. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  4. Remove the LH and RH wiper arms. See Wiper Arms (Remove and Replace).
  5. Remove the cowl screen panel. See Panel - Cowl Screen (Remove and Replace).
  6. Remove the wiper motor. See Wiper Module (Remove and Replace).
  7. Release the clip that attaches the electrical harness to the windshield washer reservoir.
  8. Peel back the LH front wheel liner and remove the lower bolt that attaches the windshield washer reservoir to the body.
    Tip
    Use of the following tool(s) is recommended:
    • 10mm Flex Head combination wrench
    • 10 mm socket
    • Flashlight LED
  9. Remove the upper bolt that attaches the windshield washer reservoir to the body.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  10. Release the washer level sensor connector.
  11. Release the washer pump connector.
  12. Remove the windshield washer reservoir from the vehicle, and then recover any fluid from the reservoir.
  13. Use a plastic trim tool to remove the level sensor from the grommet at the side of the reservoir.

Install

  1. Install the level sensor into the grommet at the side of the reservoir.
    Note
    Secure the grommet onto the reservoir first, and then install the level sensor. Make sure that the flat edge of the sensor is up and fits flush with the reservoir. Use P-80 emulsion seal lubricant as needed. Verify sensor is fully and properly seated. If the grommet is damaged, replace it with a new one.
  2. Connect the washer level sensor connector.
  3. Connect the washer pump connector.
  4. Install the upper bolt that attaches the windshield washer reservoir to the body.
    3 Nm (2.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  5. Peel back the LH front wheel liner and install the lower bolt that attaches the windshield washer reservoir to the body.
    3 Nm (2.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10mm Flex Head combination wrench
    • 10 mm socket
    • Flashlight LED
  6. Fill the windshield washer reservoir with fluid.
  7. Fasten the clip that attaches the electrical harness to the windshield washer reservoir.
  8. Install the wiper motor. See Wiper Module (Remove and Replace).
  9. Install the cowl screen panel. See Panel - Cowl Screen (Remove and Replace).
  10. Install the LH and RH wiper arms. See Wiper Arms (Remove and Replace).
  11. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  12. Center the steering wheel.
  13. Raise the LH front window and close the LH front door.
