Bracket - Rear - Center (Remove and Replace)

Correction code 10014302 1.08 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1001 - Bumper / Fascia

Torque Specifications

Table 1. Torque Specifications: Bracket - Rear - Center (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts that attach the rear center bracket to the body
4 Nm (2.9 lbs-ft)
  • 10 mm socket
 Reuse

Remove

  1. Remove the rear fascia. See Fascia - Rear (Remove and Install).
  2. Disconnect the electrical wiring harness connector from the rear Bluetooth passive entry module.
  3. Remove the bolt and release the clip that attach the Bluetooth passive entry module to the body, and then remove the module from the bracket.
    Note
    Use of the following tool(s) is recommended:
    • T30 socket
    • 2 in extension
  4. Release the clips that attach the electrical harness to the rear center bracket assembly.
    Note
    The end clip is hidden by the electrical connector.
  5. Remove the bolts that attach the rear center bracket to the body.
    Note
    Use of the following tool(s) is recommended:
    • 10 mm socket
    • 4 in extension
  6. Remove the rear center bracket from the vehicle.

Install

  1. Install the bolts that attach the rear center bracket to the body.
    4 Nm (2.9 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • 10 mm socket
    • 4 in extension
  2. Install the clips that attach the rear Bluetooth passive entry antenna electrical harness to the rear center bracket.
  3. Install the bolt that attaches the Bluetooth passive entry module to the body.
    3.5 Nm (2.6 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • T30 socket
    • 2 in extension
  4. Connect the electrical wiring harness connector to the rear Bluetooth passive entry module.
  5. Install the rear fascia. See Fascia - Rear (Remove and Install).
