Breather - Rear Drive Unit (Remove and Replace)

Correction code 40305402 1.38 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-03-31: Added step to refer to the suspension alignment tables to define whether an alignment check is required and, if so, what type of alignment check is required.
Parent topic: 4030 - Rear Gearbox and Halfshafts

Remove

  1. Remove the rear subframe assembly. See Subframe Assembly - Rear (Remove and Install).
  2. Remove the breather from the rear drive unit.

Install

  1. Install the breather onto the rear drive unit.
    5 Nm (3.7 lbs-ft)
  2. Install the rear subframe assembly. See Subframe Assembly - Rear (Remove and Install).
  3. Since the subframe was removed and reinstalled: Refer to the Alignment Requirement tables to determine whether an EPAS alignment check (EC) or four wheel alignment check (AC) is necessary. If performed, add the alignment check/adjust correction code as a separate activity to the SV. See Alignment Requirement - Suspension.
