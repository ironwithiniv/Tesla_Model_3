Firmware Update - CHAdeMO Charging Adapter

Correction code 50011003 0.10 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2023-03-27: Updated to latest validation.
  • 2024-10-31: Added extra steps for vehicles in Japan.

Special tools required for this procedure:

Part Number Description
1045160-00-A CHAdeMO Programming Tool, Turn-key
1076919-00-A Adapter DC Power Supply 60W 12V
1016990-00-A Tool, Gridconnect USB to CAN Adapter
Parent topic: 5003 - Charging Adapters

Procedure

  1. Start Toolbox 2 on a laptop configured with Toolbox 2, and sign in if necessary.
    Note
    For vehicles in Japan, skip this step.
  2. In Toolbox 2, click Options > Plugins, and then confirm that the CHAdeMO plugin is available and green.
  3. Connect the CHAdeMO programming tool CAN connector to the USB to CAN adapter, and then connect the tool power connector to the 12V DC power supply.
    Note
    Do not plug in the power supply at this time.
  4. Connect the USB to CAN adapter to the laptop, and then plug in the 12V DC power supply.
    Note
    If the laptop requests that a driver should be downloaded and/or installed, do this now. The driver can be manually downloaded from http://www.peak-system.com/fileadmin/media/files/usb.zip.
  5. Connect the CHAdeMO programming tool to the CHAdeMO adapter.
    Note
    Make sure that the tabs of the tool align with the slots in the adapter.
  6. In the lower left corner of Toolbox 2 there are two grey buttons, click the button on the right.
  7. In the window that opens, from the Vehicle drop-down menu, select Tesla CHAdeMO Adapter, from the Bus drop-down menu, select SE, select Enable Diagnostics, and then click Enable.
    Note
    Make sure that the RH button turns green. If not, check all connections.
    Note
    For vehicles in Japan, follow below steps to recover the faulty connection, upload and update the customized firmware for Japan CHAdeMO adapter:
    1. Disable the firmware connection by clicking Disable.
    2. Restart the Toolbox 2, then repeat steps 2 through 6.
    3. Click Use Custom Firmware.
    4. Choose the update file corresponding to PCBA ID stored in desktop file.
    5. In the window that opens, read the text, and then click Play.
    6. When Firmware downloads is complete, go to step 9.
  8. In Toolbox 2, click Panels > Charging > CHAdeMO Adapter Firmware Update.
  9. In the window that opens, read the text, and then click Play.
  10. After the update has completed, note the new firmware version into the service visit, and then click Finish.
  11. Disconnect the CHAdeMO programming tool from the CHAdeMO adapter.
  12. Unplug the 12V DC power supply, and then disconnect the USB to CAN adapter from the laptop.
  13. Disconnect the CHAdeMO programming tool power connector from the 12V DC power supply, and then disconnect the tool CAN connector from the USB to CAN adapter.
  14. If no further use, close Toolbox 2.
