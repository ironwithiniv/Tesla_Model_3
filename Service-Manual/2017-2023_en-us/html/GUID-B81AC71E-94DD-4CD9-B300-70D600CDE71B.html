Install Heli-Coil Inserts

  • 2026-11-6: Released procedure as Service Manual topic. Converted from TN-15-92-001.
CAUTION
This is a generic procedure. Refer to the Heli-Coil documentation before attempting to repair damaged or stripped threads.
CAUTION
To prevent galvanic corrosion, primer-free Heli-Coil inserts with a black coating are required for repairing threads in aluminum components. Stainless steel inserts should only be used to repair threads in steel components.
Warning
Heli-Coil inserts cannot be used to repair damaged threads in rivet nuts of any kind.
Note
For questions about which type of insert to use and/or to determine if it is permitted to repair the threads in a particular location:

Procedure

  1. Check the thread size of the bolt being installed and select the appropriate size Heli-Coil insert.
  2. Use a drill with the correct size bit and cylindrical guide to drill out the damaged or stripped threads.
    Note
    If the threaded hole is a through hole, drill completely through it. If the threaded hole is a blind hole, drill to the bottom of the hole using a drill stop collar or tape to mark the depth.
    Note
  3. Use a T-handle and the appropriately sized tap from the kit to cut new threads. Once the tap begins cutting the threads, turn the T-handle back every half turn to clear the metal shavings.
    CAUTION
    Ensure that the tap is straight and perpendicular to the hole while cutting the threads.
    Note
    Use cutting oil to lubricate the tap as necessary.
  4. Use a blow gun and spray compressed air inside the hole to remove all metal shavings and cutting oil.
    Warning
    Wear eye protection to avoid personal injury.
  5. Screw the Heli-Coil insert onto the end of the installation tool until the end of the installation tool is flush with the tang.
  6. Install the Heli-Coil insert until the top is half of a turn below the top of the threads.
    Note
    If the Heli-Coil insert is taller than the hole, trim the top of the insert until it is flush with the top of the hole.
    Note
    Multiple Heli-Coil inserts can be used if the hole is deeper than a single Heli-Coil insert.
  7. Remove the installation tool by unscrewing it from the Heli-Coil insert.
  8. Use the tang break-off tool and a hammer to break the tang from the bottom of the Heli-Coil insert.
  9. Use a blow gun and spray compressed air inside the hole to remove the tang and all metal shavings.
    Warning
    To avoid personal injury, eye protection must be worn when performing this step.
    Note
    If necessary, use a magnet to remove the tang.
  10. Install and torque the bolt per the relevant service procedure.
