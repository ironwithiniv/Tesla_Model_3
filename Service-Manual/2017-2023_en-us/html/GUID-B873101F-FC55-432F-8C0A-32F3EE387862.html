Antenna - eCall (LHD) (Remove and Replace)

Correction code 21341002 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 2134 - Antenna - eCall

Remove

Note
This procedure applies to vehicles built before October 5th, 2020. For vehicles built on or after October 5th, 2020, the eCall antenna makes use of the cellular antenna that is located in the LH MIMO antenna unit. See Antenna - MIMO - LH (Remove and Replace) for Remove and Replace instructions.
  1. Remove the RH air wave duct. See Duct - Air Wave - RH (LHD) (Remove and Replace).
  2. Disconnect the electrical connectors from the eCall antenna.
  3. Remove the screws (x2) that attach the eCall antenna to the IP assembly (torque 2.7 Nm).
  4. Remove the eCall antenna from the vehicle.

Install

Installation procedure is the reverse of removal.
