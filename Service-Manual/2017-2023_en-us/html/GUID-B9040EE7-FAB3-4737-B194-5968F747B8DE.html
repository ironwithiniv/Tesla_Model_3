Hall Sensor - Exterior Release - Door - Front - LH (Remove and Replace)

Correction code 11455002 0.54 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-09-05: Added disconnecting/connecting LV battery power steps, and added the window calibration routine.
Parent topic: 1145 - Exterior Door Handles

Remove

  1. Remove the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Install).
  2. Remove the LH front door inner belt seal. See Seal - Inner Belt - Front Door - LH (Remove and Replace).
  3. Remove the front LH door glass. See Glass - Door - LH - Front (Remove and Replace).
  4. Disconnect the LV battery power. See 12V/LV Power (Disconnect and Connect).
  5. Disconnect the electrical wiring harness from the LH door mirror connectors (x3), and remove the harness brackets from the door.
  6. Remove the LH front door closeout panel. See Closeout Panel - Door - Front - LH (Remove and Replace).
  7. Remove the front LH door exterior release handle. See Handle - Exterior Release - Door - Front - LH (Remove and Replace).
  8. Remove the screws that attach the hall sensor to the LH door exterior release handle, and then remove the hall sensor from the release handle.

Install

  1. Install the screws that attach the hall sensor to the LH door exterior release handle.
    1.2 Nm (.9 lbs-ft)
  2. Install the front LH door exterior release handle. See Handle - Exterior Release - Door - Front - LH (Remove and Replace).
  3. Install the LH front door closeout panel. See Closeout Panel - Door - Front - LH (Remove and Replace).
  4. Install the harness brackets to the door, and then connect the electrical wiring harness to the LH door mirror connectors (x3).
  5. Install the front LH door glass. See Glass - Door - LH - Front (Remove and Replace).
  6. Connect the LV battery power. See 12V/LV Power (Disconnect and Connect).
  7. Install the LH front door inner belt seal. See Seal - Inner Belt - Front Door - LH (Remove and Replace).
  8. Install the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Install).
  9. Locally connect a laptop with Toolbox 3 to the vehicle. See Toolbox (Connect and Disconnect).
  10. Sit on the driver seat and close the LH front door.
  11. On the laptop, click the Actions tab, type "Window" into the search field, click TEST-SELF_VCLEFT_FRONT-L_CALIBRATE-WINDOWvia Toolbox:(link), click Run, and allow the routine to complete.
    Note
    The window will cycle up and down while performing the routine.
  12. Press and hold the LH front window switch to activate the auto-lower function, and then raise the window completely to activate the auto-raise function.
  13. Disconnect the laptop.
  14. On the touchscreen, press and hold the Exit Service Mode button to exit Service Mode Plus.
