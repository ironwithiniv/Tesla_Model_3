Carpet - Rear Trunk (1-Piece) (Remove and Replace)

Correction code 15245402 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1530 - Carpeting and Mats

Remove

  1. Remove the trunk sill trim. See Trim - Sill - Trunk (Remove and Replace).
  2. Release the clips that attach the trunk carpet to the sill.
  3. Remove the LH 2nd row seat back. See Seat Back - 2nd Row - LH (Remove and Replace).
  4. Remove the RH 2nd row seat back. See Seat Back - 2nd Row - RH (Remove and Replace).
  5. Release the clips that attach the trunk carpet to the 2nd row area.
  6. Lift the trunk carpet off the ISOFIX bars.
  7. Release the clips that attach the trunk carpet to the body studs, and then remove the trunk carpet from the vehicle.

Install

Installation procedure is the reverse of removal.
