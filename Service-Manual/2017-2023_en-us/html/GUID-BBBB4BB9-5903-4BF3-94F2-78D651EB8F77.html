Harness - Subframe - Rear (Remove and Replace)

Correction code 17102002 0.90 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-04-02: Split the procedure into "Remove" and "Install" sections for clarity purposes.
Parent topic: 1710 - Harnesses

Remove

  1. Raise and support vehicle
    Note
    Ensure vehicle is not charging before lifting it off the ground
  2. Lower LH front window
  3. Open all four doors
    Note
    If vehicle is being powered down, Latch rear doors to prevent accidental closure
  4. Move LH front seat forward
  5. Move RH front seat forward
  6. Remove 2nd row seat cushion and disconnect harness
    Note
    2x tabs, 2x connectors, Press tab toward LH side of vehicle on each side to release front edge of seat cushion
  7. Open hood
  8. Power off vehicle from center display
    Note
    Via Controls > Safety & Security > Vehicle Power > Power Off, Confirm power off at warning dialogue box
  9. Remove rear apron
    Note
    12x clips, only store the rear apron visible face upwards
  10. Disconnect 12V negative terminal
    Note
    1x nut, 10mm, 6 Nm, Ensure the vehicle is in park, climate control system is off, and vehicle is not charging before disconnecting 12V
  11. Remove 12V cap from ancillary bay
    Note
    1x cap
  12. Disconnect HVC logic connector and install logic cap
    Note
    1x connector, 1x cap, Release locking tab then push the handle downward to release connector
  13. Remove all items from pockets and ensure not wearing metal items
  14. Inspect HV insulating gloves
    Note
    Check gloves for damage prior to each use, Refer to service document TN-15-92-003 R5, for information on inspecting HV gloves, https://service.tesla.com/docs/ServiceBulletins/External/TN/TN-15-92-003_High_Voltage_Awareness_Care_Points_R5.pdf
  15. Put on HV insulating gloves and leather over gloves
    Note
    Make sure to wear Electrical Protective Gloves any time Hioki tester is used
  16. Remove bolts securing ancillary bay probe lid cover to ancillary bay cover
    Note
    2x bolts, E10 5-Lobe, 6 Nm, Discard after removal
  17. Remove ancillary bay probe lid cover from the ancillary bay cover
  18. Verify no high voltage
    Note
    Make sure to wear PPE (HV gloves, safety glasses) when working on high voltage component, Measure B+ to Ground, B- to Ground, B+ to B-, If voltage is greater than 10V, Pack contactors are not open or welded, Stop work and reach out to Service Engineering
  19. Inspect ancillary bay probe lid cover gasket then position onto the ancillary bay cover
    Note
    Confirm no visual damage present,Good to reuse seal
  20. Install bolts securing ancillary bay probe lid cover to ancillary bay cover
    Note
    2x bolts, E10 5-Lobe, 6 Nm, Install new fasteners
  21. Raise vehicle fully and lower lift onto locks
    Note
    Set vehicle to comfortable working height, Make sure there's an audible click of the locks on both sides before lowering, otherwise vehicle may tilt to the side, Verify doors are clear of surrounding objects
  22. Remove mid aero shield
    Note
    13x bolts, 10mm, 5 Nm
  23. Remove bolts securing the rear diffuser to body
    Note
    6x bolts, 10mm, 4 Nm, 2x fastener covers
  24. Remove outer bolts securing rear diffuser to rear fascia assembly
    Note
    4x bolts, 10mm, 3 Nm
  25. Remove lower clips securing LH rear wheel liner
    Note
    3x push clips
  26. Remove lower clips securing the RH rear wheel liner
    Note
    3x push clips
  27. Remove bolts securing rear lower fascia to rear fascia diffuser
    Note
    2x bolts, 10mm, 3 Nm
  28. Release tabs securing rear diffuser to rear fascia and remove from vehicle
    Note
    10x tabs, Start from one side and work your way across while releasing tabs
  29. Remove LH rear wheel speed sensor harness connector clip from subframe
    Note
    1x clip
  30. Disconnect LH rear wheel speed harness
    Note
    1x connector, Release locking tab, Use mechanical hands to hold the connector end on subframe harness side
  31. Remove RH rear wheel speed sensor harness connector clip from subframe
    Note
    1x clip
  32. Disconnect RH rear wheel speed sensor connector
    Note
    1x connector
  33. Disconnect harness from ride height level sensor
    Note
    1x connector, Press the locking tab on the right side of the connector and pull down to release
  34. Remove the harness clip to the ride height level sensor
    Note
    1x clip
  35. Disconnect RH side 12V subframe harness connector
    Note
    1x connector, Release locking tab
  36. Remove RH side 12V subframe harness clip from body
    Note
    1x barrel clip
  37. Disconnect LH side 12V subframe harness connector
    Note
    1x connector
  38. Remove LH side 12V subframe harness clip from body
    Note
    1x barrel clip
  39. Release clips securing subframe harness to bottom rear of subframe
    Note
    2x clips
  40. Disconnect oil pump connector
    Note
    1x connector
  41. Disconnect resolver connector from drive unit
    Note
    1x connector, 2x clips, Release locking tab
  42. Disconnect RDU 12V connector
    Note
    1x connector, Release locking tab then push the handle downward to release connector
  43. Remove RDU 12V harness clip
    Note
    1x clip
  44. Loosen the clip that secures the inverter and coolant hose to the RDU
    Note
    3x clips
  45. Release clips securing subframe harness to top of rear subframe
    Note
    4x clips
  46. Release clips securing subframe harness to left and right of subframe
    Note
    2x clips, There is enough space to use the clip prytool to release the clips
  47. Remove the harness from the subframe
    Note
    Take out the harness from the gap between the RDU and the subframe, and take out the harness from left to right

Install

  1. Install the harness to the subframe
    Note
    Pass the new harness through the gap between the subframe and RDU from right to left, and fix the harness on the subframe, taking care not to damage the harness
  2. Install rear subframe harness into position and secure clips along left and right of subframe
    Note
    2x clips
  3. Install clips securing subframe harness to top of rear subframe
    Note
    4x clips
  4. Secure the coolant hose to the RDU
    Note
    3x clips
  5. Connect LH rear wheel speed sensor
    Note
    1x connector
  6. Install harness connector clip to subframe
    Note
    1x clip
  7. Connect RH rear wheel speed sensor connector
    Note
    1x connector
  8. Install harness connector clip to subframe
    Note
    1x clip
  9. Plug in the connector to the ride height level sensor
    Note
    1x connector, 1x locking tab
  10. Install the harness clip to the ride height level sensor
    Note
    1x harness clip
  11. Install RDU 12V harness clip
    Note
    1x clip
  12. Install RDU 12V connector
    Note
    1x connector, Engage locking handle
  13. Connect resolver connector to drive unit
    Note
    1x connector, 2x clips, Engage locking tab
  14. Connect the oil pump connector
    Note
    1x connector, Engage locking tab
  15. Install clips securing subframe harness to bottom rear of subframe
    Note
    2x clips
  16. Install LH side 12V subframe harness clip to body
    Note
    1x barrel clip
  17. Connect LH side 12V subframe harness connector
    Note
    1x connector
  18. Install RH side 12V subframe harness clip to body
    Note
    1x barrel clip
  19. Connect RH side 12V subframe harness connector
    Note
    1x connector
  20. Install rear diffuser to vehicle then engage tabs securing it to fascia
    Note
    10x tabs
  21. Install the bolts securing the rear diffuser to inner rear fascia
    Note
    2x bolts, 10mm, 3 Nm
  22. Install outer bolts securing rear diffuser to rear fascia assembly
    Note
    4x bolts, 10mm, 3 Nm
  23. Apply Loctite 222 onto rear diffuser bolts and install bolts securing rear diffuser to body
    Note
    6x bolts, 10mm, 4 Nm, 2x fastener covers, Number of bolts may vary on newer vehicles
  24. Apply Loctite 222 onto mid aero shield bolts and install mid aero shield
    Note
    13x bolts, 10mm, 5 Nm
  25. Lower vehicle until tires are touching the ground
    Note
    Raise lift off locks, then hold lock release lever to keep locks free while vehicle is lowered
  26. Remove logic cap and connect the HVC logic connector
    Note
    1x connector, 1x cap, Align connector then pull the handle to locking position get connector fully seated
  27. Install 12V cap to ancillary bay
    Note
    1x cap
  28. Connect 2nd row seat cushion harness and install 2nd row seat cushion
    Note
    2x connectors, 2x clips, Insert the seat belt buckles through the holes, Slide rear cushion inward then align front guide tabs to locking tabs, Make sure cushion is fully seated with push & pull test near clips
  29. Connect 12V negative terminal
    Note
    1x nut, 10mm, 6 Nm
  30. Install cabin intake upper duct assembly
    Note
    3x clips, Older vehicles may be equipped with 4x clips
  31. Install rear apron
    Note
    12x clips, If present untuck cut loop label and make sure it is still visible after apron is installed, Later builds may not have label
  32. Close hood
  33. Move RH front seat to original position
  34. Move LH front seat to original position
  35. Raise LH front window
  36. Close all four doors
    Note
    Unlatch rear doors before closing
  37. Remove lift arms from below vehicle
