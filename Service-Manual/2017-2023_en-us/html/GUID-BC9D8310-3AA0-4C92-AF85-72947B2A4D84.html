Hose - Inverter Inlet - Front Drive Unit (Non-Heat Pump) (Remove and Replace)

Correction code 18300112 1.08 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1830 - Cooling System

Remove

  1. Remove the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Remove the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  4. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  5. If equipped, remove the RH front wheel center cap. See Cap - Wheel (Remove and Replace).
  6. Loosen the RH front wheel lug nuts.
  7. Raise the vehicle. See Raise Vehicle - 2 Post Lift.
  8. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  9. Partially lower the vehicle, and then remove the RH front wheel. See Wheel Assembly (Remove and Install).
  10. Remove the RH front wheel arch liner. See Wheel Arch Liner - Front - LH (Remove and Replace).
  11. Fully raise the vehicle, and then position a coolant drain container underneath the RH front side of the HV battery.
  12. Release the clip to separate the front drive unit inverter coolant inlet hose, and then drain the coolant into the coolant drain container.
  13. Plug the female side of the front drive unit inverter coolant inlet hose.
  14. Release the clip that attaches the front drive unit inverter inlet hose to the vehicle.
  15. Release the clip that attaches the front drive unit inverter inlet hose to the front subframe.
  16. Release the clip that attaches the front drive unit inverter inlet hose to the exterior of the front drive unit gearbox.
  17. Release the clip that connects the front drive unit inverter inlet hose to the front drive unit inverter coolant coupling, and then remove the hose from the vehicle.

Install

  1. Position the front drive unit inverter inlet hose to the vehicle, and then install the clip that connects the hose to the front drive unit inverter coolant coupling.
    CAUTION
    Perform a push-pull test to verify that the hose is fully seated.
  2. Install the clip that attaches the front drive unit inverter inlet hose to the exterior of the front drive unit gearbox.
  3. Install the clip that attaches the front drive unit inverter inlet hose to the front subframe.
  4. Remove the plug, and then install the clip to reconnect the front drive unit inverter inlet hose.
    CAUTION
    Perform a push-pull test to verify that the hose is fully seated.
  5. Install the clip that attaches the front drive unit inverter inlet hose the vehicle.
  6. Remove the coolant drain container from underneath the vehicle.
  7. Install the RH front wheel arch liner. See Wheel Arch Liner - Front - LH (Remove and Replace).
  8. Position the RH front wheel on the vehicle, and then hand-tighten the wheel lug nuts.
  9. Install the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  10. Lower the vehicle, and then tighten the RH front wheel lug nuts. See Wheel Assembly (Remove and Install).
    Note
    Use only hand tools to remove or install the fasteners. Do not use impact or power tools.
    Note
    Use a 6 point socket. Do not use a 12 point socket or a specialty socket.
  11. If equipped, install the RH front wheel center cap. See Cap - Wheel (Remove and Replace).
  12. Connect 12V power. See 12V/LV Power (Disconnect and Connect).
  13. Refill the cooling system. See Cooling System (Vacuum Refill).
  14. Install the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  15. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  16. Install the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
