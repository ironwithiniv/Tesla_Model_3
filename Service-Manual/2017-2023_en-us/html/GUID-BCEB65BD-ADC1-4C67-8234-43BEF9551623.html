Defrost Cover - Instrument Panel - LH (Remove and Replace)

Correction code 14051502 1.68 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
  1. Open both front doors
  2. Lower both front windows
  3. Move LH front seat backward
  4. Move RH front seat backward
  5. Clear DAS Calibration through UI
    Note
    Controls > Service > Camera Calibration, Select Clear Calibration, Verify calibration was cleared successfully, Wait for prompt to disappear automatically before continuing, Calibration in Progress message and progress icon will appear during the next drive cycle
  6. Open hood
    Note
    Press "Open" button on the touchscreen to release the latch, Lift the lid manually
  7. Remove rear apron
    Note
    12x clips, Only store rear apron visible face upwards
  8. Remove cabin intake upper duct assembly
    Note
    4x clips, Heat pump vehicles have 3x clips
  9. Remove closeout panel from frunk assembly
    Note
    4x clips, 1x connector, Frunk safety switch, 3x guide tabs, Grab closeout panel from bottom then pull it upward to release clips, Disconnect the switch
  10. Remove frunk assembly carpet
  11. Remove bolts securing frunk assembly
    Note
    7x bolts, 10mm, 5 Nm, Lift up RBN covers to access upper fasteners, Newer vehicles may not be equipped with covers
  12. Remove frunk assembly from vehicle
    Note
    12x clips, Replace any clips if broken or missing, Number of clips may vary on older vehicles
  13. Remove LH wiper arm nut cover
    Note
    1x cover
  14. Disconnect washer hose from LH wiper arm to Y-tube fitting and release washer hose clips
    Note
    2x clips, 1x hose
  15. Remove the nut securing the LH wiper arm to wiper module
    Note
    1x nut, 15mm, 25 Nm
  16. Remove LH wiper arm and hose assembly from vehicle
  17. Remove RH wiper arm nut cover
    Note
    1x cover
  18. Disconnect washer hose from RH wiper arm to Y-tube fitting and release washer hose clips
    Note
    2x clips, 1x hose
  19. Remove the nut securing the RH wiper arm to wiper module
    Note
    1x nut, 15mm, 25 Nm
  20. Remove RH wiper arm and hose assembly from vehicle
  21. Remove the LH shock tower cover
    Note
    2x push clips
  22. Remove the RH shock tower cover
    Note
    2x push clips
  23. Release cowl screen from windshield and remove from vehicle
    Note
    2x push clips, 6x clips
  24. Disconnect windshield heater connector
    Note
    1x connector
  25. Secure heater harness onto windshield
  26. Remove lower quad camera cover
    Note
    4x tabs, Press on the side of the cover with a trim tool to release some of the tabs
  27. Remove tether from lower quad camera cover
    Note
    2x tabs, Depress tabs to remove tether
  28. Remove rear view mirror
    Note
    Turn mirror counterclockwise to remove, do not twist by holding the mirror itself, it will separate from the stalk, twist from the stalk connecting the mirror to the mount
  29. Disconnect rear view mirror connector
    Note
    1x connector
  30. Remove quad camera upper cover
    Note
    4x clips, 1x connector, Pull the cover down to remove and then disconnect interior camera
  31. Remove triple camera hood
    Note
    2x patch screws, T10, 1 Nm, 2x alignment pins, Discard fasteners after removal
  32. Remove triple camera assembly
    Note
    4x screws, T10, 1 Nm
  33. Disconnect humidity and temperature sensor harness connector
    Note
    1x connector
  34. Remove screw securing windshield harness to windshield bracket and move harness aside
    Note
    1x screw, T10, 1 Nm
  35. Remove GPS/GNSS antenna from bracket
    Note
    1x screw, T10, 1 Nm, 2x tabs, Slide antenna to LH side to release from bracket
  36. Separate harness track from windshield
    Note
    Located above RH visor under headliner, Slide equalizer up against track and carefully tap equalizer to separate from windshield
  37. Prepare WRD Spider 3 glass removal kit
  38. Secure line to starter tool and push tool through urethane at lower RH side of windshield
    Note
    Use the guard to prevent damage to dash pad while using starter tool
  39. Release line from starter tool and wrap line around exterior of windshield
    Note
    Pull line away from starter tool, Ensure enough length is pulled through, Wrap spider line up and around the exterior of windshield, Verify the line sits underneath the glass
  40. Attach anchor point to exterior of windshield and secure line
    Note
    Attach line to anchor once fully wrapped around windshield, Place anchor near starting point of the handle tool
  41. Secure interior side of line to the spider cutting tool
    Note
    Follow instructions on spider tool, Feed line through opening of the cutting tool and tie a knot to secure in place, If spindle is not turned the proper direction the cutting tool will be damaged
  42. Secure spider cutting tool to interior side of windshield
    Note
    Note orientation of the cutting line, Make sure line warps over large pulley and holds at a 90 degree angle
  43. Secure angle driver to electric drill
  44. Turn the spindle on the cutting tool with the drill to start removing the windshield
    Note
    Move the cutting tool as needed keeping the line close to a 90 degree angle, When passing vin plate use guard to guide line over vin to prevent damage
  45. Attach suction cups to windshield on both sides
  46. Lift up to remove windshield from vehicle
    Note
    Recommend assistance, use caution with windshield harness, Partially close hood for clearance
  47. Place windshield on support stand
    Note
    Recommend assistance
  48. Remove old urethane from windshield
  49. Remove sealing strip from windshield
  50. Clean urethane residue from windshield
    Note
    Allow 1 minute dry time
  51. Remove old urethane from vehicle
  52. Remove IP cowl foam
  53. Remove LH defrost cover
    Note
    11x tabs
  54. Install LH defrost cover
    Note
    11x tabs, Secure 2x middle tabs first then secure tabs from middle to LH side of IP, Make sure cover is flush with speaker grill
  55. Install IP cowl foam
  56. Install sealing strip onto windshield
    Note
    Follow windshield alignment marks at upper corners of glass, Start from one corner and peel tape as you apply inch by inch to ensure proper fitment
  57. Measure resistance of heater grid to check continuity
    Note
    Measured at ambient temperature, Tolerance 5.6Ω+/-10%, Check from pin 1 to pin 2 on X304, If resistance is outside tolerance then replace windshield
  58. Perform windshield dry fit
    Note
    Note any locations where net pads need to be adjusted
  59. Perform any net pad adjustments for windshield
    Note
    Add or remove to adjust flush condition if necessary, No time recorded as it was not necessary during validation
  60. Wipe urethane path on vehicle
    Note
    Allow 1 minute dry time
  61. Apply urethane primer to windshield and vehicle body along old urethane path
    Note
    Make sure to add primer over any areas that were scratched during windshield removal, Allow primer to dry for 2 minutes before applying urethane
  62. Prepare caulking gun and urethane
    Note
    Opening must be 8mm wide and 13mm tall
  63. Apply urethane to windshield following primer path
  64. Install windshield onto vehicle
    Note
    Recommend assistance
  65. Check gaps and flushness to vehicle before fully seating windshield
    Note
    Adjust glass as needed
  66. Apply tape to secure windshield to body while urethane cures
  67. Remove suction cups from windshield
  68. Install GPS/GNSS antenna onto bracket
    Note
    1x screw, T10, 1 Nm, 2x tabs, Slide antenna towards RH side to secure tabs
  69. Install screw securing windshield harness to windshield bracket
    Note
    1x screw, T10, 1 Nm, Make sure harness is routed inside of bracket
  70. Connect humidity and temperature sensor harness connector
    Note
    1x connector
  71. Secure trilobe and triple camera assembly onto windshield bracket
    Note
    4x screws, T10, 1 Nm
  72. Install triple camera hood
    Note
    2x patch screws, T10, 1 Nm, 2x alignment pins, Install new fasteners
  73. Install quad camera upper cover
    Note
    4x clips, 1x connector, Connect interior camera then push the cover up to secure
  74. Connect rear view mirror connector
    Note
    1x connector
  75. Install rear view mirror
    Note
    Turn mirror clockwise to install, do not twist by holding the mirror itself, it will separate from the stalk, twist from the stalk connecting the mirror to the mount
  76. Install tether onto lower quad camera cover
    Note
    2x tabs
  77. Install quad camera lower cover
    Note
    4x tabs, Install the tabs closest to the rearview mirror assembly and push the cover up to secure
  78. Move RH front seat to original position
  79. Move LH front seat to original position
  80. Release heater harness from windshield
  81. Connect windshield heater connector
    Note
    1x connector
  82. Install cowl screen assembly
    Note
    2x push clips, 6x clips
  83. Install the RH shock tower cover
    Note
    2x push clips
  84. Install the LH shock tower cover
    Note
    2x push clips
  85. Install the RH wiper arm and hose assembly onto vehicle
  86. Install the nut securing the RH wiper arm to wiper module
    Note
    1x nut, 15mm, 25 Nm, Make sure the wiper tip is aligned between the two indicators at corner of windshield
  87. Connect washer hose from RH wiper arm to Y-tube fitting and secure washer hose clips
    Note
    2x clips, 1x hose
  88. Install RH wiper arm nut cover
    Note
    1x cover
  89. Install LH wiper arm and hose assembly onto vehicle
    Note
    The washer hose shall be routed over the arm pivot joint, not under
  90. Install the nut securing the LH wiper arm to wiper module
    Note
    1x nut, 15mm, 25 Nm, Make sure the wiper tip is aligned between the two indicators at windshield
  91. Connect washer hose from LH wiper arm to Y-tube fitting and secure washer hose clips
    Note
    2x clips, 1x hose
  92. Install LH wiper arm nut cover
    Note
    1x cover
  93. Install frunk assembly to vehicle
    Note
    12x clips, Make sure frunk assembly is fully seated onto clips, Number of clips may vary on older vehicles
  94. Install bolts securing frunk assembly
    Note
    7x bolts, 10mm, 5 Nm, Lower RBN covers after installing upper fasteners, Newer vehicles may not be equipped with covers
  95. Install frunk assembly carpet
  96. Install frunk close out panel
    Note
    4x clips, 1x connector, Frunk safety switch, 3x guide tabs, Align 3x tabs then push downward to secure clips
  97. Install cabin intake upper duct assembly
    Note
    4x clips, Heat pump vehicles have 3x clips
  98. Install rear apron
    Note
    12x clips
  99. Close hood
  100. Raise both front windows
  101. Close both front doors
  102. Vehicle will need to be driven by customer to complete the calibration procedure. During this time DAS functions will be completely unavailable
    Note
    No time was recorded as this will be completed by the customer
