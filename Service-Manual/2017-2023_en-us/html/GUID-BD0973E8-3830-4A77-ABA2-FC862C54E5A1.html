Headlight and Fog Light Inclination

Factory specification for headlight and fog light inclination is -1%. Check local regulations for your country's tolerance. The factory headlight and fog light inclination value is stamped on the light's housing, but not always easy to see. See images for reference.

Check Headlight and Fog Light Aiming

CAUTION
When checking the aiming of the headlights, do not set the vehicle to the "Adjust Headlights" mode through the touchscreen. The "Adjust Headlights" mode creates a non-standard headlight beam pattern that should not be used for checking the aiming of the headlights.
  1. Park the vehicle on a flat and level surface.
  2. Make sure that the tire pressures are set to specification.
  3. Open the hood.
  4. Power on the headlight tester.
  5. Position the headlight aimer perpendicular to the vehicle.
    Note
    Use the visor/laser to line up the tester perpendicular to the axis between the hood struts. If the headlight aimer can move between the LH and RH headlights while maintaining the same laser angle projected onto the hood struts, it is set correctly (perpendicular) to the vehicle.
  6. Latch the LH front door.
    Note
    Latching the LH front door prevents the headlights and/or fog lights from shutting off during the procedure.
  7. Turn on the headlights.
  8. Select the "eye" icon on the LET headlight aimer, and then select the left headlight icon.
  9. Select height to <0.8m.
  10. Position the headlight aimer in front of the LH headlight.
  11. Move the headlight aiming machine following the black arrows on the screen. Once the machine is centered to the headlight, selecting the "X" button will direct you to the aiming screen.
  12. Note down the headlight "Y" and "H" values in the internal notes in SCA.
  13. Position the headlight aimer in front of the RH headlight, and then repeat steps 11 and 12 for the RH headlight.
  14. Position the headlight aimer in front of the LH fog light.
  15. Turn on the fog lights.
  16. Cover both headlights.
  17. Set up the headlight aimer for the LH fog light: select the "Adjust" (screwdriver) icon, and then select the LH fog light icon.
    Note
    When selecting the "eye" (check) icon, fog lights cannot be selected.
  18. Select the height to <0.8m.
  19. Move the headlight aiming machine following the black arrows on the screen. Once the machine is centered to the fog light, selecting the "X" button will direct you to the aiming screen.
    Note
    Take note of the Y and H values shown on the screen and make sure they are within your country's allowable tolerances. Tesla standard for vertical fog light inclination (Y-value) is -1%. Until the LET machine has been updated, disregard any red/green triangles, red/green markings shown on the fog light beam or any other red/green coloured messages as displayed on the screen of the LET machine.
  20. Note down the fog light "Y" and "H" values in the internal notes in SCA.
  21. Position the headlight aimer in front of the RH fog light.
  22. Repeat steps 19 and 20 for the RH fog light.
  23. Turn off the fog lights, and then set the headlights to AUTO.
  24. Unlatch the LH front door.
  25. If the headlight and/or fog light aiming values are out of specification, adjust the headlights and/or fog lights. See one of the following sections:
    • Headlights - Adjust - EMEA (Tool Method)
    • Headlights - Adjust - EMEA (Wall Method)
    • Headlights - Adjust - Global (Tool Method)
    • Headlights - Adjust - Global (Wall Method)
    • Headlights - Global - Adjust (EMEA with LET Tool)
    • Light - Fog - Front (Adjust)
    • Lights - Fog - Front - Adjust (EMEA with LET Tool)
