Damper Assembly - Front - LH (Dual Motor) (Remove and Replace)

Correction code 31151402 0.54 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-10-27: Added note to refer to the Collision Repair Manual to verify whether the steering gear must be replaced.
CAUTION
If performing this procedure as a result of a collision, see the Collision Repair Manual to verify whether the steering gear must be replaced as well.
Parent topic: 3115 - Coil Suspension System

Remove

  1. Verify there is no abnormal tire wear per the Courtesy Inspection.
    Note
    Note any abnormal tire wear that could indicate the need for an alignment.
  2. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  3. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  4. Use the thin-walled strut removal socket special tool to r emove the nuts (x3) that attach the LH spring and damper assembly to the LH front upper control arm (FUCA) mount.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  5. Remove the LH front wheel. See Wheel Assembly (Remove and Install).
  6. Remove the bolt that attaches the front LH ABS wheel speed sensor to the knuckle, and then separate the sensor from the knuckle.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  7. Release the clips (x2) that attach the front LH ABS wheel speed sensor electrical harness to the knuckle.
  8. Remove and discard the nut that attaches the stabilizer bar link to the LH front spring and damper assembly, and then move the link aside.
    Tip
    Use of the following tool(s) is recommended:
    • 18 mm socket
    • Torx T40 socket
  9. Remove the bolt and nut that attach the upper control arm to the knuckle, and then discard the nut.
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm deep socket
    • Torx T50 socket
  10. Remove the bolt and nut that attach the LH front spring and damper assembly to the front lower lateral link.
    Tip
    Use of the following tool(s) is recommended:
    • 21 mm socket
  11. Lift up on the LH front upper control arm to separate it from the knuckle, then move the LH front spring and damper assembly down and out of the FUCA mount.

Install

  1. Lift up on the LH front upper control arm, and then carefully move the LH front spring and damper assembly up and into the FUCA mount.
  2. Hand-tighten the bolt and nut that attach the LH front spring and damper assembly to the front lower lateral link.
    Note
    Torquing will be done at a later stage in this procedure.
  3. Use the thin-walled strut removal socket special tool to i nstall the nuts (x3) that attach the LH spring and damper assembly to the FUCA mount.
    23 Nm (17.0 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  4. Install a new nut to attach the stabilizer bar link to the LH front spring and damper assembly.
    98 Nm (72.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 18 mm socket
    • Torx T40 socket
  5. Install the upper control arm into the knuckle, and then install the bolt and a new nut to attach the upper control arm to the knuckle.
    56 Nm (41.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm deep socket
    • Torx T50 socket
  6. Install the clips (x2) that attach the front LH ABS wheel speed sensor electrical harness to the knuckle.
  7. Install the front LH ABS wheel speed sensor into the knuckle, and then install a new bolt to attach the sensor to the knuckle.
    5 Nm (3.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  8. Remove the bolt that attaches the LH front brake rotor to the hub.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  9. Install the hub jack adapter onto the LH front hub and hand-tighten the lug nuts.
  10. Use an underhoist stand to support the hub jack adapter.
  11. Measure the distance between the bottom of the fender panel and the center of the front axle and adjust the underhoist stand so that the front suspension is set to ride height.
    Note
    For proper ride height, the distance should be 423 mm.
  12. Fasten the bolt and nut that attach the strut to the front lower lateral link.
    106 Nm (78.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 21 mm socket
  13. Remove the underhoist stand from underneath the LH front suspension.
  14. Remove the lug nuts that attach the hub jack adapter, and then remove the hub jack adapter from the vehicle.
  15. Install the bolt that attaches the LH front brake rotor to the hub.
    5 Nm (3.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  16. Install the LH front wheel. See Wheel Assembly (Remove and Install).
  17. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  18. Refer to the Alignment Requirement tables to determine whether an EPAS alignment check (EC) or four wheel alignment check (AC) is necessary. If performed, add the alignment check/adjust correction code as a separate activity to the SV. See Alignment Requirement - Suspension.
