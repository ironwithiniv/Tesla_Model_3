Brake Pad Kit - Rear (Base Brakes) (Remove and Replace)

Correction code 33010802 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1134520-00-A Kit, EPB Release, Handheld
  • 1129348-00-A XP-10 Power Supply, XP-10
  • 2026-02-19: Added a warning.
  • 2025-11-17: Added step to use brake caliper spreader to manually push back the piston into the brake caliper.
  • 2024-05-28: Updated references and cautions.
Warning
During installation of the brake caliper, make sure that the flexible brake hose is not twisted and can bend forward. The flexible brake hose must not make contact with the wheel arch liner when the vehicle is lowered.
Note
For detailed brake specifications, see Brakes.
Parent topic: 3301 - Brake Discs and Calipers

Torque Specifications

Table 1. Torque Specifications: Brake Pad Kit - Rear (Base Brakes) (Remove and Replace)
Description Torque Value Reuse/Replace Notes
LH rear brake caliper to the LH rear brake caliper bracket
26.5 Nm (19.5 lbs-ft)
  • 14 mm socket
 Reuse

Remove

  1. Remove the LH rear wheel. See Wheel Assembly (Remove and Install).
  2. Place the vehicle into EPB Service Mode. See Parking Brake - Caliper - Rear - LH (Release).
  3. Remove the bolts that attach the LH rear brake caliper to the LH rear brake caliper bracket.
    Tip
    Use of the following tool(s) is recommended:
    • 14 mm socket
  4. Use a caliper spreader to manually push the piston back into the caliper.
  5. Use a brake caliper S-hook to hang the LH rear brake caliper on the body.
    CAUTION
    Make sure the brake caliper and hoses are not twisted when hanging the caliper or during reinstallation, as this can damage the brake hose.
  6. Remove the brake pads from the LH rear brake caliper bracket.
  7. Remove the caliper abutment clips from the LH rear brake caliper bracket.
  8. Repeat step 1 through step 10 for the RH rear brake pad removal.

Install

  1. Use needle-nose pliers to ensure that the slots in the rear brake caliper piston face are at the 12 o'clock and 6 o'clock positions.
  2. Install the caliper abutment clips.
  3. Apply an even layer of Silaramic lubricant to the abutment clips.
  4. Install the brake pads on the LH rear brake caliper bracket.
    Tip
    During installation, press the brake pads toward the brake rotor.
    Note
    Use the caliper spreader tool to push the caliper piston back into the caliper, if more room is needed.
  5. Install the bolts that attach the LH rear brake caliper to the LH rear brake caliper bracket.
    26.5 Nm (19.5 lbs-ft)
    Warning
    During installation of the brake caliper, make sure that the flexible brake hose is not twisted and can bend forward. The flexible brake hose must not make contact with the wheel arch liner when the vehicle is lowered.
    Tip
    Use of the following tool(s) is recommended:
    • 14 mm socket
  6. Install the LH rear wheel. See Wheel Assembly (Remove and Install).
  7. Repeat all previous install steps for the RH rear brake pad installation.
  8. Apply the parking brake by touching the Park button on the touchscreen.
  9. On the touchscreen, tap the Service Mode "wrench" (at the bottom of the touchscreen UI), and then tap Chassis > Brakes > EPB Service Mode, select Both in the EPB Selection dropping list, and select Stop in the Action Selection dropping list. Click Run, and allow the routine to complete.
  10. Exit Service mode. See Service Mode.
  11. Pump the brake pedal to seat the pads against the brake rotor until the brake pedal feels firm.
  12. Check the brake fluid level and top off the brake fluid reservoir, if necessary.
  13. Perform a road test and burnish the brake pads. See Brake Pads - Burnishing.
    Note
    Ensure proper brake pedal feel and brake performance.
    Note
    Add correction code 33013000 as a separate activity to the SV.
