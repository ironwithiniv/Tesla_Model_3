Horn - High Tone (Remove and Replace)(LV Battery)

Correction code 1753010032 FRT 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Note
This procedure is only for LV battery vehicles.
Table 1. Torque Specifications: Horn - High Tone (Remove and Replace)(LV Battery)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolt securing the high tone horn to horn assembly bracket
9.5 Nm (7.0 lbs-ft)
  • 10 mm socket
 Reuse
Parent topic: 1753 - Horns

Remove

  1. Remove the horn assembly from vehicle. See Horn Assembly (Remove and Replace).
  2. Remove bolt securing the high tone horn to horn assembly bracket.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket

Install

  1. Install bolt securing the high tone horn to horn assembly bracket.
    9.5 Nm (7.0 lbs-ft)
    Note
    The high tone horn connector should be perpendicular to the bracket frame. Adjust high tone horn angle to avoid touching the low tone horn.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  2. Install the horn assembly to vehicle. See Horn Assembly (Remove and Replace).
