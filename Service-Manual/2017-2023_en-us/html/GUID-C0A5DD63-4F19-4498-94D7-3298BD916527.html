SD Card - Car Computer (HW2.5) (Remove and Replace)

Correction code 21152402 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 2115 - Car Computer

Remove

  1. Remove the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  4. Remove the car computer connectivity board. See Connectivity Board - Car Computer (HW2.5) (Remove and Replace).
  5. Use a trim tool to slide the SD card retaining tab over, and then use plastic tweezers to remove the SD card from the computer.
    CAUTION
    Make sure not to remove the SIM card, located to the left of the SD card in this illustration.
  6. Destroy the SD card by cutting the card in half through the center, and then cut each piece into half, resulting in 4 pieces.
    CAUTION
    It is mandatory to destroy the SD card to protect user data.

Install

  1. Use plastic tweezers to install the new SD card into the computer with the gold pads up and facing away from the bulkhead.
  2. Install the car computer connectivity board. See Connectivity Board - Car Computer (HW2.5) (Remove and Replace).
  3. Connect 12V power. See 12V/LV Power (Disconnect and Connect).
  4. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  5. Install the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
