Frame - Seat Cushion - Front Passenger Seat (Remove and Replace)

Correction code 13011212 1.32 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2024-12-09: Added mini-tilt motor configuration information.
Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
  1. Check Firmware version
    Note
    Firmware package installed must be 2023.2.11 or above for configuration routine to populate, If below target package, proceed with OTA update
  2. Remove the front passenger seat assembly. See Seat Assembly - 1st Row - LH (Remove and Replace).
  3. Remove screw securing outer side cover to seat.
    Note
    1x screw, T20, 4 Nm, Ensure the front of the seat is high enough to access the T20 screw.
  4. Release outer side cover clip from seat, but do not remove
    Note
    1x clip, Do not fully remove, possible damage to the trim/switch pack/harness
  5. Disconnect seat switch connector
    Note
    1x connector
  6. Slide outer cover rearward to release clip from frame and lift up over pretensioner to remove
    Note
    1x clip
  7. Disconnect the RH front seat belt pretensioner.
    Note
    1x connector
  8. Remove RH lap pretensioner from seat track
    Note
    1x patch bolt, T50, 40 Nm, Bolt is patched and held in place with metal clip
  9. Remove RH front seat RH sideshield carrier
    Note
    2x clips, 2x tabs, Release leading edge of trim and slide away from seat frame
  10. Release seat belt pretensioner harness clips
    Note
    3x clips, Use 90 pick to release harness clips from seat track rail
  11. Remove RH front seat LH sideshield carrier
    Note
    2x clips, 2x tabs, Release leading edge of trim and slide away from seat frame
  12. Remove clips securing seat switch harness to seat cushion frame
    Note
    2x fir tree clips
  13. Remove inner side shield from seat
    Note
    3x clips, Release side clip from seat bottom frame, then pull up on rear of trim to remove
  14. Disconnect RH front seat belt buckle
    Note
    1x connector
  15. Release RH front seat belt buckle harness clip
    Note
    1x fir tree clip
  16. Remove the clips securing RH front seat belt buckle connector harness to the seat cushion frame
    Note
    2x fir tree clips
  17. Release harness clip from RH front seat bottom frame
    Note
    1x clip
  18. Remove RH front seat buckle from seat track
    Note
    1x patch bolt, T50, 40 Nm
  19. Rotate the seat to gain access to the underside of the seat
    Note
    Protect seat cushion from damage
  20. Unhook the straps for the lower section of the seat back and move the seat back flap away from the underside of the seat
    Note
    2x clips
  21. Remove seat cushion retaining clips from the seat suspension
    Note
    2x clips
  22. Remove the front retaining clip from the seat cushion frame securing the front of the seat trim to the frame
    Note
    1x clip strip, May need to start with a hook tool, Pull the clip away from the frame to release
  23. Remove the inboard retaining clip from the seat cushion frame securing the side of the seat trim to the frame
    Note
    1x clip strip, May need to start with a hook tool, Pull the clip away from the frame to release
  24. Remove the outboard retaining clip from the seat cushion frame securing the side of the seat trim to the frame
    Note
    1x clip strip, May need to start with a hook tool, Pull the clip away from the frame to release
  25. Disconnect the tilt motor connector
    Note
    1x connector
  26. Remove the harness retaining clip under the tilt motor
    Note
    1x retaining clip
  27. Disconnect the seat occupied sensor
    Note
    1x connector
  28. Disconnect seat cushion heat pad from module
    Note
    1x connector
  29. Disconnect the CAN communication pass through connector from the OCS control module
    Note
    1x connector
  30. Remove OCS control module from seat bottom frame
    Note
    2x tabs
  31. Disconnect seat cushion heat pad from seat back heat pad connector
    Note
    1x connector
  32. Remove seat cushion connector from seat cushion suspension
    Note
    Slide upward to release from trim
  33. Disconnect the seat back heater connector
    Note
    1x connector
  34. Disconnect the seat back heater harness connector from seat cushion suspension
    Note
    1x connector
  35. Disconnect the seat cushion heat pad
    Note
    1x connector
  36. Remove seat cushion heat pad from seat cushion suspension
    Note
    1x connector, 1x clip, Slide connector forward to release from seat bottom
  37. Remove clip securing the harness to the under side of the seat, next to the seat heater connectors
    Note
    1x retaining clip
  38. Disconnect the seat track position sensor connector
    Note
    1x connector
  39. Disconnect the lift motor connector
    Note
    1x connector
  40. Disconnect LH front seat track motor connector
    Note
    1x connector
  41. Release RH front seat harness from track motor bridge
    Note
    2x edge clips, Count may vary depending on build date
  42. Remove the clip securing the harness to the seat cushion frame under the lift motor
    Note
    1x retaining clip
  43. Remove the retaining clip under the main seat harness junction
    Note
    1x retaining clip
  44. Move harness away from seat frame
  45. Return seat to upright position
  46. Remove LH front seat back assembly from seat cushion frame
    Note
    4x bolts, T47P, 43 Nm, Recommend assistance, Discard bolts after removal
  47. Remove RH front seat cushion assembly from seat frame
  48. Remove LH front seat cushion suspension from power seat cushion frame
    Note
    4x tabs, Raise portion seated on rear cushion tube, Then pull assembly away from tabs to release
  49. Remove the front and rear seat track covers (x4). See Cover - Front - Seat Track - 1st Row Seat (Remove and Replace) and Cover - Rear - Seat Track - 1st Row Seat (Remove and Replace).
  50. Install the front and rear seat track covers (x4). See Cover - Front - Seat Track - 1st Row Seat (Remove and Replace) and Cover - Rear - Seat Track - 1st Row Seat (Remove and Replace).
  51. Install LH front seat cushion suspension from power seat cushion frame
    Note
    4x tabs, Position suspension along metal tabs, Then seat rear portion on rear cushion tube
  52. Position RH front seat cushion assembly onto cushion frame
  53. Install LH front seat back assembly onto seat cushion frame
    Note
    4x bolts, T47P, 43 Nm, Recommend assistance, Install new patch bolts
  54. Flip seat over to gain access to the bottom of the seat
    Note
    Protect the seat back to prevent damage
  55. Install the retaining clip under the main seat harness junction
    Note
    1x retaining clip
  56. Install the clip securing the harness to the seat cushion frame under the lift motor
    Note
    1x retaining clip
  57. Route harness towards pretensioner
  58. Install seat harness clips onto track bridge
    Note
    2x edge clips
  59. Connect RH front seat track motor connector
    Note
    1x connector
  60. Connect the lift motor connector
    Note
    1x connector
  61. Connect the seat track position sensor connector
    Note
    1x connector
  62. Install the clip securing the harness to the under side of the seat, next to the seat heater connectors
    Note
    1x retaining clip
  63. Connect the heat pad connector
    Note
    1x connector
  64. Connect the heat pad connector
    Note
    1x connector
  65. Install the seat back heater harness connector to the seat bottom
    Note
    1x connector
  66. Connect the seat back heater connector
    Note
    1x connector
  67. Install seat cushion heating pad connector onto cushion suspension
    Note
    1x connector
  68. Connect seat cushion heating pad to seat back heating pad
    Note
    1x connector
  69. Install OCS control module onto seat bottom frame
    Note
    2x tabs
  70. Connect the SRS harness connector to the OCS control module
    Note
    1x connector
  71. Connect seat cushion heating pad to module
    Note
    1x connector
  72. Install the seat occupied sensor onto the seat frame
    Note
    1x clip
  73. Connect the seat occupied sensor and install the clip onto the seat bottom
    Note
    1x connector, 1x retaining clip, Ensure harness is not routed between cushion and frame to avoid friction
  74. Install the harness retaining clip under the tilt motor
    Note
    1x retaining clip
  75. Connect the tilt motor connector
    Note
    1x connector
  76. Install the outboard seat trim retaining clip onto the seat frame
    Note
    1x clip strip, Fold the clip over towards the frame, The open end should engage the seat frame, if not the trim will need to be pulled until the correct amount of tension is achieved, Line up one end of the clip strip opening with the seat frame and press down until the clip is fully seated onto the frame
  77. Install the inboard seat trim retaining clip onto the seat frame
    Note
    1x clip strip, Fold the clip over towards the frame, The open end should engage the seat frame, if not the trim will need to be pulled until the correct amount of tension is achieved, Line up one end of the clip strip opening with the seat frame and press down until the clip is fully seated onto the frame
  78. Install the front seat trim retaining clip onto the seat frame
    Note
    1x clip strip, Fold the clip over towards the frame, The open end should engage the seat frame, if not the trim will need to be pulled until the correct amount of tension is achieved, Line up one end of the clip strip opening with the seat frame and press down until the clip is fully seated onto the frame
  79. Install the seat cushion retaining clips onto the seat suspension
    Note
    2x clips, The seat cushion and trim may need to be pulled tight for the hooks to achieve correct placement on the seat suspension
  80. Hook the strap clips for the seat back shell onto the seat suspension
    Note
    2x clips, Ensure the straps are tight for proper fit and installation
  81. Rotate the seat to normal upright position
  82. Install the clips securing RH front seat belt buckle connector harness to the seat cushion frame
    Note
    2x fir tree clips
  83. Install clip securing RH front seat belt buckle harness connector to the seat cushion frame
    Note
    1x fir tree clip
  84. Install LH sideshield carrier onto RH front seat
    Note
    2x clips, 2x tabs, Slide forward onto seat frame aligning clips and tabs
  85. Install a new bolt securing the RH front seat buckle to seat track
    Note
    1x patch bolt, T50, 40 Nm, The captive washer originally included with the assembly is not required during reinstallation, the bolt can be installed directly without it
  86. Adjust RH front seat buckle harness clip along inner seat rail and verify harness is extended as far forward as possible to eliminate slack on the back side of the clip
    Note
    1x clip, Avoid straining harness, If harness is routed as shown in 2nd photo rework is needed
  87. Connect RH front seat belt buckle
    Note
    1x connector
  88. Install inner side shield cover onto RH front seat
    Note
    3x clips, Slide the trim onto the seat from the opening for the buckle, then slide forward into position
  89. Install clips securing seat switch harness to seat cushion frame
    Note
    2x fir tree clips
  90. Install RH front seat LH sideshield carrier
    Note
    2x clips, 2x tabs, Release leading edge of trim and slide away from seat frame
  91. Install seat belt pretensioner harness clips
    Note
    3x clips, Position seat belt pretensioner harness clips to seat track rail and press down on each clip to secure
  92. Install RH front seat RH sideshield carrier
    Note
    2x clips, 2x tabs, Slide forward onto seat frame aligning clips and tabs
  93. Install RH lap pretensioner from seat track
    Note
    1x patch bolt, T50, 40 Nm, Bolt is patched and held in place with metal clip
  94. Disconnect RH front seat belt pretensioner
    Note
    1x connector, Pull both of the orange tabs down to release the connector
  95. Slide outer cover forward to engage clip into the frame and lift up over pretensioner to install
    Note
    1x clip
  96. Connect seat switch connector
    Note
    1x connector
  97. Install outer side cover clip to seat frame
    Note
    1x clip
  98. Install screw securing outer side cover to seat
    Note
    1x screw, T20, 4 Nm
  99. Install the front passenger seat assembly. See Seat Assembly - 1st Row - LH (Remove and Replace).
  100. Replacement front seat assemblies and seat cushion frame assemblies are equipped with a newly-designed "mini-tilt" motor, and replacing these parts (or the tilt motor itself) might require a configuration change. Review the configuration information in the table and perform the following substeps if a configuration update is needed.
    1. Access the Vehicle Configuration section of the Infotainment Dashboard. See Gateway Configuration (Display and Change).
    2. Update cfg_frontSeattype according to the combination of tilt motors described in the table.
  101. Connect to vehicle using Toolbox 3.0
    Note
    Vehicle connection is integrated into drivers footwell cover, Open Toolbox 3 website and establish connection to the vehicle, https://toolbox.teslamotors.com, Select connection status icon at top right corner, and select connect locally (icon will turn green when vehicle is connected)If RJ45 ethernet diagnostic connector present connect directly from laptop using an RJ45 Ethernet cable
  102. Unlock Gateway
    Note
    After vehicle has been put into "Service Mode", place keycard on center console to turn on drive rails, hold down the brake pedal, while holding down break pedal simultaneously hold the turn signal stalk fully up for at least 10 seconds, "GTW UNLOCKING" should pop up on the UI next to the VIN during these 10 seconds, once gateway is unlocked "GTW UNLOCKED 5400" will be displayed on the UI next to the VIN, the gateway will remain unlocked for 90 minutes, follow steps on Toolbox article #5582900 for any additional information
  103. Select ‘Actions’ and search for ‘OCS’
  104. Select ‘PROC_OCS1P_SELF-CALIBRATIONvia Service Mode Plus:Safety & Restraints ➜ Seats ➜ OCS1P Self Capacitance Calibrationvia Toolbox:(link)’, click ‘Run’, and allow routine to complete
    Note
    Select ‘X’ at top right of window to close once complete, Routine is specific to NA region vehicles
  105. Select ‘Actions’ and search for ‘Seat calibration’
  106. Select ‘PROC_VCRIGHT_SEAT-CALIBRATEvia Service Mode:Low Voltage ➜ Seats ➜ Calibrate Seatvia Toolbox:(link)’, click ‘Run’, and allow routine to complete
    Note
    Select ‘X’ at top right of window to close once complete
  107. Remove HSD or RJ45 cable from Ethernet port to disconnect Toolbox 3.0 from vehicle
  108. Raise all windows
  109. Close all four doors
    Note
    Unlatch rear doors before closing
