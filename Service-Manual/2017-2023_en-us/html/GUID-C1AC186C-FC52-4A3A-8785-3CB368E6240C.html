Gearbox Fluid - Rear Drive Unit (3DU) (Drain and Refill) (Machine Only)

Correction code 40300115 FRT 0.54 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 2222393-00-A - AUTOMATIC OIL CHANGE MACHINE
  • 1130484-00-A - SKT, OIL FILTER, 63.5MM X 14
Note
This procedure is only applicable in China.
Parent topic: 4030 - Rear Gearbox and Halfshafts

Procedure

  1. Remove the rear aero shield. See Panel - Aero Shield - Rear (Remove and Replace).
  2. Position the oil drain container underneath the drive unit oil filter area.
  3. Rotate the oil filter counterclockwise to remove it from the vehicle, and then discard the oil filter.
  4. Install the oil filter adapter to the vehicle, and use oil filter wrench to fully tighten the adapter.
  5. Connect the oil hoses (x2) onto the oil filter adapter.
  6. Remove the oil drain container from underneath the drive unit.
  7. Connect the automatic oil change machine to the power supply, and then pull the switch up to open the machine.
  8. Add at least 5 L new oil to the automatic oil change machine.
    Note
    Before adding new oil to the machine, make sure that old oil is fully drained.
    Note
    The volume of the oil can be read via the machine UI.
  9. Lower the vehicle to a comfortable working height.
    Note
    Make sure that the vehicle does not contact the ground.
  10. Locally connect a laptop with Toolbox 3 to the vehicle. See Toolbox (Connect and Disconnect).
  11. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): PROC_ICE_X_ENTER-DYNO-MODEvia Service Mode Plus:Chassis ➜ Brakes ➜ Enter Dyno Modevia Toolbox:(link)
  12. With an assistant, place the vehicle into Drive mode and slightly press the accelerator pedal till the oil is fully drained.
    Warning
    Before pressing the accelerator pedal, make sure that the vehicle does not contact the ground. Adjust the lift, if needed.
  13. When the wheels start to run, in the automatic oil change machine, select Equal Exchange > Normal Oil Change, and set the exchange volume to 5L via the up/down buttons, and then press the OK button to start the oil exchange process.
    Note
    Once the exchange is completed, the machine will automatically stop.
  14. Confirm the color of new oil and used oil. If the colors are extremely close, it indicates the process has been successfully completed.
    Note
    If there is a significant color difference between the two, repeat the whole procedure.
  15. Place the vehicle into Park mode.
  16. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): PROC_ICE_X_EXIT-DYNO-MODEvia Service Mode Plus:Chassis ➜ Brakes ➜ Exit Dyno Modevia Toolbox:(link)
  17. Close the automatic oil change machine, and disconnect the machine from the power supply.
  18. Raise the vehicle to a comfortable working height.
  19. Position the oil drain container underneath the drive unit oil filter area.
  20. Disconnect the oil hoses (x2) from the oil filter adapter.
  21. Use oil filter wrench to remove the oil filter adapter from the vehicle.
  22. Lightly lubricate the new oil filter seal, and then install the new oil filter to the rear drive unit.
    3 Nm (2.2 lbs-ft) + 135 degrees
  23. Remove and discard the fill plug from the rear drive unit.
  24. Fully insert the rear drive unit oil dipstick into the rear drive unit through the fill plug hole, and then remove the dipstick and check the oil level is within the notches.
    Note
    Make sure that the dipstick end is pointing down.
    Note
    The dipstick is printed with an "R".
    Note
    Add or drain the oil if needed.
  25. Install a new fill plug to the rear drive unit.
    15 Nm (11.1 lbs-ft)
  26. Install the rear aero shield. See Panel - Aero Shield - Rear (Remove and Replace).
  27. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): TEST-SELF_DIR_X_OIL-PUMP-PRESSUREvia Toolbox:(link)s
  28. Exit Service Mode or disconnect the laptop if applicable (see 0005 - Service Modes).
  29. Remove the vehicle from the lift.
  30. Raise the LH front window and close the LH front door.
