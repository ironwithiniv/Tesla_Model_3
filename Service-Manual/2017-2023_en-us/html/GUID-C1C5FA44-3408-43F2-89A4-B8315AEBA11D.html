Identify Headlight Type

The SAE/ECE headlight (1) has a different reflector and lens design compared to the Global headlight (2), illustrated below.

Headlight and Fog Light Inclination

Factory specification for headlight and fog light inclination is -1%. Check local regulations for your country's tolerance. The factory headlight and fog light inclination value is stamped on the light's housing, but not always easy to see. See images for reference.

Check Headlight and Fog Light Aiming

CAUTION
When checking the aiming of the headlights, do not set the vehicle to the "Adjust Headlights" mode through the touchscreen. The "Adjust Headlights" mode creates a non-standard headlight beam pattern that should not be used for checking the aiming of the headlights.
  1. Park the vehicle on a flat and level surface.
  2. Make sure that the tire pressures are set to specification.
  3. Open the hood.
  4. Power on the headlight tester.
  5. Position the headlight aimer in front of the LH headlight.
    Note
    Distance approx. 30 cm from the surface of the headlight lens. Adjust height as necessary to match center point of headlight at approximately (70cm). Make sure that the headlight aimer is on a surface, level with the vehicle.
  6. Use the knobs on the base of the headlight aimer to adjust the tester level.
  7. Position the headlight aimer perpendicular to the vehicle.
    Note
    Use visor/laser to line up the tester perpendicular to the axis between the hood strut furthest fender bolts. If the headlight aimer can move between the RH and LH headlights while maintaining the same laser angle projected onto the hood struts, it is set correctly (perpendicular) to the vehicle.
  8. Initiate test on the headlight aimer: select TEST EC > Free test.
  9. Select the vehicle model on the headlight aimer:
    • If headlight type is ECE or SAE, set Vehicle to Car
    • If headlight type is Global, set Vehicle to Tesla 3
  10. Select Headlight (LHD or RHD option) on the headlight aimer:
    • For LHD vehicles, select Headlight and adjust to EU Asym using the + / - buttons
    • For RHD vehicles, select Headlight and adjust to UK using the + / - buttons
    Note
    Confirm that the button to the right of "Headlight" is set to -. These settings are for inspection only. Do not use these for adjustment.
  11. Select the headlight type on the headlight aimer.
    Note
    Select Light and adjust to Bi-LED using the +/- buttons.
  12. Select Inclination on the headlight aimer.
    Note
    Select Inclinat and adjust to -1.0 % using the +/- button.
    Note
    Make sure the inclination value corresponds to your country's tolerance.
  13. Select Height on the headlight aimer.
    Note
    Select Height and adjust to approximately 70 cm as indicated on the aligner marker on the aligner post, using the +/- button, and then select OK.
  14. Select the fog light option on the headlight aimer.
    Note
    Select Yes under Fog Light.
  15. Select fog light Inclination on the headlight aimer.
    Note
    Select Inclinat and adjust to -1.0 % using the +/- button.
  16. Select the fog light Height on the headlight aimer.
    Note
    Set to the height of the aligner marker on the aligner post after adjusting the headlight aimer horizontally and vertically so that the headlight laser guide crosshair is at the center of the fog light. Height is different for different model versions (Dual Motor and Performance, for example).
  17. Select fog light type on the headlight aimer.
    Note
    Select LED, and then select OK.
  18. Position the headlight aimer in front of the LH headlight.
    Note
    Distance approx. 30 cm from the surface of the headlight lens. Adjust height as necessary to match the center point of the headlight (70cm). Make sure that the headlight aimer is on a surface, level with the vehicle.
  19. Adjust the headlight aimer to the LH headlight markings.
    Note
    Turn on the laser aimer to adjust the tester horizontal and vertical position to the LH headlight marking. Set to approximately 70 cm height on the post. A piece of paper can aid in finding the center point. Turn off the laser aimer before proceeding to the next step. Some early headlight production will not have hash-marks on the lens; align by measuring 14.7 cm from the corner of the fender to the bottom edge of the lens.
  20. Check the headlight beam aiming.
    Note
    Select which light to be checked. Specification: -1 to -1.5 degrees vertical, 0 to 2 degrees horizontal.
  21. Note the headlight aiming values in SCA.
    Note
    Note down the Headlight "V" and "H" values in internal notes in SCA. State which headlight side the values are for (LH or RH).
  22. Select the Save icon to record the results.
  23. Position the headlight aimer in front of the RH headlight.
    Note
    Position at approx. 30 cm distance from the surface of the headlight lens.
  24. Adjust the headlight aimer to the RH headlight marking.
    Turn on the laser aimer to adjust the tester horizontal and vertical position to the LH headlight marking. Set to approximately 70 cm height on the post. A piece of paper can aid in finding the center point. Turn off the laser aimer before proceeding to the next step. Some early headlight production will not have hash-marks on the lens; align by measuring 14.7 cm from the corner of the fender to the bottom edge of the lens.
  25. Check the headlight beam aiming.
    Note
    Select which light to be checked. Specification: -1 to -1.5 degrees vertical, 0 to 2 degrees horizontal.
  26. Note the headlight aiming values in SCA.
    Note
    Note down the Headlight "V" and "H" values in internal notes in SCA. State which headlight side the values are for (LH or RH).
  27. Select the Save icon to record the results.
  28. Turn on the front fog lights.
    Note
    Select Controls > Lights > Front Fog. Make sure that the vehicle is on and exterior lights are in "On" or "Auto".
  29. Position the headlight aimer in front of the LH fog light.
    Note
    Position the headlight aimer approx. 30 cm from the surface of the fog light lens.
  30. Adjust the headlight aimer to the LH fog light markings.
    Note
    Turn on the laser aimer to adjust the tester horizontal and vertical position to the center of LH fog light. Turn off the laser aimer before proceeding to the next step.
  31. Select the LH fog light icon and select the fog light measurement button at the bottom of the screen.
  32. Check the fog light beam aiming.
    Note
    Specification: -1%.
    Note
    Check local regulations to see if another specification than -1% applies in your country.
  33. Note down the Fog Light "V" value in internal notes in SCA. State which fog light the value is for (RH or LH).
  34. Select save icon to record results
  35. Roll the headlight aimer to the RH fog light.
  36. Adjust the headlight aimer to the RH fog light markings.
    Note
    Turn on laser aimer to adjust the tester horizontal and vertical position to the center of LH fog light. Turn off the laser aimer before proceeding to the next step.
  37. Select the RH fog light icon and select the fog light measurement button at the bottom of the screen.
  38. Check the fog light beam aiming.
    Note
    Specification: -1%. If aiming is within specification, continue.
    Note
    Check local regulations to see if another specification than -1% applies in your country.
  39. Note down the Fog Light "V" values in internal notes in SCA. State which fog light the value is for (LH or RH).
  40. Select the Save icon to record the results.
  41. Select the Save button once again to view the test results.
  42. If the headlight and/or fog light aiming values are out of specification, adjust the headlights and/or fog lights. See one of the following sections:
    • Headlights - Adjust - EMEA (Tool Method)
    • Headlights - Adjust - EMEA (Wall Method)
    • Headlights - Adjust - Global (Tool Method)
    • Headlights - Adjust - Global (Wall Method)
    • Headlights - Global - Adjust (EMEA with LET Tool)
    • Light - Fog - Front (Adjust)
    • Lights - Fog - Front - Adjust (EMEA with LET Tool)
