Tow Hook - Front (Remove and Replace)

Correction code 10011212 0.06 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1001 - Bumper / Fascia

Remove

  1. Open the LH front door.
  2. Open the hood.
  3. Remove the underhood storage carpet. See Carpet - Underhood Storage (Remove and Install).
  4. Remove the emergency tow hook from the underhood storage unit.

Install

  1. Install the emergency tow hook to the underhood storage unit.
  2. Install the underhood storage carpet. See Carpet - Underhood Storage (Remove and Install).
  3. Close the hood.
  4. Close the LH front door.
