Coax Cable - Side Repeater - Front - LH and RH (Overlay) (Remove and Replace)

Correction code 17403032 FRT 2.94 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
  • 2026-07-09: Released new procedure.
Parent topic: 1710 - Harnesses

Overlay

  1. Raise and support vehicle
    Note
    remove charging equipment
  2. Open LH front door
  3. Lower LH front window
  4. Open RH front door
  5. Lower RH front window
  6. Move RH front seat backward
  7. Remove the cowl screen. See Panel - Cowl Screen (Remove and Replace)
  8. Disconnect wiper module harness
    Note
    1x connector, Do NOT place limbs within the linkage movement area as wiper arms will automatically transition to parking mode
  9. Remove bolts securing wiper module
    Note
    3x bolts, 10mm, 7 Nm
  10. Remove wiper module from vehicle
    Note
    Keep your fingers away from any potential pinch points and moving parts while connecting and installing the wiper module, Do not attempt to test the module until it is fully installed in the vehicle
  11. Release harness clip from LH side of washer tank inlet
    Note
    1x clip
  12. Disconnect harness connector for washer pump and level sensor
    Note
    1x connector
  13. Remove LH front wheel center cap
    Note
    1x cap
  14. Loosen LH front wheel
    Note
    5x nuts, 21mm, 175 Nm
  15. Remove RH front wheel center cap
    Note
    1x cap
  16. Loosen RH front wheel
    Note
    5x nuts, 21mm, 175 Nm
  17. Raise vehicle partially and lower lift onto locks
    Note
    Set vehicle to comfortable working height, Make sure there's an audible click of the locks on both sides before lowering, Otherwise vehicle may tilt to the side
  18. Remove RH front wheel
    Note
    5x nuts, 21mm, 175 Nm
  19. Partially remove RH front wheel liner
    Note
    6x clips, 1x bolt, 10mm, 5 Nm, Newer vehicles may be equipped with 2x push clips securing lower portion of liner to body
  20. Disconnect front harness connectors for RH side repeater and camera
    Note
    2x connectors
  21. Remove LH front wheel
    Note
    5x nuts, 21mm, 175 Nm
  22. Partially remove LH front wheel liner
    Note
    6x clips, 1x bolt, 10mm, 5 Nm, Newer vehicles may be equipped with 2x push clips securing lower portion of liner to body
  23. Disconnect front harness connectors for LH side repeater and camera
    Note
    2x connectors
  24. Remove lower bolt securing washer tank to vehicle
    Note
    1x bolt, 10mm, 3 Nm
  25. Lower vehicle partially and set lift onto locks
    Note
    Raise lift off locks, then hold lock release lever to keep locks free while vehicle is lowered, Set vehicle to comfortable working height
  26. Remove upper bolt securing washer tank to vehicle
    Note
    1x bolt, 10mm, 3 Nm
  27. Remove washer tank from vehicle
    Note
    2x connectors，Keep washer tank upright to keep contents from spilling
  28. Power off vehicle from center display
    Note
    Via Controls > Safety > Power Off, Select Power Off button at warning dialog box
  29. Disconnect LV battery
    Note
    2x connectors, Lift up and release green locking tab, Pull black connector lock outwards to release connection
  30. Disconnect service disconnect
    Note
    1x connector, Release locking tab
  31. Release positive jump post
    Note
    1x bolt, 10mm, 5 Nm
  32. Remove LV battery cable stand off
    Note
    1x clip
  33. Release LV battery
    Note
    3x bolts, 10mm, 6 Nm, Move battery cables clear of the LV battery
  34. Lift LV battery straight up and remove out of vehicle
  35. Remove ground cable from front controller
    Note
    1x bolt, 10mm, 8.5 Nm
  36. Disconnect thermal sub-harness from front controller
    Note
    1x connector, Depress locking tab and rotate to release
  37. Remove bolts securing front controller shield assembly and remove from vehicle
    Note
    2x bolts, 10mm, 8.5 Nm
  38. Disconnect front controller harness connectors
    Note
    5x connectors, 1x harness guide, depress locking tab if equipped
  39. Remove bolts securing front controller
    Note
    3x bolts, 10mm, 10 Nm
  40. Tilt front controller forward for access
  41. Remove ground cable from backside of front controller
    Note
    1x edge clip
  42. Release harness guide and remove the front controller from vehicle
    Note
    1x tab
  43. Remove fresh air intake assembly
    Note
    2x studs, Lift cowl as needed
  44. Remove LH IP end cap
    Note
    3x clips
  45. Remove LH air wave bezel cap from main decor assembly
    Note
    2x clips, Newer vehicles are equipped with solid bezel.
  46. Remove RH IP end cap
    Note
    3x clips
  47. Remove RH air wave bezel cap from main decor assembly
    Note
    2x clips, Newer vehicles are equipped with solid bezel.
  48. Remove main decor assembly
    Note
    15x clips, Entire decor does not need to come off for glove box removal, If you lift RH side of decor then you will have access to 3x torx screws securing top of glove box, Replace securing clips as needed
  49. Release RH footwell assembly from IP
    Note
    4x push clips
  50. Remove RH footwell assembly
    Note
    2x connectors
  51. Remove bolts securing passenger knee air bag onto vehicle
    Note
    4x patch bolts, T30, 8 Nm, Discard after removal, 2x screws, T20, 2 Nm, 1x push clip, Newer vehicles have 4x E10 patch bolts
  52. Remove passenger knee air bag from vehicle
    Note
    1x connector, Release locking tab, Connector release may vary
  53. Remove screws securing glove box assembly to IP carrier
    Note
    6x screws, T20, 2.3 Nm
  54. Disconnect glove box assembly connectors
    Note
    3x electrical connectors
  55. Remove glove box from IP carrier
    Note
    3x clips
  56. Disconnect glove box USB cable from car computer
    Note
    1x connector, Depress latch on top of USB cable to release internal latches, Then release from car computer
  57. Remove clip securing passenger footwell air duct and rotate for access
    Note
    1x push clip, With glovebox installed there is not sufficient room to fully remove passenger footwell duct
  58. Disconnect RH upper duct thermistor from RH IP air wave duct
    Note
    1x connector
  59. Remove RH IP air wave duct
    Note
    2x push clips
  60. Release windshield heater connecter
    Note
    1x connector
  61. Release RH grommet from body
  62. Remove electrical tape securing harness bundle to rubber dust boot
    Note
    Use a razor blaze, carefully cut electrical tape away to expose rubber dust boot
  63. Remove locking pin from connector
    Note
    Carefully pry pin out of connector and fully remove locking pin
  64. Remove coax cable needed for the side repeater overlay M3 terminal 1 (LHS)
    Note
    Inspect all components for damage
  65. Remove coax cable needed for the side repeater overlay terminal 2 (RHS)
    Note
    Inspect all components for damage
  66. Apply harness tape onto LH coax overlay cable before installation
    Note
    Use Anti-abrasion tape and wrap the entire length of the coax cable to protect the cable for damage when it is in the vehicle
  67. Apply harness tape onto RH coax overlay cable before installation
    Note
    Use Anti-abrasion tape and wrap the entire length of the coax cable to protect the cable for damage when it is in the vehicle
  68. Release frunk harness cover
    Note
    3x tabs
  69. Position M3 LH coax overlay cable into place, Place through LH wheel liner
    Note
    Pull till you have roughly 12 inches of cable towards the interior of the vehicle
  70. Pull LH coax overlay cable through frunk harness
    Note
    Pull harness towards car computer, Route under brake booster lower connector
  71. Tape coax overlay onto fish nylon tape
  72. Pull LH coax overlay cable through bulkhead and into interior cabin
  73. Remove nylon fish tape
    Note
    Remove tape the pull nylon fish tape out of vehicle
  74. Position RH coax overlay cable into place, Place through RH wheel liner
    Note
    Pull till you have roughly 6 inches of cable towards the interior of the vehicle
  75. Pull RH coax overlay cable through RH grommet harness
    Note
    Pull harness toward car computer under RH grommet main harness
  76. Tape coax overlay onto fish nylon tape
  77. Pull RH coax overlay cable through bulkhead and into interior cabin
  78. Remove nylon fish tape
    Note
    Remove tape the pull nylon fish tape out of vehicle
  79. Disconnect side repeater cameras connector from car computer
    Note
    1x locking connector
  80. Remove locking pin from side repeater cameras connector
    Note
    Carefully pry pin out of connector and fully remove locking pin
  81. Remove coax terminal 1 (LHS) cable from connector
    Note
    Inspect all components for damage
  82. Insert new side repeater coax terminal 1 (LHS) cable onto side repeater cameras connector
    Note
    Ensure both coax cables are fully seated into connector, Audible locking and flush mounting to confirm
  83. Remove coax terminal 2 (RHS) cable from connector
    Note
    Inspect all components for damage
  84. Insert new side repeater coax terminal 2 (RHS) cable onto side repeater cameras connector
    Note
    Ensure both coax cables are fully seated into connector, Audible locking and flush mounting to confirm
  85. Secure locking pin to connector
    Note
    Align tabs of lock in connector housing, Ensure flush installation of locking pin to connector housing
  86. Connect side repeater cameras connector onto car computer
    Note
    1x locking connector
  87. Position LH coax overlay cable onto frunk main harness, Secure cable onto harness using zip ties
    Note
    7x zip-ties, Trim off excess material after harness has been secured
  88. Cut off the vehicle side repeater coax terminal and tape to vehicle harness
    Note
    Cut the coax connector only
  89. Connect front harness connectors for LH side repeater and camera
    Note
    2x connectors
  90. Position RH coax overlay cable onto frunk main harness grommet, Secure cable onto harness using zip ties
    Note
    3x zip-ties, Trim off excess material after harness has been secured
  91. Cut off the vehicle side repeater coax terminal and tape to vehicle harness
    Note
    Cut the coax connector only
  92. Connect front harness connectors for RH side repeater and camera
    Note
    2x connectors
  93. Secure RH grommet from body
    Note
    Use electrical tape to wrap the end of the dust boot
  94. Secure frunk harness cover
    Note
    3x tabs
  95. Secure windshield heater connector
    Note
    1x connector
  96. Place front controller into vehicle for installation
  97. Install ground cable to backside of front controller
    Note
    1x edge clip
  98. Install harness guide and tilt front controller backward for installation
    Note
    1x tab
  99. Install bolts securing front controller
    Note
    3x bolts, 10mm, 10 Nm
  100. Install front controller harness connectors
    Note
    5x connectors, 1x harness guide, secure locking tab if equipped
  101. Install front controller shield to the front controller
    Note
    2x bolts, 10mm, 8.5 Nm
  102. Connect thermal sub-harness to front controller
    Note
    1x connector, Rotate fully to secure locking tab
  103. Install ground cable to front controller
    Note
    1x bolt, 10 mm, 8.5 Nm
  104. Install LV battery into bracket and bolt into place
    Note
    3x bolts, 10mm, 6 Nm
  105. Secure positive jump post
    Note
    1x bolt, 10mm, 5 Nm
  106. Install battery cable standoff
    Note
    1x clip
  107. Install washer tank into position
  108. Install upper bolt securing washer tank to vehicle
    Note
    1x bolt, 10mm, 3 Nm
  109. Raise vehicle partially and lower lift onto locks
    Note
    Set vehicle to comfortable working height, Make sure there's an audible click of the locks on both sides before lowering, otherwise vehicle may tilt to the side
  110. Install lower bolt securing washer tank to vehicle
    Note
    1x bolt, 10mm, 3 Nm
  111. Install LH front wheel liner to vehicle
    Note
    6x clips, 1x bolt, 10mm, 5 Nm, Newer vehicles may be equipped with 2x push clips securing lower portion of liner to body
  112. Install LH front wheel
    Note
    5x nuts, 21mm, 175 Nm, Start lug nuts by hand before using power tool
  113. Install RH front wheel liner to vehicle
    Note
    6x clips, 1x bolt, 10mm, 5 Nm, Newer vehicles may be equipped with 2x push clips securing lower portion of liner to body
  114. Install RH front wheel
    Note
    5x nuts, 21mm, 175 Nm, Start lug nuts by hand before using power tool, Torque at later step
  115. Lower vehicle until tires are touching ground
    Note
    Raise lift off locks, then hold lock release lever to keep locks free while vehicle is lowered
  116. Torque LH front wheel
    Note
    5x nuts, 21mm, 175 Nm
  117. Install LH front wheel center cap
    Note
    1x cap, Verify emblem is aligned with valve stem
  118. Torque RH front wheel
    Note
    5x nuts, 21mm, 175 Nm
  119. Install RH front wheel center cap
    Note
    1x cap, Verify emblem is aligned with valve stem
  120. Connect harness connector for washer pump and level sensor
    Note
    1x connector
  121. Secure harness clip onto LH side of washer tank inlet
    Note
    1x clip
  122. Position wiper module to vehicle
    Note
    Keep your fingers away from any potential pinch points and moving parts while connecting and installing the wiper module, Do not attempt to test the module until it is fully installed in the vehicle
  123. Install bolts securing wiper module
    Note
    3x bolts, 10mm, 7 Nm
  124. Connect wiper module connector
    Note
    1x connector, Do NOT place limbs within the linkage movement area as wiper arms will automatically transition to parking mode
  125. Install the cowl screen. See Panel - Cowl Screen (Remove and Replace)
  126. Connect glove box USB cable to car computer
    Note
    1x connector
  127. Re-position and secure the passenger footwell air duct
    Note
    1x push clip
  128. Install RH IP air wave duct
    Note
    2x push clips
  129. Connect RH upper duct thermistor to RH IP air wave duct
    Note
    1x connector
  130. Connect glove box assembly connectors
    Note
    3x connectors, New puddle lamp harness routing prevent blocking movement of pawls, Make sure harness is routed properly above passenger footwell air duct before connecting
  131. Install glove box into IP carrier
    Note
    3x clips
  132. Install screws securing glove box assembly to IP carrier
    Note
    6x screws, T20, 2.3 Nm
  133. Install main decor assembly
    Note
    15x clips, 1x center clip
  134. Install LH air wave bezel cap to main decor assembly
    Note
    2x clips, Newer vehicles are equipped with solid bezel.
  135. Install LH IP end cap
    Note
    3x clips
  136. Install RH air wave bezel cap to main decor assembly
    Note
    2x clips, Newer vehicles are equipped with solid bezel.
  137. Install RH IP end cap
    Note
    3x clips
  138. Install passenger knee air bag onto vehicle
    Note
    1x connector, Use caution not to damage connector and harness, Support knee air bag while connecting connector
  139. Install bolts securing passenger knee air bag to vehicle
    Note
    4x patch bolts, E10, 8 Nm, Install new patch bolts, 2x screws, T20, 2 Nm, 1x push clip, If vehicle equipped with T30 bolts update to E10
  140. Install RH footwell cover assembly
    Note
    2x connectors
  141. Install RH footwell assembly onto IP
    Note
    4x push clips
  142. Connect first responder loop and LV battery
    Note
    2x connectors, Secure FRL first, Seat LV battery connection and push black connector lock inwards to secure, Engage green locking tab when fully seated
  143. Install rear apron
    Note
    12x clips
  144. Close hood
  145. Move RH front seat to original position
  146. Verify operation of windshield washers and wipers
  147. Clear DAS Calibration through UI
    Note
    Controls > Service > Camera Calibration, Select Clear Calibration, Verify calibration was cleared successfully, Wait for prompt to disappear automatically before continuing, Calibration in Progress message and progress icon will appear during the next drive cycle
  148. Vehicle will need to be driven by customer to complete the calibration procedure. During this time DAS functions will be completely unavailable
  149. Raise RH front window
  150. Close RH front door
  151. Raise LH front window
  152. Close LH front door
