A/C Line - Supermanifold to HVAC (Remove and Replace)

Correction code 18201702 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2024-09-12: Added note on adding correction code for refrigerant - recovery/recharge as a separate activity to the Service Visit.

Note
This procedure requires the A/C Refrigerant (Recovery and Recharge) procedure to be performed. If not already automatically added to the Service Visit, add correction code 18200102 as a separate correction within the same activity to the Service Visit.
Parent topic: 1820 - Refrigerant System

Remove

  1. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  2. Unlock the vehicle gateway. See Gateway (Unlock).
  3. On the touchscreen, tap the Service Mode "wrench" (at the bottom of the touchscreen UI), and then tap Thermal > Refrigerant System > Start Thermal Fill Drain (Refrigerant only) > Run, and allow the routine to complete.
  4. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  5. Recover the A/C refrigerant. See A/C Refrigerant (Recovery and Recharge).
  6. Remove the fresh intake duct. See Duct - Fresh Intake (Remove and Replace).
  7. Remove the 12V/LV auxiliary battery. See 12V/LV Battery (Remove and Replace).
  8. Remove the bolts (x2) that attach the supermanifold to HVAC A/C line to the HVAC assembly.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  9. Remove the nut that attaches the supermanifold to HVAC A/C line to the supermanifold.
    Tip
    This nut is behind the supermanifold to compressor A/C line.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  10. Release the supermanifold to HVAC A/C line from the supermanifold, and then move the A/C line rearwards and up to remove it.

Install

  1. Position the supermanifold to HVAC A/C line on the supermanifold, inserting the A/C line stud into the stud hole on the supermanifold.
    Note
    Lubricate the new seal washers with the appropriate A/C oil. See Fluids and Capacities for A/C oil specifications.
    Tip
    Reach under the supermanifold to position the A/C line.
    Tip
    Look through the supermanifold stud hole to help locate the A/C line stud.
  2. Install the nut that attaches the supermanifold to HVAC A/C line to the supermanifold.
    36 Nm (26.5 lbs-ft)
    Tip
    This nut is behind the supermanifold to compressor A/C line.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  3. Install the bolts (x2) that attach the supermanifold to HVAC A/C line to the HVAC assembly.
    28 Nm (20.6 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  4. Perform the vacuum leak test and refill A/C refrigerant. See A/C Refrigerant (Recovery and Recharge).
  5. Install the fresh intake duct. See Duct - Fresh Intake (Remove and Replace).
  6. Install the 12V/LV auxiliary battery. See 12V/LV Battery (Remove and Replace).
  7. Connect 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  8. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  9. Unlock the vehicle gateway. See .
  10. On the touchscreen, touch Service Mode > Thermal > Sensors and Valves > Run Heat Pump Commissioning and select Run, and then allow the routine to complete.
  11. Tap Actions > Test Thermal Performance, select Run, and allow the routine to complete.
  12. Tap Actions > Test HVAC Performance, select Run, and allow the routine to complete.
  13. Exit Service Mode. See Service Mode.
