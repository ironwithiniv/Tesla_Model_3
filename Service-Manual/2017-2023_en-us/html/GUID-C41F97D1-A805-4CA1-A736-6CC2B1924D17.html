Handle - Exterior Release - Door - Front - LH (Remove and Replace)

Correction code 11451002 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-01-22: Updated the nuts securing the handle to consumable parts and added the part number.
  • 2025-09-01: Added disconnecting/connecting LV battery power steps, and added the window calibration routine.
Warning
The side impact airbag deployment depends on the front door sensor's ability to detect a side impact from air pressure. Make sure that there are no uncovered holes in the front door shells. Additionally, always reinstall plugs or tape when servicing or inspecting the front doors and their components.
Parent topic: 1145 - Exterior Door Handles

Torque Specifications

Table 1. Torque Specifications: Handle - Exterior Release - Door - Front - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Nuts that attach the door exterior release handle to the door
7 Nm (5.2 lbs-ft)
  • 10 mm socket
 Replace 1137563-00-A

Remove

  1. Remove the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Install).
  2. Remove the LH front door inner belt seal. See Seal - Inner Belt - Front Door - LH (Remove and Replace).
  3. Remove the front LH door glass. See Glass - Door - LH - Front (Remove and Replace).
  4. Disconnect the LV battery power. See 12V/LV Power (Disconnect and Connect).
  5. Remove the LH front door closeout panel. See Closeout Panel - Door - Front - LH (Remove and Replace).
  6. Disconnect the electrical wiring harness from the door handle connector.
  7. Remove the plugs that cover access to the door handle nuts.
  8. Remove and discard the nuts that attach the door handle to the door, and then remove the handle from the door.
    Note
    There are 2 versions of these nuts. Replace if the nuts are nyloc nuts. Reuse if the nuts are not.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket

Install

  1. Hand-tighten the new nuts (x3) that attach the door handle to the door.
    Note
    Do not replace the nyloc nuts. Do not stack any more than two shims per mounting stud. According the check result to insert shims between the handle and door inside surface at the handle mounting studs to adjust the gap and flush of the handle if necessary.
  2. Check that the LH front door handle gap and flushness are within specification.
    Note
    See Panel Alignment Specifications
  3. Torque the nuts (x3) that attach the door handle to the door.
    7 Nm (5.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  4. Install the plugs that cover access to the door handle nuts.
  5. Connect the electrical wiring harness to the door handle connector.
    Note
    Fully seat the connector, and then engage the locking tab.
  6. Install the LH front door closeout panel. See Closeout Panel - Door - Front - LH (Remove and Replace).
  7. Connect the LV battery power. See 12V/LV Power (Disconnect and Connect).
  8. Install the front LH door glass. See Glass - Door - LH - Front (Remove and Replace).
  9. Install the LH front door inner belt seal. See Seal - Inner Belt - Front Door - LH (Remove and Replace).
  10. Install the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Install).
  11. Place the vehicle in Service Mode by using the touchscreen. See Service Mode.
  12. Unlock the vehicle gateway. See Gateway (Unlock).
  13. Close the LH front door.
  14. On the touchscreen, tap the Service Mode "wrench" (at the bottom of the touchscreen UI), and then tap Closures > Windows > Calibrate Windows > Run, and allow the routine to complete.
  15. Exit Service Mode. See Service Mode.
