Adjust the Fog Lights

  1. Park the vehicle on a level surface.
  2. Make sure that all tires are inflated to specification.

  4. Open the hood.
  5. Position the headlight aiming machine 15 cm in front of the front fascia.
  6. Use the visor/laser to line up the aiming machine perpendicular to the axis between the hood struts.
    Note
    If the headlight aiming machine can move between the LH and RH fog lights while maintaining the same laser angle projected onto the hood struts, the machine is set correctly (perpendicular) to the vehicle.
  7. Remove the front clips (x3) from the LH and RH side wheel arch liner.
  8. Close the hood and turn on the fog lights.
  9. Cover both headlights.
  10. Turn on the headlight aiming machine.
  11. Select the adjustment (screwdriver) button on the headlight aiming machine, and then select the LH fog light icon.
    Note
    Inclination values on images throughout this procedure are for demonstration purposes only. Check local regulations for your country's allowable tolerance.
  12. Select height to <0.8m.
  13. Move the headlight aiming machine following the black arrows on the screen. Once the machine is centered to the fog light, selecting the "X" button will direct you to the adjustment screen.
    Note
    Take note of the Y and H values shown on the screen and make sure they are within your country's allowable tolerances. Tesla standard for vertical fog light inclination (Y-value) is -1%. Until the LET machine has been updated, disregard any red/green triangles, red/green markings shown on the fog light beam or any other red/green coloured messages as displayed on the screen of the LET machine.
  14. Adjust the LH fog light in the direction indicated on the headlight aiming machine. When values are in spec, select the check mark.
    CAUTION
    To prevent damage, apply a small amount of penetrating lubricant to the adjustment screw if the adjustment screw does not turn easily.
  15. Position the headlight aiming machine in front of the RH fog light.
  16. Select the RH fog light icon on the headlight aiming machine.
  17. Repeat steps 13 and 14 for the RH fog light.
  18. When both the LH and RH fog lights are adjusted to specification, select the check mark to see the adjustment values.
  19. Turn off the headlight aiming machine.
  20. Install the front clips (x3) to the LH and RH side wheel arch liner.
