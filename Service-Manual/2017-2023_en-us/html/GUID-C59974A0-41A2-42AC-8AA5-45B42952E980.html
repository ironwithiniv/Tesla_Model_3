Parent topic: 3404 - Tire Pressure Monitoring System (TPMS)

Procedure

  1. Review the TPMS service tool profile.
  2. In Toolbox, select the Actions tab, and search for "TPMS Sensor Learn".
  3. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): PROC_TPMS_X_TPMS-SENSOR-LEARNvia Service Mode Plus:Chassis ➜ TPMS ➜ Learn IDvia Toolbox:(link)
  4. Use the TPMS service tool to read and record the wheel sensors in the order displayed on the tool's screen.
  5. Enter the TPMS sensor ID for each wheel.
  6. On the touchscreen, select Vehicle Info and select Remove Speed Limit.
  7. Test drive the vehicle to at least 15 mph for a short distance to verify all four sensor values are displaying on the touchscreen.
    Note
    Touch Controls > Service.
    Note
    When the vehicle receives communication from the TPMS sensors with known IDs, it will quickly connect to them.
    Note
    If the tire pressures do not populate, rescan each TPMS sensor and try again.
