Headliner (Heat Pump) (Remove and Replace)

Correction code 15203112 0.66 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
Parent topic: 1520 - Headliner

Remove

  1. Open all four doors
    Note
    If vehicle is being powered down, Latch rear doors to prevent accidental closure
  2. Lower all four windows
  3. Move LH front seat forward
  4. Move RH front seat forward
  5. Remove RH side rail assembly
    Note
    4x clips, 2x tether hooks, Pull the upper corner of the side rail then work your way to bottom, Pull the lower side rail toward LH to release clips, Remove 2x tethers by twisting and pulling away from housing, DO NOT remove the tethers from body side, must be replaced if removed
  6. Push open RH coat hook
  7. Pry open RH coat hook screw cover
    Note
    2x clips
  8. Remove RH coat hook screw
    Note
    1x screw, T25, 2.5 Nm
  9. Release clips securing the RH upper B-pillar assembly and move aside
    Note
    4x clips, Pull the bottom of the upper B-pillar toward inside of the car, then pull the top of trim to release the remaining clips
  10. Remove LH side rail assembly
    Note
    4x clips, 2x tether hooks, Pull the upper corner of the side rail then work your way to bottom, Pull the lower side rail toward RH to release clips, Remove 2x tethers by twisting and pulling away from housing, DO NOT remove the tethers from body side, must be replaced if removed
  11. Push open LH coat hook
  12. Pry open LH coat hook screw cover
    Note
    2x securing tabs
  13. Remove LH coat hook screw
    Note
    1x screw, T25, 2.5 Nm
  14. Release clips securing the LH upper B-pillar assembly and move aside
    Note
    4x clips, Pull the bottom of the upper B-pillar toward inside of the car, then pull the top to release the remaining clips
  15. Move LH front seat backward and seat back downward
  16. Remove LH IP end cap
    Note
    3x clips
  17. Remove LH mid A-pillar assembly
    Note
    1x clip, 1x tab, Release the upper clip then pull mid A-pillar upward to remove
  18. Remove clip for LH lower A-pillar trim
    Note
    1x push clip
  19. Remove LH lower A-pillar trim
    Note
    2x clips, 3 guide tabs, Pull rear of lower A-pillar upward to release clip then pull rearward to release front tabs from carpet
  20. Remove LH upper A-pillar trim
    Note
    3x clips, Pull inside of the upper portion of upper A-pillar, Remove 3x tether hooks by twisting and pulling away from housing, Then pull upper A-pillar upward to remove
  21. Remove LH sun visor bracket cover
    Note
    4x clips, Extending the sun visor may allow for extra working room
  22. Remove LH sun visor fastener
    Note
    1x screw, T25, 3.5 Nm, Extending the sun visor may allow for extra working room
  23. Remove LH sun visor from headliner area
    Note
    Fold sun visor to the closed and folded down position but do not latch in place
  24. Disconnect LH sun visor connector
    Note
    1x connector
  25. Remove lower quad camera cover
    Note
    4x tabs, Press on the side of the cover with a trim tool to release some of the tabs
  26. Remove tether from lower quad camera cover
    Note
    2x tabs, Depress tabs to remove tether
  27. Remove rear view mirror
    Note
    Turn mirror counterclockwise to remove, do not twist by holding the mirror itself, it will separate from the stalk, twist from the stalk connecting the mirror to the mount
  28. Disconnect rear view mirror
    Note
    1x connector
  29. Move RH front seat backward and seat back downward
  30. Remove RH IP end cap
    Note
    3x clips
  31. Remove RH mid A-pillar assembly
    Note
    1x clip, 1x tab, Release upper clip then pull mid A-pillar upward to remove from vehicle
  32. Remove RH upper A-pillar trim
    Note
    3x clips, Pull inside of the upper portion of upper A-pillar, Remove 3x tether hooks by twisting and pulling away from housing, Then pull upper A-pillar upward to remove
  33. Remove RH sun visor bracket cover
    Note
    4x clips, Extending the sun visor may allow for extra working room
  34. Remove RH sun visor fastener
    Note
    1x screw, T25, 3.5 Nm, Extending the sun visor may allow for extra working room
  35. Remove RH sun visor from headliner
  36. Disconnect RH sun visor connector
    Note
    1x connector
  37. Remove headliner harness clips from LH A-pillar area
    Note
    6x clips
  38. Disconnect headliner harness
    Note
    1x connector
  39. Release headliner from body
    Note
    10x clips, Start by releasing rear portion of headliner then work your way forward to ease removal
  40. Remove headliner from vehicle
    Note
    Recommend assistance, Remove through passenger front door opening

Install

  1. Position headliner into vehicle for installation
    Note
    Recommend assistance, Install through passenger front door opening
  2. Install headliner to body
    Note
    10x clips, Recommend assistance. EMEA only - If previous FOHC is equipped with e-call, config will require updating
  3. Install headliner harness clips to LH A-pillar area
    Note
    6x clips
  4. Connect headliner harness
    Note
    1x connector
  5. Connect LH sunvisor connector
    Note
    1x connector, Push the connector and wire harness backward. If original sun visor check base is magnetic, install original sun visor, otherwise replace the sun visor to the latest revision (region specific)
  6. Install LH sunvisor onto headliner area
    Note
    Fold sunvisor to the closed and folded down position then latch
  7. Install LH sunvisor fastener
    Note
    1x screw, T25, 3.5 Nm
  8. Install LH sunvisor bracket cover
    Note
    4x clips
  9. Install LH upper A-pillar trim
    Note
    3x clips, 1x tether, Slide bottom of trim along IP and speaker grill, attach tether to body side, Set clips starting at the bottom and work up, Pull seal over trim
  10. Install LH lower A-pillar trim
    Note
    2x clip, 3 guide tabs, Align the 2 front tabs then align the slot with harness bracket and then push rear clip to secure to lower B-pillar, fully seat seal along trim
  11. Install clip for LH lower A-pillar trim
    Note
    1x push clip
  12. Install LH mid A-pillar assembly
    Note
    1x clip, 1x tab, Align the bottom tab then push the top clip to fully seat mid A-pillar, Pull seal over trim
  13. Install LH IP end cap
    Note
    3x clips
  14. Move LH front seat forward and seat back upward position
  15. Connect RH sun visor connector
    Note
    1x connector ,If original sun visor check base is magnetic, install original sun visor, otherwise replace the sun visor to the latest revision (region specific)
  16. Install RH sun visor into headliner area
  17. Install RH sun visor fastener
    Note
    1x screw, T25, 3.5 Nm
  18. Install RH sun visor bracket cover
    Note
    4x clips
  19. Install RH upper A-pillar trim
    Note
    3x clips, 1x tether, Slide bottom of trim along IP and speaker grill, attach tether to body side, Set clips starting at the bottom and work up, Pull seal over trim
  20. Install RH mid A-pillar assembly
    Note
    1x clip, 1x tab, Align bottom tab then push on top clip to fully seat mid A-pillar, Make sure seal seat on top of trim
  21. Install RH IP end cap
    Note
    3x clips
  22. Connect rear view mirror connector
    Note
    1x connector
  23. Install rear view mirror
    Note
    Turn mirror clockwise to install, do not twist by holding the mirror itself, it will separate from the stalk, twist from the stalk connecting the mirror to the mount
  24. Install tether onto lower quad camera cover
    Note
    2x tabs
  25. Install quad camera lower cover
    Note
    4x tabs, Install the tabs closest to the rearview mirror assembly and push the cover up to secure
  26. Move RH front seat forward and seat back upward
  27. Install the RH upper B-pillar assembly
    Note
    4x clips, Lower the seat belt slider to align it with the B-pillar panel, Insert top portion of upper B-pillar under the headliner to align the clips, Press the bottom to fully seat upper B-pillar to lower B-pillar, Make sure the seal correctly overlaps the trim
  28. Install RH coat hook screw
    Note
    1x screw, T25, 2.5 Nm
  29. Close RH coat hook screw cover
    Note
    2x clips
  30. Push RH coat hook closed
  31. Install RH side rail assembly
    Note
    4x clips, 2x tethers, Replace tether if removed from body side, Install 2x tethers hooks to housing, Align the clips from bottom to top then press clips from top to bottom, Align the seal to sit on top of the trim
  32. Move RH front seat to original position
  33. Install the LH upper B-pillar assembly
    Note
    4x clips, Lower the seat belt slider to align it with the B-pillar panel, Insert top portion of upper B-pillar under the headliner to align the clips, Press the bottom to fully seat upper B-pillar to lower B-pillar, Make sure the seal correctly overlaps the trim
  34. Install LH coat hook screw
    Note
    1x screw, T25, 2.5 Nm
  35. Close LH coat hook screw cover
    Note
    2x securing tabs
  36. Push LH coat hook closed
  37. Install LH side rail assembly
    Note
    4x clips, 2x tethers, Replace tether if removed from body side, Install 2x tethers hooks to housing, Align the clips from bottom to top then press clips from top to bottom, Align the seal to sit on top of the trim
  38. Move LH front seat to original position
  39. Raise all windows
  40. Close all four doors
