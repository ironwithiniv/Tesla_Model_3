Box Clip - Seat Belt Reminder - 1st Row - LH (Remove and Replace)

Correction code 20051102 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 2005 - Seatbelts

Torque Specifications

Table 1. Torque Specifications: Seat Assembly - 1st Row - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Front seat to body bolt
33.5 Nm (24.7 lbs-ft)
  • Torx Plus T45 socket
Replace Bolts are patched PN: 1458818-00-B

Remove

  1. Open both LH doors and lower both LH windows.
  2. Move the seat fully forward.
  3. Remove and discard the patch bolts (x2) that attach the rear of the driver seat to the body.
    CAUTION
    Use only the Torx Plus T45 bit to remove the seat bolts.
    Note
    Use of the following tool(s) is recommended:
    • Torx Plus T45 socket
  4. Move the seat fully rearward.
  5. Remove and discard the patch bolts (x2) that attach the front of the driver seat to the body.
    CAUTION
    Use only the Torx Plus T45 bit to remove the seat bolts.
    Note
    Use of the following tool(s) is recommended:
    • Torx Plus T45 socket
  6. Tilt the seat onto its back to access the underside of the seat cushion.
  7. Release the clip that attaches the seat belt reminder to the seat frame.
  8. Release the retaining tabs (x2) that attach the seat belt reminder box clip to the seat belt reminder. Remove the seat belt reminder box clip from the vehicle.
    CAUTION
    Do not disconnect the electrical connector.

Install

  1. Move the seat belt reminder box clip in place and then secure the retaining tabs (x2) that attach the seat belt reminder box clip to the seat belt reminder.
  2. Secure the clip that attaches the seat belt reminder to the seat frame.
  3. Tilt the seat forward so that it is in place and the holes in the seat rails are aligned with the holes in the body.
    CAUTION
    Avoid damaging the carpet or trim panels when tilting the seat forward.
  4. Install new patch bolts (x2) to attach the front of the seat to the body.
    33.5 Nm (24.7 lbs-ft)
    CAUTION
    Use only the Torx Plus T45 bit to torque the seat bolts.
  5. Move the seat fully forward.
  6. Install new patch bolts (x2) to attach the rear of the seat to the body.
    33.5 Nm (24.7 lbs-ft)
    CAUTION
    Use only the Torx Plus T45 bit to torque the seat bolts.
  7. Close all doors and raise all windows.
