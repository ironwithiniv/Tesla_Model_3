Handle - Exterior Release - Door - Rear - LH (Remove and Replace)

Correction code 11452002 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-01-22: Updated the nuts securing the handle to consumable parts and added the nut part number.
Warning
The side impact airbag deployment depends on the front door sensor's ability to detect a side impact from air pressure. Make sure that there are no uncovered holes in the front door shells. Additionally, always reinstall plugs or tape when servicing or inspecting the front doors and their components.

Remove

  1. Remove the LH rear door trim panel. See Panel - Door Trim - Rear - LH (Remove and Install).
  2. Remove the rear LH door glass. See Glass - Door - LH - Rear (Remove and Replace).
  3. Remove the LH rear window motor/regulator assembly. See Window Regulator - Rear - LH (Remove and Replace).
  4. Disconnect the electrical connector from the LH rear door exterior release handle.
  5. Remove the plugs (x2) that covers access to the LH rear door exterior release handle nuts.
  6. Remove and discard the nuts that attach the LH rear door exterior release handle to the door, and then remove the handle from the door.
    7 Nm (5.2 lbs-ft)
    Note
    There are 2 versions of these nuts. Replace if the nuts are nyloc nuts. Reuse if the nuts are not.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket

Install

Installation procedure is the reverse of removal, except for the following:

  • Install new nuts to secure the handle to the door.
  • When a new handle is installed, or the removed handle is installed onto a new door, perform an adjustment of the handle.
