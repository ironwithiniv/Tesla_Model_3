Reservoir - Windshield Washer (Remove and Replace)

Correction code 17501102 0.66 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created.   • 2026-02-12: Added the U-nut steps.

Torque Specifications

Table 1. Torque Specifications: Reservoir - Windshield Washer (Remove and Install)
Description Torque Value Recommended Tools Reuse/Replace Notes
Lower/upper bolt that attaches the windshield washer reservoir to the body
3 Nm (2.2 lbs-ft)
  • 10 mm socket
 Reuse

Remove

  1. Remove the windshield washer reservoir from the vehicle, and then drain any remaining fluid from the reservoir. See Reservoir - Windshield Washer (Remove and Install).
  2. Release the clip that attaches the electrical harness to the reservoir, and then remove the electrical harness from the windshield washer reservoir.
  3. Use a screw driver to remove the U-nuts (x2) from the washer tank.
    Note
    Replace any U-nut if corroded.

Install

  1. Install the U-nuts (x2) to the washer tank.
  2. Install the windshield washer reservoir and fill the windshield washer reservoir with fluid. See Reservoir - Windshield Washer (Remove and Install).
