Ground Strap - Front Controller Chassis (Remove & Replace)

Correction code 17151162 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Note
This part is only equipped on heat-pump vehicles.
Parent topic: 1715 - Electronic Control Modules

Remove

  1. Open the LH front door and lower all four windows.
  2. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  3. Remove the cowl screen panel. See Panel - Cowl Screen (Remove and Replace).
  4. Remove the 12V/LV battery. See 12V/LV Battery (Remove and Replace).
  5. Remove the battery tie down strap. See Strap - 12V Battery (Remove and Replace).
  6. Remove the edge clip from the front body controller module.
  7. Disconnect the thermal sub-harness from the front body controller module.
    Note
    Press the locking tab, and then rotate to release.
  8. Remove the bolts (x3) that attach the front body controller module to the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  9. Tilt the front body controller module forward for access to the ground cable, and then remove the tab, edge clip, and bolt that attaches the ground cable to the module.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  10. Remove the bolt that attaches the ground strap to the chassis.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket

Install

  1. Install the bolt that attaches the ground strap to the chassis.
    10 Nm (7.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  2. Position the ground cable onto the front body controller module, and then install the tab, edge clip, and bolt that attaches the ground cable to the module.
    8.5 Nm (6.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  3. Install the bolts (x3) that attach the front body controller module to the vehicle.
    10 Nm (7.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  4. Connect the thermal sub-harness to the front body controller module.
    Note
    Press the locking tab, and then rotate to release.
  5. Install the edge clip to the front body controller module.
  6. Install the battery tie down strap. See Strap - 12V Battery (Remove and Replace).
  7. Install the 12V/LV battery. See 12V/LV Battery (Remove and Replace).
  8. Install the cowl screen panel. See Panel - Cowl Screen (Remove and Replace).
  9. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  10. Raise all windows and close all doors.
