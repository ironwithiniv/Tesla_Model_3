Cover - Airbag - Knee - Front Passenger (Remove and Replace)

Correction code 14056102 0.36 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1405 - Instrument Panel

Remove

  1. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  2. Remove the passenger footwell cover. See Cover - Footwell - Passenger (LHD) (Remove and Replace).
  3. Remove the T20 bolts (x2) that attach the front passenger knee airbag cover to the vehicle.
  4. Remove and discard the T30 patchbolts (x4) that attach the front passenger knee airbag cover to the vehicle.
    CAUTION
    Support the front passenger knee airbag cover while releasing the fasteners, as the airbag is still connected to an electrical connector.
  5. Release the clip that attaches the front passenger knee airbag cover to the vehicle.
  6. Partially release the front passenger knee airbag cover from the vehicle.
    CAUTION
    Carefully release the corner clip, as it can be easily damaged.
  7. Disconnect the electrical connector from the front passenger knee airbag, and then remove the airbag cover from the vehicle.
  8. Release the metal tabs (x11) that attach the front passenger knee airbag to the airbag cover, and then remove the cover.

Install

  1. Install the passenger knee airbag into the airbag cover by installing the rear tabs first, and then press down against the airbag while pushing upwards on the edge of the cover.
  2. Install the electrical connector to the airbag.
    CAUTION
    Support the front passenger knee airbag cover during installation.
  3. Position the front passenger knee airbag cover on the vehicle.
    Note
    Carefully install the corner clip, as it can be easily damaged.
  4. Install the clip that attaches the front passenger knee airbag cover to the vehicle.
    Note
    Make sure that the clips on the rear edge of the front passenger knee airbag cover engage the IP carrier
  5. Install the new T30 patchbolts (x4) that attach the front passenger knee airbag cover to the vehicle.
    2.3 Nm (1.7 lbs-ft)
  6. Install the T20 bolts (x2) that attach the front passenger knee airbag cover to the vehicle.
    2 Nm (1.5 lbs-ft)
  7. Install the passenger footwell cover. See Cover - Footwell - Passenger (LHD) (Remove and Replace).
  8. Reconnect 12V power. See 12V/LV Power (Disconnect and Connect).
