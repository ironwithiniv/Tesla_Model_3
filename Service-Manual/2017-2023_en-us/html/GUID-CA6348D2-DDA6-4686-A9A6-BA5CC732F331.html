Headlamps (SAE-to-Global) - Headlamp Assembly - Pair (Retrofit)

Correction code 174001060.72 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-05-22: Removed reference to obsoleted Tech Note TN-24-17-002 and added some additional info from TN-24-17-002 on the retrofit.
  • 2024-06-27: Updated Toolbox 3 headlamps configuration "Global" direction.
Note
For proper headlamp operation in Model 3 vehicles, both headlamps must be of the same type (Global or SAE), and the vehicle software configuration must match the installed headlamp type. If one headlamp is damaged, and the replacement headlamp is not the same type (Global or SAE) as the undamaged headlamp, the undamaged headlamp must also be replaced. If an SAE type headlamp is damaged, replace both the damaged and the undamaged SAE headlamps with Global headlamps.
Parent topic: 1740 - Exterior Lights

Retrofit

  1. Open the LH front door.
  2. Lower the LH front window.
  3. Remove the LH and RH headlights. See Headlight - LH (Remove and Replace).
  4. Install the new LH and RH headlights. See Headlight - LH (Remove and Replace).
    Note
    Do not adjust the headlights at this time. Headlight adjustment will be performed later in this procedure.
  5. If not already performed, enable Service Mode through the touchscreen. See Service Mode.
  6. Enable Service Mode +. See Service Mode Plus.
  7. In Toolbox 3, click on the Dashboards tab, search for “infotainment”, click Infotainment Dashboard > Vehicle Configuration > headlamps, and then change the "headlamps" configuration to "GLOBAL".
    Note
    If you do not see this configuration displayed, update the vehicle to software version 2024.20 or later.
  8. On the vehicle touchscreen, perform a software reinstall concurrently with the rest of the steps in this procedure. See Software Reinstall - Touchscreen.
  9. If the vehicle is equipped with a Virtual Pitch Sensor (VPS), in Toolbox 3, click the Actions tab, search for “PROC_ICE_X_SET-VIRTUAL-PITCH-SENSOR”, and then click Change leveling system of Virtual Pitch Sensor.
    Note
    Make sure the vehicle is running firmware version 2024.8.9 or later to run this routine.
  10. Click Run and allow the routine to complete. Click X at the top right of the window to exit once the routine is complete.
  11. In Toolbox 3, go to Tools > Vehicle Configuration > headlightLevelerType and confirm the "headlightLevelerType" configuration is "VIRTUAL_PITCH_SENSOR".
  12. Disconnect the laptop from the vehicle. See Toolbox (Connect and Disconnect).
  13. Adjust the headlights. See Headlights - Adjust - Global (Tool Method).
  14. Disable Service Mode through the touchscreen. See Service Mode.
  15. Raise the LH front window.
  16. Close the LH front door.
