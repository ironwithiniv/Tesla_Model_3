Switch and Camera Assembly - Exterior Release - Trunk (Remove and Replace)

Correction code 11355612 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-03-06: Removed "Reset DAS" step, and added "Clear Camera Calibration" step.
  • 2023-04-13: Added reference to license plate removal and updated DAS reset instructions.
Parent topic: 1135 - Latches Strikers and Pinch Sensors

Remove

  1. If necessary, remove the license plate and bracket. See Bracket - License Plate - Rear (EMEA) (Remove and Replace).
  2. Remove the trunk lid trim. See Trim - Lid - Trunk (Remove and Replace).
  3. Disconnect the electrical connectors from the trunk exterior release switch and the rear facing camera.
  4. Release the clips that attach the trunk exterior release switch assembly to the liftgate.
  5. Remove the switch and camera assembly from the vehicle.

Install

  1. Install the switch and camera assembly to the vehicle.
  2. Install new clips that attach the trunk exterior release switch assembly to the trunk.
  3. Connect the electrical connectors to the trunk exterior release switch and the rear facing camera.
  4. Install the trunk lid trim. See Trim - Lid - Trunk (Remove and Replace).
  5. Install the license plate and bracket, if applicable. See Bracket - License Plate - Rear (EMEA) (Remove and Replace)
  6. Enable Service Mode. See Service Mode.
  7. Unlock the vehicle gateway. See Gateway (Unlock).
  8. On the touchscreen, tap the Service Mode "wrench" (at the bottom of the touchscreen UI), and then tap Driver Assist > Cameras > Clear Camera Calibration, select RearView in the Camera Selection drop list, click Run, and allow the routine to complete.
  9. Disable Service Mode. See Service Mode.
  10. Verify that the rear facing camera works properly.
