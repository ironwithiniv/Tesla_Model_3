Damper Assembly - Front - LH (RWD) (Remove and Replace)

Correction code 31151002 0.48 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-05-12: Released the torque table topic to force missing torque values and other omissions to appear in topic.
  • 2026-04-22: Removed the steps of wheel speed sensor and the steps of FUCA to knuckle nut and bolt.
  • 2024-05-03: Added torque specification for the strut-to-lower control arm fastener.
  • 2023-05-03: Installation method updated to set ride height before torquing the front damper assembly to the lower control arm.
CAUTION
If performing this procedure as a result of a collision, see the Collision Repair Manual to verify whether the steering gear must be replaced as well.
Equipment:
  • 1467109-00-A Strut Removal Socket, 13mm, M3
Parent topic: 3115 - Coil Suspension System

Remove

  1. Verify there is no abnormal tire wear per the Courtesy Inspection.
    Note
    Note any abnormal tire wear that could indicate the need for an alignment.
  2. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  3. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  4. Use the thin-walled strut removal socket special tool to r emove the nuts (x3) that attach the LH spring and damper assembly to the LH front upper control arm (FUCA) mount.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  5. Remove the LH front wheel. See Wheel Assembly (Remove and Install).
  6. Remove and discard the nut that attaches the stabilizer bar link to the LH front spring and damper assembly, and then move the link aside.
    Tip
    Use of the following tool(s) is recommended:
    • 18 mm socket
    • Torx T40 socket
  7. Remove the bolt and nut that attach the LH front spring and damper assembly to the lower control arm.
    Tip
    Use of the following tool(s) is recommended:
    • 21 mm socket
  8. With assistance, remove the LH front spring and damper assembly down and out of the FUCA mount.
    Note
    Apply a downward force to the brake disc to ensure there is enough space to remove the shock absorber.

Install

  1. With assistance, install the LH front spring and damper assembly up and into the FUCA mount.
    Note
    Apply a downward force to the brake disc to ensure there is enough space to install the shock absorber.
  2. Hand-tighten the bolt and nut that attach the LH front spring and damper assembly to the lower control arm.
    Note
    Torquing will be done at a later stage in this procedure.
  3. Use the thin-walled strut removal socket special tool to install the nuts (x3) that attach the LH spring and damper assembly to the FUCA mount.
    23 Nm (17.0 lbs-ft)
  4. Install a new nut to attach the stabilizer bar link to the LH front spring and damper assembly.
    98 Nm (72.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 18 mm socket
    • Torx T40 socket
  5. Remove the bolt that attaches the LH front brake rotor to the hub.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  6. Install the hub jack adapter onto the LH front hub and hand-tighten the lug nuts.
  7. Use an underhoist stand to support the hub jack adapter.
  8. Measure the distance between the bottom of the fender panel and the center of the front axle and adjust the underhoist stand so that the front suspension is set to ride height.
    Note
    For proper ride height, the distance should be 423 mm.
  9. Fasten the bolt and nut that attach the strut to the lower control arm.
    106 Nm (78.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 21 mm socket
  10. Remove the underhoist stand from underneath the LH front suspension.
  11. Remove the lug nuts that attach the hub jack adapter, and then remove the hub jack adapter from the vehicle.
  12. Install the bolt that attaches the LH front brake rotor to the hub.
    5 Nm (3.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  13. Install the LH front wheel. See Wheel Assembly (Remove and Install).
  14. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  15. Refer to the Alignment Requirement tables to determine whether an EPAS alignment check (EC) or four wheel alignment check (AC) is necessary. If performed, add the alignment check/adjust correction code as a separate activity to the SV. See Alignment Requirement - Suspension.
