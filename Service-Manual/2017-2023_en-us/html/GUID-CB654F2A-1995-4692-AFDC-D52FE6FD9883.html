Seal - Check Strap - Front Door - LH (Remove and Replace)

Correction code 11702302 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1170 - Seals Body Closures

Remove

  1. Open the LH front door and lower the LH front window.
  2. Remove the bolt that attaches the LH front door check strap to the A-pillar.
    24 Nm (17.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
    CAUTION
    Unbolting the door check allows the door to swing freely beyond opening limits.
  3. Use a plastic trim tool to release the clips (x3) that attach the check strap seal to the door.
  4. Remove the nuts (x2) that attach the check strap to the door.
    10 Nm (7.4 lbs-ft)
    • 10 mm socket
  5. Move the LH front door stop belt inward, then remove the LH front door check belt seal.

Install

  1. Install the LH front door check belt seal.
  2. Install the nuts (x2) that attach the check strap to the door.
    10 Nm (7.4 lbs-ft)
    • 10 mm socket
  3. Install the clips (x3) that attach the check strap seal to the door.
  4. Install the bolt that attaches the LH front door check strap to the A-pillar.
    24 Nm (17.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  5. Raise the LH front window and close the LH front door.
