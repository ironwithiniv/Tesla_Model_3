Blower Motor - HVAC (Non-Heat Pump) (Remove and Replace)

Correction code 18103202 3.84 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-11-04: Replaced the two-post lift with a floor jack to remove the washer reservoir, removed the steps for removing the LH wheel and the left front seat, and updated the steps to move the main floor duct aside instead of removing it.
  • 2026-09-17: Updated Note on replacing the blower motor with the same part number as the original one.
  • 2026-08-10: Added Note on replacing the blower motor with the same part number as the original one.
  • 2026-04-02: Added steps to remove and install brake pedal assembly.
  • 2024-01-25: Added a note to remind that it is not necessary to separate the IP harness from the cross car beam when removing the cross car beam.
Note
To prevent functional issues after replacing the blower motor, make sure to replace the blower motor with the same part number as the original one. Before installation, check the new blower motor's brand; it should be the same brand as the one removed from the vehicle.
Parent topic: 1810 - Cabin HVAC

Remove

  1. Open all four doors and lower all four windows.
  2. Partially jack up the LH front of the vehicle to create clearance between the wheel and the wheelhouse.
    Note
    Do not lift wheel off the ground.
  3. Pull the wheel liner aside and remove the lower bolt that attach the washer tank to the body.
    Note
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
    • Ratchet/torque wrench
  4. Lower the vehicle and remove the floor jack.
  5. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  6. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  7. Remove the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  8. Remove the LH and RH wiper arms. See Wiper Arms (Remove and Replace).
  9. Remove the LH and RH shock tower covers. See Cover - Shock Tower - LH (Remove and Replace).
  10. Remove the cowl screen panel. See Panel - Cowl Screen (Remove and Replace).
  11. Remove the wiper module. See Wiper Module (Remove and Replace).
  12. Release the clip that attaches the electrical harness to the windshield washer reservoir.
  13. Disconnect the electrical connector from the windshield washer reservoir.
  14. Remove the outer HVAC plenum duct. See Plenum - Inlet - HVAC (Remove and Replace).
  15. Remove the inner HVAC plenum duct. See Duct - HVAC Plenum - Inner (Remove and Replace).
  16. Remove the upper bolt that attaches the windshield washer reservoir to the body.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  17. Remove the windshield washer reservoir from the vehicle.
    Note
    2x connectors. Keep the washer reservoir upright to keep contents from spilling.
  18. Remove the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  19. Remove the LH and RH middle A-pillar trim. See Trim - A-Pillar - Middle - LH (Remove and Replace).
  20. Remove the LH and RH upper A-pillar trim. See Trim - A-Pillar - Upper - LH (Remove and Replace).
  21. Remove the LH and RH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  22. Remove the LH and RH instrument panel end caps. See End Cap - Instrument Panel - LH (Remove and Replace).
  23. Remove the driver and front passenger footwell cover. See Cover - Footwell - Driver (Remove and Replace).
  24. Disconnect 12V/LV power. See 12V/LV Power (Disconnect and Connect)
  25. Remove the driver knee airbag. See Airbag - Knee - Driver (Remove and Install).
  26. Remove the LH footwell duct. See Duct - Footwell - LH (LHD) (Remove and Replace).
  27. Remove the center console. See Center Console (Remove and Install).
  28. Remove the front passenger knee airbag. See Airbag - Knee - Front Passenger (Remove and Replace).
  29. Remove the main instrument panel decor trim. See Decor Trim - Instrument Panel - Main (Remove and Replace).
  30. Remove the LH and RH air wave end cap. See End Cap - Air Wave - LH (Remove and Replace).
  31. Remove the glove box. See Glove Box - With Knee Airbags (Non-Heat Pump) (Remove and Replace).
  32. Remove the RH footwell duct. See Duct - Footwell - LH (LHD) (Remove and Replace).
  33. Remove the RH air wave duct. See Duct - Air Wave - RH (LHD) (Remove and Replace).
  34. Remove the driver air bag. See Airbag - Driver (Remove and Replace).
  35. Remove the steering wheel. See Steering Wheel (Remove and Install).
  36. Remove the steering column control module. See Module - Steering Column Control (Remove and Replace).
  37. Remove the touchscreen. See Touchscreen (Remove and Replace).
  38. Remove the LH front vent. See Vent - Front - LH (Remove and Replace).
  39. Remove the RH front vent. See Vent - Front - RH (Remove and Replace).
  40. Remove the LH, center, and RH dash speakers. See Speaker - Dash - LH (Remove and Replace).
  41. Remove the IP carrier. See IP Carrier (Remove and Install).
  42. Remove the LH air wave duct. See Duct - Air Wave - LH (LHD) (Non-Heat Pump) (Remove and Replace).


  45. Remove the cross car beam. See Beam - Cross Car (LHD) (Remove and Replace).
    Note
    No need to separate the IP harness from the cross car beam.
  46. Remove the clip that attaches the RH front main carpet to the body.
  47. Remove the clips that attach the LH front main carpet to the vehicle.
    Note
    Number of clips on vehicles may vary.
  48. Lift the LH front main carpet towards the LH front seat.
  49. Remove the main floor duct from the HVAC assembly and set aside.
    Note
    Use a bungee cord as needed to hold the floor duct in position.
  50. Remove the bolt that attaches the HVAC module to the body.
  51. Remove the bolt that attaches the lower LH side of the HVAC assembly to the vehicle.
  52. Remove the brake pedal assembly. See Brake Pedal (Remove and Replace)
  53. Remove the screws (x3) that attach the HVAC fan motor to the HVAC assembly
  54. Slightly move the HVAC assembly towards the RH side of the vehicle and rotate the blower motor towards the rear of the vehicle, and then remove the motor from the HVAC assembly.

Install

  1. Slightly move the HVAC assembly towards the RH side of the vehicle and position the HVAC fan motor on the HVAC assembly.
  2. Install the screws (x3) that attach the HVAC fan motor to the HVAC assembly.
    1.2 Nm (.9 lbs-ft)
  3. Install the brake pedal assembly. See Brake Pedal (Remove and Replace)
  4. Install the bolt that attaches the lower LH side of the HVAC assembly to the vehicle.
    5.5 Nm (4.1 lbs-ft)

  6. Install the bolt that attaches the HVAC module to the body.
    5.5 Nm (4.1 lbs-ft)

  8. Install the main floor duct to the HVAC assembly.
  9. Install the cross car beam together with the IP harness. See Beam - Cross Car (LHD) (Remove and Replace).
  10. Position the front carpets back and install the clips that attach the LH and RH front carpets.
  11. Install the LH air wave duct. See Duct - Air Wave - LH (LHD) (Non-Heat Pump) (Remove and Replace).
  12. Install the IP carrier. See IP Carrier (Remove and Install).
  13. Install the LH, center, and RH dash speakers. See Speaker - Dash - LH (Remove and Replace).
  14. Install the LH front vent. See Vent - Front - LH (Remove and Replace).
  15. Install the RH front vent. See Vent - Front - RH (Remove and Replace).
  16. Install the RH air wave duct. See Duct - Air Wave - RH (LHD) (Remove and Replace).
  17. Install the RH footwell duct. See Duct - Footwell - LH (LHD) (Remove and Replace).
  18. Install the glove box. See Glove Box - With Knee Airbags (Non-Heat Pump) (Remove and Replace).
  19. Install the main instrument panel decor trim. See Decor Trim - Instrument Panel - Main (Remove and Replace).
  20. Install the LH and RH air wave end cap. See End Cap - Air Wave - LH (Remove and Replace).
  21. Install the touchscreen. See Touchscreen (Remove and Replace).
  22. Install the steering column control module. See Module - Steering Column Control (Remove and Replace).
  23. Install the steering wheel. See Steering Wheel (Remove and Install).
  24. Install the driver air bag. See Airbag - Driver (Remove and Replace).
  25. Install the center console. See Center Console (Remove and Install).
  26. Install the front passenger knee airbag. See Airbag - Knee - Front Passenger (Remove and Replace).
  27. Install the LH footwell duct. See Duct - Footwell - LH (LHD) (Remove and Replace).
  28. Install the driver knee airbag. See Airbag - Knee - Driver (Remove and Install).
  29. Install the driver and front passenger footwell cover. See Cover - Footwell - Driver (Remove and Replace).

  31. Install the windshield washer reservoir into the vehicle, and then install the upper bolt that attaches the windshield washer reservoir to the body.
    3 Nm (2.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  32. Partially jack up the LH front of the vehicle to create clearance between the wheel and the wheelhouse.
    Note
    Do not lift wheel off the ground.
  33. Pull the wheel liner aside and install the lower bolt that attach the washer tank to the body.
    3 Nm (2.2 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
    • Ratchet/torque wrench
  34. Lower the vehicle and remove the floor jack.
  35. Connect the electrical harness to the windshield washer pump connector and level sensor connector.
  36. Fasten the clip that attaches the electrical harness to the windshield washer reservoir.
  37. Install the inner HVAC plenum duct. See Duct - HVAC Plenum - Inner (Remove and Replace).
  38. Install the outer HVAC plenum duct. See Plenum - Inlet - HVAC (Remove and Replace).
  39. Install the wiper module. See Wiper Module (Remove and Replace).
  40. Install the cowl screen panel. See Panel - Cowl Screen (Remove and Replace).
  41. Install the LH and RH shock tower covers. See Cover - Shock Tower - LH (Remove and Replace).
  42. Install the LH and RH wiper arms. See Wiper Arms (Remove and Replace).
  43. Install the LH and RH upper A-pillar trim. See Trim - A-Pillar - Upper - LH (Remove and Replace).
  44. Install the LH and RH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  45. Install the LH and RH middle A-pillar trim. See Trim - A-Pillar - Middle - LH (Remove and Replace).
  46. Install the LH and RH instrument panel end caps. See End Cap - Instrument Panel - LH (Remove and Replace).
  47. Reconnect 12V/LV power. See 12V/LV Power (Disconnect and Connect)
  48. Install the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  49. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  50. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  51. Verify the correct operation of the windshield washers and wipers.
  52. Install the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  53. Move the LH and RH front seats to their original positions.
  54. Raise all windows and close all doors.
