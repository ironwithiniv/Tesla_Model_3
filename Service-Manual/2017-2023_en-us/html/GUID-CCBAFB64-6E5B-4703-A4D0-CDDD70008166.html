DC Input Assembly - HV Battery (Busbar Type) (Remove and Replace)

Correction code 16302402 1.56 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-10-09: Updated torque data for the bolts that attach the positive/negative fastcharge busbar inlet side with the positive/negative DC input assembly busbar.
  • 2025-02-11: Split topic into Remove and Install sections and condensed procedure.
  • 2023-06-21: Added a video at Step 2 in Removal part to illustrate how to correctly remove the charge port busbar connector from the busbar HV battery DC input assembly.
Parent topic: 1630 - HV Battery Electrical Components

Remove

  1. Remove the pyrotechnic battery disconnect. See Pyrotechnic Battery Disconnect (Remove and Replace).
  2. Remove the bolt that secures the busbar access door on the busbar HV battery DC input assembly.
  3. Remove the bolts (x2) that attach the charge port busbar connector to the busbar HV battery DC input assembly.
  4. Remove the charge port busbar connector from the busbar HV battery DC input assembly.
  5. Remove the insulator for the DC input assembly.
  6. Remove and discard the bolt that attaches the negative DC input busbar to the negative fast charge contactor busbar.
  7. Remove and discard the bolt that attaches the positive DC input busbar to the positive fast charge contactor busbar.
  8. Disconnect the electrical harness from the busbar HV battery DC input assembly connector.
  9. Remove and discard the bolts (x4) that attach the busbar HV battery DC input assembly to the ancillary bay, and then remove the input assembly from the ancillary bay.

Install

  1. Perform a zero adjust of the Hioki resistance meter in preparation to measure resistances later in this procedure. See Resistance Meter (Zero Adjust).
  2. Install the busbar HV battery DC input assembly into the ancillary bay.
    Note
    Ensure seal is not damaged and seated properly
  3. Install new bolts (x4) to attach the busbar HV battery DC input assembly to the ancillary bay, and then mark the bolts with a paint pen after tightening.
    10 Nm (7.4 lbs-ft)
  4. Install a new bolt to attach the negative DC input busbar to the negative fast charge contactor busbar, and then mark the bolt with a paint pen.
    5 Nm (3.7 lbs-ft) + 60 degrees
    Note
    Use of the following tool(s) is recommended:
    • Insulated 4 in extension
    • Insulated Ratchet/torque wrench
    • Insulated 13 mm socket
    • Torque wrench with angle measurement
  5. Install a new bolt to attach the positive DC input busbar to the positive fast charge contactor busbar, and then mark the bolt with a paint pen.
    5 Nm (3.7 lbs-ft) + 60 degrees
    Note
    Use of the following tool(s) is recommended:
    • Insulated 4 in extension
    • Insulated Ratchet/torque wrench
    • Insulated 13 mm socket
    • Torque wrench with angle measurement
  6. Use the Hioki resistance meter to measure the resistance at the HV joint between the negative DC input busbar and the negative fast charge contactor busbar.
    Note
    The maximum acceptable resistance is 0.060 mΩ (60 μΩ). If the resistance is above this value, escalate to Service Engineering.
  7. Use the Hioki resistance meter to measure the resistance at the HV joint between the positive DC input busbar and the positive fast charge contactor busbar.
    Note
    The maximum acceptable resistance is 0.060 mΩ (60 μΩ). If the resistance is above this value, escalate to Service Engineering.
  8. Install the insulator for the DC input assembly.
  9. Connect the electrical harness to the DC input assembly connector.
  10. Use an alcohol wipe to clean residual Penetrox from the charge port busbar connector contact surface, and allow 1 minute to dry.
  11. Use an alcohol wipe to clean the contact surface of the busbar HV battery DC input assembly header, and allow 1 minute to dry.
  12. Apply 2 drops of Penetrox A-13 to each contact surface of the busbar HV battery DC input assembly header, one on each side.
  13. Spread the Penetrox evenly so that the contact surface is completely covered.
  14. Install the charge port busbar connector onto the busbar HV battery DC input assembly.
  15. Install the bolts (x2) that attach the charge port busbar connector to the busbar HV battery DC input assembly.
    9 Nm (6.6 lbs-ft)
  16. Use the Hioki resistance meter to measure the resistance at the HV joint between each charge port busbar lead and its respective bolt.
    Note
    The acceptable resistance is between 0.050 mΩ (50 𝜇Ω) and 0.195 mΩ (195 𝜇Ω). If the resistance is more than 0.195 mΩ (195 𝜇Ω) stop work and escalate the Toolbox session. If the resistance is lower than 0.050 mΩ (50 𝜇Ω), reposition the probes and measure again. If the resistance is repeatedly between 0 mΩ and 0.050 mΩ (50 𝜇Ω), Hioki test passed, proceed to next step.
  17. Close the busbar access door on the busbar HV battery DC input assembly and then install the bolt that secures the door closed.
    9 Nm (6.6 lbs-ft)
  18. Measure the voltage across the pyrotechnic battery disconnect mount points, and then install the pyrotechnic battery disconnect. See Pyrotechnic Battery Disconnect (Remove and Replace).
  19. Install the ancillary bay cover. See Cover - Ancillary Bay (Remove and Install).
    Note
    Perform an ancillary bay air leak test when instructed to do so.
  20. Connect 12V power. See 12V/LV Power (Disconnect and Connect).
