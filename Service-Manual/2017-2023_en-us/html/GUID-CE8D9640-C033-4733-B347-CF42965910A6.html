Panel - Cowl Screen (Remove and Replace) (RHD)

Correction code 122598020.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1225 - Underhood Trim

Remove

  1. Open the driver's door and fully lower the window.
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Remove the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  4. Remove the hood latch cover. See Cover - Hood Latch (Remove and Replace).
  5. Remove the underhood storage unit carpet. See Carpet - Underhood Storage (Remove and Install).
  6. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  7. Remove the LH and RH wiper arms. See Wiper Arms (Remove and Replace).
    Note
    Release any clips attaching the wiper hoses to the cowl screen panel.
  8. Remove the LH and RH shock tower covers. See Cover - Shock Tower - LH (Remove and Replace).
  9. Release the washer pump hose from the Y-tube, and then release the clip that attaches the tube to the cowl screen.
  10. Release the clips that attach the cowl screen panel to the vehicle, and then remove the cowl screen panel from the vehicle.

Install

  1. Fasten the clips that attach the cowl screen panel to the vehicle, and then install the cowl screen panel to the vehicle.
    CAUTION
    Carefully install the cowl screen panel to avoid damage to the windshield. Applying excessive force on the windshield can crack the glass.
  2. Install the LH and RH shock tower covers. See Cover - Shock Tower - LH (Remove and Replace).
  3. Fasten the washer pump hose from the Y-tube, and then install the clip that attaches the tube to the cowl screen.
  4. Install the LH and RH wiper arms. See Wiper Arms (Remove and Replace).
    Note
    If present, install any clips that attach the wiper hoses to the cowl screen panel.
  5. Install the underhood storage unit carpet. See Carpet - Underhood Storage (Remove and Install).
  6. Install the hood latch cover. See Cover - Hood Latch (Remove and Replace).
  7. Install the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  8. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  9. Close the driver's door and fully lower the window.
