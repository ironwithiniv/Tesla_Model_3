Connector - Pedestrian Warning Speaker (CN) (Remove and Replace)

Correction code 171007520.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1710 - Harnesses

Remove

  1. Remove the RH front wheel. See Wheel Assembly (Remove and Install).
  2. Remove the clips (x9) that attach the RH front wheel liner to the fascia, and move the wheel liner aside for access.
  3. Remove the clip that attaches the harness to the pedestrian warning speaker assembly.
  4. Release the locking tab by sliding the red tab away from the connector, then depress the locking tab to release the pedestrian warning speaker connector.
    Note
    The connector access may vary depending on the version of the super horn audio speaker installed on the vehicle. You may need to use a pocket screwdriver or a miniature pick to release the red locking tab, which is covered by an anti-tampering feature.
  5. Remove the connector locking cover, and then press down on the pins (x2) while pulling the harness downwards to remove the connector from the vehicle.

Install

  1. Insert the pins (x2) into the connector, and then install the connector locking cover.
    Note
    Perform a pull-push-pull test to verify the pins are fully seated.
  2. Connect the pedestrian warning speaker connector.
  3. Install the clip that attaches the harness to the pedestrian warning speaker assembly.
  4. Install the clips (x9) that attach the RH front wheel liner to fascia.
  5. Install the RH front wheel. See Wheel Assembly (Remove and Install).
