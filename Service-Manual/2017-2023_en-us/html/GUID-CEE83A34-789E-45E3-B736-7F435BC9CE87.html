Steering Column (LHD) (Remove and Replace)

Correction code 32051902 1.03 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-07-13: Changed step to configure the steering column from using Toolbox 3 to using the touchscreen.
  • 2025-04-04: Updated configuration instructions.
  • 2024-12-02: Modified steering column configuration and calibration steps.
  • 2024-10-25: Added step to transfer clip from old column to new column.
  • 2023-11-09: Updated steering column gateway configuration steps.
  • 2023-09-22: Swapped steps for calibration and GTW configuration change: GTW configuration change should be done before steering column calibration.
  • 2023-06-20: Removed double configuration step and updated Toolbox routine.
Note
A variant of steering column was introduced with different tilt/telescope adjustment motors. If the steering column is replaced with different tilt/telescopic motors, refer to Toolbox article 3187900 for details about the configuration settings.
CAUTION
If performing this procedure as a result of a collision, see the Collision Repair Manual to verify whether the steering gear must be replaced as well.
Parent topic: 3205 - Upper Column, Steering Wheel

Remove

  1. Remove the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Remove the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  4. Remove the hood latch cover. See Cover - Hood Latch (Remove and Replace).
  5. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  6. Move the front seats fully rearward.
  7. On the vehicle touchscreen, touch Controls > Steering Column, and then use the steering wheel left scroll wheel to move the steering wheel fully down and fully out.
  8. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  9. Remove the driver airbag. See Airbag - Driver (Remove and Replace).
  10. Remove the steering wheel. See Steering Wheel (Remove and Install).
  11. Remove the LH and RH instrument panel end caps. See End Cap - Instrument Panel - LH (Remove and Replace).
  12. Remove the LH and RH air wave end caps. See End Cap - Air Wave - LH (Remove and Replace).
  13. Remove the main instrument panel decor trim. See Decor Trim - Instrument Panel - Main (Remove and Replace).
  14. Remove the steering column control module. See Module - Steering Column Control (Remove and Replace).
  15. Remove the LH middle A-pillar trim. See Trim - A-Pillar - Middle - LH (Remove and Replace).
  16. Remove the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  17. Remove the driver footwell cover. See Cover - Footwell - Driver (Remove and Replace).
  18. If equipped, remove the driver knee airbag. See Airbag - Knee - Driver (Remove and Install).
  19. Remove the LH footwell duct. See Duct - Footwell - LH (LHD) (Remove and Replace).
  20. Remove the screws (x2) that attach the IP carrier to the cross car beam on the lower LH side.
  21. Release the clips (x4) that attach the steering column lower gap hider to the instrument panel subassembly, lift up and forward on the gap hider, and then down to remove the gap hider from the subassembly.
  22. Remove the bolt that attaches the intermediate shaft to the steering rack assembly, and then slide the intermediate shaft fully upwards.
  23. Apply masking tape to the instrument panel, to protect the opening at the steering column.
  24. Release the steering shaft boot from the bulkhead, and then pull it up from the bulkhead.
  25. Disconnect the electrical harness from the steering column connector.
  26. Remove the nuts that attach the steering column to the cross car beam, and lower the steering column off of the studs.
  27. With the help of an assistant, raise the upper portion of the steering column up toward the roof, pull down on the instrument panel carrier under the steering column to create space for the rear motor of the steering column to pass under the cross car beam, and carefully move the steering column out toward the rear of the vehicle.
  28. After the motor clears the cross car beam, rotate the steering column to the right so that the rear motor lower portion clears the instrument panel carrier, and continue to remove the steering column from the vehicle.
    Note
    Make sure that the intermediate shaft sleeves clear the bulkhead.

Install

  1. Transfer the steering column clip (PN: 1099272-00-E) from the old steering column to the replacement steering column.
  2. Record the part number of the replacement steering column to be used later in the procedure when the gateway configuration is set.
  3. With the help of an assistant, carefully move the intermediate shaft of the steering column through the opening in the instrument panel carrier, rotate the steering column to the right so that the rear motor lower portion clears the instrument panel carrier opening, and then rotate left.
  4. Raise the upper portion of the steering column up toward the roof, pull down on the instrument panel carrier under the steering column to create space for the rear motor of the steering column to pass under the cross car beam, carefully move the steering column in toward the front of the vehicle and up onto the studs of the cross car beam.
    Note
    Make sure that the intermediate shaft sleeves enter the bulkhead.
  5. Install the nuts that attach the steering column to the cross car beam.
    15 Nm (11.1 lbs-ft)
  6. Connect the electrical harness to the steering column connector.
  7. Fasten the steering shaft boot to the bulkhead.
  8. With the help of an assistant, slide the intermediate shaft down onto the steering rack shaft, and then install the bolt that attaches the intermediate shaft to the steering rack shaft.
    18 Nm (13.3 lbs-ft)
  9. Remove the masking tape from the instrument panel.
  10. Lift the steering column lower gap hider up, rearward, and down to install the gap hider onto the instrument panel subassembly, then fasten the clips (x4) that attach the gap hider to the subassembly.
  11. Install the screws (x2) that attach the IP carrier to the cross car beam on the lower LH side.
    2.3 Nm (1.7 lbs-ft)
  12. Install the LH footwell duct. See Duct - Footwell - LH (LHD) (Remove and Replace).
  13. If equipped, install the driver knee airbag. See Airbag - Knee - Driver (Remove and Install).
  14. Install the driver footwell cover. See Cover - Footwell - Driver (Remove and Replace).
  15. Install the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  16. Install the LH middle A-pillar trim. See Trim - A-Pillar - Middle - LH (Remove and Replace).
  17. Install the steering column control module. See Module - Steering Column Control (Remove and Replace).
  18. Install the main instrument panel decor trim. See Decor Trim - Instrument Panel - Main (Remove and Replace).
  19. Install the LH and RH air wave end caps. See End Cap - Air Wave - LH (Remove and Replace).
  20. Install the LH and RH instrument panel end caps. See End Cap - Instrument Panel - LH (Remove and Replace).
  21. Install the steering wheel. See Steering Wheel (Remove and Install).
  22. Install the driver airbag. See Airbag - Driver (Remove and Replace).
  23. Connect 12V power. See 12V/LV Power (Disconnect and Connect).
  24. Return the front seats to their original positions.
  25. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  26. Install the hood latch cover. See Cover - Hood Latch (Remove and Replace).
  27. Install the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  28. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  29. Install the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  30. Connect a laptop with Toolbox to the vehicle. See Toolbox (Connect and Disconnect).
  31. Use the replacement steering column part number recorded earlier and this table to determine the type of steering column installed and configuration value to be chosen.
    Part Number Drive Build Location Configuration Value
    1044811 LHD Fremont and early Giga Shanghai "BOSCH"
    1044816 RHD Fremont and early Giga Shanghai "BOSCH"
    1044871 LHD Giga Shanghai "JE"
    1044876 RHD Giga Shanghai "JE"
  32. On the touchscreen, tap Service Mode > Steering > Steering Column Configuration, select the appropriate configuration from the Steering Column Configuration menu , and confirm your change by tapping the check mark.
  33. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): PROC_STEERING_COLUMN_CALIBRATIONvia Service Mode:Chassis ➜ Steering ➜ Calibrate Steering Columnvia Toolbox:(link)
  34. Disconnect the laptop from the vehicle. See Toolbox (Connect and Disconnect).
  35. Exit Service Mode.
  36. Restore the driver and front passenger seats back to their original position.
  37. Restore the steering column back to its original position.
  38. Raise both front windows and close both front doors.
