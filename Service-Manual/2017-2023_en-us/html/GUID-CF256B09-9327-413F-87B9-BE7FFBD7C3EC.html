 Replace 8008277-00-A

Remove

  1. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  2. Place the vehicle into EPB Service Mode. See Parking Brake - Caliper - Rear - LH (Release).
  3. Remove the LH rear wheel. See Wheel Assembly (Remove and Install).
  4. Release the locking tab, and then disconnect the LH rear EPB caliper connector.
  5. Remove and discard the bolts (x2) that attach the LH rear brake caliper motor to the vehicle, and then remove the caliper motor from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • 5 mm hex
  6. Remove and discard the old O-ring from the LH rear brake caliper.

Install

  1. Install the new O-ring provided in the service kit onto the LH rear brake caliper.
  2. Position the LH rear brake caliper motor into the vehicle, and then install new bolts (x2) that attach the caliper motor to the vehicle.
    10.8 Nm (8.0 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 5 mm hex
  3. Connect the LH rear EPB caliper connector, and then engage the locking tab.
  4. Position the LH rear wheel and hand-tighten the lug nuts.
  5. On the touchscreen, touch Chassis > Brakes > EPB Service Mode, select "BOTH" in "EPB Selection" and "STOP" in "Action Selection", and then touch RUN to exit EPB Service Mode.
    Tip
    If a parking brake mismatch alert occurs, perform a software reinstall. See Software Reinstall - Touchscreen.
  6. Exit Service Mode. See Service Mode.
  7. Install the LH rear wheel. See Wheel Assembly (Remove and Install).
  8. Remove the vehicle from the lift. See Raise Vehicle - 2 Post Lift.
