Post Guide - Headrest - Front Passenger Seat (Remove and Replace)

Correction code 13040042 0.96 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1304 - Front Seat Assemblies and Hardware

Remove

  1. Check that the firmware is version 2023.2.11 or above. If the firmware version is not 2023.2.11 or above, update the vehicle firmware.
  2. Remove the front passenger seat from the vehicle. See Seat Assembly - 1st Row - LH (Remove and Replace).
  3. Remove the front passenger seat outboard side shield. See Side Shield - Outboard - Driver Seat (Remove and Replace).
    Note
    During removal, certain steps require extra care. See the animation(s) for detailed guidance.
    Note
    LH shown, RH similar
  4. Remove the front passenger seat inboard side shield. See Side Shield - Inboard - Driver Seat (Remove and Replace).
  5. Lay the seat on its seat back to gain access to the underside of the seat cushion.
    CAUTION
    Protect the seat cushion from damage as necessary.
  6. Release the clips that attach the shell apron to the underside of the seat.
  7. Disconnect the seat back heater connector.
  8. Slide the seat back harness connector straight down to release it from the seat assembly.
  9. Disconnect the seat cushion heat pad connector from the seat back head pad connector.
  10. Slide the seat cushion connector upward to release it from the seat assembly.
  11. Return the seat to the upright position.
  12. Remove the front passenger headrest trim. See Trim - Headrest - Driver (Remove and Replace).
  13. Remove the front passenger back shell. See Shell - Seat Back - Driver (Remove and Replace).
  14. Remove the front passenger seat back trim retainers (x7) from the seat back frame.
  15. Remove the lower flap that covers the outboard corner of the front passenger seat seat back frame.
    Note
    Pull the trim straight up, off of the retaining tabs to release it.
  16. Remove the upper flap that covers the outboard corner of the front passenger seat seat back frame.
    Note
    Pull the lower section of trim away from the retaining tab to release it, then pull the trim straight up off of the upper retaining tab.
  17. Remove the lower flap covering the inboard corner of the front passenger seat seat back frame.
    Note
    Pull the trim straight up, off of the retaining tabs to release it.
  18. Remove the upper flap that covers the inboard corner of the front passenger seat seat back frame.
    Note
    Pull the lower section of trim away from the retaining tab to release it, and then pull the trim straight up off of the upper retaining tab.
  19. Pull the front passenger seat seat back trim away from the front passenger seat side airbag to gain access to the air bag electrical connector.
  20. Disconnect the front passenger seat side airbag and pull the orange tabs(x2) down to release the connector.
  21. Remove the bolt that attaches the bottom of the lumbar support to the seat back frame.
    5 Nm (3.7 lbs-ft)
    Note
    The bolt is located below the lumbar ECU. Removing this bolt allows ease of access for the following step.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  22. Release the tabs(x2) that attach the bottom of the lumbar support to the seat back frame.
  23. Remove and discard the nuts (x2) that attach the front passenger seat side airbag to the seat back frame.
    5.4 Nm (4.0 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  24. Carefully pull the front passenger seat side airbag chute from the seat back frame.
    CAUTION
    Do not remove the airbag from the airbag chute.
  25. Remove the seat upholstery by pulling the bottom of the seat back trim away from the seat back frame.
    Note
    Make sure the heater harness and the seat back trim is clear of the seat back frame.
  26. Release the RH side headrest post guide from the seat back frame.
    Note
    Press in the headrest guide post clips, and then gently tap the base of the guide post with the hammer to release it.

Install

  1. Install the RH headrest post guide into the seat assembly.
  2. Install the front passenger seat seat back and foam onto the seat back frame.
    Note
    Start by sliding the foam trim straight onto the seat back frame. Make sure the posts for the headrests engage the seat back foam. Make sure the heater harness and lower trim that engages the frame are pushed through to the back side of the frame.
  3. Install the front passenger seat side airbag studs into the seat back frame.
    Note
    The studs should line up with the two round holes. The elongated hole is not used for this part.
  4. Install new nuts (x2) that attach the front passenger seat airbag to the seat back frame.
    5.4 Nm (4.0 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  5. Connect front passenger seat side airbag electrical connector.
  6. Install the upper flap that covers the outboard corner of the front passenger seat seat back frame.
    Note
    Pull the flap over the metal tangs to secure it.
  7. Install the upper flap that covers the inboard corner of the front passenger seat seat back frame.
    Note
    Pull the flap over the metal tangs to secure it.
  8. Install the lower flap that covers the outboard corner of the front passenger seat seat back frame.
    Note
    Pull the flap over the metal tangs to secure it.
  9. Install the lower flap covering the inboard corner of the front passenger seat seat back frame.
    Note
    Pull the flap over the metal tangs to secure it.
  10. Install the tabs(x2) that attach the bottom of the lumbar support to the seat back frame.
  11. Install the bolt that attaches the bottom of the lumbar support to the seat back frame.
    5 Nm (3.7 lbs-ft)
    Note
    The bolt is located below the lumbar ECU.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  12. Install the front passenger seat back trim retainers(x7) to the front passenger seat back frame.
  13. Install the front passenger seat back shell onto the seat. See Shell - Seat Back - Driver (Remove and Replace).
  14. Install the front passenger headrest trim. See Trim - Headrest - Driver (Remove and Replace).
  15. Lay the seat on its seat back to gain access to the underside of the seat cushion.
    CAUTION
    Protect the seat cushion from damage as necessary.
  16. Install the seat cushion connector to the seat assembly.
  17. Connect the seat cushion heat pad connector to the seat back head pad connector.
  18. Install the seat back harness connector to the seat assembly.
  19. Connect the seat back heater connector.
  20. Install the front passenger seat inboard side shield. See Side Shield - Inboard - Driver Seat (Remove and Replace)
  21. Install the front passenger seat outboard side shield. See Side Shield - Outboard - Driver Seat (Remove and Replace).
  22. Install the front passenger seat into the vehicle. See Seat Assembly - 1st Row - LH (Remove and Replace).
  23. If servicing the front passenger seat in a North American vehicle:
    1. Remove all objects from the front passenger seat before beginning calibration.
    2. On the vehicle touchscreen, touch Controls (Vehicle Icon) > Software and check the vehicle firmware version. If the vehicle firmware is 2023.2.11 or newer, perform a software reinstall. See Software Reinstall - Touchscreen. If the vehicle firmware is not 2023.2.11 or newer, update the vehicle firmware. See Software Update.
    3. Locally connect a laptop with Toolbox 3 to the vehicle. See Toolbox (Connect and Disconnect).
    4. Unlock the vehicle gateway. See Gateway (Unlock).
    5. In Toolbox, click on the Actions tab, and then search for "OCS".
    6. Run the PROC_OCS1P_SELF-CALIBRATIONvia Service Mode Plus:Safety & Restraints ➜ Seats ➜ OCS1P Self Capacitance Calibrationvia Toolbox:(link) routine.
    7. Click on the Actions tab, and then search for "Seat calibration".
    8. Run the PROC_VCRIGHT_SEAT-CALIBRATEvia Service Mode:Low Voltage ➜ Seats ➜ Calibrate Seatvia Toolbox:(link) routine.
    9. Disconnect Toolbox and remove the laptop from the vehicle.
