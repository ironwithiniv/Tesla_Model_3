Headlight - LH (Remove and Install)

Correction code 17400101 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1740 - Exterior Lights

Torque Specifications

Table 1. Torque Specifications: Headlight - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Screws that attach the headlight to the body
5.9 Nm (4.4 lbs-ft)
  • 10 mm socket
 Reuse
Bolt that attaches the fender bracket to the body
3 Nm (2.2 lbs-ft)
  • Torx T20 socket
 Reuse

Remove

  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Remove the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  3. Remove the hood latch cover. See Cover - Hood Latch (Remove and Replace).
  4. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  5. Remove the front fascia. See Fascia - Front (Remove and Install).
  6. Disconnect the electrical connector from the LH headlight.
    Note
    If the connector has a red locking tab: DO NOT push down on the red locking tab. Pull the tab away from the connector until the connector is unlocked, and then continue pulling the main body of the connector to fully disconnect it.
  7. Remove the bolt that attaches the fender bracket to the body, and then remove the bracket from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  8. Remove the fastener(s) that attach the LH headlight to the body.
    Note
    The headlight might not be equipped with a lower fastener.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  9. Remove the headlight from the vehicle.

Install

  1. Position the LH headlight onto the body.
    CAUTION
    Do not damage the headlight during installation.
  2. Install the fasteners that attach the LH headlight to the body.
    5.9 Nm (4.4 lbs-ft)
    Note
    The headlight might not be equipped with a lower fastener.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  3. Install the bolt that attaches the fender bracket to the body.
    3 Nm (2.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  4. Connect the electrical connector for the LH headlight.
  5. Install the front fascia. See Fascia - Front (Remove and Install).
  6. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  7. Install the hood latch cover. See Cover - Hood Latch (Remove and Replace).
  8. Install the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  9. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  10. Adjust the headlights:
    • Headlights - Adjust - EMEA (Tool Method)
    • Headlights - Adjust - EMEA (Wall Method)
    • Headlights - Adjust - Global (Tool Method)
    • Headlights - Adjust - Global (Wall Method)
    • Headlights - Adjust - NA (Tool Method)
    • Headlights - Adjust - NA (Wall Method)
