Carrier - Side Shield - Outboard - Driver Seat (Remove and Replace)

Correction code 13070012 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Note
Depending on the build location, some vehicles may not be equipped with this part. For vehicles equipped with diamond cover, see Diamond Cover - Seat Side - 1st Row - LH (Remove and Replace).
Parent topic: 1307 - Front Seat Covers Pads and Trims

Remove

  1. Remove the driver seat outboard side shield. See Side Shield - Outboard - Driver Seat (Remove and Replace).
    Note
    During removal, certain steps require extra care. See the animation(s) for detailed guidance.
  2. Remove the driver seat outboard side shield carrier clips (x2).
  3. Remove the remaining clips that secure the driver seat outboard side shield carrier.
    Note
    Release the locating clips (x2) rearward. Then lift up and pull back to release the other three clips.

Install

  1. Install the clips that secure the driver seat outboard side shield carrier.
    Note
    Align two rear clips from top to bottom and push forward to ensure they are fully seated. Then install the other clips (x3).
  2. Install the driver seat outboard side shield carrier clips (x2).
    Note
    Push the clips inward.
  3. Install the driver seat outboard side shield. See Side Shield - Outboard - Driver Seat (Remove and Replace).
