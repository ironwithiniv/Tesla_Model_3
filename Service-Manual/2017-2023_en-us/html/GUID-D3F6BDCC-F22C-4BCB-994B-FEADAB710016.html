Carrier - Front End (Heat Pump) (Remove and Replace)

Correction code 10101012 1.02 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
Parent topic: 1010 - Body Panels

Remove

  1. Open the LH front door and lower the LH front window.
  2. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  3. Remove the front fascia. See Fascia - Front (Remove and Install).
  4. Disconnect the active grille shutter actuator connector.
    Note
    Do not push down on the red tab. Pull the red tab to disengage the lock, and then pull it again to release the connector.
  5. Remove the ambient temperature sensor cover from the active grille shutter.
  6. Disconnect the ambient temperature sensor connector.
  7. Disconnect the hood latch open switch.
    Note
    Do not push down on the red tab. Pull the red tab to disengage the lock, and then pull it again to release the connector.
  8. Disconnect the hood latch actuator.
  9. Remove hood latch actuator from front end carrier
    Note
    2x bolts, 10mm, 5 Nm
  10. Remove hood latch from front end carrier
    Note
    2x bolts,10mm, 8 Nm, Mark latch location for alignment when installing
  11. Remove LH center fascia reinforcement from front end carrier
    Note
    1x tab, 2x datums, Release locking tab under fascia reinforcement, then pull straight up to release fascia reinforcement
  12. Remove RH center fascia reinforcement from front end carrier
    Note
    1x tab, 2x datums, Release locking tab under fascia reinforcement, then pull straight up to release fascia reinforcement
  13. Disconnect front acceleration sensors
    Note
    1x connector, Do not push down on red tab, Pull red tab to disengage lock, Pull again to release connector, Disconnect LH, RH, and center front acceleration sensor
  14. Remove bolts securing front bumper beam with energy absorber to LH crush can
    Note
    2x bolts, 15mm, 75 Nm
  15. Remove bolts securing front bumper beam with energy absorber to RH crush can
    Note
    2x bolts, 15mm, 75 Nm
  16. Remove front bumper beam with energy absorber
    Note
    Use a pry bar as needed to remove front bumper beam, Be cautious when prying not to damage body, Slightly tap with dead blow hammer to assist with removal as needed
  17. Disconnect LH FEM harness connector
    Note
    1x locking connector, Disengage locking tab
  18. Disconnect RH FEM harness connector
    Note
    1x locking connector, Disengage locking tab
  19. Remove radar assembly harness clip from FEM radar bracket
    Note
    1x clip
  20. Disconnect the radar assembly connector.
  21. Remove the FEM radar bracket from front end carrier
    Note
    4x bolts, 10mm, 8 Nm
  22. Use bungee cords to support the cooling fan module assembly.
  23. Remove RH bolt securing cooling fan module assembly to front end carrier
    Note
    1x bolt, 8mm, 10 Nm, Recommend assistance to support the cooling fan module assembly
  24. Remove LH bolt securing cooling fan module assembly to front end carrier
    Note
    1x bolt, 8mm, 10 Nm, Recommend assistance to support the cooling fan module assembly
  25. Remove lower bolts securing front end carrier to vehicle
    Note
    4x bolts, 13mm, 16 Nm
  26. Remove ankle catcher from front end carrier
    Note
    2x datums, Slightly pull carrier outward to clear datum from ankle catcher
  27. Remove upper bolts securing front end carrier to vehicle and remove front end carrier
    Note
    2x bolts, 13mm, 16 Nm
  28. Remove FEM harness from front end carrier (5x clips).

Install

  1. Install FEM harness to front end carrier (5x clips).
  2. Position front end carrier to vehicle and install upper bolts securing front end carrier hand tight
    Note
    2x bolts, 13mm, 16 Nm, Torque at later step
  3. Position the ankle catcher onto the front end carrier
    Note
    2x datums, Slightly pull carrier outward to secure ankle catcher onto datums
  4. Install lower bolts securing front end carrier to vehicle
    Note
    4x bolts, 13mm, 16 Nm
  5. Torque upper bolts securing front end carrier to vehicle
    Note
    2x bolts, 13mm, 16 Nm
  6. Install bolts securing cooling fan module to front end carrier
    Note
    2x bolts, 8mm, 10 Nm
  7. Remove bungee cords supporting cooling fan module assembly
    Note
    2x bungee cords
  8. Install the FEM radar bracket to front end carrier
    Note
    4x bolts, 10mm, 8 Nm
  9. Connect the radar assembly connector.
  10. Install radar assembly harness clip to FEM radar bracket
    Note
    1x clip
  11. Connect RH FEM harness connector
    Note
    1x connector, Engage locking tab
  12. Connect LH FEM harness connector
    Note
    1x connector, Engage locking tab
  13. Position front bumper beam with energy absorber
    Note
    Use a dead blow hammer as needed to install front bumper beam into front crush cans
  14. Install bolts securing front bumper beam with energy absorber to LH crush can
    Note
    2x bolts, 15mm, 75 Nm
  15. Install bolts securing front bumper beam with energy absorber to RH crush can
    Note
    2x bolts, 15mm, 75 Nm
  16. Connect front acceleration sensors
    Note
    3x connectors, Engage locking tab, Connect LH, RH, and center front acceleration sensors
  17. Install RH center fascia reinforcement to front end carrier
    Note
    1x tab, 2x datums, Engage locking tab, Push straight down for installation
  18. Install LH center fascia reinforcement to front end carrier
    Note
    1x tab, 2x datums, Engage locking tab, Push straight down for installation
  19. Install hood latch to front end carrier
    Note
    2x bolts,10mm, 8 Nm, Hand tighten bolts and make fine adjustments, Align hood latch with marked locations
  20. Install hood latch actuator onto front end carrier
    Note
    2x bolts, 10mm, 5 Nm
  21. Connect the hood latch actuator.
  22. Connect the hood latch open switch connector
    Note
    1x connector, Engage locking tab
  23. Connect the ambient temperature sensor connector.
  24. Install ambient temperature sensor cover into active grille shutter
  25. Install connector to active grille shutter actuator
    Note
    1x connector , Engage locking tab
  26. Install the front fascia. See Fascia - Front (Remove and Install).
  27. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
