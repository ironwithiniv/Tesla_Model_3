Firmware Update - Mobile Connector

Correction Code 50010003

  • 2024-06-06: Added steps to update Mobile Connector firmware on vehicles operating software version 2024.14+.
Parent topic: 5001 - Mobile Connector

Determine Vehicle Software Version

On the vehicle touchscreen, touch Controls (vehicle icon) > Software, and then scroll down to display the vehicle software version.

  • If the vehicle software version is 2024.14 or newer, perform Update Mobile Connector Firmware On Vehicle Software Version 2024.14 And Newer to update the Mobile Connector firmware.
  • If the vehicle software version is older than 2024.14, perform Update Mobile Connector Firmware On Vehicle Software Version Older Than 2024.14 to update the Mobile Connector firmware.

Update Mobile Connector Firmware On Vehicle Software Version 2024.14 And Newer

  1. Make sure the vehicle's HV battery has at least 5% SoC.
  2. Using the Mobile Connector, charge the vehicle for at least 10 minutes.
  3. Shortly after 10 minutes of charging have elapsed, the Mobile Connector firmware update will begin.
    Note
    A notification will appear on the touchscreen, stating "Charge Connector Update in Progress".
  4. The Mobile Connector firmware update will finish within 3 minutes.
    Note
    Ignore any charging related error messages that appear on the instrument panel/touchscreen.

Update Mobile Connector Firmware On Vehicle Software Version Older Than 2024.14

Note
Charge the vehicle to at least 55% before continuing with this procedure.
  1. Open the LH front door.
  2. Connect the Mobile Connector to a wall outlet.
  3. Use the button on the Mobile Connector to open the charge port door, and then connect the Mobile Connector to the vehicle.
  4. On the touchscreen charging menu, touch Set Limit, and then set the charge limit below the current charge level.
  5. The Mobile Connector firmware update will begin within 1 minute.
    Note
    A notification will appear on the instrument panel, stating "Charge Connector Update in Progress".
  6. The Mobile Connector firmware update will finish within 3 minutes.
    Note
    Ignore any charging related error messages that appear on the instrument panel/touchscreen.
  7. Disconnect the Mobile Connector from the vehicle, and then close the charge port door.
  8. Disconnect the Mobile Connector from the wall outlet.
  9. Connect the Mobile Connector to the wall outlet.
  10. Use the button on the Mobile Connector to open the charge port door, and then connect the Mobile Connector to the vehicle.
  11. On the touchscreen charging menu, touch Set Limit, and then set the charge limit above the current charge level.
  12. Make sure that the vehicle begins charging.
  13. Disconnect the Mobile Connector from the vehicle, and then close the charge port door.
  14. Disconnect the Mobile Connector from the wall outlet.
