Bracket - Headlight - LH (Remove and Replace)

Correction code 17400112 0.84 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1080559-20-A TOOL, TORQUE SCREWDRIVER, 0.8-2.0NM (NA, APAC)
  • 1080559-21-A TOOL, TORQUE SCREWDRIVER, 0.8-2.0NM (EMEA)
Parent topic: 1740 - Exterior Lights

Torque Specifications

Table 1. Torque Specifications: Bracket - Headlight - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Screws that attach the headlight bracket to the headlight
1.8 Nm (1.3 lbs-ft)
  • Torx T25 socket
 Reuse

Remove

Note
If the headlight bracket is not available as a standalone serviceable part, the headlight assembly (which includes the bracket) should be replaced.
  1. Remove the headlight. See Headlight - LH (Remove and Replace).
  2. Remove the screws that attach the bracket to the headlight, and then remove the bracket from the headlight.
    Note
    Use of the following tool(s) is recommended:
    • Torx T25 socket

Install

  1. Install the screws that attach the bracket to the headlight.
    1.8 Nm (1.3 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • Torx T25 socket
  2. Install the headlight. See Headlight - LH (Remove and Replace).
    CAUTION
    Make sure to adjust the headlights after installing the headlight.
