PTC Heater Electronics (Retrofit)

Correction code 16014567 FRT 1.92 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-10-28: Corrected images and HV carrier screw spec, added steps for HV header, busbar replacement, rear aero shield and skid plate, and updated terminal pulling tool.
  • 2026-08-21: Updated part number for extraction tool.
  • 2026-06-22: Updated part numbers for special tools.
  • 2026-05-07: Added terminal connection method and resistance value for HV carriers equipped with a compressor negative coil.
Note
Newer replacement HV battery packs do not have PTC heater electronics. Follow this procedure to install PTC heater electronics on the replacement pack.
Note
This procedure begins with the old HV battery already removed from the vehicle. Use this correction in conjunction with the appropriate HV battery (Remove and Replace) correction.
Note
The parts required for this rework will be automatically added to the service activity. However, the heat shrink tubing must be procured externally. Tesla employees in NA: use the Digikey punchout (3M PN: EPS300-3/4-48"-RED-45 PCS, Digikey PN: 3M161211-ND); Tesla employees in CN: order 2393485-00-A - Woer 3:1 Heat Shrink Tubing 9.5, Yellow. Tesla employees in EMEA: procure a heat shrink with 3:1 ratio (19mm before shrinking, 6mm after shrinking) through local punch out. Example: 3733 19 from Foerch.

Remove

  1. Remove the ancillary bay cover. See Cover - Ancillary Bay (Remove and Install).
  2. Remove the pyrotechnic disconnect and install the dummy disconnect. See Pyrotechnic Battery Disconnect (Remove and Replace).
  3. Use bungee to secure the HVC (high voltage controller) in an upwards position.
    Note
    Wrap the bungee around the RH headrest.
  4. Remove and discard the patch nuts (x2) that secure the 700VDC 63A compressor fuse, and remove the fuse from the ancillary bay.
    Tip
    Use of the following tool(s) is recommended:
    • Insulated 8 mm socket
  5. Remove and discard the patch nuts (x2) that secure the 700VDC 63A PCS output fuse, and remove the fuse from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • Insulated 8 mm socket
  6. Remove the nut that secures the HV battery ancillary positive busbar.
    Tip
    Use of the following tool(s) is recommended:
    • Insulated 8 mm socket
  7. Remove and discard the HV battery ancillary positive busbar from the AWD busbar and distribution assembly.
    Note
    The busbar that divides the HV to 3 fuses instead of 2 will be needed later in the install step.
  8. Remove the nut that attaches the negative AC harness to the negative HV battery DC link busbar.
    Tip
    Use of the following tool(s) is recommended:
    • Insulated 8 mm socket
  9. Remove the nuts (x2) that attach the AC negative harness to the transformer.
    Note
    The two terminals will be connected together later in the rework; the nuts will not be reinstalled.
    Tip
    Use of the following tool(s) is recommended:
    • Insulated 7 mm socket
  10. Disconnect the HV carrier connector.
  11. Remove the screw that secures the HV carrier assembly.
    Tip
    Use of the following tool(s) is recommended:
    • Insulated Torx T25 bit
  12. Remove the rear aero shield. See Panel - Aero Shield - Rear (Remove and Replace).
  13. Remove the rear HV battery skid plate. See Skid Plate - HV Battery - Rear (Remove and Replace).
  14. Position a coolant drain container underneath the RH rear of the vehicle.
  15. Disconnect the HV battery return tube from the RH rear of the new HV battery.
    Note
    1x spring clip, 1x plug. Plug HV battery and hose. Use shop towel to clean any residue coolant if necessary. Coolant loss greater than 1 L will require vacuum fill.
  16. Remove the coolant drain container from underneath the vehicle.
  17. Disconnect the ancillary harness connector from the RH rear of the new HV battery.
    Note
    Release the red locking tab and rotate the lever arm to release.
  18. Remove the bolts (x2) that secure the 4-pole HV header to the HV battery.
    Note
    Use of the following tool(s) is recommended:
    • SKT, 1/4" DR, EP10, LOW PROFILE
    Note
    Discard the bolts if disassembled more than three times.
  19. Insert the 4-pole header assembly removal tool into the HV header and remove the header from the HV battery.
    Note
    Insert the 4-pole header assembly removal tool into the align tool slot with short portion of the internal connector. Verify the tool is fully seated. Squeeze the tool release tabs and remove the HV carrier assembly. Gently pry on header to remove if necessary.
  20. Lower the vehicle to a comfortable working height.
  21. Release the tabs (x2) and the locating pins (x2) to remove the HV carrier assembly.

Install

  1. Apply a 600v heat shrink sleeve to the harness, connect 2 terminals together using an M4 nut and bolt, and then apply heat shrink.
    2.5 Nm (1.8 lbs-ft)
    Note
    The nut is 8 mm and the bolt is T20. Check the resistance with the Hioki and make sure the resistance is less than 70 μΩ.
    Note
    For the HV carriers equipped with compressor negative coils, use nuts (1104396-00-A) (x2) (torque 2.5 Nm) instead of using a nut, a bolt and a heat shrink to connect the 2 terminals.
    Tip
    Use of the following tool(s) is recommended:
    • Insulated Torx T20 bit
    • Insulated 8 mm socket
  2. Install the HV carrier assembly (2x tabs, 2x locating pins).
    Note
    Use insulated pick to pull terminal through.
  3. Install the screw that secures the HV carrier assembly.
    3 Nm (2.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Insulated Torx T25 bit
  4. Secure the metal tabs (x2) to attach the 4-pole HV header to the pin carrier.
  5. Install the bolts (x2) that secure the HC-Stak HV header to the HV battery.
    10 Nm (7.4 lbs-ft)
    Note
    Install new bolts if the old bolts were disassembled more than three times.
  6. Connect the ancillary harness connector to the RH rear of the HV battery.
    Note
    Hold the connector level with the header and secure with even upward force. Rotate the lever arm and secure the locking tab. Verify that the latch is fully secured and not damaged.
  7. Position a coolant drain container underneath the RH rear of the vehicle.
  8. Remove the plug and connect the HV battery return tube to the RH rear of the HV battery (1x spring clip).
    Note
    Perform a push-pull-push test to make sure that the hose is fully secured.
    Note
    Coolant loss greater than 1L requires vacuum fill.
  9. Remove the coolant drain container from underneath the vehicle.
  10. Install the rear HV battery skid plate. See Skid Plate - HV Battery - Rear (Remove and Replace).
  11. Connect the HV carrier connector.
  12. Install the nut that attaches the negative AC harness to the negative HV battery DC link busbar.
    4.5 Nm (3.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Insulated 8 mm socket
  13. Perform Hioki resistance test at AC harness to negative HV battery DC link busbar.
    Note
    The acceptable value is 55 μΩ or less. Perform zero adjust to Hioki meter prior to testing.
  14. Install upside-down M5 nuts (x2) to the ancillary tray as circled in the image.
  15. Install a new HV battery ancillary positive busbar (1097629-00-C) to the AWD busbar and distribution assembly.
  16. Install the nut that secures the HV battery ancillary positive busbar.
    4.5 Nm (3.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Insulated 8 mm socket
  17. Perform Hioki resistance test at ancillary positive busbar bracket to positive HV battery DC link busbar.
    Note
    The acceptable value is 60μΩ or less. Perform zero adjust to Hioki meter prior to testing.
  18. Position the 700VDC 63A PCS output fuse in the ancillary bay, install new bolts (x2) that secure the 700VDC 63A PCS output fuse, and mark the bolts with a paint pen after torquing.
    4.5 Nm (3.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Insulated 8 mm socket
  19. Perform Hioki resistance test at 63A PCS fuse output joint.
    Note
    The acceptable value is 105μΩ or less. Perform zero adjust to Hioki meter prior to testing.
  20. Perform Hioki resistance test at 63A PCS fuse input joint.
    Note
    The acceptable value is 145μΩ or less. Perform zero adjust to Hioki meter prior to testing.
  21. Install new nuts (x2) that secure the 700VDC 63A compressor fuse.
    4.5 Nm (3.3 lbs-ft)
    Note
    Mark after torque.
    Tip
    Use of the following tool(s) is recommended:
    • Insulated 8 mm socket
  22. Perform Hioki resistance test at 63A compressor fuse output joint.
    Note
    The acceptable value is 105 μΩ or less. Perform zero adjust to Hioki meter prior to testing.
  23. Perform Hioki resistance test at 63A compressor fuse input joint.
    Note
    The acceptable value is 145μΩ or less. Perform zero adjust to Hioki meter prior to testing.
  24. Install new nuts (x2) to secure the 700VDC 63A PTC heater fuse.
    4.5 Nm (3.3 lbs-ft)
    Note
    Mark after torque.
    Tip
    Use of the following tool(s) is recommended:
    • Insulated 8 mm socket
  25. Perform Hioki resistance test at 63A PTC heater fuse output joint.
    Note
    The acceptable value is 105 μΩ or less. Perform zero adjust to Hioki meter prior to testing.
  26. Perform Hioki resistance test at 63A PTC heater fuse input joint.
    Note
    The acceptable value is 145 μΩ or less. Perform zero adjust to Hioki meter prior to testing.
  27. Install the fuses access insulator (3x clips).
  28. Remove the dummy disconnect and install the pyrotechnic disconnect. See Pyrotechnic Battery Disconnect (Remove and Replace).
  29. Install the ancillary bay cover. See Cover - Ancillary Bay (Remove and Install).
