ECU - ABS Modulator (Heat Pump) (Remove and Replace)

Correction code 33010122 1.56 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-04-29: Corrected torque figures for the bolts that attach the shock tower brace to the vehicle.
Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
Parent topic: 3301 - Brake Discs and Calipers

Remove

  1. Raise and support vehicle
  2. Open all four doors
    Note
    If vehicle is being powered down, Latch rear doors to prevent accidental closure
  3. Lower all four windows
  4. Move LH front seat forward
  5. Move RH front seat forward
  6. Remove 2nd row seat cushion and disconnect harness
    Note
    2x tabs, 2x connectors, Press tab toward LH side of vehicle on each side to release front edge of seat cushion
  7. Move LH front seat backward
  8. Open hood
    Note
    Press "Open" button on the touchscreen to release the latch, Lift the lid manually
  9. Remove rear apron
    Note
    12x clips, Only store rear apron visible face upwards
  10. Remove cabin intake upper duct assembly
    Note
    4x clips, Heat pump vehicles have 3x clips
  11. Power off vehicle from center display
    Note
    Via Controls > Safety & Security > Vehicle Power > Power Off, Confirm power off at warning dialogue box
  12. Disconnect 12V negative terminal
    Note
    1x nut, 10mm, 6 Nm, Ensure the vehicle is in park, climate control system is off, and vehicle is not charging before disconnecting 12V
  13. Disconnect first responder loop
    Note
    1x connector, Release locking tab
  14. Lock steering wheel into position
  15. Remove all items from pockets and ensure not wearing metal items
  16. Inspect HV insulating gloves
    Note
    Check gloves for damage prior to each use, Refer to service document TN-15-92-003 R5, for information on inspecting HV gloves, https://service.tesla.com/docs/ServiceBulletins/External/TN/TN-15-92-003_High_Voltage_Awareness_Care_Points_R5.pdf
  17. Put on HV insulating gloves and leather over gloves
    Note
    Make sure to wear Electrical Protective Gloves any time Hioki tester is used
  18. Remove bolts securing ancillary bay probe lid cover to ancillary bay cover
    Note
    2x bolts, EP10 5-Lobe, 6 Nm, Discard after removal
  19. Remove ancillary bay probe lid cover from ancillary bay cover
  20. Verify no high voltage
    Note
    Make sure to wear PPE (HV gloves, safety glasses) when working on high voltage component, Measure B+ to Ground, B- to Ground, B+ to B-, If voltage is greater than 10V, Pack contactors are not open or welded, Stop work and reach out to Service Engineering
  21. Inspect ancillary bay probe lid cover gasket then position onto the ancillary bay cover
    Note
    Confirm no damage is present, Seal can be re-used
  22. Install bolts securing ancillary bay probe lid cover to ancillary bay cover
    Note
    2x bolts, E10 5-Lobe, 6 Nm, Install new fasteners
  23. Remove HV insulating gloves
  24. Remove closeout panel from frunk assembly
    Note
    4x clips, 1x connector, Frunk safety switch, 3x guide tabs, Grab closeout panel from bottom then pull it upward to release clips, Disconnect the switch
  25. Remove bolts securing frunk assembly
    Note
    7x bolts, 10mm, 5 Nm, Lift up RBN covers to access upper fasteners, Newer vehicles may not be equipped with covers
  26. Remove frunk assembly from vehicle
    Note
    12x clips, Replace any clips if broken or missing, Number of clips may vary on older vehicles
  27. Remove vent tube hose from LH side of 12V battery
    Note
    1x tube adapter
  28. Release terminal cover and remove positive terminal
    Note
    2x clips, 1x nut, 10mm, 6 Nm, Do not fully remove positive terminal nut
  29. Remove bolt securing 12V battery upper tie down strap to AC compressor bracket
    Note
    1x bolt, 10mm, 5 Nm
  30. Remove battery upper tie down strap
    Note
    Lift battery tie down strap up and remove it from the rear tie down hook strap
  31. Remove 12V battery from vehicle
  32. Remove bolt securing the steering gear assembly to intermediate shaft assembly
    Note
    1x bolt, 13mm, 18 Nm
  33. Slide the electric steering column upward to remove it from the steering gear assembly
    Note
    May need to wiggle or use dead blow to help separate
  34. Disconnect the hydraulic control unit connector
    Note
    1x connector, Disengage locking tab and pull up on connector to release
  35. Remove fasteners securing hydraulic control unit to hydraulic control unit bracket
    Note
    2x nuts, 10mm, 8 Nm, Discard nuts after removal
  36. Disconnect harness from LH front rail bracket
    Note
    1x connector, Red locking tab, Release lock from opposite side of bracket then release connector towards front of vehicle, Image zoomed in for clarity
  37. Release clips securing front harness and coolant hose from brackets
    Note
    2x clips
  38. Release front harness clip from LH frame rail
    Note
    1x clip
  39. Disconnect the steering gear assembly connectors
    Note
    2x connectors, Two stage connectors, Move the red locking tab to the left then depress the connector release to disconnect the connector
  40. Disconnect the logic connectors from steering gear
    Note
    2x connectors, Do not push down on red tab, Pull red tab to disengage lock, Pull again to release connector, Image zoomed out for location reference
  41. Disconnect the HVIL connector
    Note
    1x locking connector, Do not push down on red tab, Pull red tab to disengage lock, Pull tab again to release connector
  42. Release clip securing HVIL connector harness onto body
    Note
    1x clip
  43. Disconnect LH front headlamp
    Note
    1x connector, Pull tab to disengage lock mechanism, Pull again to release connector, Do not press down on tab, Connector style may vary
  44. Remove grounds G098 and G099 from LH side of body
    Note
    2x bolts, 10mm, 10 Nm, Discard thread-cutting tri-lobular bolts after removal, If equipped with new bolts (1447438-00-A), fasteners can be reused
  45. Remove grounds G011 and G013 from LH frame rail
    Note
    2x bolts, 10mm, 10 Nm, Discard thread-cutting tri-lobular bolts after removal, If equipped with new bolts (1447438-00-A), fasteners can be reused
  46. Release front harness clips from LH frame rail
    Note
    3x clips
  47. Remove the inner bolts that attach the shock tower brace to the RH shock tower.
  48. Remove the outer bolt that attaches the shock tower brace to the RH shock tower.
  49. Remove the inner bolts that attach the shock tower brace to the LH shock tower.
  50. Remove the outer bolt that attaches the shock tower brace to the LH shock tower.
  51. Shift shock tower brace assembly to gain clearance
    Note
    Shift shock tower brace forward, but do not fully remove
  52. Release the master cylinder brake lines from clip at rear of hydraulic control unit bracket
    Note
    1x harness clip
  53. Raise vehicle fully and lower lift onto locks
    Note
    Set vehicle to comfortable working height, Make sure there's an audible click of the locks on both sides before lowering, otherwise vehicle may tilt to the side, Verify doors are clear of surrounding objects
  54. Remove outer fasteners securing front aero shield
    Note
    9x bolts, 10mm, 5 Nm
  55. Remove remaining nuts and remove front aero shield from vehicle
    Note
    2x nuts, 15mm, 5 Nm
  56. Remove bolt securing FDU HV harness to the FDU
    Note
    1x bolt, 10mm, 10 Nm
  57. Disconnect the FDU HV harness connector
    Note
    1x clip, Release locking tab and rotate the release lever up to disengage the connector, Do not force the release lever up, Ensure the alignment tabs on the FDU header are not damaged
  58. Remove the FDU HV harness connector from the FDU and move aside
    Note
    1x connector
  59. Slide intermediate shaft towards rear of vehicle
  60. Release front harness clips from hydraulic control unit bracket
    Note
    2x clips
  61. Lower front harness away from hydraulic control unit
    Note
    Lower front harness to gain enough clearance to hydraulic control unit
  62. Remove lower bolt securing the hydraulic control unit bracket to frame rail
    Note
    1x bolt, 10mm, 10 Nm
  63. Lower vehicle partially and set lift onto locks
    Note
    Raise lift off locks, then hold lock release lever to keep locks free while vehicle is lowered, Set vehicle to comfortable working height
  64. Remove upper bolt securing the hydraulic control unit bracket to frame rail
    Note
    1x bolt, 10mm, 10 Nm
  65. Release hydraulic control unit bracket from hydraulic control unit
    Note
    Slide trim tool between hydraulic control unit bracket and hydraulic control unit and use for leverage, Position 20 in clip panel tool between trim tool and hydraulic control unit and gently pry to release bracket, Release bracket far enough to access hydraulic control unit ECU bolts
  66. Remove upper bolts securing hydraulic control unit ECU to hydraulic control unit
    Note
    2x bolts, E5, 3 Nm, Discard bolts after removal
  67. Remove lower bolts securing hydraulic control unit ECU to hydraulic control unit
    Note
    2x bolts, E5, 3 Nm, Discard nuts after removal
  68. Remove hydraulic control unit ECU from hydraulic control unit
    Note
    Gently release ECU towards rear of vehicle, Do not use any tools to pry the ECU away from the hydraulic control unit

Install

  1. Clean surface on hydraulic control unit
    Note
    Use a lint free cloth to clean any debris from hydraulic control unit, Do not use any chemicals, Do not allow any debris to fall into connecting hole of pump motor, Do not touch pressure sensor with fingers
  2. Install hydraulic control unit ECU into hydraulic control unit
    Note
    Align pump motor on ECU with connecting hole on hydraulic control unit
  3. Install upper right bolt securing hydraulic control unit ECU to hydraulic control unit hand tight
    Note
    1x bolt, E5, 3 Nm, Install new bolt, Hydraulic control unit bolts must be installed in sequence, Torque at later step,
  4. Install lower left bolt securing hydraulic control unit ECU to hydraulic control unit hand tight
    Note
    1x bolt, E5, 3 Nm, Install new bolt, Hydraulic control unit bolts must be installed in sequence, Torque at later step
  5. Install upper left bolt securing hydraulic control unit ECU to hydraulic control unit hand tight
    Note
    1x bolt, E5, 3 Nm, Install new bolt, Hydraulic control unit bolts must be installed in sequence, Torque at later step
  6. Install lower right bolt securing hydraulic control unit ECU to hydraulic control unit hand tight
    Note
    1x bolt, E5, 3 Nm, Install new bolt, Hydraulic control unit bolts must be installed in sequence, Torque at later step
  7. Torque upper right bolt securing hydraulic control unit ECU to hydraulic control unit
    Note
    1x bolt, E5, 3 Nm, Hydraulic control unit bolts must be torqued in sequence
  8. Torque lower left bolt securing hydraulic control unit ECU to hydraulic control unit
    Note
    1x bolt, E5, 3 Nm, Hydraulic control unit bolts must be torqued in sequence
  9. Torque upper left bolt securing hydraulic control unit ECU to hydraulic control unit
    Note
    1x bolt, E5, 3 Nm, Hydraulic control unit bolts must be torqued in sequence
  10. Torque lower right bolt securing hydraulic control unit ECU to hydraulic control unit
    Note
    1x bolt, E5, 3 Nm, Hydraulic control unit bolts must be torqued in sequence
  11. Install hydraulic control unit bracket to hydraulic control unit
    Note
    Support HCU while installing bracket, Avoid bending or damaging brake lines
  12. Install upper bolt securing the hydraulic control unit bracket to frame rail
    Note
    1x bolt, 10mm, 10 Nm
  13. Raise vehicle fully and lower lift onto locks
    Note
    Set vehicle to comfortable working height, Make sure there's an audible click of the locks on both sides before lowering, otherwise vehicle may tilt to the side
  14. Install lower bolt securing the hydraulic control unit bracket to frame rail
    Note
    1x bolt, 10mm, 10 Nm
  15. Raise front harness into position for installation
  16. Install clips securing front harness to hydraulic control unit bracket
    Note
    2x clips
  17. Slide intermediate shaft towards front of vehicle
  18. Install FDU HV harness connector to FDU
    Note
    1x connector, Ensure the connector is installed far enough on the FDU manifold so the manifold alignment tooth is making contact with the connector lever
  19. Secure FDU HV harness connection to FDU
    Note
    1x locking connector, Verify lever is in the upright and open position, Carefully seat connector and allow lever to engage, Fully secure lever and engage red locking tab, Do not damage connector or header
  20. Install bolt securing FDU HV harness to FDU
    Note
    1x bolt, 10mm, 10 Nm
  21. Position front aero shield to vehicle and install nuts
    Note
    2x nuts, 15mm, 5 Nm
  22. Apply Loctite 222 onto front aero shield bolts and install outer fasteners to front aero shield
    Note
    9x bolts, 10mm, 5 Nm
  23. Lower vehicle fully
    Note
    Raise lift off locks, then hold lock release lever to keep locks free while vehicle is lowered
  24. Install the fasteners securing the hydraulic control unit to the hydraulic control unit bracket
    Note
    2x nuts, 10mm, 8 Nm
  25. Position the master cylinder brake lines to clip at rear of hydraulic control unit bracket
    Note
    1x harness clip
  26. Connect the hydraulic control unit connector
    Note
    1x connector, Gently push connector downward, Engage locking tab
  27. Slide the intermediate shaft assembly downward to install it to the steering gear assembly
    Note
    Ensure the intermediate shaft is aligned and fully seated, if necessary to align the shaft to steering gear
  28. Install bolt securing the intermediate shaft assembly to the steering gear assembly
    Note
    1x bolt, 13mm, 18 Nm
  29. Secure front harness clips to LH frame rail
    Note
    3x clips
  30. Connect LH front headlamp
    Note
    1x connector, Engage locking tab, Connector style may vary
  31. Install clip securing HVIL connector harness onto body
    Note
    1x clip
  32. Connect the HVIL connector
    Note
    1x locking connector, Engage locking tab
  33. Install grounds G011 and G013 to LH frame rail
    Note
    2x bolts, 10mm, 10 Nm, Discard thread-cutting tri-lobular bolts after removal, If equipped with new bolts (1447438-00-A), fasteners can be reused
  34. Resecure grounds G098 and G099 to the body
    Note
    2x bolts, 10mm, 10 Nm, Install new bolts if thread-cutting tri-lobular bolts were installed previously, Hand-start bolts at least 6 rotations before applying torque to avoid damaging the weld nut
  35. Connect the logic connectors on steering gear
    Note
    2x connectors, Engage locking tabs
  36. Connect the steering gear assembly connectors
    Note
    2x connectors, Engage locking tabs
  37. Install clip securing front harness bracket to LH frame rail
    Note
    1x clip
  38. Connect harness located at LH front rail bracket
    Note
    1x connector, Red locking tab, Connect from front of bracket and lock from opposite side of bracket, Image zoomed in for clarity
  39. Install clips securing front harness and coolant hose onto brackets
    Note
    2x clips
  40. Position shock tower brace assembly back for installation
  41. Install the outer bolt that attaches the shock tower brace to the LH shock tower.
    62 Nm (45.7 lbs-ft)
  42. Install the inner bolts (x2) that attach the shock tower brace to the LH shock tower.
    55 Nm (40.6 lbs-ft)
  43. Tighten the outer bolt that attaches the shock tower brace to the RH shock tower.
    62 Nm (45.7 lbs-ft)
  44. Tighten the inner bolts (x2) that attach the shock tower brace to the RH shock tower.
    55 Nm (40.6 lbs-ft)
  45. Install 12V battery into vehicle
  46. Position battery tie down strap onto the battery
    Note
    Hook the upper tie down strap into the rear tie down hook strap and position for installation
  47. Install bolt securing upper tie down strap to the AC compressor bracket
    Note
    1x bolt, 10mm, 5 Nm
  48. Install vent tube hose in 12V battery
  49. Install positive terminal and terminal cover
    Note
    1x nut, 10mm, 6 Nm, 2x clips
  50. Install frunk assembly to vehicle
    Note
    12x clips, Make sure frunk assembly is fully seated onto clips, Number of clips may vary on older vehicles
  51. Install bolts securing frunk assembly
    Note
    7x bolts, 10mm, 5 Nm, Lower RBN covers after installing upper fasteners, Newer vehicles may not be equipped with covers
  52. Install frunk close out panel
    Note
    4x clips, 1x connector, Frunk safety switch, 3x guide tabs, Align 3x tabs then push downward to secure clips
  53. Install cabin intake upper duct assembly
    Note
    4x clips, Heat pump vehicles have 3x clips
  54. Connect first responder loop
    Note
    1x connector, Engage locking tab, Connect FRL before connecting 12V to avoid damage to car computer
  55. Connect 12V negative terminal
    Note
    1x nut, 10mm, 6 Nm
  56. Install rear apron
    Note
    12x clips
  57. Close hood
  58. Remove the steering wheel holder
  59. Move LH front seat forward
  60. Connect 2nd row seat cushion harness and install 2nd row seat cushion
    Note
    2x connectors, Both connectors are located on LH side of vehicle, Insert the seat belt buckles through the holes, Slide rear cushion inward then align front guide tabs to locking tabs, Make sure cushion is fully seated with push & pull test near clips
  61. Move RH front seat to original position
  62. Move LH front seat to original position
  63. Reinstall the vehicle software. See Software Reinstall - Touchscreen.
  64. Raise all windows
  65. Close all four doors
    Note
    Unlatch rear doors before closing
