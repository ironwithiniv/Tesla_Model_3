Panel - Aero Shield - Rear (Remove and Replace)

Correction code 12030502 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2024-01-04: Updated consumables information.
Parent topic: 1203 - Undertray and Diffuser

Torque Specifications

Table 1. Torque Specifications: Panel - Aero Shield - Rear (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolt that attaches the rear aero shield panel to the vehicle
5.5 Nm (4.1 lbs-ft)
  • 10 mm socket
 Reuse
Note
Apply threadlocker to the threads of each bolt prior to installation.

Remove

  1. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  2. Remove the bolts (x13) that attach the rear aero shield panel to the vehicle, and then remove the panel from the vehicle.
  3. Inspect the HV battery vent assemblies at the rear of the HV battery for the presence of breathers.
  4. If any breathers are missing, install them now. See Breathers - HV Battery (Remove and Replace).
    Note
    After installing the breather(s), if necessary, return to the procedure that required removal of the rear aero shield panel.

Install

  1. Apply a thin bead of threadlocker to the threads of the bolts that attach the rear aero shield panel to the vehicle.
  2. Install the rear aero shield panel to the underside of the vehicle, and then install the bolts that attach the panel to the vehicle.
    5.5 Nm (4.1 lbs-ft)
  3. Lower the vehicle. See Raise Vehicle - 2 Post Lift.
