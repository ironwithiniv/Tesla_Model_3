HV Battery (1-Phase to 3-Phase) (Retrofit) (Battery On Table)

Correction code 16010206 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Note
This procedure is to be performed if the HV battery has been removed and components must be reworked or swapped between old and new HV batteries. Add this correction code as a separate activity.
Warning
Remove all jewelry (watches, bracelets, rings, necklaces, earrings, ID tags, piercings, etc.) from your person, and all objects (keys, coins, pens, pencils, tools, fasteners, etc.) from your pockets before performing any procedure that exposes you to high voltage.
Warning
If corrective eyewear is necessary to safely perform any procedure, make sure that the eyewear is securely restrained to the head and cannot fall off.
Warning

Only technicians who have completed all required certification courses are permitted to perform this procedure. Tesla recommends third party service provider technicians undergo equivalent training before performing this procedure. For more information on Tesla Technician requirements, or descriptions of the subject matter for third parties, see HV Certification Requirements. Proper personal protective equipment (PPE) and insulating HV gloves with a minimum rating of class 0 (1000V) must be worn at all times a high voltage cable, busbar, or fitting is handled. Refer to Tech Note TN-15-92-003, High Voltage Awareness Care Points for additional safety information.

Parent topic: HV Battery Replacement - Add-On Procedures

Procedure

  1. Remove the 3-Phase Power Conversion System from the old HV battery. See Power Conversion System (Remove and Replace).
  2. Remove the 1-Phase Power Conversion System from the new HV battery. See Power Conversion System (Remove and Replace).
  3. Remove the 1-Phase AC Inlet Harness from the new HV battery. See Harness - AC Inlet - HV Battery (Remove and Replace).
  4. Install and hand tighten the bolts (x2) for the pyrotechnic battery disconnect into the ancillary bay of the old HV battery.
    Note
    Do not install the pyrotechnic battery disconnect. Only install the bolts.
  5. Install the pyrotechnic battery disconnect insulators onto the bolts of the pyrotechnic disconnect.
  6. Install the 3-Phase Power Conversion System from the old HV Battery into the new HV battery. See Power Conversion System (Remove and Replace).
  7. Install a new 3-Phase AC Inlet Harness into the new HV battery. See Harness - AC Inlet - HV Battery (Remove and Replace).
  8. Install the ancillary bay cover from the old HV Battery onto the new HV battery. See Cover - Ancillary Bay (Remove and Replace).
  9. Install the ancillary bay cover from the new HV Battery onto the old HV battery. See Cover - Ancillary Bay (Remove and Replace).
  10. Perform an ancillary bay air leak test. See Ancillary Bay Air Leak Test (Inspection).
