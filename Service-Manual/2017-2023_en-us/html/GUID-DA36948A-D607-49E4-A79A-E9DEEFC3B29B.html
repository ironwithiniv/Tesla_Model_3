Hose - Front Manifold - LH (Remove and Replace)

Correction code 18309302 0.78 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1830 - Cooling System

Remove

  1. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  2. Open the LH front door and lower the LH front window.
  3. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  4. Remove the cabin intake upper duct assembly. See Duct - Upper - Cabin Intake (Remove and Replace).
  5. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  6. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  7. Remove the front HV battery skid plate. See Skid Plate - HV Battery - Front (Remove and Replace).
  8. Remove the push clip that attaches the LH front wheel liner to LH rocker panel.
  9. Position a coolant the drain container underneath the LH front of the HV battery.
  10. Release the spring clip, disconnect the LH front manifold hose from the LH front of the HV battery, and then plug the HV battery fitting.
  11. Position the coolant drain container below the HV battery hose.
  12. Release the clip that attaches the front HV battery hose to the body.
  13. Release the spring clip, disconnect the front HV battery hose from the LH front manifold tube, and then plug the HV battery fitting.
  14. Release the spring clip, disconnect the LH front manifold hose from the front of the HV battery, and then plug the HV battery fitting.
  15. Release the spring clip, disconnect the LH front manifold hose from the RH manifold tube, and then plug the RH manifold tube.

Install

  1. Remove the hose plug, connect the LH front manifold hose to the RH manifold tube, and then install the spring clip.
    Note
    Perform a push-pull-push test to make sure the hose is fully seated.
  2. Remove the hose plug, connect the LH front manifold hose to the front of the HV battery, and then install the spring clip.
    Note
    Perform a push-pull-push test to make sure the hose is fully seated.
  3. Remove the hose plug, connect the LH front manifold hose to the front of the HV battery hose, and then install the spring clip.
    Note
    Perform a push-pull-push test to make sure the hose is fully seated.
  4. Install the clip that attaches the front HV battery hose to the body.
  5. Position a coolant the drain container underneath the LH front of the HV battery.
  6. Remove the hose plug, connect the LH front manifold hose to the LH front of the HV battery, and then install the spring clip.
    Note
    Perform a push-pull-push test to make sure the hose is fully seated.
  7. Remove the coolant drain container from underneath the vehicle.
  8. Install the that attaches the LH front wheel liner to the LH front rocker panel.
  9. Install the front HV battery skid plate. See Skid Plate - HV Battery - Front (Remove and Replace).
  10. Install the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  11. Remove the coolant bottle cap.
  12. Inspect the coolant level and top off as necessary.
    Note
    Make sure the fluid level is at the "Max" line.
  13. Connect 12V power. See 12V/LV Power (Disconnect and Connect).
  14. Connect a laptop with Toolbox 3.0 to the vehicle.
  15. Click the Actions/Autodiag tab, and then search for "Purge".
  16. Click TEST_VCFRONT_X_THERMAL-COOLANT-AIR-PURGEvia Service Mode:
    • Thermal ➜ Actions ➜ Coolant Purge Stop or Coolant Purge Start
    • Thermal ➜ Coolant System ➜ Coolant Purge Start
    via Service Mode Plus:
    • Drive Inverter ➜ Front Drive Inverter Replacement ➜ Coolant Air Purge
    • Drive Inverter ➜ Rear Drive Inverter Replacement ➜ Coolant Air Purge
    • Drive Inverter ➜ Rear Left Drive Inverter Replacement ➜ Coolant Air Purge
    • Drive Inverter ➜ Rear Right Drive Inverter Replacement ➜ Coolant Air Purge
    • Drive Unit ➜ Front Drive Unit Replacement ➜ Coolant Air Purge
    • Drive Unit ➜ Rear Drive Unit Replacement ➜ Coolant Air Purge
    via Toolbox:(link)    , click Run, and allow the routine to complete.
    Note
    Select the "X" at the top right of the window to close once the routine is complete.
  17. Disconnect Toolbox and remove the laptop from the vehicle.
  18. Inspect the coolant level and top off as necessary.
    Note
    Make sure the fluid level is at the "Max" line.
  19. Install the coolant bottle cap.
  20. Install the cabin intake upper duct assembly. See Duct - Upper - Cabin Intake (Remove and Replace).
  21. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  22. Raise the LH front window and close the LH front door.
  23. Remove the vehicle from the lift. See Raise Vehicle - 2 Post Lift.
