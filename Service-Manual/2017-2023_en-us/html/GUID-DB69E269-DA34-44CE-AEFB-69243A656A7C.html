Parent topic: 4401 - Charge System Inlet

Remove

  1. Remove the charge port. See Charge Port (GB) (Remove and Replace).
    Note
    During removal, certain steps require extra care. See the animation(s) for detailed guidance.
  2. Pull and hold the manual release cable to release the actuator.
  3. Remove the screws (x2) that attach the actuator to the charge port assembly.
    Note
    Newer vehicle is equipped with T20 tamper proo.
    Tip
    Use of the following tool(s) is recommended:
    • Mini Ratchet Bit Set - 1450424-00-A
  4. Remove the actuator from the charge port assembly.
    Note
    Turn over 30 degrees and then take out the actuator.
  5. Remove and discard the DC charge port latch stick o-ring from the charge port assembly.
  6. Rotate to remove the AC charge port latch stick from the actuator.

Install

  1. Apply efficient amount of lubricant to lubricate the AC latch stick and the o-ring.
  2. Rotate to install the AC latch stick to the actuator.
  3. Install the DC latch stick o-ring to the charge port assembly.
    Note
    Do not damage the o-ring.
  4. Position the actuator to the charge port assembly.
    Note
    Gently push the actuator. Make sure there is no gap between the actuator and the charge port.
  5. Install the screws (x2) that attach the actuator to the charge port assembly.
    3.3 Nm (2.4 lbs-ft)
    Note
    Newer vehicle is equipped with T20 tamper proo.
    Tip
    Use of the following tool(s) is recommended:
    • Mini Ratchet Bit Set - 1450424-00-A
  6. Install the charge port. See Charge Port (GB) (Remove and Replace).
