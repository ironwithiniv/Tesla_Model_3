Filler Neck - Reservoir - Windshield Washer (RHD) (Remove and Replace)

Correction code 17503102 0.06 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1750 - Wipers and Washers

Remove

  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Remove the bolt that attaches the filler neck to the underhood storage unit.
    5 Nm (3.7 lbs-ft)
  3. Release the clip that attaches the electrical harness to the filler neck.
  4. Pull the filler neck directly away from the windshield washer reservoir to remove it.

Install

Installation procedure is the reverse of removal, except for the following:

  • Ensure the new filler neck is equipped with an O-ring. If an O-ring is not installed, install one.
