Splash Guard - LH (Remove and Replace)

Correction code 12208102 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  1. Turn the steering wheel fully to the left to provide access to the working area.
  2. Remove the screws and washers (1st generation kits) or push clips (2nd generation kits) that attach the splash guard to the wheel arch liner.
  3. Remove the bolt that attaches the bottom of the mud flap to the lower rocker panel cover.
  4. Remove the splash guard and mud flap assembly from the vehicle.
  5. Pull the splash guard away from the mud flap to release the adhesive tape.
  6. Clean the mud flap with an alcohol wipe and allow to fully dry.
Parent topic: 1220 - Exterior Trim

Install

  1. Secure the new LH splash guard to the LH mud flap:
    1. Remove the adhesive backing from the new splash guard.
    2. Align the splash guard with the mud flap so that the holes are aligned.
    3. Apply pressure along the mud flap to ensure it is adhered to the splash guard.
  2. Install the LH splash guard and mud flap as an assembly (1st GENERATION KITS):
    1. Place washers over the screws, then install the screws and washers that secure the splash guard to the U-nuts in the front LH wheel arch liner.
      1.5 Nm (1.1 lbs-ft)
    2. Install the bolt that attaches the bottom of the mud flap to the lower rocker panel cover.
      5 Nm (3.7 lbs-ft)
  3. Install the LH splash guard and mud flap as an assembly (2nd GENERATION KITS):
    1. Align the holes in the mud flap/splash guard to the holes in the front wheel arch liner, and then insert the opened (plastic rivet pulled out) push clips into the holes. Once the push clips are fully inserted, push the plastic rivets in to close the push clips and lock the mud flap/splash guard in place.
    2. Install the bolt that attaches the bottom of the mud flap to the lower rocker panel cover.
      5 Nm (3.7 lbs-ft)
  4. Ensure the splash guard is aligned with the body. Make adjustments as necessary.
