Bracket - 12V Battery (RWD) (Remove and Replace)

Correction code 17014002 0.54 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-04-28: Corrected torque figures for the bolts that attach the shock tower brace to the vehicle.
Parent topic: 1701 - 12V Battery and Fuses

Remove

  1. Remove the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Remove the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  4. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  5. Remove the LH and RH wiper arms. See Wiper Arms (Remove and Replace).
  6. Remove the LH and RH shock tower covers. See Cover - Shock Tower - LH (Remove and Replace).
  7. Remove the cowl screen panel. See Panel - Cowl Screen (Remove and Replace).
  8. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  9. Remove the 12V auxiliary battery. See 12V/LV Battery (Remove and Replace).
  10. Remove the bolt that attaches the 12V battery rear hook tie down to the body, and then remove the tie down from the body.
  11. Remove the nuts (x2) that attach the superbottle to the thermal beam.
  12. Release the clip that attaches the coolant hose to the battery bracket.
  13. Release the clip that attaches the 12V battery vent hose to the 12V battery bracket.
  14. Remove the upper bolts (x2) that attach the battery bracket to the shock tower brace, and the lower bolts (x2) that attach the battery bracket to the battery beam.
    Note
    Reach through under the superbottle to gain access to the underside of the battery beam and the lower bolts.
  15. Loosen the inner bolts that attach the shock tower brace to the RH shock tower.
  16. Loosen the outer bolt that attaches the shock tower brace to the RH shock tower.
  17. Remove the inner bolts that attach the shock tower brace to the LH shock tower.
  18. Remove the outer bolt that attaches the shock tower brace to the LH shock tower.
  19. Shift the LH side of the shock tower brace forward to increase working space, and then remove the battery bracket from the vehicle.
  20. Remove and discard the nut that attaches the 12V battery tie down bracket to the battery bracket, and then remove the tie down bracket from the battery bracket.
  21. Remove and discard the nut that attaches the front hook to the battery bracket, and then remove the front hook from the battery bracket.

Install

  1. Install the front hook onto the battery bracket, and then install a new nut to attach the front hook to the battery bracket.
    9 Nm (6.6 lbs-ft)
  2. Install the tie down bracket onto the battery bracket, and then install a new nut to attach the tie down bracket to the battery bracket.
    9 Nm (6.6 lbs-ft)
  3. Install the battery bracket to the shock tower brace and battery beam, and then shift the LH side of the shock tower brace rearward so that the bolt holes in the brace and shock tower align..
  4. Install the outer bolt that attaches the shock tower brace to the LH shock tower.
    62 Nm (45.7 lbs-ft)
  5. Install the inner bolts (x2) that attach the shock tower brace to the LH shock tower.
    55 Nm (40.6 lbs-ft)
  6. Install the outer bolt that attaches the shock tower brace to the RH shock tower.
    62 Nm (45.7 lbs-ft)
  7. Install the inner bolts (x2) that attach the shock tower brace to the RH shock tower.
    55 Nm (40.6 lbs-ft)
  8. Install the upper bolts (x2) that attach the battery bracket to the shock tower brace, and the lower bolts (x2) that attach the battery bracket to the battery beam.
    15 Nm (11.1 lbs-ft)
    9 Nm (6.6 lbs-ft)
    Note
    Reach through under the superbottle to gain access to the underside of the battery beam and the lower bolts.
  9. Fasten the clip that attaches the 12V battery vent hose to the 12V battery bracket.
  10. Fasten the clip that attaches the coolant hose to the battery bracket.
  11. Install the nuts (x2) that attach the superbottle to the thermal beam.
    8 Nm (5.9 lbs-ft)
  12. Install the 12V battery rear hook tie down to the body, and then install the bolt that attaches the tie down to the body.
    9 Nm (6.6 lbs-ft)
  13. Install the 12V auxiliary battery. See 12V/LV Battery (Remove and Replace).
  14. Connect 12V power. See 12V/LV Power (Disconnect and Connect).
  15. Install the cowl screen panel. See Panel - Cowl Screen (Remove and Replace).
  16. Install the LH and RH shock tower covers. See Cover - Shock Tower - LH (Remove and Replace).
  17. Install the LH and RH wiper arms. See Wiper Arms (Remove and Replace).
  18. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  19. Install the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  20. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  21. Install the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
