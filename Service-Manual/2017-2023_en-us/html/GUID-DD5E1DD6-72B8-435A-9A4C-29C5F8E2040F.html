Harness - Headliner (Remove and Replace)

Correction code 17102502 0.96 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1710 - Harnesses

Remove

  1. Remove the headliner. See Headliner (Non-Heat Pump) (Remove and Install).
  2. Disconnect the electrical harness from the LH headliner tweeter connector.
  3. Disconnect the electrical harness from the front overhead console connector.
  4. Disconnect the electrical harness from the RH headliner tweeter connector.
  5. Disconnect the electrical harness from the rear overhead console connector.
  6. Separate the glue attaching points (x6) that attach the headliner harness to the headliner.
  7. Release the clips that attach the headliner harness to the headliner, and then remove the harness from the headliner.

Install

Installation procedure is the reverse of removal, except for the following:

  • Use a glue gun to attach the headliner harness to the headliner. Allow time for the glue to set.
