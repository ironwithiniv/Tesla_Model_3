Trim - Package Tray (Remove and Replace)

Correction code 15243002 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2023-10-26: Added "number of clips vary on newer vehicles" that attach the package trim to the vehicle.
Parent topic: 1524 - Luggage Compartment Trim

Remove

  1. Move the driver seat and the front passenger seat fully forward.
    Note
    Note the position of the driver seat and the front passenger seat prior to movement so that both seats are restored to their original position during installation.
  2. Remove the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  3. Remove the LH side rail trim. See Trim - Side Rail - LH (Remove and Replace).
  4. Remove the LH upper C-pillar trim. See Trim - C-Pillar - Upper - LH (Remove and Replace).
  5. Remove the LH rear C-pillar trim. See Trim - C-Pillar - Rear - LH (Remove and Replace).
  6. Remove the RH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  7. Remove the RH side rail trim. See Trim - Side Rail - LH (Remove and Install).
  8. Remove the RH upper C-pillar trim. See Trim - C-Pillar - Upper - LH (Remove and Replace).
  9. Remove the RH rear C-pillar trim. See Trim - C-Pillar - Rear - LH (Remove and Replace).
  10. Release the clips that attach the package tray wiring harness to the C-pillar.
  11. Disconnect the package tray harness connector from the RH body electrical harness.
  12. Release the clip that attaches the speaker wiring harness to the tuner.
  13. Disconnect the speaker harness connector from the tuner.
  14. Release the clip that attaches the antenna amplifier wiring harness to the body.
  15. Disconnect the electrical connector from the antenna amplifier.
  16. Release the clips (x2 or x4) that attach the package tray trim to the body.
    Note
    Number of clips vary on newer vehicles.
  17. Release the tabs that attach the package tray trim to the body, and then slide the package tray forward to remove it from the vehicle.

Install

  1. Install the package tray trim to the vehicle.
    Note
    Slide the package tray rearwards to install it to the vehicle, and then attach the package tray to the body with tabs.
  2. Install the clips that attach the package tray trim to the body.
  3. Connect the electrical connector to the antenna amplifier.
  4. Install the clip that attaches the antenna amplifier wiring harness to the body.
  5. Connect the speaker harness connector to the tuner.
  6. Install the clip that attaches the speaker wiring harness to the tuner.
  7. Connect the package tray harness connector to the RH body electrical harness.
  8. Install the clips that attach the package tray wiring harness to the C-pillar.
  9. Install the RH rear C-pillar trim. See Trim - C-Pillar - Rear - LH (Remove and Replace).
  10. Install the RH upper C-pillar trim. See Trim - C-Pillar - Upper - LH (Remove and Replace).
  11. Install the RH side rail trim. See Trim - Side Rail - LH (Remove and Install).
  12. Install the RH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  13. Install the LH rear C-pillar trim. See Trim - C-Pillar - Rear - LH (Remove and Replace).
  14. Install the LH upper C-pillar trim. See Trim - C-Pillar - Upper - LH (Remove and Replace).
  15. Install the LH side rail trim. See Trim - Side Rail - LH (Remove and Replace).
  16. Install the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  17. Move the driver seat and the front passenger seat to their original position.
