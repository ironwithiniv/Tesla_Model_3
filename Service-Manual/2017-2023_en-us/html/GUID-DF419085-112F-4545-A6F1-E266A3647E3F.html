Bushing Bracket - Stabilizer Bar - Front - LH (Remove and Replace)

Correction code 31016102 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-09-01: Removed the steps to remove/install the nut that attaches the LH front stabilizer bar to the bar link.
  • 2025-11-10: An inflatable bag is installed between the front stabilizer bar and front valance for sufficient working space, replacing the need to fully remove the front valance.
  • 2025-08-28: Added the torque table and the consumable parts information.
Parent topic: 3101 - Front Suspension (Including Hubs)

Torque Specifications

Table 1. Torque Specifications: Bushing Bracket - Stabilizer Bar - Front - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Nuts that attach the front stabilizer bar to the front subframe
35 Nm (25.8 lbs-ft)
  • 15 mm deep socket
Replace 1111145-00-A

Remove

  1. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  2. Release the clips (x2) that attach the valance to the stabilizer bar brackets.
  3. Remove the push clips (x4) that attach the LH and RH sides of the valance to the wheel liners.
    Note
    Remove the outer clips as necessary to allow for easier access to the nuts behind the wheel liner.
  4. Install an inflatable bag vertically between the front stabilizer bar and front valance to ensure sufficient working space.
  5. Remove and discard the nuts (x2) that attach the LH front stabilizer bar to the front subframe.
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm deep socket
  6. Remove the bracket from the front stabilizer bar bushing.
    Note
    Carefully remove the bracket with a flat head screwdriver, taking care not to damage the stabilizer bar bushing.

Replace

  1. Install the bracket to the front stabilizer bar bushing.
    Note
    Make sure to fit the bracket onto the bushing, apply lubricant for better installation.
  2. Install new nuts (x2) to attach the stabilizer bar to the subframe, and then mark the nuts with a paint pen after they are torqued.
    35 Nm (25.8 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm deep socket
  3. Remove the inflatable bag.
  4. Install the push clips (x4) that attach the LH and RH sides of the valance to the wheel liners.
    Note
    Install the outer clips if removed earlier.
  5. Fasten the clips (x2) that attach the valance to the stabilizer bar brackets.
  6. Install the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
