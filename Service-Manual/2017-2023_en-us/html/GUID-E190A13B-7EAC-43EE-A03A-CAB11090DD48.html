Remove and Clean Radiator (Heat Pump) (Maintenance)

Correction code 18301200 1.14 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
  • 2026-09-16: Added Caution to emphasize necessity of coolant vacuum refilling during cooling fan module installation.
  • 2026-08-11: Added routine: PROC_VC_X_RESET-RADIATOR-UA-INDEX.
  • 2026-04-21: Released new procedure.
  1. Open LH front door and lower the LH front window.
  2. Raise and support the vehicle.
  3. Remove the radiator. See Radiator (Heat Pump) (Remove and Replace).
  4. Use a vacuum to clean debris from both sides of the radiator.
    Note
    Do not damage fins of radiator
  5. Use a blow gun to clean both sides of the radiator with compressed air.
    Note
    Do not damage fins of radiator.
  6. Install the radiator. See Radiator (Heat Pump) (Remove and Replace).
    CAUTION
    Make sure that the coolant vacuum refill procedure is performed during installation of the cooling fan module assembly.
  7. Connect a laptop with Toolbox 3 to the vehicle. See Toolbox (Connect and Disconnect).
  8. Run the routine: PROC_VC_X_RESET-RADIATOR-UA-INDEXvia Toolbox:(link)
    Note
    Perform this step for firmware versions develop/2026.14.3 and later.
  9. Run the routine using Service Mode or Toolbox: TEST-SELF_VCFRONT_X_THERMAL-PERFORMANCEvia Service Mode:Thermal ➜ Actions ➜ Test Thermal Performancevia Service Mode Plus:
    • Drive Inverter ➜ Front Drive Inverter Replacement ➜ Thermal System Test
    • Drive Inverter ➜ Rear Drive Inverter Replacement ➜ Thermal System Test
    • Drive Inverter ➜ Rear Left Drive Inverter Replacement ➜ Thermal System Test
    • Drive Inverter ➜ Rear Right Drive Inverter Replacement ➜ Thermal System Test
    • Drive Unit ➜ Front Drive Unit Replacement ➜ Thermal System Test
    • Drive Unit ➜ Rear Drive Unit Replacement ➜ Thermal System Test
    via Toolbox:(link)
  10. Disconnect Toolbox and remove the laptop from the vehicle.
  11. Exit Service Mode Plus. See Service Mode Plus.
  12. Raise the LH front window and close the LH front door.
  13. Remove the vehicle from the lift.
