Trim - Headrest - Driver (Remove and Replace)

Correction code 13042002 0.06 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1132841-00-A M3 1R Headrest Removal Tool
Parent topic: 1304 - Front Seat Assemblies and Hardware

Remove

  1. Partially recline the driver seatback to provide more working room.
  2. Depress the material on the LH side of the outboard headrest post to expose the retaining spring that restrains the post into the driver seatback.
  3. With the headrest removal tool handle horizontal and the tool tabs pointing down, insert the tabs into the LH side of the outboard headrest post.
    Note
    The shaft of the tool points to the rear of the vehicle.
  4. Press the headrest removal tool in and down, rotate the tool handle clockwise to vertical to release the spring from the headrest post, and then leave the tool attached.
  5. Depress the material on the LH side of the inboard headrest post (under the headrest) to expose the retaining spring that restrains the post into the driver seatback.
  6. With the second headrest removal tool handle horizontal and the tool tabs pointing down, insert the tabs into the LH side of the inboard headrest post.
    Note
    The shaft of the tool points to the rear of the vehicle.
  7. Press the headrest removal tool in and down, rotate the tool handle clockwise to vertical to release the spring from the headrest post, and then leave the tool attached.
  8. Remove the headrest from the driver seatback.
  9. Rotate the headrest removal tool handles counter-clockwise to horizontal, and then remove the tools from the driver seatback.

Install

  1. Align the posts of the headrest with the holes in the driver seatback.
    Note
    The detents in the headrest posts are to the LH side.
  2. Press the headrest in firmly so that it is fully seated with a click.
  3. Pull up on the headrest to confirm that it is secure in the driver seatback.
  4. Return the driver seatback to its original position.
