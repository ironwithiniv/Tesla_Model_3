Sensor - Relative Humidity and Temperature (Remove and Replace)

Correction code 10206002 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-05-12: Updated procedure with additional and modified procedure steps.
  • 2025-07-11: Added information on replacement part requirements.
  • 2024-12-02: Updated notes and Service Mode instructions.
Parent topic: 1020 - Windshield and Body Glass

Remove

  1. Open the LH front door and lower the LH front window.
  2. Disconnect 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  3. Use the touchscreen to clear DAS Calibration. Wait for the prompt to automatically disappear before continuing.
    Note
    Controls > Service > Camera Calibration > Clear Calibration
    Note
    Verify the calibration was cleared successfully.
    Note
    Wait for the prompt to disappear automatically before continuing.
  4. Remove the lower quad camera cover. See Quad Camera Cover - Lower (Remove and Replace).
  5. Remove the rear view mirror. See Mirror - Rear View (Remove and Replace).
  6. Remove the quad camera upper cover. See Quad Camera Cover - Upper (Remove and Replace).
  7. Remove the triple camera hood. See Glare Shield (Remove and Replace).
  8. Remove the screws (x4) that attach the triple camera assembly to the windshield bracket, and then release the assembly from the bracket.
  9. Put on an ESD wrist strap, and then connect the ESD wrist strap to vehicle ground.
    Note
    Make sure that the ground lead is connected to a ground source.
  10. Disconnect the electrical connector from the humidity and temperature sensor.
  11. Use a PH00 (Phillips #00) screwdriver to remove the screws (x2) that attach the humidity and temperature sensor to the windshield bracket.
    Note
    Use the correct screwdriver to remove the screws, otherwise it might strip the screw heads.
    Note
    The screws are tiny, make sure not to misplace them.
  12. Remove the relative humidity and temperature sensor from the windshield bracket.
    Note
    Angle the sensor circuit board up and over the plastic alignment pin, and then move the sensor circuit board upwards to clear the pin.
  13. Disconnect relative humidity and temperature sensor connector and use a PH00 (Phillips #00) screwdriver to remove the screws (x2) that attach the humidity and temperature sensor to the windshield bracket.
    Note
    Use the correct screwdriver to remove the screws, otherwise it might strip the screw heads.
    Note
    The screws are tiny, make sure not to misplace them.

Install

Note
Ensure that a graphene foam block is present on the contact pad and the blue tape is removed from the sensor foam pad before installation. If the foam is degraded or no longer present, install a new graphene foam block. Clean all adhesive residue that is left from the old foam. The foam is required for conducting the temperature of the windshield to the sensor.
Note
Make sure that the serial number of the replacement part number starts with PGT25067 or later. See Toolbox article 8984500 for additional details.
  1. Clean the area where the foam pad of the humidity and temperature sensor circuit board contacts the windshield with an isopropyl alcohol (IPA) wipe, and then allow the area to dry before continuing.
    CAUTION
    Make sure all adhesive residue from the windshield is removed and the windshield is dry before installation. The foam pad will not stick if the windshield is wet. Align the located hole of the sensor with the plastic alignment pin on the windshield bracket.
  2. Install the new humidity and temperature sensor circuit board on the windshield bracket.
    Note
    Make sure that the blue tape is removed from the foam pad.
    Note
    Align the hole on the PCB with the plastic alignment pin.
  3. Use a PH00 (Phillips #00) screwdriver to install the screws (x2) that attach the humidity and temperature sensor to the windshield bracket.
    0.12 Nm (1 lbs-in)
    CAUTION
    Use a Wiha precision torque wrench or similar to fasten the screws to the windshield bracket. The screw threads in the bracket are very delicate and can strip out very easily.
  4. Connect the electrical connector to the humidity and temperature sensor.
  5. Remove the ESD wrist strap from your body, and then disconnect the wrist strap from the vehicle ground point.
  6. Position the triple camera assembly onto the windshield bracket, and then install the screws (x4) that attach the assembly to the windshield bracket.
    1 Nm (.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • T10 socket
  7. Install the triple camera hood. See Glare Shield (Remove and Replace).
  8. Install the quad camera upper cover. See Quad Camera Cover - Upper (Remove and Replace).
  9. Install the rear view mirror. See Mirror - Rear View (Remove and Replace).
  10. Install the lower quad camera cover. See Quad Camera Cover - Lower (Remove and Replace).
  11. Connect 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  12. Reinstall the vehicle software through the touchscreen. See Software Reinstall - Touchscreen.
  13. Inform the customer that manual driving is now required to self-calibrate the camera.
    Note
    Self-calibration can take up to 100 miles (160 km) of manual driving, depending upon the road type and condition. Until self-calibration is complete, the message "Autopilot Features Currently Unavailable: Manual Driving Required While Camera Is Calibrating" is displayed if an attempt is made to engage an Autopilot feature.
  14. Raise the LH front window and close the LH front door.
