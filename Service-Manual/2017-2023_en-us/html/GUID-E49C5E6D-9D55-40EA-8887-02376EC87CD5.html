A/C Refrigerant (Heat Pump) (Unknown Oil Quantity or System Flush)

Correction code 18200112 1.07 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 1120026-01-A A/C SERVICE MACHINE, WAECO, ASC5500 RPA
Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
Warning
Only technicians who have completed all required certification courses are permitted to perform this procedure. Tesla recommends third party service provider technicians undergo equivalent training before performing this procedure.

For EMEA, in addition to any local A/C or F-gas certification, Tesla technicians are required to complete the Air Conditioning Safety Essentials training before working on Thermal Management and A/C systems.

Note
This procedure requires the A/C Refrigerant (Recovery and Recharge) procedure to be performed. If not already automatically added to the Service Visit, add correction code 18200102 as a separate correction within the same activity to the Service Visit.

Disconnect

  1. Set up AC machine.
  2. Open all four doors and lower all four windows.
    Note
    If vehicle is being powered down, Latch rear doors to prevent accidental closure
  3. Unlock the vehicle gateway. See Gateway (Unlock).
  4. On the touchscreen, tap the Service Mode "wrench" (at the bottom of the touchscreen UI), and then tap Thermal > Refrigerant System > Start Thermal Fill Drain (Refrigerant only) > Run, and allow the routine to complete.
  5. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  6. Move the seats forward.
  7. Disconnect the 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  8. Remove the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  9. Perform vehicle HV disablement procedure. See Vehicle HV Disablement Procedure.
  10. Wear appropriate personal protective equipment.
    DANGER
    R134a and R1234yf refrigerants are dangerous liquids and can cause serious injury if handled improperly. When recycling or recharging the air conditioning system, you must wear appropriate personal protective equipment (PPE), including face shields, heat-resistant gloves, rubber boots, aprons or waterproof overalls.
  11. Remove caps from low side and high side AC ports
    Note
    2x caps
  12. Connect hoses to vehicle
  13. Perform refrigerant system recovery.
    Note
    Note or print the amount of refrigerant and oil recovered. If drained oil level increased more than 1.01 oz (30 mL) refer to drained oil loss chart Article 353700.
  14. Remove AC hoses from vehicle.
  15. Release vacuum from A/C lines.
    Note
    2x Schrader valves, Carefully depress the schrader valves to release vacuum from AC lines
  16. Remove the 12V/LV battery. See 12V/LV Battery (Remove and Replace).
  17. Remove rear battery tie down strap
    Note
    Rotate forward to disengage
  18. Remove the clips securing the coolant hose to AC compressor bracket
    Note
    2x clips
  19. Release 12v battery vent tube from battery bracket
    Note
    1x fir tree clip
  20. Remove retaining clip securing AC compressor logic harness to AC compressor HV harness bracket
    Note
    1x fir tree clip
  21. Disconnect AC compressor logic connector
    Note
    1x locking electrical connector, Do not push down on red tab, pull to disengage lock, pull again to release connector
  22. Remove fastener securing AC compressor HV harness bracket to AC compressor
    Note
    1x bolt, 13mm, 9 Nm
  23. Remove AC compressor ground strap
    Note
    1x bolt, T25, 7 Nm
  24. Remove the clip securing the coolant hose to the AC compressor bracket
    Note
    1x fir tree clip
  25. Disconnect HV harness connector from AC compressor
    Note
    1x locking electrical connector, 3 stage locking connector, See photos for connector positions, Move black locking tab away form the AC compressor, position 1, then using a 45 degree pick, push down on position 2 of the locking connector while prying up on position 3 and disconnect
  26. Remove nut securing low side of manifold to compressor pipe and move low side pipe out of the way
    Note
    1x nut, 13mm, 22 Nm
  27. Remove nut securing high side of manifold to compressor pipe and move high side pipe out of the way
    Note
    1x nut, 13mm, 22 Nm
  28. Remove the desiccant bag from the accumulator. See Desiccant (Heat Pump) (Remove and Replace).
  29. Install the old cap into the accumulator, and then install the snap ring into the accumulator.
    Note
    Make sure that the snap ring is properly seated inside the groove of the accumulator.

Flush HVAC system with Snap-On A/C Machine

  1. Install the nuts (x2) to attach the flush adapters onto the supermanifold to compressor A/C line.
    Note
    Use the 13 mm nuts from the compressor to attach the flush adapters to the supermanifold to compressor A/C line.
  2. Connect the A/C machine hoses to the flush adapters.
  3. Connect Snap on A/C machine hoses to A/C flush adapters and run the full flush procedure by selecting Menu > Num 4 > OK > OK.
    Note
    Flush procedure runs for approximately 90 minutes, minimum of 3.2 kg of refrigerant needed in tank to run system flush procedure.
  4. After flush is complete, disconnect the A/C machine hoses from the A/C flush adapters.
  5. Stop flushing on the A/C machine when flushing is complete.
  6. Disconnect the A/C machine lines from the flush adapter and remove the flush adapter from the vehicle.

Flush HVAC system with Waeco A/C Machine

  1. Install the nuts (x2) to attach the flush adapters onto the supermanifold to compressor A/C line.
    Note
    Use the 13 mm nuts from the compressor to attach the flush adapters to the supermanifold to compressor A/C line.
  2. Connect the red pressure line to the high pressure A/C line and bolt the blue line coming from the flush kit to the low pressure A/C line.
  3. Set up flush kit to A/C machine.
    Note
    Attach the flush kit to the Waeco A/C machine. 2x bolts, 8mm, 1x Nyloc nut.
  4. Inspect the liquid line filter drier marking.
    Note
    Mark the filter before every flush with paint marker, replace the filter after 10 flushes.
    Note
    If replacement of the filter is not yet necessary, go to step 7.
  5. Remove the liquid inline filter drier
    Note
    Remove the filter from the container (the grey filter attached to the flush unit) PR052FM, Good to re-use copper o-ring, use hand force no tools
  6. Replace the liquid inline filter drier (the grey filter attached to the flush unit) PR052FM
    Note
    1x new filter, 2x new copper sealing rings, Wear appropriate PPE, Swap the nipple from old to new filter, Install copper sealing ring between connections, Do not over tighten, hand tight, due to copper line Ensure old sealing was removed before installing new filter, use pick tool to remove copper ring if needed
  7. Connect the low pressure hose from the A/C machine to the quick connector of the filter
  8. Connect A/C machine hoses to A/C flush adapters and do a full flush the HVAC case and A/C lines.
    Note
    Full flush runs around 1 hours 40 minutes. Must use A/C Service Machine WAECO ASC 5500G RPA R1234YF. Minimum of 6 kg of refrigerant needed in tank to run system flush procedure. Press Enter =>Other Selections =>Enter =>Flushing =>Enter =>Enter =>Enter =>=>Full Flushing =>Enter
  9. Press STOP on the machine after flush is complete.
    Note
    Fast flush is 40 minutes, full flush is 1 hour and 40 minutes.

Connect

  1. Remove AC compressor HV harness from the AC compressor and set aside
    Note
    Move AC compressor HV harness bracket toward the front of the vehicle, lift the bracket up to clear the upper bracket mount and carefully set harness and bracket aside
  2. Remove bolts securing AC compressor bracket to strut tower support brace and remove AC compressor and AC compressor bracket assembly from vehicle
    Note
    2x bolts, 15mm, 31 Nm, Recommend assistance, Support the AC compressor while removing the fasteners, Carefully remove the AC compressor and AC compressor bracket towards the front of the vehicle, under the strut tower support brace
  3. Remove AC compressor bracket from AC compressor
    Note
    3x bolts, 10mm, 9 Nm
  4. Use a wire brush to remove as much NVH cover material from the compressor as possible.
    CAUTION
    Failure to remove material will result in an inaccurate weight measurement.
  5. Add oil to the compressor.
    Note
    Different brands of compressors have different dry weights, After adding the oil, the gross weight should equals dry weight + 250g.
  6. Install NVH acoustic onto AC compressor
    Note
    Install new NVH blanket or re-use old one if new one is not available, and adhesive is in good working condition. Remove adhesive backing, Lay NVH acoustic cover down with adhesive side facing up, Align cut outs of NVH acoustic cover to suction port on AC compressor, Install NVH acoustic cover around suction port on AC compressor then continue to wrap NVH acoustic cover around compressor
  7. Install AC compressor bracket to AC compressor
    Note
    3x bolts, 10mm, 9 Nm
  8. Position AC compressor and AC compressor bracket assembly to strut tower support brace and secure
    Note
    2x bolts, 15mm, 31 Nm, Recommend assistance, Support the AC compressor while installing the fasteners, Carefully install the AC compressor and AC compressor bracket towards the rear of the vehicle, under the strut tower support brace, Keep AC compressor caps on the compressor until manifold lines are installed, Hand start bolts
  9. Position AC compressor HV harness onto AC compressor for installation
    Note
    Ensure the HV harness bracket engages the upper bracket mount on the AC compressor
  10. Connect HV harness connector to AC compressor
    Note
    1x locking electrical connector, 3 stage locking connector, After fully seating the connector onto the AC compressor engage the black locking tab by pushing toward the AC compressor, Perform push-pull-push test to ensure proper seating
  11. Install bolt securing AC compressor HV harness bracket to AC compressor
    Note
    1x bolt, 13mm, 9 Nm
  12. Install the clip securing the coolant hose to the AC compressor bracket
    Note
    1x fir tree clip
  13. Install AC compressor ground strap
    Note
    1x bolt, T25, 7 Nm
  14. Install retaining clip securing AC compressor logic harness to AC compressor HV harness bracket
    Note
    1x fir tree clip
  15. Connect the AC compressor logic connector
    Note
    1x locking electrical connector, Engage locking tab
  16. Install clips securing coolant hoses to AC compressor bracket
    Note
    2x clips
  17. Install rear battery tie down strap
    Note
    Insert assembly into bracket and rotate to 90 degrees
  18. Install 12V battery vent tube to battery bracket
  19. Install the 12V/LV battery. See 12V/LV Battery (Remove and Replace).
  20. Disconnect AC machine hoses from AC flush adapters
  21. Remove AC flush adapters from supermanifold to compressor AC line assembly
    Note
    2x nuts, 13mm, 22 Nm
  22. Replace seal washer on supermanifold to compressor AC line assembly on compressor discharge line
    Note
    1x seal washer. Lube seal washers with the appropriate A/C oil. See Fluids and Capacities for A/C oil specifications.
  23. Replace seal washer on supermanifold to compressor AC line assembly on compressor suction line
    Note
    1x seal washer. Lubricate seal washer with the appropriate A/C oil. See Fluids and Capacities for A/C oil specifications.
  24. Install supermanifold to compressor discharge line to compressor
    Note
    1x nut, 13mm, 22 Nm
  25. Install supermanifold to compressor suction line to compressor
    Note
    1x nut, 13mm, 22 Nm
  26. Install a new desiccant bag. See Desiccant (Heat Pump) (Remove and Replace).
  27. Reconnect AC hoses to vehicle
  28. Perform AC vacuum and refill the refrigerant.
    Note
    Select 20 mins of Vacuum, Recharge refrigerant to car's specs, add oil quantity as needed, select both HP and LP for charging
  29. Remove AC hoses from vehicle.
  30. Install caps onto AC ports.
    Note
    2x caps
  31. Connect 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  32. Unlock the vehicle gateway. See Gateway (Unlock).
  33. On the touchscreen, tap the Service Mode "wrench" (at the bottom of the touchscreen UI), and then tap Thermal > Sensors and Valves > Run Heat Pump Commissioning > Run, and allow the routine to complete.
  34. Tap Actions > Test Thermal Performance, select Run, and allow the routine to complete.
  35. Tap Actions > Test HVAC Performance, select Run, and allow the routine to complete.
  36. Disable Service Mode. See Service Mode.
  37. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  38. Install the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  39. Move front seats to original positions.
  40. Raise all windows and close all doors.
