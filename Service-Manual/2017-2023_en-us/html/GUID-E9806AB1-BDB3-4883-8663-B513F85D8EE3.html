Diamond Cover - Seat Side - 1st Row - LH (Remove and Replace)

Correction code 13072402 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Note
Depending on build location, some vehicles may not be equipped with this part. For vehicles equipped with side shield carriers, see Carrier - Side Shield - Outboard - Driver Seat (Remove and Replace).
Parent topic: 1307 - Front Seat Covers Pads and Trims

Remove

  1. Remove the driver seat outboard side shield. See Side Shield - Outboard - Driver Seat (Remove and Replace)
    Note
    During removal, certain steps require extra care. See the animation(s) for detailed guidance.
  2. Use the clip tool to sperate the diamond cover from seat frame, rotate clockwise and remove it from the LH front seat.

Install

  1. Install the diamond cover downward and engage the clip to the LH front seat.
  2. Install the driver seat outboard side shield. See Side Shield - Outboard - Driver Seat (Remove and Replace)
