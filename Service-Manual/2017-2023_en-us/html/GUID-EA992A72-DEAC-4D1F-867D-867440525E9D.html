Switch - Window - Front Passenger (Remove and Replace)

Correction code 11502702 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1150 - Door Glass and Regulators

Remove

  1. Open the RH front door and lower the RH front window.
  2. Remove the bolt that attaches the lower bolt cover to the RH front door trim panel.
    6 Nm (4.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • T30 socket
  3. Release the clips (x7) that attach the bolt cover to the RH front door trim panel, and then pivot the bolt cover down and off of the door trim panel.
  4. Release the clips (x2) that attach the puddle light to the bolt cover and then remove the bolt cover from the RH front door trim panel.
  5. Release the clips (x3) that attach the window switch to the door trim panel.
    Tip
    Use a 45 degree pick or a pocket screw driver to release the clips.
    Tip
    Pull up on the manual release handle for access, and then use thumb to push down on the switch to release it.
    Note
    Replace the door trim if any tab is broken during removal.
  6. Disconnect the passenger window switch electrical connector, and then remove the switch from the vehicle.

Install

  1. Remove the jumper harness from the new passenger window switch.
  2. Connect the passenger window switch electrical connector.
  3. Position the passenger window switch into the vehicle, and then secure the clips (x3) that attach the switch to the door trim panel.
  4. Install the clips (x2) that attach the puddle light to the bolt cover.
  5. Install the clips (x7) that attach the bolt cover to the RH front door trim panel.
  6. Install the bolt that attaches the lower bolt cover to the RH front door trim panel.
    6 Nm (4.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • T30 socket
  7. Raist the RH front window and close the RH front door.
