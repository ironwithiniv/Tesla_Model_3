Fuse - Positive - 12V Battery (Heat Pump) (Remove and Replace)

Correction code 17010502 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Nut that attaches the cable eyelet terminal to the fuse holder
9 Nm (6.6 lbs-ft)
  • 10 mm deep socket
 Reuse

Remove

  1. Disconnect the LV battery power. See 12V/LV Power (Disconnect and Connect).
  2. Release the 12V positive terminal cover by squeezing the tabs together and pulling the cover upwards.
  3. Remove the nut that attaches the cable eyelet terminal to the fuse holder.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  4. Release the tabs on both sides, and then remove the little fuse from the 12V battery positive fuse holder.

Install

  1. Install the little fuse to the 12V battery positive fuse holder.
    Note
    Make sure that the tabs on both sides are completely fixed to the fuse.
  2. Install the nut that attaches the cable eyelet terminal to the fuse holder.
    9 Nm (6.6 lbs-ft)
    Note
    The edge of the cable terminal shall be parallel to the edge of the battery post terminal.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  3. Install the 12V positive terminal cover.
  4. Connect the LV battery power. See 12V/LV Power (Disconnect and Connect).
