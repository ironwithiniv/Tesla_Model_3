Hose - Outlet - Radiator (Non-Heat Pump) (Remove and Replace)

Correction code 18302702 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1830 - Cooling System

Remove

  1. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  2. Open all the doors and lower all the windows.
    Note
    If vehicle is being powered down, latch the rear doors to prevent accidental closure.
  3. Move the front seats forward.
  4. Open the hood.
  5. Remove the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  6. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  7. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  8. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  9. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  10. Lower the vehicle fully.
  11. Position fluid catcher underneath the front of the vehicle.
  12. Release the clips (x2) that attach the radiator outlet hose to the RH side of the vehicle.
  13. Release the spring clip, disconnect the radiator outlet hose from the radiator, allow the coolant to drain, and then plug the male and female fittings.
  14. Place absorbent material underneath the superbottle hose fittings to avoid coolant on the steering gear connections.
  15. Release the spring clip, disconnect the radiator outlet hose from the superbottle, plug the male and fittings, and then remove the radiator hose from the vehicle.

Install

  1. Remove the hose plugs, connect a new radiator outlet hose to the superbottle, and then install the spring clip.
  2. Remove the hose plugs, connect the radiator outlet hose to the radiator, and then install the spring clip.
    Note
    Perform a push-pull-push test to make sure hose is fully seated.
  3. Install the clips (x2) that attach the radiator outlet hose to the RH side of the vehicle.
  4. Remove the fluid catcher from underneath the vehicle.
  5. Install the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  6. Lower the vehicle fully.
  7. Remove the superbottle cap.
  8. Inspect the coolant level and top off as necessary.
    Note
    Make sure that the fluid level is 5mm above the "Max" line.
  9. Connect 12V power. See 12V/LV Power (Disconnect and Connect).
  10. Connect a laptop with Toolbox 3 to the vehicle.
  11. In Toolbox, click the Actions/Autodiag tab, and then search for "Purge".
  12. Click TEST_VCFRONT_X_THERMAL-COOLANT-AIR-PURGEvia Service Mode:
    • Thermal ➜ Actions ➜ Coolant Purge Stop or Coolant Purge Start
    • Thermal ➜ Coolant System ➜ Coolant Purge Start
    via Service Mode Plus:
    • Drive Inverter ➜ Front Drive Inverter Replacement ➜ Coolant Air Purge
    • Drive Inverter ➜ Rear Drive Inverter Replacement ➜ Coolant Air Purge
    • Drive Inverter ➜ Rear Left Drive Inverter Replacement ➜ Coolant Air Purge
    • Drive Inverter ➜ Rear Right Drive Inverter Replacement ➜ Coolant Air Purge
    • Drive Unit ➜ Front Drive Unit Replacement ➜ Coolant Air Purge
    • Drive Unit ➜ Rear Drive Unit Replacement ➜ Coolant Air Purge
    via Toolbox:(link)    , click Run, and allow the routine to complete.
  13. Disconnect Toolbox and remove the laptop from the vehicle.
  14. Inspect the coolant level and top off as necessary.
    Note
    Make sure that the fluid level is 5mm above the "Max" line.
  15. Install the superbottle cap.
  16. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  17. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  18. Install the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  19. Move the front seats to the original positions.
  20. Raise all the windows and close all the doors.
