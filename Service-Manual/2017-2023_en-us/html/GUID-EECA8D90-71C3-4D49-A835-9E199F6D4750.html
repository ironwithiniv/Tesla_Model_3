Seatbelt - 2nd Row - LH (Remove and Replace)

Correction code 20056102 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2024-12-10: Fixed incorrect torque values for retractor to body fastener.
Parent topic: 2005 - Seatbelts

Torque Specifications

 Replace
Bolt that attaches the seat belt retractor to the body
35 Nm (25.8 lbs-ft)
  • 13 mm socket
 Replace

Remove

  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Remove the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  3. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  4. Remove the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  5. Remove the LH side rail trim. See Trim - Side Rail - LH (Remove and Replace).
  6. Remove the LH upper C-pillar trim. See Trim - C-Pillar - Upper - LH (Remove and Replace).
  7. Remove the LH rear C-pillar trim. See Trim - C-Pillar - Rear - LH (Remove and Replace).
  8. Remove and discard the bolt that attaches the 2nd row LH lower seat belt anchor to the body.
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm socket
  9. Release the clips (x2) that attach the bezel to the LH rear upper C-pillar trim, and then slide the bezel off the seat belt.
  10. Guide the seat belt through the LH rear upper C-pillar trim, and the remove the trim from the vehicle.
  11. Disconnect the electrical connector from the 2nd row LH seat belt retractor.
  12. Remove and discard the bolt that attaches the 2nd row LH seat belt retractor to the body, and then remove the retractor from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket

Install

  1. Install the 2nd row LH seat belt retractor to the body, and then install a new bolt to attach the retractor to the body.
    35 Nm (25.8 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  2. Connect the electrical connector to the 2nd row LH seat belt retractor.
  3. Install the bezel onto the seat belt, and then attach the clips (x2) to the LH rear upper C-pillar trim.
  4. Install a new bolt that attaches the 2nd row LH lower seat belt anchor to the body.
    35 Nm (25.8 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm socket
  5. Install the LH rear C-pillar trim. See Trim - C-Pillar - Rear - LH (Remove and Replace).
  6. Install the LH upper C-pillar trim. See Trim - C-Pillar - Upper - LH (Remove and Replace).
  7. Install the LH side rail trim. See Trim - Side Rail - LH (Remove and Replace).
  8. Install the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  9. Connect 12V power. See 12V/LV Power (Disconnect and Connect).
  10. Install the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  11. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
