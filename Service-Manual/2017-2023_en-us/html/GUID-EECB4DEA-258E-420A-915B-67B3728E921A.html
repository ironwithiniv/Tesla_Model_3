Mount and Bushings Set - Rear Drive Unit (4DU) (Remove and Replace)

Correction code 40012822 3.72 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

    Equipment:
    • Drive Unit Bushing Kit
    Parent topic: 4001 - Rear Drive Unit Assembly

    Remove

    1. Remove the rear drive unit (4DU). See Drive Unit - Rear (4DU) (Remove and Install).
    2. Install the drive unit bushing tool onto the rear bushing.
      Note
      Use cups "C", "A" and "G" when assembling the special tool.
      Note
      Always drive on the bearing side and hold the opposite side.
    3. Press the gearcase bushing out from the drive unit casting.
    4. Separate the bushing tool, and then remove it from the drive unit.
    5. Install the bushing removal tool on the RH bushing.
      Note
      Use cups "C", "A" and "G" when assembling the special tool.
      Note
      Always drive on the bearing side and hold the opposite side.
    6. Press the right hand bushing out from the drive unit casting.
    7. Separate the bushing tool, and then remove it from the drive unit.
    8. Remove and discard the bolts that attach the LH mount to the rear drive unit, and remove the mount from the rear drive unit.

    Install

    1. Install new bolts that attach the LH mount to the rear drive unit (torque 35 Nm +55 deg).
      Note
      Bolt PN: 1111864-00-B
    2. Set up the bushing tool to press in the new RH bushing.
      Note
      Use cups "E" and "G" when assembling the special tool, as shown.
      Note
      Always drive on the bearing side and hold the opposite side. Ensure the keyway is up and the lug on the bushing is in the center of the "G" cup opening.
    3. Turn the bearing-side bushing installation tool nut with a wrench while holding the other nut in place.
      Note
      Apply spray lubricant to the bushing exterior before installing it.
    4. Separate the bushing tool, and then remove it from the drive unit.
    5. Set up the bushing tool to press in the new LH bushing.
      Note
      Use cups "E" and "G" when assembling the special tool.
      Note
      Always drive on the bearing side and hold the opposite side. Ensure the keyway is up and the lug on the bushing is in the center of the "G" cup opening.
    6. Turn the nut on the thrust washer to press the new bushing into the drive unit.
      Note
      Apply spray lubricant to the bushing exterior before installing it.
    7. Separate the bushing tool, and then remove it from the drive unit.
    8. Install the rear drive unit (4DU). See Drive Unit - Rear (4DU) (Remove and Install).
    9. Refer to the Alignment Requirement tables to determine whether an EPAS alignment check (EC) or four wheel alignment check (AC) is necessary. If performed, add the alignment check/adjust correction code as a separate activity to the SV. See Alignment Requirement - Suspension.
