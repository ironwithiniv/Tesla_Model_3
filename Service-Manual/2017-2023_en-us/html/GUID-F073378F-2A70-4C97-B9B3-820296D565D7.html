Handle - Seat Back - 2nd Row - LH (Remove and Replace)

Correction code 13054012 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1305 - 2nd Row Seat Assemblies and Hardware

Remove

  1. Remove the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  4. Remove the LH 2nd row buckle. See Buckle - 2nd Row - LH (Remove and Replace).
  5. Remove the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  6. Remove the 2nd row LH seat back hinge bracket. See Bracket - Hinge - Seat Back - 2nd Row - LH (Remove and Replace).
  7. Remove the 2nd row center seatbelt assembly. See Seatbelt - 2nd Row - Center (Remove and Replace).
  8. Remove the LH 2nd row seat back latch. See Latch - Seat Back - 2nd Row - LH (Remove and Replace).
  9. Release the clip that attaches the LH 2nd row seat back latch control cable to the LH 2nd row seat backplate.
  10. Remove the bolts that attach the LH 2nd row seat back handle assembly to the backplate, and then slide the handle assembly from the backplate.

Install

  1. Slide the LH 2nd row seat back handle assembly onto the LH 2nd row seat backplate, and then install the bolts that attach the handle assembly to the backplate.
    2 Nm (1.5 lbs-ft)
  2. Fasten the clip that attaches the LH 2nd row seat back latch control cable to the LH 2nd row seat backplate.
  3. Install the LH 2nd row seat back latch. See Latch - Seat Back - 2nd Row - LH (Remove and Replace).
  4. Install the 2nd row center seatbelt assembly. See Seatbelt - 2nd Row - Center (Remove and Replace).
  5. Install the 2nd row LH seat back hinge bracket. See Bracket - Hinge - Seat Back - 2nd Row - LH (Remove and Replace).
  6. Install the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  7. This video shows how to properly stack the 2nd row LH seat buckle onto the 2nd row center seat belt anchor:
  8. Set the 2nd row center seat belt anchor onto the 2nd row LH inner ancillary bay rail, with the belt to the RH side.
  9. Make sure that the belt is not twisted, and lays flat against the 2nd row seatback.
  10. Set the guide pin of the 2nd row LH seat buckle bracket into the hole of the 2nd row LH inner ancillary bay rail, and pivot the bracket down onto the anchor, aligning the guide pin to the slot in the anchor.
  11. Install a new bolt to attach the seat buckle bracket, the seat belt anchor, and the inner ancillary bay rail to the body.
    40 Nm (29.5 lbs-ft)
  12. Verify the stacking.
    Callout Description
    1 LH 2nd Row Buckle on Top
    2 Center 2nd Row Seatbelt Anchor in the Middle
    3 LH Inner Ancillary Bay Rail at the Bottom
  13. Install the plastic bracket that attaches the female side of the electrical connector to the body studs.
  14. Connect the electrical harness to the LH rear seat belt buckle connector.
  15. Connect 12V power. See 12V/LV Power (Disconnect and Connect).
  16. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  17. Install the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
