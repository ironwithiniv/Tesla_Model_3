Clevis Pin - Brake (Remove and Replace)

Correction code 33253102 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1108272-00-B Cap, Logic Conn, Inv, 3DU
Parent topic: 3325 - Brake Pedal

Remove

  1. Open all doors and lower all windows.
  2. Remove the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  3. Move the LH front seat backward.
  4. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  5. Remove the 12V cap from the ancillary bay.
  6. Disconnect the HVC logic connector and install the logic cap.
  7. Remove the brake light switch. See Switch - Brake Light (Remove and Replace).
  8. Remove the brake clevis pin cotter pin.
  9. Remove the clevis pin from the brake pedal assembly.

Install

  1. Align the brake pedal to iBooster rod and install the clevis pin to the brake pedal assembly.
  2. Install the brake clevis pin cotter pin.
  3. Install the brake light switch. See Switch - Brake Light (Remove and Replace).
  4. Remove the logic cap and connect the HVC logic connector.
  5. Install the 12V cap to the ancillary bay.
  6. Connect 12V power. See 12V/LV Power (Disconnect and Connect).
  7. Install the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  8. Raise all windows and close all doors.
