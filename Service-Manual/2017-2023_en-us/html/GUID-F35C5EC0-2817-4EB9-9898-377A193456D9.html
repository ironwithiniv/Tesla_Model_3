Seat Assembly - 1st Row - LH (Remove and Replace)

Correction code 13040102 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
Seat base edges are sharp and can cause personal injury. Wear cut resistant gloves when removing the seat from the vehicle, and while performing procedures that involve work on or near the seat base.
Note
The front seats contain airbags and pretensioners and therefore must be disposed of properly. See Remove the Front Seat Airbag and Discard for more information. Add Correction Code 20010707 to document the labor; the labor time for destructively removing and disposing of the front seat airbag and pretensioner is not reflected in the front seat removal and replacement labor time.
Note
Though the 1st row LH seat is described, the procedure is the same for the 1st row RH seat. This procedure can be used for the driver seat and the passenger seat in LHD and RHD vehicles.
CAUTION
Supplemental Restraint System (SRS) components can be hazardous if not serviced and handled correctly. See
CAUTION
In the event of an airbag or seatbelt pretensioner deployment, certain components must be replaced, and other components must be inspected for damage. Refer to the Collision Repair Manual for a specific list of items that must be inspected and replaced.
Equipment:
  • 1133787-00-A Key, Seat Belt Release, Model 3

Torque Specifications

Table 1. Torque Specifications: Seat Assembly - 1st Row - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Front seat to body bolt
33.5 Nm (24.7 lbs-ft)
  • Torx Plus T45 socket
Replace Bolts are patched PN: 1458818-00-B

Remove

  1. Open all the doors and lower all the windows.
  2. If servicing the front passenger seat:
    1. Place the vehicle into Service Mode. See Service Mode.
    2. Unlock the vehicle gateway. See Gateway (Unlock).
    3. Reinstall the vehicle software. See Software Reinstall - Touchscreen.
  3. Remove the LH middle A-Pillar trim. See Trim - A-Pillar - Middle - LH (Remove and Replace).
  4. Remove the LH lower A-Pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  5. Move the LH front seat rearward.
  6. Remove and discard the bolts (x2) that attach the front of the 1st row LH seat to the body.
    CAUTION
    Use only the Torx Plus T45 bit to remove the seat bolts.
    Note
    Use the torchless heat induction tool to ease the removal of patch bolts, if necessary.
  7. Move the LH front seat forward.
  8. Insert the seat belt release key (1133787-00-A) into the bottom of the seatbelt pretensioner coupling to release the seatbelt from the pretensioner.
  9. Remove and discard the bolts (x2) that attach the rear of the 1st row LH seat to the body.
    CAUTION
    Use only the Torx Plus T45 bit to remove the seat bolts.
    Note
    Use the torchless heat induction tool to ease the removal of patch bolts, if necessary.
  10. Remove the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  11. Position the LH front seat to the middle of the track and the seat back to the vertical position.
  12. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  13. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  14. Disconnect the seat electrical harness connector from the LH body controller.
  15. Release the clips that attach the seat electrical harness to the body.
  16. With an assistant, remove the seat from the vehicle.
    Note
    Lift the seat, tilt the seat back, rotate the cushion toward the door, and remove the seat from the vehicle, cushion first.
    CAUTION
    If discarding the entire seat, Service Centers must remove the seat-mounted airbag and pre-tensioner (if present) before discarding the seat. Follow local Environmental Health and Safety (EH&S) best practices to dispose of the airbag and pre-tensioner (for example, place the airbag and pre-tensioner into the appropriate hazardous waste receptacles located in the Service Center). Refer to Remove the Front Seat Airbag and Discard for instructions, and use Correction Code 20010707 to document the labor; the labor time for destructively removing and disposing of the front seat airbag (and pre-tensioner, if equipped) is not reflected in the front seat removal and replacement labor time.

Install

  1. With an assistant, install the seat into the vehicle.
    Note
    Lift the seat sideways with the headrest toward the door opening and the seat cushion toward the rear of the vehicle. Move the headrest in through the door and follow with the seat cushion. Rotate the seat so that the cushion points up, set the seat down onto the carpet, and then rotate the seat back up to vertical.
  2. Fasten the clips that attach the seat electrical harness to the body.
  3. Connect the seat electrical harness connector to the LH body controller.
    CAUTION
    Remove all debris from the seat electrical harness connector, firmly press the connector into the body controller, and then engage the connector lock.
  4. Tuck excess harness length between the 12V harness bracket and the body.
  5. Connect 12V power. See 12V/LV Power (Disconnect and Connect).
  6. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  7. Install the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace)
  8. Move the seat fully rearward.
  9. Install new bolts (x2) to attach the front of the 1st row LH seat to the body.
    33.5 Nm (24.7 lbs-ft)
    CAUTION
    Use only the Torx Plus T45 bit to torque the seat bolts.
  10. Move the seat fully forward.
  11. Install new bolts (x2) to attach the rear of the 1st row LH seat to the body.
    33.5 Nm (24.7 lbs-ft)
    CAUTION
    Use only the Torx Plus T45 bit to torque the seat bolts.
  12. Install the seatbelt into the seatbelt pretensioner coupling.
    Note
    After reinstalling the seatbelt pretensioner into the seatbelt pretensioner coupling, perform a pull test to make sure that the seatbelt and pretensioner are securely engaged.
  13. Install the LH lower A-Pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  14. Replacement front seat assemblies and seat cushion frame assemblies are equipped with a newly-designed "mini-tilt" motor, and replacing these parts (or the tilt motor itself) might require a configuration change. Review the configuration information in the table and perform the following substeps if a configuration update is needed.
    1. Access the Vehicle Configuration section of the Infotainment Dashboard. See Gateway Configuration (Display and Change).
    2. Update cfg_frontSeattype according to the combination of tilt motors described in the table.
  15. If servicing the driver seat:
    1. Use the vehicle touchscreen to place the vehicle into Service Mode. See Service Mode.
    2. Reinstall the vehicle software. See Software Reinstall - Touchscreen.
    3. On the vehicle touchscreen, touch Controls > Service > Driver Seat, Steering & Mirrors Calibration > Start.
    4. Exit Service Mode. See Service Mode.
  16. If servicing the front passenger seat in a North American or Korean vehicle:
    1. Consult the parts catalog to see if a configuration change is needed.
    2. Remove all objects from the front passenger seat before beginning calibration.
    3. Reinstall the vehicle software. See Software Reinstall - Touchscreen.
    4. Remove all objects from the front passenger seat before beginning calibration.
    5. Locally connect a laptop with Toolbox 3 to the vehicle. See Toolbox (Connect and Disconnect).
    6. Unlock the vehicle gateway. See Gateway (Unlock).
    7. In Toolbox, click on the Actions tab, and then search for "OCS".
    8. Run the PROC_OCS1P_SELF-CALIBRATIONvia Service Mode Plus:Safety & Restraints ➜ Seats ➜ OCS1P Self Capacitance Calibrationvia Toolbox:(link) routine.
    9. Click on the Actions tab, and then search for "Seat calibration".
    10. Run the PROC_VCRIGHT_SEAT-CALIBRATEvia Service Mode:Low Voltage ➜ Seats ➜ Calibrate Seatvia Toolbox:(link) routine.
    11. Disconnect Toolbox and remove the laptop from the vehicle.
  17. If servicing the front passenger seat in a European vehicle built before May 2019:
    1. Consult the parts catalog to see if a configuration change is needed.
      Note
      Early European vehicles came with OCS module but only trace wires connected and no sandwich pad. From ~ May 2019 and forward, vehicles are configured for Resistive pad and without OCS module installed on seat. When replacing the passenger seat on an early Model 3 the new seats will come with Resistive pad only, and the vehicle needs to have configuration corrected.
    2. Reinstall the vehicle software. See Software Reinstall - Touchscreen.
    3. Locally connect a laptop with Toolbox 3 to the vehicle. See Toolbox (Connect and Disconnect).
    4. Unlock the vehicle gateway. See Gateway (Unlock).
    5. In Toolbox, click on the Actions tab, and then search for "Occupancy".
    6. Run the PROC_ICE_X_SET-PASSENGER-OCCUPANCY-SENSORvia Toolbox:(link) routine.
    7. Disconnect Toolbox and remove the laptop from the vehicle.
  18. Move the seat to the original position.
  19. Raise all the windows and close all the doors.
