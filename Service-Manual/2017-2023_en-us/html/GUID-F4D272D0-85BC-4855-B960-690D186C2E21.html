Shield - Body Controller - Front (Heat Pump) (Remove and Replace)

Correction code 17152122 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
Parent topic: 1715 - Electronic Control Modules

Remove

  1. Open LH front door
  2. Lower LH front window
  3. Open hood
    Note
    Press "Open" button on touchscreen to release latch, Lift lid manually
  4. Remove rear apron
    Note
    12x clips, Only store rear apron visible face upwards
  5. Power off vehicle from center display
    Note
    Via Controls > Safety > Power Off, Select Power Off button at warning dialogue box
  6. Disconnect 12V negative terminal
    Note
    1x nut, 10mm, 6 Nm, Ensure vehicle is in park, climate control system is off, and vehicle is not charging before disconnecting 12V
  7. Disconnect first responder loop
    Note
    1x connector, Release locking tab
  8. Remove vent tube hose from LH side of 12V battery
    Note
    1x tube adapter
  9. Release terminal cover and remove positive terminal
    Note
    2x clips, 1x nut, 10mm, 6 Nm, Do not fully remove positive terminal nut
  10. Remove 12V battery upper tie down strap to AC compressor bracket
    Note
    1x bolt, 10mm, 5 Nm, Lift battery tie down strap up and remove it from rear tie down hook strap
  11. Remove battery upper tie down strap
    Note
    Lift battery tie down strap up and remove it from the rear tie down hook strap
  12. Remove 12V battery from vehicle
  13. Remove rear battery tie down strap
    Note
    Rotate forward to disengage
  14. Disconnect thermal sub-harness from front controller
    Note
    1x connector, Depress locking tab and rotate to release
  15. Remove bolts securing front controller shield assembly and remove from vehicle
    Note
    2x bolts, 10mm, 8.5 Nm

Install

  1. Install front controller shield to the front controller
    Note
    2x bolts, 10mm, 8.5 Nm
  2. Connect thermal sub-harness to front controller
    Note
    1x connector, Rotate fully to secure locking tab
  3. Install rear battery tie down strap
    Note
    Insert assembly into bracket and rotate to 90 degrees
  4. Install 12V battery into vehicle
  5. Position battery tie down strap onto battery
    Note
    Hook upper tie down strap into rear tie down hook strap and position for installation
  6. Install bolt securing upper tie down strap to AC compressor bracket
    Note
    1x bolt, 10mm, 5 Nm
  7. Install vent tube hose in 12V battery
  8. Install positive terminal and terminal cover
    Note
    1x nut, 10mm, 6 Nm, 2x clips
  9. Connect first responder loop
    Note
    1x connector, Engage locking tab, Connect FRL before connecting 12V to avoid damage to car computer
  10. Connect 12V negative terminal
    Note
    1x nut, 10mm, 6 Nm
  11. Install rear apron
    Note
    12x clips
  12. Close hood
  13. Raise LH front window
  14. Close LH front door
