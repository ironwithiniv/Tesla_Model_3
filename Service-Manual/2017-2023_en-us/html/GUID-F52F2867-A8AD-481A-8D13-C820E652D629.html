Suspension - Seat Cushion - Driver Seat (Remove and Replace)

Correction code 13071122 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2024-01-05: Rewrite the procedure according to the latest validation in which the driver seat cushion suspension is removed without removing the driver seat.
Table 1. Torque Specifications: Suspension - Seat Cushion - Driver Seat (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
LH front seat fasteners (x4)
33.5 Nm (24.7 lbs-ft)
  • Torx Plus T45 socket
Replace Bolts are patched
Warning
Seat base edges are sharp and can cause personal injury. Wear cut resistant gloves when removing the seat from the vehicle, and while performing procedures that involve work on or near the seat base.
Parent topic: 1307 - Front Seat Covers Pads and Trims

Remove

  1. Open all doors and lower all windows.
  2. Move both front seats forward.
  3. Remove the 2nd row seat cushion and disconnect the harness. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  4. Remove the LH middle A-pillar trim. See Trim - A-Pillar - Middle - LH (Remove and Replace).
  5. Remove the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  6. Use a clip prytool to release the LH front seat harness from the sill trim clips (x3).
  7. Pull the LH front seat harness from under the LH front cabin carpet.
  8. Move the LH front seat forward, and then remove and discard the LH front seat rear fasteners (x2).
    Tip
    Use of the following tool(s) is recommended:
    • Torx Plus T45 socket
  9. Move the LH front seat backward, and then remove and discard the LH front seat front fasteners (x2).
    Tip
    Use of the following tool(s) is recommended:
    • Torx Plus T45 socket
  10. Tilt the LH front seat rearward to gain access to the underside of the LH front seat.
    Note
    It is not necessary to disconnect the LH seat harness from the body controller. Take care when moving the seat. Ensure the carpet is not damaged.
  11. With assistance, remove the retaining clips (x4) under the main seat harness junction from the LH front seat frame.
  12. Move the LH front seat to most forward.
  13. Disconnect the LV power. See 12V/LV Power (Disconnect and Connect).
  14. With assistance, unhook the clips (x2) that attach the lower section of the seat back trim and move the seat back flap away from the working area.
  15. With assistance, release the clips (x2) that attach the seat cushion foam to the seat suspension.
  16. Disconnect the seatback heater connector, and then separate the connector from the seat underside.
    Note
    Slide the connector straight down to release it from the seat assembly.
  17. Disconnect the seat cushion heat pad connector, and then separate the connector from the seat underside.
  18. Disconnect seat occupied sensor connector.
  19. Release the clip that attaches the seat occupied sensor to the seat underside, and then separate the sensor from the seat underside.
    Note
    Release the sensor from the seat frame by depressing the retaining clip and pulling the sensor away.
  20. Remove the clips (x2) that attach the seat occupied sensor connector and the LH seat harness to the seat cushion suspension.
  21. With assistance, remove the upper part of the LH front seat cushion suspension from the seat frame.
    Note
    Reversely use the clip prytool to remove the seat suspension. Press the seat suspension down with appropriate force to completely separate it from the seat frame.
  22. With assistance, remove the LH front seat cushion suspension from the seat frame.
    Note
    Rotate the seat suspension downwards to a horizontal position and lift it upwards to remove the lower part of the seat suspension.

Install

  1. With assistance, install the lower part of the LH front seat cushion suspension to the seat frame.
    Note
    Clip the seat suspension to the seat frame in a horizontal position and then rotate upwards.
  2. With assistance, install the upper part of the LH front seat cushion suspension to the seat frame.
    Note
    Reversely use the clip prytool to install the seat suspension. Press the seat suspension down with appropriate force to install it to the inside of the seat frame.
  3. Fasten the clip that attaches the seat cushion heat pad connector to the seat underside, and then connect the connector.
    Note
    Slide the connector onto the seat frame clip to secure.
  4. Fasten the clip that attaches the seatback heater connector to the seat underside, and then connect the connector.
    Note
    Slide the connector onto the seat frame clip to secure.
  5. Install the clips (x2) that attach the seat occupied sensor connector and the LH seat harness to the seat cushion suspension.
  6. Install the seat occupied sensor to the seat underside, and then fasten the clip that attaches the sensor to the seat underside.
  7. Secure the clip that attaches the seat occupied sensor to the seat assembly, and then connect occupied sensor electrical connector.
  8. Connect the LV power. See 12V/LV Power (Disconnect and Connect).
  9. Move the LH front seat to most rearward.
  10. With assistance, install the retaining clips (x4) under the main seat harness junction to the LH front seat frame.
    Note
    The number of clips may vary.
  11. Fasten the clips (x2) that attach the seat cushion to the seat suspension.
  12. Attach the clips that attach the lower section of the seat back trim to the seat suspension.
    Note
    Ensure the straps are tight for proper fit and installation.
  13. Return the LH front seat to the vertical position.
    Note
    Take care when moving the seat. Ensure the carpet is not damaged.
  14. Secure the LH front seat harness under the LH front cabin carpet.
  15. Install the LH front seat harness to the sill trim clips (x3).
  16. Install new LH front seat front fasteners (x2).
    33.5 Nm (24.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx Plus T45 socket
  17. Move the LH front seat forward, and then install new LH front seat rear fasteners (x2).
    33.5 Nm (24.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx Plus T45 socket
  18. Install the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  19. Install the LH middle A-pillar trim. See Trim - A-Pillar - Middle - LH (Remove and Replace).
  20. Connect the 2nd row seat cushion harness and install the 2nd row seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  21. Move both front seats to original position.
  22. Raise all windows and close all doors.
