Steering Wheel (Remove and Replace)

Correction code 32051802 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

CAUTION
Supplemental Restraint System (SRS) components can be hazardous if not serviced and handled correctly. See
CAUTION
In the event of an airbag or seatbelt pretensioner deployment, certain components must be replaced, and other components must be inspected for damage. Refer to the Collision Repair Manual for a specific list of items that must be inspected and replaced.
  • 2023-06-20: Eliminated redundant Toolbox routines, changed software update to software reinstall.
Note
If only the steering wheel rim is provided as replacement part, retrofit parts from the old steering wheel to the new steering wheel. See Rim - Steering Wheel (Remove and Replace).

If a new steering wheel is to be assembled from new parts, refer to the install section of Surround - Steering Wheel (Remove and Replace) to assemble the steering wheel shroud and then refer to Rim - Steering Wheel (Remove and Replace) to complete the installation. Add correction code 32051812 as a separate activity.

Parent topic: 3205 - Upper Column, Steering Wheel

Remove

  1. Remove the steering wheel. See Steering Wheel (Remove and Install).

Install

  1. Install the steering wheel. See Steering Wheel (Remove and Install).
  2. Reinstall the vehicle software via touchscreen. See Software Reinstall - Touchscreen.
