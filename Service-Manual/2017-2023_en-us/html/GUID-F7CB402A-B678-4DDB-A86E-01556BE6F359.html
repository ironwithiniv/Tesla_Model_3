Establish a Direct-to-Module Connection (Vehicles Built Through 10/05/2020)

  1. Open all four doors
    Note
    If vehicle is being powered down, Latch rear doors to prevent accidental closure
  2. Lower all four windows
  3. Move LH front seat forward
  4. Move RH front seat forward
  5. Remove 2nd row seat cushion and disconnect harness
    Note
    2x tabs, 2x connectors, Slide locking tabs to left of vehicle while lifting up seat benchNewer models have connectors on both sides of bench, Older models have 2x connectors on one side of bench
  6. Open hood
    Note
    Press "Open" button on touchscreen to release latch, Lift lid manually
  7. Remove rear apron
    Note
    12x clips, Only store rear apron visible face upwards
  8. Move RH front seat backward
  9. Move LH front seat backward
    Note
    Ensure the front of the seat is high enough to access the T20 screw for the outer side cover
  10. Remove LH front floor mat
  11. Remove LH console side panel carpet
    Note
    12x clips, Use trim tool starting at rear edge to release upper clips, then pull bottom to release remaining clips
  12. Remove LH front exterior hardware from center console
    Note
    2x bolts, 10mm, 7 Nm
  13. Remove RH front floor mat
  14. Remove RH console side panel carpet
    Note
    12x clips, Use trim tool starting at rear edge to release upper clips, Pull bottom to release remaining clips
  15. Remove RH front exterior hardware from center console
    Note
    2x bolts, 10mm, 7 Nm
  16. Disconnect USB harness at right front of center console
    Note
    1x USB connector
  17. Open front console rotating lid
    Note
    Push down lightly to open
  18. Open rear console rotating lid
    Note
    Push down lightly to open
  19. Remove console lid interior fasteners
    Note
    2x screws, T20, 1.7 Nm, Top photo is early production vehicles, Bottom is for later production vehicles
  20. Move LH front seat forward
  21. Raise LH front seat cushion to maximum height
  22. Move RH front seat forward
  23. Raise RH front seat cushion to maximum height
    Note
    This will allow access to HV battery bolts at RH front foot well and below RH front seat, Adjust seat back if needed to avoid contacting headliner
  24. Remove console lower rear panel
    Note
    5x clips, Insert the plastic trim tool with a 90 degree bend at the bottom of the cover and pull straight out to release
  25. Remove LH rear exterior bolt from center console
    Note
    1x bolt, 10mm, 7 Nm
  26. Remove RH rear exterior bolt from center console
    Note
    1x bolt, 10mm, 7 Nm
  27. Disconnect harness from rear of center console
    Note
    1x connector
  28. Move RH front seat backward
  29. Close front console rotating lid
    Note
    This will avoid lid getting hung up on center display upon removal
  30. Remove center console from vehicle
    Note
    Recommend assistance, Tilt rear of console upward, pull assembly towards rear of vehicle, then tilt front of console upward and remove through passenger side
  31. Power off vehicle from center display
    Note
    Via Controls > Safety > Power Off, Select Power Off button at warning dialogue box
  32. Disconnect 12V negative terminal
    Note
    1x nut, 10mm, 6 Nm, Ensure vehicle is in park, climate control system is off, and vehicle is not charging before disconnecting 12V
  33. Remove 12V cap from penthouse
    Note
    1x cap
  34. Disconnect HVC logic connector and install logic cap
    Note
    1x connector, 1x cap, Release locking tab then push the handle downward to release connector
  35. Disconnect RCM connectors
    Note
    2x connectors
  36. Remove nuts securing RCM onto body
    Note
    3x nuts, 10mm, 8 Nm, Discard patch nuts
  37. Remove RCM from vehicle
  38. Connect Tesla Direct-to-Module EDR Retrieval Harness to RCM
    Note
    2x connectors
  39. Connect Tesla Direct-to-Module EDR Retrieval Harness to PCAN-USB adapter
    Note
    1x connector
  40. Connect PCAN-USB adapter to laptop via USB port
    Note
    1x connector,
  41. Connect 12V power to Tesla Direct-to-Module EDR Retrieval Harness
    Note
    1x connector
  42. Open Tesla EDR Retrieval Program
    Note
    Program will automatically try to connect to RCM and will show a green circle in the lower left corner when connected
  43. Once connected, click "Run EDR Retrieval" button and follow the on-screen prompts to retrieve and save EDR data
  44. Use retrieved data to generate a Tesla EDR Report at https://edr.tesla.com
    Note
    Time will vary based on user and retrieved data
  45. Close Tesla EDR program
    Note
    Select "x" at the top right of the window to close once complete
  46. Disconnect 12V power from Tesla Direct-to-Module EDR Retrieval Harness
    Note
    1x connector
  47. Disconnect PCAN-USB adapter from computer
    Note
    1x connector
  48. Disconnect Tesla Direct-to-Module EDR Retrieval Harness from PCAN-USB adapter
    Note
    1x connector
  49. Disconnect Tesla Direct-to-Module EDR Retrieval Harness from RCM
    Note
    2x connector
  50. Position RCM into vehicle for installation
  51. Install nuts securing RCM onto body
    Note
    3x nuts, 10mm, 8 Nm, Install new patch nuts
  52. Connect RCM connectors
    Note
    2x connectors, verify that fully seated or make sure connector is fully seated 
  53. Remove logic cap and connect HVC logic connector
    Note
    1x connector, 1x cap, Align connector then pull the handle to locking position get connector fully seated
  54. Install 12V cap to penthouse
    Note
    1x cap
  55. Connect 12V negative terminal
    Note
    1x nut, 10mm, 6 Nm
  56. Install center console into vehicle
    Note
    Recommend assistance, Tilt front of console downward, Slide assembly towards front of vehicle and tilt rear of console down into place
  57. Open front console rotating lid
  58. Connect harness to rear of center console
    Note
    1x connector
  59. Install RH rear exterior bolt to center console
    Note
    1x bolt, 10mm, 7 Nm
  60. Install LH rear exterior bolt to center console
    Note
    1x bolt, 10mm, 7 Nm
  61. Install console lower rear panel
    Note
    5x clips
  62. Lower RH front seat height
  63. Lower LH front seat height
  64. Install console lid interior fasteners
    Note
    2x bolts, T20, 1.7 Nm, Top photo is early production vehicles, Bottom is for later production vehicles
  65. Close rear console rotating lid
  66. Close front console rotating lid
  67. Connect USB harness at right front of center console
    Note
    1x USB connector
  68. Install RH front exterior bolts to center console
    Note
    2x bolts, 10mm, 7 Nm
  69. Install RH console side panel carpet
    Note
    1 tab, 12x clips, Position side panel and align the front tab. Push the console panel from the front towards the rear
  70. Install RH front floor mat
  71. Install LH front exterior bolts to center console
    Note
    2x bolts, 10mm, 7 Nm
  72. Install LH console side panel carpet
    Note
    1 tab, 12x clips, Position side panel and align the front tab. Push the console panel from the front towards the rear
  73. Install LH front floor mat
  74. Move LH front seat forward
  75. Move RH front seat forward
  76. Install rear apron
    Note
    12x clips
  77. Close hood
  78. Connect 2nd row seat cushion harness and install 2nd row seat cushion
    Note
    2x connectors, 2x clips, Insert the seat belt buckles through the holes, Slide rear cushion inward then align front guide tabs to locking tabs, Make sure cushion is fully seated with push & pull test near clips
  79. Move RH front seat to original position
  80. Move LH front seat to original position
  81. Raise all windows
  82. Close all four doors
    Note
    Unlatch rear doors before closing

Establish a Direct-to-Module Connection (Vehicles Built After 10/05/2020)

  1. Open all four doors
    Note
    If vehicle is being powered down, Latch rear doors to prevent accidental closure
  2. Lower all four windows
  3. Place vehicle in service mode
    Note
    Via UI > Controls > Software, Touch and hold "Model 3 or Y" for 4 seconds then release, Use screen keyboard to type "service" into dialog box then select OK
  4. Open hood
    Note
    Press "Open" button on touchscreen to release latch, Lift lid manually
  5. Move LH front seat backward
  6. Remove LH front floor mat
  7. Remove LH console side panel carpet
    Note
    12x clips, Use trim tool starting at rear edge to release upper clips, then pull bottom to release remaining clips
  8. Remove LH front exterior hardware from center console
    Note
    2x bolts, 10mm, 7 Nm
  9. Move LH front seat forward
  10. Remove console lower rear panel
    Note
    5x clips, Insert the plastic trim tool with a 90 degree bend at the bottom of the cover and pull straight out to release
  11. Remove LH rear exterior bolt from center console
    Note
    1x bolt, 10mm, 7 Nm
  12. Move RH front seat forward
  13. Remove RH rear exterior bolt from center console
    Note
    1x bolt, 10mm, 7 Nm
  14. Move RH front seat backward and seat back downward
  15. Remove RH front floor mat
  16. Remove RH console side panel carpet
    Note
    12x clips, Use trim tool starting at rear edge to release upper clips, Pull bottom to release remaining clips
  17. Remove RH front exterior hardware from center console
    Note
    2x bolts, 10mm, 7 Nm
  18. Power off vehicle from center display
    Note
    Via Controls > Safety > Power Off, Select Power Off button at warning dialogue box
  19. Remove rear apron
    Note
    12x clips, Only store rear apron visible face upwards
  20. Disconnect 12V negative terminal
    Note
    1x nut, 10mm, 6 Nm, Ensure vehicle is in park, climate control system is off, and vehicle is not charging before disconnecting 12V
  21. Disconnect first responder loop
    Note
    1x connector, Release locking tab
  22. Disconnect harness from rear of center console
    Note
    1x connector
  23. Disconnect USB harness at right front of center console
    Note
    1x USB connector
  24. Remove center console from vehicle
    Note
    Recommend assistance, Tilt rear of console upward, pull assembly towards rear of vehicle, then tilt front of console upward and remove through passenger side
  25. Disconnect universal restraint control module
    Note
    2x connectors, Disengage locking tab to release levers
  26. Remove universal restraint control module from vehicle
    Note
    3x nuts, 10mm, 8 Nm, Discard patch nuts after removal
  27. Connect Tesla Direct-to-Module EDR Retrieval Harness to RCM
    Note
    2x connectors
  28. Connect Tesla Direct-to-Module EDR Retrieval Harness to PCAN-USB adapter
    Note
    1x connector
  29. Connect CAN dongle to laptop via USB port
    Note
    1x connector,
  30. Connect 12V power to Tesla Direct-to-Module EDR Retrieval Harness
    Note
    1x connector
  31. Open Tesla EDR Retrieval Program
    Note
    Program will automatically try to connect to RCM and will show a green circle in the lower left corner when connected
  32. Once connected, click "Run EDR Retrieval" button and follow the on-screen prompts to retrieve and save EDR data
  33. Use retrieved data to generate a Tesla EDR Report at https://edr.tesla.com
    Note
    Time will vary based on user and retrieved data
  34. Close Tesla EDR program
    Note
    Select "x" at the top right of the window to close once complete
  35. Disconnect 12V power from Tesla Direct-to-Module EDR Retrieval Harness
    Note
    1x connector
  36. Disconnect PCAN-USB adapter from computer
    Note
    1x connector
  37. Disconnect Tesla Direct-to-Module EDR Retrieval Harness from PCAN-USB adapter
    Note
    1x connector
  38. Disconnect Tesla Direct-to-Module EDR Retrieval Harness from RCM
    Note
    2x connector
  39. Install universal restraint control module onto vehicle
    Note
    3x nuts, 10mm, 8 Nm, Install new patch nuts, Verify part number on new module is correct
  40. Connect universal restraint control module
    Note
    2x connectors, Engage locking levers
  41. Install center console into vehicle
    Note
    Recommend assistance, Tilt front of console downward, Slide assembly towards front of vehicle and tilt rear of console down into place
  42. Connect USB harness at right front of center console
    Note
    1x USB connector
  43. Connect harness to rear of center console
    Note
    1x connector
  44. Install RH front exterior bolts to center console
    Note
    2x bolts, 10mm, 7 Nm
  45. Install RH console side panel carpet
    Note
    1 tab, 12x clips, Position side panel and align the front tab. Push the console panel from the front towards the rear
  46. Install RH front floor mat
  47. Connect first responder loop
    Note
    1x connector, Engage locking tab, Connect FRL before connecting 12V to avoid damage to car computer
  48. Connect 12V negative terminal
    Note
    1x nut, 10mm, 6 Nm
  49. Install rear apron
    Note
    12x clips
  50. Close hood
  51. Move RH front seat forward
  52. Install RH rear exterior bolt to center console
    Note
    1x bolt, 10mm, 7 Nm
  53. Install LH rear exterior bolt to center console
    Note
    1x bolt, 10mm, 7 Nm
  54. Install console lower rear panel
    Note
    5x clips
  55. Move LH front seat backward
  56. Install LH front exterior bolts to center console
    Note
    2x bolts, 10mm, 7 Nm
  57. Install LH console side panel carpet
    Note
    1 tab, 12x clips, Position side panel and align the front tab. Push the console panel from the front towards the rear
  58. Install LH front floor mat
  59. Connect to vehicle using Toolbox 3.0
    Note
    Vehicle connection is integrated into drivers footwell cover, Open Toolbox 3 website and establish connection to the vehicle, https://toolbox.teslamotors.com, Select connection status icon at top right corner, and select connect locally (icon will turn green when vehicle is connected)If RJ45 ethernet diagnostic connector present connect directly from laptop using an RJ45 Ethernet cable
  60. Select ‘Actions/Autodiag’ and search for ‘Service_Redeploy’
  61. Select ‘UPDATE_SERVICE-REDEPLOY’, click ‘Run’, and allow routine to complete
    Note
    Select ‘X’ at top right of window to close once complete
  62. Once firmware redeploy is complete, Verify on center display release notes are present
    Note
    If the redeploy fails you may receive an error message on UI
  63. Re-establish vehicle connection to Toolbox 3.0
  64. Run "Restraint Control Module Beginning-of-line Configuration" PROC_RCM_X_BOL-CONFIGURATIONvia Toolbox:(link) routine
    Note
    This routine will only appear on FW 2022.16.1 and newer, Routine only required when upgrading from 12.0 to 12.1 RCM
  65. Select ‘Dashboards’, and search for 'RCM retrofit'
  66. Select ‘Service Tasks’, click ‘Run’, and allowroutine to complete
    Note
    Select ‘X’ at top right of window to close oncecomplete
  67. Remove HSD or RJ45 cable from Ethernet port to disconnect Toolbox 3.0 from vehicle
  68. Move LH front seat to original position
  69. Move RH front seat to original position
  70. Raise all windows
  71. Exit Service Mode
    Note
    Via UI > Service > Exit, Press and hold "Exit Service Mode" button
  72. Close all four doors
    Note
    Unlatch rear doors before closing
