Coolant Pump - HV Battery (Remove and Replace)

Correction code 18308502 0.90 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-07-28: Added coolantPumpType configuration step.
  • 2024-08-06: Changed instruction for lubrication of O-rings to use Silicone lubricant instead of using silaramic grease.
Parent topic: 1830 - Cooling System

Torque Specifications

Table 1. Torque Specifications: Coolant Pump - HV Battery (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x4) that attach the coolant pump to the superbottle
1.8 Nm (1.3 lbs-ft)
  • T20 socket
Reuse

Remove

  1. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  2. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  3. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  4. Position a coolant drain under the superbottle.
  5. If the vehicle is equipped with dual motors, perform these steps. Otherwise, go to step 6.
    1. Install a foldable funnel underneath the front drive unit heat exchanger.
      Note
      Make sure the foldable funnel covers the front drive unit 12V connector, steering rack, and is positioned to catch fluid from the heat exchanger coolant outlet.
    2. Release the clip and disconnect the front drive unit heat exchanger to superbottle hose from the heat exchanger coolant outlet, and then drain the coolant into the coolant drain container.
    3. Install plugs into the front drive unit heat exchanger to superbottle hose and the heat exchanger coolant outlet.
  6. Release the clip that attaches the electrical harness to the superbottle.
  7. Disconnect the electrical harness from the HV battery coolant pump connector.
  8. Remove the bolts (x4) that attach the HV battery coolant pump to the superbottle, and then remove the pump from the superbottle.

Install

  1. Remove and discard any o-rings or debris in the superbottle where the coolant pump will install.
  2. Make sure that new o-rings are installed onto the new coolant pump.
  3. Lubricate the o-rings with Silicone lubricant.
  4. Position the outlet of the coolant pump in the up position, and insert the coolant pump into the superbottle.
  5. Make sure that the coolant pump is fully seated in the superbottle.
  6. Hand-tighten the bolts (x4) to attach the coolant pump to the superbottle.
  7. Tighten the coolant pump bolts in a cross-pattern.
    1.8 Nm (1.3 lbs-ft)
  8. Connect the electrical harness to the coolant pump connector.
  9. Fasten the clip that attaches the electrical harness to the superbottle.
  10. If the vehicle is equipped with dual motors, perform these steps. Otherwise, go to step 11.
    1. Remove the plugs from the front drive unit heat exchanger to superbottle hose and the heat exchanger coolant outlet.
    2. Connect the front drive unit heat exchanger to superbottle hose to the heat exchanger coolant outlet, and then fasten the clip.
    3. Remove the foldable funnel from underneath the front drive unit heat exchanger.
  11. Remove the coolant drain from under the vehicle.
  12. Install the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  13. Perform a cooling system vacuum refill. See Cooling System (Vacuum Refill).
  14. Connect 12V power. See 12V/LV Power (Disconnect and Connect).
  15. Install the cabin intake duct assembly. See Duct - Upper - Cabin Intake (Remove and Replace).
  16. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
