Actuator - Lower Mode (Heat Pump) (Remove and Replace)

Correction code 18102512 3.36 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-10-19: Added steps of removing the instrument panel and the HVAC Case Test routine.
  • 2023-10-16: Reorganized the procedure.
Parent topic: 1810 - Cabin HVAC

Remove

  1. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  2. Remove the wiper module. See Wiper Module (Remove and Replace).
  3. Remove the HVAC inlet plenum. See Plenum - Inlet - HVAC (Remove and Replace).
  4. Remove the windshield washer reservoir. See Reservoir - Windshield Washer (Remove and Install).
  5. Remove the vehicle from the lift.
  6. Enable EPB using service mode. See Parking Brake - Caliper - Rear - LH (Release).
  7. Remove the instrument panel carrier. See IP Carrier (Remove and Install).
  8. Remove the LH air wave duct. See Duct - Air Wave - LH (LHD) (Non-Heat Pump) (Remove and Replace).
  9. Remove the LH front carpet from the vehicle. See Carpet - Front - LH (Remove and Replace).
  10. Partially release the cross car beam assembly to allow for enough space to remove the lower actuator. See Beam - Cross Car (LHD) (Remove and Replace).
  11. Remove the bolts(x2) that attach the lower mode actuator to the HVAC assembly.
    Note
    Insert the mini ratchet bit from behind the harness.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 bit
  12. Disconnect the lower mode actuator electrical connector, and then remove the actuator from the HVAC assembly.

Install

  1. Position the lower mode actuator on the HVAC assembly; align the guide, and then push the lower mode actuator towards the left to install.
  2. Connect the lower mode actuator electrical connector.
  3. Install the bolts(x2) that attach the lower mode actuator to the HVAC assembly.
    1.2 Nm (.9 lbs-ft)
    Note
    Insert the mini ratchet bit from behind the harness.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 bit
    • Torque Wrench Hexagon - 1060071-00-A
  4. Restore the cross car beam back into position. See Beam - Cross Car (LHD) (Remove and Replace).
    Note
    Make sure the harness is not squeezed.
  5. Install the LH front carpet. See Carpet - Front - LH (Remove and Replace).
  6. Install the LH air wave duct. See Duct - Air Wave - LH (LHD) (Non-Heat Pump) (Remove and Replace).
  7. Install the instrument panel carrier. See IP Carrier (Remove and Install).
  8. Raise and support the vehicle.
  9. Install the windshield washer reservoir. See Reservoir - Windshield Washer (Remove and Install).
  10. Install the HVAC inlet plenum. See Plenum - Inlet - HVAC (Remove and Replace).
  11. Install the wiper module. See Wiper Module (Remove and Replace).
  12. Place the vehicle into Park.
    Note
    Remove wheel chocks if present. Make sure parking brakes are engaged. This also disables EPB service mode.
  13. Connect a laptop with Toolbox to the vehicle. See Toolbox (Connect and Disconnect).
  14. Perform the following routine: TEST-SELF_VCRIGHT_X_HVAC-CASE-ACTUATORSvia Toolbox:(link)
  15. Remove the laptop from the vehicle.
  16. Exit Service Mode Plus.
  17. Raise all four windows and close all four doors.
