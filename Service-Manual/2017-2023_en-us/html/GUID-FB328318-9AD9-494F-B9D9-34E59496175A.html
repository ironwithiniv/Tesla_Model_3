Side Shield - Outboard - Driver Seat (Remove and Replace)

Correction code 13074202 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-11-02: Added information about the tab that attaches the side shield to the front seat.
  • 2026-07-29: Added skills of releasing the side shield clip, and added images and notes for side shields with different clip versions.

Equipment:
  • 1133787-00-A Key, Seat Belt Release, Model 3
Parent topic: 1307 - Front Seat Covers Pads and Trims

Torque Specifications

Table 1. Torque Specifications: Side Shield - Outboard - Driver Seat (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolt that attaches the outboard side shield to the seat frame
4 Nm (2.9 lbs-ft)
  • Torx T20 socket
Reuse

Remove

  1. Open the LH doors and lower the LH windows.
  2. Move the driver's seat fully forward.
  3. Insert the seat belt release key (1133787-00-A) into the bottom of the seatbelt pretensioner coupling to release the seatbelt from the pretensioner.
    Tip
    Lower/raise the seat as needed for access.
    CAUTION
    Do not allow the seat headrest to compress the sun visor as it might crack the mirror.
  4. Raise the LH front seat cushion to the maximum height.
    CAUTION
    Adjust the seat back if needed to avoid contacting the headliner.
    CAUTION
    Do not allow the seat headrest to compress the sun visor as it might crack the mirror.
  5. Remove the screw that attaches the driver seat outboard side shield to the seat frame, and then pull outward to release the seat outboard side shield assembly tab from front seat assembly
    Note
    Some vehicles may equip with 8mm bolt with a torque of 5 Nm.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  6. Use a clip prytool to release the clip tabs (x2) from the seat bottom, and then pull the driver seat outboard side shield away from the seat frame to release the clip that attaches the side shield to the center of the seat frame.
    CAUTION
    Do not forcefully release the trim clip, as this may damage the clip.
    CAUTION
    Do not fully remove the side shield at this time as this might damage the trim, switch pack or and/or harness.
    Note
    Vehicles built after 2023.6.30 have side shields with 7 clips.
  7. Disconnect the electrical harness from the backrest and cushion adjust switch connector, if so equipped.
  8. Pull the driver seat outboard side shield outward and lift it off from the vehicle.
  9. If the driver seat outboard side shield is being replaced, remove the back rest and cushion adjust switch from the outboard side shield. See Switch - Back Rest and Cushion Adjust - Driver Seat (Remove and Replace).

Install

  1. If a new driver seat outboard side shield is being installed, install the back rest and cushion adjust switch to the outboard side shield. See Switch - Back Rest and Cushion Adjust - Driver Seat (Remove and Replace).
  2. Connect the electrical harness to the backrest and cushion adjust switch connector, if so equipped.
  3. Push the driver seat outboard side shield into the seat frame to fasten the clip that attaches the side shield to the center of the seat frame.
    Note
    Vehicles built after 2023.6.30 have side shields with 7 clips.
  4. Push inward to secure the outboard side shield assembly tab to the front seat assembly, and then install the screw that attaches the driver seat outboard side shield to the seat frame.
    4 Nm (2.9 lbs-ft)
    CAUTION
    Carefully push the outboard side shield assembly to avoid damage.
    Note
    Some vehicles may equip with 8mm bolt with a torque of 5 Nm.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  5. Move the LH front seat to its original position.
  6. Install the LH front seat belt pretensioner coupling onto the LH front seat pretensioner.
    Note
    Perform a pull-push-pull test to verify the pretensioner and coupling are fully engaged.
  7. Raise the LH windows and close the LH doors.
