Steering Column - Inspect for Lateral Play (Inspection)

Correction code 32051900 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-12-08: Changed measurement method and removed video.
  • 2025-02-18: Added video.
  • 2025-02-06: Released new procedure.
Note
This procedure is intended to find safety related structural integrity concerns, such as loose steering column mounting bolts or a loose steering wheel nut.
Parent topic: 0006 - Periodic Roadworthiness Inspections

Inspection

  1. Move the steering column to the highest and most inward position.
    Note
    On the touchscreen, select Controls > Steering, and then use the left scroll wheel on the steering wheel to adjust the steering column.
  2. Set the steering wheel in the straight ahead position.
  3. Perform a pull/wiggle test on the steering wheel: gently pull and push the steering wheel away from and towards the steering column and note any unusual movement.
    • If any unusual movement is observed, install a new steering wheel bolt that attaches the steering wheel to the steering column and torque it to specification before continuing to the next step. See Steering Wheel (Remove and Install). Make sure there is no more unusual movement of the steering wheel, and then continue to step 4.
      Note
      Add correction code 32051801 as a separate activity to the Service Visit.
    • If no unusual movement is observed, continue to the next step.
  4. Apply tape onto steering wheel at the 9 o'clock position and put protective material onto the center console.
  5. Prepare the steering column lateral play inspection tools on the center console.
  6. Close the LH front door.
  7. Install the brake rotor run-out tool onto the LH front window and steering wheel.
    Note
    Install the suction cup onto the LH front window. Apply masking tape onto the suction cup for protection, then install the brake run-out tool onto the LH front window. Align the tool horizontally with the tape on the steering wheel at the 9 o'clock position.
    Note
    Make sure that the indicator rod is properly depressed and allows travel in both directions without bottoming out. Set dial to zero.
  8. Inspect the steering column for lateral play.
    1. Apply significant force on the steering wheel in one lateral direction, and then release the force.
    2. Record the value at which the dial indicator stabilizes.
    3. Apply significant force on the steering wheel in the opposite lateral direction, and then release the force.
    4. Record the value at which the dial indicator stabilizes.
    5. Calculate the difference between the two recorded values. If the difference is 1 mm or less, then the steering column is within the specified tolerance.
  9. Remove the brake rotor run-out tool from the LH front window.
  10. Remove protective materials from the steering wheel and center console.
