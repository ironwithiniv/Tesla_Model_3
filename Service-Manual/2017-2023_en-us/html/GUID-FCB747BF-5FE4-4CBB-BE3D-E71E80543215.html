Seal - Secondary - Front Door - LH (Remove and Replace)

Correction code 11705002 0.48 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1170 - Seals Body Closures

Remove

  1. Open the LH front door.
  2. Release the LH front door inner belt seal and glass run seal clips (x3) to fully access the secondary seal.
  3. Use narrow-width tape to carefully mark the location of the secondary seal around the door.
    CAUTION
    Make sure that the edge of the tape accurately follows the edge of the seal.
  4. Release the ends of the door secondary seal from the rear of the inner belt seal and the door glass run seal.
  5. Slowly peel the length of the secondary seal from the perimeter of the door.
    Note
    Discard the seal as it can not be reused.
  6. Clean any remaining adhesive or residue from the door.
    Note
    If needed, carefully use the following tools to clean adhesive or residue:
    • 1071510-00-AWHEEL, STRIPE OFF
    • 1076972-00-A4 Piece Non-Marring Scraper Set
    • 2151853-00-A3M PN38180 Glue Cleaner_230G
    • 2150371-00-AIPA Wipers

Install

  1. Ensure the area where the secondary seal will be installed is clean.
  2. Peel a short section of the seal backing on each end of the seal and position the ends into the door assembly.
    Note
    Make sure that the open edge of the seal is facing the inside of the door.
    Note
    Make sure the front edge of the seal is under the cutout for the glass run seal, and the rear edge is under the cutout for the inner belt seal.
    Note
    Make sure that the drain holes of the seal are at the bottom of the door.
  3. Firmly press the remaining portion of the seal into place while removing the film from the double sided tape.
    Note
    Do not stretch the seal as it is applied to the door.
  4. Remove the marking tape from the door.
  5. Install the LH front door inner belt seal and glass run seal clips (x3).
