Sub-Assembly - Latch - Charge Port (EMEA) (Remove and Replace)

Correction code 44012122 0.66 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2023-10-25: Update charge port to body bolt torque to 9 Nm.
  • 2023-08-25: Added link to charge port voltage check procedure.
Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
Parent topic: 4401 - Charge System Inlet

Remove

  1. Open all four doors.
    Note
    Latch rear doors to prevent accidental closing.
  2. Lower all the windows.
  3. Move LH front seat forward.
  4. Move RH front seat forward.
  5. Remove 2nd row seat cushion and disconnect harness.
    Note
    2x tabs, 2x connectors, Press tab toward LH side of vehicle on each side to release front edge of seat cushion.
  6. Open trunk from exterior switch.
  7. Open hood.
  8. Remove rear apron.
    Note
    12x clips.
  9. Open charge port door.
  10. Disconnect 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  11. Perform the charge port voltage check procedure. See Charge Port Voltage Check.
  12. Remove HV cap from ancillary bay.
    Note
    1x cap.
  13. Fold the 60 seat in down position.
    Note
    Protect the seat cushion.
  14. Remove LH side bolster.
    Note
    1x clip, 1 tab, Pull outward then slightly upward to remove.
  15. Remove and discard bolster plastic bracket from LH side.
    Note
    2x clips, If necessary, depress the clips from behind, this bracket may come out with bolster. Discard after removal.
  16. Fold the 60 seat into vertical position.
    Note
    Remove seat protection.
  17. Remove the LH rear door sill trim panel.
    Note
    3x clips, 1x guide tab, Pull upward at the lower corner of sill trim to release clip from lower B-pillar, then remove the remaining clips by pulling away from the body.
  18. Remove the LH rear seat belt buckle.
    Note
    1x patch bolt, 15mm, 40 Nm, If the bolt is difficult to remove, Use an inductive heating tool to melt the adhesive patch material, Position the inductive heating tool coil around the bolt, then heat the bolt for 20 seconds, Allow the bolt to cool for 2 minutes, Discard after removal.
  19. Disconnect 60 seat back seat heater harness.
    Note
    1x connector.
  20. Remove nuts securing 60 seat back hinge bracket to body.
    Note
    2x nuts, 13mm, 18 Nm.
  21. Remove 60 seat back by lifting up on LH side and pulling inner pivot out of 40 seat back and set onto padded work surface.
  22. Remove the LH side trunk carpet clips from body studs under 2nd row seat cushion.
    Note
    2x clips, Newer vehicles may not be equipped with clips or the number of clips may vary.
  23. Lift trunk carpet off isofix bars on LH side.
    Note
    2x bars.
  24. Remove load floor.
    Note
    Use pull tab located at rear edge of panel.
  25. Remove trunk sill trim assembly.
    Note
    4x clips, Pull corner upward release clip on the end the away from body for remaining clips.
  26. Remove clips securing trunk garnish to body.
    Note
    2x push clips.
  27. Release trunk garnish from body.
    Note
    6x clips.
  28. Remove clips for LH trunk side trim.
    Note
    6x push clips, The number of clips on newer vehicles may vary.
  29. Disconnect LH trunk side trim puddle lamp connector.
    Note
    1x connector.
  30. Remove LH trunk side trim.
  31. Disconnect LH rear bodyside tail lamp assembly connector.
    Note
    1x connector.
  32. Disconnect LV charge port harness connector from charge port ECU.
    Note
    1x connector.
  33. Release LV harness edge clip from charge port closeout panel.
    Note
    1x clip.
  34. Remove charge port closeout panel.
    Note
    7x tabs, Work around perimeter with plastic trim tool to disengage tabs, May need to pry.
  35. Remove bolt securing charge port bracket and ground cable to body on LH side of trunk.
    Note
    1x bolt, 10mm, 6 Nm.
  36. Pull the manual release cable off of the hold down clip.
    Note
    Pull the cable up and away from the hold down clip or pull up vertically away from the charge port assembly.
  37. Release edge clip from charge port assembly .
    Note
    1x edge clip.
  38. Remove bolts securing charge port assembly to body.
    Note
    3x bolts, 10mm, 9 Nm.
  39. Pull the entire rear side of the harness assembly away from the body .
  40. Disconnect actuator connector.
    Note
    1x connector.
  41. Remove charge port latch sub-assembly from charge port.
    Note
    3x patch bolts, T20, 3.0 Nm, 2x alignment pins, Discard bolts after removal.

Install

  1. Install charge port latch sub-assembly to charge port.
    Note
    3x patch bolts, T20, 3.0 Nm, 2x alignment pins, Install new patch bolts.
  2. Connect latch actuator connector.
    Note
    1x connector.
  3. Move charge port assembly into position for installation.
  4. Install bolts securing charge port assembly to body.
    Note
    3x bolts, 10mm, 9 Nm.
    Warning
    Make sure the harness is routed out, and the adhesive pad with zip tie is properly mounted if it is installed. .
  5. Install edge clip on charge port cable assembly.
    Note
    1x edge clip.
  6. Insert manual release cable back into the locking tab.
    Note
    Push down on the release cable to secure it into the locking tab.
  7. Install charge port closeout panel.
    Note
    7x clips.
  8. Install LV harness edge clip to charge port closeout panel.
    Note
    1x clip.
  9. Connect LV charge port harness connector to charge port ECU.
    Note
    1x connector.
  10. Connect LH rear bodyside tail lamp assembly.
    Note
    1x connector.
  11. Install LH trunk side trim.
  12. Connect LH trunk side trim puddle lamp connector.
    Note
    1x connector.
  13. Install clips for LH trunk side trim.
    Note
    6x push clips, The number of clips on newer vehicles may vary.
  14. Install trunk garnish onto body.
    Note
    6x clips, Number of clips may vary on newer vehicles, Verify trunk seal is fully seated along garnish.
  15. Install clips securing trunk garnish to body.
    Note
    2x push clips.
  16. Install trunk sill trim assembly.
    Note
    4x clips, Align the latch with center slot then 2 locator to their slot and then press to secure the clips, Adjust the seal to overlap the trim.
  17. Install load floor.
  18. Close trunk.
  19. Align the trunk carpet over isofix bars on LH side.
    Note
    2x bars.
  20. Install the LH side trunk carpet clips onto body studs under 2nd row seat cushion.
    Note
    2x clips, Newer vehicles may not be equipped with clips or the number of clips may vary.
  21. Install 60 seat back to vehicle.
    Note
    Align center and outer pivot locations.
  22. Install nuts securing 60 seat back hinge bracket to body.
    Note
    2x nuts, 13mm, 18 Nm.
  23. Connect 60 seat back seat heater harness.
    Note
    1x connector.
  24. Install the LH rear seat belt buckle into vehicle.
    Note
    1x patch bolt, 15mm, 40 Nm, Position center seat belt under buckle, make sure the guide pin is aligned, Install new patch bolt.
  25. Fold the 60 seat in down position.
    Note
    Protect the seat cushion if necessary.
  26. Fold the 60 seat into vertical position.
    Note
    Remove seat cushion protection.
  27. Install the LH rear door sill trim panel.
    Note
    3x clips, 1x guide tab, Align the guiding tab to slot, Then push downward to install the clips after aligning them, Make sure the seal sits overlapping the trim. Newer vehicles may not be equipped with metal bracket and a foam insert will be present the bottom of trim piece.
  28. Fold the 60 seat in down position.
    Note
    Protect the seat cushion if necessary.
  29. Install new bolster plastic bracket to LH side bolster.
    Note
    2x clips, Install new bolster bracket.
  30. Install LH side bolster.
    Note
    1x clip, 1x tab, Align the bottom tab then push inward to install.
  31. Fold the 60 seat into vertical position.
    Note
    Remove seat cushion protection.
  32. Install HV cap to ancillary bay.
    Note
    1x cap.
  33. Remove logic cap and connect the HVC logic connector.
    Note
    1x connector, 1x cap, Align connector then pull the handle to locking position get connector fully seated.
  34. Install 12V cap to ancillary bay.
    Note
    1x cap.
  35. Connect 12V negative terminal.
    Note
    1x nut, 10mm, 6 Nm.
  36. Install 2nd row seat cushion and connect harness.
    Note
    2x connectors, 2x clips, Insert the seat belt buckles through the holes, Slide rear cushion inward then align front guide tabs to locking tabs, Make sure cushion is fully seated with push & pull test near clips.
  37. Move RH front seat to original position.
  38. Move LH front seat to original position.
  39. Install rear apron.
    Note
    12x clips, If present untuck cut loop label and make sure it is still visible after apron is installed, Later builds may not have label.
  40. Close hood.
  41. Raise all the windows.
  42. Close all four doors.
