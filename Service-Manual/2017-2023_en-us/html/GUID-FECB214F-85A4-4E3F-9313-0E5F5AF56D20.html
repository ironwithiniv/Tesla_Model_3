Frame - Back Rest - Front Passenger Seat (Remove and Replace)

Correction code 13043502 1.32 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-10-29: Removed the steps about removing and installing the recliner motor.
Warning
Seat base edges are sharp and can cause personal injury. Wear cut resistant gloves when removing the seat from the vehicle, and while performing procedures that involve work on or near the seat base.
Parent topic: 1304 - Front Seat Assemblies and Hardware

Torque Specifications

Table 1. Torque Specifications: Frame - Back Rest - Front Passenger Seat (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts that attach the LH and RH seat back frame to the seat cushion frame
43 Nm (31.7 lbs-ft)
  • Torx T50 socket
Replace 1128435-00-C

Remove

  1. Remove the 2nd row seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  2. Remove the front passenger seat assembly from the vehicle. See Seat Assembly - 1st Row - LH (Remove and Replace).
  3. Remove the front passenger seat back rest lumbar support. See Lumbar Support - Back Rest - Front Passenger Seat (Remove and Replace).
  4. Remove the tabs that attach the plastic insulators to the front passenger seat frame, and then remove the plastic insulators.
  5. Remove the LH and RH headrest post guides from the seat back frame. See Post Guide - Headrest - Front Passenger Seat (Remove and Replace).
  6. Remove and discard the clip that attaches the recliner tube to the frame.
  7. Use a rubber hammer to tap the recliner tube where the clip was located earlier, and then remove the tube from the frame.
    Note
    The removal of the tube might require several taps with the rubber hammer in order to get the tube out of the seat.
  8. Remove and discard the bolts that attach the LH and RH seat back frame to the seat cushion frame.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket
  9. Rotate the frame away from the cushion frame, and then lift the back rest frame straight up to remove it from the seat assembly.

Install

  1. Position the front passenger seat back rest frame onto the seat assembly for installation.
  2. Install new bolts that attach the LH and RH seat back frame to the seat cushion frame.
    43 Nm (31.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket
  3. Install the recliner tube into the seat back frame, through the recliner motor, and to the other side of the frame.
    Note
    Use the rubber hammer to tap the recliner tube so that the tube extends 16mm out of the seat back frame.
  4. With assistance, install a new clip onto the recliner tube.
    Note
    Use a 12mm deep socket and rubber hammer to tap the clip onto the recliner tube. Have an assistant use another hammer at the other end of the tube to oppose the tapping.
  5. Install the LH and RH headrest post guides to the seat back frame. See Post Guide - Headrest - Front Passenger Seat (Remove and Replace).
  6. Install the tabs that attach the plastic insulators to the front passenger seat frame, and then remove the plastic insulators.
  7. Install the front passenger seat back rest lumbar support. See Lumbar Support - Back Rest - Front Passenger Seat (Remove and Replace).
  8. Install the front passenger seat assembly to the vehicle. See Seat Assembly - 1st Row - LH (Remove and Replace).
  9. Install the 2nd row seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
