Actuator - Latch - Hood - Secondary (Remove and Replace)

Correction code 11355302 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2023-04-25: Corrected link to frunk manual release tool.
Parent topic: 1135 - Latches Strikers and Pinch Sensors

Remove

Note
If the hood latch does not open electronically, use the manual front trunk tool to open the hood. See TP_1130534-00-A_TOOL FRUNK RELEASE MANUAL MODEL 3 .
  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Remove the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  3. Remove the hood latch cover. See Cover - Hood Latch (Remove and Replace).
  4. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  5. Release the secondary hood latch actuator cable from the hood latch.
    Note
    Release the clip before removing the actuator cable from the latch arm.
  6. Disconnect the electrical connector from the secondary hood latch actuator.
  7. Release the clip that attaches the secondary hood latch actuator to the front end carrier.
  8. Remove the bolts that attach the secondary hood latch actuator to the front end carrier, and then remove the actuator from the vehicle.

Install

  1. Install the bolts that attach the secondary hood latch actuator to the front end carrier.
    5 Nm (3.7 lbs-ft)
  2. Connect the electrical connector to the secondary hood latch actuator.
  3. Install the clip that attaches the secondary hood latch actuator to the front end carrier.
  4. Install the secondary hood latch actuator cable to the hood latch.
    Note
    Secure the cable end to the latch arm, and then attach the clip.
  5. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  6. Install the hood latch cover. See Cover - Hood Latch (Remove and Replace).
  7. Install the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  8. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
