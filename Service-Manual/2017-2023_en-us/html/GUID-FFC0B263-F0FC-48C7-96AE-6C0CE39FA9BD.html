Door - Front - LH (Remove and Replace)

Correction code 10106002 1.32 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1010 - Body Panels

 Reuse

Remove

  1. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  2. Remove the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Install).
  3. Remove the LH front door inner belt seal. See Seal - Inner Belt - Front Door - LH (Remove and Replace).
  4. Remove the LH front door outer belt seal. See Seal - Outer Belt - Front Door - LH (Remove and Replace).
  5. Remove the LH front window motor/regulator assembly. See Window Motor / Regulator Assembly - Front - LH (Remove and Replace).
  6. Remove the LH door exterior release handle. See Handle - Exterior Release - Door - Front - LH (Remove and Replace).
  7. Remove the LH front door latch. See Latch - Door - Front - LH (Remove and Replace).
  8. Remove the LH door mirror. See Mirror - Door - LH (Remove and Replace).
  9. Remove the button plugs from the bottom of the door.
  10. Remove the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  11. Disconnect the door wiring harness connectors at the LH body controller module.
  12. Release the wiring harness clip from the LH body controller module.
  13. Push the door wiring harness through the A-pillar bulkhead.
  14. Release all door harness clips.
  15. Push the wiring harness through the door bulkhead, and then remove the harness from the door.
  16. Remove the bolt that attaches the door check to the A-pillar.
    24 Nm (17.7 lbs-ft)
    CAUTION
    Unbolting the door check allows the door to swing freely beyond opening limits.
  17. Release the clips that attach the door check seal to the door, and then remove the seal.
  18. Remove the nuts that attach the door check inside the door, and then remove the door check from the door.
    10 Nm (7.4 lbs-ft)
  19. Loosen the hinge bolts, and then remove the lower bolts for each hinge.
    24 Nm (17.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
  20. Partially unthread the upper bolt for each hinge, and with assistance, lift the door away from the vehicle.

Install

CAUTION
If using this procedure to install an unpainted part, make sure to apply seam sealer to all seams prior to installing and painting the part. Refer to the Collision Repair manual for more information.
Tip
For instructions on how to align the front door, refer to Front Door Alignment.

Installation procedure is the reverse of removal, except for the following:

  • CAUTION

    Replace all patchbolts.

    Replace all nyloc nuts.

  • Install a new LH front door secondary seal on the new door. See Seal - Secondary - Front Door - LH (Remove and Replace).
  • Partially thread the upper bolt/nut for each hinge in the door so that the door can set on the hinges to install the lower bolt/nut.
  • Apply touch up paint to painted fasteners that were removed and reinstalled during this procedure.
  • After installing the door assembly, perform the following routines:
    1. Place the vehicle in Service Mode by using the touchscreen. See Service Mode.
    2. Touch Service Wrench > Closures > Windows > Calibrate Windows.
    3. Exit Service Mode. See Service Mode.
