Inverter - Front Drive Unit (3DU) (Remove and Replace)

Correction code 3920010012 FRT 3.54 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 3920 - Front Drive Inverter

Remove

  1. Verify that the vehicle firmware is version feature/poppyseed-32-5 or later. Update the vehicle software if this is not the case.
  2. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  3. Open all doors and lower all windows.
  4. Move both front seats forward.
  5. Connect a laptop with Toolbox to the vehicle. See Toolbox (Connect and Disconnect).
    Note
    Upon successful connection, Service Mode Plus will be enabled, and the "Service Mode Plus" watermark will appear on the touchscreen.
  6. Enable Service Mode Plus. See Service Mode Plus.
  7. On the touchscreen, touch Service Mode Plus > High Voltage > Procedures > Front Drive INVERTER Replacement.
  8. Run PROC_PMF_X_STORE-DATA-BOOTvia Toolbox:(link)
  9. Run PROC_DIF_X_STORE-DATA-APPvia Toolbox:(link)
  10. Run PROC_VCFRONT_X_START-THERMAL-FILL-DRAIN-COOLANTvia Toolbox:(link)
  11. Disconnect the laptop with Toolbox from the vehicle. See Toolbox (Connect and Disconnect).
  12. Disconnect the LV battery power. See LV Power (Disconnect and Connect) (Modify).
  13. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  14. Perform the Vehicle HV Disablement Procedure. See Vehicle HV Disablement Procedure.
  15. Set the steering wheel straight ahead.
  16. Lock the steering wheel into position.
  17. Remove bolt securing steering column to steering gear assembly
    Note
    1x bolt, 13mm, 18 Nm, Discard fastener after removal
  18. Disconnect steering column from steering gear assembly
    Note
    Slide steering column upward from steering gear assembly to disconnect, pictures are shown for clarity of how to disconnect steering column from steering gear
  19. Release connection for FDU front subframe harness
    Note
    1x locking connector, Release the grey locking tab then press on the tab to release the connector
  20. Disconnect steering gear assembly connectors
    Note
    4x connectors, Release locking tabs
  21. Remove both front wheels. See Wheel Assembly (Remove and Install).
  22. Remove the front fascia. See Fascia - Front (Remove and Install).
  23. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  24. Remove bolt securing RH front wheel liner to skid plate.
    Note
    1x bolt, 10mm, 5 Nm
  25. Remove push clips securing lower rear edge of RH front wheel liner to vehicle for access to coolant hose
    Note
    3x push clips
  26. Remove both LH and RH bolts securing wheel liners to front skid plate
    Note
    2x blots, 10mm, 5 Nm
  27. Remove front skid plate
    Note
    4x bolts, EP10, 13 Nm, 2x tabs, Move forward to remove
  28. Remove bolt securing FDU HV harness to FDU
    Note
    1x bolt, 10mm, 10 Nm
  29. Disconnect FDU HV harness connector
    Note
    1x clip, Release locking tab and rotate the release lever up to disengage the connector, Do not force the release lever up, Ensure the alignment tabs on the FDU header are not damaged
  30. Remove bolt securing FDU ground strap to FDU
    Note
    1x bolt, 10mm, 6 Nm
  31. Release FDU ground strap harness clip from FDU
    Note
    1x clip
  32. Position coolant drain container underneath RH front of HV battery
  33. Disconnect PT return tube from FDU inverter inlet hose
    Note
    1x spring clip, 2x plugs, Plug hose end and fluid coupling
  34. Position coolant drain underneath RH front of FDU
  35. Disconnect FDU PT return hose from FDU heat exchanger
    Note
    1x spring clip, 2x plugs, Plug heat exchanger and FDU PT return hose end as quickly as possible to avoid coolant loss. Coolant loss greater than 1 L will require vacuum fill
  36. Remove the coolant drain container from underneath the vehicle.
  37. Lower vehicle partially and set lift onto locks
    Note
    Raise lift off locks, Then hold lock release lever to keep locks free while vehicle is lowered, Set vehicle to comfortable working height
  38. Release bolt securing LH front brake hose bracket to knuckle
    Note
    1x bolt, 10mm, 5 Nm
  39. Release bolt securing LH front wheel speed sensor to knuckle
    Note
    1x bolt, T30, 5 Nm
  40. Release LH front wheel speed sensor harness from knuckle
    Note
    2x clips，Sensor removed to one side
  41. Remove LH front brake caliper from knuckle
    CAUTION
    Make sure the brake caliper and hoses are not twisted when hanging the caliper or during reinstallation, as this can damage the brake hose.
    Note
    2x bolts, E18, 94 Nm, Discard fasteners after removal, Hang caliper off to the side with S-hook
  42. Remove nut securing front stabar end link to LH front strut and separate
    Note
    1x nyloc nut, 18mm, 98 Nm, Counter hold ball joint with T40, Discard fastener after removal, Separate end link from the strut, If required a pry bar can be used to relieve tension
  43. Remove nut and bolt securing LH front upper control arm to knuckle
    Note
    1x bolt, T50, 1x nyloc nut, 15mm, 56 Nm, Discard nut after removal, Release nut and compress ball joint downwards to release bolt
  44. Remove bolt and nut securing LH strut to lower fore link
    Note
    1x bolt, 21mm, 1x nut, 21mm, 106 Nm
  45. Release bolt securing RH front wheel speed sensor to knuckle
    Note
    1x bolt, 10mm, 5 Nm
  46. Release RH front wheel speed sensor harness from knuckle and move aside
    Note
    2x harness clips
  47. Release bolt securing RH front brake hose bracket to knuckle
    Note
    1x bolt, 10mm, 5 Nm
  48. Release RH front brake caliper from RH front knuckle
    CAUTION
    Make sure the brake caliper and hoses are not twisted when hanging the caliper or during reinstallation, as this can damage the brake hose.
    Note
    2x bolts, E18, 94 Nm, Discard fasteners after removal, Hang caliper off to the side with S-hook
  49. Release nut securing front stabar end link to RH front strut and separate
    Note
    1x nyloc nut, 18mm, 98 Nm, Counter hold ball joint with T40, Discard fastener after removal, Separate end link from the strut
  50. Release nut and bolt securing RH front upper control arm to knuckle
    Note
    1x bolt, T50, 1x nyloc nut, 15mm, 56 Nm, Discard nut after removal, Release nut and compress ball joint downwards to release bolt
  51. Release nut and bolt securing RH strut to RH front lower lateral link
    Note
    1x bolt, 21mm, 1x nut, 21mm, 106 Nm
  52. Raise the vehicle to a comfortable working height, and lower the lift onto locks.
    CAUTION

    Make sure there is an audible click of the locks on both sides before lowering, otherwise the vehicle may tilt to one side.

    Make sure that the doors are clear of surrounding objects.

  53. Position powertrain subframe lift underneath front of vehicle
  54. Connect air supply to subframe lifting tool
  55. Raise powertrain table and subframe fixture into position
    Note
    2x subframe datums, 1x FDU datum, Raise fixture until the front subframe is fully supported, Line up the two subframe datums and support arms, Continue to line up the FDU datum and FDU support arm, Raise and adjust arms as needed,
  56. Fully secure straps from fixture onto front subframe
  57. Remove bolts securing front end carrier to LH front subframe crash can assembly
    Note
    2x bolts, 13mm, 16 Nm
  58. Remove bolts securing front end carrier to RH front subframe crash can assembly
    Note
    2x bolts, 13mm, 16 Nm
  59. Remove bolt securing RH motor mount to RH motor mount bracket
    Note
    1x bolt, E18, 105 Nm
  60. Remove bolt securing LH motor mount to LH motor mount bracket
    Note
    1x bolt, E18, 105 Nm
  61. Remove bolts securing front subframe mid mounts to body
    Note
    2x bolts, 15mm, 50 Nm, Discard after removal
  62. Remove bolts securing front portion of front subframe to body
    Note
    2x bolts, 18mm, 72 Nm, Discard after removal
  63. Remove smaller bolts securing rear portion of front subframe to body
    Note
    2x bolts, 15mm, 50 Nm, Discard after removal
  64. Remove larger bolts securing rear portion of front subframe to body
    Note
    2x bolts, 21mm, 125 Nm, Discard after removal
  65. Lower front subframe assembly and front unit assembly from vehicle
    Note
    Keep an eye out for any components that could get caught while lowering
  66. Disconnect air supply from subframe lifting tool
  67. Remove subframe lifting tool from under vehicle
  68. Position fluid catcher under subframe and fixture assembly
    Note
    Position to catch all coolant loss, Use a foldable funnel as required for the next steps
  69. Release FDU inverter to oil cooler hose from the heat exchanger
    Note
    1x hose clip, Use a foldable funnel as required
  70. Release FDU inverter to oil cooler hose from inverter fluid coupling
    Note
    1x hose clip, Use a foldable funnel as required
  71. Release inverter to oil cooler hose clip from FDU
  72. Remove inverter to oil cooler hose from FDU
    Note
    Remove coolant plugs from each hose end if discarding
  73. Release FDU inverter inlet hose from 90deg fluid coupling
    Note
    1x spring clip, Use a foldable funnel as required
  74. Release clips securing FDU inverter inlet hose and remove hose
    Note
    2x clips
  75. Disconnect FDU inverter logic connector
    Note
    1x connector, Release locking tab then push handle downward
  76. Release the FDU harness clips (x2) from the inverter housing
  77. Remove front drive unit LH mount from front drive unit
    Note
    3x bolts, E14, 35 Nm + 55 degrees, Discard after removal
  78. Attach an Electrostatic Discharge (ESD) wrist strap to the front drive unit inverter housing.
  79. Remove label from phase cover
    Note
    Discard label after removal
  80. Remove bolts securing phase out cover
    Note
    2x bolts, EP10, 14 Nm
  81. Remove phase out cover
    Note
    Use a plastic trim tool to aid in removal, If phase out cover or O-rings are damaged then replace with a new unit
  82. Release fasteners securing inverter to the 3 phase lugs
    Note
    3x bolts, 10mm, 11.5 Nm, Do not drop fasteners, Fasteners can be re-used
  83. Remove bolts securing the FDU inverter to gearbox assembly
    Note
    12x bolts, EP10, 12.5 Nm, Fasteners can be re-used
  84. Remove inverter and gasket from drive unit
    Note
    1x gasket, Carefully remove inverter, Take care and do not damage the circuit board when handling, Drain inverter of coolant, Do not damage or place face down on HV lugs, Careful not to damage the PCBA during removal
  85. Place drive inverter on ESD mat
    Note
    Carefully place inverter on ESD safe mat, Do not place inverter facing downwards on the circuit board as it is fragile, Do not damage or place face down on HV lugs, Careful not to damage the PCBA during removal
  86. Remove ESD wrist strap from inverter
  87. If the pyrotechnic fuse of the drive unit inverter has not been actuated, dispose of the drive unit inverter as hazardous material. If the pyrotechnic fuse has been actuated, follow the normal regulations for waste disposal.
    Note
    If Autodiag falsely indicated that the pyrotechnic fuse was actuated, but visual check confirms that it was not activated, list the serial number of the drive unit inverter in Autodiag using 'Report an Issue'.

Install

  1. Prepare new drive inverter
    Note
    Prepare new drive inverter, Save packaging to MRB old drive inverter, Remove any red protective covers，Refer to https://toolbox.teslamotors.com/articles/6865600 for instruction of installing 2PO inverter to the 3DU vehicle
  2. Secure ESD strap to new inverter housing
  3. Clean mating surfaces of phase lugs
    Note
    Clean with IPA, Allow 1 min to dry, Do not leave any debris on the mating surfaces
  4. Inspect gap pad of the new inverter
    Note
    Verify the gap pad is fully attached and covering the discharge resistor array, No resistors should be visible, Gap pad should be clean of debris and evenly adhered. Replace gap pad if it does not match the criteria
  5. Position inverter with gasket to drive unit
    Note
    1x gasket, 2x guide pins, Make sure the 3 phase cables and guides align during installation
  6. Install fasteners securing inverter to gearbox assembly
    Note
    12x bolts, EP10, 12.5 Nm, Install hand tight, Install new fasteners, Torque at a later step
  7. Torque fasteners securing FDU inverter to FDU
    Note
    12x bolts, EP10, 12.5 Nm, Torque two fasteners nearest alignment dowels first
  8. Install fasteners securing inverter to the 3 phase lugs
    Note
    3x bolts, 10mm, 11.5 Nm, Fasteners can be re-used, Do not drop fasteners, Use a magnet as needed, If re-using fastener torque to 11.5 Nm. If installing new fasteners torque to 12.5 Nm, Reverse 180 degrees, then torque to 5 Nm + 40 degrees, With new fasteners, perform run down sequence to prevent under torque
  9. Install phase out cover
    Note
    If phase out cover or O-rings are damaged then replace with a new unit, Fully seat cover
  10. Install bolts securing phase out cover
    Note
    2x bolts, EP10, 14 Nm
  11. Install new 3 phase access label
    Note
    Verify label is properly seated
  12. Remove ESD wrist strap from inverter
  13. Take old inverter and prepare for MRB, Label properly for return or disposal
    Note
    Use ESD wrist strap, Label inverter for MRB and return to packaging, Secure any protective red caps, Return or dispose of packaging through proper channels, Label the part as MRB
  14. Install leak test adapter plug to 12V connector at inverter
  15. Install leak test adapter to HV connector
  16. Connect regulator to adapter at HV connector
  17. Close both valves on the regulator test tool
  18. Connect regulator to air supply
  19. Turn on regulator and open valve closest to regulator
  20. Set regulator to 1 psi
  21. Open 2nd valve to inject air into penthouse
    Note
    Close valve when pressure reaches 1 psi and stable
  22. Wait 45 seconds for pressure to settle
  23. Record start pressure valve
  24. Wait 60 seconds for test
  25. Record end pressure valve
    Note
    If pressure did not drop more than 0.04 psi, continue to next step. If pressure dropped more than 0.04 psi, then inspect for leaks.
  26. Disconnect air supply from regulator tool
  27. Disconnect regulator from leak test adapter at HV connector
  28. Remove leak test adapter from HV connector
  29. Remove leak test adapter plug from 12V connector at inverter
  30. Install the front drive unit LH mount to the front drive unit
    Note
    3x bolts, E14, 35 Nm + 55 degrees, Install new bolts
  31. Secure FDU harness clips (x2) onto the inverter housing.
  32. Connect FDU inverter logic connector.
    Note
    Fully seat connector then secure locking tab
  33. Position FDU inverter inlet hose and remove hose and secure clips
    Note
    2x clip
  34. Secure FDU inverter inlet hose to 90deg fluid coupling
    Note
    1x hose clip, Perform push-pull-push test
  35. Install inverter to oil cooler hose onto FDU
    Note
    1x clip
  36. Connect FDU inverter inlet hose to fluid coupling
    Note
    1x spring clip, 1x plug, Remove plug from fluid coupling, Perform push-pull-push test to make sure hose is fully engaged. Coolant loss greater than 1 L will require vacuum fill
  37. Connect FDU inverter inlet hose to heat exchanger
    Note
    1x spring clip, Remove plug from heat exchanger, Perform push-pull-push test to make sure hose is fully engaged. Coolant loss greater than 1 L will require vacuum fill
  38. Position lifting tool and subframe under vehicle for installation
  39. Connect air supply to subframe lifting tool
  40. Position lifting tool and subframe and FDU assembly to under vehicle for installation
    Note
    Raise front subframe assembly and line up into vehicle, Guide the motor mount bushings into the mount isolators, Verify the front struts are also positioned correctly over the front axles
  41. Thread in all bolts securing front subframe to body
    Note
    2x bolts, 21mm, 125 Nm, 2x bolts, 15mm, 50 Nm, 2x bolts, 18mm, 72 Nm, 2x bolts, 15mm, 50 Nm, Line up with markings and start threads for all fasteners, Install new fasteners, Torque at later step
  42. Loosely install bolts securing front end carrier to RH front subframe crash can assembly
    Note
    2x bolts, 13mm, 16 Nm
  43. Loosely install bolts securing front end carrier to LH front subframe crash can assembly
    Note
    2x bolts, 13mm, 16 Nm
  44. Position subframe to marked location
    Note
    Use marks on bushings to position subframe, Lower or raise powertrain table as needed
  45. Torque larger bolts securing rear portion of front subframe to body
    Note
    2x bolts, 21mm, 125 Nm
  46. Torque smaller bolts securing rear portion of front subframe to body
    Note
    2x bolts, 15mm, 50 Nm
  47. Torque bolts securing front portion of front subframe to body
    Note
    2x bolts, 18mm, 72 Nm
  48. Torque bolts securing front subframe mid mounts to body
    Note
    2x bolts, 15mm, 50 Nm
  49. Torque bolts securing front end carrier to RH front subframe crash can assembly
    Note
    2x bolts, 13mm, 16 Nm
  50. Torque bolts securing front end carrier to LH front subframe crash can assembly
    Note
    2x bolts, 13mm, 16 Nm
  51. Install bolt securing RH motor mount to RH motor mount bracket
    Note
    1x bolt, E18, 105 Nm, Use the FDU support stands to line up hole as needed
  52. Install bolt securing LH motor mount to LH motor mount bracket
    Note
    1x bolt, E18, 105 Nm, Use the FDU support stands to line up hole as needed
  53. Release fixture straps from front subframe
  54. Lower subframe lifting tool from vehicle
  55. Disconnect air supply from subframe lifting tool
  56. Remove subframe lifting tool from under vehicle
  57. Secure FDU ground strap harness clip to FDU
    Note
    1x clip
  58. Install bolt securing FDU ground strap to FDU
    Note
    1x bolt, 10mm, 6 Nm
  59. Install FDU HV harness connector to FDU
    Note
    1x connector, Install HV connector lever lock to FDU HV cable connector, Align connector to FDU then remove HV connector lever lock before fully latching connector, Use one hand to support the connector while other latching locking tab, Once installed, verify that the latch is not damaged and fully secured in the latched position
  60. Install bolt securing FDU HV harness to FDU
    Note
    1x bolt, 10mm, 10 Nm
  61. Position coolant drain container underneath RH front of HV battery
  62. Connect PT return hose
    Note
    1x spring clip, Remove plugs, Perform push-pull test to verify hoses are fully engaged. Loss of coolant greater than 1L requires coolant vacuum fill
  63. Position coolant drain underneath RH front of FDU
  64. Install FDU PT return hose to FDU heat exchanger
    Note
    1x spring clip, 1x plug, Perform push-pull-push test to make sure hose is fully engaged, Installing chiller side of hose first will eliminate coolant loss when making connection to supermanifold
  65. Remove coolant drain container from underneath vehicle
  66. Lower vehicle partially and set onto locks
    Note
    Raise lift off locks, then hold lock release lever to keep locks free while vehicle is lowered, Set vehicle to comfortable working height
  67. Loosely install bolt and nut securing RH strut to RH front lower lateral link
    Note
    1x bolt, 21mm, 1x nut, 21mm, 106 Nm, Torque at later step
  68. Position the RH upper control arm to the knuckle and install nut and bolt
    Note
    1x bolt, T50, 1x nyloc nut, 15mm, 56 Nm, Install new nyloc nut, Compress ball joint downwards to install bolt
  69. Position front stabar end link onto RH front strut and secure nut
    Note
    1x nyloc nut, 18mm, 98 Nm, Counter hold ball joint with T40, Install new fastener, Prybar can be used to relieve tension
  70. Install RH front brake caliper onto knuckle
    Note
    2x bolts, E18, 94 Nm, Install new bolts
  71. Install bolt securing RH front brake hose bracket to front knuckle
    Note
    1x bolt, 10mm, 5 Nm
  72. Install RH front wheel speed sensor harness to knuckle
    Note
    2x harness clips
  73. Install bolt securing RH wheel speed sensor to knuckle
    Note
    1x bolt, T30, 5 Nm
  74. Loosely install bolt and nut securing LH strut to LH front lower lateral link
    Note
    1x bolt, 21mm, 1x nut, 21mm, 106 Nm, Torque at later step
  75. Position the LH upper control arm to knuckle and install nut and bolt
    Note
    1x bolt,T50,1x nyloc nut,15mm,56 Nm, Install new nyloc nut
  76. Position front stabar end link onto LH front strut and secure nut
    Note
    1x nyloc nut, 18mm, 98 Nm, Counter hold ball joint with T40, Install new fastener, Prybar can be used to relieve tension
  77. Install LH front brake caliper onto LH front knuckle
    Note
    2x bolts, E18, 94 Nm, Install new bolts
  78. Install bolt securing LH front brake hose bracket to LH front knuckle
    Note
    1x bolt, 10mm, 5 Nm
  79. Install LH front wheel speed sensor harness to knuckle
    Note
    2x harness clips
  80. Install bolt securing LH front wheel speed sensor to knuckle
    Note
    1x bolt, T30, 5 Nm
  81. Install the front fascia. See Fascia - Front (Remove and Install).
  82. Raise the vehicle to a comfortable working height, and lower the lift onto locks.
    CAUTION

    Make sure there is an audible click of the locks on both sides before lowering, otherwise the vehicle may tilt to one side.

    Make sure that the doors are clear of surrounding objects.

  83. Remove bolt securing RH front rotor to knuckle
    Note
    1x bolt, 10mm, 5 Nm
  84. Install hub jack adapter onto RH front hub
    Note
    5x lug nuts, 21mm
  85. Position and raise support stand to simulate RH front suspension at ride height
  86. Measure from bottom of fender to center of axle as a check to make sure RH suspension is set close to ride height
    Note
    Placeholder specification is 423mm, Be wary of lifting vehicle up from the rack while raising pole jack, Take caution
  87. Torque bolt and nut securing RH strut to RH front lower lateral link
    Note
    1x bolt, 21mm, 1x nut, 21mm, 106 Nm, Mark with paint pen
  88. Remove support stand from underneath RH front suspension
  89. Remove hub jack adapter from RH front hub
    Note
    5x lug nuts, 21mm, Gently tap with a dead blow to aid in removal
  90. Install bolt securing RH front rotor to knuckle
    Note
    1x bolt, 10mm, 5 Nm
  91. Install RH front wheel
    Note
    5x nuts, 21mm, 175 Nm, Start lug nuts by hand before using power tool, Torque at later step
  92. Remove bolt securing LH front rotor to knuckle
    Note
    1x bolt, 10mm, 5 Nm
  93. Install hub jack adapter onto LH front hub
    Note
    5x lug nuts, 21mm, Hand tighten
  94. Position and raise support stand to simulate LH front suspension at ride height
  95. Measure from bottom of fender to center of axle as a check to make sure LH suspension is set close to ride height
    Note
    Specification is 423mm, Be wary of lifting vehicle up from the rack while raising pole jack, Take caution
  96. Torque bolt and nut securing LH strut to LH front lower lateral link
    Note
    1x bolt, 21mm, 1x nut, 21mm, 106 Nm, Mark with paint pen
  97. Remove support stand from underneath LH front suspension
  98. Remove hub jack adapter from LH front hub
    Note
    5x lug nuts, 21mm,Gently tap with a dead blow to aid in removal
  99. Install bolt securing LH front rotor to knuckle
    Note
    1x bolt, 10mm, 5 Nm
  100. Install LH front wheel
    Note
    5x nuts, 21mm, 175 Nm, Start lug nuts by hand before using power tool
  101. Install push clips securing lower rear edge of RH front wheel liner to vehicle
    Note
    3x push clips
  102. Install bolt securing RH front wheel liner to skid plate
    Note
    1x bolt, 10mm, 5 Nm, Apply Loctite 222 onto front wheel liner bolts
  103. Install front skid plate
    Note
    4x bolts, EP10, 13 Nm, 2x tabs, Position and move backward to installation
  104. Apply Loctite 222 onto front wheel liner bolts and install bolts securing front wheel liners to front skid plate
    Note
    2x blots, 10mm, 5 Nm, Apply Loctite 222 onto front wheel liner bolts
  105. Install the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  106. Install both front wheels. See Wheel Assembly (Remove and Install).
  107. Connect FDU front subframe harness
    Note
    1x connector, Engage locking tab
  108. Connect steering gear assembly
    Note
    4x connectors, Secure locking tabs
  109. Connect steering column to steering gear assembly
    Note
    Slide steering column downward to install steering gear assembly, Ensure the intermediate shaft is aligned and fully seated, pictures are shown for clarity of how to connect steering column to steering gear
  110. Install bolt securing steering column to steering gear assembly
    Note
    1x bolt, 13mm, 18 Nm, Install new bolt
  111. Perform a cooling system vacuum refill. See Cooling System - Vacuum Refill (Test/Adjust).
  112. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  113. Install the 2nd row seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  114. Connect first responder loop and LV battery
    Note
    1x connector, Engage locking tab
  115. Connect the low-voltage battery maintainer-charger
    Note
    Release positive terminal cover, Secure positive terminal to jump post, Secure negative terminal to bolt located between brake fluid reservoir and front trunk, Connect maintainer to power supply, To avoid damaging the vehicle DO NOT allow positive cable to make contact with other metal components, Never have a float charger and the LV battery simultaneously connected for any extended period of time
  116. Remove the steering wheel holder.
  117. Remove the steering wheel level from the vehicle.
  118. Move both front seats to original position.
  119. Connect a laptop with Toolbox to the vehicle. See Toolbox (Connect and Disconnect).
    Note
    Upon successful connection, Service Mode Plus will be enabled, and the "Service Mode Plus" watermark will appear on the touchscreen.
  120. Select "Stop Fluid Fill /Drain" through UI
  121. Select "Run" through UI to Stop Fluid Fill /Drain
    Note
    Allow routine to complete, ensure routine is successful,then select "close" through UI
  122. Select "Restore Bootloader Data " through UI
  123. Select "Run" through UI to Restore Bootloader Data
    Note
    Allow routine to complete, ensure routine is successful,then select "close" through UI
  124. Select "CAN Redeploy" through UI
  125. Select "Run" through UI to run CAN Redeploy
    Note
    Allow routine to complete, ensure routine is successful
  126. Select "Restore Application Data" through UI
  127. Select "Run" through UI to Restore Application Data
    Note
    Allow routine to complete, ensure routine is successful,then select "close" through UI
  128. Select " Coolant Air Purge " through UI
  129. Select "Run" through UI to run Coolant Air Purge
    Note
    Allow routine to complete, ensure routine is successful,then select "close" through UI
  130. Disconnect the low-voltage battery maintainer-charger
  131. Select " Thermal system Test " through UI
  132. Select "Run" through UI to run Thermal system Test
    Note
    Allow routine to complete, ensure routine is successful,then select "close" through UI
  133. Inspect coolant level and top off as necessary
    Note
    Ensure that fluid level is at Max line
  134. Install the coolant bottle cap.
  135. Manually engage the hood latch.
    Note
    If the hood is open, or if the hood latch is not manually engaged, the vehicle speed will be limited and the resolver learn routine will fail.
  136. Place stanchions around the vehicle.
  137. Raise the vehicle to a comfortable working height, and lower the lift onto locks.
    CAUTION

    Make sure there is an audible click of the locks on both sides before lowering, otherwise the vehicle may tilt to one side.

    Make sure that the doors are clear of surrounding objects.

  138. Press the brake pedal to ensure the drive rails are on.
  139. Select " Resolver Error Learn " through UI
  140. Select "Run" through UI to run Resolver Error Learn
    Note
