Assembly - Brake Lines - Master Cylinder to HCU (RHD) (Remove and Replace)

Correction code 3303020022 FRT 4.26 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2024-06-17: Added step to perform test drive and add correction code 00040100 as a separate activity to the Service Visit.
Parent topic: 3303 - Brake Pipes and Hoses

Remove

  1. Remove the steering column. See Steering Rack (Dual Motor) (RHD) (Remove and Replace).
  2. Remove the wiper module. See Wiper Module (RHD) (Remove and Replace).
  3. Remove the fresh air intake assembly. See Fresh Air Intake - HVAC (Remove and Replace).
  4. Remove the LV battery. See LV Battery (Remove and Replace).
  5. Remove the shock tower brace. See Brace - Shock Tower (Remove and Replace).
  6. Remove the front controller. See Module - Body Controller (Remove and Replace).
  7. Disconnect the steering gear assembly connectors (x4).
  8. Disconnect FDU front subframe harness connector.
  9. Remove washer hose from LH front frame rail area
    Note
    1x clip
  10. Release front harness clips around LH front frame rail area
    Note
    6x clips
  11. Remove front harness ground terminal at LH front shock tower
    Note
    1x bolts, 10mm, 8 Nm,
  12. Remove LH harness bracke clip and remove from vehicle
    Note
    2x clips
  13. Remove bolts securing front harness bracke from vehicle
    Note
    2x bolts,10mm,9 Nm
  14. Release clips securing harness behind LH shock tower
    Note
    4x clips
  15. Position fluid catcher under underneath vehicle
  16. Place absorbent material underneath brake booster and reservoir area
  17. Remove fluid from brake fluid reservoir
  18. Disconnect forward brake line from brake booster
    Note
    1x nut, 12mm, 16 Nm
  19. Disconnect rear brake line from brake booster
    Note
    1x nut, 12mm, 16 Nm
  20. Disconnect the hydraulic control unit connector
    Note
    1x connector, Disengage locking tab and pull up on connector to release
  21. Remove RH front brake line tube nut from hydraulic control unit
    Note
    1x nut, 12mm, 16 Nm
  22. Remove the LH rear brake line tube nut from hydraulic control unit
    Note
    1x nut, 12mm, 16 Nm
  23. Remove RH rear brake line tube nut from hydraulic control unit
    Note
    1x nut, 12mm, 16 Nm
  24. Remove LH front brake line tube nut from hydraulic control unit
    Note
    1x nut, 12mm, 16 Nm
  25. Remove the master cylinder secondary pipe nut from hydraulic control unit
    Note
    1x nut, 12mm, 16 Nm
  26. Remove the master cylinder primary pipe nut from hydraulic control unit
    Note
    1x nut, 12mm, 16 Nm
  27. Remove bolts securing hydraulic control unit bracket to frame rail
    Note
    2x bolts, 10mm, 10 Nm
  28. Remove hydraulic control unit and bracket from vehicle
    Note
    2x tabs
  29. Place absorbent material below car computer coolant hose connection points to collect any spilled coolant
  30. Disconnect outer coolant hose from car computer mount
    Note
    1x spring clip, Plug hose
  31. Disconnect inner coolant hose to car computer mount and remove coolant hoses from car computer
    Note
    1x spring clip, Plug hose
  32. Install car computer coolant plug
    Note
    1x coolant plug
  33. Install plugs to car computer coolant hoses
    Note
    2x plugs, Do not need to engage spring clips
  34. Release primary and secondary pipe from bundle clip
  35. Release LH bundle clip from body
    Note
    Be careful with water pipe during disassembly
  36. Release primary and secondary pipe from LH bundle clip
  37. Release RH bundle clip from body
    Note
    Be careful with water pipe during disassembly
  38. Release primary and secondary pipe from RH bundle clip
  39. Release primary and secondary pipe from bundle clips
    Note
    2x clips
  40. Remove brake line bundle from vehicle
    Note
    Move right side of pipeline upwards, pass through wiring harness, and take it out from right side

Install

  1. Install brake line bundle to vehicle
  2. Install primary and secondary pipe to bundle clips
    Note
    2x clips
  3. Install primary and secondary pipe to RH bundle clip
  4. Install RH bundle clip to body
    Note
    Be careful with water pipe during disassembly
  5. Install primary and secondary pipe to LH bundle clip
  6. Install LH bundle clip to body
    Note
    Be careful with water pipe during disassembly
  7. Install primary and secondary pipe to bundle clip
  8. Remove plugs to car computer coolant hoses
    Note
    2x plugs, Do not need to engage spring clips
  9. Remove coolant plug from car computer
    Note
    1x coolant plug
  10. Install inner coolant hose to car computer mount
    Note
    1x spring clip, Plug hose
  11. Install outer coolant hose to car computer mount
    Note
    1x spring clip, Plug hose
  12. Remove absorbent material
  13. Install hydraulic control unit and bracket to vehicle
    Note
    2x tabs
  14. Install bolts securing hydraulic control unit bracket to frame rail
    Note
    2x bolts, 10mm, 10 Nm
  15. Install the master cylinder primary pipe nut to hydraulic control unit
    Note
    1x nut, 12mm, 16 Nm
  16. Install the master cylinder secondary pipe nut to hydraulic control unit
    Note
    1x nut, 12mm, 16 Nm
  17. Move master cylinder lines into position for installation
  18. Install LH front brake line tube nut to hydraulic control unit
    Note
    1x nut, 12mm, 16 Nm
  19. Install RH front brake line tube nut to hydraulic control unit
    Note
    1x nut, 12mm, 16 Nm
  20. Install RH rear brake line tube nut to hydraulic control unit
    Note
    1x nut, 12mm, 16 Nm
  21. Install LH rear brake line tube nut to hydraulic control unit
    Note
    1x nut, 12mm, 16 Nm
  22. Install RH front brake line tube nut to hydraulic control unit
    Note
    1x nut, 12mm, 16 Nm
  23. Connect the hydraulic control unit connector
    Note
    1x connector, Gently push connector downward, Engage locking tab
  24. Connect rear brake line into brake booster
    Note
    1x nut, 12mm, 16 Nm
  25. Connect forward brake line into brake booster
    Note
    1x nut, 12mm, 16 Nm
  26. Remove absorbent material from underneath brake booster and reservoir area
  27. Remove fluid catcher from underneath vehicle
  28. Secure clips securing harness behind LH shock tower
    Note
    4x clips
  29. Install bolts securing front harness bracke from vehicle
    Note
    2x bolts,10mm,9 Nm
  30. Secure LH harness bracke clips to vehicle
    Note
    2x clips
  31. Secure front harness clips around LH front frame rail area
    Note
    6x clips
  32. Secure washer hose to LH front frame rail area
    Note
    1x clip
  33. Install bolts securing front harness ground terminal at LH front shock tower
    Note
    1x bolts, 10mm, 8 Nm,
  34. Connect FDU front subframe harness
    Note
    1x connector
  35. Connect steering gear assembly connectors
    Note
    4x connectors
  36. Install the front body controller. See Module - Body Controller (Remove and Replace).
  37. Install the shock tower brace. See Brace - Shock Tower (Remove and Replace).
  38. Install the LV battery. See LV Battery (Remove and Replace).
  39. Install the fresh air intake assembly. See Fresh Air Intake - HVAC (Remove and Replace).
  40. Install the wiper module. See Wiper Module (RHD) (Remove and Replace).
  41. Install the steering column. See Steering Rack (Dual Motor) (RHD) (Remove and Replace).
  42. Bleed the brake fluid. See Brake Fluid Bleed/Flush (Maintenance).
  43. Perform a road test using a series of aggressive stops to make sure there is proper pedal feel and brake performance.
    Note
    Add test drive correction code 00040100 as a separate activity to the Service Visit.
