Actuator and Cable Assembly - Hood Latch (Remove and Replace)

Correction code 1133040102 1133040101 FRT 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
  • 2026-02-19: Released new procedure.
  1. Open LH front door
  2. Lower LH front window
  3. Open hood
  4. Remove rear underhood apron
    Note
    14x clips
  5. Remove fresh air gutter assembly
    Note
    3x clips
  6. Remove access panel from frunk assembly
    Note
    3x clips, 1x connector, 3x guide tabs, Frunk safety switch, Grasp access panel at top and pull it back to release clips, Disconnect switch
  7. Remove bolts securing frunk assembly from body
    Note
    4x bolts, 10mm, 5 Nm
  8. Remove frunk assembly from vehicle
    Note
    8x clips, 3x location pins, Replace any clips if broken or missing
  9. Release hood latch actuator cable from hood latch assembly
    Note
    1x cable, Release plastic tabs securing cable and remove cable end from latch arm
  10. Disconnect hood latch actuator
    Note
    1x connector
  11. Remove hood latch actuator from front end carrier
    Note
    2x bolts, 10mm, 5 Nm
  12. Install hood latch actuator onto front end carrier
    Note
    2x bolts, 10mm, 5 Nm
  13. Connect hood latch actuator
    Note
    1x connector
  14. Install hood latch actuator cable to hood latch assembly
    Note
    1x cable, Engage cable clips and install cable end to latch arm
  15. Position frunk assembly to vehicle
    Note
    8x clips, 3x locator pins, Ensure clips are aligned at thermal beam, Replace any clips if broken or missing
  16. Install bolts securing frunk assembly
    Note
    4x bolts, 10mm, 5 Nm, Number of bolts may vary depending on build date
  17. Install access panel to frunk assembly
    Note
    3x clips, 1x connector, Frunk safety switch, 3x guide tabs, Align 3x tabs then push forward to secure clips
  18. Install fresh air gutter assembly
    Note
    3x clips
  19. Install rear underhood apron
    Note
    14x clips, Hold rear wall of frunk to keep from flexing while engaging front clips
  20. Close hood
  21. Raise LH front window
  22. Close LH front door
