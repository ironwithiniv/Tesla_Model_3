Steering Gear (LHD) (Remove and Replace)

Correction code 3201010012 FRT 0.90 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-09-22: Updated the procedure to remove and install the steering gear without removing the cooling fan module assembly.

Remove

  1. Remove the steering gear. See Steering Gear (LHD) (Remove and Install).

Install

  1. Mark the threads on the new LH inner tie rod to the nut.
    Note
    Mark the original location to help reinstall to a similar position.
  2. Rotate the tie rod counter clockwise to remove the LH outer tie rod end from the new steering gear assembly.
  3. With assistance, fully disperse the pressure of the steering rack to the RH side.
    Tip
    Use of the following tool(s) is recommended:
    • Combination 12pt 15mm wrench
  4. Position the RH side of the steering gear assembly into the underhood storage area, and then slide the LH side into the vehicle. Position the steering rack so that the bolt holes are aligned.
  5. Loosely install the inner bolts (x2) that attach the steering gear assembly to the front subframe.
    Tip
    Use of the following tool(s) is recommended:
    • Ratchet/torque wrench
    • 6 in extension
    • 18 mm socket
    • 3 in extension
  6. Loosely install the outer bolts (x2) that attach the steering gear assembly to the front subframe.
    Tip
    Use of the following tool(s) is recommended:
    • Flex head ratchet/flex head torque wrench
    • 11 in extension
    • 15 mm socket
  7. Tighten the inner bolts that attach the steering gear assembly to the front subframe.
    75 Nm (55.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Ratchet/torque wrench
    • 6 in extension
    • 18 mm socket
    • 3 in extension
  8. Tighten the outer bolts that attach the steering gear assembly to the front subframe.
    47 Nm (34.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Flex head ratchet/flex head torque wrench
    • 11 in extension
    • 15 mm socket
  9. Connect the steering gear assembly connectors (x4).
  10. Connect the clip and the connector that attach the front drive unit front subframe harness to the vehicle.
  11. Slide the electric steering column downward to install it to the steering gear assembly.
  12. Install the new bolt that attaches the steering gear assembly to the electric steering column.
    18 Nm (13.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
    • Ratchet/torque wrench
  13. Install the clip that secures the radiator inlet hose to the vehicle.
  14. Release the radiator assembly and move it back to the normal position.
  15. Install and hand-tighten the LH and RH bolts (x2) that attach the bottom of the condenser fan module to the ankle catcher.
  16. Torque the bolts that attach the bottom of the condenser fan module to the ankle catcher.
    10 Nm (7.4 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • 8 mm socket
    • Ratchet/torque wrench
  17. Install the underhood storage unit reinforcement assembly to the cooling fan assembly.
  18. Install the bolts (x2) that attach the underhood storage unit reinforcement bracket to the cooling fan, and slide the underhood storage unit reinforcement rearward to remove it from the cooling fan module assembly.
    16 Nm (11.8 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
    • 4 in extension
    • Cordless 1/4in Dr Ratchet
  19. Install the harness clips (x3) to the underhood storage unit reinforcement assembly.
  20. Connect the LV power. See LV Power (Disconnect and Connect) (Modify).
  21. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  22. Remove the steering wheel holder and turn the steering wheel to the center position.
  23. Enable Service Mode. See Service Mode.
  24. On the touchscreen, select Service mode > Chassis > Alignment & Tires and inspect whether the steering wheel illustration is approximately at 0 degrees.
    Note
    If the steering wheel is off by ±360 degrees, reinstall the steering column and steering gear assembly accordingly.
  25. Reinstall the vehicle firmware. See Software Reinstall - Touchscreen.
  26. Raise the vehicle fully and lower the lift onto locks.
  27. Rotate the LH tie rod end clockwise with the exact number of turns noted during removal to install it to the steering gear assembly.
    Note
    Align the LH front tie rod end to the original location marked on threads.
  28. Install the new nuts (x2) that attach the LH and the RH front tie rod ends to the LH and the RH front suspension knuckles to install the both tie rod ends to the knuckles.
    180 Nm (132.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Cordless 1/2in Dr Impact
    • 22 mm deep socket
    • 1/2 in to 3/4 in adapter - 1717365-00-A
    • Ratchet/torque wrench
  29. Tighten the jamb nut to the LH outer tie rod end.
    80 Nm (59.0 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Combination wrench 12pt 21mm
  30. Lower the vehicle partially and set the lift onto locks.
  31. Install the front wheels. See Wheel Assembly (Remove and Install).
  32. Exit the Service Mode. See Service Mode.
  33. Raise the LH front window and close the LH front door.
  34. Remove the lift arms from below the vehicle.
  35. Refer to the Alignment Requirement tables to determine whether an EPAS alignment check (EC) or four wheel alignment check (AC) is necessary. If performed, add the alignment check/adjust as a separate activity. See Alignment Requirement - Suspension.
