Hockey Stick - Center Console - LH (Model 3 Standard) (Remove and Replace)

Correction code 15190401702 15190401701 15190401802 15190401801 FRT 0.36 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
  • 2025-09-05: Released new procedure.
  1. Remove the phone dock assembly. See Phone Dock Assembly - Center Console (Model 3 Standard) (Remove and Replace)
  2. Remove LH rear side panel from center console assembly
    Note
    12x tabs, 2x positioning clips, Pull out the rear side panel from the rear to the front
  3. Remove LH hockey stick from center console assembly
    Note
    20x tabs, 3x positioning clips, Release all clips and pull out the hockey stick
  4. Install LH hockey stick to center console assembly
    Note
    20x clips, 3x positioning clips, Align all clips and press the hockey stick inward, Make sure that all clips are installed in place
  5. Install LH rear side panel to center console assembly
    Note
    12x tabs, 2x positioning clips
  6. Install the phone dock assembly. See Phone Dock Assembly - Center Console (Model 3 Standard) (Remove and Replace)
