Glare Shield - Front Camera (Remove and Replace)

Correction code 1505010042 FRT 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-11-18: Added note for correct GNSS routing.
Parent topic: 1505 - Interior Mirror and Sun Visors

Remove

  1. Remove the lower camera cover. See Camera Cover - Lower (Remove and Replace).
  2. Remove the rear view mirror. See Mirror - Rear View (Remove and Replace).
  3. Remove the upper camera cover. See Camera Cover - Upper (Remove and Replace).
  4. Disconnect the electrical connectors (x3) from the interior camera.
  5. Disconnect the GPS/GNSS antenna connector.
  6. Remove the bolts (x2) that attach the glare shield to the windshield bracket.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless hex driver
    • Torx T10 bit
  7. Remove the bolt that attach GPS/GNSS antenna to the glare shield.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless hex driver
    • Torx T10 bit

Install

  1. Install the bolt that attach GPS/GNSS antenna to the glare shield.
    0.8 Nm (7 lbs-in)
    Tip
    Use of the following tool(s) is recommended:
    • Ratchet/torque wrench
    • Torx T10 bit
    • Wiha Torque 0.8 Nm - 5 Nm screwdriver
  2. Install the bolts (x2) that attach the glare shield to the windshield bracket.
    1 Nm (.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Cordless hex driver
    • Torx T10 bit
    • Wiha Torque 0.8 Nm - 5 Nm screwdriver
  3. Connect the GPS/GNSS antenna connector.
    CAUTION
    Do not route the GNSS cable through the camera trilobe. GNSS cable routing should allow slack in the cable to avoid potential camera interference. See images for correct and incorrect cable routing.
  4. Connect the electrical connectors (x3) to the interior camera.
  5. Install the upper camera cover. See Camera Cover - Upper (Remove and Replace).
  6. Install the rear view mirror. See Mirror - Rear View (Remove and Replace).
  7. Install the lower camera cover. See Camera Cover - Lower (Remove and Replace).
