Tie Rod - Inner and Outer - LH (Remove and Replace)

Correction code 32013202 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-09-21: Released new procedure.
Parent topic: 3201 - Steering Rack and Lower Column

Remove

  1. Remove the LH wheel arch liner. See aise and support the vehicle. See Wheel Arch Liner - Front - LH (Remove and Replace).
  2. Remove and discard the nut that attaches the LH tie rod outer assembly to the LH front knuckle.
  3. Remove the LH front tie rod end from the LH front knuckle.
  4. Remove and discard the large bellows clamp from the bellows.
  5. Remove the bellows seal clip from the bellows.
  6. Slide the bellows toward the LH outer tie rod end.
  7. Remove the LH tie rod assembly from the pinion housing.
    Note
    38mm crowfoot. Twist until it comes off.

Install

  1. Adjust the new tie rod length to match old tie rod before installation.
    Note
    1x jam nut, 21mm, 14mm. Turn inner tie rod as needed. Parts line up is to count the threads on the removed tie rod then adjust to the same count on the new one. This will make alignment adjustment easier.
  2. Install the LH inner tie rod assembly onto the pinion housing.
    88 Nm (64.9 lbs-ft)
    Note
    Use a 38 mm crowfoot. Twist until it's fully seated.
  3. Slide the bellows into the clamping position.
  4. Install the large bellows clamp onto the bellows.
  5. Install the bellows seal clip onto the bellows.
  6. Position the LH tie rod outer assembly to the LH front knuckle.
  7. Install a new nyloc nut that attaches the LH tie rod outer assembly to the LH front knuckle.
    180 Nm (132.7 lbs-ft)
  8. Install the LH front wheel liner. See Wheel Arch Liner - Front - LH (Remove and Replace).
  9. Install the LH front wheel. See Wheel Assembly (Remove and Install).
  10. Review the wheel alignment requirements and add correction code(s) as needed. See Alignment Requirement - Suspension.
