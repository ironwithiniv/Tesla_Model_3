Key Card (Remove and Replace)

Correction code 1745010012 FRT 0.06 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Note
Configuration changes from within Toolbox can only be performed by a Tesla employee at this time. Third parties must request the configuration change through their agreed Tesla technical support channel.
Note
This procedure authenticates two keys, and should only be performed if no authenticated keys are present or if the security controller was replaced. If an authenticated key is available, see Key Card (Remove and Replace).
Note
The vehicle supports up to 19 keys. When reaching this limit, a key must be deleted before a new key can be added.
Warning
Stacking a mobile phone and a NFC card in wireless charger may damage the card.
Parent topic: 1745 - Keyless Entry and Security

Procedure

  1. Place the two new keys on the top of the wireless charger pad.
  2. Connect a laptop with Toolbox to the vehicle. See Toolbox (Connect and Disconnect).
  3. In Toolbox, click the Actions tab, type "Pair NFC" in the search field, click on PROC_VCSEC_C_PAIR-NFC-CARD-V2via Service Mode:Low Voltage ➜ Keys ➜ Pair Keyvia Toolbox:(link), and then click Run to start the pairing process.
  4. In Toolbox, under "number_to_pair", type "2", and then click Submit.
    Note
    Allow the routine to run. If the routine fails, try again.
  5. Once the routine completes, confirm that it displays the correct number of paired keys.
    Note
    If the number of keys successfully paired does not match the number of keys requested, reposition the keys on the center console or phone dock and repeat from step 3.
  6. Tap each new key against the driver's side B-pillar applique to verify that the key locks and unlocks the vehicle.
  7. Place each new key onto the key reader behind the cup holders on top of the center console to verify they are both authenticated and can start the vehicle.
  8. Disconnect the laptop with Toolbox from the vehicle. See Toolbox (Connect and Disconnect).
