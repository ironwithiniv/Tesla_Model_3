Coolant - HV Battery (Drain and Refill)

Correction code 16200505 0.95 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1135762-00-A Kit, Svc Plug, Cooling Hose, Model 3
  • 1133843-00-B KIT, COOLANT DRAIN & FILL ADAPTERS, M3
  • 1050448-00-B COOLANT VACUUM FILL - JTC
  • 1053600-00-D LEAK TEST FIXTURE, 0-50PSI
  • 1065131-00-A TOOL KIT, BATT COOLANT DRN & FILL
  • 1132185-00-D KIT, COOLANT LEAK TEST ADAPTERS
  • 1479505-00-A KIT, M3 VACUUM FILL COOLANT ADAPTER
Parent topic: 1620 - HV Battery Cooling System

Remove

  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Remove the cabin intake duct. See Assembly - Fresh Air Gutter - HVAC (Remove and Replace).
  3. Unlock the gateway. See Gateway Unlock.
  4. On the touchscreen, touch Service Mode > Thermal > Coolant System > Coolant Fill/Drain and select Run to start the "Start Thermal Fluid Fill/Drain (Coolant Only)" routine.
    Note
    If the routine takes more than 5 hours, perform the routine again.
  5. Disconnect LV power. See LV Power (Disconnect and Connect) (Modify).
  6. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  7. Remove the front skid plate. See Skid Plate - HV Battery - Front (Remove and Replace).
  8. Remove the bolt that attaches the LH front wheel liner to the skid plate.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 4 in extension
    • 10 mm socket
  9. Remove the push clips (x3) that attach the lower rear edge of the LH front wheel liner to the vehicle for access to the coolant hose.
  10. Use a bungee strap to pull back the LH front wheel liner and attach it to the subframe.
  11. Drain the coolant. See Drain.

Drain

  1. Position a coolant drain container under the LH front of the HV battery.
  2. Release the clip that attaches the front manifold hose to the body.
  3. Release the spring clip, disconnect the front manifold hose, and then plug the female side of the hose.
  4. Attach the coolant leak test adapter to the male side of the front manifold hose.
  5. Attach the coolant leak test adapter to the pressure test fixture.
  6. Release the spring clip, disconnect the HV battery return tube, and then plug the male side of the tube.
  7. Attach the HV battery coolant drain fitting adapter to the female side of the HV battery return tube.
  8. Attach the HV battery drain fitting adapter to the coolant cart drain hose.
  9. Attach the compressed air line to the pressure test fixture.
    Note
    Ensure the valves on the pressure test fixture are closed.
  10. Open the P1 valve on the pressure test fixture slowly and adjust the pressure to 26 psi.
    CAUTION
    As coolant may spill, use caution and make sure safety glasses are worn.
  11. Slowly open the P2 valve on the pressure test fixture and wait at least 5 minutes to allow the coolant to completely drain.
  12. Disconnect the compressed air from the pressure test fixture.
  13. Disconnect the coolant cart drain hose from the drain fitting adapter.
  14. Disconnect the drain fitting adapter from the HV battery return tube.
  15. Remove the plug, connect the HV battery return hose, and then fasten the clip.
    Note
    Perform a push-pull-push test to make sure that the hose is secure.
  16. Disconnect the pressure text fixture from the coolant leak test adapter.
  17. Disconnect the coolant leak test adapter from the front manifold hose.
  18. Remove the plug, connect the front manifold hose, and then fasten the clip.
    Note
    Perform a push-pull-push test to make sure that the hose is secure.
  19. Fasten the clip that attaches the front manifold hose to the body.
  20. Remove the coolant drain container from underneath the vehicle.

Refill

  1. Release the LH front wheel liner from the bungee strap, and remove the strap from the vehicle.
  2. Install the lower clips (x3) that attach the lower rear edge of the LH wheel arch liner to the body.
  3. Install the bolt that attaches the LH front wheel liner to the skid plate.
    5 Nm (3.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 4 in extension
    • 10 mm socket
    • Ratchet/torque wrench
  4. Install the front skid plate. See Skid Plate - HV Battery - Front (Remove and Replace).
  5. Install the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  6. Refill the system with coolant. See Cooling System - Vacuum Refill (Test/Adjust).
  7. Exit Service Mode. See Service Mode.
  8. Install the cabin intake duct. See Assembly - Fresh Air Gutter - HVAC (Remove and Replace).
  9. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
