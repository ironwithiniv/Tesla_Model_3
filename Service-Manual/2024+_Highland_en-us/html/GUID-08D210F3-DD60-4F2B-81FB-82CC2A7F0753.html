Reservoir - Windshield Washer (Remove and Replace)

Correction code 1750020212 FRT 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1750 - Wipers and Washers

Remove

  1. Remove the windshield washer reservoir assembly. See Assembly - Reservoir - Windshield Washer (Remove and Replace).
  2. Remove the windshield washer pump and pump grommet from the windshield washer reservoir.
    Note
    Inspect the washer pump grommet for damage and replace as necessary.
  3. Use a plastic trim tool to gently pry the washer level sensor and sensor grommet from the washer reservoir.
    CAUTION
    Be careful not to damage the sensor.
    Note
    Inspect the washer level sensor grommet for damage and replace as necessary.
  4. Use a plastic trim tool to remove the cap from the windshield washer reservoir.
    Note
    The cap and the retaining collar are a single piece.
  5. Remove the windshield washer reservoir.

Install

  1. Align the locating slot on the cap with the locating tab on the reservoir, and then fully seat the cap onto the reservoir.
  2. Install the grommet into the windshield washer reservoir.
    Note
    Inspect the grommet for damage before installation.
  3. Install the windshield washer level sensor so that the flat edge of the sensor housing is facing upwards and the sensor connector is facing directly to the rear.
  4. Install the windshield washer pump and pump grommet to the washer reservoir.
    Note
    Ensure the washer pump is aligned with the positioning slot.
    Note
    Inspect the grommet for damage before installation.
  5. Install the windshield washer reservoir assembly. See Assembly - Reservoir - Windshield Washer (Remove and Replace).
