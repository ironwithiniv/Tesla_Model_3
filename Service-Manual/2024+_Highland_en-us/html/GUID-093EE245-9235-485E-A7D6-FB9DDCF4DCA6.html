Steering Column (LHD) (Remove and Replace)

Correction code 3205010112 1.26 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-08-13: Updated the steps from removing/installing the connectors (x2) on the column assembly to removing/installing the IP harness connector.
  • 2026-05-01: Added missing steps for removing/installing upper nuts that attach the steering column to the cross car beam.
  • 2025-04-16: Updated the original IP carrier removal step to the steps of partially releasing the IP carrier to remove the steering column.
  • 2024-12-02: Updated steering column configuration and calibration steps.
  • 2024-09-12: Added knee airbag steps for NA vehicles.
CAUTION
If performing this procedure as a result of a collision, see the Collision Repair Manual to verify whether the steering gear must be replaced as well.

Remove

  1. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  2. Remove the steering column control module. See Module - Steering Column Control (Remove and Replace).
  3. Remove the driver footwell duct. See Duct - Footwell - LH (Remove and Replace).
  4. Remove the lower instrument panel. See Assembly - Instrument Panel - Lower (Remove and Replace).
  5. Remove the screws (x6) that attach the lower LH side and the lower center of the IP (instrument panel) carrier to the cross car beam to gain access to the steering column.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  6. Remove the screws (x4) that attach the steering column shroud and the upper gap hider to the steering column.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  7. Tape around the steering column to avoid damage.
  8. Remove the lower gap hider. See Gap Hider - Steering Column - Lower (Remove and Replace).
  9. Disconnect the IP harness connector from the electronic steering column.
    Note
    1x clip
  10. Release the steering shaft boot from the bulkhead and pull it into the vehicle.
    Note
    Release at one point and then work around.
  11. Remove and discard the bolt that attaches the steering column to the steering gear assembly.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm deep socket
  12. Slide the steering column upward to disconnect it from the steering gear assembly.
  13. Remove the upper nuts (x2) that attach the steering column to the cross car beam.
  14. Remove the steering wheel upper gap hider. See Gap Hider - Steering Column - Upper (Remove and Replace).
  15. Remove the remaining nuts (x2) that attach the steering column to the cross car beam.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  16. Gently waggle the steering column and pull it out of the vehicle.
    Note
    Slightly pull the IP outward to give extra access for the steering column removal. Make sure the steering column are not blocked by the plastic beam on the IP. Ask for assistance to move the steering shaft as needed.

Install

  1. Record the part number of the new steering column for subsequent configuration.
  2. Place the steering column face down and slowly put it into the vehicle. Make sure the motor is not stuck at the plastic beam, and then rotate the steering column clockwise until it is at a position that fits to connect the connectors.
  3. Install the lower nuts (x2) that attach the steering column to the cross car beam.
    15 Nm (11.1 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  4. Install the steering wheel upper gap hider. See Gap Hider - Steering Column - Upper (Remove and Replace).
  5. Install the remaining nuts (x2) that attach the steering column to the cross car beam.
    15 Nm (11.1 lbs-ft)
  6. Slide the steering column downward to connect it to the steering gear assembly.
    Note
    Ensure the intermediate shaft is aligned and fully seated.
  7. Install new bolt that attaches the steering column to the steering gear assembly.
    18 Nm (13.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm deep socket
  8. Install the steering column boot onto the bulkhead.
  9. Connect the IP harness connector to the electronic steering column.
    Note
    1x clip
  10. Install the lower gap hider. See Gap Hider - Steering Column - Lower (Remove and Replace).
  11. Install the screws (x4) that attach the steering column shroud and the upper gap hider to the steering column.
    1.2 Nm (.9 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  12. Align the datums on the body to the holes on the IP carrier, and then install the screws (x6) that attach the lower LH side and the lower center of the IP carrier to the cross car beam.
    2.3 Nm (1.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  13. Remove the protective tapes.
  14. Install the lower instrument panel. See Assembly - Instrument Panel - Lower (Remove and Replace).
  15. Install the driver footwell duct. See Duct - Footwell - LH (Remove and Replace).
  16. Install the steering column control module. See Module - Steering Column Control (Remove and Replace).
  17. Connect LV power. See LV Power (Disconnect and Connect) (Modify).
  18. Place the vehicle into Service Mode Plus. See Service Mode Plus.
  19. In Service Mode Plus, touch Vehicle Configurations, find steeringColumnMotorType, and use the steering column part number recorded earlier and this table to determine the configuration value to be chosen. Choose the correct value.
    Part Number Drive Build Location Configuration Value
    1344811 LHD Fremont "BOSCH_COMMON_TO_JE"
    1344813 LHD Giga Shanghai "JE"
    1344817 RHD Giga Shanghai "NEXTEER"
  20. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): PROC_STEERING_COLUMN_CALIBRATIONvia Service Mode:Chassis ➜ Steering ➜ Calibrate Steering Columnvia Toolbox:(link)
  21. On the touchscreen, press and hold the Exit Service Mode button to exit Service Mode Plus.
  22. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
