Vent Cover - Center Console(with a Screw-secured Phone Dock) (Remove and Replace)

Correction code 1519010142 FRT 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Note
For clip-secured phone dock, use correction code 1519011142.
Parent topic: 1519 - Center Console

Torque Specifications

Table 1. Torque Specifications: Vent Cover - Center Console(with a Screw-secured Phone Dock) (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Screws (x2) that attach rear vent assembly to the center console
1 Nm (.7 lbs-ft)
  • Torx T20 socket
 Reuse

Remove

  1. Remove the center console phone dock assembly. See Phone Dock (Clip) - Center Console (Remove and Replace) or Phone Dock (Screw) - Center Console (Remove and Replace).
    Note
    It is not necessary to remove the inductive charger from the phone dock.
  2. Remove the rear end panel. See Panel - Rear End - Center Console (Remove and Replace).
  3. Remove the center console USB bezel. See USB Module - Center Console (Remove and Replace).
  4. Remove the LH center console rear side panel. See Panel - Rear Side - Center Console - LH (Remove and Replace).
  5. Remove the LH center console front side panel. See Carpet - Side - Center Console - LH (Remove and Replace).
  6. Remove the LH center console décor trim. See Hockey Stick Assembly -LH (with a Clip-secured Phone Dock) (Remove and Replace).
  7. Repeat step 4 through step 6 for the RH side of the vehicle.
  8. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  9. Disconnect LV battery power. See LV Power (Disconnect and Connect) (Modify)
  10. Remove the rear display. See Touchscreen - Rear (Remove and Replace).
  11. Remove the screws (x2) that attach rear vent assembly to the airwave assembly.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  12. Release the clips (x3) that attach the center console rear vent assembly to the center console, and then remove the rear vent assembly from the center console.

Install

  1. Install the clips (x3) that attach the center console rear vent assembly to the center console.
    Note
    Make sure that the clips and datums are properly engaged.
  2. Install the screws (x2) that attach rear vent assembly to the center console.
    1 Nm (.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  3. Install the rear display. See Touchscreen - Rear (Remove and Replace).
  4. Connect LV battery power. See LV Power (Disconnect and Connect) (Modify)
  5. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  6. Install the LH center console décor trim. See Hockey Stick Assembly -LH (with a Clip-secured Phone Dock) (Remove and Replace).
  7. Install the LH center console front side panel. See Carpet - Side - Center Console - LH (Remove and Replace).
  8. Install the LH center console rear side panel. See Panel - Rear Side - Center Console - LH (Remove and Replace).
  9. Repeat step 6 through step 8 for the RH side of the vehicle.
  10. Install the center console USB bezel. See USB Module - Center Console (Remove and Replace).
  11. Install the rear end panel. See Panel - Rear End - Center Console (Remove and Replace).
  12. Install the center console phone dock assembly. See Phone Dock (Clip) - Center Console (Remove and Replace) or Phone Dock (Screw) - Center Console (Remove and Replace).
