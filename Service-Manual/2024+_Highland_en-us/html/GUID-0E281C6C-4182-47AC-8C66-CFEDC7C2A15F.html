Tube - Drain - Extension - HVAC (Remove and Replace)

Correction code 18101601102 FRT 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1810 - Cabin HVAC

Remove

  1. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  2. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  3. Release the clip that attaches the front drive unit inverter inlet hose to the front drive unit.
  4. Use gasket scraper to remove the HVAC extension drain tube from the vehicle.
    Note
    Make sure that the 2 O-rings are removed along with the tube.
  5. Use IPA wipes and approved chemicals to remove any remaining adhesive or residue from the vehicle.
    Note
    The adhesive remover may vary by region. Wear appropriate PPE for personal protection before use.

Install

  1. Gently lift the adhesive backing, cut a slit in it, and then press the backing back into place.
    Note
    This is to make later removal easier.
  2. Remove the lid, and then use the appropriate grease to lubricate the O-rings on the extension drain tube. See for Fluids and Capacities.
  3. Install the extension drain tube to the body.
    1. Align the extension drain tube with the body sheet metal, and keep the arrow on the extension drain tube points upward.
    2. Peel off the adhesive backing.
    3. Press firmly to fully seat the extension drain tube.
    \
  4. Install the rear aero shield panel. See Panel - Aero Shield - Rear (Remove and Replace).
  5. Remove the vehicle from the 2 post lift. See Raise Vehicle - 2 Post Lift.
