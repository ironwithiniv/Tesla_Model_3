Trim - Side - Trunk - LH (Remove and Replace)

Correction code 1530030062 FRT 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1530 - Carpeting and Mats

Remove

  1. Remove the 2nd row side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  2. Remove the trunk load floor. See Load Floor - Trunk (Remove and Replace).
  3. Remove the trunk sill trim. See Trim - Trunk Sill (Remove and Replace).
  4. Remove the LH load floor bracket. See Bracket - Trunk Load Floor - LH (Remove and Replace).
  5. Remove the trunk garnish. See Garnish - Trunk (Remove and Replace).
  6. Use a pry tool to remove the clips (x2) that attach the trunk side trim to the vehicle.
  7. Disconnect the LH trunk task light connector.
  8. Remove the trunk side trim.

Install

  1. Install the trunk side trim.
  2. Connect the LH trunk task light connector.
  3. Install the clips (x2) that attach the trunk side trim to the vehicle.
  4. Install the trunk garnish. See Garnish - Trunk (Remove and Replace).
  5. Install the LH load floor bracket. See Bracket - Trunk Load Floor - LH (Remove and Replace).
  6. Install the trunk sill trim. See Trim - Trunk Sill (Remove and Replace).
  7. Install the trunk load floor. See Load Floor - Trunk (Remove and Replace).
  8. Install the 2nd row side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
