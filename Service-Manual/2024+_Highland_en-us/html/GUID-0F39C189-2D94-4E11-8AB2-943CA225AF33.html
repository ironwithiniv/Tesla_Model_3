Replacing Additional Suspension Components (Access Already Performed)

When a suspension component such as a knuckle, hub, or subframe has been removed/released as a part of vehicle service, other suspension components may be directly accessible and serviceable without needing to perform a full "Remove and Replace" procedure.

If replacing one or more suspension parts that are "already accessed", add correction code 31000000 to the activity and refer to the table below for guidance on calculating the FRT.

Example #1:
  1. The LH rear knuckle is getting replaced. Add correction code 31030202.
  2. It is determined that the LH rear lower fore link and LH rear upper fore link also need to be replaced.
  3. Since the LH rear knuckle is already removed, both rear lower fore links only need to be released from the subframe. Add correction code 31000000.
  4. Edit the FRT of 31000000 to 0.60, since two additional suspension components are getting replaced.
Example #2:
  1. The front subframe is dropped due to replacement of the RH FDU mount. Add correction code 30011032.
  2. It is determined that the LH and RH front knuckle, LH and RH front compliance link, and LH and RH front lateral link also need to be replaced.
  3. Since the front subframe is already removed, the knuckle and lower links are more easily accessed. Add correction code 31000000.
  4. Edit the FRT of 31000000 to 1.80, since six additional suspension parts are getting replaced.
Table 1. FRT of 31000000 according to number of suspension parts replaced
