Shell - Seat Back - Front Seat (Sport Seat) (Remove and Replace)

Correction code 1307020402 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
Seat base edges are sharp and can cause personal injury. Wear cut resistant gloves when removing the seat from the vehicle, and while performing procedures that involve work on or near the seat base.
Parent topic: 1307 - Front Seat Covers Pads and Trims

Remove

  1. Remove the driver headrest trim from the seat. See Headrest - Front Seat - LH (Sport Seat) (Remove and Replace).
  2. Move the LH front seat to most forward and upward position.
  3. Remove strap clips for lower section from LF seat back shell assembly.
  4. Release headrest bracket assembly.
  5. Push inward and pull back the shell to release the bottom clips on both sides from the slots. Then starting at the top of the seat, pull the shell clips away from the frame to remove the LH seat back shell assembly from the seat back frame.
    Note
    12 x clips, 2 x guide pins. When releasing the clips, protect the seat leather to avoid damage. Move the seat as needed for access.

Install

  1. Install the lower clips of the seat back shell first, rotate the shell up into place, and apply light pressure as needed to install the seat back shell assembly to the seat back frame.
    Note
    The headrest posts will engage the seat back when the shell is installed.
  2. Hook strap clips onto seat back shell assembly.
  3. Install headrest bracket assembly.
  4. Install the driver headrest trim to the seat. See Headrest - Front Seat - LH (Sport Seat) (Remove and Replace).
  5. Close LH rear door.
  6. Move the LH front seat to most forward and upward position.
  7. Raise LH front window and Close LH front door.
