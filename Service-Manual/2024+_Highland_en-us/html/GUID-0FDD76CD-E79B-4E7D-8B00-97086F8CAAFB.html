Sideshield Carrier - LH Side - 1st Row Seat (Model 3 Standard) (Remove and Replace)

Correction code 13070103902 13070103901 13070104002 13070104001 FRT 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-10-08: Released new procedure.
Parent topic: 1307 - Front Seat Covers Pads and Trims

Remove

  1. Remove the LH outboard sideshield assembly from the LH front seat. See Sideshield - Outboard - 1st Row Seat - LH (Model 3 Standard) (Remove and Replace).
  2. Remove the LH 1st row sideshield carrier clips (x2) from the LH front seat.
  3. Partially lift the LH 1st row sideshield carrier upper shroud from the LH front seat.
    CAUTION
    Lifting with too much force will damage the carrier and trim.
  4. Remove the 1st row sideshield carrier from the LH front seat.
    Note
    Pull the carrier backward to release the positioning clips (x2).

Install

  1. Install the 1st row sideshield carrier onto the LH front seat.
    Note
    Push the carrier forward to secure the positioning clips (x2) to the front left seat.
  2. Press the 1st row sideshield carrier upper shroud into the LH front seat.
    Tip
    The shroud can be adjusted to ensure that the carrier is installed in place.
    CAUTION
    Be careful not to damage the carrier and trim.
  3. Install the 1st row sideshield carrier clips to the LH front seat.
    Note
    2x clips
  4. Install the LH 1st row outboard sideshield onto the LH front seat. See Sideshield - Outboard - 1st Row Seat - LH (Model 3 Standard) (Remove and Replace).
