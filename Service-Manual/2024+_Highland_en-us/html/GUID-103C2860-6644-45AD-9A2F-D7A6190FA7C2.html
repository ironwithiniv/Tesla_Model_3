Panel - Rear Side - Center Console - LH (Remove and Replace)

Correction code 1519010112 FRT 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1519 - Center Console

Remove

  1. Remove the rear end panel. See Panel - Rear End - Center Console (Remove and Replace).
  2. Move the driver seat all the way backward, then move the seat back all the way down.
  3. Release the clips (x10) and tabs (x2) that attach the rear side panel to the center console.
    Note
    Use a trim tool and start from the rear edge of the LH side panel to release the rearmost clips.
  4. Remove the rear side panel.

Install

  1. Align the tabs (x2) in the front and rear of the LH side panel.
  2. Install the clips (x10) that attach the rear side panel to the center console.
  3. Return the driver seat to its original position.
  4. Install the rear end panel. See Panel - Rear End - Center Console (Remove and Replace).
