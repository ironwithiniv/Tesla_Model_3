Handle - Exterior Release - Door - Front - LH (Remove and Replace)

Correction code 1145010012 FRT 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1145 - Exterior Door Handles

Torque Specifications

Table 1. Torque Specifications: Handle - Exterior Release - Door - Front - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Nuts that attach the exterior door handle to the door panel
7 Nm (5.2 lbs-ft)
  • 10 mm socket
 Replace

Remove

  1. Remove the LH front door reflector. See Reflector - Door - Front - LH (Remove and Replace).
  2. Remove the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
  3. Remove the LH front door puddle light. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  4. Remove the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  5. Remove the LH front door outer belt seal. See Seal - Outer Belt - Front Door - LH (Remove and Replace).
  6. Remove the LH front door glass. See Glass - Door - Front - LH (Remove and Replace).
  7. Disconnect the LV power. See LV Power (Disconnect and Connect) (Modify).
  8. Remove the LH front door closeout panel. See Closeout Panel - Door - Front - LH (Remove and Replace).
  9. Disconnect the electrical connector from the exterior door handle.
  10. Use a plastic trim tool to remove the plugs (x2) that cover access to the door handle nuts.
  11. Remove the nuts (x3) that attach the exterior door handle to the door panel, and then remove the handle from the door.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket

Install

  1. Hand tighten the nuts (x3) that attach the exterior door handle to the door panel.
  2. Use the gap and flush tool to check the gap and flush of the handle to the door surface.
  3. Torque the nuts (x3) that attach the exterior door handle to the door panel.
    7 Nm (5.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  4. Connect the electrical connector to the exterior door handle.
  5. Install the plugs (x2) that cover access to the door handle nuts.
  6. Install the LH front door closeout panel. See Closeout Panel - Door - Front - LH (Remove and Replace).
  7. Connect the LV power. See LV Power (Disconnect and Connect) (Modify).
  8. Install the front LH door glass. See Glass - Door - Front - LH (Remove and Replace).
  9. Install the LH front door outer belt seal. See Seal - Outer Belt - Front Door - LH (Remove and Replace).
  10. Install the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  11. Install the LH front door puddle light. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  12. Install the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
  13. Install the LH front door reflector. See Reflector - Door - Front - LH (Remove and Replace).
  14. Unlock the vehicle gateway. See Gateway Unlock.
  15. On the touchscreen, touch Controls > Service Mode > Windows > Calibrate Windows, then select Start to calibrate the window.
  16. Disable Service Mode. See Service Mode.
