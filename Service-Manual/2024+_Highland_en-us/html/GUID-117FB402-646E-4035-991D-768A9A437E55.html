Steering Column Control Module (Model 3 Standard) (Remove and Replace)

Correction code 32050200302 32050200301 FRT 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-09-05: Released new procedure.
CAUTION
Supplemental Restraint System (SRS) components can be hazardous if not serviced and handled correctly. See Airbag and Supplementary Restraint System (SRS) Precautions
CAUTION
In the event of an airbag or seatbelt pretensioner deployment, certain components must be replaced, and other components must be inspected for damage. Refer to the Collision Repair Manual for a specific list of items that must be inspected and replaced.
Parent topic: 3205 - Upper Column, Steering Wheel

Remove

  1. Remove the upper shroud from the steering column. See Shroud - Upper - Steering Column (Model 3 Standard) (Remove and Replace).
  2. Disconnect the steering column control module assembly connector.
    Note
    Remove the retaining clip on the connector, then release the connector
    Note
    Remove and discard the broken retaining clip.
  3. Loosen but do not remove the bolt that secures the steering column control module to the steering column .
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket
  4. Remove the steering column control module from the steering column.

Install

  1. Position the steering column control module onto the steering column.
  2. Torque the bolt that secures the steering column control module to the steering column.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket
    2.4 Nm (1.8 lbs-ft)
  3. Connect the steering column control module assembly connector.
    Note
    Install a new retaining clip to the connector, then install the steering column control module connector. Perform a push-pull-push text to make sure the connector is seated properly.
    Note
    Original retaining clips are black. All replacement clips are orange.
  4. Install the upper shroud onto the steering column. See Shroud - Upper - Steering Column (Model 3 Standard) (Remove and Replace).
