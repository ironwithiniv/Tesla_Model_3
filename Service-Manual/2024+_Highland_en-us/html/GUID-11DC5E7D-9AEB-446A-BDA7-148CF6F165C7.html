Hose - Washer Tank (Remove and Replace)

Correction code 1750010702 FRT 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Torque Specifications

Table 1. Torque Specifications: Hose - Washer Tank (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x3) that attach the washer reservoir to the front end carrier
4 Nm (2.9 lbs-ft)
  • 10 mm deep socket
  • Cordless 1/4in Dr Ratchet
 Reuse

Remove

  1. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  2. Disconnect the front camera washer hose.
    Note
    Unlock the black tab then separate the hose.
  3. Release the clip that attaches the front camera hose to the washer reservoir.
  4. Disconnect the washer level sensor connector.
  5. Disconnect the washer pump connector.
  6. Release the clips (x4) to release the washer level sensor harness from the washer reservoir.
  7. Remove the bolts (x3) that attach the washer reservoir to the front end carrier, then move the reservoir aside.
    Note
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
    • Cordless 1/4in Dr Ratchet
    Note
    Do not tip the reservoir to one side to prevent leaks.
  8. Place an empty container into the front storage area.
    Note
    Make sure the container is clean and not contaminated.
  9. Open the washer reservoir cap.
  10. Pour the washer fluid out of the washer reservoir.
    Note
    Be careful not to spill the washer fluid.
    Note
    Remove as much fluid as possible from the reservoir.
  11. Remove the container from the vehicle.
  12. Disconnect the washer tank hose from the windshield fluid pump.
  13. Release the clip and the guide clips (x5) that attach the washer tank hose to the washer reservoir, and remove the hose.

Replace

  1. Install the washer tank hose into the washer tank assembly, and install the clips.
  2. Install the washer tank hose to the windshield fluid pump.
  3. Position the washer reservoir back into place, and then install the bolts (x3) that attach the washer reservoir to the front end carrier.
    4 Nm (2.9 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
    • Cordless 1/4in Dr Ratchet
    Note
    Do not tip the reservoir to one side to prevent leaks.
  4. Connect the clip that attaches the front camera hose to the washer reservoir.
  5. Connect the front camera washer hose.
    Note
    Engage the black tab.
  6. Secure the clips (x4) that attach the washer level sensor harness to the washer reservoir.
  7. Connect the washer pump connector.
  8. Connect the washer level sensor connector.
  9. Fill the windshield washer reservoir with washer fluid.
  10. Close the washer reservoir cap.
  11. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
