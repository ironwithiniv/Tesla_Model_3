Glove Box (RHD) (Remove and Replace)

Correction code 1405010202 FRT 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1405 - Instrument Panel

Remove

  1. Remove the passenger footwell cover. See Cover - Footwell - Front Passenger (RHD) (Remove and Replace).
  2. Remove the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  3. Remove the clip that secures the passenger footwell duct.
  4. Release the locking tab, and then disconnect the connector that attaches the glove box USB cable to the car computer.
  5. Remove the screws (x4) that attach the glove box to the instrument panel carrier.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
    • 2 in extension
    • Cordless Ratchet/Impact Driver
    • WIHA Torque Screwdriver 0.8-5Nm
    • Mini Ratchet Bit Set - 1450424-00-A
  6. Release the clips (x10), the locator pins (x3), and a datum that attach the glove box to the instrument panel carrier.
    CAUTION
    Avoid damage to the electromagnetic switch.
  7. Disconnect the glove box assembly electrical connectors (x2).
  8. Remove the glove box from the vehicle.
  9. Remove the bolts (x2) that attach the glove box USB cable to the glove box.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 2 in extension
    • Torx T20 socket
    • Ratchet/torque wrench

Install

  1. Install the bolts (x2) that attach the glove box USB cable to the glove box.
    1.5 Nm (1.1 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 2 in extension
    • Torx T20 socket
    • Ratchet/torque wrench
  2. Connect the glove box assembly electrical connectors (x2).
  3. Secure the clips (x10), the locator pins (x3), and a datum that attach the glove box to the instrument panel carrier.
  4. Install the screws (x4) that attach the glove box to the instrument panel carrier.
    2.3 Nm (1.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
    • 2 in extension
    • Cordless Ratchet/Impact Driver
    • WIHA Torque Screwdriver 0.8-5Nm
    • Mini Ratchet Bit Set - 1450424-00-A
  5. Connect the connector that attaches the glove box USB cable to the car computer, and engage the locking tab.
  6. Install the clip that secures the passenger footwell duct.
    Note
    Ensure that the footwell duct is installed in proper place.
  7. Install the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  8. Install the passenger footwell cover. See Cover - Footwell - Front Passenger (RHD) (Remove and Replace).
