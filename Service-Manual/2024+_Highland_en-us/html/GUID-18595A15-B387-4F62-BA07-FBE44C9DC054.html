Motor - Seat Height - Driver Seat (Remove and Replace)

Correction code 1301020052 FRT 0.36 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-08-24: Updated the steps for completely removing the seat to steps for tilting the seat.
Parent topic: 1301 - Front Seat Tracks and Motors

Torque Specifications

Table 1. Torque Specifications: Motor - Seat Height - Driver Seat (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Foremost bolt that attaches the driver seat height motor to the seat frame
23 Nm (17.0 lbs-ft)
  • Torx T50 socket
 Replace 1109796-00-C
Rear bolt that attaches the motor to the frame
18 Nm (13.3 lbs-ft)
  • Torx T45 socket
 Replace 1106615-00-C

Remove

  1. Open the LH doors and lower the LH windows.
  2. On the touchscreen, tap the vehicle icon at the bottom left corner, then tap Controls > Steering Wheel, and use the left steering wheel roller to adjust the steering column to the highest and most inward position.
  3. Remove the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  4. Remove the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  5. Remove and discard the bolts (x4) that secure the driver seat assembly. See Seat Assembly - 1st Row - LH (Remove and Replace).
  6. Release the clips that attach the LH front seat harness to the sill trim.
  7. Pull the LH front seat harness from under the LH front cabin carpet.
  8. Use cloth to cover the center console and the rear seat to prevent damage.
  9. Tilt the LH front seat backward.
  10. Disconnect the height motor electrical connector.
  11. Remove and discard the foremost bolt that attaches the driver seat height motor to the seat frame.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket
  12. Remove and discard the rear bolt that attaches the driver seat height motor to the seat frame, and then remove the motor from the assembly.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T45 socket

Install

  1. Install the driver seat height motor to the seat frame, and then install a new foremost bolt that attaches the driver seat height motor to the seat frame.
    23 Nm (17.0 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket
  2. Install a new rear bolt that attaches the motor to the frame.
    18 Nm (13.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T45 socket
  3. Connect the height motor electrical connector.
  4. Position the driver seat assembly in the upright position.
  5. Remove the protection cloth.
  6. Install the LH front seat harness under the LH front cabin carpet.
  7. Position the 1st row LH seat harness in the sill trim harness guide, and then install the clips that attach the harness to the harness guide.
  8. Install new bolts (x4) that secure the driver seat assembly. See Seat Assembly - 1st Row - LH (Remove and Replace).
  9. Install the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  10. Install the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  11. Move the LH front seat to its original position.
  12. Move the steering wheel to its original position.
  13. Raise the LH windows and close the LH doors.
