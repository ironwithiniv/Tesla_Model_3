Armrest - Center Console (Remove and Install)

Correction code 1519010001 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2023-11-02: Added missing info on removing/installing 2 additional screws in Removal step 10 and Installation step 2.
Parent topic: 1519 - Center Console

Torque Specifications

Table 1. Torque Specifications: Armrest - Center Console (Remove and Install)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x6) that attach the armrest to the center console
1 Nm (.7 lbs-ft)
  • Torx T20 socket
 Reuse

Remove

  1. Remove the center console phone dock. See Phone Dock (Clip) - Center Console (Remove and Replace).
  2. Remove center console rear end panel. See Panel - Rear End - Center Console (Remove and Replace)
  3. Remove LH rear side panel from center console assembly. See Panel - Rear Side - Center Console - LH (Remove and Replace).
  4. Remove LH front side panel from center console assembly. See Carpet - Side - Center Console - LH (Remove and Replace).
  5. Remove LH center décor trim. See Hockey Stick Assembly -LH (with a Clip-secured Phone Dock) (Remove and Replace).
  6. Repeat step 3 through step 5 for the RH side of the vehicle.
  7. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  8. Disconnect LV battery power. See LV Power (Disconnect and Connect) (Modify)
  9. Remove the rear end module assembly. See Module - Rear End - Center Console (Remove and Install)
    Note
    No need to remove the rear end module from the assembly.
  10. Remove the bolts (x6) and screws (x2) that attach the armrest to the center console.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  11. Release the armrest pins (x4), and then remove the armrest from the vehicle.

Install

  1. Align the armrest pins (x4) with the tab in the armrest hinge hole.
  2. Install the bolts (x6) and screws (x2) that attach the armrest to the center console.
    1 Nm (.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  3. Install the rear end module assembly. See Module - Rear End - Center Console (Remove and Install)
  4. Connect LV battery power. See LV Power (Disconnect and Connect) (Modify)
  5. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  6. Install LH center console décor trim. See Hockey Stick Assembly -LH (with a Clip-secured Phone Dock) (Remove and Replace).
  7. Install LH center console front side panel. See Carpet - Side - Center Console - LH (Remove and Replace).
  8. Install LH center console rear side panel. See Panel - Rear Side - Center Console - LH (Remove and Replace).
  9. Repeat step 6 through step 8 for the RH side of the vehicle.
  10. Install the center console rear end panel. See Panel - Rear End - Center Console (Remove and Replace)
  11. Install the center console phone dock. See Phone Dock (Clip) - Center Console (Remove and Replace).
