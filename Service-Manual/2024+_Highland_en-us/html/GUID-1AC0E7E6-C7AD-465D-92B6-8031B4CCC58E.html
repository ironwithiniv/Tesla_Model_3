A/C Compressor and Supermanifold (Remove and Replace)

Correction code 1820020302 1.98 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-07-09: Updated the steps to connect/disconnect the LV maintainer.
  • 2026-04-07: Updated the step to configure the compressor type.
  • 2026-04-01: Added and corrected part numbers for special tools used in the procedure.
  • 2026-03-04: Added the compressor type selection reference.
  • 2025-10-21: Updated the A/C line torque values.
  • 2025-06-17: Released new procedure.
Equipment:
  • 1600279-00-A A/C OIL FLUSH ADAPTER SET, MODEL Y or 1600279-N0-BHEAT PUMP VEHICLE A/C FLUSHING FOR UNKNOWN OIL CONDITIONS
  • 1838504-00-B Heat Pump HVAC Debris Flush Adapter
  • 1711245-00-A Snap On Ecotechnics Dual Gas AC Machine, includes Flush Adapter Kit R134A & R1234YF or
  • 1120026-01-A A/C SERVICE MACHINE, WAECO, ASC5500 RPA
Note
This procedure requires the A/C Refrigerant (Recovery and Recharge) procedure to be performed. If not already automatically added to the Service Visit, add correction code 18200102 as a separate correction within the same activity to the Service Visit.
Parent topic: 1820 - Refrigerant System

Remove

  1. Set up the A/C machine.
  2. Prepare the vehicle for lifting. See Raise Vehicle - 2 Post Lift.
  3. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  4. Enable Service Mode. See Service Mode.
  5. Unlock the vehicle Gateway. See Gateway Unlock.
  6. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): PROC_VCFRONT_X_START-THERMAL-FILL-DRAINvia Service Mode:
    • Thermal ➜ Actions ➜ Start Thermal Fill/Drain
    • Thermal ➜ Coolant System ➜ Start Coolant Fill/Drain
    • Thermal ➜ Refrigerant System ➜ Start Refrigerant Fill/Drain
    via Service Mode Plus:
    • Drive Unit ➜ Front Drive Unit Replacement ➜ Start Coolant Fill/Drain
    • Drive Unit ➜ Rear Drive Unit Replacement ➜ Start Coolant Fill/Drain
    via Toolbox:(link)
  7. Power off the vehicle through the touchscreen.
  8. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  9. Recover the refrigerant. See A/C Refrigerant (Recovery and Recharge) (Restore).
  10. Remove A/C hoses from vehicle.
  11. Release vacuum from the A/C lines
    Note
    2x Schrader valves. Carefully depress the Schrader valves to release the vacuum from the A/C lines.
  12. Disconnect LV power. See LV Power (Disconnect and Connect) (Modify).
  13. Perform the vehicle HV disablement procedure. See Vehicle HV Disablement Procedure.
  14. Remove the fresh air intake assembly.
    Note
    2x studs. Lift cowl screen panel as needed.
  15. Remove the LV battery. See LV Battery (Remove and Replace).
  16. Position a fluid catcher underneath the front of the vehicle.
  17. Remove the coolant bottle cap.
  18. Disconnect the powertrain bypass hose from the supermanifold.
    Note
    This will drain the coolant reservoir
  19. Disconnect the radiator outlet hose from the supermanifold.
  20. Disconnect the radiator inlet hose from the supermanifold.
  21. Disconnect the chiller to battery hose sensor connector.
  22. Disconnect the PT supply hose sensor connector.
  23. Disconnect the chiller to battery hose from the supermanifold.
  24. Disconnect the powertrain supply hose from the supermanifold.
  25. Disconnect the HV battery return hose from the supermanifold.
  26. Disconnect the thermal sub-harness from the front controller.
  27. Remove the clip that attaches the thermal assembly harness to front harness guide cover.
  28. Put on HV insulating gloves and leather over gloves.
  29. Release the retaining clip that attaches the A/C compressor logic harness to the A/C compressor HV harness bracket.
  30. Disconnect the A/C compressor logic connector.
  31. Disconnect the HV harness connector from the A/C compressor.
  32. Remove the bolt that attaches the A/C compressor HV harness bracket to the A/C compressor.
  33. Remove the A/C compressor HV harness from the A/C compressor and set aside.
    Note
    Move A/C compressor HV harness bracket toward the front of the vehicle. Lift bracket up to clear upper bracket mount and carefully set the harness and bracket aside.
  34. Disconnect the HVIL connector.
  35. Remove the retaining clips that attach the A/C compressor HV harness to the shock tower support brace.
    Note
    5x retaining clips. Pull upward on clip to assist with removal. Do not pull on the HV cable.
  36. Remove HV insulating gloves.
  37. Remove the bolt that attaches the A/C compressor ground strap.
  38. Remove the clip that attaches the coolant hose to the A/C compressor bracket.
  39. Remove the clips (x2) that attach the coolant hose to the A/C compressor bracket.
  40. Remove the nut that attaches the low side of the manifold to compressor pipe and move low side pipe out of the way.
  41. Remove the nut that attaches the high side of the manifold to compressor pipe and move the high side pipe out of the way.
  42. Remove the bolt that attaches the supermanifold to the compressor A/C line assembly.
  43. Remove the supermanifold to compressor A/C line assembly from the supermanifold and remove it from the vehicle.
  44. Remove the bolts (x2) that attach the supermanifold to the HVAC A/C line assembly to the HVAC assembly.
  45. Remove the retaining clips that attach the LV battery and first responder loop to the shock tower support brace.
  46. Remove the bolts (x3) that attach the LH side of the shock tower brace to the vehicle.
  47. Remove the bolts (x3) that attach the RH side of the shock tower brace to the vehicle.
  48. Remove the shock tower brace with supermanifold and compressor from the vehicle.
    Note
    2 technicians are required for this step. Mind the connectors and A/C lines. Slowly lift the brace, and then put it on a cardboard pad.
  49. Remove the bolts (x2) that attach the supermanifold to shock tower beam, and then remove the supermanifold.
  50. Remove the nut that attaches the supermanifold to HVAC A/C line assembly to the supermanifold and remove the supermanifold to HVAC A/C line assembly.
  51. Remove the bolts (x2) that attach the A/C compressor bracket to the shock tower brace, and then remove the A/C compressor/
  52. Remove the bolts (x2) that attach the A/C compressor bracket to the A/C compressor.

Flush

  1. Install the bolts (x2) that attach the old supermanifold to HVAC A/C line assembly to the HVAC assembly.
    28 Nm (20.6 lbs-ft)
  2. Install the nut to attach the flush adapter to the A/C line assembly manifold to HVAC.
    36 Nm (26.5 lbs-ft)
  3. Install the bolt that attaches the old supermanifold to compressor A/C line assembly to the flush adapter.
    22 Nm (16.2 lbs-ft)
  4. Install the nuts (x2) that attach the A/C flush adapters onto the supermanifold to compressor A/C line assembly.
    22 Nm (16.2 lbs-ft)
    Note
    Install the flush adapters onto the suction and discharge lines on compressor side. Leave seal washers on A/C manifold line. Use 13mm nuts from compressor to attach the flush adapters.
  5. Connect the A/C machine hoses to the A/C flush adapters and run the system flush procedure. See A/C Refrigerant (Unknown Oil Quantity or System Flush) (Restore).
    Note
    The system flush procedure runs for approximately 90 minutes. A minimum of 3200g of refrigerant is needed in the tank to run the system flush procedure. On the A/C machine main menu select > Manual > Flushing Kit, Enter 25min vacuum time > Enter > Connect and open couplers > Enter. Machine will perform multiple flush cycles. Allow the process to complete.
  6. Disconnect the A/C machine hoses from the A/C flush adapters.
  7. Remove the A/C flush adapters from the supermanifold to compressor A/C line assembly.
  8. Remove the old supermanifold to compressor A/C line assembly from the flush adapter.
  9. Remove the flush adapter to the A/C line assembly manifold form HVAC.
  10. Remove the old supermanifold to HVAC A/C line assembly from the HVAC assembly.

Install

  1. Document the old and new part numbers and serial numbers of the supermanifold.
    Note
    The label is located in front of the accumulator. Document part numbers and serial numbers into the repair order.
  2. Position the supermanifold assembly to the shock tower brace, and then install the bolts (x2) that attach the supermanifold to the shock tower brace.
    Note
    Hand start the bolts to the supermanifold, torque at a later step.
  3. Replace the seal washers on the supermanifold to HVAC A/C line assembly on the supermanifold side.
    Note
    5x seal washers. Install new seals, lubricate seal washers with ND-11 oil.
  4. Replace the seal washers on the supermanifold to HVAC A/C line assembly on the HVAC side.
    Note
    5x seal washers. Install new seals, lubricate seal washers with ND-11 oil.
  5. Install the supermanifold to HVAC A/C line assembly to supermanifold and install the nut hand tight.
    Note
    Torque the nut at a later step.
  6. Torque the nut that attaches the supermanifold to HVAC A/C line assembly to the supermanifold.
    36 Nm (26.5 lbs-ft)
  7. Confirm part numbers of new and old compressors to update configuration in a later step.
    Note
    Compressor configuration: see Toolbox article5696900.
  8. Install the NVH acoustic onto the A/C compressor.
    Note
    Install a new NVH blanket. Remove the adhesive backing. Put the NVH acoustic cover down with the adhesive side facing up, align cut outs of NVH acoustic cover to suction port on A/C compressor, then Install NVH acoustic cover around the suction port on the A/C compressor and continue to wrap NVH acoustic cover around the compressor.
  9. Install the bolts (x3) that attach the A/C compressor bracket to the A/C compressor.
    9 Nm (6.6 lbs-ft)
  10. Position the A/C compressor and A/C compressor bracket assembly to the shock tower brace and hand tighten the bolts (x2).
    Note
    Torque the bolts at a later step.
  11. Install the shock tower brace to the vehicle.
    Note
    2 technicians are required for this step. Take care of connectors and AC lines.
  12. Install the RH shock tower brace bolts (x3).
    Note
    Torque the bolts as shown in the image.
  13. Install the LH shock tower brace bolts (x3).
    Note
    Torque the bolts as shown in the image.
  14. Torque the bolts that attach the supermanifold to the shock tower brace.
    31 Nm (22.9 lbs-ft)
  15. Torque the bolts that attach the A/C compressor to the shock tower brace.
    31 Nm (22.9 lbs-ft)
  16. Installation the retaining clip that attaches the LV battery and first responder loop to the shock tower support brace.
  17. Install the bolts that attach the supermanifold to HVAC A/C line assembly to the HVAC assembly.
    28 Nm (20.6 lbs-ft)
  18. Install the radiator inlet hose to the supermanifold.
    Note
    Perform a push-pull-push test to make sure the hose is fully seated. Do not wiggle the hose at the connection.
  19. Install the radiator outlet hose to the supermanifold.
    Note
    Perform a push-pull-push test to make sure the hose is fully seated. Do not wiggle the hose at the connection.
  20. Install the powertrain bypass hose to the supermanifold.
    Note
    Perform a push-pull-push test to make sure the hose is fully seated. Do not wiggle the hose at the connection.
  21. Connect HV battery return hose to supermanifold
    Note
    Perform a push-pull-push test to make sure the hose is fully seated. Do not wiggle the hose at the connection.
  22. Connect the powertrain supply hose to the supermanifold.
    Note
    Perform a push-pull-push test to make sure the hose is fully seated. Do not wiggle the hose at the connection.
  23. Connect the chiller to battery hose to the supermanifold.
    Note
    Perform a push-pull-push test to make sure the hose is fully seated. Do not wiggle the hose at the connection.
  24. Connect the PT supply hose sensor connector.
    Note
    Harness and coolant hose are color coded. Match harness color to coolant hose color.
  25. Connect the chiller to battery hose sensor connector.
    Note
    Harness and coolant hose are color coded. Match harness color to coolant hose color.
  26. Install the clip that attaches the thermal assembly harness to the front harness guide cover.
  27. Connect the thermal sub-harness to the front controller.
    Note
    Rotate fully to secure the locking tab.
  28. Install the clips (x2) that attach the coolant hose to the A/C compressor bracket.
  29. Install the clip that attaches the coolant hose to the A/C compressor bracket.
  30. Install the bolt that attaches the A/C compressor ground strap.
    7 Nm (5.2 lbs-ft)
  31. Put on HV insulating gloves and leather over gloves.
  32. Install the retaining clips (x5) that attach the A/C compressor HV harness to the shock tower brace.
  33. Position the A/C compressor HV harness onto the A/C compressor for installation.
    Note
    Make sure that the HV harness bracket engages the upper bracket mount on the A/C compressor.
  34. Install the bolt that attaches the A/C compressor HV harness bracket to the A/C compressor.
    9 Nm (6.6 lbs-ft)
  35. Connect the HV harness connector to the A/C compressor
    Note
    Fully seat the connector onto the A/C compressor and engage black locking tab by pushing it towards the A/C compressor.
  36. Install the retaining clip that attaches the A/C compressor logic harness to the A/C compressor HV harness bracket.
  37. Connect the A/C compressor logic connector.
  38. Connect the HVIL connector.
  39. Remove HV insulating gloves.
  40. Replace the seal washers of the supermanifold to compressor A/C line assembly on the supermanifold side.
    Note
    2x seal washers. Install new seals and lubricate them with ND-11 oil.
  41. Replace seal washer on the supermanifold to compressor A/C line assembly on the compressor discharge line.
    Note
    Install new seal and lubricate seal with ND-11 oil.
  42. Replace the seal washer on the supermanifold to compressor A/C line assembly on the compressor suction line.
    Note
    Install new seal and lubricate it with ND-11 oil.
  43. Install the nut tat attaches the supermanifold to compressor suction line to the compressor.
    22 Nm (16.2 lbs-ft)
  44. Install the nut that attaches the supermanifold to compressor discharge line to the compressor.
    22 Nm (16.2 lbs-ft)
  45. Install the bolt that attaches the supermanifold to compressor A/C line assembly onto the supermanifold.
    22 Nm (16.2 lbs-ft)
  46. Install the LV battery. See LV Battery (Remove and Replace).
  47. Connect LV power. See LV Power (Disconnect and Connect) (Modify).
  48. Unlock the vehicle Gateway. See Gateway Unlock.
  49. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): PROC_VCFRONT_X_START-THERMAL-FILL-DRAINvia Service Mode:
    • Thermal ➜ Actions ➜ Start Thermal Fill/Drain
    • Thermal ➜ Coolant System ➜ Start Coolant Fill/Drain
    • Thermal ➜ Refrigerant System ➜ Start Refrigerant Fill/Drain
    via Service Mode Plus:
    • Drive Unit ➜ Front Drive Unit Replacement ➜ Start Coolant Fill/Drain
    • Drive Unit ➜ Rear Drive Unit Replacement ➜ Start Coolant Fill/Drain
    via Toolbox:(link)
  50. Disconnect LV power. See LV Power (Disconnect and Connect) (Modify).
  51. Perform system vacuum test and refrigerant refill. See A/C Refrigerant (Recovery and Recharge) (Restore).
  52. Perform a coolant vacuum refill. See Cooling System - Vacuum Refill (Test/Adjust).
  53. Connect LV power. See LV Power (Disconnect and Connect) (Modify).
  54. Connect a low-voltage battery maintainer. See LV Maintainer (Connect and Disconnect) (Maintenance).
  55. Select thermal configurations via the touchscreen.
    Note
    Thermal > Actions > Thermal Configurations
  56. Set the compressor Type using the touchscreen:
    • For vehicles that run firmware version 2026.2.3 or later (NA/EMEA) or 2025.44.32 or later (APAC), touch Thermal > Actions > Configure Compressor, and then touch Run to start the routine.
    • For vehicles that run earlier firmware versions, touch Thermal > Actions > Thermal Configurations > compressorType, and then select and save the correct compressor type
    Note
    In case the routine did not complete successfully, refer to Toolbox article 5696900 for compressor configuration.
    Note
    Check the Gateway configuration for compressorType and make sure it shows as intended.
  57. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): PROC_ICE_X_SAFE-SET-VEHICLE-CONFIGSvia Service Mode Plus:HVAC Blower ➜ HVAC Blower Replacement ➜ Set Blower Motor Type to Identifiedvia Toolbox:(link)
    Note
    This routine can be performed via the touchscreen:
    1. On the touchscreen, tap Service Mode > Thermal > Actions > Thermal Configurations.
    2. Change the configuration of "coolantPumpType" to DUAL_MIX.
    3. Click Run and allow the routine to complete.
  58. Reinstall vehicle software. See Software Reinstall - Touchscreen.
  59. Disconnect low-voltage battery maintainer. See LV Maintainer (Connect and Disconnect) (Maintenance).
  60. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): PROC_VCFRONT_X_STOP-THERMAL-FILL-DRAINvia Service Mode:
    • Thermal ➜ Actions ➜ Stop Thermal Fill/Drain
    • Thermal ➜ Coolant System ➜ Stop Coolant Fill/Drain
    • Thermal ➜ Refrigerant System ➜ Stop Refrigerant Fill/Drain
    via Service Mode Plus:
    • Drive Inverter ➜ Front Drive Inverter Replacement ➜ Stop Fluid Fill/Drain
    • Drive Inverter ➜ Rear Drive Inverter Replacement ➜ Stop Fluid Fill/Drain
    • Drive Inverter ➜ Rear Left Drive Inverter Replacement ➜ Stop Fluid Fill/Drain
    • Drive Inverter ➜ Rear Right Drive Inverter Replacement ➜ Stop Fluid Fill/Drain
    • Drive Unit ➜ Front Drive Unit Replacement ➜ Stop Coolant Fill/Drain
    • Drive Unit ➜ Rear Drive Unit Replacement ➜ Stop Coolant Fill/Drain
    via Toolbox:(link)
  61. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): TEST-SELF_VCFRONT_X_COOLANT-PUMPS-IDENTIFICATIONvia Service Mode:
    • Thermal ➜ Actions ➜ Run Coolant Pumps Identification
    • Thermal ➜ Coolant System ➜ Pump Identification
    via Toolbox:(link)
  62. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): TEST-SELF_VCFRONT_X_HEAT-PUMP-COMMISSIONINGvia Service Mode:Thermal ➜ Refrigerant System ➜ Commission Heat Pumpvia Service Mode Plus:Drive Inverter ➜ Front Drive Inverter Replacement ➜ Heatpump commissioningvia Toolbox:(link)
  63. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): TEST_VCFRONT_X_THERMAL-COOLANT-AIR-PURGE-STARTvia Toolbox:(link)
  64. Remove the fluid catcher from underneath the vehicle.
  65. Install the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  66. Install the fresh air intake assembly.
  67. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  68. Inspect coolant level and top off as necessary.
    Note
    Make sure that the fluid level is at the Max line.
  69. Install the coolant bottle cap.
  70. Install the fresh air gutter assembly.
    Note
    3x clips
  71. Install the rear underhood apron.
  72. Exit Service Mode. See Service Mode.
