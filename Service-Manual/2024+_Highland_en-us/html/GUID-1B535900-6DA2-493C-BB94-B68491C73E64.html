Stabilizer Bar - Front (Remove and Replace)

Correction code 3101062012 FRT 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-11-10: An inflatable bag is installed between the front stabilizer bar and front valance for sufficient working space, replacing the need to fully remove the front valance.
CAUTION
If performing this procedure as a result of a collision, see the Collision Repair Manual to verify whether the steering gear must be replaced as well.
Parent topic: 3101 - Front Suspension (Including Hubs)

Remove

  1. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  2. Remove the push clips (x6) that attach the LH and RH sides of the valance to the wheel arch liners.
    Note
    Remove the outer clips as necessary to allow for easier access to the nuts behind the wheel liner.
  3. Install an inflatable bag vertically between the front stabilizer bar and front valance to ensure sufficient working space.
  4. Remove and discard the nuts (x2) that attach the LH and RH front stabar links to the front stabar.
    Tip
    Use of the following tool(s) is recommended:
    • 18 mm socket
  5. Move the LH and RH front stabar links aside.
  6. With assistance, remove and discard the LH and RH nuts (x4) that attach the front stabar to the front subframe.
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm deep socket
  7. Remove the stabilizer bar from the vehicle.

Install

  1. Position the front stabar to the front subframe, and then install new LH and RH nuts (x4) (1044388-00-B) to attach the front stabar to the front subframe.
    35 Nm (25.8 lbs-ft)
    Note
    Mark after torque.
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm deep socket
  2. Position the LH and RH front stabar links to the front stabar.
    Note
    Pull down the stabar as needed to allow the end links to engage.
  3. Install new nuts (x2) (1111543-00-A) to attach the LH and RH front stabar links to the front stabar.
    98 Nm (72.3 lbs-ft)
    Note
    Mark after torque.
    Tip
    Use of the following tool(s) is recommended:
    • 18 mm socket
  4. Remove the inflatable bag.
  5. Install the push clips (x6) that attach the LH and RH sides of the valance to the wheel liners.
