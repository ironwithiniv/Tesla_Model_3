Speaker - Headliner - LH (Remove and Replace)

Correction code 2121012032 FRT 0.72 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 2121 - Audio System - Speakers Subwoofer Amplifier

Torque Specifications

Table 1. Torque Specifications: Speaker - Headliner - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x3) that attach the LH headliner speaker to the headliner
0.5 Nm (4 lbs-in)
  • Cordless Ratchet/Impact Driver
  • Torx T10 socket
  • 2 in extension
  • Torx T10 bit
  • Ratchet/torque wrench
  • Digital Torque Screwdriver 0.10Nm - 2.0Nm
 Reuse

Remove

  1. Remove the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  2. Remove the LH upper A-pillar trim. See Trim - A-Pillar - Upper - LH (Remove and Replace).
  3. Remove the LH sun visor. See Sun Visor Assembly - LH (Remove and Replace).
  4. Remove the lower camera cover. See Camera Cover - Lower (Remove and Replace).
  5. Remove the rear view mirror. See Mirror - Rear View (Remove and Replace).
  6. Repeat step 1 through step 3 for the RH side of the vehicle.
  7. Remove the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  8. Remove the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  9. Remove the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  10. Remove the LH lower B-pillar trim. See Trim - B-Pillar - Lower - LH (Remove and Replace).
  11. Remove the LH middle B-pillar trim. See Trim - B-Pillar - Middle - LH (Remove and Replace).
  12. Remove the LH upper B-pillar trim. See Trim - B-Pillar - Upper - LH (Remove and Replace).
  13. Repeat step 7 and step 9 through step 12 for the RH side of the vehicle.
  14. Release the clips (x6) and locator pin that attach the front of the headliner to the vehicle.
    Note
    Take care not to bend the headliner when releasing the clips.
    Note
    If the metal clips are damaged during releasing, replace them with new metal clips.
  15. Disconnect the electrical connector from the LH headliner speaker.
  16. Remove the bolts (x3) that attach the LH headliner speaker to the headliner, and then remove the speaker from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • Torx T10 socket
    • 2 in extension
    • Torx T10 bit
    • Ratchet/torque wrench
    • Digital Torque Screwdriver 0.10Nm - 2.0Nm

Install

  1. Position the LH headliner speaker on the headliner, and then install the bolts (x3) that attach the speaker to the headliner.
    0.5 Nm (4 lbs-in)
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • Torx T10 socket
    • 2 in extension
    • Torx T10 bit
    • Ratchet/torque wrench
    • Digital Torque Screwdriver 0.10Nm - 2.0Nm
  2. Connect the electrical connector to the LH headliner speaker.
  3. Align the locating pin of the front of the headliner to the slot, and then install the clips (x6) that attach the front of the headliner to vehicle.
    Note
    Make sure that the door seal correctly overlaps the LH upper B-pillar trim.
  4. Install the rear view mirror. See Mirror - Rear View (Remove and Replace).
  5. Install the lower camera cover. See Camera Cover - Lower (Remove and Replace).
  6. Install the LH upper A-pillar trim. See Trim - A-Pillar - Upper - LH (Remove and Replace).
  7. Install the LH sun visor. See Sun Visor Assembly - LH (Remove and Replace).
  8. Repeat step 6 and step 7 for the RH side of the vehicle.
  9. Install the LH upper B-pillar trim. See Trim - B-Pillar - Upper - LH (Remove and Replace).
  10. Install the LH middle B-pillar trim. See Trim - B-Pillar - Middle - LH (Remove and Replace).
  11. Install the LH lower B-pillar trim. See Trim - B-Pillar - Lower - LH (Remove and Replace).
  12. Install the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  13. Install the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  14. Repeat step 9 through step 13 for the RH side of the vehicle.
  15. Install the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  16. Install the 2nd row LH and RH seat side bolsters. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
