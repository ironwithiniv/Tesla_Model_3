Insulator - Stuffer - Wheelhouse (Remove and Replace)

Correction code 1530010022 FRT 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1530 - Carpeting and Mats

Remove

  1. Remove the trunk load floor. See Load Floor - Trunk (Remove and Replace).
  2. Remove the trunk garnish. See Garnish - Trunk (Remove and Replace).
  3. Remove the trunk sill trim. See Trim - Trunk Sill (Remove and Replace).
  4. Remove the LH load floor bracket. See Bracket - Trunk Load Floor - LH (Remove and Replace).
  5. Use a pry tool to remove the LH clip that attaches the trunk side trim to the vehicle, then move the trunk side trim aside.
  6. Remove the LH trunk tub stuffer.

Install

  1. Install the LH trunk tub stuffer.
  2. Install the LH clip that attaches the trunk side trim to the vehicle.
  3. Install the LH load floor bracket. See Bracket - Trunk Load Floor - LH (Remove and Replace).
  4. Install the trunk sill trim. See Trim - Trunk Sill (Remove and Replace).
  5. Install the trunk garnish. See Garnish - Trunk (Remove and Replace).
  6. Install the trunk load floor. See Load Floor - Trunk (Remove and Replace).
