Map Light - Rear - LH (Remove and Replace)

Correction code 1520010062 FRT 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-12-03: Added the step to install the disposable tether hooks and added its part number 1771862-00-C.
  • 2025-03-18: Updated the torque value of the LH map lamp from 0.3Nm to 0.55Nm.
  • 2024-08-16: Added steps to run TEST-SELF_VCLEFT_REAR-DOME-LIGHTS routine.

2.5 Nm (1.8 lbs-ft)

 Reuse
Bolt that attaches the LH rear map light to the headliner
0.55 Nm (5 lbs-in)
  • Torx T10 bit
  • Digital Torque Screwdriver 0.10Nm - 2.0Nm
 Reuse

Remove

  1. Open the LH front and rear doors and lower the windows.
  2. Move the LH front seat fully forward.
  3. Remove the LH side rail assembly. See Trim - Side Rail - LH (Remove and Replace).
  4. Remove and discard the tether hooks (x2) from the LH body.
  5. Push the LH coat hook open.
  6. Remove the LH coat hook screw cover.
  7. Remove the LH coat hook screw.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket
  8. Use a plastic trim tool to remove the LH map lamp bezel from the headliner.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  9. Partially remove/lower the headliner.
    Note
    Release 2x clips and 1x locating pin. Pull the headliner trim at the rear LH side no more than 10cm (4in) to get access to the map light.
  10. Disconnect the electrical connector from the LH map lamp.
  11. Remove the bolt that attaches the LH rear map light to the headliner.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T10 bit
    • Digital Torque Screwdriver 0.10Nm - 2.0Nm
  12. Release the tabs (x2) that attach the LH map light to the headliner, and then remove the LH map light from the headliner.

Install

  1. Position the LH map light to the headliner, and then install the tabs (x2) that attach the LH map light to the headliner.
  2. Install the bolt that attaches the LH rear map light to the headliner.
    0.55 Nm (5 lbs-in)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T10 bit
    • Digital Torque Screwdriver 0.10Nm - 2.0Nm
  3. Connect the electrical connector to the LH map lamp.
  4. Install the partially removed headliner.
    Note
    2x clips, 1x locating pin. First push the locating pin in the hole and then push the headliner until the clips engage.
  5. Align the LH map light bezel pin, and then install the tabs (x2) that attach the LH map light bezel to the headliner.
    Note
    Make sure that the bezel alignment pin is fully seated into the map light.
  6. Install the LH coat hook screw.
    2.5 Nm (1.8 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket
  7. Close the LH coat hook screw cover.
  8. Close the LH coat hook cover.
  9. Install new tether hooks (x2) (1771862-00-C) onto the LH side rail assembly.
  10. Install the LH side rail assembly. See Trim - Side Rail - LH (Remove and Replace).
  11. Connect a laptop with Toolbox to the vehicle. See Toolbox (Connect and Disconnect).
  12. In Toolbox, click the Actions tab, and then search for "Rear Dome Lights".
  13. Click TEST-SELF_VCLEFT_REAR-DOME-LIGHTSvia Toolbox:(link), and then click Run and allow the routine to complete.
  14. Disconnect Toolbox and remove the laptop from the vehicle. See Toolbox (Connect and Disconnect).
  15. Reinstall the vehicle firmware. See Software Reinstall - Touchscreen.
  16. Move the LH front seat back to its original position.
