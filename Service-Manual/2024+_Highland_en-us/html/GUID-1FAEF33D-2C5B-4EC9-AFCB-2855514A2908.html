Lamp Switch - Front - Center Console (Model 3 Standard) (Remove and Replace)

Correction code 15190401102 15190401101 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
  • 2025-09-05: Released new procedure.
  1. Remove the phone dock assembly. See Phone Dock Assembly - Center Console (Model 3 Standard) (Remove and Replace)
  2. Remove sliding door cover
    Note
    Using a plastic trim tool, gently apply pressure toward the rear of the center console to release the sliding door cover
  3. Remove fastener securing front lamp switch
    Note
    1x screw, T10, 0.5Nm
  4. Disconnect front lamp switch connector
    Note
    1x connector, 1x locking tab, Using a 90 degree pick, carefully unlock locking tab, gently disconnect the connector from the center console harness assembly
  5. Remove front lamp switch
    Note
    1x locking tab for connector, 3x routing tabs for harness, to remove the switch from the center console assembly, gently pull the switch upward and toward the front of the console to release it. Then, use a small flathead screwdriver to carefully disengage the locking tab on the connector to disconnect it
  6. Position the front lamp switch
    Note
    1x locking tab for connector, 3x routing tabs for harness
  7. Connect front lamp switch to center console harness assembly
    Note
    1x connector, 1x locking tab
  8. Secure front lamp switch fastener
    Note
    1x screw, T10, 0.5Nm
  9. Install sliding door cover
    Note
    Install the sliding door onto the assembly and press it toward the front of the center console to secure the cover
  10. Install the phone dock assembly. See Phone Dock Assembly - Center Console (Model 3 Standard) (Remove and Replace)
