Hose - Front Manifold (Remove and Replace)

Correction code 1830020012 FRT 0.48 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1830 - Cooling System

Remove

  1. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Disconnect the LV power. See LV Power (Disconnect and Connect) (Modify).
  4. Remove the cabin intake duct. See Assembly - Fresh Air Gutter - HVAC (Remove and Replace).
  5. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  6. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  7. Remove the front HV battery skid plate. See Skid Plate - HV Battery - Front (Remove and Replace).
  8. Remove the push clips (x3) that secure the RH front wheel arch liner to the HV battery.
  9. Use a bungee strap to pull back the RH front wheel arch liner and secure it to the subframe.
  10. Position a coolant drain container underneath the RH front of the HV battery.
  11. Release the spring clip, disconnect the RH front manifold hose from the RH front of the HV battery, and then immediately plug both fittings.
  12. Position a coolant drain container underneath the front right center of the HV battery.
  13. Release the spring clip, disconnect the RH front manifold hose from the front of the HV battery, and then immediately plug both fittings.
  14. Position a coolant drain container underneath the HV battery manifold hose.
  15. Release the spring clip, disconnect the RH front manifold hose from the LH manifold hose, and then immediately plug both fittings.

Install

  1. Remove the coolant plugs, connect the RH front manifold hose to the LH front manifold hose, and then fasten the spring clip.
    Note
    Perform a push-pull test to verify that the hose is fully seated.
  2. Position a coolant drain container underneath the front right center of the HV battery.
  3. Remove the coolant plugs, connect the RH front manifold hose to the front of the HV battery, and then install the spring clip.
    Note
    Perform a push-pull test to verify that the hose is fully seated.
  4. Position a coolant drain container underneath the RH front of the HV battery.
  5. Remove the coolant plugs, connect the RH front manifold hose to the RH front of the HV battery, and then install the spring clip.
    Note
    Perform a push-pull test to verify that the hose is fully seated.
  6. Remove the coolant drain container from underneath the vehicle.
  7. Install the front HV battery skid plate. See Skid Plate - HV Battery - Front (Remove and Replace).
  8. Release the RH front wheel arch liner from the bungee strap.
  9. Install the push clips (x3) that secure the RH front wheel arch liner to the HV battery.
  10. Install the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  11. Lower the vehicle fully.
  12. Connect the LV power. See LV Power (Disconnect and Connect) (Modify).
  13. Remove the coolant bottle cap, and then fill the coolant to the proper level.
    Note
    Ensure that the coolant level is at the "Max" line.
  14. Unlock the gateway. See Gateway Unlock.
  15. Touch Service Mode > Thermal > Coolant System > Coolant Purge on the touchscreen to start the Coolant Purge Routine and allow the routine to complete.
    Note
    Make sure vehicle is not in Drive, shifting the vehicle into Drive will stop this routine. The test will last approximately 10 mins. The test will vary speeds from 3500-6500 RPM (idle speed = ~1500 RPM) and actuate the valve between series and parallel. If speed hovers at 7000 RPM, it indicates the pump is air locked, perform the vacuum fill again. Continue to add coolant and purge until the coolant level reaches between the NOM and MAX Lines on the bottle.
  16. Inspect the coolant level and top off as necessary, and then install the coolant bottle cap.
    Note
    Ensure that the coolant level is at the "Max" line.
  17. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  18. Install the cabin intake duct. See Assembly - Fresh Air Gutter - HVAC (Remove and Replace).
  19. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
