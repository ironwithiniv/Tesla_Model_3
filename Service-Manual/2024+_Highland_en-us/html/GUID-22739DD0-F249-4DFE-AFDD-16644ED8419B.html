Side Panel - Center Console - LH (Model 3 Standard) (Remove and Replace)

Parent topic: 1519 - Center Console

Remove

  1. Open LH front door
  2. Move LH front seat backward
    Note
    Via UI > Seat Controls
  3. Remove LH console side panel carpet
    Note
    11x clips, 2x positioning clips, 1x tab, Use trim tool starting at rear edge to release upper clips, If clips is too tight, Use prytool to remove clips, Then pull bottom to release remaining clips, Finally, release tab and pull out side panel backward, Replace clips if it is damaged

Install

  1. Install LH console side panel carpet
    Note
    11x clips, 2x positioning clips, 1x tab, Position side panel and align the front tab, Push the console panel from the front towards the rear
  2. Move LH front seat to original position
    Note
    Via UI > Seat Controls
  3. Close LH front door
