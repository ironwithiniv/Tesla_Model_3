Armrest - Outer - Center Console (Remove and Replace)

Correction code 1519010292 FRT 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created.   • 2026-06-23: Removed the center console assembly removal/installation steps.

Torque Specifications

Table 1. Torque Specifications: Armrest - Outer - Center Console (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Screws (x4) that attach the center console outer armrest to the armrest hinge
0.8 Nm (7 lbs-in)
  • Torx T20 socket
 Reuse

Remove

  1. Open the LH front door and lower the LH front window.
  2. Move the LH front seat backward and adjust the seat back to a lower position.
  3. Open the armrest.
  4. Release the clips (x15) that attach the armrest inner assembly to the armrest outer assembly, and move the armrest inner assembly aside.
    Note
    Start releasing the clips from the armrest inner trim top, then release the left and right side clips, and then finally to release the lower clips. Be careful not to damage any parts.
  5. Remove the screws (x4) that attach the center console outer armrest to the armrest hinge, and then remove the outer armrest from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket

Install

  1. Align the location tabs (x4) and position the outer armrest to the armrest assembly, and then install the screws (x4) that attach the center console outer armrest to the armrest hinge.
    0.8 Nm (7 lbs-in)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  2. Install the clips (x15) that attach the armrest inner assembly to the armrest outer assembly.
    Note
    Align all the clips and press the armrest inner assembly to ensure it is installed in place.
  3. Close the armrest.
  4. Move the LH front seat to original position.
  5. Raise the LH front window and close the LH front door.
