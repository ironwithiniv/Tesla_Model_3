Harness - Center Console Extension (Remove and Replace)

Correction code 1701080042 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1710 - Harnesses

Remove

  1. Open all four doors and lower all four windows.
  2. Remove the center console phone dock. See Phone Dock (Clip) - Center Console (Remove and Replace).
  3. Remove the center console rear end panel. See Panel - Rear End - Center Console (Remove and Replace).
  4. Remove the center console LH and RH rear side panels. See Panel - Rear Side - Center Console - LH (Remove and Replace).
  5. Remove the center console LH and RH front side panels. See Carpet - Side - Center Console - LH (Remove and Replace).
  6. Remove the center console LH and RH hockey sticks. See Hockey Stick Assembly -LH (with a Clip-secured Phone Dock) (Remove and Replace).
  7. Disconnect the LV power. See LV Power (Disconnect and Connect) (Modify).
  8. Remove the center console rear end module. See Module - Rear End - Center Console (Remove and Install).
  9. Disconnect the electric harness from the right vertical actuator connector.
  10. Disconnect the electric harness from the left vertical actuator connector.
  11. Disconnect the electric harness from the right horizontal actuator connector.
  12. Disconnect the electric harness from the left horizontal actuator connector.
  13. Disconnect the electric harness from the USB connector.
  14. Release the clips (x6) that attach the extension harness to the rear end module assembly, and then remove the center console extension harness from the rear end module assembly.

Install

  1. Install the clips (x6) that attach the center console extension harness to the rear end module assembly.
  2. Connect the electric harness to the USB connector.
  3. Connect the electric harness to the left horizontal actuator connector.
  4. Connect the electric harness to the right horizontal actuator connector.
  5. Connect the electric harness to the left vertical actuator connector.
  6. Connect the electric harness to the right vertical actuator connector.
  7. Install the center console rear end module. See Module - Rear End - Center Console (Remove and Install).
  8. Connect the LV power. See LV Power (Disconnect and Connect) (Modify).
  9. Install the center console LH and RH hockey sticks. See Hockey Stick Assembly -LH (with a Clip-secured Phone Dock) (Remove and Replace).
  10. Install the center console LH and RH front side panels. See Carpet - Side - Center Console - LH (Remove and Replace).
  11. Install the center console LH and RH rear side panels. See Panel - Rear Side - Center Console - LH (Remove and Replace).
  12. Install the center console rear end panel. See Panel - Rear End - Center Console (Remove and Replace).
  13. Install the center console phone dock. See Phone Dock (Clip) - Center Console (Remove and Replace).
  14. Raise all the windows and close all the doors.
