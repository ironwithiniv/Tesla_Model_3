Inductive Charger Assembly - Center Console (Model 3 Standard) (Remove and Replace)

Correction code 15190401902 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-09-05: Released new procedure.
Parent topic: 1519 - Center Console

Remove

  1. Remove the phone dock assembly. See Phone Dock Assembly - Center Console (Model 3 Standard) (Remove and Replace).
  2. Remove the screws (x3) that secure the wireless charger to the phone dock assembly.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 bit
  3. Remove the wireless charger module from phone dock assembly.
    Tip
    Release the 2 tabs at top of the assembly. Angle the wireless charger up and slide it out of the phone dock assembly.

Install

  1. Install the wireless charger module to the phone dock assembly.
    Note
    Slide the inductive charger into the phone dock assembly datums and positioning clips. Fully engage the tabs at the top of dock assembly.
  2. Install the screws (x3) that secure the wireless charger to the phone dock assembly.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 bit
  3. Install the phone dock assembly. See Phone Dock Assembly - Center Console (Model 3 Standard) (Remove and Replace).
