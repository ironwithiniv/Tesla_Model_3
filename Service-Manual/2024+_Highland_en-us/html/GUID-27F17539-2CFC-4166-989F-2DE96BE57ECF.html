Skid Plate - HV Battery - Front (Remove and Replace)

Correction code 1601010022 FRT 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-07-01: Added torque spec for non-e-coated skid plate.

Remove

  1. Remove the front aero shield. See Panel - Aero Shield - Front (Remove and Replace).
  2. Remove the bolts that attaches the front of the LH and RH front wheel liner to the HV battery.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket (for installation only)
  3. Remove the clips (x2) and bolts (x4) that attach the skid plate to the battery, and then remove the plate from the battery.
    Tip
    Use of the following tool(s) is recommended:
    • External Torx Plus EP10

Install

  1. Install the clips (x2) and bolts (x4) that attach the skid plate to the battery.
    Note
    There are two different skid plates, each with different fastener torque specs.
    Black skid plate (e-coated)
    13 Nm (9.6 lbs-ft)
    Silver skid plate (not e-coated)
    17 Nm (12.5 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • External Torx Plus EP10
  2. Install the bolts that attaches the front of the LH and RH front wheel liner to the HV battery.
    5 Nm (3.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket (for installation only)
  3. Install the front aero shield. See Panel - Aero Shield - Front (Remove and Replace).
