Ambient Lighting Brightwork Assembly - Rear - LH (China) (Remove and Replace)

Correction code 1513011702 FRT 0.48 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-06-16: Reduced the number of cut-off tabs and updated the routines.
  • 2024-08-28: Added a note to remind not to polish the tab near the ambient light.
Equipment:
  • 1082494-00-A Blow Gun
  • 2064251-00-A V Metal Wedge
  • 2145068-00-A Top Cutting Plier
  • 2082332-00-A Ultrasonic welding machine
Parent topic: 1513 - Door Trim

Remove

  1. Remove the NVH pad. See NVH Pad - Door - Rear - LH (Remove and Replace).
  2. Disconnect the LH rear door ambient light LED module connector.
  3. Use a paint pen to mark the heat staked tabs on the LH rear door trim.
    Note
    14x round tabs, 1x square tab
  4. Cut off the heat staked tabs for the LH rear door panel.
    CAUTION
    Do not cut the tab near the ambient light.
    CAUTION
    Be careful not to damage the door panel
    Note
    14x round tabs, 1x square tab
    Tip
    Use of the following tool(s) is recommended:
    • 2145068-00-A - Top Cutting Plier
  5. With assistance, release the tabs that attach the upper trim and ambient light brightwork assembly to the LH rear door panel.
    Note
    25x tabs, 1x locating tab
  6. Use the blow gun to clean the LH rear door lower trim.

Replace

  1. With assistance, install the ambient light brightwork to the LH rear door panel.
    Note
    16x tabs, 1x locating tab
    Note
    Make sure the labels are in place.
  2. With assistance, install the upper trim to the LH rear door panel.
    Note
    9x tabs
    Note
    Make sure the labels are in place.
  3. Check the clearance between the trim and the ambient light.
    Note
    Ensure that the upper trim and the ambient light do not interfere with each other, and the door trim and the ambient light do not interfere with each other. Adjust if necessary.
  4. With assistance. weld the heat staked tabs for the LH rear door panel.
    Note
    12x round tabs, 14x square tabs
    Note
    The solder joint tools are available in 2 types: round and square. Use the correct solder joint tools for welding.
    Note
    Ensure there is no large gap between the ambient light and door trim plate, and then push down slowly to make sure the weld spot is flat.
  5. Connect the LH rear door ambient light LED module connector.
  6. Install the NVH pad. See NVH Pad - Door - Rear - LH (Remove and Replace).
  7. Place the vehicle in Service Mode. See Service Mode.
  8. Unlock the gateway. See Gateway Unlock.
  9. Run PROC_VC_X_RGB-LIGHTS-ADDRESSINGvia Service Mode:
    • Low Voltage ➜ Lighting ➜ Address RGB Lights
    • Mid Voltage ➜ Lighting ➜ Address RGB Lights
    via Toolbox:(link)
  10. Reinstall the firmware. See Software Reinstall - Touchscreen.
  11. Exit Service Mode.
  12. Close the door and verify the operation of the manual door release lever, that the door latch releases smoothly and easily.
  13. Raise the LH front window and close the door.
