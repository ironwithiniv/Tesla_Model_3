Trim - B-Pillar - Middle - LH (Remove and Replace)

Correction code 1518010072 FRT 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1518 - Pillar and Sill Trim

Remove

  1. Remove the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  2. Remove the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  3. Remove the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  4. Remove the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  5. Remove the LH lower B-pillar trim. See Trim - B-Pillar - Lower - LH (Remove and Replace).
  6. Release the clips that attach the LH middle B-pillar to the body, and then remove the trim from the vehicle.
    Note
    Pull the bottom of the LH B-pillar middle trim towards the inside of the vehicle, and then pull the top of the trim to release the remaining upper clips.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.

Install

  1. Align the positioning clips (x3) to the slots, and then install the clips that attach the B-pillar middle trim to the vehicle.
    Note
    Make sure that the door seal corretly overlaps the LH middle B-pillar trim.
  2. Install the LH lower B-pillar trim. See Trim - B-Pillar - Lower - LH (Remove and Replace).
  3. Install the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  4. Install the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  5. Install the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  6. Install the 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
