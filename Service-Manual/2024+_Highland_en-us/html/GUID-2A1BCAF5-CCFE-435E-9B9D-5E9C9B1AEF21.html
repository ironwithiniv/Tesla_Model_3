Airbag - Knee - RH (Remove and Replace)

Correction code 2001010032 FRT 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-02-20: Added note on using PROC_RCM_DISARM if using this procedure to diagnose the SRS.
  • 2024-07-10: Updated the correction code to 2001010032.
Warning
If using this procedure to diagnosis the vehicle's Supplemental Restraint Systems (SRS), disarm the RCM, which will prevent all airbags and pretensioners from deploying. Re-arm the RCM after all of the vehicle's SRS components are re-installed.
  • Disarm RCM:PROC_RCM_DISARMvia Service Mode Plus:
    • Safety & Restraints ➜ Airbags ➜ Disarm RCM
    • Safety & Restraints ➜ Seats ➜ Disarm RCM
    via Toolbox:(link)
  • Re-arm RCM:PROC_RCM_ARMvia Service Mode Plus:
    • Safety & Restraints ➜ Airbags ➜ Re-Arm RCM
    • Safety & Restraints ➜ Seats ➜ Re-Arm RCM
    via Toolbox:(link)
Warning
Make sure 12V/LV power has been disconnected for at least 1 minute before disconnecting the electrical harness from Supplementary Restraint System (SRS) components, such as Restraint Control Module, sensors, airbags, etc. Disconnect the 12V/LV battery and the First Responder Loop. Failure to do so can result in unintended safety system behaviors. For more information on SRS precautions, see Airbag and Supplementary Restraint System (SRS) Precautions.
Warning
Supplementary Restraint System (SRS) components can be hazardous if not handled properly. For more information on SRS precautions, see Airbag and Supplementary Restraint System (SRS) Precautions.
Note
The passenger knee airbag is only equipped on North American vehicles.
CAUTION
Supplemental Restraint System (SRS) components can be hazardous if not serviced and handled correctly. See Airbag and Supplementary Restraint System (SRS) Precautions
CAUTION
In the event of an airbag or seatbelt pretensioner deployment, certain components must be replaced, and other components must be inspected for damage. Refer to the Collision Repair Manual for a specific list of items that must be inspected and replaced.

Remove

  1. Open the all doors and fully lower all windows.
  2. Disconnect LV power. See LV Power (Disconnect and Connect) (Modify).
  3. Remove the passenger footwell cover. See Cover - Footwell - Front Passenger (Remove and Replace).
  4. Remove the passenger knee airbag bolt covers.
  5. Remove and discard the bolts (x4) that attach the passenger knee airbag to the instrument panel.
    Tip
    Use of the following tool(s) is recommended:
    • External Torx E10
    • Cordless 3/8in Dr Impact
    • 3 in extension
    • Ratchet/torque wrench
  6. Disconnect the wiring harness connector from the passenger knee airbag, and then remove the airbag from the vehicle.
    Note
    Peel the back the plastic film.
  7. Use a 90-degree pick to apply pressure along the rear edge of the airbag assembly, and while doing so, flex the knee airbag cover surround to release each of the airbag tabs from the cover surround.
  8. Pivot the airbag up, unhook the tabs at the front of the airbag from the cover surround, and then remove the airbag from the cover.
    CAUTION
    Properly dispose of the airbag.

Install

  1. Install the passenger knee airbag to the passenger knee airbag cover.
    Note
    Engage the rear tabs first and then press to engage the front tabs to hook the metal tabs.
  2. Connect the wiring harness connector to the passenger knee airbag, and then install the passenger knee airbag to the vehicle.
    Note
    Place the plastic film back over the squib assembly.
  3. Install new bolts (x4) that attach the passenger knee airbag to the instrument panel.
    8.5 Nm (6.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • External Torx E10
    • Cordless 3/8in Dr Impact
    • 3 in extension
    • Ratchet/torque wrench
  4. Install the passenger knee airbag bolt covers.
  5. Install the passenger footwell cover. See Cover - Footwell - Front Passenger (Remove and Replace).
  6. Connect LV power. See LV Power (Disconnect and Connect) (Modify).
  7. Raise all windows and close all doors.
