Sensor - Pressure Tube - Pedestrian Protection (Remove and Replace)

Correction code 2020010102 FRT 0.72 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-07-27: Added the LV disconnecting/connecting steps to ensure safety during operation.
  • 2025-12-19: Removed the LV disconnecting/connecting steps and added post-replacement routines.
  • 2024-04-01: Updated the description of installing the protection pressure tube sensor assembly and FRT per the validation.
CAUTION
Supplemental Restraint System (SRS) components can be hazardous if not serviced and handled correctly. See Airbag and Supplementary Restraint System (SRS) Precautions
CAUTION
In the event of an airbag or seatbelt pretensioner deployment, certain components must be replaced, and other components must be inspected for damage. Refer to the Collision Repair Manual for a specific list of items that must be inspected and replaced.
Parent topic: 2020 - Sensors

Remove

  1. Open the LH front door and lower the LH front window.
  2. Disconnect the LV battery power. See LV Power (Disconnect and Connect) (Modify).
  3. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  4. Remove the bolts (x5) that attach the upper portion of the front fascia to the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  5. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  6. Remove the front fascia assembly from the vehicle. See Fascia - Front (Remove and Install).
  7. Disconnect the LH and RH front pedestrian protection pressure tube sensor connectors.
    Note
    Do not push down on the red tab. Pull the red tab to disengage the lock, then pull it again to release the connector.
  8. Remove and discard the clips (x4) that attach the front bumper beam foam to the bumper beam.
  9. Remove and discard the clips (x2) that attach the pedestrian protection pressure tube sensor assembly to the bumper beam foam, and then remove the sensor assembly from the vehicle.

Install

  1. Position the protection pressure tube sensor assembly to the front bumper beam foam, and then install new clips (x2) that attach the LH and RH pedestrian protection pressure tube sensors.
  2. Install new clips (x4) to attach the front bumper beam foam to the bumper beam.
  3. Engage the locking tabs to connect the LH and RH front pedestrian protection pressure tube sensor connectors.
  4. Install the front fascia. See Fascia - Front (Remove and Install).
  5. Install the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  6. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  7. Connect the LV battery power. See LV Power (Disconnect and Connect) (Modify).
  8. Unlock the vehicle gateway, See Gateway Unlock.
  9. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): PROC_RCM_X_SERVICE-TASKSvia Service Mode Plus:Safety & Restraints ➜ Safety Testing ➜ RCM Service Tasksvia Toolbox:(link)
  10. Exit Service Mode Plus.
  11. Raise the LH front window and close the LH front door.
  12. Remove the lift arms from below the vehicle.
