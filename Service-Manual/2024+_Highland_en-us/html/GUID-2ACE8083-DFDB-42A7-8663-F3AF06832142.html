Window Motor / Regulator Assembly - Rear - LH (Remove and Replace)

Correction code 1150010062 FRT 0.54 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1150 - Door Glass and Regulators

Torque Specifications

Table 1. Torque Specifications: Window Motor / Regulator Assembly - Rear - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Screws (x12) that attach the LH rear window motor/regulator assembly to the LH rear door
4 Nm (2.9 lbs-ft)
  • 8 mm socket
 Reuse

Remove

  1. Open the LH front door and lower the LH front window.
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Remove the LH rear door puddle light. See Puddle Lamp - Rear Door (Remove and Replace).
  4. Remove the LH rear door trim panel. See Panel - Door Trim - Rear - LH (Remove and Replace).
  5. Remove the LH rear door glass. See Glass - Door - Rear - LH (Remove and Replace).
  6. Disconnect LV power. See LV Power (Disconnect and Connect) (Modify).
  7. Disconnect the electrical harness from the LH rear window motor/regulator assembly.
  8. Disconnect the electrical harness from the LH rear door pressure sensor.
  9. Release the clips (x2) that attach the LH rear door harness to the LH rear window motor/regulator assembly.
  10. Release the clip that attaches the manual latch release cable to the LH rear window motor/regulator assembly.
  11. Remove the screws (x12) and release the metal clips (x2) that attach the LH rear window motor/regulator assembly to the LH rear door, and then remove the assembly from the door.
    CAUTION
    Never loosen or remove the nuts (x4) that attach the regulator arms to the assembly closeout panel.
    Tip
    Use of the following tool(s) is recommended:
    • 8 mm socket

Install

  1. Inspect the condition of the mounting holes for the LH rear window motor/regulator assembly.
    Note
    Install rivnuts where any of the mounting hole threads are stripped. Use a 7.5mm drill to prepare the hole for rivnut installation.
  2. Install the LH rear window motor/regulator assembly to the LH rear door, hand-install the screws (x12) and fasten the metal clips that attach the assembly to the door, and then tighten the screws.
    4 Nm (2.9 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 8 mm socket
  3. Fasten the clips (x2) that attach the LH rear door harness to the LH rear window motor/regulator assembly.
  4. Connect the electrical harness to the LH rear window motor/regulator assembly.
  5. Connect the electrical harness to the LH rear door pressure sensor.
  6. Fasten the clip that attaches the manual latch release cable to the LH rear window motor/regulator assembly.
  7. Connect LV power. See LV Power (Disconnect and Connect) (Modify).
  8. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  9. Install the LH rear door glass. See Glass - Door - Rear - LH (Remove and Replace).
  10. Install the LH rear door puddle light. See Puddle Lamp - Rear Door (Remove and Replace).
  11. Install the LH rear door trim panel. See Panel - Door Trim - Rear - LH (Remove and Replace).
  12. Calibrate the LH rear window regulator. See Window Regulator (Recalibrate) (Maintenance).
  13. Raise the LH front window and close the LH front door.
