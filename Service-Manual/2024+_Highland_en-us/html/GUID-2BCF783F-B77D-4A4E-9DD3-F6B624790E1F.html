Subframe Assembly - Rear (Partial Drop) (Remove and Install)

Correction code 30010231 FRT 2.10 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

CAUTION
Do not use this procedure by itself. This procedure should only be used when it is referenced by another procedure.
Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
Parent topic: 3001 - Chassis and Subframes

Partially Lower Rear Subframe

  1. Support the vehicle on a 2-post lift and remove both rear wheels. See Wheel Assembly (Remove and Install).
  2. Open all four doors
  3. Lower all four windows
  4. Open trunk from exterior switch
  5. Move LH front seat forward
  6. Move RH front seat forward
  7. Place vehicle in service mode
    Note
    Via UI > Controls > Software, Touch and hold "Model 3" for 4 seconds then release, Use screen keyboard to type "service" into dialog box then select OK
  8. Place vehicle into tow mode
    Note
    Via Controls > Service > ''Towing''
  9. Disconnect LV power and perform Vehicle HV Disablement. See Vehicle HV Disablement Procedure.
  10. Remove LH trough trim
    Note
    3x clips, 1x bolt, T20, 1.2Nm
  11. Remove RH trough trim
    Note
    3x clips, 1x bolt, T20, 1.2Nm
  12. Remove bolt securing LH corner of rear fascia to body
    Note
    1x bolt, 10mm, 4 Nm
  13. Remove bolt securing RH corner of rear fascia to body
    Note
    1x bolt, 10mm, 4 Nm
  14. Raise vehicle fully and lower lift onto locks
    Note
    Set vehicle to comfortable working height, Make sure there's an audible click of the locks on both sides before lowering, otherwise vehicle may tilt to the side, Verify doors are clear of surrounding objects
  15. Remove rear aero shield clips
    Note
    2x clips, One clip on LH side wheel liner, One clip on RH side wheel liner
  16. Remove rear aero shield
    Note
    11x bolts, 10mm, 5 Nm
  17. Remove LH rear suspension cover
    Note
    1x bolt, 10mm, 6 Nm, 2x tabs
  18. Remove RH rear suspension cover
    Note
    1x bolt, 10mm, 6 Nm, 2x tabs
  19. Remove lower clips securing LH rear wheel liner
    Note
    3x push clips
  20. Remove lower clips securing RH rear wheel liner
    Note
    3x push clips
  21. Remove bolts securing rear diffuser to body
    Note
    4x bolts, 10mm, 4 Nm, 2x fastener covers
  22. Lower vehicle partially and set lift onto locks
    Note
    Raise lift off locks, then hold lock release lever to keep locks free while vehicle is lowered, Set vehicle to comfortable working height
  23. Remove screw securing rear fascia to LH quarter panel
    Note
    1x screw, T25, 2 Nm
  24. Remove screw securing rear fascia to RH quarter panel
    Note
    1x screw, T25, 2 Nm
  25. Remove rear fascia
    Note
    2x connector, Recommend assistance, place on padded surface
  26. Remove LH rear brake caliper from knuckle and hang from body
    CAUTION
    Make sure the brake caliper and hoses are not twisted when hanging the caliper or during reinstallation, as this can damage the brake hose.
    Note
    2x bolts, E18, 83 Nm, Discard after removal, Hand tighten lug nut to secure rotor on early production vehicles
  27. Install spring compressor onto LH rear coil spring
    Note
    Tooling may vary per service center, Reference photos for clarification
  28. Remove RH rear brake caliper from knuckle and hang from body
    CAUTION
    Make sure the brake caliper and hoses are not twisted when hanging the caliper or during reinstallation, as this can damage the brake hose.
    Note
    2x bolt, E18, 83 Nm, Discard bolts after removal, Hand tighten lug nut to secure rotor on early production vehicles
  29. Install spring compressor onto RH rear coil spring
    Note
    Tooling may vary per service center, Reference photos for clarification
  30. Remove nut securing RDU ground strap to vehicle
    Note
    1x nut, 10mm, 10 Nm, Located at LH rear wheel well area
  31. Raise vehicle fully and lower lift onto locks
    Note
    Set vehicle to comfortable working height, Make sure there's an audible click of the locks on both sides before lowering, otherwise vehicle may tilt to the side, Verify doors are clear of surrounding objects
  32. Disconnect RH side subframe harness connector
    Note
    1x connector, Release locking tab
  33. Remove RH side subframe harness clip from body
    Note
    2x clips
  34. Remove nut securing LH rear stabilizer bar end link to stabilizer bar
    Note
    1x nyloc nut, 15mm, 55 Nm, Break nut loose then counter-hold ball joint with 5mm hex, Discard after removal
  35. Remove stabilizer bar from LH rear end link
    Note
    May need to move the stabilizer bar up/down to get the correct angle to remove end link
  36. Remove nut securing RH rear stabilizer bar end link to stabilizer bar
    Note
    1x nyloc nut, 15mm, 55 Nm, Break nut loose then counter-hold ball joint with 5mm hex, Discard after removal
  37. Remove stabilizer bar from RH rear end link
    Note
    May need to move the stabilizer bar up/down to get the correct angle to remove end link
  38. Position support stand to support front portion of rear subframe
  39. Remove bolts securing rear stabilizer bar to subframe and remove assembly
    Note
    4x patch bolts, 11mm, 30 Nm, Discard after removal
  40. Remove support stand from under vehicle
  41. Release clips securing coolant hoses to LH shear plate
    Note
    2x fir tree clips
  42. Release LH side hose clip from rear battery skid plate enclosure
    Note
    1x fir tree clip
  43. Release RH side hose clips from rear battery skid plate enclosure
    Note
    2x fir tree clips
  44. Release clips securing coolant hoses to RH shear plate
    Note
    2x fir tree clips
  45. Remove lower bolts securing HV battery rear skid plate enclosure
    Note
    2x bolts, EP10, 13 Nm, Older VINs may be equipped with additional fastener count
  46. Remove upper nut securing HV battery rear skid plate enclosure
    Note
    1x nut, 10mm, 13 Nm, Fastener count may vary on older built vehicles
  47. Remove upper bolts securing HV battery rear skid plate enclosure
    Note
    4x bolts, 13mm, 35 Nm
  48. Remove HV battery rear skid plate enclosure
  49. Release push clips securing RH rear wheel liner to rocker panel
    Note
    2x clips, Remove indicated clips and move liner aside for access
  50. Release RDU inverter inlet tube from RDU HV cable harness
    Note
    1x fir tree clip
  51. Remove nut securing RDU HV cable bracket to HV battery
    Note
    1x nut, 10mm, 10 Nm
  52. Disconnect RDU HV cable from HV battery
    Note
    1x connector, Release locking tab and rotate the release lever up to disengage the connector, Do not force the release lever up, Ensure the alignment tabs on the RDU header are not damaged
  53. Place subframe lifting tool into position underneath rear subframe
  54. Connect air supply to subframe lifting tool
  55. Raise subframe lifting tool to support rear subframe
    Note
    3x straps, Attach metal hooks at the end of straps to rings on subframe lifting tool and pull straps until secure, Lower the vehicle if necessary, Recommend assistance
  56. Lock the subframe lifting tool wheel(s) so that the assembly will not move during service.
  57. Remove upper bolts securing LH damper to body
    Note
    2x bolts, 15mm, 41 Nm
  58. Remove upper bolts securing RH damper to body
    Note
    2x bolts, 15mm, 41 Nm
  59. Mark LH rear and RH rear subframe bolts
    Note
    2x bolts, Mark original location of subframe, Re-align during install, Can also mark subframe casting and subframe bushing to body if needed
  60. Remove smaller fasteners securing LH shear plate
    Note
    2x bolts, 13mm, 35 Nm
  61. Remove large bolt securing LH shear plate and subframe to body and remove shear plate
    Note
    1x bolt, 21mm, 130 Nm, Discard after removal
  62. Remove smaller fasteners for RH shear plate
    Note
    2x bolts, 13mm, 35 Nm
  63. Remove large bolt securing RH shear plate and subframe to body and remove shear plate
    Note
    1x bolt, 21mm, 130 Nm, Discard after removal
  64. Remove LH rear bolt securing subframe to body
    Note
    1x bolt, 21mm, 160 Nm, Discard after removal
  65. Remove RH rear bolt securing subframe to body
    Note
    1x bolt, 21mm, 160 Nm, Discard after removal
  66. Partially lower the rear subframe and drive unit assembly
    CAUTION
    Do not lower the subframe more than 21 cm. Gradually and carefully lower the subframe, as coolant hoses, suspension links, and other components will still be attached to the vehicle. Monitor these components for tension while incrementally lowering the vehicle.

Raise Rear Subframe

  1. Raise the partially lowered subframe
    Note
    Use caution to not damage components while raising subframe
  2. Install RH rear bolt securing rear subframe to body hand tight
    Note
    1x bolt, 21mm, 160 Nm, Install new bolt, Torque at later step
  3. Install LH rear bolt securing rear subframe to body hand tight
    Note
    1x bolt, 21mm, 160 Nm, Install new bolt, Torque at later step
  4. Install LH front bolt and shear plate to rear subframe hand tight
    Note
    1x bolt, 21mm, 130 Nm, Install new bolt, Torque at later step
  5. Install bolts securing LH shear plate to HV battery hand tight
    Note
    2x bolts, 13mm, 35 Nm, Torque at a later step
  6. Install RH front bolt and shear plate to rear subframe hand tight
    Note
    1x bolt, 21mm, 130 Nm, Install new bolt, Torque at later step
  7. Install bolts securing RH shear plate to HV battery hand tight
    Note
    2x bolts, 13mm, 35 Nm, Torque at a later step
  8. Position subframe to marked location
    Note
    Use previous markings to align subframe to body, Return to original position as close as possible
  9. Torque bolt securing RH rear of subframe to body
    Note
    1x rear bolt, 21mm, 160 Nm, Mark bolt after torque
  10. Torque bolt securing LH rear of subframe to body
    Note
    1x rear bolt, 21mm, 160 Nm, Mark bolt after torque
  11. Torque bolt securing subframe and LH shear plate to body
    Note
    1x front bolt, 21mm, 130 Nm, Mark bolt after torque
  12. Torque bolt securing subframe and RH shear plate to body
    Note
    1x front bolt, 21mm, 130 Nm, Mark bolt after torque
  13. Torque bolts securing shear plates to vehicle
    Note
    4x bolts, 13mm, 35 Nm
  14. Install upper bolts securing LH damper to body
    Note
    2x bolts, 15mm, 41 Nm
  15. Install bolts securing RH damper to body at top mount
    Note
    2x bolts, 15mm, 41 Nm
  16. Lower rear subframe lifting tool from vehicle
    Note
    Verify yellow safety straps are removed from subframe
  17. Disconnect air supply from subframe lifting tool
  18. Remove subframe lifting tool from underneath vehicle
  19. Connect RDU HV cable to HV battery
    Note
    1x connector, Make sure the connector lock is 90 degrees from the connector before beginning to secure the connector, Use one hand to support the connector while other latching locking tab. Once installed, verify that the latch is not damaged and fully secured in the latched position
  20. Install nut securing RDU HV cable bracket to HV battery
    Note
    1x nut, 10mm, 10 Nm, Number of fasteners may vary
  21. Secure RDU inverter inlet tube onto RDU HV cable harness
    Note
    1x fir tree clip
  22. Secure push clips securing RH rear wheel liner to rocker panel
    Note
    2x clips
  23. Position HV battery rear skid plate enclosure onto HV battery for installation
    Note
    Recommend assistance if needed
  24. Install upper bolts securing HV battery rear skid plate enclosure hand tight
    Note
    4x bolts, 13mm, 35 Nm, Torque at later step
  25. Install upper nut securing HV battery rear skid plate enclosure hand tight
    Note
    1x nut, 10mm, 13 Nm, Torque at later step
  26. Install lower bolts securing HV battery rear skid plate enclosure
    Note
    2x bolts, EP10, 13 Nm, Earlier VINs may be equipped with additional bolts
  27. Torque bolts securing HV battery rear skid plate enclosure to vehicle
    Note
    4x bolts, 13mm, 35 Nm
  28. Torque upper nut securing HV battery rear skid plate enclosure
    Note
    1x nut, 10mm, 13 Nm
  29. Install clips securing coolant hoses to RH shear plate
    Note
    2x fir tree clips
  30. Install RH side hose clips to HV battery rear skid plate enclosure
    Note
    2x fir tree clips
  31. Install LH side hose clip to HV battery rear skid plate enclosure
    Note
    1x clip
  32. Install clips securing coolant hoses to LH shear plate
    Note
    2x fir tree clips
  33. Place stabilizer bar into position for installation and raise stand to support stabilizer bar
  34. Position rear stabilizer bar into vehicle and install fasteners
    Note
    4x patch bolts, 11mm, 30 Nm, Position rear stabilizer bar into vehicle, Thread in fasteners and torque down evenly, Install new patch bolts
  35. Position LH rear end link into stabilizer bar
    Note
    Adjust the end link to align with stabilizer bar, Also may need to move the stabilizer bar up/down to get the correct angle to install end link
  36. Install nut securing LH rear end link to stabilizer bar
    Note
    1x nyloc nut, 15mm, 55 Nm, Counter-hold ball joint with 5mm hex, Install new nyloc nut, Mark bolt after torque
  37. Position RH rear end link into stabilizer bar
    Note
    Adjust the end link to align with stabilizer bar, Also may need to move the stabilizer bar up/down to get the correct angle to install end link
  38. Install nut securing RH rear end link to stabilizer bar
    Note
    1x nyloc nut, 15mm, 55 Nm, Counter-hold ball joint with 5mm hex, Install new nyloc nut, Mark bolt after torque
  39. Remove support stand from under vehicle
  40. Install RH side subframe harness clip to body
    Note
    2x clips
  41. Connect RH side subframe harness connector
    Note
    1x connector
  42. Lower vehicle partially and set lift onto locks
    Note
    Raise lift off locks, then hold lock release lever to keep locks free while vehicle is lowered, Set vehicle to comfortable working height
  43. Install RDU ground strap
    Note
    1x bolt, 10mm, 10 Nm, Re-install 1x washer if vehicle had this washer during removal, Located at LH rear wheel well area
  44. Install LH rear brake caliper onto knuckle
    CAUTION
    Make sure the brake caliper and hoses are not twisted when hanging the caliper or during reinstallation, as this can damage the brake hose.
    Note
    2x bolt, E18, 83 Nm, Install new bolts, Remove the S-hook from vehicle
  45. Remove spring compressor from LH rear coil spring
  46. Install RH rear brake caliper onto knuckle
    CAUTION
    Make sure the brake caliper and hoses are not twisted when hanging the caliper or during reinstallation, as this can damage the brake hose.
    Note
    2x bolt, E18, 83 Nm, Install new bolts, Remove the S-hook from vehicle
  47. Remove spring compressor from RH rear coil spring
    Note
    Tooling may vary per service center
  48. Install rear fascia
    Note
    2x connector, Recommend assistance
  49. Raise vehicle fully and lower lift onto locks
    Note
    Set vehicle to comfortable working height, Make sure there's an audible click of locks on both sides before lowering, otherwise vehicle may tilt to side
  50. Install LH rear suspension cover
    Note
    1x bolt, 10mm, 6 Nm, 2x tabs
  51. Install RH rear suspension cover
    Note
    1x bolt, 10mm, 6 Nm, 2x tabs
  52. Install rear aero shield
    Note
    11x bolts, 10mm, 5 Nm, Apply Loctite 222 onto rear aero shield bolts
  53. Install LH and RH clips securing rear aero shield to wheel house liner
    Note
    2x clips
  54. Install bolts securing rear diffuser to body
    Note
    4x bolts, 10mm, 4 Nm, 2x fastener covers, Apply Loctite 222 onto bolts
  55. Lower vehicle partially and set onto locks
    Note
    Raise lift off locks, then hold lock release lever to keep locks free while vehicle is lowered, Set vehicle to comfortable working height
  56. Install U-nut and screw securing rear fascia to LH quarter panel
    Note
    1x screw, T25, 2 Nm,
  57. Install U-nut and screw securing rear fascia to RH quarter panel
    Note
    1x screw, T25, 2 Nm
  58. Install lower clips securing RH rear wheel liner
    Note
    3x push clips
  59. Install lower clips securing LH rear wheel liner
    Note
    3x push clips
  60. Install bolt securing RH corner of rear fascia
    Note
    1x bolt, 10mm, 4 Nm
  61. Install bolt securing LH corner of rear fascia
    Note
    1x bolt, 10mm, 4 Nm
  62. Install RH trough trim
    Note
    3x clips, 1x bolt, T20, 1.2Nm
  63. Install LH trough trim
    Note
    3x clips, 1x bolt, T20, 1.2Nm
  64. Reinstall both rear wheels. See Wheel Assembly (Remove and Install).
  65. Connect 2nd row seat harness and secure cushion
    Note
    2x clips, 2x connectors, Insert buckles through holes, Slide rear inward then align front clips, Perform push-pull-push test
  66. Connect First Responder Loop and LV battery
    Note
    2x connectors, Secure FRL first, Seat LV battery connection and push black connector lock inwards to secure, Engage green locking tab when fully seated
  67. Install rear underhood apron
    Note
    14x clips, Hold rear wall of frunk to keep from flexing while engaging front clips
  68. Close hood
  69. Move RH front seat to original position
  70. Move LH front seat to original position
  71. Hold brake pedal and select park on UI to disable EPB service mode
  72. Close trunk via interior switch
  73. Raise all windows
  74. Close all four doors
  75. Remove lift arms from below vehicle
    Note
    Lower rack arms fully and remove them from under vehicle
  76. Refer to the alignment requirement matrix to determine the need for suspension alignment. See Alignment Requirement - Suspension.
