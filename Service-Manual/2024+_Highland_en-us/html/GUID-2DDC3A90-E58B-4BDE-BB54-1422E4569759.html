Airbag - Front Passenger (NA) (Remove and Replace)

Correction code 2001010012 FRT 0.54 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-02-20: Added note on using PROC_RCM_DISARM if using this procedure to diagnose the SRS.
Warning
If using this procedure to diagnosis the vehicle's Supplemental Restraint Systems (SRS), disarm the RCM, which will prevent all airbags and pretensioners from deploying. Re-arm the RCM after all of the vehicle's SRS components are re-installed.
  • Disarm RCM:PROC_RCM_DISARMvia Service Mode Plus:
    • Safety & Restraints ➜ Airbags ➜ Disarm RCM
    • Safety & Restraints ➜ Seats ➜ Disarm RCM
    via Toolbox:(link)
  • Re-arm RCM:PROC_RCM_ARMvia Service Mode Plus:
    • Safety & Restraints ➜ Airbags ➜ Re-Arm RCM
    • Safety & Restraints ➜ Seats ➜ Re-Arm RCM
    via Toolbox:(link)
Warning
Make sure LV power has been disconnected for at least 2 minutes before disconnecting the electrical harness from Supplementary Restraint System (SRS) components, such as Restraint Control Module, sensors, airbags, etc. Failure to do so can result in unintended safety system behaviors. For more information on SRS precautions, see Airbag and Supplementary Restraint System (SRS) Precautions.
Warning
Supplementary Restraint System (SRS) components can be hazardous if not handled properly. For more information on SRS precautions, see Airbag and Supplementary Restraint System (SRS) Precautions.
CAUTION
Supplemental Restraint System (SRS) components can be hazardous if not serviced and handled correctly. See Airbag and Supplementary Restraint System (SRS) Precautions
CAUTION
In the event of an airbag or seatbelt pretensioner deployment, certain components must be replaced, and other components must be inspected for damage. Refer to the Collision Repair Manual for a specific list of items that must be inspected and replaced.

Torque Specifications

Table 1. Torque Specifications: Airbag - Front Passenger (NA) (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x6) that attach the passenger air bag to the vehicle
8.5 Nm (6.3 lbs-ft)
  • External Torx E10
  • Cordless 3/8in Dr Impact
  • 6 in extension
  • Ratchet/torque wrench
 Replace 1116594-00-B

Remove

  1. Disconnect LV power. See LV Power (Disconnect and Connect) (Modify).
  2. Remove the front passenger knee airbag. See Airbag - Knee - RH (Remove and Replace).
  3. Remove the RH air wave duct. See Duct - Air Wave - RH (Remove and Replace).
  4. Disconnect the connectors (x3) that connect the passenger airbag to the vehicle.
    Note
    Release each white tab at the same time to disconnect the connectors.
  5. Remove and discard bolts (x6) that attach the passenger air bag to the vehicle.
    Note
    Harnesses may need to be manipulated to gain access to frontmost bolts.
    Tip
    Use of the following tool(s) is recommended:
    • External Torx E10
    • Cordless 3/8in Dr Impact
    • 6 in extension
    • Ratchet/torque wrench
  6. Remove the air bag from the vehicle.

Install

  1. Install new bolts (x6) that attach the passenger air bag to the vehicle.
    8.5 Nm (6.3 lbs-ft)
    Note
    Harnesses may need to be manipulated to gain access to frontmost bolts.
    Tip
    Use of the following tool(s) is recommended:
    • External Torx E10
    • Cordless 3/8in Dr Impact
    • 6 in extension
    • Ratchet/torque wrench
  2. Connect the connectors (x3) that connect the passenger airbag to the vehicle.
  3. Install the RH air wave duct. See Duct - Air Wave - RH (Remove and Replace).
  4. Install the front passenger knee airbag. See Airbag - Knee - RH (Remove and Replace).
  5. Connect LV power. See LV Power (Disconnect and Connect) (Modify).
