Harness - Rear Door - LH (Remove and Replace)

Correction code 1710020032 FRT 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1454796-00-A WINDOW SWITCH TOOL
  • 1588903-00-A BODY GAP AND FLUSH TOOL
Parent topic: 1710 - Harnesses

Remove

  1. Open the LH front door and lower the LH front window.
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Remove the LH rear door puddle light. See Puddle Lamp - Rear Door (Remove and Replace).
  4. Remove the LH rear door trim panel. See Panel - Door Trim - Rear - LH (Remove and Replace).
  5. Remove the LH rear door glass. See Glass - Door - Rear - LH (Remove and Replace).
  6. Disconnect LV power. See LV Power (Disconnect and Connect) (Modify).
  7. Remove the LH rear window regulator assembly. See Window Motor / Regulator Assembly - Rear - LH (Remove and Replace).
  8. Disconnect the electrical connector from the LH rear door latch.
  9. Disconnect the electrical connector from the LH rear door handle sensor.
  10. Release the clips (x7) that attach the LH rear door harness to the LH rear door.
  11. Release the LH rear door harness seal from the front of the LH rear door.
  12. Release the tabs (x4) that attach the LH rear door harness seal to the B-pillar.
  13. Disconnect the LH rear door harness connector from the LH body harness.
  14. Push the LH rear door harness through the front inner door harness port, and then remove the harness from the vehicle.

Install

  1. Feed the LH rear door harness through the front inner door harness port.
  2. Connect the LH rear door harness connector to the LH body harness.
  3. Secure the tabs (x4) that attach the LH rear door harness seal to the B-pillar.
  4. Install the LH rear door harness seal to the front of the LH rear door.
  5. Fasten the clips (x7) that attach the LH rear door harness to the LH rear door.
  6. Connect the electrical connector to the LH rear door latch.
  7. Connect the electrical connector to the LH rear door handle sensor.
  8. Install the LH rear window regulator assembly. See Window Motor / Regulator Assembly - Rear - LH (Remove and Replace).
  9. Connect LV power. See LV Power (Disconnect and Connect) (Modify).
  10. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  11. Install the LH rear door glass. See Glass - Door - Rear - LH (Remove and Replace).
  12. Install the LH rear door puddle light. See Puddle Lamp - Rear Door (Remove and Replace).
  13. Install the LH rear door trim panel. See Panel - Door Trim - Rear - LH (Remove and Replace).
  14. Calibrate the window. See Window Regulator (Recalibrate) (Maintenance).
  15. Raise the LH front window and close the LH front door.
