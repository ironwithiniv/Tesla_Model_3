Check Strap - Door - Front - LH (Remove and Replace)

Correction code 1133010012 FRT 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1454796-00-A TOOLKIT, WINDOW SWITCH
Parent topic: 1133 - Closure Assist Mechanisms and Hinges

10 Nm (7.4 lbs-ft)

 Reuse

Remove

  1. Remove the LH front door reflector. See Reflector - Door - Front - LH (Remove and Replace).
  2. Remove the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
  3. Remove the LH front door puddle light. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  4. Remove the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  5. Connect the window switch tool to the LH front door harness and fully raise the front LH door window.
  6. Disconnect the electrical connector from the front door speaker.
  7. Remove the bolts (x4) and tabs (x4) that attach the front door speaker to the LH front door, and then remove the speaker.
    Tip
    Use of the following tool(s) is recommended:
    • 8 mm socket
  8. Remove the bolt that attaches the LH front door check strap to the A-pillar.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  9. Use a plastic trim to release the clips (x3) that attach the LH front door check strap to the LH front door.
  10. Remove the nuts (x2) that attach the check strap to the LH front door.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm 12-point deep socket
  11. Reach inside the speaker bracket opening and remove the check strap from the vehicle.

Install

  1. Reach inside the speaker bracket opening and install the check strap to the vehicle.
  2. Install the nuts (x2) that attach the check strap to the LH front door.
    10 Nm (7.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm 12-point deep socket
  3. Fasten the clips (x3) that attach the LH front door check strap to the LH front door.
  4. Install the bolt that attaches the LH front door check strap to the A-pillar.
    24 Nm (17.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  5. Install the bolts (x4) and tabs (x4) that attach the front door speaker to the LH front door.
    4 Nm (2.9 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 8 mm socket
  6. Connect the electrical connector to the front door speaker.
  7. Fully lower the LH front door window and disconnect the window switch tool from the LH front door harness.
  8. Install the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  9. Install the LH front door puddle light. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  10. Install the LH front door reflector. See Reflector - Door - Front - LH (Remove and Replace).
  11. Install the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
