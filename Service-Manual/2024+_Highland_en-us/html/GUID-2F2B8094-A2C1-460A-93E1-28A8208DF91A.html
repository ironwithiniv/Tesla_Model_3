Steering Column (RHD) (Remove and Replace)

Correction code 3205011112 1.68 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

CAUTION
If performing this procedure as a result of a collision, see the Collision Repair Manual to verify whether the steering gear must be replaced as well.
Parent topic: 3205 - Upper Column, Steering Wheel

  • 2024-12-02: Updated steering column configuration and calibration steps.

 Reuse

Remove

  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Disconnect LV power. See LV Power (Disconnect and Connect) (Modify).
  3. Remove the cabin intake duct. See Assembly - Fresh Air Gutter - HVAC (Remove and Replace).
  4. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  5. Remove the LH and RH IP end caps. See End Cap - Instrument Panel - LH (Remove and Replace).
  6. Remove the LH and RH upper A-pillar trims. See Trim - A-Pillar - Upper - LH (Remove and Replace).
  7. Remove the driver footwell cover. See Cover - Footwell - Driver (RHD) (Remove and Replace).
  8. Remove the driver footwell duct. See Duct - Footwell - RH (RHD) (Remove and Replace).
  9. Remove the passenger footwell cover. See Cover - Footwell - Front Passenger (RHD) (Remove and Replace).
  10. Remove the glove box. See Glove Box (RHD) (Remove and Replace).
  11. Remove the passenger footwell duct. See Duct - Footwell - RH (RHD) (Remove and Replace).
  12. Remove the LH air wave duct. See Duct - Air Wave - LH (RHD) (Remove and Replace).
  13. Remove the driver footwell cover. See Cover - Footwell - Driver (Remove and Replace).
  14. Remove the lower instrument panel. See Assembly - Instrument Panel - Lower (Remove and Replace).
  15. Remove the driver airbag. See Airbag - Driver (Remove and Replace).
  16. Remove the steering wheel. See Steering Wheel (Remove and Replace).
  17. Remove the steering wheel upper shroud. See Shroud - Upper - Steering Column (Remove and Replace).
  18. Remove the steering wheel lower shroud. See Shroud - Lower - Steering Column (Remove and Replace).
  19. Remove the steering column control module. See Module - Steering Column Control (Remove and Replace).
  20. Remove the IP service panel. See Service Panel - Instrument Panel (Remove and Replace).
  21. Remove the touchscreen. See Touchscreen - Front (Remove and Replace)
  22. Remove the IP speaker grille. See Speaker Grille - Instrument Panel (Remove and Replace).
  23. Remove the LH and RH dash speakers. See Speaker - Dash - LH (Remove and Replace).
  24. Remove the center dash speaker. See Speaker - Dash - Center (Remove and Replace).
  25. Remove the IP carrier. See IP Carrier (Remove and Replace).
  26. Remove the steering wheel lower gap hider. See Gap Hider - Steering Column - Lower (Remove and Replace).
  27. Remove the steering wheel upper gap hider. See Gap Hider - Steering Column - Upper (Remove and Replace).
  28. Remove the RH air wave duct. See .
  29. Disconnect the IP harness electrical connector from the steering column.
  30. Release the steering column boot from the bulkhead, and then push the upper portion of the boot into the cabin.
  31. Remove the bolt that attaches the steering gear assembly to the electric steering column.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
    • Ratchet/torque wrench
  32. Slide the steering column intermediate shaft upwards and off of the steering gear input shaft.
  33. Remove the nuts (x4) that attach the steering column to the cross car beam.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  34. Remove the steering column from the vehicle.

Install

  1. Place the steering column into position for installation.
  2. Install the nuts (x4) that attach the steering column to the cross car beam.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  3. With assistance, slide the steering column intermediate shaft downward and on the steering gear input shaft, making sure the shaft is aligned and fully seated.
  4. Install the bolt that attaches the steering gear assembly to the electric steering column.
    18 Nm (13.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
    • Ratchet/torque wrench
  5. Install the steering column boot on the bulkhead, as shown.
  6. Connect the IP harness electrical connector to the steering column.
  7. Install the RH air wave duct. See .
  8. Install the steering wheel upper gap hider. See Gap Hider - Steering Column - Upper (Remove and Replace).
  9. Install the steering wheel lower gap hider. See Gap Hider - Steering Column - Lower (Remove and Replace).
  10. Install the IP carrier. See IP Carrier (Remove and Replace).
  11. Install the LH and RH dash speakers. See Speaker - Dash - LH (Remove and Replace).
  12. Install the center dash speaker. See Speaker - Dash - Center (Remove and Replace).
  13. Install the IP speaker grille. See Speaker Grille - Instrument Panel (Remove and Replace).
  14. Install the touchscreen. See Touchscreen - Front (Remove and Replace)
  15. Install the IP service panel. See Service Panel - Instrument Panel (Remove and Replace).
  16. Install the steering column control module. See Module - Steering Column Control (Remove and Replace).
  17. Install the steering wheel lower shroud. See Shroud - Lower - Steering Column (Remove and Replace).
  18. Install the steering wheel upper shroud. See Shroud - Upper - Steering Column (Remove and Replace).
  19. Install the steering wheel. See Steering Wheel (Remove and Replace).
  20. Install the driver airbag. See Airbag - Driver (Remove and Replace).
  21. Install the lower instrument panel. See Assembly - Instrument Panel - Lower (Remove and Replace).
  22. Install the LH air wave duct. See Duct - Air Wave - LH (RHD) (Remove and Replace).
  23. Install the passenger footwell duct. See Duct - Footwell - RH (RHD) (Remove and Replace).
  24. Install the glove box. See Glove Box (RHD) (Remove and Replace).
  25. Install the passenger footwell cover. See Cover - Footwell - Front Passenger (RHD) (Remove and Replace).
  26. Install the driver footwell duct. See Duct - Footwell - RH (RHD) (Remove and Replace).
  27. Install the driver footwell cover. See Cover - Footwell - Driver (RHD) (Remove and Replace).
  28. Install the LH and RH upper A-pillar trims. See Trim - A-Pillar - Upper - LH (Remove and Replace).
  29. Install the LH and RH IP end caps. See End Cap - Instrument Panel - LH (Remove and Replace).
  30. Connect LV power. See LV Power (Disconnect and Connect) (Modify).
  31. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  32. Put the vehicle into Service Mode Plus. See Service Mode Plus.
  33. Unlock the Vehicle Gateway. See Gateway Unlock.
  34. Use the replacement steering column part number recorded earlier and this table to determine the type of steering column installed and configuration value to be chosen.
    Part Number Drive Build Location Configuration Value
    1344811 LHD Fremont "BOSCH_COMMON_TO_JE"
    1344813 LHD Giga Shanghai "JE"
    1344817 RHD Giga Shanghai "NEXTEER"
  35. In Service Mode Plus, navigate the Vehicle Configurations > steeringColumnMotorType, and choose the correct configuration value as shown in the table in the previous step.
  36. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): PROC_STEERING_COLUMN_CALIBRATIONvia Service Mode:Chassis ➜ Steering ➜ Calibrate Steering Columnvia Toolbox:(link)
  37. Install the cabin intake duct. See Assembly - Fresh Air Gutter - HVAC (Remove and Replace).
  38. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
