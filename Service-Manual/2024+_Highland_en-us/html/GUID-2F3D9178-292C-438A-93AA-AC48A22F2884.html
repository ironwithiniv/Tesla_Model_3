Shield - Body Controller - Front (Remove and Replace)

Correction code 1715010022 FRT 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1715 - Electronic Control Modules

Torque Specifications

Table 1. Torque Specifications: Shield - Body Controller - Front (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts that attach the front body controller shield to the front body controller
8.5 Nm (6.3 lbs-ft)
  • 10 mm socket
 Reuse

Remove

  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Disconnect the LV power. See LV Power (Disconnect and Connect) (Modify).
  3. Remove the LV power. See LV Battery (Remove and Replace).
  4. Use a pocket screwdriver to press the connector tab, then push it to the left to disconnect the thermal sub-harness electrical connector from the front body controller.
  5. Remove the bolts (x2) that attach the front body controller shield to the front body controller, then remove the front body controller shield.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket

Install

  1. Position the front body controller shield onto the front body controller, then install the bolts (x2) that attach the front body controller shield to the front body controller.
    8.5 Nm (6.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  2. Connect the thermal sub-harness electrical connector to the front body controller.
  3. Install the LV power. See LV Battery (Remove and Replace).
  4. Connect the LV power. See LV Power (Disconnect and Connect) (Modify).
  5. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
