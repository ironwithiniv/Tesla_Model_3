Partial Remove and Clean Radiator (Heat Pump) (Maintenance)

Correction code 18301000 FRT 1.03 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-08-03: Added the PROC_VC_X_RESET-RADIATOR-UA-INDEX routine.
Parent topic: 1830 - Cooling System

Procedure

  1. Place the vehicle on the 2-post lift.
  2. Open the LH front door and lower the LH front window.
  3. Remove the active grille shutter. See Active Grille Shutter (Remove and Replace).
    Note
    Disconnect the cooling fan module connector at a later step. The connector should be disconnected after coolant hose is caped to avoid coolant damaging connector.
  4. Remove the locking tabs (x8) that attach the plastic grille to the radiator.
  5. Use a vacuum to clean the dirt on the radiator.
    Note
    If necessary, remove the large debris.
  6. Use a blow gun to clean the dirt on the radiator again.
    Note
    Do not get too close to the radiator blades.
    Note
    Dust and debris may fly out during the process; make sure to protect the vehicle and wear proper PPE , such as a mask, safety glasses, etc.
  7. Disconnect the cooling fan module connector.
  8. Release the upper and lower locking tabs that secure the radiator to the cooling and shroud assembly, and then slide it out from the holding mount.
  9. Use 2 S-hooks to hook the radiator to the front rails.
    Note
    Hook the radiator at the coolant inlet/outlet.
  10. Clean the backside of the radiator.
    Note
    Make sure the blow gun does not touch the radiator fins.
  11. Release the radiator from the front rails.
  12. Install the radiator into the cooling fan and shroud assembly (2x locking tabs, 2x holding mounts).
  13. Connect the cooling fan module connector.
  14. Install the locking tabs (x8) that attach the plastic grille to the radiator.
  15. Install the active grille shutter. See Active Grille Shutter (Remove and Replace).
    Note
    Terminate after connecting the LV power.
  16. Locally connect a laptop with Toolbox 3 to the vehicle. See Toolbox (Connect and Disconnect).
  17. In Toolbox, click the Actions tab, search for "Radiator", select PROC_VC_X_RESET-RADIATOR-UA-INDEXvia Toolbox:(link), select Run, then allow the routine to complete.
    Note
    Perform this step for firmware versions develop/2026.14.3 and later.
  18. On the touchscreen, select Thermal > Actions > Test Thermal Performance, then select Run and allow the routine to complete.
  19. Disconnect Toolbox and remove the laptop from the vehicle.
  20. Exit Service Mode Plus. See Service Mode Plus.
  21. Raise the LH front window and close the LH front door.
  22. Remove the vehicle from the lift.
