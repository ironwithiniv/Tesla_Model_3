Bezel - Handle - Seat Back - 2nd Row - RH (Remove and Replace)

Correction code 1305020032 FRT 0.06 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1305 - 2nd Row Seat Assemblies and Hardware

Remove

  1. Open the RH rear door and lower the RH rear window.
  2. Fold the RH 2nd row seat down.
  3. Use a clip pry tool to release the push clip and metal clip that attach the RH 2nd row seat back latch release bezel to the seat back, and then remove the bezel from the seat back.

Install

  1. Install the RH 2nd row seat back latch release bezel into the RH 2nd row seat back, and then fasten the clips that attach the bezel to the seat back.
  2. Unfold the RH 2nd row seat back so that it is upright and secured.
  3. Raise the RH rear window and close the RH rear door.
