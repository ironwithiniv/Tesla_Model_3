Seatback - 2nd Row - RH (Remove and Replace)

Correction code 1305010022 FRT 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1305 - 2nd Row Seat Assemblies and Hardware

Torque Specifications

Table 1. Torque Specifications: Seatback - 2nd Row - RH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Nuts (x2) that attach the RH 2nd row seat back hinge bracket to the body
18 Nm (13.3 lbs-ft)
  • 13 mm socket
 Reuse

Remove

  1. Remove the RH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  2. Remove the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  3. Disconnect the electrical harness from the heated seat connector for the RH 2nd row seat back.
  4. Remove the nuts (x2) that attach the RH seat back hinge bracket to the body.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  5. Lift the right side of the RH seat back assembly up, move forward and to the right, and pull the RH seat back assembly away from the inner pivot of the LH seat back assembly.
  6. Remove the RH 2nd row seat back from the vehicle.

Install

  1. Move the RH seat back assembly into the 2nd row area.
  2. Insert the inner pivot of the LH seat back assembly into the receptacle of the RH seat back assembly, move the assembly rearward and to the left, and then lower the RH seat back assembly hinge bracket onto the body studs.
  3. Install the nuts (x2) that attach the RH seat back hinge bracket to the body.
    18 Nm (13.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  4. Connect the electrical harness to the heated seat connector for the RH 2nd row seat back assembly.
  5. Install the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  6. Install the RH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
