Hinge - Door - Front - Upper - LH (Remove and Replace)

Correction code 1133010122 FRT 0.36 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1079485-00-A Crowfoot Open End Set
Parent topic: 1133 - Closure Assist Mechanisms and Hinges

Torque Specifications

Table 1. Torque Specifications: Hinge - Door - Front - Upper - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x2) that attach the LH front upper door hinge to the door
27 Nm (19.9 lbs-ft)
  • 10mm 12pt combination wrench
  • Crowfoot Open End Set - 1079485-00-A (for installation only)
 Reuse
Bolts (x3) that attach the LH front upper door hinge to body
27 Nm (19.9 lbs-ft)
  • 13mm 12pt combination wrench
  • Crowfoot Open End Set - 1079485-00-A (for installation only)
 Reuse

Remove

  1. Open the LH front door and lower the LH front window.
  2. Use a floor jack to support the LH front door.
    CAUTION
    Use soft material to protect the door paint.
  3. Apply masking tape to the area surrounding the LH front door upper hinge on the body and door to aid in alignment during installation.
  4. Remove the bolts (x2) that attach the LH upper front door hinge to the LH front door.
    Tip
    Use of the following tool(s) is recommended:
    • 10mm 12pt combination wrench
    • Crowfoot Open End Set - 1079485-00-A (for installation only)
  5. Remove the bolts (x3) that attach the LH upper front door hinge to the body.
    Tip
    Use of the following tool(s) is recommended:
    • 13mm 12pt combination wrench
    • Crowfoot Open End Set - 1079485-00-A (for installation only)
  6. Push outward on the top of the door near the speaker with one hand, and then feed the LH upper front door hinge upward and then outward towards the rear of the vehicle to remove it.

Install

  1. Position the LH upper front door hinge into the vehicle.
    Note
    Push outward on the top of the door near the speaker with one hand, and then insert the LH upper front door hinge.
  2. Install and hand tighten the bolts (x3) that attach the LH upper front door hinge to the body.
  3. Install and hand tighten the bolts (x2) that attach the LH upper front door hinge to the LH front door.
  4. Torque the bolts (x3) that attach the LH upper front door hinge to the body.
    27 Nm (19.9 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13mm 12pt combination wrench
    • Crowfoot Open End Set - 1079485-00-A (for installation only)
  5. Torque the bolts (x2) that attach the LH upper front door hinge to the LH front door.
    27 Nm (19.9 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10mm 12pt combination wrench
    • Crowfoot Open End Set - 1079485-00-A (for installation only)
  6. Remove the floor jack from underneath the LH front door.
  7. Close the LH front door, and then check that gap and flushness are within specifications. Adjust as necessary.
    Note
    See Panel Alignment Specifications
  8. Remove the masking tape from the door and body.
  9. Use IPA wipes to clean the LH upper front door hinge bolt heads, and then allow 1 minute of dry time before continuing to the next step.
  10. Apply touch up paint on the LH upper front door hinge bolt heads as needed.
    Note
    Shake the touch up paint before applying. Allow the first coat to dry for 20 minutes before applying and second coat.
  11. Raise the LH front window and close the LH front door.
