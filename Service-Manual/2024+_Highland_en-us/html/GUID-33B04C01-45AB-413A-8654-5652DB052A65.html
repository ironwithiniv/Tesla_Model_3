Bracket - Hood Strut - LH (Remove and Replace)

Correction code 1133030042 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1133 - Closure Assist Mechanisms and Hinges

Torque Specifications

Table 1. Torque Specifications: Bracket - Hood Strut - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x2) that attach the LH strut bracket to the body
10 Nm (7.4 lbs-ft)
  • 10 mm deep socket
 Reuse

Remove

  1. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Disconnect the LV battery. See LV Power (Disconnect and Connect) (Modify).
  4. Remove the cabin intake duct. See Assembly - Fresh Air Gutter - HVAC (Remove and Replace).
  5. Remove the access panel. See Cover - Hood Latch (Remove and Replace).
  6. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  7. Remove the LH front wheel. See Wheel Assembly (Remove and Install).
  8. Remove the pyrotechnic actuator. See Actuator - Pedestrian Protection - Active Hood - LH (Remove and Replace).
  9. Remove the bolts (x2) that attach the LH active hood strut bracket to the body, and then remove the bracket from the vehicle.
    Note
    Use of the following tool(s) is recommended:
    • 10 mm deep socket

Install

  1. Install the LH active hood strut bracket to the body, and then install the bolts (x2) attach the bracket to the body.
    10 Nm (7.4 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  2. Install the pyrotechnic actuator. See Actuator - Pedestrian Protection - Active Hood - LH (Remove and Replace)
  3. Install the LH front wheel. See Wheel Assembly (Remove and Install).
  4. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  5. Install the access panel. See Cover - Hood Latch (Remove and Replace).
  6. Connect the LV battery. See LV Power (Disconnect and Connect) (Modify).
  7. Install the cabin intake duct. See Assembly - Fresh Air Gutter - HVAC (Remove and Replace).
  8. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  9. Lower the vehicle. See Raise Vehicle - 2 Post Lift.
