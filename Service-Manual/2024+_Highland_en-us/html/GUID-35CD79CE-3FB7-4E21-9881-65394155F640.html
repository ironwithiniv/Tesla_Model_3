Duct - Footwell - LH (Remove and Replace)

Correction code 1405030072 FRT 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2024-09-05: Added knee airbag steps for NA vehicles.
Parent topic: 1405 - Instrument Panel

Remove

  1. Disconnect the LV battery power. See LV Power (Disconnect and Connect) (Modify).
  2. Remove the LH footwell cover. See Cover - Footwell - Driver (Remove and Replace).
  3. For NA vehicles only: Remove the LH knee airbag. See Airbag - Knee - LH (Remove and Replace).
  4. Release the clips (x2) that attach the LH footwell duct to the HVAC module.
  5. Remove the LH footwell duct.

Install

  1. Install the LH footwell duct.
  2. Install the clips (x2) that attach the LH footwell duct to the HVAC module.
  3. For NA vehicles only: Install the LH knee airbag. See Airbag - Knee - LH (Remove and Replace).
  4. Install the LH footwell cover. See Cover - Footwell - Driver (Remove and Replace).
  5. Connect the LV battery power. See LV Power (Disconnect and Connect) (Modify).
