Fascia - Front (Remove and Replace)

Correction code 1001020042 FRT 0.90 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-12-18: Added steps to install the fender brackets onto the front fascia.
  • 2025-10-22: Added steps relate to the front fascia camera.
Parent topic: 1001 - Bumper / Fascia

Remove

  1. Remove the front fascia assembly. See Fascia - Front (Remove and Install).
  2. Release the clip that attaches the front fascia harness to the tow hook cover.
  3. Disconnect the electrical connector from the front fascia camera.
    Note
    This connector may not be present on early production vehicles. If not, skip this step.
  4. Disconnect the electrical connector from the pedestrian warning speaker.
  5. Use a clip prytool to release the clips (x9) that attach the front fascia harness to the front fascia, then remove the front fascia harness.
  6. Remove the front valance. See Valance - Front Fascia (Remove and Replace).
    Note
    No need to remove the pedestrian warning speaker from the valance.
  7. Remove the fascia grille. See Grille - Fascia - Front (Remove and Replace).
  8. Remove the B-nuts (x8) from the front fascia.
    Note
    Push both side lock pieces to release the nuts.

Install

  1. Install the B-nuts (x8) to the front fascia.
    Note
    Replace any nuts if damaged.
    Note
    Make sure that the nuts are fully in place.
  2. Install the fascia grille. See Grille - Fascia - Front (Remove and Replace).
  3. Install the front valance. See Valance - Front Fascia (Remove and Replace).
  4. Install the clips (x9) that attach the front fascia harness to the front fascia.
  5. Connect the electrical connector to the pedestrian warning speaker.
  6. Connect the electrical connector to the front fascia camera.
    Note
    This connector may not be present on early production vehicles. If not, skip this step.
  7. Install the clip that attaches the front fascia harness to the tow hook cover.
  8. Place a new LH fender bracket (1734299-00-H) onto the LH fascia, securing it with 2 new rivets (1064496-00-A).
  9. Place a new RH fender bracket (1734300-00-H) onto the RH fascia, securing it with 2 new rivets (1064496-00-A).
  10. Install the front fascia assembly. See Fascia - Front (Remove and Install).
  11. Connect a laptop with Toolbox to the vehicle. See Toolbox (Connect and Disconnect).
  12. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): PROC_DAS_X_ENTER-CALIBRATION-MODEvia Toolbox:(link)
  13. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): PING-HTTP_DAS_X_FASCIA-CAMERA-SCRIPTvia Toolbox:(link)
  14. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): PROC_DAS_X_EXIT-CALIBRATION-MODEvia Service Mode Plus:Driver Assist ➜ Cameras ➜ Exit Factory Calibration Modevia Toolbox:(link)
  15. Disconnect the laptop with Toolbox from the vehicle.
  16. Exit Service Mode. See Service Mode.
