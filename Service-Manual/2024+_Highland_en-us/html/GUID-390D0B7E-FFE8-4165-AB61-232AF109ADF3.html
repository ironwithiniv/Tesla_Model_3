Headrest (w/ Toggle Bolts) - Front Seat (Sport Seat) (Remove and Replace)

Correction code 13040104202 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-04-23: Released new procedure.
Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
  1. Open LH front door
  2. Lower LH front window
  3. Tilt LH front seat rearward to allow for headrest removal
  4. Remove LH front headrest with toggle bolts from seat assembly
    Note
    2x locking clips, 2x toggle bolts, remove by pulling out then use plastic trim tool to release clips with toggle bolts, This will require extra force, Note: The clips and toggle bolts will need to be pulled out and are likely to break during removal, Discard headrest after removal
  5. Remove strap clips for lower section from LF seat back shell assembly
    Note
    2x clips
  6. Release headrest bracket assembly
    Note
    2x locking clips, depress headrest release clips, ensure both clips are fully released then release by pulling straight up
  7. Remove LH seat back shell assembly from seat back frame
    Note
    16x clips, Start at the top of the seat and pull the shell away from the frame, When the side clips are free, pull the bottom and carefully roll the bottom tabs out of the slots, If pulled straight out the clips on the seat back can break off, Release remaining clips from underneath seat assembly, Move seat as needed for access
  8. Release seat back retainer from seat back frame
    Note
    1x retainer
  9. Remove toggle bolts or clips residues
    Note
    Discard any residues found on seat back, this can cause NVH noises in the future
  10. Install seat back retainer from seat back frame
    Note
    1x retainer
  11. Install the seat back shell assembly to seat back frame
    Note
    16x clips, Install the lower clips first and rotate the shell up into place, Light pressure may need to be applied to the shell to ensure it's fully seated, The headrest posts will engage the seat back when installed
  12. Hook strap clips onto seat back shell assembly
    Note
    2x clips, Ensure the straps are tight for proper fit and installation
  13. Install headrest bracket assembly
    Note
    2x locking clips, Ensure the headrest is fully seated, An audible click will be heard when installing the headrest, Ensure the headrest assembly is seated by tugging up on the headrest
  14. Install headrest into seat
    Note
    2x locking clips, Ensure the headrest is fully seated, An audible click will be heard when installing the headrest, Ensure the headrest is seated by tugging up on the headrest
  15. Move LH front driver seat to original position
  16. Raise LH front window
  17. Close LH front door
