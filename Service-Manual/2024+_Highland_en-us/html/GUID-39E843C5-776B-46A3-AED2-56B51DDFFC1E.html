Harness - Windshield (Remove and Replace)

Correction code 1710090012 FRT 0.36 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1060071-00-A HEXAGON
Parent topic: 1710 - Harnesses

Torque Specifications

Table 1. Torque Specifications: Harness - Windshield (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolt that attaches the windshield harness to the windshield bracket
1 Nm (.7 lbs-ft)
  • Torx T10 socket
 Reuse

Remove

  1. Open the RH front door and lower the RH window.
  2. Remove the lower camera cover. See Camera Cover - Lower (Remove and Replace).
  3. Remove the rear view mirror. See Mirror - Rear View (Remove and Replace).
  4. Remove the upper camera cover and the interior camera. See Camera Cover - Upper (Remove and Replace).
    Note
    No need to remove the interior camera from the upper camera cover.
  5. Disconnect the forward bi-camera connectors (x2).
  6. Disconnect the GPS/GNSS antenna connector.
  7. Disconnect the humidity and temperature sensor electrical connector.
  8. Remove the bolt that attaches the windshield harness to the windshield bracket, and remove the harness aside.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T10 socket
  9. Remove the RH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  10. Remove the RH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  11. Remove the RH upper A-pillar trim. See Trim - A-Pillar - Upper - LH (Remove and Replace).
  12. Remove the RH sun visor. See Sun Visor Assembly - LH (Remove and Replace).
  13. Release the clips (x4) and locator pin that attach the front center of the headliner to the body.
    Note
    Take care not to bend the headliner.
    Note
    Replace any damaged clips.
  14. Disconnect the windshield harness electrical connectors (x3) at the lower A-pillar.
  15. Release the clips (x6) that attach the windshield harness to the RH A-pillar.
  16. Release the clips (x6) that attach the windshield harness along the top portion of the windshield, and then remove the harness from the vehicle.

Install

  1. Install the windshield harness along the top portion of the windshield, and then fasten the clips (x6) that attach the harness to the windshield.
  2. Fasten the clips (x6) that attach the windshield harness to the RH A-pillar.
  3. Connect the windshield harness electrical connectors (x3) at the lower A-pillar.
  4. Fasten the clips (x4) and locator pin that attach the front center of the headliner to the body.
    Note
    Take care not to bend the headliner.
    Note
    Replace any damaged clips.
  5. Install the RH upper A-pillar trim. See Trim - A-Pillar - Upper - LH (Remove and Replace).
  6. Install the RH sun visor. See Sun Visor Assembly - LH (Remove and Replace).
  7. Install the RH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  8. Install the RH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  9. Install the bolt that attaches the windshield harness to the windshield bracket.
    1 Nm (.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T10 socket
  10. Connect the humidity and temperature sensor electrical connector.
  11. Connect the GPS/GNSS antenna connector.
  12. Connect the forward bi-camera connectors (x2).
  13. Install the upper camera cover and the interior camera. See Camera Cover - Upper (Remove and Replace).
    Note
    No need to install the interior camera to the upper camera cover.
  14. Install the rear view mirror. See Mirror - Rear View (Remove and Replace).
  15. Install the lower camera cover. See Camera Cover - Lower (Remove and Replace).
  16. Close the RH front door and raise the window.
