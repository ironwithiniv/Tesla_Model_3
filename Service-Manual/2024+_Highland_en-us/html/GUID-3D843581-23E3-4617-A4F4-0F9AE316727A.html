Thermistor - HVAC - LH (Remove and Replace)

Correction code 1810011112 FRT 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1810 - Cabin HVAC

Remove

  1. Remove LH front side panel from center console assembly. See Carpet - Side - Center Console - LH (Remove and Replace).
  2. Disconnect the LH lower duct thermistor connector.
  3. Use a small flat head screwdriver to release the tabs (x2) that attach the LH lower duct thermistor to the HVAC assembly, and then remove the thermistor from the vehicle.

Install

  1. Fasten the tabs (x2) that attach the LH lower duct thermistor to the HVAC assembly.
  2. Connect the LH lower duct thermistor connector.
  3. Install LH front side panel from center console assembly. See Carpet - Side - Center Console - LH (Remove and Replace).
  4. Enter Service Mode. See Service Mode.
  5. Unlock the vehicle gateway. See Gateway Unlock.
  6. On the touchscreen, perform HVAC performance: Thermal > Actions > Test HVAC Performance, and select Run to start the routine.
    Note
    Make sure the routine is passed, then touch Close to close it.
  7. Exit Service Mode. See Service Mode.
