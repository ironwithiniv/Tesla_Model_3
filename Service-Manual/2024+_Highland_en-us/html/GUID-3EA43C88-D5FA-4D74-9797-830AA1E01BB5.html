Foam - Bumper Beam - Front (Remove and Replace)

Correction code 1001030022 FRT 0.54 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2024-04-01: Added steps of removing/installing the protection pressure tube sensor assembly.
Parent topic: 1001 - Bumper / Fascia

Remove

  1. Remove the front fascia assembly. See Fascia - Front (Remove and Replace).
    Note
    It is not necessary to remove the front fascia harness, valance and grille from the front fascia assembly.
  2. Disconnect the LH and RH pedestrian protection pressure tube sensors.
  3. Remove and discard the clips (x4) that attach the front bumper beam foam to the front bumper beam.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  4. Remove and discard the clips (x2) that attach the LH and RH pedestrian protection pressure tube sensors to the front bumper beam foam, then remove the protection pressure tube sensor assembly from the front bumper beam foam.

Install

  1. Install the front bumper beam foam onto the front bumper beam.
  2. Position the protection pressure tube sensor assembly to the front bumper beam foam, and then install new clips (x2) that attach the LH and RH pedestrian protection pressure tube sensors.
  3. Install the clips (x4) that attach the front bumper beam foam to the front bumper beam.
  4. Connect the LH and RH pedestrian protection pressure tube sensors.
  5. Install the front fascia assembly. See Fascia - Front (Remove and Replace).
