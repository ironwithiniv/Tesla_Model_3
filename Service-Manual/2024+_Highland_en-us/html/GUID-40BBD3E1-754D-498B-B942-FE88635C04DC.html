Harness - Fascia -Front (Remove and Replace)

Correction code 1710030012 FRT 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-10-11: For vehicles equipped with a front fascia camera, added steps of disconnecting/connecting the front fascia camera connector.
  • 2024-04-16: Added a note to clarify that it is not necessary to remove the front fascia harness, valance and grille from the front fascia assembly.
Parent topic: 1710 - Harnesses

Remove

  1. Remove the front fascia assembly. See Fascia - Front (Remove and Replace).
    Note
    It is not necessary to remove the front fascia harness, valance and grille from the front fascia assembly.
  2. Release the clip that attaches the front fascia harness to the tow hook cover.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  3. Disconnect the electrical connector from the front fascia camera.
    Note
    This connector may not be present on early production vehicles. If not, skip this step.
  4. Disconnect the electrical connector from the pedestrian warning speaker.
  5. Use a clip prytool to release the clips (x9) that attach the front fascia harness to the front fascia, then remove the front fascia harness.

Install

  1. Position the front fascia harness in the front fascia.
  2. Install the clips (x9) that attach the front fascia harness to the front fascia.
  3. Connect the electrical connector to the pedestrian warning speaker.
  4. Connect the electrical connector to the front fascia camera.
    Note
    This connector may not be present on early production vehicles. If not, skip this step.
  5. Install the clip that attaches the front fascia harness to the tow hook cover.
  6. Install the front fascia assembly. See Fascia - Front (Remove and Replace).
