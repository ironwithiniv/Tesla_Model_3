Air Vent - Driver (Remove and Install)

Correction code 1405030051 FRT 1.56 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1405 - Instrument Panel

Remove

  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Remove the IP carrier. See IP Carrier (Remove and Install).
  3. Disconnect the LH front vent height adjustment actuator connector.
  4. Disconnect the LH front vent horizontal adjustment actuator connector.
  5. Remove the screws (x5) that attaches the LH front vent to the instrument panel carrier, and then remove the LH front vent from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 6 in extension
    • Torx T20 socket
    • Ratchet/torque wrench

Install

  1. Install the LH front vent to the instrument panel, and then install the screws (x5) that attach the LH front vent to the instrument panel.
    0.9 Nm (8 lbs-in)
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 6 in extension
    • Torx T20 socket
    • Ratchet/torque wrench
  2. Connect the LH front vent horizontal adjustment actuator connector.
  3. Connect the LH front vent height adjustment actuator connector.
  4. Install the IP carrier. See IP Carrier (Remove and Install).
  5. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
