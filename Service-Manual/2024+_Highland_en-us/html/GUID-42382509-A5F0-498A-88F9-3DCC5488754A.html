CloseOut - Center Console (Remove and Replace)

Correction code 1519010032 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1060071-00-A Torque Wrench 1/4in Dr Hexagon
Parent topic: 1519 - Center Console

Torque Specifications

Table 1. Torque Specifications: CloseOut - Center Console (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Screw that attaches the console closeout assembly to the center console
1 Nm (.7 lbs-ft)
  • Torx T20 socket
 Reuse

Remove

  1. Open all the doors and lower all the windows.
  2. Remove the phone dock assembly. See Phone Dock (Clip) - Center Console (Remove and Replace)
  3. Remove the center console rear end panel. See Panel - Rear End - Center Console (Remove and Replace).
  4. Remove the LH center console rear side panel. See Panel - Rear Side - Center Console - LH (Remove and Replace).
  5. Remove the LH center console front side panel. See Carpet - Side - Center Console - LH (Remove and Replace).
  6. Remove LH center console decor trim. See Hockey Stick Assembly -LH (with a Clip-secured Phone Dock) (Remove and Replace).
  7. Remove the RH center console rear side panel. See Panel - Rear Side - Center Console - LH (Remove and Replace).
  8. Remove the RH center console front side panel. See Carpet - Side - Center Console - RH (Remove and Replace).
  9. Remove the RH center console decor trim. See Hockey Stick Assembly -LH (with a Clip-secured Phone Dock) (Remove and Replace).
  10. Remove the center console top face panel. See Top Face Panel - Center Console (Remove and Replace).
  11. Remove the center console sliding bin lid assembly. See Sliding Door Assembly - Center Console (Remove and Replace).
  12. Remove the screw that secures the console closeout assembly to the center console.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  13. Disconnect the center console puddle lamp electrical harness from the console closeout connector, and then remove the console closeout from the center console.
    Note
    Pull the console closeout straight up to remove it from the datums (x3).

Install

  1. Install the console closeout to the center console, and then connect the center console puddle lamp electrical harness to the console closeout connector.
    Note
    Align the datum holes (x3) when installing the console closeout.
    CAUTION
    Ensure the connector is properly installed. Perform a push-pull test before continuing this procedure.
  2. Install the screw that secures the console closeout assembly to the center console.
    1 Nm (.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  3. Install the center console sliding bin lid assembly. See Sliding Door Assembly - Center Console (Remove and Replace).
  4. Install the center console top face panel. See Top Face Panel - Center Console (Remove and Replace).
  5. Install the RH center console decor trim. See Hockey Stick Assembly -LH (with a Clip-secured Phone Dock) (Remove and Replace).
  6. Install the RH center console front side panel. See Carpet - Side - Center Console - RH (Remove and Replace).
  7. Install the RH center console rear side panel. See Panel - Rear Side - Center Console - LH (Remove and Replace).
  8. Install LH center console decor trim. See Hockey Stick Assembly -LH (with a Clip-secured Phone Dock) (Remove and Replace).
  9. Install the LH center console front side panel. See Carpet - Side - Center Console - LH (Remove and Replace).
  10. Install the LH center console rear side panel. See Panel - Rear Side - Center Console - LH (Remove and Replace).
  11. Install the center console rear end panel. See Panel - Rear End - Center Console (Remove and Replace).
  12. Install the phone dock assembly. See Phone Dock (Clip) - Center Console (Remove and Replace)
  13. Raise all the windows and close all the doors.
