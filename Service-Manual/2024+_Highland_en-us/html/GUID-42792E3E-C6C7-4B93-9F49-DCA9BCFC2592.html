Switch - Interior Door Release - Front - LH (Remove and Replace)

Correction code 1513010092 FRT 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1513 - Door Trim

Torque Specifications

Table 1. Torque Specifications: Switch - Interior Door Release - Front - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x2) that attach the LH front door interior handle to the door trim panel
1 Nm (.7 lbs-ft)
  • Torx T20 socket
 Reuse

Remove

  1. Open the LH front door, and then lower the LH front window.
  2. Remove the LH front door reflector. See Reflector - Door - Front - LH (Remove and Replace).
  3. Remove the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
  4. Remove the LH front door puddle light. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  5. Remove the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  6. Remove the LH front door NVH pad. See NVH Pad - Door - Front - LH (Remove and Replace).
  7. Disconnect the LH front door interior release switch connector.
  8. Remove the bolts (x2) that attach the LH front door interior handle to the door trim panel.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  9. Apply protective tape around the work area to protect the door trim panel.
  10. Use a plastic trim tool to separate the front portion of the LH front door interior handle from the interior release switch.
  11. Release the tabs (x4) that attach the LH front door interior release switch to the LH front door trim panel, and then remove the switch from the LH front door trim panel.
    Note
    Carefully insert a V-shape wedge into the gap between the switch and the handle to release the clips.
    CAUTION
    Take sure not to damage the handle and door trim.

Install

  1. Install the tabs (x4) that attach the interior door release switch to the LH front door trim panel.
  2. Secure the LH front door interior handle into the LH front door trim panel.
  3. Remove the protective tape from the work area.
  4. Install the bolts (x2) that attach the LH front door interior handle to the door trim panel.
    1 Nm (.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  5. Connect the LH front door interior release switch connector.
  6. Install the LH front door NVH pad. See NVH Pad - Door - Front - LH (Remove and Replace).
  7. Install the LH front door puddle light. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  8. Install the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  9. Install the LH front door reflector. See Reflector - Door - Front - LH (Remove and Replace).
  10. Install the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
  11. Raise the LH front window, and then close the LH front door.
