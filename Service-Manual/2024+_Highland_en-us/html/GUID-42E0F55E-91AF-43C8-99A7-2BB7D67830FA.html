Breather Assembly - Front Drive Unit (3DU) (Remove and Replace)

Correction code 3901010062 FRT 0.48 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 3901 - Front Drive Unit Assembly

Remove

  1. Remove the body controller. See Module - Body Controller (Remove and Replace).
  2. Remove bolts (x2) that attach the front harness bracket to the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • Ratchet/torque wrench
    • 10 mm socket
    • 2 in extension
  3. Move the front harness bracket forward appropriately to remove the front drive unit breather.
    Tip
    Use of the following tool(s) is recommended:
    • Ratchet/torque wrench
    • ¼ in to 3/8 in adapter
    • 1/2 in to 3/8 in adapter
    • 22 mm socket
    • 3 in extension

Install

  1. Install the new front drive unit breather.
    5 Nm (3.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Ratchet/torque wrench
    • ¼ in to 3/8 in adapter
    • 1/2 in to 3/8 in adapter
    • 22 mm socket
    • 3 in extension
  2. Install bolts (x2) that attach the front harness bracket to the vehicle.
    9 Nm (6.6 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Ratchet/torque wrench
    • 10 mm socket
    • 2 in extension
  3. Install the body controller. See Module - Body Controller (Remove and Replace).
