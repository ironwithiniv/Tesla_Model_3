Inertia Lock - Armrest (Remove and Replace)

Correction code 1519010072 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1519 - Center Console

Torque Specifications

Table 1. Torque Specifications: Inertia Lock - Armrest (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
screw that attaches the inertia lock to the center console
0.8 Nm (7 lbs-in)
  • Torx T20 socket
 Reuse

Remove

  1. Remove the center console phone dock assembly. See Phone Dock (Clip) - Center Console (Remove and Replace).
    Note
    It is not necessary to remove the inductive charger from the phone dock.
  2. Remove the rear end panel. See Panel - Rear End - Center Console (Remove and Replace).
  3. Remove the LH rear side panel. See Panel - Rear Side - Center Console - LH (Remove and Replace).
  4. Remove the LH front side panel. See Carpet - Side - Center Console - LH (Remove and Replace).
  5. Remove the LH décor trim. See Hockey Stick Assembly -LH (with a Clip-secured Phone Dock) (Remove and Replace).
  6. Repeat step 3 through step 5 for the RH side of the vehicle.
  7. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  8. Disconnect LV battery power. See LV Power (Disconnect and Connect) (Modify)
  9. Remove the rear end module assembly. See Module - Rear End - Center Console (Remove and Install)
    Note
    It is not necessary to remove the rear end module from the assembly.
  10. Remove the screw that attaches the inertia lock to the center console.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  11. Remove the inertia lock from the center console.
    Note
    Be careful not drop the spring.

Install

  1. Position the inertia lock onto the center console.
  2. Install the screw that attaches the inertia lock to the center console.
    0.8 Nm (7 lbs-in)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  3. Install the rear end module assembly. See Module - Rear End - Center Console (Remove and Install)
  4. Connect LV battery power. See LV Power (Disconnect and Connect) (Modify)
  5. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  6. Install the LH décor trim. See Hockey Stick Assembly -LH (with a Clip-secured Phone Dock) (Remove and Replace).
  7. Install the LH front side panel. See Carpet - Side - Center Console - LH (Remove and Replace).
  8. Install the LH rear side panel. See Panel - Rear Side - Center Console - LH (Remove and Replace).
  9. Repeat step 6 through step 8 for the RH side of the vehicle.
  10. Install the rear end panel. See Panel - Rear End - Center Console (Remove and Replace).
  11. Install the center console phone dock assembly. See Phone Dock (Clip) - Center Console (Remove and Replace).
