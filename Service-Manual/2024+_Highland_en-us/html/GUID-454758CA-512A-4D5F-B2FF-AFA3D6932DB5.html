Bracket - EPB Harness - LH (Remove and Replace)

Correction code 3301020052 FRT 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 3301 - Brake Discs and Calipers

Torque Specifications

Table 1. Torque Specifications: Bracket - EPB Harness - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolt that attaches the LH rear EPB harness bracket to the LH rear caliper
5 Nm (3.7 lbs-ft)
  • 10 mm socket
 Reuse
Bolt that attaches the LH rear EPB harness bracket to the body
5 Nm (3.7 lbs-ft)
  • 10 mm socket
 Reuse

Remove

  1. Remove the LH rear wheel. See Wheel Assembly (Remove and Install).
  2. Remove the LH rear wheel arch liner. See Wheel Arch Liner - Rear - LH (Remove and Replace).
  3. Disconnect the LH rear EPB caliper connector.
  4. Remove the bolt that attaches the LH rear EPB harness bracket to the LH rear caliper.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  5. Remove the bolt that attaches the LH rear EPB harness bracket to the body.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  6. Disconnect the LH rear EPB connector from the rear main body harness.

Install

  1. Connect the LH rear EPB connector to the rear main body harness.
  2. Install the bolt that attaches the LH rear EPB harness bracket to the body.
    5 Nm (3.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  3. Install the bolt that attaches the LH rear EPB harness bracket to the LH rear caliper.
    5 Nm (3.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  4. Connect the LH rear EPB caliper connector.
  5. Install the LH rear wheel arch liner. See Wheel Arch Liner - Rear - LH (Remove and Replace).
  6. Install the LH rear wheel. See Wheel Assembly (Remove and Install).
  7. Perform a test drive that includes a minimum speed of 25mph in straight line for at least five seconds to allow the ESP internal system checks to complete. The ESP faults will clear if the vehicle is repaired correctly. If faults are persistent after the test drive, continue troubleshooting the repair.
