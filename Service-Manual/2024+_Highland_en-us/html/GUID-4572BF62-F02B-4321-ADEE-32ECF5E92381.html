Buckle - Seatbelt - 1st Row - LH (Remove and Replace)

Correction code 2005010072 FRT 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

CAUTION
Supplemental Restraint System (SRS) components can be hazardous if not serviced and handled correctly. See Airbag and Supplementary Restraint System (SRS) Precautions
CAUTION
In the event of an airbag or seatbelt pretensioner deployment, certain components must be replaced, and other components must be inspected for damage. Refer to the Collision Repair Manual for a specific list of items that must be inspected and replaced.
Parent topic: 2005 - Seatbelts

Torque Specifications

Table 1. Torque Specifications: Buckle - Seatbelt - 1st Row - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
The patchbolt that attaches the buckle to the seat track
40 Nm (29.5 lbs-ft)
  • Torx T50 socket
 Replace

Remove

  1. Remove the LH front seat inboard side shield. See Side Shield - Inboard - LH (Remove and Replace).
  2. Disconnect the LH front seat buckle electrical connector.
  3. Release the felt that attaches the connector to the seat track.
  4. Remove and discard the patchbolt that attaches the buckle to the seat track, and then remove the buckle.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket

Install

  1. Position the driver seat buckle into the vehicle, make sure to engage the pin on the buckle with the slot in the seat track.
  2. Install a new patchbolt that attaches the buckle to the seat track.
    40 Nm (29.5 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket
  3. Secure the felt that attaches the connector to the seat track.
  4. Connect the LH front seat buckle electrical connector.
  5. Install the driver seat inboard side shield. See Side Shield - Inboard - LH (Remove and Replace).
