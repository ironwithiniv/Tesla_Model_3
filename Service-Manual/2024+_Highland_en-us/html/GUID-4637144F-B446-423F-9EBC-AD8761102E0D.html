Closeout Panel - Door - Front - LH (Remove and Replace)

Correction code 1133010042 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1133 - Closure Assist Mechanisms and Hinges

  • 8 mm socket
 Reuse

3 Nm (2.2 lbs-ft)
  • 8 mm socket
 Reuse
Screws (x8) that attach the LH front door closeout panel to the LH front door
4 Nm (2.9 lbs-ft)
  • 8 mm socket
 Reuse

Remove

  1. Remove the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
  2. Remove the LH front door puddle light. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  3. Remove the LH front door reflector. See Reflector - Door - Front - LH (Remove and Replace).
  4. Remove the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  5. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  6. Disconnect the LV power. See LV Power (Disconnect and Connect) (Modify).
  7. Disconnect the electrical connector from the LH front door mirror.
  8. Release the clip that attaches the LH front door mirror harness to the LH front door.
  9. Disconnect the electrical connector from the LH front window motor.
  10. Disconnect the electrical connector from the front door speaker.
  11. Remove the LH front door pressure sensor. See Sensor - Pressure - Door - Front - LH (Remove and Replace).
  12. Remove the bolts (x4) and tabs (x4) that attach the front door speaker to the LH front door, and then remove the speaker.
    Tip
    Use of the following tool(s) is recommended:
    • 8 mm socket
  13. Release the clips (x5) that attach the electrical wiring harness to the LH front door closeout panel.
  14. Remove the screws (x5) that attach the LH front window motor to the LH front door closeout panel.
    Note
    Use of the following tool(s) is recommended:
    • 8 mm socket
  15. Remove the clip that attaches the LH front window motor to the LH front door closeout panel.
  16. Remove the screws (x8) that attach the LH front door closeout panel to the LH front door.
    Tip
    Use of the following tool(s) is recommended:
    • 8 mm socket
  17. Release the clips (x2) that attach the LH front door closeout panel to the LH front door, and then remove the closeout panel from the vehicle.

Install

  1. Feed the electrical harness through the LH front door closeout panel, and then fasten the clips (x2) that attach the LH front door closeout panel to the LH front door.
  2. Install the screws (x8) that attach the LH front door closeout panel to the LH front door.
    4 Nm (2.9 lbs-ft)
    Note
    Hand-tighten the screws first to avoid stripping the threads
    Tip
    Use of the following tool(s) is recommended:
    • 8 mm socket
  3. Install the screws (x5) that attach the LH front window motor to the LH front door closeout panel.
    3 Nm (2.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 8 mm socket
  4. Install the clip that attaches the LH front window motor to the LH front door closeout panel.
  5. Fasten the clips (x5) that attach the electrical wiring harness to the LH front door closeout panel.
  6. Install the LH front door pressure sensor. See Sensor - Pressure - Door - Front - LH (Remove and Replace).
  7. Connect the electrical connector to the front door speaker.
  8. Connect the electrical connector to the LH front window motor.
  9. Fasten the clip that attaches the LH front door mirror harness to the LH front door.
  10. Connect the electrical connector to the LH front door mirror.
  11. Install the bolts (x4) and tabs (x4) that attach the front door speaker to the LH front door.
    4 Nm (2.9 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 8 mm socket
  12. Connect the LV power. See LV Power (Disconnect and Connect) (Modify).
  13. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  14. Install the LH front door puddle light. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  15. Install the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  16. Install the LH front door reflector. See Reflector - Door - Front - LH (Remove and Replace).
  17. Install the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
