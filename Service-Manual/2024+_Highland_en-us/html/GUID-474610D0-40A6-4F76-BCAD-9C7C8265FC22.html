IP Carrier (Remove and Replace)

Correction code 1405010012 1.74 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-02-10: Updated the screw torque values securing the vent and duct to the IP carrier.
  • 2025-02-14: Updated procedure to most recent validation.
Parent topic: 1405 - Instrument Panel

Remove

  1. Remove the IP carrier from the vehicle. See IP Carrier (Remove and Install).
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  2. Put the old IP carrier on a stand.
  3. Remove the screws (x2) that attach the LH defrost duct to the IP carrier.
  4. Remove the LH defrost duct from the IP carrier.
  5. Disconnect the LH air duct height adjustment actuator connector.
  6. Disconnect the LH air duct horizontal adjustment actuator connector.
  7. Disconnect the ETC connector.
  8. Remove the LH IP harness from the IP carrier.
    Note
    4x clips
  9. Remove the screws (x5) that attach the LH air vent to the IP carrier.
    Note
    5x screws, 4x datums
  10. Remove the LH air vent from the IP carrier.
  11. Remove the screws (x2) that attach the RH defrost duct to the IP carrier.
  12. Remove the RH defrost duct from the IP carrier.
  13. Disconnect the RH passenger air duct height adjustment actuator connector.
  14. Disconnect the RH passenger air duct horizontal adjustment actuator connector.
  15. Remove the RH IP harness from the IP carrier.
    Note
    2x clips, 2x slots
  16. Remove the screws that attach the RH passenger air vent to the IP carrier.
    Note
    5x screws, 4x datums
  17. Remove the passenger air vent from the IP carrier.
  18. Remove and discard the bolts (x6) that attach the passenger air bag to the IP carrier.

Install

  1. Put the new IP carrier on a stand.
    Note
    Recommend assistance
  2. Install new bolts (x6) that attach the passenger air bag to the new IP carrier (torque 8 Nm).
    Note
    6x patch bolts 1116594-00-B.
  3. Install the passenger air vent to the IP carrier.
  4. Install the screws (x5) that attach the passenger air vent to the IP carrier (torque 0.9 Nm).
    Note
    5x screws, 3x datums.
  5. Install the clips (x2) and slots (x2) that attach the RH IP harness to the IP carrier.
  6. Connect the passenger air duct horizontal adjustment actuator connector.
  7. Connect the passenger air duct height adjustment actuator connector.
  8. Install the RH defrost duct to the IP carrier.
  9. Install the screws (x2) that attach the RH defrost duct to the IP carrier (torque 0.9 Nm).
  10. Install the driver air vent to the IP carrier.
  11. Install the screws (x5) that attach the driver air vent to the IP carrier (torque 0.9 Nm).
    Note
    5x screws, 4x datums.
  12. Install the clips (x4) that attach the LH IP harness to the IP carrier.
  13. Connect the ETC connector.
  14. Connect the LH air duct horizontal adjustment actuator connector.
  15. Connect the LH air duct height adjustment actuator connector.
  16. Install the LH defrost duct to the IP carrier.
  17. Install the screws (x2) that attach the LH defrost duct to the IP carrier (torque 0.9 Nm).
  18. Install the IP carrier onto the cross car beam.
    Note
    Be careful not to press the speaker connector and ambient light connector onto the IP.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  19. Perform all further installation steps outlined in IP Carrier (Remove and Install).
