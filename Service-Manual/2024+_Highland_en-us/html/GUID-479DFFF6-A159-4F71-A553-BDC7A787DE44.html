Armrest - 2nd Row (Remove and Replace)

Correction code 1305010072 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1305 - 2nd Row Seat Assemblies and Hardware

Torque Specifications

Table 1. Torque Specifications: Armrest - 2nd Row (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x2) that attach the center armrest bracket to the seat frame
25 Nm (18.4 lbs-ft)
  • Torx T40 socket
 Reuse

Remove

  1. Remove the 2nd row LH seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  2. Remove the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  3. Remove the 2nd row LH seat back hinge bracket. See Bracket - Hinge - Seat Back - 2nd Row (Remove and Replace).
  4. Remove the 2nd row armrest closeout. See Closeout - Armrest - 2nd Row (Remove and Replace).
  5. Remove the bolts (x2) that secure the center armrest bracket to the seat frame.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T40 socket
  6. Release the clips and then pull the center armrest outward to remove it from the seat back.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.

Install

  1. Place the center armrest onto the seat frame and push it inward to make sure all clips are installed in place.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  2. Install the bolts (x2) that secure the center armrest bracket to the seat frame.
    25 Nm (18.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T40 socket
  3. Install the 2nd row armrest closeout. See Closeout - Armrest - 2nd Row (Remove and Replace).
  4. Install the 2nd row LH seat back hinge bracket. See Bracket - Hinge - Seat Back - 2nd Row (Remove and Replace).
  5. Install the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  6. Install the 2nd row LH seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
