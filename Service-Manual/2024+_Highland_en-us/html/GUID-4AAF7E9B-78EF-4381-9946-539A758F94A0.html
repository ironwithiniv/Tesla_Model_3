Duct - Air Wave - RH (Remove and Replace)

Correction code 1405030082 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1405 - Instrument Panel

Remove

  1. Remove the passenger footwell cover. See Cover - Footwell - Front Passenger (Remove and Replace).
  2. Remove the RH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  3. Remove the glove box. See Glove Box (Remove and Replace).
    Note
    No need to remove the glove box USB cable.
  4. Remove the RH footwell duct. See Duct - Footwell - RH (Remove and Replace).
  5. Remove the RH airwave duct thermistor. See Thermistor - Duct - RH (Remove and Replace).
  6. Release the clips (x2) that attach the LH airwave duct to the IP carrier.
  7. Remove the RH airwave duct from the HVAC module.

Install

  1. Install the RH airwave duct to the HVAC module.
  2. Fasten the clips (x2) that attach the LH airwave duct to the IP carrier.
  3. Install the RH airwave duct thermistor. See Thermistor - Duct - RH (Remove and Replace).
  4. Install the RH footwell duct. See Duct - Footwell - RH (Remove and Replace).
  5. Install the glove box. See Glove Box (Remove and Replace).
    Note
    No need to install the glove box USB cable.
  6. Install the RH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  7. Install the passenger footwell cover. See Cover - Footwell - Front Passenger (Remove and Replace).
