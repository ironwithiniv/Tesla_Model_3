Panel - Door Trim - Front - LH (Remove and Replace)

Correction code 1513010012 FRT 0.36 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Torque Specifications

Table 1. Torque Specifications: Panel - Door Trim - Front - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Screws (x3) that attach the LH front door panel to the LH front door
6 Nm (4.4 lbs-ft)
  • Torx T30 socket
 Reuse

Remove

  1. Open the front LH door, and fully lower the window.
  2. Remove the reflector from the rear edge of the LH front door trim panel.
  3. Remove the bolts (x3) that attach the trim panel to the door.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T30 socket
  4. Remove the front LH door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
  5. Remove the LH front door puddle light. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  6. Pull out on the trim panel from the puddle light opening to release the clips that attach the trim panel to the door.
    CAUTION
    Do not remove the trim panel from the door at this time.
    Note
    If needed, insert an inflatable air bag to the lower left corner of the LH front door trim to help removal.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  7. Continue to pull and release all of the clips around the edge of the trim panel, working from the bottom up.
    CAUTION
    Do not remove the trim panel from the door at this time.
  8. Release the manual release cable from the cable bracket and then remove the cable collar from the trim panel and pivot the collar down to a vertical orientation.
  9. Slide the cable barrel end out of the release lever, and remove the cable from the trim panel.
  10. Disconnect the electrical harness from the door connector.
    CAUTION
    Do not remove the trim panel from the door at this time.
  11. Raise the trim panel up to unhook it from the door, and then remove the panel from the door.
  12. Check the LH front door for any remaining push clip retainers, and if present, remove them from the door.
    Tip
    Insert a 90° pick into the push clip retainers and pry inward to bend or break the tabs. Then, use a trim tool to release the push clip retainers for the door.
  13. Release the NVH pad tabs (x4), then remove the NVH pad from the door panel.
  14. Disconnect the electric release switch connector.
    Tip
    Use of the following tool(s) is recommended:
    • Pick Miniature Soft Grip, 90 degree tip, 6 in
  15. Disconnect the door window switch connector.
    Tip
    Use of the following tool(s) is recommended:
    • Pick Miniature Soft Grip, 90 degree tip, 6 in
  16. Disconnect the door LED connector.
    Tip
    Use of the following tool(s) is recommended:
    • Pick Miniature Soft Grip, 90 degree tip, 6 in
  17. Disconnect the atmosphere light connector.
    Tip
    Use of the following tool(s) is recommended:
    • Pick Miniature Soft Grip, 90 degree tip, 6 in
  18. Disconnect the door speaker connector.
  19. Release the door harness from the hooks (x9) and fir tree clips (x2), then remove the door harness from the door panel.

Install

  1. Install the door harness into the door panel. Secure it into the hooks (x9) and fir tree clips (x2).
    Note
    The door harness from the old door trim transferred into the new trim if it is in good condition.
  2. Connect the door speaker connector.
  3. Connect the atmosphere light connector.
  4. Connect the door LED connector.
  5. Connect the electric release switch connector.
  6. Connect the door window switch connector.
  7. Install the underside puddle light to the LH front door panel. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  8. Install the NVH pad into the door panel, then secure the tabs (x4).
  9. Bring the trim panel to the door, and rest it on the door edge.
  10. Connect the electrical harness to the LH front door connector.
  11. Position the manual release cable in a vertical orientation, and slide the cable barrel end into the release lever.
  12. Pivot the manual release cable collar to a horizontal orientation and press the collar into the trim panel, and then secure the cable to the cable bracket.
    Note
    Make sure the manual release cable is routed underneath the door harness.
  13. Lift the trim panel, compress the LH front door inner belt seal slightly, and then hook the three trim panel tabs into the top edge of the door.
  14. Fasten the clips that attach the trim panel to the door.
  15. Make sure that the trim panel fits tightly, and that there are no gaps from misaligned or bent clips.
    Note
    The instrument panel belt line is 1 mm underflush to the door belt line at nominal.
  16. Install the screws (x3) that attach the trim panel to the door.
    6 Nm (4.4 lbs-ft)
    CAUTION
    Make sure that all fasteners are properly torqued and not cross-threaded.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T30 socket
  17. Install the reflector to the rear edge of the trim panel.
  18. Install the front LH door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
  19. Verify the vehicle firmware is version 2024.44 or later.
  20. Place the vehicle in Service Mode by using the touchscreen. See Service Mode.
  21. Unlock the vehicle gateway. See Gateway Unlock.
  22. On the touchscreen, tap the Service Mode "wrench" (at the bottom of the touchscreen UI), and then tap Low Voltage > Interior Lighting > Address RGB Lights, click Run, and allow the routine to complete.
  23. Reinstall the vehicle firmware. See Software Reinstall - Touchscreen.
  24. Exit Service Mode. See Service Mode.
  25. Close the door and verify the operation of the manual door release lever, that the door latch releases smoothly and easily.
  26. Raise the LH front window and close the door.
