Switch - Interior Door Release - Rear - LH (Remove and Replace)

Correction code 1513020052 FRT 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-04-14: Removed an unnecessary bolt handling step and updated the images for improved positioning and clarity.
Parent topic: 1513 - Door Trim

Torque Specifications

Table 1. Torque Specifications: Switch - Interior Door Release - Rear - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x2) that attach the LH rear door interior handle to the door trim panel
1 Nm (.7 lbs-ft)
  • Torx T20 socket
 Reuse

Remove

  1. Open the LH rear door.
  2. Lower the LH rear window.
  3. Remove the LH rear door puddle light. See Puddle Lamp - Rear Door (Remove and Replace).
  4. Remove the LH rear door trim panel. See Panel - Door Trim - Rear - LH (Remove and Replace).
  5. Release the tabs (x3), and then remove the NVH pad from the LH rear door trim panel.
    Note
    Recommend an assistant to hold the door trim.
    Note
    Do not remove the door electrical connector and clips.
  6. Disconnect the electric release switch connector.
  7. Remove the bolts (x2) that attach the interior door handle to the LH rear door panel trim.
    Tip
    Use of the following tool(s) is recommended:
  8. Apply masking tape around the work area to protect the door trim panel.
  9. Pry open the front portion of interior door handle.
    Note
    Make sure there is enough space to remove the interior door release switch.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  10. Carefully pry to release the tabs (x6) and guide pin, then remove the interior door release switch from the door trim panel.

Install

  1. Align the guide pin and secure the tabs (x6) that attach the interior door release switch onto the door trim panel.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  2. Secure the front portion of the interior door handle onto the door trim panel.
  3. Remove the masking tape from the door trim panel.
  4. Install the bolts (x2) that attach the interior door handle to door panel trim.
    1 Nm (.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
  5. Connect the electric release switch connector.
  6. Install the NVH pad onto the rear door trim panel and secure the pad with the tabs (x3).
  7. Install the LH rear door puddle light. See Puddle Lamp - Rear Door (Remove and Replace).
  8. Install the LH rear door trim panel. See Panel - Door Trim - Rear - LH (Remove and Replace).
