 Replace 1919198-00-A

Remove

  1. Place the vehicle in Service Mode by using the touchscreen. See Service Mode.
  2. Remove the upper camera cover. See Camera Cover - Upper (Remove and Replace).
  3. Remove and discard the bolts (x2) that attach the interior camera to the camera upper cover, and then remove the interior camera.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T10 bit

Install

  1. Secure the interior camera into the tab on the upper camera cover.
  2. Install new bolts (x2) that attach the interior camera to the upper camera cover.
    0.8 Nm (7 lbs-in)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T10 bit
  3. Install the upper camera cover. See Camera Cover - Upper (Remove and Replace).
  4. Unlock the vehicle gateway. See Gateway Unlock.
  5. Run PROC_DAS_X_CLEAR-CALIBRATIONvia Service Mode:
    • Driver Assist ➜ Cameras ➜ Clear Camera Calibration
    • Driver Assist ➜ Driverless ➜ Clear Calibration
    via Toolbox:(link)
  6. Run PROC_DAS_X_UPDATE-CAMERAvia Service Mode:Driver Assist ➜ Cameras ➜ Update Cameravia Toolbox:(link)
    Note
    This routine will be available in software version 2026.8.6 and later. Until then, run the following routines to update the camera:
    1. Connect a laptop with Toolbox 3 to the vehicle. See Toolbox (Connect and Disconnect).
    2. In Toolbox, click the Actions tab, type "DAS" into the search field, click PROC_DAS_X_ENTER-CALIBRATION-MODEvia Toolbox:(link), click Run, and allow the routine to complete.
    3. Type "Side Repeater" into the search field, click PING-HTTP_DAS_X_INTERIOR-CAMERA-SCRIPTvia Toolbox:(link), change the timeout to 100, click Run, and allow the routine to complete.
    4. Type "DAS" into the search field, click PING-HTTP_DAS_X_INTERIOR-CAMERA-SCRIPTvia Toolbox:(link), click Run, and allow the routine to complete.
    5. Disconnect the laptop from the vehicle.
  7. Exit Service Mode Plus. See Service Mode Plus.
