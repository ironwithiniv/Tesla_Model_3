LV Battery (Remove and Replace)

Correction code 1702010012 FRT 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-08-06: Updated the required firmware version for performing the LV battery learn routine.
  • 2024-11-20: Added a note to remind of checking the 12V/LV battery temperature before performing the procedure.
  • 2024-10-30: Added a Note about replacing the LV battery with different types.

Warning
Before performing the following procedure, make sure the 12V/LV battery temperature is not overheated.

Remove

Note
The LV battery may not need to be replaced. Attempt to recover the LV battery first before determining that the LV battery needs replacement. Refer to Toolbox article 6249900 for more information.
  1. Place the vehicle in Service Mode. See Service Mode.
  2. Make sure the vehicle firmware is 2025.26.6 or later.
  3. Disconnect LV power. See LV Power (Disconnect and Connect) (Modify).
  4. Wait 2 minutes for the electrical system to fully discharge.
  5. Remove the bolt that secures the positive jump post to the LV battery bracket.
    Tip
    Use of the following tool(s) is recommended:
    • 8 mm socket
  6. Remove the bolts (x3) that attach the LV battery to the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • 8 mm socket
  7. Remove the LV battery from the vehicle.

Install

  1. Install the bolts (x3) that attach the LV battery to the vehicle.
    6 Nm (4.4 lbs-ft)
    Note
    The black-cased LFP Li-Ion LV battery variant can be replaced by silver-cased NMC Li-Ion LV battery variant, but the silver-cased NMC Li-Ion LV battery variant can not be replaced by the black-cased LFP Li-Ion LV battery variant.
    Tip
    Use of the following tool(s) is recommended:
    • 8 mm socket
  2. Secure the bolt that secures the positive jump post to the LV battery bracket.
    5 Nm (3.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 8 mm socket
  3. Connect LV power. See LV Power (Disconnect and Connect) (Modify).
  4. Verify that the network connectivity is available.
  5. Unlock vehicle gateway. See Gateway Unlock.
  6. On the vehicle touchscreen, touch Low Voltage > Power Distribution > Battery Icon > Learn New Battery, and click Run to start the routine.
    CAUTION
    Vehicle software must be FW 2025.26.6 or later version.
    Note
    Once the routine is completed, the Mosfet and ECPA will be Closed.
  7. Only if the replacement battery is CATL_LI_ION: reinstall the vehicle software. See Software Reinstall - Touchscreen.
    Note
    You can read the battery configuration via service UI > Low Voltage > Power Distribution > Li-Ion LV battery > Config.
  8. Exit Service Mode. See Service Mode.
  9. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
