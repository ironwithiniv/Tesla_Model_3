Clevis Pin - Brake Pedal (Remove and Replace)

Correction code 3325010212 FRT 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 3325 - Brake Pedal

Remove

  1. Remove the driver footwell cover. See Cover - Footwell - Driver (Remove and Replace).
  2. Remove the LH footwell duct. See Duct - Footwell - LH (Remove and Replace).
  3. Release the cotter clip that attaches the brake clevis clip pin to the pedal assembly.
    Note
    Remove the cotter clip by hand.
  4. Remove the brake clevis clip pin from the brake pedal assembly, and then release the clevis clip from the pedal.
    Note
    Wiggle the brake pedal to aid in pin removal.

Install

  1. Align the brake pedal with the iBooster rod, and then install the brake clevis clip pin that attaches the clevis clip to the brake pedal assembly.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  2. Install the cotter clip that attaches the brake clevis clip pin to the pedal assembly.
    Note
    Move all parts to their original positions. Replace the cotter clip if damaged.
  3. Install the LH footwell duct. See Duct - Footwell - LH (Remove and Replace).
  4. Install the driver footwell cover. See Cover - Footwell - Driver (Remove and Replace).
