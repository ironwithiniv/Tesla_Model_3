Actuator - Charge Port (Gen 3) (Remove and Replace)

Correction code 4401010022 FRT 0.72 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 4401 - Charge System Inlet

Torque Specifications

Table 1. Torque Specifications: Actuator - Charge Port (Gen 3) (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Screws (x3) that attach the charge port actuator to the charge port
1 Nm (.7 lbs-ft)
  • Torx T10 socket
  • 4 in extension
  • Ratchet/torque wrench
 Reuse

Remove

  1. Remove the charge port door assembly. See Door Assembly - Charge Port (China) (Remove and Replace).
    Note
    During removal, certain steps require extra care. See the animation(s) for detailed guidance.
  2. Disconnect the charge port door actuator connector.
  3. Release the charge port door actuator harness.
    Note
    Extract the smaller grommet from larger grommet and then pull the harness through the larger grommet to release.
  4. Remove the screws (x3) that attach the actuator to the charge port door assembly, and then remove the actuator from the charge port door.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T10 socket
    • 4 in extension
    • Ratchet/torque wrench

Install

  1. Install the screws (x3) that attach the actuator on the charge port door.
    1 Nm (.7 lbs-ft)
    Note
    When engaging the actuator to the charge port door, make sure the legs from the charge port door align with the access holes on the actuator, and then fully seat the components before installing the screws.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T10 socket
    • 4 in extension
    • Ratchet/torque wrench
  2. Fasten the charge port door actuator harness.
    Note
    Pull the harness through the larger grommet to fasten.
  3. Connect the charge port door actuator connector.
  4. Install the charge port door assembly. See Door Assembly - Charge Port (China) (Remove and Replace).
