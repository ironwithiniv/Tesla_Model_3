A/C Refrigerant (Unknown Oil Quantity or System Flush) (Restore)

Correction code 18200112 FRT 1.02 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-01-06: Added TPN for AC oil flush adapters.
Warning
Only technicians who have completed all required certification courses are permitted to perform this procedure. Tesla recommends third party service provider technicians undergo equivalent training before performing this procedure.

For EMEA, in addition to any local A/C or F-gas certification, Tesla technicians are required to complete the Air Conditioning Safety Essentials training before working on Thermal Management and A/C systems.

Note
This procedure requires the A/C Refrigerant (Recovery and Recharge) procedure to be performed. If not already automatically added to the Service Visit, add correction code 18200102 as a separate correction within the same activity to the Service Visit.

Procedure

  1. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  2. Enter service mode. See Service Mode.
  3. Unlock the vehicle gateway. See Gateway Unlock.
  4. On the touchscreen, touch Service Mode > Thermal > Refrigerant System > Start Thermal Fill Drain (Refrigerant Only) and select Run to start the "Start Thermal Fill Drain (Refrigerant Only)" routine.
  5. Disconnect LV power. See LV Power (Disconnect and Connect) (Modify).
  6. Connect the A/C machine hose to the vehicle and recover the A/C refrigerant. See A/C Refrigerant (Recovery and Recharge) (Restore).
  7. Remove the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  8. Perform the Vehicle HV Disablement Procedure. See Vehicle HV Disablement Procedure.
  9. Remove the LV auxiliary battery. See LV Battery (Remove and Replace).
  10. Remove the nut that attaches the low pressure fitting to the A/C compressor.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  11. Remove the nut that attaches the high pressure fitting to the A/C compressor, and then set the hose assembly aside.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  12. Install the nuts (x2) that attaches the A/C flush adapters to the lower pressure pipe and high pressure pipe of the A/C compressor.
    22 Nm (16.2 lbs-ft)
    Note
    Before installing, inspect o-ring and replace if necessary.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  13. On the AC machine main menu, select Manual > Flushing Kit, enter 25 min as Vacuum Time, and select Enter > Enter, and run the flush cycles.
    Note
    System flush procedure runs for approximately 90 minutes.
    Note
    Minimum of 3200g of refrigerant needed in tank to run system flush procedure.
  14. Remove the compressor. See A/C Compressor (Remove and Replace).
  15. Use a digital scale to weigh the removed compressor and reset the oil quantity.
    Note
    Take note of the compressor weight and add A/C oil of the appropriate type (see Fluids and Capacities for A/C oil specifications) through the suction port of the compressor until it weighs 7181 grams (Denso compressor) or 7889 grams (Sanden compressor).
  16. Install the compressor. See A/C Compressor (Remove and Replace).
    Note
    Do not install the nuts (x2) that attach the lower pressure pipe and high pressure pipe to the A/C compressor yet.
  17. Disconnect the AC machine hoses from the AC flush adapters.
  18. When flush cycles complete, remove the nuts (x2) that attach the A/C flush adapters to the A/C compressor, and then remove the flush adapters.
    22 Nm (16.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  19. Replace the o-rings on the high pressure and low pressure supermanifold to A/C compressor hose fittings.
  20. Position the supermanifold to A/C compressor low pressure fitting on the A/C compressor, and then install the nut that attaches the fitting to the A/C compressor.
    22 Nm (16.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  21. Position the supermanifold to A/C compressor high pressure fitting on the A/C compressor, and then install the nut that attaches the fitting to the A/C compressor.
    22 Nm (16.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  22. Connect the A/C machine red high pressure hose to the vehicle's high pressure port, and the blue low pressure hose to the vehicle's low pressure port.
  23. Follow the A/C machine instructions to perform a vacuum leak for 2 minutes, and then run a vacuum for 15 more minutes to remove excess moisture from the vehicle.
  24. Perform the A/C refrigerant recharge, but do not install the underhood storage unit or rear underhood apron yet. See Recharge.
    CAUTION
    Recharge the refrigerant exactly as instructed. Failure to adhere to the instructions can cause catastrophic damage to the cooling system.
  25. Install LV power. See LV Battery (Remove and Replace).
  26. Connect LV power. See LV Power (Disconnect and Connect) (Modify).
  27. On the touchscreen, select Thermal > Refrigerant System > Stop Thermal Fill Drain and allow the routine to complete.
  28. On the touchscreen, select Thermal > Sensors and Valves > Run Heat Pump Commissioning and allow the routine to complete.
  29. On the touchscreen, select Thermal > Actions > Test Thermal Performance and allow the routine to complete.
  30. On the touchscreen, select Thermal > Actions > Test HVAC Performance and allow the routine to complete.
  31. Exit Service Mode. See Service Mode
  32. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  33. Install the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
