Fascia - Rear - Lower (Performance) (Remove and Replace)

Correction code 1001040032 FRT 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1001 - Bumper / Fascia

Torque Specifications

Table 1. Torque Specifications: Fascia - Rear - Lower (Performance) (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x4) that attach the lower rear fascia to the upper rear fascia
3 Nm (2.2 lbs-ft)
  • 10 mm socket
 Reuse

Remove

  1. Remove the rear fascia diffuser. See Diffuser - Rear Fascia (Remove and Replace).
  2. Remove the bolts (x4) that attach the rear lower fascia to the rear upper fascia.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  3. Remove the LH and RH rear fascia lamp assemblys. See Rear Fascia Light - LH (Remove and Replace).
  4. Remove the tabs (x19) that attach the lower fascia to the upper fascia.

Install

  1. Install the tabs (x19) that attach the lower fascia to the upper fascia from either side.
    CAUTION
    Take care not to damage painted fascia.
  2. Install the LH and RH rear fascia lamp assemblys. See Rear Fascia Light - LH (Remove and Replace).
  3. Install the bolts (x4) that attach the lower rear fascia to the upper rear fascia.
    3 Nm (2.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  4. Install the rear fascia diffuser. See Diffuser - Rear Fascia (Remove and Replace).
