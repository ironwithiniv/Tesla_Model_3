Ambient Light - Front Door (Remove and Replace)

Correction code 1513021612 FRT 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-11-20: Added the software reinstall step.
  • 2025-09-15: Update post-replacement service routine.
Parent topic: 1513 - Door Trim

Remove

  1. Open the LH front door, and then lower the LH front window.
  2. Remove the LH front door reflector. See Reflector - Door - Front - LH (Remove and Replace).
  3. Remove the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
  4. Remove the LH front door puddle light. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  5. Remove the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  6. Remove the LH front door NVH pad. See NVH Pad - Door - Front - LH (Remove and Replace).
  7. Disconnect the LH front door ambient light module connector.
  8. Release the tab that attaches the LH front door ambient light module to the door trim bracket.
  9. Use a 45 degree pick to release the tabs (x2) and locator pin that attach the LH front door ambient light module to the LED light strip, and then remove the ambient light module from the vehicle.

Install

  1. Engage the tabs (x2) and locator pin that attach the LH front door ambient light module to the LED light strip.
    Note
    Align the locator pin before installation.
    Note
    Take care not damaging the LED light strip.
  2. Engage the tab that attaches the LH front door ambient light module to the door trim bracket.
  3. Connect the LH front door ambient light module connector.
  4. Install the LH front door NVH pad. See NVH Pad - Door - Front - LH (Remove and Replace).
  5. Install the LH front door puddle light. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  6. Install the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  7. Install the LH front door reflector. See Reflector - Door - Front - LH (Remove and Replace).
  8. Install the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
  9. Unlock the vehicle gateway. See Gateway Unlock.
  10. Run PROC_VC_X_RGB-LIGHTS-ADDRESSINGvia Service Mode:
    • Low Voltage ➜ Lighting ➜ Address RGB Lights
    • Mid Voltage ➜ Lighting ➜ Address RGB Lights
    via Toolbox:(link)
    Note
    This routine requires the vehicle to be operating software version 2024.44 or later.
  11. Reinstall vehicle software. See Software Reinstall - Touchscreen.
  12. Exit Service Mode. See Service Mode.
  13. Raise the LH front window, and then close the LH front door.
