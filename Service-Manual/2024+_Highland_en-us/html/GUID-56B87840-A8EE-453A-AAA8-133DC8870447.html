Seat Assembly - 1st Row - No Lumbar - RH (Remove and Replace)

Correction code 1304010012 FRT 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2024-12-10: Added mini-tilt motor configuration information.
CAUTION
Supplemental Restraint System (SRS) components can be hazardous if not serviced and handled correctly. See Airbag and Supplementary Restraint System (SRS) Precautions
CAUTION
In the event of an airbag or seatbelt pretensioner deployment, certain components must be replaced, and other components must be inspected for damage. Refer to the Collision Repair Manual for a specific list of items that must be inspected and replaced.

Remove

  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Remove the RH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  3. Remove the RH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  4. Insert the seat belt release key (1133787-00-A) into the bottom of the seat belt pretensioner coupling to release the seat belt from the pretensioner.
  5. Move the seat fully forward.
  6. Remove and discard the bolts (x2) that attach the rear of the RH 1st row seat to the body.
    CAUTION
    Use only the Torx Plus T45 bit to remove the seat bolts.
    Note
    Use of the following tool(s) is recommended:
    • Torx Plus T45 socket
    Note
    Use the torchless heat induction tool to ease the removal of patch bolts, if necessary.
  7. Move the seat fully rearward.
  8. Remove and discard the bolts (x2) that attach the front of the RH 1st row seat to the body.
    CAUTION
    Use only the Torx Plus T45 bit to remove the seat bolts.
    Note
    Use of the following tool(s) is recommended:
    • Torx Plus T45 socket
    Note
    Use the torchless heat induction tool to ease the removal of patch bolts, if necessary.
  9. Adjust the RH front seat to the middle of the seat tracks, and then raise the seat fully.
    Tip
    Performing this step will aide in removing the seat.
  10. Disconnect LV power. See LV Power (Disconnect and Connect) (Modify).
  11. Locate the RH front seat electrical connector on the RH body controller module.
  12. Release the RH front seat connector lock, and then remove the connector from the RH body controller.
    Note
    Squeeze the release tab on the RH front seat connector lock, and then swing the lock away from the connector to release the lock.
    CAUTION
    Do not pull on the connector too hard. If the connector does not easily disconnect from the RH body controller, the lock is still engaged.
  13. Release the clip that attaches the RH front seat harness to the RH footwell support bracket near the RH side of the RH footwell.
  14. Release the clips that attach the RH front seat harness to the RH front seat harness guide.
  15. Pull the RH front seat harness out from under the RH front carpet.
  16. With assistance, remove the seat from the vehicle.
    Note
    Lift the seat, tilt the seat back, rotate the cushion toward the front door, and remove the seat from the vehicle, cushion first.
    CAUTION
    Take care not to damage the upholstery or trim while removing the seat.
    CAUTION
    If reinstalling the seat, place the seat in an area where it is not likely to be tipped over or otherwise damaged.

Install

  1. With assistance, position the RH 1st row seat in the vehicle.
    CAUTION
    Take care not to damage the upholstery or trim while positioning the seat.
  2. Route the RH 1st row seat harness under the RH front carpet, position the harness in the harness guide, and then install the clips that attach the harness to the harness guide.
  3. Install the clip that attaches the RH front seat harness to the RH footwell support bracket near the RH side of the RH footwell.
  4. Install the RH front seat harness connector on the RH body controller, and then engage the connector lock.
    Note
    Perform a push-pull test to ensure that the connector is fully seated and locked.
  5. Connect LV power. See LV Power (Disconnect and Connect) (Modify).
  6. Move the RH front seat fully rearward.
  7. Install the new bolts (x2) that attach the front of the RH 1st row seat to the body.
    33.5 Nm (24.7 lbs-ft)
    CAUTION
    Use only the Torx Plus T45 bit to install the seat bolts.
    Note
    Use of the following tool(s) is recommended:
    • Torx Plus T45 socket
  8. Move the RH front seat fully forward.
  9. Install the new bolts (x2) that attach the rear of the RH 1st row seat to the body.
    33.5 Nm (24.7 lbs-ft)
    CAUTION
    Use only the Torx Plus T45 bit to install the seat bolts.
    Note
    Use of the following tool(s) is recommended:
    • Torx Plus T45 socket
  10. Install the RH 1st row seat belt retractor onto the pretensioner.
    Note
    After reinstalling the seat belt pretensioner into the seat belt pretensioner coupling, perform a pull test to make sure that the seat belt and pretensioner are securely engaged.
  11. Reinstall the vehicle firmware. See Software Reinstall - Touchscreen.
  12. Install the RH lower A-Pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  13. Install the RH IP end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  14. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  15. Replacement front seat assemblies and seat cushion frame assemblies are equipped with a newly-designed "mini-tilt" motor, and replacing these parts (or the tilt motor itself) might require a configuration change. Review the configuration information in the table and perform the following substeps if a configuration update is needed.
    1. Access the Vehicle Configuration section of the Infotainment Dashboard. See Gateway Configuration (Display and Change).
    2. Update cfg_frontSeattype according to the combination of tilt motors described in the table.
  16. Run PROC_VCLEFT_SEAT-CALIBRATEvia Service Mode:Low Voltage ➜ Seats ➜ Calibrate Seatvia Toolbox:(link).
    CAUTION
    The seat will move automatically during this routine. Prior to execution, make sure there is nothing (including objects and aftermarket accessories) behind or underneath the related seat to prevent component damage.
  17. Move the RH front seat to its original position.
  18. Raise the LH front window and close the LH front door.
