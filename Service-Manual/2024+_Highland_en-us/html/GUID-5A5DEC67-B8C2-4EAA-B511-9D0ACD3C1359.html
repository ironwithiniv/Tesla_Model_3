Sensor - Cabin Temperature - Fan Driven (Remove and Replace)

Correction code 1810010122 FRT 0.06 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1810 - Cabin HVAC

Torque Specifications

Table 1. Torque Specifications: Sensor - Cabin Temperature - Fan Driven (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x2) that attach the cabin temperature sensor to the touchscreen
2 Nm (1.5 lbs-ft)
  • Torx T20 socket
Reuse

Remove

  1. Open the RH front door, and lower the RH front window.
  2. Insert a plastic trim tool into the top center slot of the service panel, and then release the clips (x2) and tabs (x4) that attach the service panel to the instrument panel.
    CAUTION
    An electrical harness is still connected to the service panel. Do not pull the service panel too far from the instrument panel.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  3. Disconnect the electrical harness from the cabin temperature sensor.
  4. Remove the service panel from the touchscreen.
  5. Remove the bolts (x2) that attach the cabin temperature sensor to the service panel, and then remove the sensor.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket

Install

  1. Position the cabin temperature sensor to instrument panel service panel, and then install the bolts (x2) that attach the sensor to the service panel.
    2 Nm (1.5 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  2. Connect the temperature sensor connector, and then secure the clips (x2) and tabs (x4) that attach the service panel to the vehicle.
  3. Raise the RH front window and close the RH front door.
