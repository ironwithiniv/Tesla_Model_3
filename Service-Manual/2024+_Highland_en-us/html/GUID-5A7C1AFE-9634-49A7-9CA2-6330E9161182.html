Cooling System (Check and Fill)

Correction code 18300200 0.05 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1830 - Cooling System

Procedure

Warning
Wear appropriate personal protective equipment (PPE) including a full face mask when performing this procedure.
  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Remove the coolant bottle cap.
  3. Fill the coolant to the proper level.
    Note
    Ensure that the coolant level is at the "Max" line.
  4. Install the coolant bottle cap.
  5. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
