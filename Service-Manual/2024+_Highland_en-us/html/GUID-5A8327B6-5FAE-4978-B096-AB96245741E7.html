Frame - Seat Cushion - Front Seat (Remove and Replace)

Remove

  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Remove the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  3. Remove the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  4. Remove the driver seat assembly. See Seat Assembly - 1st Row - LH (Remove and Replace).
  5. Remove the driver seat outboard side shield. See Side Shield - Outboard - LH (Remove and Replace).
    Note
    It is not necessary to remove the seat cushion button switch, the recliner button switch and the 8 way switch.
  6. Remove the driver seat outboard side shield carrier. See Carrier - Side Shield - Outboard - 1st Row (Remove and Replace).
  7. Remove the driver seat inboard side shield. See Side Shield - Inboard - LH (Remove and Replace).
  8. Remove the driver seat inboard side shield carrier. See Carrier - Side Shield - Outboard - 1st Row (Remove and Replace).
  9. Remove the driver seat cushion harness. See Harness - 1st Row Seat - LH (Remove and Replace).
    Note
    Only need to remove the cushion harness; no need to remove lumbar support and lumbar pump connectors.
  10. Remove and discard the outboard patch bolts (x2) that attach the driver seat back frame to the driver seat cushion frame.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket
  11. Remove and discard the inboard patch bolts (x2) that attach the driver seat back frame to the driver seat cushion frame.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket
  12. Tilt the driver seat back frame away from the driver cushion frame and lift the driver seat back frame up to remove it.
    Note
    Take care not to damage the harness.
  13. Remove the patch bolt and the felt that attach the driver seat belt buckle to the driver seat cushion frame, and discard the patch bolt.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket
  14. Remove the patch bolt and the felt that attach the driver pretensioner to the driver seat cushion frame, and discard the patch bolt.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket
  15. Release the driver seat cushion suspension from the driver seat cushion frame.
  16. Release the tabs that attach the driver seat cushion ventilation fan to the frame.
  17. Remove the track covers (x4) from the driver seat cushion frame.

Install

  1. Install the track covers (x4) to the driver seat cushion frame.
  2. Fasten the tabs that attach the driver seat cushion ventilation fan to the frame.
  3. Install the driver seat cushion suspension to the driver seat cushion frame.
    Note
    Make sure the fixing slots (x4) are properly attached to the frame.
  4. Install a new patch bolt and the felt that attach the driver pretensioner to the driver seat cushion frame.
    40 Nm (29.5 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket
  5. Install a new patch bolt and the felt that attach the driver seat belt buckle to the driver seat cushion frame.
    40 Nm (29.5 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket
  6. Install the driver seat back frame to the driver seat cushion frame.
    Note
    Take care not to damage the harness.
  7. Install new outboard patch bolts (x2) that attach the driver seat back frame to the driver seat cushion frame.
    43 Nm (31.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket
  8. Install new inboard patch bolts (x2) that attach the driver seat back frame to the driver seat cushion frame.
    43 Nm (31.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket
  9. Place the cushion pad assembly onto the seat cushion frame.
    Note
    Insert the rear of the seat cushion to the seat bottom frame, ensuring the rear portion of foam is seated over the rear seat cushion rail. Make sure that the wiring harness are routed through the back of seat frame.
  10. Maneuver the seat to gain access to the underside.
  11. Install the driver seat cushion harness. See Harness - 1st Row Seat - LH (Remove and Replace).
    Note
    No need to remove driver seat cover and operate on lumbar support and lumbar pump connectors.
  12. Install the driver seat outboard side shield carrier. See Carrier - Side Shield - Outboard - 1st Row (Remove and Replace).
  13. Install the driver seat outboard side shield. See Side Shield - Outboard - LH (Remove and Replace).
    Note
    It is not necessary to install the the seat cushion button switch, the recliner button switch and the 8 way switch.
  14. Install the driver seat inboard side shield carrier. See Carrier - Side Shield - Outboard - 1st Row (Remove and Replace).
  15. Install the driver seat inboard side shield. See Side Shield - Inboard - LH (Remove and Replace).
  16. Install the driver seat assembly. See Seat Assembly - 1st Row - LH (Remove and Replace).
    Note
    Do not perform the seat calibration routine at this time. Do it after performing the configuration change.
  17. Install the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  18. Install the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  19. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  20. Replacement front seat assemblies and seat cushion frame assemblies are equipped with a newly-designed "mini-tilt" motor, and replacing these parts (or the tilt motor itself) might require a configuration change. Review the configuration information in the table and perform the following substeps if a configuration update is needed.
    1. Access the Vehicle Configuration section of the Infotainment Dashboard. See Gateway Configuration (Display and Change).
    2. Update cfg_frontSeattype according to the combination of tilt motors described in the table.
  21. Perform the following routine using Service Mode or Toolbox (see 0005 - Service Modes): PROC_VCLEFT_SEAT-CALIBRATEvia Service Mode:Low Voltage ➜ Seats ➜ Calibrate Seatvia Toolbox:(link)
    CAUTION
    The seat will move automatically during this routine. Prior to execution, make sure there is nothing (including objects and aftermarket accessories) behind or underneath the related seat to prevent component damage.
  22. Exit Service Mode. See Service Mode.
