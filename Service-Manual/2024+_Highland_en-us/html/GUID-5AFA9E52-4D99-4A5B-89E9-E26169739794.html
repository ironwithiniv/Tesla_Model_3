Speaker - Front Door - LH (Remove and Replace)

Correction code 2121010312 FRT 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 2121 - Audio System - Speakers Subwoofer Amplifier

Torque Specifications

Table 1. Torque Specifications: Speaker - Front Door - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x4) that attach the front door speaker to the door
4 Nm (2.9 lbs-ft)
  • Cordless Ratchet/Impact Driver
  • 8 mm socket
  • Ratchet/torque wrench
 Reuse

Remove

  1. Open the LH front door and lower the LH front window.
  2. Remove the LH front door reflector. See Reflector - Door - Front - LH (Remove and Replace).
  3. Remove the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
  4. Remove the LH front door puddle light. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  5. Remove the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  6. Disconnect the electrical connector from the front door speaker.
  7. Remove the bolts (x4) that attach the front door speaker to the door, and then remove the speaker.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 8 mm socket
    • Ratchet/torque wrench

Install

  1. install the bolts (x4) that attach the front door speaker to the door.
    4 Nm (2.9 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 8 mm socket
    • Ratchet/torque wrench
  2. Connect the electrical connector to the front door speaker.
  3. Install the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  4. Install the LH front door puddle light. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  5. Install the LH front door reflector. See Reflector - Door - Front - LH (Remove and Replace).
  6. Install the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
  7. Raise the LH front window, and then close the LH front door.
