Sensor - Wheel Speed - Front - LH (Remove and Replace)

Correction code 3310010012 FRT 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2024-07-10: Added a note to remind routing the wheel speed sensor harness properly.
Equipment:
  • 1044206-00-A Wheel Trim Removal Tool
  • 1705887-00-A ½" Dr. Electric Impact
Parent topic: 3310 - ABS Traction and Stability Control

Torque Specifications

Table 1. Torque Specifications: Sensor - Wheel Speed - Front - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolt that attaches the LH front ABS wheel speed sensor to the knuckle
5 Nm (3.7 lbs-ft)
  • 10 mm deep socket
 Reuse

Remove

  1. Remove the LH front wheel. See Wheel Assembly (Remove and Install).
  2. Release the clips (x9) that attach the front of the LH front wheel arch liner to the vehicle, and then release the front portion of the LH front wheel arch liner.
  3. Disconnect the electrical harness from the LH front ABS wheel speed sensor connector.
  4. Release the clips (x5) that attach the LH front ABS wheel speed sensor harness to the LH front upper control arm.
  5. Remove the bolt that attaches the LH front ABS wheel speed sensor to the knuckle.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  6. Remove the LH front ABS wheel speed sensor from the vehicle.

Install

  1. Install the LH front ABS wheel speed sensor to the knuckle.
  2. Install the bolt that attaches the LH front ABS wheel speed sensor to the knuckle.
    5 Nm (3.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  3. Fasten the clips (x5) that attach the LH front ABS wheel speed sensor harness to the LH front upper control arm.
    CAUTION
    Ensure the harness is routed correctly to avoid contact with moving suspension components.
    CAUTION
    Perform a push-pull check on each clip to make sure they are fully attached to the upper control arm.
  4. Connect the electrical harness to the LH front ABS wheel speed sensor connector.
  5. Install the clips (x9) that attach the front of the LH front wheel arch liner to the vehicle.
  6. Install the LH front wheel. See Wheel Assembly (Remove and Install).
  7. Perform a test drive that includes a minimum speed of 25mph in straight line for at least five seconds to allow the ESP internal system checks to complete. The ESP faults will clear if the vehicle is repaired correctly. If faults are persistent after the test drive, continue troubleshooting the repair.
