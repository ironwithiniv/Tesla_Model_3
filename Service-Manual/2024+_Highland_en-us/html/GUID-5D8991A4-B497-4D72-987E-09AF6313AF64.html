Software Reinstall - Touchscreen

Parent topic: 0002 - Firmware Service

Firmware Reinstall (Li-Ion Battery) - Contactors Closed

  1. Enable Service Mode. See Service Mode.
  2. Go to the Service Mode menu: touch the Service Mode "wrench" icon at the bottom of the vehicle touchscreen.
    Note
    Alternatively, for vehicles with older firmware versions: Touch Controls (vehicle icon), and then touch Service Mode.
  3. On the vehicle touchscreen, touch Software Reinstall.
  4. When the prompt appears, read the instructions, and then touch REQUEST.
  5. Touch the Software tab and touch SOFTWARE UPDATE > INSTALL NOW.
    Note
    If a countdown timer appears, tap the timer until the clock reaches "0".
  6. Once the reinstallation is complete, check that the release notes appear on the touchscreen, indicating a successful reinstallation.
  7. Disable Service Mode. See Service Mode.
