Escutcheon - Seat Belt - Center (Remove and Replace)

Correction code 1305020102 FRT 0.06 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1305 - 2nd Row Seat Assemblies and Hardware

Remove

  1. Open the LH rear door and lower the LH rear window.
  2. Release the LH rear passenger seat back, and then fold the seat back down.
  3. Release the clips (x4) that attach the 2nd row center escutcheon to the seat assembly, and then separate the trim from the seat belt.

Install

  1. Install the 2nd row center escutcheon onto the seat belt, and then install the clips (x4) that attach the 2nd row center escutcheon to the seat assembly.
  2. Return the LH rear passenger seat back to its original position.
  3. Raise the LH rear window and close the LH rear door.
