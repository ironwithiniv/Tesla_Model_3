Headliner (Remove and Replace)

Correction code 1520010012 FRT 1.08 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

 Reuse

Remove

  1. Remove the headliner assembly. See Headliner (Remove and Install).

Replace

  1. Install the headliner assembly. See Headliner (Remove and Install).
  2. Locally connect a laptop with Toolbox 3 to the vehicle. See Toolbox (Connect and Disconnect).
  3. Select the Actions tab, search for TEST-SELF_VCLEFT_REAR-DOME-LIGHTS, click on TEST-SELF_VCLEFT_REAR-DOME-LIGHTSvia Toolbox:(link), click Run, and allow the routine to complete.
  4. Reinstall the firmware. See Software Reinstall - Touchscreen.
  5. Disconnect the laptop and exit Service Mode.
