Hockey Stick Assembly -LH (with a Clip-secured Phone Dock) (Remove and Replace)

Correction code 1519010092 FRT 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1519 - Center Console

Remove

  1. Remove the center console phone dock. See Phone Dock (Clip) - Center Console (Remove and Replace) or Phone Dock (Screw) - Center Console (Remove and Replace).
    Note
    For screw secured phone dock, use correction code 1519011002.
  2. Remove the rear end panel. See Panel - Rear End - Center Console (Remove and Replace).
  3. Remove the LH rear side panel. See Panel - Rear Side - Center Console - LH (Remove and Replace).
  4. Remove the LH front side panel. See Carpet - Side - Center Console - LH (Remove and Replace).
  5. Use a trim tool to release the clips (x18) and tabs (x3) that attach the LH décor trim to the center console.
  6. Remove the décor trim.

Install

  1. Align the tabs (x3) in the front and rear of the LH side panel.
  2. Install the clips (x18) that attach the rear side panel to the center console.
  3. Install the LH front side panel. See Carpet - Side - Center Console - RH (Remove and Replace).
  4. Install the LH rear side panel. See Panel - Rear Side - Center Console - LH (Remove and Replace).
  5. Install the rear end panel. See Panel - Rear End - Center Console (Remove and Replace).
  6. Install the center console phone dock. See Phone Dock (Clip) - Center Console (Remove and Replace) or Phone Dock (Screw) - Center Console (Remove and Replace).
