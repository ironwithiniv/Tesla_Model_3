Top Face Panel - Center Console (Remove and Replace)

Correction code 1519010082 FRT 0.30 Correction code 1519110082 FRT 0.48 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-12-24: Added correction code for top face panels on the vehicles with screw-secured phone docks.
Note
Verify the vehicle build date first.
  • If the vehicle is built after March 3rd, 2024, the phone dock should be secured by screws. In this case, use correction code 1519110082.
  • If the vehicle is built before March 3rd, 2024, the phone dock should be secured by clips. In this case, use correction code 1519010082.
Parent topic: 1519 - Center Console

Torque Specifications

Table 1. Torque Specifications: Top Face Panel - Center Console (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Screws (x4) that attach the top face panel to the center console
1 Nm (.7 lbs-ft)
  • Torx T20 socket
  • Digital Torque Screwdriver 0.10Nm - 2.0Nm (for installation only)
 Reuse

Remove

  1. Remove the center console phone dock. See Phone Dock (Screw) - Center Console (Remove and Replace) or Phone Dock (Clip) - Center Console (Remove and Replace).
  2. Remove the rear end panel. See Panel - Rear End - Center Console (Remove and Replace).
  3. Remove the LH and RH rear side panels. See Panel - Rear Side - Center Console - LH (Remove and Replace).
  4. Remove the LH front side panel. See Carpet - Side - Center Console - LH (Remove and Replace).
  5. Remove the RH front side panel. See Carpet - Side - Center Console - RH (Remove and Replace).
  6. Remove the LH and RH décor trims. See Hockey Stick Assembly -LH (with a Clip-secured Phone Dock) (Remove and Replace).
  7. Remove the screws (x4) that attach the top face panel to the center console.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
    • Digital Torque Screwdriver 0.10Nm - 2.0Nm (for installation only)
  8. Lift up the armrest.
  9. Use a trim tool to release the guide tabs (x2) and clips (x2) that attach the top face panel to the center console.
  10. Remove the top face panel.

Install

  1. Position the top face panel onto the center console.
  2. Install the guide tabs (x2) and clips (x2) that attach the top face panel to the center console.
  3. Install the screws (x4) that attach the top face panel to the center console.
    1 Nm (.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
    • Digital Torque Screwdriver 0.10Nm - 2.0Nm (for installation only)
  4. Install the LH and RH décor trims. See Hockey Stick Assembly -LH (with a Clip-secured Phone Dock) (Remove and Replace).
  5. Install the RH front side panel. See Carpet - Side - Center Console - RH (Remove and Replace).
  6. Install the LH front side panel. See Carpet - Side - Center Console - LH (Remove and Replace).
  7. Install the LH and RH rear side panels. See Panel - Rear Side - Center Console - LH (Remove and Replace).
  8. Install the rear end panel. See Panel - Rear End - Center Console (Remove and Replace).
  9. Install the center console phone dock. See Phone Dock (Screw) - Center Console (Remove and Replace) or Phone Dock (Clip) - Center Console (Remove and Replace).
