Duct - Floor - 2nd Row - RH (Remove and Replace)

Correction code 1810020012 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1810 - Cabin HVAC

Remove

  1. Open all the doors and lower all the windows.
  2. Remove the center console rear end panel. See Panel - Rear End - Center Console (Remove and Replace).
  3. Remove the RH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  4. Remove the RH lower A-pillar assembly. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  5. Remove the RH front seat assembly. See Seat Assembly - 1st Row - No Lumbar - RH (Remove and Replace).
  6. Remove the RH front footwell cover. See Cover - Footwell - Front Passenger (Remove and Replace).
  7. Remove the RH center console front side panel. See Carpet - Side - Center Console - RH (Remove and Replace).
  8. Remove the RH center console rear side panel. See Panel - Rear Side - Center Console - LH (Remove and Replace).
  9. Remove the RH front carpet. See Carpet - Front - RH (Remove and Replace).
  10. Remove the RH 2nd row floor duct from the main duct, and then remove it from the vehicle.

Install

  1. Install the RH 2nd row floor duct to the main duct.
  2. Install the RH front carpet. See Carpet - Front - RH (Remove and Replace).
  3. Install the RH center console rear side panel. See Panel - Rear Side - Center Console - LH (Remove and Replace).
  4. Install the RH center console front side panel. See Carpet - Side - Center Console - RH (Remove and Replace).
  5. Install the RH front footwell cover. See Cover - Footwell - Front Passenger (Remove and Replace).
  6. Install the RH front seat assembly. See Seat Assembly - 1st Row - No Lumbar - RH (Remove and Replace).
  7. Install the RH lower A-pillar assembly. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  8. Install the RH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  9. Install the center console rear end panel. See Panel - Rear End - Center Console (Remove and Replace).
  10. Raise all the windows and close all the doors.
