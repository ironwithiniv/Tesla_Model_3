Module - Ambient Light - Instrument Panel (Remove and Replace)

Correction code 1405021702 FRT 0.36 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-09-08: Released new procedure.
Parent topic: 1405 - Instrument Panel

Remove

  1. Remove the speaker grille. See Speaker Grille - Instrument Panel (Remove and Replace).
  2. Lift the ambient light LED modules upward to release the tabs (x2) that attach the modules to the speaker grille.
    Note
    Make sure not to damage the tubes.
  3. Release the tabs (x4) on both sides that attach the ambient light LED modules to the tubes, then remove the modules.
    Note
    Make sure not to damage the tubes.

Replace

  1. Install the ambient light LED modules onto the tubes.
    Note
    Perform push-pull test to ensure the ambient light LED modules are fully seated.
  2. Install the ambient light LED modules onto the speaker grille.
    Note
    Make sure not to damage the tubes.
  3. Install the speaker grille. See Speaker Grille - Instrument Panel (Remove and Replace).
