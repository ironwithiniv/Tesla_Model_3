End Cap - Instrument Panel - LH (Remove and Replace)

Correction code 1405010072 FRT 0.06 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1405 - Instrument Panel

Remove

  1. Open the LH front door and lower the LH front window.
  2. Partially release the lower section of the LH front primary door seal.
  3. Release the clips that attach the end cap to the vehicle, and then remove the end cap from the vehicle.
    Warning
    Wear cut-resistant gloves when performing this step to avoid personal injury.

Install

  1. Position the end cap to the vehicle, and then fasten the clips that attach the end cap to the vehicle.
  2. Install the lower section of the LH front primary seal to the vehicle and make sure it is properly seated.
  3. Raise the LH front window and close the LH front door.
