Webbing Guide Bar - Seatbelt - 1st Row (Single Side) (Remove and Replace)

Correction code 2005010022 FRT 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2024-11-14: Updated the torque info of the bolts that attach the 1st row webbing guide bar to the vehicle from 3.5 Nm to 5 Nm.
Parent topic: 2005 - Seatbelts

Torque Specifications

Table 1. Torque Specifications: Webbing Guide Bar - Seatbelt - 1st Row (Single Side) (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x2) that attach the 1st row webbing guide bar to the vehicle
5 Nm (3.7 lbs-ft)
  • Cordless Ratchet/Impact Driver
  • 8 mm socket
  • Torque wrench with angle measurement (for installation only)
 Replace

Remove

  1. Insert the seat belt release key (1133787-00-A) into the bottom of the seatbelt pretensioner coupling to release the seatbelt from the pretensioner.
  2. Remove the side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  3. Remove the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  4. Remove the end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  5. Remove the lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  6. Remove the lower B-pillar trim. See Trim - B-Pillar - Lower - LH (Remove and Replace).
  7. Remove the middle B-pillar trim. See Trim - B-Pillar - Middle - LH (Remove and Replace).
  8. Remove the upper B-pillar trim. See Trim - B-Pillar - Upper - LH (Remove and Replace).
  9. Remove and discard the bolts (x2) that attach the 1st row webbing guide bar to the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 8 mm socket
    • Torque wrench with angle measurement (for installation only)
  10. Remove the 1st row webbing guide bar.

Install

  1. Install new bolts (x2) that attach the 1st row webbing guide bar to the vehicle.
    5 Nm (3.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 8 mm socket
    • Torque wrench with angle measurement (for installation only)
  2. Install the upper B-pillar trim. See Trim - B-Pillar - Upper - LH (Remove and Replace).
  3. Install the middle B-pillar trim. See Trim - B-Pillar - Middle - LH (Remove and Replace).
  4. Install the lower B-pillar trim. See Trim - B-Pillar - Lower - LH (Remove and Replace).
  5. Install the lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  6. Install the end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  7. Install the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  8. Install the side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  9. Install the 1st row seatbelt retractor onto the pretensioner.
    Note
    After reinstalling the seatbelt pretensioner into the seatbelt pretensioner coupling, perform a pull test to make sure that the seatbelt and pretensioner are securely engaged.
