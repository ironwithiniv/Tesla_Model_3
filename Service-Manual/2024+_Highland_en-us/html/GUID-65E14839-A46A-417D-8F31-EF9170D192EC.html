Harness - 1st Row Seat - RH (Remove and Replace)

Correction code 1710060022 FRT 0.78 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1710 - Harnesses

Remove

  1. Remove the front passenger seat. See Seat Assembly - 1st Row - No Lumbar - RH (Remove and Replace).
  2. Remove the front passenger headrest trim. See Headrest - Front Seat - LH (Remove and Replace).
  3. Remove the RH seat back shell. See Shell - Seat Back - Front Seat - LH (Remove and Replace).
  4. Remove the upper flap covering the outboard corner of the seat back frame
    Note
    Pull flap out of the metal tabs to release
  5. Remove the lower flap covering the outboard corner of the seat back frame
    Note
    Pull flap out of the metal tabs to release
  6. Remove the upper flap covering the inboard corner of the seat back frame
    Note
    Pull flap out of the metal tabs to release
  7. Remove the lower flap covering the inboard corner of the seat back frame
    Note
    Pull flap out of the metal tabs to release
  8. Release seat back trim retainers from seat back frame
    Note
    7x retainers，1x Lock sheet
  9. Remove backrest ventilation fan connector
    Note
    1x connector
  10. Pull the seat upholstery away from the side air bag to gain access to the air bag electrical connector
  11. Disconnect seat side air bag connector
    Note
    1x connector, Press and hold the black tabs on both sides and pull down to release the connector
  12. Pull the seat upholstery away from the FSAB to gain access to the air bag electrical connector
  13. Disconnect seat FSAB connector
    Note
    1x connector, Press and hold the black tabs on both sides and pull down to release the connector
  14. Remove the harness clip securing the air bag pigtail to the seat back frame
    Note
    1x fir tree clip
  15. Remove the seat harness from seat back frame
    Note
    4x clips
  16. Remove the harness clip securing the FSAB pigtail to the seat back frame
    Note
    1x fir tree clip
  17. Disconnect the recliner motor
    Note
    1x connector
  18. Remove bolt securing outer side cover to seat
    Note
    1x bolt, 8mm, 5 Nm, Ensure the front of the seat is high enough to access the 8mm bolt
  19. Pull outward at front to release outer side cover clip from RH front seat
    Note
    1x clip, Do not fully remove for risk of damage to the trim/switch pack/harness
  20. Pull outward from the upper part of the trim panel to release the outer cover clips from the right front seats
    Note
    2x clips,1x positioning clip,Need to remove the lower clips first and then the upper positioning clip,Do not fully remove outer cover for risk of damage to the trim/switch pack/harness
  21. Disconnect RH front seat switch connector
    Note
    1x connector
  22. Remove the outer cover from the RH front seat
    Note
    5x clips, Pull outwards then upwards to release
  23. Disconnect the passenger pre-tensioner connector
    Note
    1x electrical connector, 2 stage locking connector, Release the first lock by pulling away from the connector, Then remove the connector from the pre-tensioner
  24. Release seat belt pretensioner harness bracket
    Note
    2x clips, First move the harness bracket forwards, Then remove the harness bracket backwards
  25. Remove clips securing seat switch harness to seat cushion frame
    Note
    2x fir tree clips
  26. Rotate seat to gain access to underside
    Note
    Protect seat cushion from damage
  27. Unhook the straps for the lower section of the seat back and move the seat back flap away from the underside of the seat
    Note
    2x clips
  28. Remove seat cushion ventilation fan connector
    Note
    1x connector
  29. Disconnect the seat back heater connector
    Note
    1x connector, Green
  30. Remove the seat back harness connector from the seat bottom
    Note
    Slide connector forward to release from seat bottom
  31. Disconnect the heat pad connector
    Note
    1x connector
  32. Remove seat occupied sensor connector from seat harness bracket
    Note
    2x tabs
  33. Disconnect the seat occupied sensor and set the sensor harness pigtail aside
    Note
    1x connector
  34. Remove clip securing harness to under side of the seat, next to seat heater connectors
    Note
    1x retaining clip
  35. Remove clips securing track motor harness to track motor housing
    Note
    2x edge clips
  36. Disconnect the tilt motor connector
    Note
    1x connector
  37. Disconnect the lift motor connector
    Note
    1x connector
  38. Disconnect RH front seat track motor connector
    Note
    1x connector
  39. Remove the clip securing the RH front seat harness to the outboard seat track
    Note
    1x clip
  40. Disconnect the seat belt buckle connector
    Note
    1x connector, 2x clips, First move the connector bracket backwards, Then remove the connector bracket forwards
  41. Remove clips securing seat belt buckle connector harness to seat cushion frame
    Note
    2x fir tree clips
  42. Remove the seat harness bracket from the the seat frame
    Note
    3x clips
  43. Route wire harness around the seat frame
    Note
    With the wire harness bracket as the center, Route wire harness around the seat frame, Keep the harness away from the seat, The harness will be completely free from the seat at this point
  44. Remove the seat harness assembly from the seat frame

  1. Position the new seat harness for installation
    Note
    With the wire harness bracket as the center, Route the harness under the lift motor and tilt motor placing the harness legs in the correct locations, Harness clips will be installed later
  2. Install the seat harness bracket to the seat base assembly
    Note
    3x clips
  3. Install the clips securing the seat belt buckle connector harness to the seat cushion frame
    Note
    2x fir tree clips
  4. Connect the seat belt buckle connector
    Note
    1x connector, First move the connector bracket backwards, Then install the connector bracket forwards
  5. Install the clip securing the LH front seat harness to the outboard seat track
    Note
    1x clip
  6. Connect RH front seat track motor connector
    Note
    1x connector
  7. Connect the lift motor connector
    Note
    1x connector
  8. Connect the tilt motor connector
    Note
    1x connector
  9. Install the clips securing the track motor harness to the track motor housing
    Note
    2x retaining clips
  10. Install the clip securing the harness to the under side of the seat, next to the seat heater connectors
  11. Connect heat pad connector
    Note
    1x connector
  12. Connect the seat occupied sensor and install the sensor onto the seat harness bracket
    Note
    1x connector, 2x tabs, Ensure harness is not routed between cushion and frame to avoid friction
  13. Install seat back harness connector to the seat bottom
    Note
    1x connector, 1x clip, Slide connector onto seat frame clip to secure
  14. Connect seat heater harness
    Note
    1x connector
  15. Install seat cushion ventilation fan connector
    Note
    1x connector
  16. Rotate seat back to the upright position
  17. Install clips securing seat switch harness to seat cushion frame
    Note
    2x fir tree clips
  18. Install seat belt pretensioner harness bracket
    Note
    2x clips, First move the connector bracket backwards, Then install the connector bracket forwards
  19. Connect the LH front seat belt pretensioner
    Note
    1x connector, Ensure connector locks engage
  20. Place outer cover on RH front seat
    Note
    5x clips, Apply light pressure to the rear of the exterior trim to seat it fully on the seat frame and align with the contour of the seat back
  21. Connect the RH front seat switch connector
    Note
    1x connector
  22. Install outer cover clips to RH front seat
    Note
    2x clips,1x Positioning clip, Need to install the upper Positioning clip first and then the lower clips, Ensure the trim and the switch are not damaged during install
  23. Install screw securing outer side cover to RH front seat
    Note
    1x bolt, 8mm, 5 Nm
  24. Connect the recliner motor
    Note
    1x connector
  25. Install backrest ventilation fan connector
    Note
    1x connector
  26. Install the harness clip securing the FSAB pigtail to the seat back frame
    Note
    1x fir tree clip
  27. Install the seat harness to seat back frame
    Note
    4x clips
  28. Install the harness clip securing the airbag pigtail to the seat back frame
    Note
    1x fir tree clip
  29. Connect RH front seat side air bag
    Note
    1x connector
  30. Connect front seat FSAB connector
    Note
    1x connector
  31. Install the lower flap covering the inboard corner of the seat back frame
    Note
    Pull the flap over the metal tangs to secure
  32. Install the upper flap covering the inboard corner of the seat back frame
    Note
    Pull the flap over the metal tangs to secure
  33. Install the lower flap covering the outboard corner of the seat back frame
    Note
    Pull the flap over the metal tangs to secure
  34. Install the upper flap covering the outboard corner of the seat back frame
    Note
    Pull the flap over the metal tangs to secure
  35. Secure seat back trim retainers onto seat back frame
    Note
    7x retainers,1x Lock sheet
  36. Install the RH seat back shell. See Shell - Seat Back - Front Seat - LH (Remove and Replace).
  37. Install the front passenger headrest trim. See Headrest - Front Seat - LH (Remove and Replace).
  38. Install the front passenger seat. See Seat Assembly - 1st Row - No Lumbar - RH (Remove and Replace).
