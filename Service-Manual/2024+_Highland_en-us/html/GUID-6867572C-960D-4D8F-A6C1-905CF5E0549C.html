Foam - Seat Back - 2nd Row - LH (Remove and Replace)

Correction code 1308010032 FRT 0.72 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1501599-00-A, Pliers, Hog Ring
Parent topic: 1308 - 2nd Row Seat Covers Pads and Trims

Torque Specifications

Table 1. Torque Specifications: Foam - Seat Back - 2nd Row - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x2) that attach the LH 2nd row seat back handle to the seat back frame
2 Nm (1.5 lbs-ft)
  • Torx T25 socket
 Reuse

Remove

  1. Remove the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  2. Remove the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  3. Remove the LH 2nd row seat back. See Seatback - 2nd Row - LH (Remove and Replace).
  4. Remove the LH 2nd row seat back hinge bracket. See Bracket - Hinge - Seat Back - 2nd Row (Remove and Replace).
  5. Remove the LH 2nd row seat back handle bezel. See Bezel - Handle - Seat Back - 2nd Row - LH (Remove and Replace).
  6. Remove the 2nd row center escutcheon. See Escutcheon - Seat Belt - Center (Remove and Replace).
  7. Remove the 2nd row armrest closeout. See Closeout - Armrest - 2nd Row (Remove and Replace).
  8. Remove the 2nd row armrest. See Armrest - 2nd Row (Remove and Replace).
  9. Remove the LH 2nd row seat back cover. See Trim - Seat Back - 2nd Row - LH (Remove and Replace).
  10. Remove the bolts (x2) that attach the LH 2nd row seat back handle to the seat back frame.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket
  11. Release the clips (x2) that attach 2nd row center seat backrest handle to the seat back frame.
  12. Remove the LH 2nd row seat back foam from the seat back frame.

Install

  1. Install the LH 2nd row seat back foam to the seat back frame.
  2. Install the clips (x2) that attach 2nd row center seat backrest handle to the seat back frame.
  3. Install the bolts (x2) that attach the LH 2nd row seat back handle to the seat back frame.
    2 Nm (1.5 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket
  4. Install the LH 2nd row seat back cover. See Trim - Seat Back - 2nd Row - LH (Remove and Replace).
  5. Install the 2nd row armrest. See Armrest - 2nd Row (Remove and Replace).
  6. Install the 2nd row armrest closeout. See Closeout - Armrest - 2nd Row (Remove and Replace).
  7. Install the 2nd row center escutcheon. See Escutcheon - Seat Belt - Center (Remove and Replace).
  8. Install the LH 2nd row seat back handle bezel. See Bezel - Handle - Seat Back - 2nd Row - LH (Remove and Replace).
  9. Install the LH 2nd row seat back hinge bracket. See Bracket - Hinge - Seat Back - 2nd Row (Remove and Replace).
  10. Install the LH 2nd row seat back. See Seatback - 2nd Row - LH (Remove and Replace).
  11. Install the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  12. Install the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
