Coax Cable - Side Repeater - Front - RH (Overlay) (Remove and Replace)

Correction code 17403112 FRT 1.74 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
  • 2026-07-09: Released new procedure.
  1. Raise and support vehicle
    Note
    Ensure vehicle is not charging
  2. Open LH front door
  3. Lower LH front window
  4. Open RH front door
  5. Lower RH front window
  6. Move RH front seat backward
  7. Open hood
  8. Remove rear apron
    Note
    14x clips
  9. Remove fresh air gutter assembly
    Note
    3x clips
  10. Remove LH wiper arm nut cover
    Note
    1x cover
  11. Release LH wiper arm hose nozzle
    Note
    1x hose
  12. Remove nut securing LH wiper arm to wiper module
    Note
    1x nut, 15mm, 25 Nm
  13. Remove LH wiper arm assembly from vehicle
  14. Remove RH wiper arm nut cover
    Note
    1x cover
  15. Release RH wiper arm hose nozzle
    Note
    1x hose
  16. Remove nut securing RH wiper arm to wiper module
    Note
    1x nut, 15mm, 25 Nm
  17. Remove RH wiper arm assembly from vehicle
  18. Release clips on the LH shock tower cover and move the tower cover to side
    Note
    2x clips
  19. Release clips on the RH shock tower cover and move the tower cover to side
    Note
    2x clips
  20. Remove LH hood hinge cover
    Note
    2x clips,1x dowel hole
  21. Remove RH hood hinge cover
    Note
    2x clips,1x dowel hole
  22. Disconnect main washer hose
    Note
    1x clip
  23. Remove clip securing FRL harness to cowl screen
    Note
    1x clip
  24. Remove clip securing main washer hose to cowl screen
    Note
    1x clip
  25. Remove cowl screen
    Note
    2x push clips, 4x clipsRelease cowl from windshield retainer
  26. Disconnect wiper module connector
    Note
    1x connector, Do not place limbs within the linkage movement area as wiper arms will automatically transition to parking mode
  27. Remove bolts securing wiper module to body
    Note
    3x bolts, 10mm, 7 Nm
  28. Remove wiper module from vehicle
    Note
    Keep your fingers away from any potential pinch points and moving parts while connecting and installing the wiper module, Do not attempt to test the module until it is fully installed in the vehicle
  29. Remove fresh air intake assembly
    Note
    2x studs, Lift cowl as needed
  30. Remove RH front wheel center cap
    Note
    1x cap, Pull the inner side of the adjacent 2 claws on the wheel center cap by hands
  31. Loosen RH front wheel nuts
    Note
    5x nuts, 21mm, 175 Nm
  32. Raise vehicle partially and lower lift onto locks
    Note
    Set vehicle to a comfortable working height, Make sure there's an audible click of the locks on both sides before lowering, Otherwise vehicle may tilt to the side
  33. Remove RH front wheel
    Note
    5x nuts, 21mm, 175 Nm
  34. Partially remove RH front wheel liner
    Note
    8x clips, 1x bolt, 10mm, 5 Nm
  35. Disconnect the front harness connectors for the RH side repeater and camera
    Note
    2x connectors, Release locking tabs
  36. Power off vehicle from center display
    Note
    Via Controls > Safety > Power Off, Select Power Off button at warning dialog box
  37. Disconnect LV battery and first responder loop
    Note
    2x connectors, Ensure that one minute has passed after window movement before performing the power-off, Release green locking tab, Press black tab then pull black connector lock outwards to release connection, Release red lock tab on FRL, Allow 2 minutes for all electrical circuits to fully discharge
  38. Release RH footwell cover
    Note
    2x magnets, 1x guide tab, 1x connector
  39. Partially release RH front primary door seal
    Note
    Release lower section of RH front primary door seal
  40. Remove RH IP end cap
    Note
    5x clips, 2x guide tabs
  41. Remove RH lower A-pillar trim
    Note
    4x clips, 2x guide tabs, Pull rear of lower A-pillar upward to release clip then pull rearward to release front tabs from carpet
  42. Remove RH knee airbag bolt covers
    Note
    2x covers
  43. Remove RH knee airbag bolts
    Note
    4x bolts, EP10, 8.5 Nm, Discard bolts after removal, brake loose e10 by hand then use e-ratchet to back off hardware
  44. Remove RH knee air bag assembly
    Note
    1x air bag connector, 1x connector, Peel back plastic film, Release by pulling back both white tabs simultaneously, Avoid straining harness, Only one tab visible in image matching tab is on opposite side
  45. Remove clips securing passenger footwell duct
    Note
    2x clips
  46. Disconnect glove box USB cable connector from car computer
    Note
    1x connector, Release locking tab then release connector
  47. Remove screws securing glove box to IP
    Note
    4x screws, T20, 2.3 Nm
  48. Release glove box from IP assembly
    Note
    10x clips, 3x locator pins, 1x datum, Avoid damage to electromagnetic switch
  49. Remove glove box
    Note
    2x connectors
  50. Remove RH passenger footwell duct from HVAC module
  51. Disconnect RH IP air wave duct thermistor connector
    Note
    1x connector
  52. Remove RH IP air wave duct from HVAC module
  53. Unfold RH front main cabin carpet back to original position
    Note
    1x locator clip
  54. Release windshield heater connecter
    Note
    1x connector
  55. Release RH grommet from body
  56. Remove electrical tape securing harness bundle to rubber dust boot
    Note
    Use a razor blaze, carefully cut electrical tape away to expose rubber dust boot
  57. Remove locking pin from connector
    Note
    Carefully pry pin out of connector and fully remove locking pin
  58. Remove coax cable needed for the side repeater overlay terminal 1 (RHS)
    Note
    Inspect all components for damage
  59. Apply harness tape onto RH coax overlay cable before installation
    Note
    Use Anti-abrasion tape and wrap the entire length of the coax cable to protect the cable for damage when it is in the vehicle
  60. Position RH coax overlay cable into place, Place through RH wheel liner
    Note
    Pull till you have roughly 6 inches of cable towards the interior of the vehicle
  61. Pull RH coax overlay cable through RH grommet harness
    Note
    Pull harness toward car computer under RH grommet main harness
  62. Tape coax overlay onto fish nylon tape
  63. Pull RH coax overlay cable through bulkhead and into interior cabin
  64. Remove nylon fish tape
    Note
    Remove tape the pull nylon fish tape out of vehicle
  65. Disconnect side repeater cameras connector from car computer
    Note
    1x locking connector
  66. Remove locking pin from side repeater cameras connector
    Note
    Carefully pry pin out of connector and fully remove locking pin
  67. Remove coax terminal 1 (RHS) cable from connector
    Note
    Inspect all components for damage
  68. Insert new side repeater coax terminal 1 (RHS) cable onto side repeater cameras connector
    Note
    Ensure both coax cables are fully seated into connector, Audible locking and flush mounting to confirm
  69. Secure locking pin to connector
    Note
    Align tabs of lock in connector housing, Ensure flush installation of locking pin to connector housing
  70. Connect side repeater cameras connector onto car computer
    Note
    1x locking connector
  71. Position RH coax overlay cable onto frunk main harness grommet, Secure cable onto harness using zip ties
    Note
    3x zip-ties, Trim off excess material after harness has been secured
  72. Cut off the vehicle side repeater coax terminal and tape to vehicle harness
    Note
    Cut the coax connector only
  73. Connect front harness connectors for the RH side repeater and camera
    Note
    2x connectors, Secure locking tabs
  74. Secure RH grommet from body
    Note
    Use electrical tape to wrap the end of the dust boot
  75. Secure windshield heater connector
    Note
    1x connector
  76. Install RH front wheel liner to vehicle
    Note
    8x clips, 1x bolt, 10mm, 5 Nm
  77. Install RH front wheel
    Note
    5x nuts, 21mm, 175 Nm, Start lug nuts by hand before using power tool, Torque at later step
  78. Lower vehicle until tires are touching ground
    Note
    Raise lift off locks, then hold lock release lever to keep locks free while vehicle is lowered
  79. Torque RH front wheel
    Note
    5x nuts, 21mm, 175 Nm
  80. Install RH front wheel center cap
    Note
    1x cap, Ensure that the cap is installed in place
  81. Install cowl screen to vehicle
    Note
    2x push clips, 4x clips
  82. Install LH shock tower cover
    Note
    3x push clips
  83. Install LH hood hinge cover
    Note
    2x clips,1x dowel hole, Install the lower portion onto the hinge, then press straight up to fully seat the cover
  84. Install RH shock tower cover
    Note
    3x push clips
  85. Install RH hood hinge cover
    Note
    2x clips,1x dowel hole, Install the lower portion onto the hinge, then press straight up to fully seat the cover
  86. Install clip securing washer hose to cowl screen
    Note
    1x clip
  87. Install clip securing harness to cowl screen
    Note
    1x clip
  88. Connect main washer hose
    Note
    1x clip
  89. Install RH wiper arm and hose assembly onto vehicle
  90. Install nut securing RH wiper arm to wiper module
    Note
    1x nut, 15mm, 25 Nm, Make sure the wiper tip is aligned between the two indicators at corner of windshield
  91. Secure RH wiper arm washer nozzle
    Note
    1x hose, Hose is routed below the arm
  92. Install RH wiper arm nut cover
    Note
    1x cover
  93. Install LH wiper arm and hose assembly onto vehicle
  94. Install nut securing LH wiper arm to wiper module
    Note
    1x nut, 15mm, 25 Nm, Make sure the wiper tip is aligned between the two indicators at corner of windshield
  95. Secure LH wiper arm washer nozzle
    Note
    1x hose, Hose is routed below the arm
  96. Install LH wiper arm nut cover
    Note
    1x cover
  97. Install fresh air intake assembly
    Note
    2x studs, Lift cowl as needed
  98. Position frunk assembly to vehicle
    Note
    8x clips, 3x locator pins, Ensure clips are aligned at thermal beam, Replace any clips if broken or missing
  99. Install bolts securing frunk assembly
    Note
    4x bolts, 10mm, 5 Nm, Number of bolts may vary depending on build date
  100. Install access panel to frunk assembly
    Note
    3x clips, 1x connector, Frunk safety switch, 3x guide tabs, Align 3x tabs then push forward to secure clips
  101. Install fresh air gutter assembly
    Note
    3x clips
  102. Install RH IP air wave duct to HVAC module
  103. Install clips securing RH IP air wave duct
    Note
    2x push clips
  104. Connect thermistor connector RH IP air wave duct
    Note
    1x connector
  105. Install RH passenger footwell duct to HVAC module
  106. Position glove box assembly
    Note
    2x connectors
  107. Install glove box into IP assembly
    Note
    10x clips, 3x locator pin, 1x datum, If necessary, Replace any clips that are broken
  108. Install screws securing glove box assembly to IP assembly
    Note
    4x screws, T20, 2.3 Nm
  109. Connect glove box USB cable to car computer
    Note
    1x connector, Engage locking tab
  110. Install clips securing passenger footwell duct
    Note
    2x push clips, Ensure that the footwell duct is installed in place
  111. Install RH IP end cap
    Note
    5x clips, 2x guide tabs
  112. lnstall seat lower section of RH front primary seal
    Note
    Verify seal is seated properly on all trim panels
  113. Install RH knee air bag assembly
    Note
    1x air bag connector, 1x connector, Ensure airbag connector is fully engaged, Place plastic film back over squib assembly
  114. Install RH knee airbag bolts
    Note
    4x bolts, EP10, 8.5 Nm, use socket wrench to start hardware by hand to avoid cross threading. Avoid Over tightening Hardware during installation avoid using power tools
  115. Install RH knee air bag bolt covers
    Note
    2x covers
  116. Install RH footwell cover
    Note
    2x magnets, 1x guide tab, 1x connector
  117. Connect first responder loop and LV battery
    Note
    2x connectors, Secure FRL first, Seat LV battery connection and push black connector lock inwards to secure, Engage green locking tab when fully seated
  118. Install rear apron
    Note
    14x clips, Hold rear wall of frunk to keep from flexing while engaging front clips
  119. Close hood
  120. Move RH front seat to original position
  121. Raise RH front window
  122. Close RH front door
  123. Verify operation of windshield washers and wipers
  124. Clear DAS Calibration through UI
    Note
    Controls > Service > Camera Calibration, Select Clear Calibration, Verify calibration was cleared successfully, Wait for prompt to disappear automatically before continuing, Calibration in Progress message and progress icon will appear during the next drive cycle
  125. Raise LH front window
  126. Close LH front door
  127. Remove lift arms from below vehicle
    Note
    Lower rack arms fully and remove them from under vehicle
  128. Vehicle will need to be driven by customer to complete calibration procedure. During this time DAS functions will be completely unavailable
    Note
    No time was recorded as this will be completed by the customer
