Retractor - Seatbelt - 2nd Row - Outboard (Single Side) (Remove and Replace)

Correction code 2005020012 FRT 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

CAUTION
Supplemental Restraint System (SRS) components can be hazardous if not serviced and handled correctly. See Airbag and Supplementary Restraint System (SRS) Precautions
CAUTION
In the event of an airbag or seatbelt pretensioner deployment, certain components must be replaced, and other components must be inspected for damage. Refer to the Collision Repair Manual for a specific list of items that must be inspected and replaced.
Parent topic: 2005 - Seatbelts

Torque Specifications

Table 1. Torque Specifications: Retractor - Seatbelt - 2nd Row - Outboard (Single Side) (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolt that attaches the 2nd row outboard seat belt retractor to the body
35 Nm (25.8 lbs-ft)
  • 3 in extension
  • 13 mm socket
  • Cordless Ratchet/Impact Driver
  • Flex head ratchet/flex head torque wrench (for installation only)
 Replace 1117251-00-B

Remove

  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Disconnect the LV power. See LV Power (Disconnect and Connect) (Modify).
  3. Remove the side rail trim. See Trim - Side Rail - LH (Remove and Replace).
  4. Remove the 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  5. Remove the upper C-pillar trim. See Trim - C-Pillar - LH (Remove and Replace).
  6. Disconnect the electrical connector from the 2nd row LH seat belt retractor.
    Note
    Lift the red tab to release the connector.
  7. Remove and discard the bolt that attaches the 2nd row seat belt retractor to the body, and then remove the retractor from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • 3 in extension
    • 13 mm socket
    • Cordless Ratchet/Impact Driver
    • Flex head ratchet/flex head torque wrench (for installation only)

Install

  1. Install the 2nd row seat belt retractor to the body, ensure to engage the T-tab on the retractor with the slot in the body, and then install a new bolt to attach the retractor to the body.
    35 Nm (25.8 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 3 in extension
    • 13 mm socket
    • Cordless Ratchet/Impact Driver
    • Flex head ratchet/flex head torque wrench (for installation only)
  2. Connect the electrical connector to the 2nd row seat belt retractor.
    Note
    Press the connector and a click sound of the secondary locking pin returning will be heard when the connector is fully seated.
  3. Install the upper C-pillar trim. See Trim - C-Pillar - LH (Remove and Replace).
  4. Install the 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  5. Install the side rail trim. See Trim - Side Rail - LH (Remove and Replace).
  6. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  7. Reconnect the LV power. See LV Power (Disconnect and Connect) (Modify).
