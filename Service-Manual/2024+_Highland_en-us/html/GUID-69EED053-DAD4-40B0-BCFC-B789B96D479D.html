Harness - Instrument Panel (LHD) (Remove and Replace)

Correction code 1710010032 FRT 1.92 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1710 - Harnesses

Remove

  1. Remove IP carrier from vehicle. See IP Carrier (Remove and Install).
  2. Remove RH IP fresh air intake from HVAC module. See Fresh Air Intake - HVAC (Remove and Replace).
  3. Remove the RH riser bracket. See Riser Bracket - Instrument Panel - RH (Remove and Replace).
  4. Disconnect the instrument panel harness connectors (x2) from the LH controller area.
  5. Remove the harness clip from the instrument panel near the LH controller.
  6. Remove the HVAC harness fixing clip from the instrument mount bracket.
  7. Disconnect the electrical connector from the electric steering column.
  8. Remove bracket securing the connector to crossbeam.
  9. Remove SCCM wiring harness clip from crossbeam.
  10. Disconnect the blower motor electrical connector.
  11. Release the blower motor harness clips (x2) from the cross car beam.
  12. Remove the instrument panel harness clips (x3) and harness holder from the top of the cross car beam, and then release the HVAC harness from the instrument panel harness.
  13. Remove UI harness fixing card from crossbeam.
  14. Remove the wiring harness fixing clip from the lower part of the dashboard Cross Car Beam.
  15. Remove RH wiring harness from instrument panel mounting bracket.
  16. Disconnect J10 connector from RH body controller.
  17. Remove IP harness clips from body.
  18. Disconnect IP harness connector from RCM.
  19. Remove instrument panel wiring harness from bottom area of center console area and move it aside.
  20. Remove IP harness from cross car beam.

Install

  1. Position IP harness to cross car beam for installation.
  2. Install instrument panel wiring harness to bottom area of center console area and move it aside.
  3. Connect HVAC connector to LH body controller.
  4. Connect instrument panel harness x035 connector to LH body controller.
  5. Install the harness clip from the instrument panel near the LH controller.
  6. Install the HVAC harness fixing clip to the instrument mount bracket.
  7. Install SCCM wiring harness clip to crossbeam.
  8. Install bracket securing the connector to crossbeam.
  9. Connect the electrical connector to the electric steering column.
  10. Install the instrument panel harness clips (x3) and harness holder to the top of the cross car beam, and then install the HVAC harness to the instrument panel harness.
  11. Install UI harness fixing card to crossbeam.
  12. Fasten the blower motor harness clips (x2) to the cross car beam.
  13. Connect the blower motor electrical connector.
  14. Install the wiring harness fixing clip to the lower part of the dashboard Cross Car Beam.
  15. Install RH wiring harness from instrument panel mounting bracket.
  16. Install IP harness clips to body.
  17. Connect IP harness connector to RCM.
  18. Connect J11 connector to RH body controller
  19. Install the RH riser bracket. See Riser Bracket - Instrument Panel - RH (Remove and Replace).
  20. Install RH instrument panel fresh air intake to HVAC module. See Fresh Air Intake - HVAC (Remove and Replace).
  21. Install instrument panel carrier to vehicle. See IP Carrier (Remove and Install).
