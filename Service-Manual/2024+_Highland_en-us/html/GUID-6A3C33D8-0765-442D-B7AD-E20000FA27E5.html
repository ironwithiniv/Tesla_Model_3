Harness - HVAC (Remove and Replace)

Correction code 1810010062 FRT 2.82 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Note
This procedure requires the A/C Refrigerant (Recovery and Recharge) procedure to be performed. If not already automatically added to the Service Visit, add correction code 18200102 as a separate correction within the same activity to the Service Visit.
Parent topic: 1810 - Cabin HVAC

Remove

  1. Remove the HVAC assembly. See HVAC Assembly (Remove and Replace).
  2. Disconnect the LH evaporator thermistor connector.
  3. Disconnect the LH lower duct thermistor connector.
  4. Disconnect the RH lower duct thermistor connector.
  5. Disconnect the lower mode actuator connector.
  6. Disconnect the upper mode actuator connector.
  7. Disconnect the intake actuator connector.
  8. Release the tabs (x4) that attach the HVAC harness to the left of the HVAC assembly.
  9. Release the tabs (x2) that attach the HVAC harness to the top of the HVAC assembly.
  10. Release the clips (x3) that attach the HVAC harness to the upper right of the HVAC assembly.
  11. Release the tabs (x4) that attach the HVAC harness to the right of the HVAC assembly, and then remove the harness from the vehicle.

Install

  1. Position the HVAC harness onto the HVAC assembly.
    Note
    Use connectors to confirm the harness position.
  2. Secure the tabs (x4) that attach the HVAC harness to the right of the HVAC assembly.
  3. Fasten the clips (x3) that attach the HVAC harness to the upper right of the HVAC assembly.
  4. Secure the tabs (x2) that attach the HVAC harness to the top of the HVAC assembly.
  5. Secure the tabs (x4) that attach the HVAC harness to the left of the HVAC assembly.
  6. Connect the lower mode actuator connector.
  7. Connect the upper mode actuator connector.
  8. Connect the intake actuator connector.
  9. Connect the LH evaporator thermistor connector.
  10. Connect the LH lower duct thermistor connector.
  11. Connect the RH lower duct thermistor connector.
  12. Install the HVAC assembly. See HVAC Assembly (Remove and Replace).
