Air Wave - Center Console (Remove and Replace)

NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Remove

  1. Open all the doors and lower all the windows.
  2. Remove the phone dock assembly. See Phone Dock (Clip) - Center Console (Remove and Replace) or Phone Dock (Screw) - Center Console (Remove and Replace).
  3. Remove the center console rear end panel. See Panel - Rear End - Center Console (Remove and Replace).
  4. Remove the USB bezel assembly. See USB Module - Center Console (Remove and Replace).
  5. Remove the LH and RH center console rear side panels. See Panel - Rear Side - Center Console - LH (Remove and Replace).
  6. Remove the LH and RH center console front side panels. See Carpet - Side - Center Console - LH (Remove and Replace).
  7. Remove LH and RH center console decor trims. See Hockey Stick Assembly -LH (with a Clip-secured Phone Dock) (Remove and Replace).
  8. Disconnect the LV power. See LV Power (Disconnect and Connect) (Modify).
  9. Remove the center console rear end module. See Module - Rear End - Center Console (Remove and Install).
  10. Remove the rear display. See Touchscreen - Rear (Remove and Replace).
  11. Remove the screws (x2) securing both sides of the airwave assembly.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  12. Remove the center console airwave.

Install

  1. Install the clips (x3) that attach the airwave assembly to the vent cover panel.
  2. Install the screws (x2) securing both sides of the airwave assembly.
    1 Nm (.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  3. Install the rear display. See Touchscreen - Rear (Remove and Replace).
  4. Install the center console rear end module. See Module - Rear End - Center Console (Remove and Install).
  5. Connect the LV battery power. See LV Power (Disconnect and Connect) (Modify).
  6. Install the RH and LH center console decor trims. See Hockey Stick Assembly -LH (with a Clip-secured Phone Dock) (Remove and Replace).
  7. Install the RH and LH center console front side panels. See Carpet - Side - Center Console - LH (Remove and Replace).
  8. Install the RH and LH center console rear side panels. See Panel - Rear Side - Center Console - LH (Remove and Replace).
  9. Install the USB bezel assembly. See USB Module - Center Console (Remove and Replace).
  10. Install the center console rear end panel. See Panel - Rear End - Center Console (Remove and Replace).
  11. Install the phone dock assembly. See Phone Dock (Clip) - Center Console (Remove and Replace)or Phone Dock (Screw) - Center Console (Remove and Replace).
  12. Connect a laptop with Toolbox to the vehicle. See Toolbox (Connect and Disconnect).
  13. In Toolbox, click the Actions/Autodiag tab, type "TEST-SELF_VCUSB_X_HVAC-ACTUATOR" in the search field.
  14. Click on TEST-SELF_VCUSB_X_HVAC-ACTUATORvia Toolbox:(link), and then click Runand allow the routine to complete.
  15. Disconnect the laptop with Toolbox from the vehicle. See Toolbox (Connect and Disconnect).
  16. Exit Service Mode Plus. See Service Mode Plus.
  17. Raise all the windows and close all the doors.
