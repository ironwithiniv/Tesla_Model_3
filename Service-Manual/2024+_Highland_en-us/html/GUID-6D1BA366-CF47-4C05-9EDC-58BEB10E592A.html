Harness - Instrument Panel Trim - RH (LHD) (Remove and Replace)

Correction code 1710010022 FRT 1.20 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1710 - Harnesses

Remove

  1. Remove the IP Carrier. See IP Carrier (Remove and Replace).
  2. Disconnect RH air duct height adjustment actuator connector.
  3. Disconnect RH air duct horizontal adjustment actuator connector.
  4. Remove the RH instrument panel harness from the instrument panel.

Install

  1. Connect the RH instrument panel harness to the instrument panel.
  2. Connect RH air duct horizontal adjustment actuator connector.
  3. Connect RH air duct height adjustment actuator connector.
  4. Install the IP Carrier. See IP Carrier (Remove and Replace).
