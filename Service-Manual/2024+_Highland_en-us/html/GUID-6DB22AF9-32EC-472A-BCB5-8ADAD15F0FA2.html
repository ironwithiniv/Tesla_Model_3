Sensor - Ambient Air Temperature (Remove and Replace)

Correction code 1850010022 FRT 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1850 - Air Distribution

Remove

  1. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  2. Carefully remove the ambient temperature sensor cover from the active grille shutter.
  3. Disconnect the ambient temperature sensor electrical connector.
  4. Release the clips that attach the ambient temperature sensor to the active grille shutter.
  5. Remove the ambient temperature sensor from the vehicle.

Install

  1. Install the clips that attach the ambient temperature sensor to the active grille shutter.
  2. Connect the ambient temperature sensor electrical connector.
  3. Install the ambient temperature sensor cover to the active grille shutter.
  4. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
