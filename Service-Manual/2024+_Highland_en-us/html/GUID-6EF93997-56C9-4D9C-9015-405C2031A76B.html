Jumper Harness - Trailer Hitch (Remove and Replace)

Correction code 17102012 FRT 0.54 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1710 - Harnesses

Torque Specifications

Table 1. Torque Specifications: Jumper Harness - Trailer Hitch (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts secure rear fascia center bracket to vehicle
4 Nm (2.9 lbs-ft)
  • 10 mm deep socket
 Reuse
Nuts (x6) secure trailer hitch to vehicle
60 Nm (44.2 lbs-ft)
  • 15 mm deep socket
 Reuse

Remove

  1. Remove the rear fascia. See Fascia Assembly - Rear (Remove and Install).
  2. Disconnect trailer hitch ECU.
  3. Release rear fascia center bracket.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  4. Remove trailer hitch from vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm deep socket

Install

  1. Install trailer hitch onto vehicle.
    60 Nm (44.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm deep socket
  2. Install rear fascia center bracket.
    4 Nm (2.9 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  3. Connect trailer hitch ECU.
  4. Install the rear fascia. See Fascia Assembly - Rear (Remove and Install).
