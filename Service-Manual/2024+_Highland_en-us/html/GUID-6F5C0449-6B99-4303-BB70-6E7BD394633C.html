Bracket - Cable Release - Charge Port (Remove and Replace)

Correction code 4401010042 FRT 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 4401 - Charge System Inlet

Remove

  1. Open the LH front door and lower the LH front window.
  2. Open the trunk from exterior switch.
  3. Remove the rear trunk load floor. See Load Floor - Trunk (Remove and Replace).
  4. Remove the trunk garnish assembly. See Garnish - Trunk (Remove and Replace).
  5. Remove the trunk sill trim assembly. See Trim - Trunk Sill (Remove and Replace).
  6. Remove the LH trunk load floor bracket. See Bracket - Trunk Load Floor - LH (Remove and Replace).
  7. Disconnect the LH trunk task light connector.
  8. Remove the clip that secures the LH trunk side trim to the vehicle, and then move the side trim aside.
    Note
    Take care not to cause excessive creasing when moving the side trim.
  9. Release the charge port manual release cable from the cable bracket.
    Note
    Gently release the clip to avoid damage. Do not apply excess force.
  10. Remove the charge port manual release cable bracket from the vehicle.

Install

  1. Install the charge port manual release cable bracket to the vehicle.
  2. Secure the charge port manual release cable onto the cable bracket.
  3. Move the LH trunk side trim into the original position.
  4. Connect the LH trunk task light connector.
  5. Install the clip that secures the LH trunk side trim to the vehicle.
  6. Install the trunk garnish assembly. See Garnish - Trunk (Remove and Replace).
  7. Install the LH trunk load floor bracket. See Bracket - Trunk Load Floor - LH (Remove and Replace).
  8. Install the trunk sill trim assembly. See Trim - Trunk Sill (Remove and Replace).
  9. Install the rear trunk load floor. See Load Floor - Trunk (Remove and Replace).
  10. Close the trunk via exterior switch.
  11. Raise the LH front window and close the LH front door.
