Harness - Parcel Shelf (Gen 2) (EU) (Remove and Replace)

Correction code 1710100012 FRT 0.54 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1111306-00-A GLUE GUN
Parent topic: 1710 - Harnesses

Remove

  1. Remove the LH and RH side rail trims. See Trim - Side Rail - LH (Remove and Replace).
  2. Remove the LH and RH side bolsters. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  3. Remove the LH and RH C-pillar trims. See Trim - C-Pillar - LH (Remove and Replace).
    Note
    No need to remove the bolts that attach the seatbelt anchors to the body.
  4. Remove the package tray trim. See Trim - Package Tray (Premium) (Remove and Replace).
  5. Disconnect the electrical connector from the LH parcel shelf speaker.
  6. Disconnect the electrical connector from the RH parcel shelf speaker.
  7. Disconnect the electrical connector from the high mounted brake light.
  8. Remove the sound insulation cotton.
    Note
    Only remove the soundproof cotton which covers the harness.
  9. Remove the tree clips (x2) and clips (x6) that attach the parcel shelf harness to the parcel shelf, and then remove the harness from the vehicle.

Install

  1. Fasten the tree clips (x2) and clips (x6) that attach the parcel shelf harness to the parcel shelf.
  2. Connect the electrical connector to the LH parcel shelf speakers.
  3. Connect the electrical connector to the RH parcel shelf speakers.
  4. Connect the electrical connector to the center high mounted brake light.
  5. Use a glue gun to apply hot glue adhesive to the original position and install the sound insulation cotton.
    Note
    Only install the soundproof cotton which covers the harness.
  6. Install the package tray trim. See Trim - Package Tray (Premium) (Remove and Replace).
  7. Install the LH and RH C-pillar trims. See Trim - C-Pillar - LH (Remove and Replace).
    Note
    No need to install the bolts that attach the seatbelt anchors to the body.
  8. Install the LH and RH side bolsters. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  9. Install the LH and RH side rail trims. See Trim - Side Rail - LH (Remove and Replace).
