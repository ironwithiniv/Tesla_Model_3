Sensor - Exterior Door Handle - Front - LH (Remove and Replace)

Correction code 1145010032 FRT 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1145 - Exterior Door Handles

Torque Specifications

Table 1. Torque Specifications: Sensor - Exterior Door Handle - Front - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Screws that attach the hall sensor to the LH door exterior release handle
1.2 Nm (.9 lbs-ft)
  • Torx T20 socket
 Reuse

Remove

  1. Remove the LH front door reflector. See Reflector - Door - Front - LH (Remove and Replace).
  2. Remove the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
  3. Remove the LH front door puddle light. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  4. Remove the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  5. Remove the LH front door outer belt seal. See Seal - Outer Belt - Front Door - LH (Remove and Replace).
  6. Remove the LH front door glass. See Glass - Door - Front - LH (Remove and Replace).
  7. Disconnect the LV power. See LV Power (Disconnect and Connect) (Modify).
  8. Remove the LH front door closeout panel. See Closeout Panel - Door - Front - LH (Remove and Replace).
  9. Remove the LH front exterior door handle. See Handle - Exterior Release - Door - Front - LH (Remove and Replace).
  10. Remove the screws (x2) that attach the hall sensor to the LH door exterior release handle, and then remove the hall sensor from the release handle.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket

Install

  1. Install the screws that attach the hall sensor to the LH door exterior release handle.
    1.2 Nm (.9 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  2. Install the LH front exterior door handle. See Handle - Exterior Release - Door - Front - LH (Remove and Replace).
  3. Install the LH front door closeout panel. See Closeout Panel - Door - Front - LH (Remove and Replace).
  4. Connect the LV power. See LV Power (Disconnect and Connect) (Modify).
  5. Install the LH front door glass. See Glass - Door - Front - LH (Remove and Replace).
  6. Install the LH front door outer belt seal. See Seal - Outer Belt - Front Door - LH (Remove and Replace).
  7. Install the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  8. Install the LH front door puddle light. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  9. Install the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
  10. Install the LH front door reflector. See Reflector - Door - Front - LH (Remove and Replace).
  11. Unlock the vehicle gateway. See Gateway Unlock.
  12. On the touchscreen, touch Controls > Service Mode > Windows > Calibrate Windows, then select Start to calibrate the window.
  13. Disable Service Mode. See Service Mode.
