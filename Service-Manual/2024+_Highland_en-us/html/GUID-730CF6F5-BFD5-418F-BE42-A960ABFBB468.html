Link - Compliance - Lower - Front - LH (Remove and Replace)

Correction code 3101020102 FRT 0.36 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-09-07: Added steps to hand-tighten the fasteners securing the compliance link to the vehicle before torquing them.
CAUTION
If performing this procedure as a result of a collision, see the Collision Repair Manual to verify whether the steering gear must be replaced as well.
Parent topic: 3101 - Front Suspension (Including Hubs)

Torque Specifications

Table 1. Torque Specifications: Link - Compliance - Lower - Front - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Nut that attaches the LH front lower compliance link to the knuckle
180 Nm (132.7 lbs-ft)
  • Breaker bar
  • 22 mm deep socket
 Replace
Bolt and nut that attach the LH front lower compliance link to the front subframe
115 Nm (84.8 lbs-ft)
  • 21 mm socket
 Reuse

Remove

  1. Inspect the vehicle for abnormal tire wear that might indicate the need for a wheel alignment. Note any findings.
  2. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  3. Remove the LH front wheel. See Wheel Assembly (Remove and Install).
  4. Remove the front aero shield. See Panel - Aero Shield - Front (Remove and Replace).
  5. Remove and discard the nut that attaches the LH front lower compliance link to the knuckle.
    Tip
    Use of the following tool(s) is recommended:
    • Breaker bar
    • 22 mm deep socket
  6. Remove the bolt and nut that attach the LH front lower compliance link to the front subframe, and then remove the link from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • 21 mm socket

Replace

  1. With assistance, position the LH front lower compliance link to the front subframe, and then hand-tighten the bolt and nut that attach the LH front lower compliance link to the front subframe.
    Note
    Torque at a later step.
  2. Hand-tighten a new nut that attaches the LH front lower compliance link to the knuckle.
    Note
    Torque at a later step.
  3. Torque the bolt and nut that attach the LH front lower compliance link to the front subframe.
    115 Nm (84.8 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 21 mm socket
  4. Torque the nut that attaches the LH front lower compliance link to the knuckle.
    180 Nm (132.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Breaker bar
    • 22 mm deep socket
  5. Install the front aero shield. See Panel - Aero Shield - Front (Remove and Replace).
  6. Install the LH front wheel. See Wheel Assembly (Remove and Install).
  7. Refer to the Alignment Requirement tables to determine whether an EPAS alignment check (EC) or four wheel alignment check (AC) is necessary. If performed, add the alignment check/adjust as a separate activity. See Alignment Requirement - Suspension.
