Actuator - Pedestrian Protection - Active Hood - LH (Remove and Replace)

Correction code 2020010052 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

CAUTION
Supplemental Restraint System (SRS) components can be hazardous if not serviced and handled correctly. See Airbag and Supplementary Restraint System (SRS) Precautions
CAUTION
In the event of an airbag or seatbelt pretensioner deployment, certain components must be replaced, and other components must be inspected for damage. Refer to the Collision Repair Manual for a specific list of items that must be inspected and replaced.

  • Cordless Ratchet/Impact Driver
  • Torx T30 socket
  • ¼ in hex to ¼ in square 6 in adapter

 Reuse

Remove

  1. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Disconnect the LV battery. See LV Power (Disconnect and Connect) (Modify).
  4. Remove the cabin intake duct. See Assembly - Fresh Air Gutter - HVAC (Remove and Replace).
  5. Remove the access panel. See Cover - Hood Latch (Remove and Replace).
  6. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  7. Remove the LH front wheel. See Wheel Assembly (Remove and Install).
  8. Remove the bolt that attaches the LH front wheel arch liner to the vehicle.
    Note
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  9. Remove the clips (x8) that attach the LH front wheel arch liner to the body and then partially remove the LH front wheel arch liner.
  10. Disconnect the pyrotechnic actuator connector.
  11. Use a small flat head screwdriver to release the clip that attaches the LH hood strut to the LH hood strut bracket, and then remove the strut from the bracket.
  12. Remove the nuts (x2) that attach the pyrotechnic actuator to the body, and then remove the actuator from the vehicle.
    Note
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • Torx T30 socket
    • ¼ in hex to ¼ in square 6 in adapter
    • Ratchet/torque wrench

Install

  1. Install the pyrotechnic actuator to the body, and then install the nuts (x2) attach the actuator to the body.
    6 Nm (4.4 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • Torx T30 socket
    • ¼ in hex to ¼ in square 6 in adapter
    • Ratchet/torque wrench
  2. Position the strut to the LH active hood strut bracket, and then install the clip that attaches the strut to the bracket.
  3. Connect the pyrotechnic actuator connector.
  4. Move the LH front wheel arch liner back, and then install the clips (x8) that attach the LH front wheel arch liner to the body.
  5. Install the bolt that attaches the LH front wheel arch liner to the vehicle.
    5 Nm (3.7 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  6. Install the LH front wheel. See Wheel Assembly (Remove and Install).
  7. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  8. Install the access panel. See Cover - Hood Latch (Remove and Replace).
  9. Connect the LV battery. See LV Power (Disconnect and Connect) (Modify).
  10. Install the cabin intake duct. See Assembly - Fresh Air Gutter - HVAC (Remove and Replace).
  11. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  12. Lower the vehicle. See Raise Vehicle - 2 Post Lift.
    Note
    Replace the RCM after the deployment of a Pedestrian Protection hood actuator.
