Hood Assembly (Remove and Install)

Correction code 10100301 FRT 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1080562-00-A Telescoping Hood Prop
Parent topic: 1010 - Body Panels

Torque Specifications

Table 1. Torque Specifications: Hood Assembly (Remove and Install)
Description Torque Value Recommended Tools Reuse/Replace Notes
Nuts (x4) that attach the hood to the LH and RH hood hinges
15 Nm (11.1 lbs-ft)
  • 13 mm socket
 Reuse

Remove

  1. Open the LH front door and lower the LH front window.
  2. Open the hood and support it in an open position.
    Tip
    Use of the following tool(s) is recommended:
    • Telescoping Hood Prop - 1080562-00-A
  3. Release the clips (x2) that attach the LH and RH hood gas struts to the LH and RH hood strut brackets, and then set the struts aside.
  4. With assistance, remove the nuts (x4) that attach the hood to the LH and RH hood hinges.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  5. With assistance, remove the hood from the vehicle, and then place it on a padded surface.

Install

  1. With assistance, install the hood onto the vehicle and align with the hood hinges.
  2. Loosely install the nuts (x4) that attach the hood to the LH and RH hood hinges.
  3. Support the hood in an open position.
    Tip
    Use of the following tool(s) is recommended:
    • Telescoping Hood Prop - 1080562-00-A
  4. Install the clips (x2) that attach the LH and RH hood gas struts to the LH and RH hood strut brackets.
  5. Remove the hood prop, close the hood and check hood fitment.
  6. Open hood and make adjustments, if necessary.
  7. Torque the nuts (x4) that attach the hood to the LH and RH hood hinges.
    15 Nm (11.1 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  8. Clean the LH and RH hood hinge bolts and the surrounding area with isopropyl alcohol (IPA), and then let dry for at least 1 minute.
  9. If necessary, apply touch up paint matching the vehicle's body color to the LH and RH hood hinge studs/nuts.
  10. Close the hood, raise the LH front window and close the LH front door.
