Latch - Door - Front - LH (Remove and Replace)

Correction code 1133020022 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1133 - Closure Assist Mechanisms and Hinges

Torque Specifications

Table 1. Torque Specifications: Latch - Door - Front - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x3) that attach the LH front door latch to the rear of the LH front door
10 Nm (7.4 lbs-ft)
  • Torx T30 socket
 Reuse

Remove

  1. Remove the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
  2. Remove the LH front door puddle light. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  3. Remove the LH front door reflector. See Reflector - Door - Front - LH (Remove and Replace).
  4. Remove the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  5. Connect the window switch tool to the LH front door harness and fully raise the front LH door window.
  6. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  7. Disconnect the LV power. See LV Power (Disconnect and Connect) (Modify).
  8. Remove the LH front door closeout panel. See Closeout Panel - Door - Front - LH (Remove and Replace).
    Note
    No need to remove the LH front door pressure sensor from the LH front door closeout panel.
  9. Remove the bolts (x3) that attach the LH front door latch to the rear of the LH front door.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T30 socket
  10. Disconnect the electrical harness from the LH front door latch connector.
  11. Press the latch cable grommet in through the door, and move the cable in through the opening while simultaneously removing the latch from the door.

Install

  1. Feed the latch cable through the opening, and then install the grommet.
  2. Install the bolts (x3) that attach the LH front door latch to the rear of the LH front door.
    10 Nm (7.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T30 socket
  3. Connect the electrical harness to the LH front door latch connector.
  4. Install the LH front door closeout panel. See Closeout Panel - Door - Front - LH (Remove and Replace).
    Note
    No need to install the LH front door pressure sensor to the LH front door closeout panel.
  5. Connect the LV power. See LV Power (Disconnect and Connect) (Modify).
  6. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  7. Fully lower the LH front door window and disconnect the window switch tool from the LH front door harness.
  8. Install the LH front door puddle light. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  9. Install the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  10. Install the LH front door reflector. See Reflector - Door - Front - LH (Remove and Replace).
  11. Install the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
