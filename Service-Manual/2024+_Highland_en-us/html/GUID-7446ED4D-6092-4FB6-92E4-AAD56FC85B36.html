Sensor - Pressure - Door - Front - LH (Remove and Replace)

Correction code 2020010042 FRT 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 2020 - Sensors

Remove

  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Disconnect the LV power. See LV Power (Disconnect and Connect) (Modify).
  3. Remove the LH front door reflector. See Reflector - Door - Front - LH (Remove and Replace).
  4. Remove the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
  5. Remove the LH front door puddle light. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  6. Remove the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  7. Release the connector lock, and then disconnect the LH front door pressure sensor electrical connector.
  8. Twist the tabs counterclockwise and remove the LH front door pressure sensor from the closeout panel.

Install

  1. Position a new LH front door pressure sensor onto the closeout panel, and then twist the tabs clockwise to secure it to the panel.
    Note
    Verify the sensor is locked in place.
  2. Connect the LH front door pressure sensor electrical connector, and then engage the locking tab.
  3. Install the LH front door puddle light. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  4. Install the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  5. Install the LH front door reflector. See Reflector - Door - Front - LH (Remove and Replace).
  6. Install the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
  7. Connect the LV power. See LV Power (Disconnect and Connect) (Modify).
  8. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
