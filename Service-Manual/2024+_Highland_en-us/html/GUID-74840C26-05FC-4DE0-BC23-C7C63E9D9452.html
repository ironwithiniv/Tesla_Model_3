Closeout - Armrest - 2nd Row (Remove and Replace)

Correction code 1305020012 FRT 0.36 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1305 - 2nd Row Seat Assemblies and Hardware

Remove

  1. Remove the 2nd row LH seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  2. Remove the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  3. Remove the 2nd row LH seat back. See Seatback - 2nd Row - LH (Remove and Replace).
  4. Turn over the 2nd row LH seat back assembly and then unzip the seat back trim cover.
  5. Pull the clip strips of the seat back trim cover away from the seat frame to release the clip strips and then lift the seat back trim cover to uncover the frame.
  6. Unfold the center armrest from the 2nd row LH seat back assembly.
  7. Release the clips (x2) on the back of the armrest closeout panel first, and then pull the panel outward to release other clips and lower tabs (x2) and finally lift up the panel to remove it from the LH seat frame.
    Note
    Using a plastic trim tool is recommended. Replace the clips if they are damaged during removal.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.

Install

  1. Slide the 2nd row armrest closeout panel down first to engage the lower tabs (x2) to the seat frame, then press the panel inwards to secure all other clips.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
    Note
    Ensure that all clips are not damaged and installed in place.
  2. Fold the 2nd row armrest back.
  3. Install the rear trim cover to the seat back.
    Note
    Engage the clip strips of the seat back trim cover to the seat frame.
  4. Zip the seat back trim cover.
  5. Install the 2nd row LH seat back. See Seatback - 2nd Row - LH (Remove and Replace).
  6. Install the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  7. Install the 2nd row LH seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
