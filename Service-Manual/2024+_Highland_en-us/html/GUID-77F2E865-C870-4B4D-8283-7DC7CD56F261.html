Handle - Seat Back - 2nd Row - LH (Remove and Replace)

Correction code 1305020082 FRT 0.66 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1305 - 2nd Row Seat Assemblies and Hardware

Remove

  1. Remove the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  2. Remove the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  3. Remove the 2nd row LH seat back hinge bracket. See Bracket - Hinge - Seat Back - 2nd Row (Remove and Replace).
  4. Remove the 2nd row LH seat back handle bezel. See Bezel - Handle - Seat Back - 2nd Row - LH (Remove and Replace).
  5. Remove the 2nd row LH seat back center escutcheon. See Escutcheon - Seat Belt - Center (Remove and Replace).
  6. Remove the center armrest assembly. See Armrest - 2nd Row (Remove and Replace).
  7. Remove the 2nd row LH seat back trim and foam assembly. See Trim - Seat Back - 2nd Row - LH (Remove and Replace).
  8. Remove the 2nd row center seat back escutcheon support. See Support - Escutcheon - Seat Belt - Center (Remove and Replace)
  9. Remove the 2nd row LH seat back handle assembly cable from the seat back latch bracket assembly with a clip prytool.
    Note
    Release the clips that attach the handle assembly cable to the seat back latch bracket in the sepuence and direction as the arrows show.
  10. Release the clip that attaches the handle cable to the seat frame, and then remove the 2nd row LH seat back handle assembly from the seat frame.

Install

  1. Secure the clip that attaches the 2nd row LH seat back handle assembly to the seat frame.
  2. Install the 2nd row LH seat back handle assembly to the seat frame.
    Note
    Install the clips that attach the handle assembly cable to the seat back latch bracket in the sepuence and direction as the arrows show.
  3. Remove the 2nd row center seat back escutcheon support. See Support - Escutcheon - Seat Belt - Center (Remove and Replace)
  4. Remove the 2nd row LH seat back trim and foam assembly. See Trim - Seat Back - 2nd Row - LH (Remove and Replace).
  5. Remove the center armrest assembly. See Armrest - 2nd Row (Remove and Replace).
  6. Remove the 2nd row LH seat back center escutcheon. See Escutcheon - Seat Belt - Center (Remove and Replace).
  7. Remove the 2nd row LH seat back handle bezel. See Bezel - Handle - Seat Back - 2nd Row - LH (Remove and Replace).
  8. Remove the 2nd row LH seat back hinge bracket. See Bracket - Hinge - Seat Back - 2nd Row (Remove and Replace).
  9. Remove the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  10. Remove the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
