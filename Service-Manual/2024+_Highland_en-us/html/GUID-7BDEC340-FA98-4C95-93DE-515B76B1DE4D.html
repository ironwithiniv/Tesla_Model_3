Handle - Exterior Release - Door - Front - LH (Recalibrate)

Correction code 11451300 0.50 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
The side impact airbag deployment depends on the front door sensor's ability to detect a side impact from air pressure. Make sure that there are no uncovered holes in the front door shells. Additionally, always reinstall plugs or tape when servicing or inspecting the front doors and their components.
Parent topic: 1145 - Exterior Door Handles

Procedure

  1. Use the gap and flush tool to check the gap and flush of the handle to the door surface.
    • Gap: 1mm +1.5/-0.0mm
    • Flush: 0.5mm +2.5/-0.5mm
    Note
    Perform this procedure only when the gap or flush is outside of specification.
  2. Remove the LH front door reflector. See Reflector - Door - Front - LH (Remove and Replace).
  3. Remove the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
  4. Remove the LH front door puddle light. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  5. Remove the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  6. Remove the LH front door outer belt seal. See Seal - Outer Belt - Front Door - LH (Remove and Replace).
  7. Remove the LH front door glass. See Glass - Door - Front - LH (Remove and Replace).
  8. Disconnect the LV power. See LV Power (Disconnect and Connect) (Modify).
  9. Remove the LH front door closeout panel. See Closeout Panel - Door - Front - LH (Remove and Replace).
  10. Remove the LH front exterior door handle. See Handle - Exterior Release - Door - Front - LH (Remove and Replace).
  11. Exercise the handle mechanism, pulling the handle to the maximum position and releasing it, 5 times.
  12. If the handle binds or slows down during the exercise, replace the handle.
  13. Remove the shims from the handle, noting which shims are for which mounting hole.
  14. Enlarge the handle mounting holes (x3) to 10mm diameter.
    Note
    The shims might need to be enlarged as well.
  15. Remove the temporary setting feature tab from the handle.
  16. Return the shims to the handle.
    Note
    Use grease to temporarily hold the shims in place on the handle.
  17. Hand tighten the nuts (x3) that attach the exterior door handle to the door panel.
  18. Use the gap and flush tool to check the gap and flush of the handle to the door surface.
    • Gap: 1mm +1.5/-0.0mm
    • Flush: 0.5mm +2.5/-0.5mm
  19. Insert shims between the handle and door inside surface at the handle mounting studs to adjust the gap and flush of the handle, if necessary.
    Note
    Do not stack any more than two shims per mounting stud.
  20. When the gap and flush are within specification, tighten the nuts that attach the handle to the door.
    7 Nm (5.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  21. Exercise the handle mechanism, pulling the handle to the maximum position and releasing it, 5 times.
  22. If the handle binds or slows down during the exercise, replace the handle.
  23. Install the plugs (x2) that cover access to the door handle nuts.
  24. Connect the electrical connector to the exterior door handle.
  25. Install the LH front door closeout panel. See Closeout Panel - Door - Front - LH (Remove and Replace).
  26. Connect the LV power. See LV Power (Disconnect and Connect) (Modify).
  27. Install the front LH door glass. See Glass - Door - Front - LH (Remove and Replace).
  28. Install the LH front door outer belt seal. See Seal - Outer Belt - Front Door - LH (Remove and Replace).
  29. Install the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  30. Install the LH front door puddle light. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  31. Install the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
  32. Install the LH front door reflector. See Reflector - Door - Front - LH (Remove and Replace).
  33. Unlock the vehicle gateway. See Gateway Unlock.
  34. On the touchscreen, touch Controls > Service Mode > Windows > Calibrate Windows, then select Start to calibrate the window.
  35. Disable Service Mode. See Disable Service Mode.
