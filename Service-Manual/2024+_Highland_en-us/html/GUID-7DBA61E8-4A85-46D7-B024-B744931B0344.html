Door - Front - LH (Remove and Replace)

Correction code 1010025022 FRT 1.26 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-07-22: Removed the step to pull the secondary seal away from the door.
  • 2024-01-24: Added a note in case that the shouldered / tapered bolts are not allowing for successful adjustment.
  • 2023-12-11: Updated correction code.
Equipment:

  • 1079485-00-A 3/8in Crowfoot Open End Set

Parent topic: 1010 - Body Panels

Remove

  1. Open the LH front door and lower the LH front window.
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Remove the LH door trim panel. See Panel - Door Trim - Front - LH (Remove and Install).
  4. Remove the LH front door outer belt assembly. See Seal - Outer Belt - Front Door - LH (Remove and Replace).
  5. Remove the LH front door inner belt seal. See Seal - Inner Belt - Front Door - LH (Remove and Replace).
  6. Connect a window switch special tool (1454796-00-A) to the LH front door harness.
  7. Remove the LH door glass. See Glass - Door - Front - LH (Remove and Replace).
  8. Manually engage the LH front door latch.
  9. Disconnect the window switch special tool.
  10. Disconnect the LV battery power. See LV Power (Disconnect and Connect) (Modify).
  11. Remove the LH front exterior mirror assembly. See Mirror - Door - LH (Remove and Replace).
  12. Remove the LH front glass run seal. See Seal - Glass Run - Front Door - LH (Remove and Replace).
  13. Remove the LH front door closeout panel. See Closeout Panel - Door - Front - LH (Remove and Replace).
  14. Remove the LH front door window regulator. See Window Motor / Regulator Assembly - Front - LH (Remove and Replace).
  15. Remove the LH front door latch. See Latch - Door - Front - LH (Remove and Replace).
  16. Remove the LH front outer door handle. See Handle - Exterior Release - Door - Front - LH (Remove and Replace).
  17. Remove the LH front door check strap. See Check Strap - Door - Front - LH (Remove and Replace).
  18. Use a clip prytool to release the clips (x9) that secure the LH front door electrical harness.
  19. Remove the LH front door harness from the side of the door assembly.
  20. Apply tape to the LH front fender.
  21. Remove the lower bolts (x2) that attach the hinges to the LH front door, and then loosen the upper bolts (x2) that attaches the hinges to the door.
    Tip
    Use of the following tool(s) is recommended:
    • 10mm 12pt combination wrench
  22. With assistance, lift the LH front door up and remove it from the vehicle.

Replace

CAUTION
If using this procedure to install an unpainted part, make sure to apply seam sealer to all seams prior to installing and painting the part. Refer to the Collision Repair manual for more information.
  1. Manually install the upper bolts (x2) that attach the hinges to the LH front door for easy installation.
  2. With assistance, install the LH front door assembly onto the vehicle.
    Note
    Align the bolts to their installation position.
  3. Hand-tighten the bolts (x4) that attach the hinges to the LH front door.
    Note
    Align the hinge with the previously applied tape on the door.
    Tip
    Use of the following tool(s) is recommended:
    • 10mm 12pt combination wrench
  4. Route the LH front door harness through the hole on the door assembly, then install the harness sealing plug properly.
  5. Install the clips (x9) that secure the LH front door electrical harness.
  6. Install the LH front door check strap. See Check Strap - Door - Front - LH (Remove and Replace).
  7. Install the LH front outer door handle. See Handle - Exterior Release - Door - Front - LH (Remove and Replace).
  8. Install the LH front door latch. See Latch - Door - Front - LH (Remove and Replace).
  9. Install the LH front door window regulator. See Window Motor / Regulator Assembly - Front - LH (Remove and Replace).
  10. Install the LH front door closeout panel. See Closeout Panel - Door - Front - LH (Remove and Replace).
  11. Install the LH front glass run seal. See Seal - Glass Run - Front Door - LH (Remove and Replace).
  12. Install the LH front exterior mirror assembly. See Mirror - Door - LH (Remove and Replace).
  13. Install the LH door glass. See Glass - Door - Front - LH (Remove and Replace).
  14. Install the LH front door outer belt assembly. See Seal - Outer Belt - Front Door - LH (Remove and Replace).
  15. Install the LH front door inner belt seal. See Seal - Inner Belt - Front Door - LH (Remove and Replace).
  16. Connect the LV battery power. See LV Power (Disconnect and Connect) (Modify).
  17. Release the LH front door latch.
  18. Close the LH front door and check the gap and flushness.
    Note
    If the shouldered / tapered bolts are not allowing for successful adjustment, replace the selected shouldered / tapered bolts with 1063260-00-C. Adjust the LH front door, if necessary. Refer to CVIS for current specifications.
  19. Torque the bolts (x4) that attach the hinges to the LH front door.
    27 Nm (19.9 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Flex head ratchet/flex head torque wrench
    • 3/8in Crowfoot Open End Set - 1079485-00-A
  20. Remove tape from the LH front fender.
  21. Release the clips (x3) that attach the LH inner belt seal and glass run seal to the LH front door panel to fully access the area where the secondary seal will be installed.
  22. Use IPA wipes to clean the area where the secondary seal will be installed, and allow 1 minute for the IPA to dry.
  23. Peel back the adhesive backing at the ends of the seal, and position the seal onto the door.
    Note
    Ensure the drain holes of the seal are at the bottom of the door. Ensure both edges are under the cut outs for the inner belt and the glass run seal. Ensure the open edge of the seal is facing the inside of the door.
  24. Install new secondary LH front door seal by firmly pressing the seal into place, removing the film from the double sided tape.
    Note
    Ensure the seal is even all the way around the edge of the door. Ensure the door seal follows the contour of the door, Ensure the open edge of the seal is facing the inside of the door.
  25. Secure the clips (x3) that attach the LH inner belt seal and glass run seal to the LH front door assembly.
  26. Install the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Install).
  27. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  28. Calibrate the window. See Window Regulator (Recalibrate) (Maintenance).
  29. Raise the LH front window and close the LH front door.
