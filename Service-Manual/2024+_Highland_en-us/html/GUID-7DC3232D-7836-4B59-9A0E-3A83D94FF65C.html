Trim - Seat Back - 2nd Row - RH (Remove and Replace)

Correction code 1308010062 FRT 0.58 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1501599-00-A, Pliers, Hog Ring
Parent topic: 1308 - 2nd Row Seat Covers Pads and Trims

Remove

  1. Remove the RH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  2. Remove the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  3. Remove the RH 2nd row seat back. See Seatback - 2nd Row - RH (Remove and Replace).
  4. Remove the RH 2nd row seat back hinge bracket. See Bracket - Hinge - Seat Back - 2nd Row (Remove and Replace).
  5. Remove the RH 2nd row escutcheon. See Escutcheon - Seat Belt - Center (Remove and Replace).
    Note
    There are 2 clips in the RH 2nd row escutcheon.
  6. Remove the RH 2nd row seat back latch release bezel. See Bezel - Handle - Seat Back - 2nd Row - RH (Remove and Replace).
  7. Unzip the RH 2nd row seat back upholstery cover.
  8. Put the electrical harness through the RH 2nd row seat back upholstery cover.
  9. Release the lower portion of the RH 2nd row seat back upholstery cover from the pivot bar.
  10. Gently separate the RH seat back upholstery cover from the foam starting from the bottom of the cover.
    Note
    Make sure the Velcro does not damage the foam pad.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  11. Use diagonal cutters to cut the hog rings (x3) at the center of the seat back, and then release the cover from the hog rings.
    Note
    Push down on the foam to allow access to the rings.
    Note
    Remove any excess hog ring pieces.
  12. Gently release the remaining Velcro that attach the RH 2nd row seat back upholstery cover to the foam pad.
    Note
    Make sure the Velcro does not damage the foam pad.
  13. Remove the RH 2nd row cover from the foam pad.
    Note
    Carefully clear seat release bezel.

Install

  1. Starting from the RH 2nd row headrest, install the RH 2nd row seat back upholstery cover.
    Note
    Massage the Velcro while working downward toward the center of the seat back.
  2. Use hog ring pliers to crimp new hog rings (1566544-00-A x3) to the RH 2nd row seat back upholstery trim cover at the center of the seat back.
    Note
    Place the hog ring into the hog ring pliers prior to installation.
    Note
    Push down on the foam to allow access to the rings.
  3. Attach the remaining portion of the RH 2nd row seat back upholstery cover to the seat back.
    Note
    Massage the Velcro while working downward toward the bottom of the seat back.
  4. Install the lower portion of the RH seat back upholstery cover to the pivot bar.
  5. Put the electrical harness through the RH seat back upholstery cover.
  6. Zip the RH 2nd row seat back cover.
  7. Install the RH 2nd row seat back latch release bezel. See Bezel - Handle - Seat Back - 2nd Row - RH (Remove and Replace).
  8. Install the RH 2nd row escutcheon. See Escutcheon - Seat Belt - Center (Remove and Replace).
    Note
    There are 2 clips in the RH 2nd row escutcheon.
  9. Install the RH 2nd row seat back hinge bracket. See Bracket - Hinge - Seat Back - 2nd Row (Remove and Replace).
  10. Install the RH 2nd row seat back. See Seatback - 2nd Row - RH (Remove and Replace).
  11. Install the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  12. Install the RH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
