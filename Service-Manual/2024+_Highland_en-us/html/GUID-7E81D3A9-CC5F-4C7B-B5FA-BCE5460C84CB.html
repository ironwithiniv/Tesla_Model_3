Seal - Check Strap - Door - Front (Remove and Replace)

Correction code 1133010032 FRT 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1133 - Closure Assist Mechanisms and Hinges

Torque Specifications

Table 1. Torque Specifications: Seal - Check Strap - Door - Front (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolt that attaches the LH front door check strap to the vehicle
24 Nm (17.7 lbs-ft)
  • 13 mm socket
 Reuse
Nuts (x2) that attach the LH front door check strap to the door assembly
10 Nm (7.4 lbs-ft)
  • 10 mm deep socket
 Reuse

Remove

  1. Open the LH front door and lower the LH front window.
  2. Remove the bolt that attaches the LH front door check strap to the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  3. Release the clips (x3) that attach the check strap seal to the vehicle with a plastic trim tool.
  4. Remove the nuts (x2) that secure the LH front door check strap to the LH front door assembly.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  5. Move the LH front door check strap inward and remove the LH front door check strap seal.

Install

  1. Install the LH front door check belt seal.
  2. Install the nuts (x2) that secure the LH front door check strap to the LH front door assembly.
    10 Nm (7.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  3. Install the clips (x3) that attach the check strap seal to the vehicle.
  4. Install the bolt that attaches the LH front door check strap to the vehicle.
    24 Nm (17.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  5. Raise the LH front window and close the LH front door.
