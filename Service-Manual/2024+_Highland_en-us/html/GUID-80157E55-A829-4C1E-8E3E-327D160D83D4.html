Gap Hider - Steering Column - Upper (Remove and Replace)

Correction code 3205010092 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-09-24: Removed the steps to remove/install the steering column control module; changed the recommended tool for the upper gap hider screws (steering column) from T20 to T25.
Parent topic: 3205 - Upper Column, Steering Wheel

Torque Specifications

Table 1. Torque Specifications: Gap Hider - Steering Column - Upper (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Screws (x2) that attach the upper gap hider to the steering column
1.2 Nm (.9 lbs-ft)
  • Ratchet/torque wrench
  • Torx T25 socket
  • 6 in locking extension
 Reuse
Nuts (x2) that attach the upper gap hider to the cross car beam
15 Nm (11.1 lbs-ft)
  • Ratchet/torque wrench
  • 3 in extension
  • 13 mm socket
  • Cordless Ratchet/Impact Driver
 Reuse

Remove

  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Disconnect the LV power. See LV Power (Disconnect and Connect) (Modify).
  3. Remove the driver airbag. See Airbag - Driver (Remove and Replace).
  4. Remove the steering wheel. See Steering Wheel (Remove and Replace).
  5. Remove the steering column upper shroud. See Shroud - Upper - Steering Column (Remove and Replace).
  6. Remove the steering column lower shroud. See Shroud - Lower - Steering Column (Remove and Replace).
  7. Remove the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  8. Remove the driver footwell cover. See Cover - Footwell - Driver (Remove and Replace).
  9. Remove the lower instrument panel. See Assembly - Instrument Panel - Lower (Remove and Replace).
  10. Remove the lower gap hider. See Gap Hider - Steering Column - Lower (Remove and Replace).
  11. Remove the screws (x2) that attach the upper gap hider to the steering column.
    Tip
    Use of the following tool(s) is recommended:
    • Ratchet/torque wrench
    • Torx T25 socket
    • 6 in locking extension
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  12. Remove the nuts (x2) that attach the upper gap hider to the cross car beam.
    Tip
    Use of the following tool(s) is recommended:
    • Ratchet/torque wrench
    • 3 in extension
    • 13 mm socket
    • Cordless Ratchet/Impact Driver

Install

  1. Install the nuts (x2) that attach the upper gap hider to the cross car beam.
    15 Nm (11.1 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Ratchet/torque wrench
    • 3 in extension
    • 13 mm socket
    • Cordless Ratchet/Impact Driver
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  2. Install the screws (x2) that attach the lower gap hider to the steering column.
    1.2 Nm (.9 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Ratchet/torque wrench
    • Torx T25 socket
    • 6 in locking extension
  3. Install the lower gap hider. See Gap Hider - Steering Column - Lower (Remove and Replace).
  4. Install the lower instrument panel. See Assembly - Instrument Panel - Lower (Remove and Replace).
  5. Install the driver footwell cover. See Cover - Footwell - Driver (Remove and Replace).
  6. Install the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  7. Install the steering column lower shroud. See Shroud - Lower - Steering Column (Remove and Replace).
  8. Install the steering column upper shroud. See Shroud - Upper - Steering Column (Remove and Replace).
  9. Install the steering wheel. See Steering Wheel (Remove and Replace).
  10. Install the driver airbag. See Airbag - Driver (Remove and Replace).
  11. Connect the LV power. See LV Power (Disconnect and Connect) (Modify).
  12. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
