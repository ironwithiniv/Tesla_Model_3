Ancillary Bay Coolant (Drain and Refill) (Test/Adjust)

Correction code 16202000 FRT 0.84 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1053600-00-D Drive Unit Pressure Test Fixture
  • 1135762-00-A Coolant Hose Plug Kit
  • 1065131-00-A Battery Coolant Drain Kit
  • 1080568-00-A Fluid Catcher
Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
Parent topic: 1620 - HV Battery Cooling System

Procedure

  1. Place the vehicle on the 2-post lift.
    Tip
    Ensure the vehicle is not charging.
  2. Open all doors and lower all windows.
  3. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  4. Place the vehicle in Service Mode by using the touchscreen. See Service Mode.
  5. Unlock the vehicle gateway. See Gateway Unlock.
  6. Run Thermal Fill Drain (Coolant Only) through the UI: go to Thermal > Coolant System > Coolant Fill/Drain, touch Run and close once the routine is completed.
    Note
    Thermal Fill Drain routine has a 5 hour time limit. If the run time exceeds 5 hours, the routine must be performed again.
  7. Disconnect the LV battery power. See LV Power (Disconnect and Connect) (Modify).
  8. Raise the vehicle fully and lower lift onto locks.
    CAUTION

    Make sure there is an audible click of the locks on both sides before lowering, otherwise the vehicle may tilt to one side.

    Make sure that the doors are clear of surrounding objects.

  9. Remove the rear aero shield panel. See Panel - Aero Shield - Rear (Remove and Replace).
  10. Remove the rear skid plate from the vehicle. See Skid Plate - HV Battery - Rear (Remove and Replace).
  11. Perform the ancillary bay coolant leak test. See Ancillary Bay Coolant Leak Test (Inspection).
    Note
    Return to this procedure after disconnecting the coolant drain and fill adapter from the PCS inlet hose coupling.
  12. Position the coolant drain container underneath RH rear of vehicle.
  13. Connect rear powertrain supply hose to the PCS inlet hose coupling.
    Note
    Remove the plug, and perform push-pull-push test to make sure hose is fully seated.
  14. Disconnect the coolant leak test fixture outlet hose from the leak test adapter.
  15. Disconnect the coolant leak test adapter from the PCS outlet hose coupling.
    Note
    1x spring clip
  16. Position coolant drain container underneath LH rear of the vehicle.
  17. Connect the RDU inverter inlet tube to PCS outlet hose coupling.
    Note
    Remove plugs and perform push-pull-push test to make sure hose is fully engaged.
  18. Remove the coolant drain container from underneath vehicle.
  19. Install the rear skid plate from the vehicle. See Skid Plate - HV Battery - Rear (Remove and Replace).
  20. Perform the cooling system vacuum refill. See Cooling System - Vacuum Refill (Test/Adjust).
  21. Exit Service Mode. See Service Mode.
  22. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  23. Raise all windows and close all doors.
  24. Remove the lift arms from below the vehicle.
