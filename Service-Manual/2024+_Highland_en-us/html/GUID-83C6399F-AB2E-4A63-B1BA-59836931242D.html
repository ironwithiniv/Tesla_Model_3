Actuator - Upper - HVAC (Remove and Replace)

Correction code 1810010102 FRT 0.36 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-10-08: Added the HVAC Case Test routine.
Parent topic: 1810 - Cabin HVAC

Torque Specifications

Table 1. Torque Specifications: Actuator - Upper - HVAC (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x2) that attach the upper mode actuator to the HVAC assembly
1.2 Nm (.9 lbs-ft)
  • Torx T20 socket
Reuse

Remove

  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Disconnect the LV power. See LV Power (Disconnect and Connect) (Modify).
  3. Remove the RH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  4. Remove the passenger footwell cover. See Cover - Footwell - Front Passenger (Remove and Replace).
  5. Remove the glove box. See Glove Box (Remove and Replace).
    Note
    No need to remove the glove box USB cable.
  6. Remove the RH footwell duct. See Duct - Footwell - RH (Remove and Replace).
  7. Disconnect the RH airwave duct thermistor connector.
  8. Remove the RH air wave duct. See Duct - Air Wave - RH (Remove and Replace).
  9. Release the clip that attaches the instrument panel harness to the RH side of the HVAC assembly.
  10. Disconnect the electrical connector from the upper mode actuator.
  11. Remove the bolts (x2) and dowel pin that attach the upper mode actuator to the HVAC assembly, and then remove the upper mode actuator.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket

Install

  1. Position the upper mode actuator onto the HVAC assembly; align the dowel pin and push the actuator to install.
  2. Install the bolts (x2) that attach the upper mode actuator to the HVAC assembly.
    1.2 Nm (.9 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  3. Connect the electrical connector to the upper mode actuator.
  4. Fasten the clip that attaches the instrument panel harness to the RH side of the HVAC assembly.
  5. Install the RH air wave duct. See Duct - Air Wave - RH (Remove and Replace).
  6. Connect the RH airwave duct thermistor connector.
  7. Install the RH footwell duct. See Duct - Footwell - RH (Remove and Replace).
  8. Install the glove box. See Glove Box (Remove and Replace).
    Note
    No need to install the glove box USB cable.
  9. Install the passenger footwell cover. See Cover - Footwell - Front Passenger (Remove and Replace).
  10. Install the RH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  11. Connect LV power. See LV Power (Disconnect and Connect) (Modify).
  12. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  13. Connect a laptop with Toolbox to the vehicle. SeeToolbox (Connect and Disconnect).
  14. Perform the following routine: TEST-SELF_VCRIGHT_X_HVAC-CASE-ACTUATORSvia Toolbox:(link)
  15. Remove the laptop from the vehicle and exit the service mode.
  16. Raise the LH front window and close the LH front door.
