Projections Cover - Seat Back - 2nd Row (Remove and Replace)

Correction code 1305020112 FRT 0.36 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1305 - 2nd Row Seat Assemblies and Hardware

Remove

  1. Remove the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  2. Remove the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  3. Remove the LH 2nd row seat back. See Seatback - 2nd Row - LH (Remove and Replace).
  4. Remove the seat back hinge bracket. See Bracket - Hinge - Seat Back - 2nd Row (Remove and Replace).
  5. Unzip the 2nd row seat back trim cover and separate it from the seat back frame.
  6. Remove the 2nd row seat back projections cover from the seat back frame.

Install

  1. Install the 2nd row seat back projections cover to the seat back frame.
  2. Install the 2nd row seat back trim cover to the seat back frame and zip it up.
  3. Install the seat back hinge bracket. See Bracket - Hinge - Seat Back - 2nd Row (Remove and Replace).
  4. Install the LH 2nd row seat back. See Seatback - 2nd Row - LH (Remove and Replace).
  5. Install the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  6. Install the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
