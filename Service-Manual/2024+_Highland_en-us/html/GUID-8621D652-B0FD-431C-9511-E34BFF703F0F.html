Touchscreen - Rear (Remove and Replace)

Torque Specifications

Table 1. Torque Specifications: Touchscreen - Rear (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x5) that attach the rear display to the rear end module
1 Nm (.7 lbs-ft)
  • Torx T20 bit
 Replace 1096312-00-C

Remove

  1. Remove the rear end module assembly. See Module - Rear End - Center Console (Remove and Install)
    Note
    No need to remove the rear end module from the assembly.
  2. Remove and discard the bolts (x5) that attach the rear display to the rear end module assembly, and then remove the rear display from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 bit

Replace

  1. Install new bolts (x5) that attach the rear display to the rear end module.
    1 Nm (.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 bit
  2. Install the rear end module assembly. See Module - Rear End - Center Console (Remove and Install)
  3. Locally connect a laptop with Toolbox 3 to the vehicle. See Toolbox (Connect and Disconnect).
  4. On the laptop, click the Actions tab, type "PING-BASH_DISPLAY" into the search field, click PING-BASH_DISPLAYvia Toolbox:(link), select rear in the Poppyseed Display Test Arg field, change the timeout to 20, click Run, and allow the routine to complete.
  5. Disconnect the laptop.
  6. Reinstall the firmware. See Software Reinstall - Touchscreen.
