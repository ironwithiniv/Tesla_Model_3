OBD Connector (Retrofit) (Retrofit)

Correction code 00050300 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • Tools Required:
    • 1115191-00-A - Pick Miniature Soft Grip 90 degree tip 6in
    • 1706381-00-A - Cordless Heat Gun
    • 1061177-00-C - KIT, WIRE HARNESS REPAIR
    • 1944989-00-A - Depinning Tool 45 degrees
Parent topic: 0005 - Service Modes

Rework

  1. Disconnect the LV battery and First Responder Loop. See LV Power (Disconnect and Connect) (Modify).
  2. Remove the LH footwell cover. See Cover - Footwell - Driver (Remove and Replace).
  3. Remove Pin 3 (violet) wire terminal from OBD connector.
  4. Remove Pin 11 (white) wire terminal from OBD connector.
  5. Install heat shrink onto pin 3 and 11 wire terminals.
  6. Apply tape to secure pin 3 and 11 reworked wire terminals onto OBD wire harness bundle.
  7. Install the LH footwell cover. See Cover - Footwell - Driver (Remove and Replace).
  8. Connect the LV battery and First Responder Loop. See LV Power (Disconnect and Connect) (Modify).
