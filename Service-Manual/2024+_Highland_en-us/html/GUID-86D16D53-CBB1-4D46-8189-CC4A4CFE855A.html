Striker - Seat Back - 2nd Row (Remove and Replace)

Correction code 1305020022 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1305 - 2nd Row Seat Assemblies and Hardware

Torque Specifications

Table 1. Torque Specifications: Striker - Seat Back - 2nd Row (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x2) that attach the seat back striker to the vehicle
16 Nm (11.8 lbs-ft)
  • Torx T40 socket
 Replace

Remove

  1. Open all four doors and lower all four windows.
    Note
    If the vehicle is being powered down, latch rear doors to prevent accidental closure.
  2. Move the LH and RH front seats forward.
  3. Remove the LH side rail trim. See Trim - Side Rail - LH (Remove and Replace).
  4. Remove the LH and RH 2nd row seat side bolsters. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  5. Remove the LH upper C-pillar trim. See Trim - C-Pillar - LH (Remove and Replace).
  6. Remove the RH side rail trim. See Trim - Side Rail - LH (Remove and Replace).
  7. Remove the RH upper C-pillar trim. See Trim - C-Pillar - LH (Remove and Replace).
  8. Release the clips (x5) that attach the front of the package tray to the body.
  9. Pull the package tray forward, and then lift up the package tray to access the seat back striker.
    Note
    Support the package tray in the raised position.
  10. Remove the bolts (x2) that attach the seat back striker to the body, and then remove the striker from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T40 socket

Install

  1. Install the bolts (x2) that attach the seat back striker to the body.
    16 Nm (11.8 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T40 socket
  2. Install the the clips (x5) that attach the front of the package tray to the body.
  3. Install the RH upper C-pillar trim. See Trim - C-Pillar - LH (Remove and Replace).
  4. Install the RH side rail trim. See Trim - Side Rail - LH (Remove and Replace).
  5. Install the LH upper C-pillar trim. See Trim - C-Pillar - LH (Remove and Replace).
  6. Install the LH and RH 2nd row seat side bolsters. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  7. Install the LH side rail trim. See Trim - Side Rail - LH (Remove and Replace).
  8. Move the LH and RH front seats to original position.
  9. Raise all four windows and close all four doors.
