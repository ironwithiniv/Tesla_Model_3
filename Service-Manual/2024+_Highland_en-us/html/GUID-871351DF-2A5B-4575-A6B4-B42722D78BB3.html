Latch - Door - Rear - LH (Remove and Replace)

Correction code 1133060022 FRT 0.66 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1133 - Closure Assist Mechanisms and Hinges

Torque Specifications

Table 1. Torque Specifications: Latch - Door - Rear - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x3) that attach the LH rear door latch to the rear of the LH rear door
10 Nm (7.4 lbs-ft)
  • Torx T30 socket
 Reuse

Remove

  1. Open the LH front door and lower the LH front window.
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Remove the LH rear door puddle light. See Puddle Lamp - Rear Door (Remove and Replace).
  4. Remove the LH rear door trim panel. See Panel - Door Trim - Rear - LH (Remove and Replace).
  5. Remove the LH rear door glass. See Glass - Door - Rear - LH (Remove and Replace).
  6. Disconnect LV power. See LV Power (Disconnect and Connect) (Modify).
  7. Remove the LH rear window regulator assembly. See Window Motor / Regulator Assembly - Rear - LH (Remove and Replace).
  8. Disconnect the LH rear door electrical harness from the LH rear door latch connector.
  9. Remove the bolts (x3) that attach the LH rear door latch to the rear of the LH rear door.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T30 socket
  10. Press the LH rear door latch cable grommet in through the LH rear door bulkhead, and move the latch cable in through the door opening while simultaneously remove the latch from the door.

Install

  1. Feed the latch cable through the opening, and then install the grommet.
  2. Feed the LH rear door latch through the LH rear door, and then install the latch cable grommet.
  3. Install and hand-tighten the bolts (x3) that attach the LH rear door latch to the rear of the LH rear door.
  4. Connect the LH rear door electrical harness to the LH rear door latch connector.
  5. Adjust LH rear door gap and flush at the LH rear door striker.
  6. Tighten the bolts (x3) that attach the LH rear door latch to the rear of the LH rear door.
    10 Nm (7.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T30 socket
  7. Install the LH rear window regulator assembly. See Window Motor / Regulator Assembly - Rear - LH (Remove and Replace).
  8. Connect LV power. See LV Power (Disconnect and Connect) (Modify).
  9. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  10. Install the LH rear door glass. See Glass - Door - Front - LH (Remove and Replace).
  11. Install the LH rear door puddle light. See Puddle Lamp - Rear Door (Remove and Replace).
  12. Install the LH rear door trim panel. See Panel - Door Trim - Rear - LH (Remove and Replace).
  13. Calibrate the window. See Window Regulator (Recalibrate) (Maintenance).
