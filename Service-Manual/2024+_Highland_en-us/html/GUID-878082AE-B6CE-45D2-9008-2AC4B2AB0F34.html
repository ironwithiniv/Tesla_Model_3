Retractor - Seatbelt - 2nd Row - Center (Remove and Replace)

Correction code 2005020022 FRT 0.66 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

CAUTION
Supplemental Restraint System (SRS) components can be hazardous if not serviced and handled correctly. See Airbag and Supplementary Restraint System (SRS) Precautions
CAUTION
In the event of an airbag or seatbelt pretensioner deployment, certain components must be replaced, and other components must be inspected for damage. Refer to the Collision Repair Manual for a specific list of items that must be inspected and replaced.
Parent topic: 2005 - Seatbelts

Torque Specifications

Table 1. Torque Specifications: Retractor - Seatbelt - 2nd Row - Center (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x2) that attach the 2nd row left seat back handle to the 2nd row seat frame
2 Nm (1.5 lbs-ft)
  • Cordless Ratchet/Impact Driver
  • Torx T25 socket
  • Ratchet/torque wrench
 Reuse
Bolt that attaches the 2nd row center seat belt to the 2nd row seat frame
45 Nm (33.2 lbs-ft)
  • Cordless Ratchet/Impact Driver
  • 13 mm socket
  • Flex head ratchet/flex head torque wrench
 Replace

Remove

  1. Remove the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  2. Remove the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  3. Remove the LH 2nd row seat back. See Seatback - 2nd Row - LH (Remove and Replace).
  4. Remove the LH 2nd row seat back hinge bracket. See Bracket - Hinge - Seat Back - 2nd Row (Remove and Replace).
  5. Remove the LH 2nd row seat back handle bezel. See Bezel - Handle - Seat Back - 2nd Row - LH (Remove and Replace).
  6. Remove the 2nd row center escutcheon. See Escutcheon - Seat Belt - Center (Remove and Replace).
  7. Remove the 2nd row armrest closeout. See Closeout - Armrest - 2nd Row (Remove and Replace).
  8. Remove the 2nd row armrest. See Armrest - 2nd Row (Remove and Replace).
  9. Remove the bolts (x2) that attach the 2nd row left seat back handle to the 2nd row seat frame.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • Torx T25 socket
    • Ratchet/torque wrench
  10. Remove the LH 2nd seat back assembly. See Trim - Seat Back - 2nd Row - LH (Remove and Replace).
  11. Remove the 2nd row center seat back escutcheon support. See Support - Escutcheon - Seat Belt - Center (Remove and Replace).
  12. Remove the 2nd row seat back projection cover. See Projections Cover - Seat Back - 2nd Row (Remove and Replace).
  13. Remove and discard the bolt that attaches the 2nd row center seat belt to the 2nd row seat frame.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 13 mm socket
    • Flex head ratchet/flex head torque wrench
  14. Release the tabs (x3) that attach the 2nd row center seat belt retractor to the 2nd row seat frame, and then remove the retractor from the seat frame.

Install

  1. Engage the tabs (x3) of the 2nd row center seat belt retractor onto the seat frame slots (x3).
  2. Install a new bolt that attaches the 2nd row center seat belt to the 2nd row seat frame.
    45 Nm (33.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 13 mm socket
    • Flex head ratchet/flex head torque wrench
  3. Install the 2nd row seat back projection cover. See Projections Cover - Seat Back - 2nd Row (Remove and Replace).
  4. Install the 2nd row center seat back escutcheon support. See Support - Escutcheon - Seat Belt - Center (Remove and Replace).
  5. Install the LH 2nd seat back assembly. See Trim - Seat Back - 2nd Row - LH (Remove and Replace).
  6. Install the bolts (x2) that attach the 2nd row left seat back handle to the 2nd row seat frame.
    2 Nm (1.5 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • Torx T25 socket
    • Ratchet/torque wrench
  7. Install the 2nd row armrest. See Armrest - 2nd Row (Remove and Replace).
  8. Install the 2nd row armrest closeout. See Closeout - Armrest - 2nd Row (Remove and Replace).
  9. Install the 2nd row center escutcheon. See Escutcheon - Seat Belt - Center (Remove and Replace).
  10. Install the LH 2nd row seat back handle bezel. See Bezel - Handle - Seat Back - 2nd Row - LH (Remove and Replace).
  11. Install the LH 2nd row seat back hinge bracket. See Bracket - Hinge - Seat Back - 2nd Row (Remove and Replace).
  12. Install the LH 2nd row seat back. See Seatback - 2nd Row - LH (Remove and Replace).
  13. Install the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  14. Install the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
