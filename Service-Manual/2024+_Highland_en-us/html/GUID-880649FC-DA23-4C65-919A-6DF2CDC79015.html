Hose - Return - Front Drive Unit Return (Remove and Replace)

Correction code 1830020102 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1080568-00-A Fluid Catcher
  • 1135762-00-A Kit, Svc Plug, Cooling Hose, Model 3
  • 1065131-00-A Battery Coolant Drain Kit
Parent topic: 1830 - Cooling System

Remove

  1. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Disconnect the LV power. See LV Power (Disconnect and Connect) (Modify).
  4. Remove the cabin intake duct. See Assembly - Fresh Air Gutter - HVAC (Remove and Replace).
  5. Remove the access panel. See Cover - Hood Latch (Remove and Replace).
  6. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  7. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  8. Position a fluid catcher underneath the front of vehicle.
  9. Release the spring clip, disconnect the front drive unit powertrain return hose from the supermanifold, and then immediately plug the hose and the supermanifold.
    Note
    Plug the hose as quickly as possible to minimize coolant loss.
    Note
    If the coolant loss is greater then 1L, vacuum fill will be required. See Cooling System - Vacuum Refill (Test/Adjust).
  10. Release the spring clip, disconnect the front drive unit powertrain return hose from the front drive unit heat exchanger, and then plug the hose and the heat exchanger.
  11. Remove the front drive unit powertrain return hose from the vehicle.

Install

  1. Remove the plug from the heat exchanger, immediately connect the front drive unit powertrain return hose to the heat exchanger, and then fasten the clip.
    Note
    Perform a push-pull-push test to make sure that the hose is secure.
  2. Remove the plug from the supermanifold, immediately connect the front drive unit powertrain return hose to the supermanifold, and then fasten the clip.
    Note
    Perform a push-pull-push test to make sure that the hose is secure.
  3. Remove the fluid catcher from underneath the front of the vehicle.
  4. Install the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  5. Connect LV power. See LV Power (Disconnect and Connect) (Modify).
  6. Perform the cooling system (partial refill and bleed) procedure. See Cooling System (Partial Refill and Bleed) (Modify).
  7. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  8. Install the access panel. See Cover - Hood Latch (Remove and Replace).
  9. Install the cabin intake duct. See Assembly - Fresh Air Gutter - HVAC (Remove and Replace).
  10. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  11. Remove the vehicle from the 2 post lift. See Raise Vehicle - 2 Post Lift.
