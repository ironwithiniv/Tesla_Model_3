Bracket - Hinge - Seat Back - 2nd Row (Remove and Replace)

Correction code 1305020042 FRT 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • Torque Wrench - 1143989-00-A
Parent topic: 1305 - 2nd Row Seat Assemblies and Hardware

Torque Specifications

Table 1. Torque Specifications: Bracket - Hinge - Seat Back - 2nd Row (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolt that attaches the seat back hinge bracket to the seat back
45 Nm (33.2 lbs-ft)
  • 13 mm socket
 Reuse

Remove

  1. Remove the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  2. Remove the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  3. Remove the LH 2nd row seat back. See Seatback - 2nd Row - LH (Remove and Replace).
  4. Use a clip prytool, release the clip that secures the seat heater connector to the hinge bracket.
  5. Remove the bolt securing the seat back hinge bracket and then remove the seat back hinge bracket from the seat back.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket

Install

  1. Install the bolt that secures the LH 2nd row seat back hinge bracket to the seat back.
    45 Nm (33.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  2. Install the clip that secures the seat heater connector to the hinge bracket.
  3. Install the LH 2nd row seat back. See Seatback - 2nd Row - LH (Remove and Replace).
  4. Install the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  5. Install the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
