Cover - Front Fascia Camera (Remove and Replace)

Correction code 10010100602 FRT 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1001 - Bumper / Fascia

Torque Specifications

Table 1. Torque Specifications: Cover - Front Fascia Camera (Remove and Replace) / Camera - Fascia - Front (Remove and Install)
Description Torque Value Recommended Tools Reuse/Replace Notes
Screws (x2) that attach the front fascia camera cover to the front fascia assembly
4 Nm (2.9 lbs-ft)
  • Torx T20 socket
Reuse
Screws (x2) that attach the front fascia camera to the cover
2 Nm (1.5 lbs-ft)
  • PH2 STUBBY PHILLIPS SCREWDRIVER
Reuse

Remove

  1. Remove the screws (x2) that attach the front fascia camera cover to the front fascia assembly.
    Note
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  2. Release the nano nozzle to disconnect the washer hose.
  3. Remove the screws (x2) that attach the front fascia camera to the cover, and then remove the cover from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • PH2 STUBBY PHILLIPS SCREWDRIVER

Install

  1. Install the screws (x2) that attach the front fascia camera to the cover.
    2 Nm (1.5 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • PH2 STUBBY PHILLIPS SCREWDRIVER
  2. Install the nano nozzle to connect the washer hose.
    Note
    Perform a pull-push-pull test to verify the hose is fully connected.
  3. Install the screws (x2) that attach the front fascia camera cover to the front fascia assembly.
    4 Nm (2.9 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • Torx T20 socket
