Trim - C-Pillar - LH (Remove and Replace)

Correction code 1518010172 FRT 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1518 - Pillar and Sill Trim

Torque Specifications

Table 1. Torque Specifications: Trim - C-Pillar - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolt that attaches the LH seatbelt anchor to the body
35 Nm (25.8 lbs-ft)
  • 15 mm socket
 Replace

Remove

  1. Remove the LH side rail trim. See Trim - Side Rail - LH (Remove and Replace).
  2. Remove the LH side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  3. Remove and discard the bolt that attaches the LH seatbelt anchor to the body.
    Tip
    Use of the following tool(s) is recommended:
    • 3 in extension
    • Ratchet/torque wrench
    • 15 mm socket
    • Cordless Ratchet/Impact Driver
  4. Release the clips (x3) and tabs (x3) that attach the C-pillar trim to the vehicle.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  5. Feed the seatbelt through the LH C-pillar trim, and then remove the trim.

Install

  1. Feed the seatbelt through the LH C-pillar trim, and then remove the trim.
  2. Install the clips (x3) and tabs (x3) that attach the C-pillar trim to the vehicle.
  3. Install a new bolt that attaches the LH seatbelt anchor to the body.
    35 Nm (25.8 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm socket
  4. Install the LH side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  5. Install the LH side rail trim. See Trim - Side Rail - LH (Remove and Replace).
