Harness - Front Door - LH (Remove and Replace)

Correction code 1710020072 FRT 0.78 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1454796-00-A TOOLKIT, WINDOW SWITCH
Parent topic: 1710 - Harnesses

Remove

  1. Open all doors and lower all windows.
  2. Remove the LH front door trim panel from the LH front door. See Panel - Door Trim - Front - LH (Remove and Replace).
  3. Disconnect the LV battery power. See LV Power (Disconnect and Connect) (Modify).
  4. Connect a window switch tool to the LH front door harness and fully raise the LH front window, and then disconnect the tool.
  5. Remove the closeout panel from the door. See Closeout Panel - Door - Front - LH (Remove and Replace).
  6. Release the clip that secures the door harness to the window motor.
  7. Release the red locking tab to disconnect the electrical wiring harness from the door handle connector.
  8. Release the clips (x3) that secure the LH front door harness.
  9. Disconnect the LH front door latch.
  10. Release the clips (x4) that secure the LH front door harness and the black harness clips (x2) along the door edge.
  11. Partially release the lower left part of the LH front primary door seal to let the LH lower A-pillar trim pass.
  12. Remove the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  13. Remove the LH footwell duct from the HVAC module. See Duct - Footwell - LH (Remove and Replace).
  14. Disconnect the J7 LH front door electrical connector from the LH body controller.
  15. Remove the rubber grommets (x2), and then remove the LH front door harness from the LH front door assembly.

Install

  1. Connect a window switch tool to the LH front door harness and fully raise the LH front window, and then disconnect the tool.
  2. Seat the LH front door harness into the LH front door assembly, and then install the rubber grommets (x2).
  3. Connect the J7 LH front door electrical connector to the LH body controller.
  4. Install the LH footwell duct to the HVAC module. See Duct - Footwell - LH (Remove and Replace).
  5. Install the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  6. Install the LH front primary door seal.
  7. Install the clips (x4) that secure the LH front door harness and the black harness clips (x2) along the door edge.
  8. Connect the LH front door latch.
  9. Install the clips (x3) that secure the LH front door harness.
  10. Engage the red locking tab to connect the electrical wiring harness to the door handle connector.
  11. Install the clip that secures the door harness to the window motor.
  12. Install the closeout panel to the door. See Closeout Panel - Door - Front - LH (Remove and Replace).
  13. Connect a window switch tool to the LH front door harness and fully lower the LH front window, and then disconnect the tool.
  14. Connect the LV battery power. See LV Power (Disconnect and Connect) (Modify).
  15. Install the LH front door trim panel to the LH front door. See Panel - Door Trim - Front - LH (Remove and Replace).
  16. Raise all windows and close all doors.
