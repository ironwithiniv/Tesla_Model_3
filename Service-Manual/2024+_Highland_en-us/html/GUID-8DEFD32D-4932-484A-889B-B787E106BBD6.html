Cover - Shock Tower - LH (Remove and Install)

Correction code 1225010011 FRT 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1225 - Underhood Trim

Remove

  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Remove the cabin intake duct. See Assembly - Fresh Air Gutter - HVAC (Remove and Replace).
  3. Remove the access panel. See Cover - Hood Latch (Remove and Replace).
  4. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  5. Release the clips (x3) that attach the LH shock tower cover to the vehicle, and then remove the cover from the vehicle.

Install

  1. Install the clips (x3) that attach the LH shock tower cover to the vehicle.
  2. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  3. Install the access panel. See Cover - Hood Latch (Remove and Replace).
  4. Install the cabin intake duct. See Assembly - Fresh Air Gutter - HVAC (Remove and Replace).
  5. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
