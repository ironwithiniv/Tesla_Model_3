Panel - Cowl Screen (Remove and Replace)

Correction code 1225010032 FRT 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2024-04-16: Removed the underhood storage unit related steps, and changed the shock tower cover removal steps to partially tucking the covers inside.
Parent topic: 1225 - Underhood Trim

Remove

  1. Open the LH front door and lower the LH front window.
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Remove the cabin intake duct. See Assembly - Fresh Air Gutter - HVAC (Remove and Replace).
  4. Remove the LH and RH wiper arms and blades. See Wiper Arm - Driver Side (Remove and Replace).
  5. Release the clips (x4) on the LH and RH shock tower covers, and partially tuck both tower covers inside.
  6. Remove the LH and RH hood hinge covers. See Cover - Hood Hinge - LH (Remove and Replace)
  7. Disconnect the main washer hose.
  8. Release the clip that attaches the harness to the cowl screen panel.
  9. Release the clip that attaches the washer hose to the cowl screen panel.
  10. Release the clips (x4) and push clips (x2) that attach the cowl screen panel to the vehicle, and then remove the cowl screen panel from the vehicle.

Install

  1. Position the cowl screen panel, and then install the clips (x4) and push clips (x2) that attach the cowl screen panel to the vehicle.
    CAUTION
    Carefully install the cowl screen panel to avoid damage to the windshield. Applying excessive force on the windshield can crack the glass.
  2. Restore the shock tower covers and install the clips (x4) onto the LH and RH shock tower covers.
  3. Install the LH and RH hood hinge covers. See Cover - Hood Hinge - LH (Remove and Replace)
  4. Install the clip that attaches the washer hose to the cowl screen panel.
  5. Install the clip that attaches the harness to the cowl screen panel.
  6. Connect the main washer hose.
  7. Install the LH and RH wiper arms and blades. See Wiper Arm - Driver Side (Remove and Replace).
  8. Install the cabin intake duct. See Assembly - Fresh Air Gutter - HVAC (Remove and Replace).
  9. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  10. Raise the LH front window and close the LH front door.
