Module - Rear End - Center Console (Remove and Install)

Correction code 1519010131 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-07-20: Updated the steps from removing the hockey sticks to partially releasing them for enough access space.
  • 2025-11-13: Changed the bolt that attaches the ground harness to the rear end module to a consumable part, and added the part number.
Parent topic: 1519 - Center Console

Bolt that attaches the ground harness to the rear end module

 Replace 1096312-00-A

Remove

  1. Remove the rear end panel. See Panel - Rear End - Center Console (Remove and Replace).
  2. Remove the LH and RH rear side panels. See Panel - Rear Side - Center Console - LH (Remove and Replace).
  3. Lift up the armrest.
  4. Partially release the LH hockey stick and place an inflatable air bag for enough space to access the rear display fasteners.
    Note
    4x clips, 1x location tab, 1x guide tab
  5. Partially release the RH hockey stick and place an inflatable air bag for enough space to access the rear display fasteners.
    Note
    4x clips, 1x location tab, 1x guide tab
  6. Disconnect LV battery power. See LV Power (Disconnect and Connect) (Modify)
  7. Remove the screws (x6) that attach the rear end module assembly to the center console.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  8. Release the datums (x2) that attach the rear end module assembly to the center console.
  9. Disconnect the rear end module electrical connectors (x2).
  10. Remove and discard the bolt that attaches the ground harness to the rear end module assembly, then remove the rear end module assembly from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket

Install

  1. Install a new bolt that attaches the ground harness to the rear end module assembly.
    1 Nm (.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  2. Connect the rear end module electrical connectors (x2).
  3. Fasten the datums (x2) that attach the rear end module assembly to the center console.
  4. Install the screws (x6) that attach the rear end module assembly to the center console.
    1 Nm (.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  5. Remove the inflatable air bag, then secure the LH hockey stick onto the center console.
    Note
    4x clips, 1x location tab, 1x guide tab
    Note
    Ensure that the guide tab is properly installed.
  6. Remove the inflatable air bag, then secure the RH hockey stick onto the center console.
    Note
    4x clips, 1x location tab, 1x guide tab
    Note
    Ensure that the guide tab is properly installed.
  7. Put down the armrest.
  8. Connect LV battery power. See LV Power (Disconnect and Connect) (Modify)
  9. Install the LH and RH rear side panels. See Panel - Rear Side - Center Console - LH (Remove and Replace).
  10. Install the rear end panel. See Panel - Rear End - Center Console (Remove and Replace).
  11. Connect a laptop with Toolbox to the vehicle. See Toolbox (Connect and Disconnect).
  12. In Toolbox, click the Actions tab, type "PING-BASH_DISPLAY" into the search field, click PING-BASH_DISPLAYvia Toolbox:(link), select rear for the Poppyseed Display Test Arg field, change the timeout to 20, and then click Run and allow the routine to complete.
  13. Disconnect the laptop with Toolbox from the vehicle. See Toolbox (Connect and Disconnect).
