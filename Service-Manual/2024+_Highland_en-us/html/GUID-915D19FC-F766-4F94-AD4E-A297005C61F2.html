Hose - Chiller to HV Battery (LHD) (RWD) (Remove and Replace)

Correction code 1830010052 0.90 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
Parent topic: 1830 - Cooling System

Remove

  1. Raise and support vehicle.
    Note
    Ensure vehicle is not charging.
  2. Open the LH front door and lower the LH front window.
  3. Place vehicle in service mode through UI.
    Note
    Select vehicle's badge icon in Controls > Software for four seconds and then type "service" into dialog box.
  4. Unlock the vehicle gateway. See Gateway Unlock.
  5. Run Thermal Fill Drain (Coolant Only) through the UI.
    Note
    Select Thermal > Coolant System > Coolant Fill/Drain, click Run, close once routine is completed, Thermal Fill Drain routine has a 5 hour time limit, After 5 hours routine must be performed again.
  6. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  7. Disconnect the LV battery power. See LV Power (Disconnect and Connect) (Modify).
  8. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  9. Disconnect manifold hose from front of HV battery.
    Note
    1x spring clip, 2x plugs, Plug hoses as required, Coolant loss greater than 1L will require vacuum fill.
  10. Release chiller to battery hose clips.
    Note
    5x clips.
  11. Lower vehicle until tires are touching the ground.
    Note
    Raise lift off locks, then hold lock release lever to keep locks free while vehicle is lowered.
  12. Position fluid catcher underneath front of vehicle.
  13. Remove fresh air intake assembly.
    Note
    2x studs, Lift cowl as needed.
  14. Place absorbent material below car computer coolant hose connection points to collect any spilled coolant.
  15. Disconnect inner coolant hose to car computer mount.
    Note
    1x spring clip, Plug hose.
  16. Disconnect outer coolant hose from car computer mount and remove coolant hoses from car computer.
    Note
    1x spring clip, Plug hose.
  17. Install car computer coolant plug.
    Note
    1x coolant plug.
  18. Disconnect the sensor for the chiller to battery hose.
    Note
    1x locking electrical connector, Do not push down on Red tab, Pull red tab to disengage lock, Pull again to release connector.
  19. Disconnect chiller to battery hose from supermanifold.
    Note
    1x spring clip.
  20. Remove chiller to battery hose from vehicle.
    Note
    Remove hose from RH side of vehicle, Gently Maneuver hose as needed to clear surrounding objects.

Install

  1. Position chiller to battery hose to vehicle for installation.
    Note
    Feed hose into position from RH side of vehicle along bulkhead, Gently maneuver hose as needed to clear surrounding objects, See images for clarity.
  2. Connect chiller to battery hose to the Supermanifold.
    Note
    Perform a push-pull-push test to make sure the hose is fully seated. Do not wiggle the hose at the connection.
  3. Connect chiller to battery hose sensor connector.
    Note
    1x locking connector, Engage locking tab, Harness and coolant hose are color coded, Match harness color to coolant hose color.
  4. Install outer coolant hose to car computer mount .
    Note
    1x spring clip, Plug hose.
  5. Install inner coolant hose to car computer mount.
    Note
    1x spring clip, Plug hose.
  6. Install fresh air intake assembly.
    Note
    2x studs, Lift cowl as needed.
  7. Remove fluid catcher from underneath vehicle.
  8. Raise vehicle fully and lower lift onto locks.
    Note
    Set vehicle to comfortable working height, Make sure there's an audible click of the locks on both sides before lowering, otherwise vehicle may tilt to the side, Verify doors are clear of surrounding objects.
  9. Secure chiller to battery hose clips.
    Note
    5x clips.
  10. Connect HV battery manifold hose.
    Note
    1x spring clip, Remove plugs.
  11. Position front aero shield onto vehicle.
    Note
    2x nuts, 15mm, 5 Nm, Hand-tighten the nuts to temporarily hold the panel in place.
  12. Apply Loctite 222 onto front aero shield bolts and install outer fasteners to front aero shield.
    Note
    7x bolts, 10mm, 5 Nm.
  13. Lower vehicle fully.
    Note
    Raise lift off locks, then hold lock release lever to keep locks free while vehicle is lowered.
  14. Install frunk assembly to vehicle.
    Note
    4x clips, Replace any clips if broken or missing.
  15. Install bolts securing frunk assembly.
    Note
    6x bolts, 10mm, 5 Nm.
  16. Install frunk service panel.
    Note
    3x clips, Push towards rear of vehicle to secure.
  17. Install access panel to frunk assembly.
    Note
    3x clips, 1x connector, Frunk safety switch, 3x guide tabs, Align 3x tabs then push forward to secure clips.
  18. Remove coolant bottle cap.
  19. Place empty coolant container into front storage area.
  20. Fill container with at least 15L of coolant.
  21. Place filled coolant container into front storage area.
  22. Install refill tool cap onto coolant bottle assembly.
  23. Setup vacuum refill tool.
    Note
    Verify all valves on refill tool are in the closed position, See image for clarity.
  24. Install vacuum refill hose into refill cap on coolant bottle.
    Note
    Perform push-pull-push test to verify hose is fully engaged.
  25. Position overflow hose into empty container.
  26. Place refill hose inside filled coolant container .
    Note
    Make sure hose end is fully submerged into coolant.
  27. Connect shop air supply to coolant refill tool.
    Note
    If not already done, Verify refill valve is set to off.
  28. Open air inlet valve to draw a vacuum, Once gauge stabilizes, Fully close valve.
    Note
    Gauge stabilizes roughly (60-70 cmHg), Vacuum should not drop after the valves are closed.
  29. Slowly open coolant refill valve to allow coolant to be drawn into coolant refill hose, Close valve when hose is full of coolant.
    Note
    This purges trapped air from the hose.
  30. Monitor gauge for 30 seconds to verify a vacuum is maintained in cooling system.
  31. Reopen the air inlet valve for 3 minutes to continue evacuating cooling system, then close valve.
  32. Slowly open refill valve to allow coolant to be drawn into system.
    Note
    Make sure hose end of refill hose is fully submerged during entire process.
  33. Once gauge reads zero, close refill valve.
  34. Disconnect shop air supply from coolant refill tool.
  35. Remove coolant refill hose from coolant container.
  36. Remove coolant overflow hose from coolant container.
  37. Remove vacuum refill hose from refill cap on coolant bottle.
  38. Remove coolant refill tool from vehicle.
  39. Remove both coolant containers from inside underhood area.
  40. Connect First Responder Loop and LV battery.
    Note
    2x connectors, Secure FRL first, Seat LV battery connection and push black connector lock inwards to secure, Engage green locking tab when fully seated.
  41. Access Thermal System routines using the UI.
    Note
    Select Service mode > Thermal.
  42. Select "Start Coolant Air Purge" using the UI.
    Note
    Wait until coolant pumps stop running (audible noise), Routine Passed will appear, but pumps will run for 10 minutes, If you start next another routine during this time, it will fail, Make sure vehicle is not in "Drive", Routine is still running despite the completed message, Idle speed = ~1500 RPM, Test will vary speeds from 3500-6500 RPM and actuate valves between SERIES and PARALLEL, Putting vehicle into "Drive" will stop this routine, If speeds hover at 7000 RPM, this indicates the pumps are air locked, perform a vacuum fill, Continue to add coolant and purge until the coolant level reaches between the NOM and MAX Lines on the bottle.
  43. Inspect coolant level and top off as necessary.
    Note
    Ensure that fluid level is at Max line.
  44. Install coolant bottle cap.
  45. Perform Thermal Performance through the UI.
    Note
    Select Thermal > Actions > Test Thermal Performance, click Run, close once routine is completed.
  46. Exit Service Mode through UI.
    Note
    Exit Service Mode: Controls > Service Mode > Exit Service Mode, Press and hold to exit.
  47. Install fresh air gutter assembly.
    Note
    3x clips.
  48. Install rear underhood apron.
    Note
    14x clips, Hold rear wall of frunk to keep from flexing while engaging front clips.
  49. Close hood.
  50. Raise LH front window.
  51. Close LH front door.
  52. Remove lift arms from below vehicle.
    Note
    Lower rack arms fully and remove them from under vehicle.
