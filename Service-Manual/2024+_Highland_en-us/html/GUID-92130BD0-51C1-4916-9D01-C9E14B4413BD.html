SD Card - Car Computer (Remove and Replace)

Correction code 2110010022 FRT 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 2105 - Touchscreen

Remove

  1. Open the RH front door and lower the RH front window.
  2. Move the RH front seat rearward.
  3. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  4. Disconnect LV battery power. See LV Power (Disconnect and Connect) (Modify).
  5. Remove the RH footwell assembly. See Cover - Footwell - Front Passenger (Remove and Replace).
  6. Use a pick to slide the SD card retaining tab over, and then use tweezers to remove the SD card from the computer.
    CAUTION
    Make sure not to remove the SIM card, located to the left of the SD card.
    Tip
    Use of the following tool(s) is recommended:
    • Tweezers - 1126453-00-A
    • Pick Miniature Soft Grip 90 degree tip 6in
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  7. Destroy the SD card by cutting the card in half through the center, and then cut each piece into half, resulting in 4 pieces.
    CAUTION
    It is mandatory to destroy the SD card to protect user data.

Install

  1. Position the SD card into the install guide.
    Note
    Ensure the install guide slide is in the down position. Slide the SD card into the top of the tool from left to right until fully seated.
    Tip
    Use of the following tool(s) is recommended:
    • SD Card Install Guide - 1607771-00-A
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  2. Install the SD card into the computer with the gold pads up.
    Note
    Slide the guide locking tab upward until there is an audible click.
  3. Install the RH footwell assembly. See Cover - Footwell - Front Passenger (Remove and Replace).
  4. Connect LV battery power. See LV Power (Disconnect and Connect) (Modify).
  5. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  6. Move the RH front seat to its original position.
  7. Raise the RH front window and close the RH front door.
