Side Shield - Outboard - LH (Remove and Replace)

Correction code 1307010122 FRT 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-11-04: Added information about the tab that attaches the side shield to the front seat.
  • 2026-07-17: Added a note to ensure that the seat is high enough to access the bolt securing the outboard side shield to the seat frame.

Hexagon - 1060071-00-A

Mini Ratchet Bit Set - 1450424-00-A

Note
In certain regions, if the 1st row outboard shield is supplied as an assembly with buttons and switch pre-installed, skip the steps of removing/installing the buttons and switch.
Parent topic: 1307 - Front Seat Covers Pads and Trims

Remove

  1. Open the LH front door.
  2. Move the driver's seat fully forward, and adjust the seat cushion height to maximum.
    CAUTION
    Do not allow the seat headrest to compress the sun visor as it might crack the mirror.
  3. Insert the seat belt release key (1133787-00-A) into the bottom of the seatbelt pretensioner coupling to release the seatbelt from the pretensioner.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  4. Remove the bolt that attaches the driver seat outboard side shield to the seat frame.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless 1/4in Dr Ratchet
    Note
    Ensure the front of the seat is high enough to access the bolt.
  5. Pull the driver seat outboard side shield away from the seat frame to release the tab that attaches the side shield to the front of the seat frame.
  6. Pull the driver seat outboard side shield away from the seat frame to release the clip that attaches the side shield to the upper part of the seat frame.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  7. Disconnect the electrical harness from the backrest and cushion adjust switch connector, if so equipped.
  8. Remove the driver seat outboard side shield from the vehicle.
  9. Carefully release the clips that attach the seat cushion and seat back buttons to the driver seat backrest and cushion adjust switch, and then remove the buttons from the outboard side shield.
  10. Remove the screws securing the 8 way switch to LH front outer side cover, then remove LH front outer side cover from 8 way switch assembly.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket

Install

  1. Install the screws securing the 8 way switch to LH front outer side cover, then install LH front outer side cover from 8 way switch assembly.
    1.7 Nm (1.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  2. Install the clips that attach the seat cushion and seat back buttons to the driver seat backrest and cushion adjust switch, and then install the buttons to the outboard side shield.
  3. Place the driver seat outboard side shield to the vehicle.
  4. Connect the electrical harness from the backrest and cushion adjust switch connector, if so equipped.
  5. Install the upper and lower part clips that attaches the side shield to the center of the seat frame.
  6. Push inward to secure the outboard side shield assembly tab to the front seat assembly, and then install the screw that attaches the driver seat outboard side shield to the seat frame.
    5 Nm (3.7 lbs-ft)
    CAUTION
    Carefully push the outboard side shield assembly to avoid damage.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless 1/4in Dr Ratchet
  7. Return the seat back to the original position.
  8. Install LH front seat belt retractor to seat.
  9. Raise LH front window.
  10. Close the LH front door.
