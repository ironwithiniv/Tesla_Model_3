Harness - Main Front (Remove and Replace)

Correction code 1710040022 4.32 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-05-27: Added steps for removal and re-installation of the front body controller module.
  • 2025-05-06: Added steps for removal and re-installation of the glove box.
  • 2024-04-18: Updated the cover image.
Equipment:
  • 1454796-00-A TOOLKIT, WINDOW SWITCH
Parent topic: 1710 - Harnesses

Remove

  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace)
  2. Disconnect 12V/LV power. See LV Power (Disconnect and Connect) (Modify).
  3. Remove the LH and RH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  4. Remove the LH and RH knee airbag assembly, if equipped. See Airbag - Knee - LH (Remove and Replace).
  5. Remove the glove box. See Glove Box (Remove and Replace).
  6. Remove the wiper module. See Wiper Module (LHD) (Remove and Replace).
  7. Remove the front body controller module. See Module - Body Controller (Remove and Replace).

    1x bolt, 10mm, 8 Nm,

    Note
    2x clips

    Note

  16. Disconnect RH front harness connector on left side of car computer
    Note
    1x connector

    Note

  18. Release windshield heater connector clips from the body

    1x connector
  28. Disconnect front harness white connector X909 from LH body harness
    Note
    1x connector
  29. Release front harness from left body controller

    Note
    1x bolt, 10mm, 8 Nm,

  41. Remove LH front harness test junction
    Note
    1x bolt, 10mm, 8 Nm, Inspect bolt: if it is a self tapping tri-lobular bolt (1128269-00-A) then discard, If it is a normal bolt (1447438-00-A) it can be reused
  42. Disconnect LH front acceleration sensor connector

  57. Remove the front harness test junction around RH front frame rail area
    Note

  58. Disconnect RH front acceleration sensor connector
    Note
    1x connector, Release locking tab
  59. Disconnect RH headlamp connector
    Note
    1x locking connector, Do not push down on red tab, Pull red tab to disengage lock, Pull tab again to release connector 
  60. Remove and discard the nut that attaches the DCDC positive cables to the RH body controller.
  61. Remove the wheel chocks.
  62. With an assistant, move the vehicle to a lift.
    CAUTION
    The vehicle is safely pushed for only a very short distance and at a very slow speed.
  63. Remove the front LH and front RH wheels. See Wheel Assembly (Remove and Install).
  64. Remove the LH and RH front wheel arch liners. See Wheel Arch Liner - Front - LH (Remove and Replace).
  65. Remove the front harness clip at the rear of RH front wheel liner area for the side repeater and camera harness
    Note

  67. Disconnect the RH front wheel speed sensor

    Note

  71. Remove the front harness clips from the outer RH rail area
    Note

  72. Remove bolts securing front harness bracket from vehicle
    Note
    2x bolts,10mm,9 Nm
  73. Remove LH harness bracket clip and remove from vehicle
    Note
    2x clips
  74. Route the LH side of the front harness from wheel liner to frunk area
  75. Route the LH side of the front harness toward the front controller area
  76. Route the RH side of the front harness from wheel liner to frunk area
  77. Route the RH side of the front harness toward the front controller area
  78. Remove the front harness from vehicle

Install

  1. Position the front harness to vehicle for installation
    Note
    Make sure to route RH branch underneath A/C compressor HV harness
  2. Push LH front harness into driver side compartment then secure grommet
  3. Route LH front harness from frunk to LH wheel liner area
  4. Route LH front harness toward LH front fascia area
    Note
    Make sure plastic housing is properly oriented with clips facing frame rail, Feed harness down behind fascia
  5. Push RH front harness into passenger side compartment then secure grommet
  6. Route RH front harness from frunk to RH wheel liner area
  7. Route RH front harness toward RH front fascia area
  8. Secure LH harness bracket clips to vehicle
    Note
    2x clips
  9. Install bolts securing front harness bracket from vehicle
    Note
    2x bolts,10mm,9 Nm
  10. Secure clips securing harness behind LH shock tower
    Note
    4x clips
  11. Connect brake fluid reservoir connector
    Note
    Connect brake fluid reservoir connector
  12. Connect connector to brake booster assembly
    Note
    1x connector, Secure locking tab
  13. Connect harness connector from brake booster assembly
    Note
    1x connector, Secure locking tab
  14. Connect hydraulic control unit
    Note
    1x connector, Gently push connector downward, Secure locking tab
  15. Secure front harness clips around LH front frame rail area
    Note
    6x clips
  16. Secure washer hose to LH front frame rail area
    Note
    1x clip
  17. Secure steering gear harness bracket clips to vehicle
    Note
    2x clips
  18. Install clip securing radiator outlet hose to RH side of vehicle
    Note
    1x clip
  19. Connect FDU front subframe harness
    Note
    1x connector, Secure locking tab
  20. Connect steering gear assembly
    Note
    4x connectors, Secure locking tabs
  21. Install AC compressor ground strap
    Note
    1x bolt, T25, 7 Nm
  22. Secure front harness clips to frunk reinforcement bracket
    Note
    3x clips
  23. Connect HVIL connector
    Note
    1x locking connector, 1x fir tree clip/1x adhesive clip, Engage locking tab, Clean BIW bracket area and secure harness adhesive clip when applicable on older VIN's, If BIW has a hole then no need to rework harness, Attach fir tree clip onto BIW bracket hole

    1x bolts, 10mm, 8 Nm,
  25. Install bolt securing LH front harness test junction
    Note
    1x bolt, 10mm, 8 Nm,
  26. Connect LH front acceleration sensor connector
    Note
    1x connector, Secure locking tab
  27. Connect LH front headlamp connector
    Note
    1x connector, Secure locking tab
  28. Secure level sensor harness to washer tank
    Note
    4x clips
  29. Connect level sensor connector
    Note
    1x connector
  30. Connect washer pump connector
    Note
    1x connector
  31. Install the front harness clip around RH front frame rail area
    Note
    2x clips
  32. Connect front harness connector for the LH front carrier harness

    1x connector, Secure locking tab
  33. Connect front harness from cooling fan module
    Note
    1x connector
  34. Connect LH front wheel speed sensor
    Note
    1x connector, Secure locking tab
  35. Secure front harness clip for the LH side repeater and camera harness
    Note
    1x clip
  36. Connect front harness connectors for LH side repeater and camera
    Note
    2x connectors, Secure locking tabs

    2x clips

  54. Secure front harness clip at the rear of RH front wheel liner area for the side repeater and camera harness
    Note
    1x clip
  55. Connect front harness connectors for the RH side repeater and camera
    Note
    2x connectors, Secure locking tabs
