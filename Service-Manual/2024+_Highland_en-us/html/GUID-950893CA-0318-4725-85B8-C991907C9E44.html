Stuck Sliding Lid - Center Console (Premium/Performance) (Test/Adjust)

Correction code 15190405500 0.06 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Note
A bottle or other object in the cupholder, if struck, can sometimes unseat the cupholder mounting clips, preventing the center console sliding lid from fully closing; this procedure can address this particular condition.
  • 2026-08-21: Released new procedure.
  1. Open both front doors
  2. Inspect center console sliding lid
    Note
    Check sliding lid functionality, press in to see if it closes and clears cup holder
  3. If the sliding lid will not fully close, secure the cup holder
    Note
    6x clips, press down on the 6 points shown in the first image; the 6 clips are on the underside of the cupholder assembly, where indicated by the yellow arrows. To assure cup holder is fully seated check for gaps and do a wiggle test
  4. Verify sliding lid is functional
    Note
    Check sliding lid functionality, press in to see if it closes and clears cup holder. If sliding lid is stuck in the open position recommend replacing center console sliding door assembly
  5. Close both front doors
