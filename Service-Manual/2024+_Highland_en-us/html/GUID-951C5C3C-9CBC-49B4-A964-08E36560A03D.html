Identify Headlight Type

The global headlight (2) has a different reflector and lens design compared to the SAE/ECE headlight (1), illustrated below. Identify the headlight type to make sure you follow the correct procedure.

Adjust the Headlights

  1. Park the vehicle on a level surface.
  2. Make sure that all tires are inflated to specification.

  4. Enable Service Mode. See Service Mode
  5. Open the hood.
  6. Enter the headlight adjustment mode through the touchscreen via Controls > Service > Adjust Headlights.
  7. Enable test drive override.
  8. Position the headlight aiming machine in front of the vehicle, maintaining a distance of 35 cm from the headlamp lens.
  9. Use the visor/laser to line up the aiming machine perpendicular to the axis between the hood struts.
    Note
    If the headlight aiming machine can move between the LH and RH headlights while maintaining the same laser angle projected onto the hood struts, the machine is set correctly (perpendicular) to the vehicle.
  10. Close the hood and turn on the headlights.
  11. Turn on the headlight aiming machine.
  12. Position the headlight aiming machine in front of the LH headlight.
    Note
    Adjust the height of the headlight aiming machine so that it is aligned with the center point of the headlight.
  13. Set up the headlight aiming machine for the LH headlight: select OEM > Global and then select the LH headlight icon.
  14. Select height to <0.8m
  15. Move the headlight aiming machine following the black arrows on the screen. Once the machine is centered to the headlight, selecting the "X" button will direct you to the adjustment screen.
  16. Adjust the LH headlight using the scroll wheel on the steering wheel. The X and Y values need to be set as closely as possible to 0.00. When values are in spec, select the check mark.
    Note
    Make sure to set the X and Y values as closely as possible to "0.00". When the headlight aiming mode is exited, the X and Y versions will be automatically set to the default regional horizontal and vertical adjustment values.
    Note
    DO NOT touch the 15/45 deg button (if available). Doing so will completely change the machine's settings, meaning you will need to start the headlight aiming procedure all over again from the beginning.
  17. Move the headlight aiming machine to the RH headlight, and then repeat steps 15 and 16 for the RH headlight.
  18. When both the LH and RH headlights are adjusted to specification, select the check mark to see the adjustment values.
  19. Turn off the headlight aiming machine.
  20. Exit the headlight adjustment mode.
  21. Exit Service Mode. See Service Mode.
