Wiper Module (RHD) (Remove and Replace)

Correction code 1750020002 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1750 - Wipers and Washers

Remove

  1. Open the RH front door and lower the RH front window.
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Remove the fresh air gutter assembly. See Assembly - Fresh Air Gutter - HVAC (Remove and Replace).
  4. Remove the wiper arms. See Wiper Arm - Driver Side (Remove and Replace).
  5. Remove the cowl screen panel. See Panel - Cowl Screen (Remove and Replace).
  6. Remove the bolts (x3) that attach the wiper module to the body, and then move it aside.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  7. Disconnect the wiper module connector.
    Note
    Do not place the limbs within the linkage movement area as the wiper arms will automatically transition to parking mode.
  8. Remove the wiper module from the vehicle.

Install

  1. Connect the wiper module connector.
    Warning
    Keep your fingers away from any potential pinch points and moving parts while connecting and installing the wiper module. Do not attempt to test the module until it is fully installed in the vehicle.
    Note
    Do not place the limbs within the linkage movement area as the wiper arms will automatically transition to parking mode.
  2. Install the bolts (x3) that attach the wiper module to the body.
    7 Nm (5.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  3. Install the cowl screen panel. See Panel - Cowl Screen (Remove and Replace).
  4. Install the wiper arms. See Wiper Arm - Driver Side (Remove and Replace).
  5. Install the fresh air gutter assembly. See Assembly - Fresh Air Gutter - HVAC (Remove and Replace).
  6. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  7. Enable Service Mode through the touchscreen. See Service Mode.
  8. Unlock the vehicle gateway for diagnostic communication. See Gateway Unlock.
  9. Run PROC_WIPER_X_POST-REPLACEMENT-PROCEDURESvia Service Mode:Closures ➜ Windows ➜ Wiper Module Replacementvia Service Mode Plus:low-voltage ➜ Wiper Post Replacement ➜ Wiper Post Replacement Procedurevia Toolbox:(link)
  10. Reinstall the vehicle software. See Software Reinstall - Touchscreen.
  11. Raise the RH front window and close the RH front door.
