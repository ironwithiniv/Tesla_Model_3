Upholstery Wire - Armrest - 2nd Row - LH (Remove and Replace)

Correction code 1308010042 FRT 0.48 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1308 - 2nd Row Seat Covers Pads and Trims

Remove

  1. Remove the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  2. Remove the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  3. Remove the LH 2nd row seat back. See Seatback - 2nd Row - LH (Remove and Replace).
  4. Remove the 2nd row armrest closeout. See Closeout - Armrest - 2nd Row (Remove and Replace).
  5. Remove the 2nd row armrest. See Armrest - 2nd Row (Remove and Replace).
  6. Remove the clips (x2) that attach the cover plate to the seat assembly.
  7. Unhook the LH seat back armrest upholstery wire that attach the LH seat back upholstery trim cover to the seat back frame.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  8. Starting from the bottom of the LH seat back, gently remove the LH seat back armrest upholstery wire from the LH seat back.
    Note
    Make sure the LH seat back armrest upholstery wire does not damage the LH seat back.

Install

  1. Starting from the bottom of the LH seat back, gently install the LH seat back armrest upholstery wire to the LH seat back.
    Note
    Make sure the LH seat back armrest upholstery wire does not damage the LH seat back.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  2. Hook the LH seat back armrest upholstery wire that attach the LH seat back upholstery trim cover to the seat back frame.
  3. Install the clips (x2) that attach the cover plate to the seat assembly.
  4. Install the 2nd row armrest. See Armrest - 2nd Row (Remove and Replace).
  5. Install the 2nd row armrest closeout. See Closeout - Armrest - 2nd Row (Remove and Replace).
  6. Install the LH 2nd row seat back. See Seatback - 2nd Row - LH (Remove and Replace).
  7. Install the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  8. Install the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
