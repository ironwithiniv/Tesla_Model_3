Switch - Window - Driver (Remove and Replace)

Correction code 1513021412 FRT 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-01-30: Added steps about removing and installing the switch harness.
Parent topic: 1513 - Door Trim

Remove

  1. Remove the LH front door trim. See Panel - Door Trim - Front - LH (Remove and Install).
  2. Remove the LH front door NVH pad. See NVH Pad - Door - Front - LH (Remove and Replace).
  3. Use a plastic trim tool to release the clips (x8) that attach the LH front lower bolt cover to the LH front door trim panel.
  4. Release the clips (x2) that attach the harness connector to the bolt cover.
  5. Disconnect the switch connector from the LH front driver window switch.
  6. Release the LH front window switch harness from the harness clips (x3) and release the connector from the tabs (x4), and move the harness and the connector to one side.
  7. Press down on the driver window switch assembly, and at the same time, release the clips (x4) that attach the window switch to the door trim panel.
    Tip
    Use a 45 degree pick or a pocket screw driver to release the clips.
    Tip
    Pull up on the manual release handle for access, and then use thumb to push down on the switch to release it.
    Note
    Replace the door trim if any tab is broken during removal.
  8. Remove the driver window switch from the vehicle.

Install

  1. Pull up on the manual release handle for access, and position the driver window switch into the vehicle, and then secure the clips (x4) that attach the switch to the door trim panel.
  2. Install the LH front window switch harness to the harness clips (x3) and install the connector to the tabs (x4).
    Note
    Make sure the wiring harness passes through the door trim.
  3. Connect the switch connector to the LH front driver window switch.
  4. Secure the clips (x2) that attach the harness connector to the bolt cover.
  5. Secure the clips (x8) that attach the LH front lower bolt cover to the LH front door trim panel.
  6. Install the LH front door NVH pad. See NVH Pad - Door - Front - LH (Remove and Replace).
  7. Install the LH front door trim. See Panel - Door Trim - Front - LH (Remove and Install).
