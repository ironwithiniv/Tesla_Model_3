Cover - Front - Seat Track - Front Seat (Remove and Replace)

Correction code 1301020022 FRT 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1301 - Front Seat Tracks and Motors

Remove

  1. Open all the doors and fully lower all the windows.
  2. Move the driver seat fully forward.
  3. Remove and discard the bolts (x2) that attach the rear of the driver seat to the body.
    CAUTION
    Use only the Torx Plus T45 to remove the seat bolts.
    Note
    Use of the following tool(s) is recommended:
    • Torx Plus T45 socket
  4. Move the driver seat fully rearward.
  5. Remove and discard the bolts (x2) that attach the front of the driver seat to the body.
    CAUTION
    Use only the Torx Plus T45 bit to remove the seat bolts.
    Note
    Use of the following tool(s) is recommended:
    • Torx Plus T45 socket
  6. Lift the driver seat upward, and then slide the track covers forward to remove from the seat assembly.

Install

  1. Install the seat track covers into the vehicle.
  2. Move the driver seat fully rearward.
  3. Install new bolts (x2) to attach the front of the driver seat to the body.
    33.5 Nm (24.7 lbs-ft)
    CAUTION
    Use only the Torx Plus T45 to torque the seat bolts.
    Note
    Use of the following tool(s) is recommended:
    • Torx Plus T45 socket
  4. Move the driver seat fully forward.
  5. Install new bolts (x2) to attach the rear of the driver seat to the body.
    33.5 Nm (24.7 lbs-ft)
    CAUTION
    Use only the Torx Plus T45 bit to torque the seat bolts.
    Note
    Use of the following tool(s) is recommended:
    • Torx Plus T45 socket
  6. Move the driver seat to its original position.
  7. Raise all the windows and close all the doors.
