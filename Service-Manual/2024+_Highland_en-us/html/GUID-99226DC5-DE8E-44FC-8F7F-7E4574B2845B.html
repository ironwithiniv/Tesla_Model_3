Underbody Deflector Assembly - Subframe - Front (Remove and Replace)

Correction code 3001010602 FRT 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-05-07: Released new procedure.
Parent topic: 3001 - Chassis and Subframes

Torque Specifications

Table 1. Torque Specifications: Underbody Deflector Assembly - Subframe - Front (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Nuts (x2) that attach the underbody deflector assembly to the front subframe
35 Nm (25.8 lbs-ft)
  • SKT, 3/8" DR, DEEP, 15MM
 Replace 1111145-00-A

Remove

  1. Remove the front valance. See Valance - Front Fascia (Remove and Replace).
    Note
    Do not remove the pedestrian warning speaker from the front valance.
  2. Remove and discard the nuts (x2) that attach the underbody deflector assembly to the front subframe.
    Tip
    Use of the following tool(s) is recommended:
    • SKT, 3/8" DR, DEEP, 15MM

Replace

  1. Install new nuts (x2) that attach the underbody deflector assembly to the front subframe.
    35 Nm (25.8 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • SKT, 3/8" DR, DEEP, 15MM
  2. Install the front valance. See Valance - Front Fascia (Remove and Replace).
