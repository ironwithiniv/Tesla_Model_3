Hose - Return - Front Drive Unit Bypass (Remove and Replace)

Correction code 1830020092 FRT 0.47 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1080568-00-A Fluid Catcher
  • 1135762-00-A Kit, Svc Plug, Cooling Hose, Model 3
  • 1065131-00-A Battery Coolant Drain Kit
Parent topic: 1830 - Cooling System

Torque Specifications

Table 1. Torque Specifications: Hose - Return - Front Drive Unit Bypass (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolt that attaches the RH front wheel arch liner to the skid plate
5 Nm (3.7 lbs-ft)
  • 10 mm deep socket
Reuse

Remove

  1. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Disconnect the LV power. See LV Power (Disconnect and Connect) (Modify).
  4. Remove the cabin intake duct. See Assembly - Fresh Air Gutter - HVAC (Remove and Replace).
  5. Remove the access panel. See Cover - Hood Latch (Remove and Replace).
  6. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  7. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  8. Remove the push clips (x3) and bolt that attach the RH front wheel arch liner to the skid plate.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  9. Use a bungee strap to pull back the RH front wheel arch liner and secure it to the subframe.
  10. Position a coolant drain container underneath the RH front of the HV battery.
  11. Release the clip, disconnect the front drive unit powertrain bypass hose and plug the hose and the powertrain return tube as soon as possible to avoid coolant loss.
    Note
    Plug the supermanifold as quickly as possible to minimize coolant loss.
  12. Release the clip that attaches the front drive unit powertrain bypass hose to the front subframe.
  13. Remove the coolant drain collector from under the vehicle.
  14. Lower the vehicle to a comfortable working height.
  15. Position a fluid catcher underneath the front of vehicle.
  16. Release the clip, disconnect the front drive unit powertrain bypass hose from the supermanifold and plug the hose and the supermanifold as soon as possible to avoid coolant loss.
    Note
    Plug the supermanifold as quickly as possible to minimize coolant loss.
  17. Remove the front drive unit powertrain bypass hose from the vehicle.

Install

  1. Remove the plug from the supermanifold, immediately connect the front drive unit powertrain bypass hose to the supermanifold, and then fasten the clip.
    Note
    Perform a push-pull-push test to make sure that the hose is secure.
  2. Remove the fluid catcher from underneath the front of the vehicle.
  3. Raise the vehicle fully and then lower the lift until the safety locks are safely engaged.
  4. Position a coolant drain container underneath the RH front of the HV battery.
  5. Remove the plug from the powertrain return tube, immediately connect the front drive unit powertrain bypass hose to the powertrain retrun tube, and then fasten the clip.
    Note
    Perform a push-pull-push test to make sure that the hose is secure.
  6. Secure the clip that attaches the front drive unit powertrain bypass hose to the front subframe.
  7. Remove the coolant drain collector from under the vehicle.
  8. Remove the bungee strap from the RH front wheel arch liner.
  9. Install the push clips (x3) and bolt that attaches the RH front wheel arch liner to the skid plate.
    5 Nm (3.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  10. Install the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  11. Connect LV power. See LV Power (Disconnect and Connect) (Modify).
  12. Perform the cooling system (partial refill and bleed) procedure. See Cooling System (Partial Refill and Bleed) (Modify).
  13. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  14. Install the access panel. See Cover - Hood Latch (Remove and Replace).
  15. Install the cabin intake duct. See Assembly - Fresh Air Gutter - HVAC (Remove and Replace).
  16. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  17. Remove the vehicle from the 2 post lift. See Raise Vehicle - 2 Post Lift.
