Speaker - Dash - Center (Remove and Replace)

Correction code 2121010532 FRT 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-07-02: Added special tooling part number.
Parent topic: 2121 - Audio System - Speakers Subwoofer Amplifier

Torque Specifications

Table 1. Torque Specifications: Speaker - Dash - Center (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Screws (x3) that attach the center dash speaker to the IP carrier
2.3 Nm (1.7 lbs-ft)
  • Torx T20 bit
  • Ratchet/torque wrench
 Reuse
Equipment:
  • 1450424-00-B - 78PCS DOUBLE END MINI RATCHET BIT SET

Remove

  1. Remove the LH and RH instrument panel end caps. See End Cap - Instrument Panel - LH (Remove and Replace).
  2. Remove the LH and RH upper A-Pillar trims. See Trim - A-Pillar - Upper - LH (Remove and Replace).
  3. Remove the instrument panel speaker grille. See Speaker Grille - Instrument Panel (Remove and Replace).
  4. Remove the screws (x3) that attach the center dash speaker to the instrument panel, and then remove the speaker from the instrument panel.
    CAUTION
    Do not pull the speaker too far away from the instrument panel, as the speaker electrical connector is still attached.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 bit
    • 1450424-00-B - 78PCS DOUBLE END MINI RATCHET BIT SET
  5. Disconnect the electrical connector from the center dash speaker connector, and then remove the speaker from the vehicle.

Install

  1. Connect the electrical connector to the center dash speaker connector.
  2. Install the screws (x3) that attach the center dash speaker to the instrument panel.
    2.3 Nm (1.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 bit
    • 1450424-00-B - 78PCS DOUBLE END MINI RATCHET BIT SET
  3. Install the instrument panel speaker grille. See Speaker Grille - Instrument Panel (Remove and Replace).
    Note
    No need to run the TEST-SELF_VCLEFT_RGBvia Toolbox:(link) via Toolbox.
  4. Install the LH and RH upper A-Pillar trims. See Trim - A-Pillar - Upper - LH (Remove and Replace).
  5. Install the LH and RH instrument panel end caps. See End Cap - Instrument Panel - LH (Remove and Replace).
