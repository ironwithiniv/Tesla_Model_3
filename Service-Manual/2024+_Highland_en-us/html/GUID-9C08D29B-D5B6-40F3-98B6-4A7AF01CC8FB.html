Speaker Grille - Instrument Panel (Model 3 Standard) (Remove and Replace)

Correction code 14050105802 FRT 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-10-08: Released new procedure.
Parent topic: 1405 - Instrument Panel

Remove

  1. Open both front doors.
  2. Lower both front windows.
  3. Moth both front seats backward.
  4. Release the lower section of the the LH front primary door seal.
  5. Release the clips (x5) on the LH IP end cap, then remove the end cap.
    Note
    5x clips, 2x guide tabs
  6. Remove the LH upper A-pillar trim.
    Tip
    Depress both tabs to release the metal clip and pull the inside of the upper portion of the upper A-pillar. Then, pull the upper A-pillar upward to remove.
  7. Repeat the previous 3 steps for the RH side of the vehicle.
  8. Release the clips (x9) on the speaker grille assembly, then remove the assembly.
    CAUTION
    Be careful not to damage the IP or the windshield.

Install

  1. Install the speaker grille assembly. Press it in to confirm that all clips (x9) are engaged.
    CAUTION
    Be careful not to damage the IP or the windshield.
  2. Install the RH upper A-pillar trim.
    Note
    Slide the bottom of the trim along the IP and speaker grill. Attach the tether to the body side, then push clips in starting at the bottom. Pull the seal over the trim.
  3. Install the RH IP end cap. Engage all clips (x5).
  4. Install the lower section of the RH front primary seal.
  5. Repeat the previous 3 steps for the LH side of the vehicle.
  6. Move both front seats to their original positions.
  7. Raise both front windows.
  8. Close both front doors.
