Hub - Rear - LH (Remove and Replace)

Correction code 3103010012 FRT 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1096075-00-A Tool, Hub Puller, Hydraulic
  • 1062500-00-A Card, Magnetic Field Viewer
Parent topic: 3103 - Rear Suspension (Including Hubs)

Torque Specifications

Table 1. Torque Specifications: Hub - Rear - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x3) that attach the LH rear hub to the knuckle
85 Nm (62.7 lbs-ft)
  • 3 in extension
  • 18 mm socket
  • Flex head ratchet/flex head torque wrench
 Reuse

Remove

  1. Loosen the LH rear wheel lug nuts, but do not remove the wheel at this time. See Wheel Assembly (Remove and Install).
  2. Loosen the LH rear halfshaft nut.
  3. Remove the LH rear wheel. See Wheel Assembly (Remove and Install).
  4. Disconnect the LH rear EPB caliper connector.
  5. Remove and discard the bolts (x2) that attach the LH rear caliper to the LH rear knuckle, remove the caliper from the knuckle, and allow the caliper to hang from an S-hook.
    Tip
    Use of the following tool(s) is recommended:
    • External Torx E18
    • Ratchet/torque wrench
  6. Remove and discard the nut, and remove the washer that attach the LH halfshaft to the hub assembly.
    Note
    The washers are attached to the nut.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 32 mm deep impact socket
  7. Remove the bolt that attaches the LH rear brake rotor to the hub.
    Note
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 10 mm socket
    • 2 in extension
  8. Remove the LH rear rotor from the vehicle.
    Note
    Store the rotor hat down to reduce likelihood of damage to the rotor face.
  9. Install the hub puller onto the LH rear rotor, and then install and hand-tighten the puller washers (x5) and the lug nuts (x5) onto the rotor studs.
  10. Use the hub puller to free the halfshaft from the hub splines.
  11. Remove the lug nuts (x5) and the puller washers (x5) from the LH rear rotor studs, and then remove the hub puller from the rotor.
  12. Remove the bolts (x3) that attach the LH rear hub to the knuckle, and remove the hub from the vehicle.
    Warning
    A magnetic field from a pick-up tool or magnetic parts tray could permanently damage the magnetic pattern on the hub/bearing tone ring. Place the hub on a non-magnetic surface
    Note
    Use of the following tool(s) is recommended:
    • 3 in extension
    • 18 mm socket
    • Flex head ratchet/flex head torque wrench

Install

  1. Check the tone ring on the LH rear hub prior to installation: Use a magnetic field viewing card to make sure that the magnetic field on the tone ring is not damaged.
  2. Clean the mating surfaces of the LH rear hub and the wheel speed sensor with IPA wipers.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  3. Apply Molykote M-77 Lubricant Paste to the outboard side of the LH rear halfshaft assembly.
    Note
    Clean the halfshaft before applying if necessary.
    Note
    Apply no more than 1 gram to axle only.
  4. Line up the LH rear drive unit halfshaft splines, and then install the LH rear hub on the LH rear knuckle.
  5. Install the bolts (x3) that attach the LH rear hub to the LH rear knuckle.
    85 Nm (62.7 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • 3 in extension
    • 18 mm socket
    • Flex head ratchet/flex head torque wrench
  6. Install the washer and a new nut (1765133-00-A) that attach the LH halfshaft to the hub assembly.
    300 Nm (221.2 lbs-ft)
    Note
    The washers are attached to the nut. Install the nut by hand first and then use the power tool to torque.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 32 mm deep impact socket
  7. Install the LH rear rotor onto the vehicle.
  8. Install the bolt that attaches the LH rear brake rotor to the LH rear hub.
    5 Nm (3.7 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 10 mm socket
    • 2 in extension
  9. Install new bolts (x2) (1088969-00-B) that attach the LH rear caliper to the LH rear knuckle.
    83 Nm (61.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • External Torx E18
    • Ratchet/torque wrench
    Warning
    Upon installation, make sure that the flexible brake hose is not twisted and can bend forward. The flexible brake hose must not make contact with the wheel arch liner when the vehicle is lowered.
  10. Connect the LH rear EPB caliper connector.
  11. Install the LH rear wheel. See Wheel Assembly (Remove and Install).
  12. Tighten the LH rear halfshaft nut.
    300 Nm (221.2 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • Long Breaker Bar
    • 32 mm deep impact socket
  13. Exit the vehicle from "Towing" mode.
  14. Lower the vehicle. See Raise Vehicle - 2 Post Lift.
  15. Raise the LH front window and close the LH front door.
  16. Refer to the Alignment Requirement tables to determine whether an EPAS alignment check (EC) or four wheel alignment check (AC) is necessary. If performed, add the alignment check/adjust as a separate activity. See Alignment Requirement - Suspension.
