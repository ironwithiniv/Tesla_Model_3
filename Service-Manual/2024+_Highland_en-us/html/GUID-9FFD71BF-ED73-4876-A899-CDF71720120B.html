Cover - Hood Latch (Remove and Replace)

Correction code 1001020122 FRT 0.06 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1001 - Bumper / Fascia

Remove

  1. Remove the front tow hook. See Tow Hook - Front (Remove and Replace).
  2. Release the clips (x3) and guide tabs (x3) that attach the access panel to the underhood storage unit, and then carefully pull the panel away from the vehicle.
    CAUTION
    Do not completely remove the panel as a harness is still connected to it.
    Tip
    Grab the panel from the top, and then pull it rearward to release the clips.
  3. Disconnect the electrical harness from the access panel, and then remove the panel from the vehicle.

Install

  1. Connect the electrical harness to the access panel.
  2. Position the guide tabs (x3) into the grommets, and install the access panel into the underhood storage unit.
  3. Install the front tow hook. See Tow Hook - Front (Remove and Replace).
