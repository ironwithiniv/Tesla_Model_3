Assembly - Instrument Panel - Lower (Remove and Replace)

Correction code 1405010022 FRT 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1405 - Instrument Panel

Remove

  1. Open the LH front door and lower the LH front window.
  2. Partially release the LH front primary door seal.
  3. Remove the instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  4. Remove the LH footwell cover. See Cover - Footwell - Driver (Remove and Replace)
  5. Remove the screw and use the plastic trim tool to release the tabs (x13) that attach the lower instrument panel to the instrument panel, and then remove the panel from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless 1/4in Dr Ratchet
    • Torx T20 socket

Install

  1. Install the screw and fasten the tabs (x13) that attach the lower instrument panel to the instrument panel, and then install the panel to the vehicle.
    2.3 Nm (1.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Cordless 1/4in Dr Ratchet
    • Torx T20 socket
  2. Install the instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  3. Install the LH front primary door seal.
  4. Install the LH footwell cover. See Cover - Footwell - Driver (Remove and Replace)
  5. Raise the LH front window and close the LH front door.
