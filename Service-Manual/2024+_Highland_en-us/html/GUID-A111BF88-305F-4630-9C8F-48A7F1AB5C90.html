Reinforcement - Fascia - Front - LH (Remove and Replace)

Correction code 1001010022 FRT 0.48 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. Torque Specifications

Table 1. Torque Specifications: Reinforcement - Fascia - Front - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x2) that attach the fascia reinforcement to the front end of carrier
5 Nm (3.7 lbs-ft)
  • 10 mm deep socket
 Reuse

Remove

  1. Remove the front fascia assembly. See Fascia - Front (Remove and Install).
  2. Remove the bolts (x2) that attach the fascia reinforcement to the front end of carrier.
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm socket
  3. Release the tabs (x2) that lock the fascia reinforcement to the front end of carrier, then pull to remove the fascia reinforcement.

Install

  1. Lock the tab (x2) to install the fascia reinforcement to the front end of carrier .
  2. Install the bolts (x2) that attach the fascia reinforcement to the front end of carrier.
    5 Nm (3.7 lbs-ft)

    Tip
    Use of the following tool(s) is recommended:
    • 15 mm socket
  3. Install the front fascia assembly. See Fascia - Front (Remove and Install).
