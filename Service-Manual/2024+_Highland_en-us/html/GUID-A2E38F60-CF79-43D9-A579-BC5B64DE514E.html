Speaker - Pedestrian Warning (Remove and Replace)

Correction code 2121010712 FRT 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-10-08: Updated the procedure to perform the replacement by moving the lower portion of the right rear wheel arch liner aside.
Table 1. Torque Specifications: Speaker - Pedestrian Warning (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Screws (x3) that attach the pedestrian warning speaker to the vehicle
1.8 Nm (1.3 lbs-ft)
  • Torx T25 socket
 Reuse
Parent topic: 1754 - Pedestrian Warning Speaker

Remove

  1. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  2. Remove the RH rear wheel. See Wheel Assembly (Remove and Install).
  3. Release four push clips and partially move the RH rear wheel liner aside.
  4. Disconnect the electrical connector from the pedestrian warning speaker.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  5. Remove the clip that attaches the harness to the pedestrian warning speaker.
  6. Remove the screws (x3) that attach the pedestrian warning speaker to the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket
  7. Remove the pedestrian warning speaker.

Install

  1. Install the screws (x3) that attach the pedestrian warning speaker to the vehicle.
    1.8 Nm (1.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket
  2. Install the clip that attaches the harness to the pedestrian warning speaker.
  3. Connect the electrical connector to the pedestrian warning speaker.
  4. Install four push clips and move the RH rear wheel liner back to the original position.
  5. Install the RH rear wheel. See Wheel Assembly (Remove and Install).
  6. Lower the vehicle fully and remove the vehicle from the lift arms.
