Switch - Console Light (Remove and Replace)

Correction code 1519010252 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1519 - Center Console

Torque Specifications

Table 1. Torque Specifications: Switch - Console Light (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolt that attaches the lamp switch to the center console
0.35 Nm (3 lbs-in)
  • Torx T10 socket
  • Digital Torque Screwdriver 0.10Nm - 2.0Nm
 Reuse

Remove

  1. Remove the center console phone dock. See Phone Dock (Clip) - Center Console (Remove and Replace).
  2. Remove center console rear end panel. See Panel - Rear End - Center Console (Remove and Replace)
  3. Remove LH rear side panel from center console assembly. See Panel - Rear Side - Center Console - LH (Remove and Replace).
  4. Remove LH front side panel from center console assembly. See Carpet - Side - Center Console - LH (Remove and Replace).
  5. Remove LH center décor trim. See Hockey Stick Assembly -LH (with a Clip-secured Phone Dock) (Remove and Replace).
  6. Repeat step 3 through step 5 for the RH side of the vehicle.
  7. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  8. Disconnect LV battery power. See LV Power (Disconnect and Connect) (Modify)
  9. Remove the rear end module assembly. See Module - Rear End - Center Console (Remove and Install)
    Note
    No need to remove the rear end module from the assembly.
  10. Release the clip that attaches the center console harness to the center console.
  11. Release the tabs (x2) that attach the center console armrest lamp switch connector to the center console.
  12. Disconnect the lamp switch connector.
  13. Release the hook that attaches the lamp switch harness to the center console.
  14. Remove the bolt that attaches the lamp switch to the center console, and then remove the lamp switch from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T10 socket
    • Digital Torque Screwdriver 0.10Nm - 2.0Nm

Install

  1. Install the bolt that attaches the lamp switch to the center console.
    0.35 Nm (3 lbs-in)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T10 socket
    • Digital Torque Screwdriver 0.10Nm - 2.0Nm
  2. Secure the hook that attaches the lamp switch harness to the center console.
  3. Connect the lamp switch connector.
  4. Secure the tabs (x2) that attach the center console armrest lamp switch connector to the center console.
  5. Secure the clip that attaches the center console harness to the center console.
  6. Install the rear end module assembly. See Module - Rear End - Center Console (Remove and Install)
  7. Connect LV battery power. See LV Power (Disconnect and Connect) (Modify)
  8. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  9. Install LH center console décor trim. See Hockey Stick Assembly -LH (with a Clip-secured Phone Dock) (Remove and Replace).
  10. Install LH center console front side panel. See Carpet - Side - Center Console - LH (Remove and Replace).
  11. Install LH center console rear side panel. See Panel - Rear Side - Center Console - LH (Remove and Replace).
  12. Repeat step 9 through step 11 for the RH side of the vehicle.
  13. Install the center console rear end panel. See Panel - Rear End - Center Console (Remove and Replace)
  14. Install the center console phone dock. See Phone Dock (Clip) - Center Console (Remove and Replace).
