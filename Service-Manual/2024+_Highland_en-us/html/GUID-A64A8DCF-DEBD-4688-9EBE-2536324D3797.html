Window Motor / Regulator Assembly - Front - LH (Remove and Replace)

Correction code 1150010032 FRT 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
The side impact airbag deployment depends on the front door sensor's ability to detect a side impact from air pressure. Make sure that there are no uncovered holes in the front door shells. Additionally, always reinstall plugs or tape when servicing or inspecting the front doors and their components.
Table 1. Torque Specifications: Window Motor / Regulator Assembly - Front - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Nuts (x4) that attach the window regulator to the LH front door
10 Nm (7.4 lbs-ft)
  • 10 mm deep socket
 Reuse
Parent topic: 1150 - Door Glass and Regulators

Remove

  1. Remove the LH front door glass. See Glass - Door - Front - LH (Remove and Replace).
  2. Disconnect LV power. See LV Power (Disconnect and Connect) (Modify).
  3. Remove the front LH door closeout panel. See Closeout Panel - Door - Front - LH (Remove and Replace).
  4. Remove the plugs (x2) that cover the access holes to the window regulator nuts.
  5. Remove the nuts (x4) that attach the window regulator to the LH front door, and then remove the window regulator from the door.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket

Install

  1. Seat the window regulator into the door, and then install the nuts (x4) that attach the window regulator to the LH front door.
    10 Nm (7.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  2. Install the plugs (x2) that cover the access holes to the window regulator nuts.
  3. Install the front LH door closeout panel. See Closeout Panel - Door - Front - LH (Remove and Replace).
  4. Connect LV power. See LV Power (Disconnect and Connect) (Modify).
  5. Install the LH front door glass. See Glass - Door - Front - LH (Remove and Replace).
  6. Raise the LH front window, and then sit in the driver seat and close the LH front door.
  7. Unlock the vehicle gateway. See Gateway Unlock.
  8. On the touchscreen, tap Controls > Service Mode > Closures > Windows > Calibrate Windows > Start to calibrate the windows.
  9. Disable Service Mode. See Service Mode.
  10. Get out of the vehicle and close the LH front door.
