Speaker Grille - Front Door - LH (Remove and Replace)

Correction code 1513010052 FRT 0.36 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1513 - Door Trim

Remove

  1. Open the LH front door, and then lower the LH front window.
  2. Remove the LH front door reflector. See Reflector - Door - Front - LH (Remove and Replace).
  3. Remove the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
  4. Remove the LH front door puddle light. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  5. Remove the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  6. Remove the LH front door NVH pad. See NVH Pad - Door - Front - LH (Remove and Replace).
  7. Place the LH front door trim panel on a suitable work surface to avoid damage.
  8. Drill out the heat staked tabs (x7) that attach the LH front door speaker grille to the LH front door, and then remove the LH front door speaker grille.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Drill
    • 8 mm drill bit
    Note
    Avoid oversizing the holes.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  9. Use a razor blade and/or a round file to remove any debris from the work area.

Install

  1. Prepare the applicator and epoxy.
  2. Install the heat staked tabs (x7) that attach the LH front door speaker grille to the LH front door.
    Note
    Make sure all tabs are engaged.
    Note
    Apply the masking tape to the LH front door panel and verify the panel is flush.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  3. Apply the epoxy around the heat staked tabs (x7) and allow 10 minutes for the epoxy to set.
  4. Remove the masking tape from the LH front door panel and verify the LH front door speaker grille is properly secured.
  5. Install the LH front door NVH pad. See NVH Pad - Door - Front - LH (Remove and Replace).
  6. Install the LH front door puddle light. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  7. Install the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  8. Install the LH front door reflector. See Reflector - Door - Front - LH (Remove and Replace).
  9. Install the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
  10. Raise the LH front window, and then close the LH front door.
