1st Row Seat Belts -Service Kit - OCS (Rework)

Correction code 2005010011 FRT 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 2005 - Seatbelts

Procedure

  1. Open the front doors and lower the front windows.
  2. Move RH front seat fully rearward and upward.
  3. Disconnect the LV battery power. See LV Power (Disconnect and Connect) (Modify).
  4. Disconnect the Occupant Classification System (OCS) module connector underneath the RH front seat.
  5. Connect the OCS filter module to the seat.
  6. Release the strap that secures the lower seat upholstery.
  7. Secure the OCS filter module to the bottom of the seat.
    Note
    Slide the tab over the white bar before securing the clip. Make sure the harnesses are routed properly so there is not too much tension.
  8. Secure the lower seat upholstery strap.
    Note
    The strap may partially overlap the OCS filter module.
  9. Connect the OCS filter module to the OCS module.
    Note
    Route the harness between the existing seat harness and the bottom of the seat.
  10. Install the clips (x2) that attach the ferrite to the seat heater harness, and apply tapes to secure the ferrite.
    Note
    Make sure to completely cover the ferrite to eliminate the possibility of NVH concerns, and secure the ferrite to the harness to keep it from moving along the harness.
  11. Connect the LV battery power. See LV Power (Disconnect and Connect) (Modify).
  12. Move the RH front seat back to the original position.
  13. Raise the front windows and close the front doors.
