Harness - Steering Wheel (Remove and Replace)

Correction code 3205010012 FRT 0.36 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 3205 - Upper Column, Steering Wheel

Torque Specifications

Table 1. Torque Specifications: Harness - Steering Wheel (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolt that attaches the harness to the steering wheel
3.7 Nm (2.7 lbs-ft)
  • Cordless 1/4in Dr Ratchet
  • 4 in extension
  • Torx T20 socket
  • Torque Wrench 1/4in Dr Hexagon - 1060071-00-A
 Reuse

Remove

  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Disconnect the LV power. See LV Power (Disconnect and Connect) (Modify).
  3. Remove the driver airbag. See Airbag - Driver (Remove and Replace).
  4. Remove the steering wheel. See Steering Wheel (Remove and Replace).
  5. Remove the steering wheel lower spoker cover. See Cover - Lower Spoke - Steering Wheel (Remove and Replace).
  6. Release the harness from the LH steering wheel switch harness bracket.
  7. Release the harness from the RH steering wheel switch harness bracket.
  8. Disconnect the LH steering wheel switch connector.
  9. Disconnect the RH steering wheel switch connector.
  10. Disconnect the LH steering wheel heater connector.
  11. Disconnect the RH steering wheel heater connector.
  12. Remove the bolt that attaches the harness to the steering wheel.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless 1/4in Dr Ratchet
    • 4 in extension
    • Torx T20 socket
    • Torque Wrench 1/4in Dr Hexagon - 1060071-00-A

Install

  1. Install the bolt that attaches the harness to the steering wheel.
    3.7 Nm (2.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Cordless 1/4in Dr Ratchet
    • 4 in extension
    • Torx T20 socket
    • Torque Wrench 1/4in Dr Hexagon - 1060071-00-A
  2. Connect the RH steering wheel heater connector.
  3. Connect the LH steering wheel heater connector.
  4. Connect the RH steering wheel switch connector.
  5. Connect the LH steering wheel switch connector.
  6. Secure the harness to the LH steering wheel switch harness bracket.
  7. Secure the harness to the RH steering wheel switch harness bracket.
  8. Install the steering wheel lower spoker cover. See Cover - Lower Spoke - Steering Wheel (Remove and Replace).
  9. Install the steering wheel. See Steering Wheel (Remove and Replace).
  10. Install the driver airbag. See Airbag - Driver (Remove and Replace).
  11. Connect the LV power. See LV Power (Disconnect and Connect) (Modify).
  12. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
