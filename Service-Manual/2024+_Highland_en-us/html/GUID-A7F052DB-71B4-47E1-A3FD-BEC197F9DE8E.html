Trim - B-Pillar - Upper - LH (Remove and Replace)

Correction code 1518010052 FRT 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1518 - Pillar and Sill Trim

Remove

  1. Open all doors and lower all windows.
  2. Insert the seat belt release tool (1133787-00-A) into the bottom of the seatbelt pretensioner coupling to release the seatbelt from the pretensioner.
  3. Remove the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  4. Remove the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  5. Remove the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  6. Remove the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  7. Remove the LH lower B-pillar trim. See Trim - B-Pillar - Lower - LH (Remove and Replace).
  8. Remove the LH middle B-pillar trim. See Trim - B-Pillar - Middle - LH (Remove and Replace).
  9. Release the clips that attach the LH upper B-pillar trim to the body.
    Note
    Pull the bottom of the LH upper B-pillar trim towards the inside of the vehicle, and then pull the top of the trim to release the remaining upper clips.
  10. Guide the seatbelt retainer through the LH upper B-pillar trim, and then remove the trim from the vehicle.

Install

  1. Guide the seatbelt retainer through the LH upper B-pillar trim.
    Note
    Make sure the seat belt is not twisted.
  2. Lower the LH front seatbelt slider and LH height ajuster to their lowest positions to align the LH front upper B-pillar trim with the B-pillar.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  3. Align the locating pins (x3) to the slots, and then install the clips that attach the LH upper B-pillar trim to the vehicle.
    Note
    Make sure that the door seal corretly overlaps the LH upper B-pillar trim.
  4. Install the LH middle B-pillar trim. See Trim - B-Pillar - Middle - LH (Remove and Replace).
  5. Install the LH lower B-pillar trim. See Trim - B-Pillar - Lower - LH (Remove and Replace).
  6. Install the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  7. Install the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  8. Install the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  9. Install the 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  10. Install the LH front seatbelt pretensioner coupling onto the LH front seat pretensioner.
    Note
    Perform a pull-push-pull test to verify the pretensioner and coupling are fully seated.
  11. Raise all windows and close all doors.
