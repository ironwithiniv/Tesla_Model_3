Vehicle Controller - USB Assembly(with a Clip-secured Phone Dock) (Remove and Replace)

Correction code 1715010612 FRT 0.54 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Note
For screw-secured phone dock, use correction code 1715010622.
Parent topic: 1715 - Electronic Control Modules

Torque Specifications

Table 1. Torque Specifications: Vehicle Controller - USB Assembly(with a Clip-secured Phone Dock) (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x4) and datum that attach the USB hub to the center console
1.1 Nm (.8 lbs-ft)
  • Torx T20 socket
 Reuse

Remove

  1. Remove the rear end module assembly. See Module - Rear End - Center Console (Remove and Install)
    Note
    No need to remove the rear end module from the assembly.
  2. Disconnect the center console USB hub connector.
  3. Remove the bolts (x4) and datum that attach the USB hub to the center console, and then remove the USB hub from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket

Install

  1. Install the bolts (x4) and datum that attach the USB hub to the center console.
    1.1 Nm (.8 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  2. Connect the center console USB hub connector.
  3. Install the rear end module assembly. See Module - Rear End - Center Console (Remove and Install)
  4. Reinstall the vehicle firmware. See Software Reinstall - Touchscreen.
  5. Connect a laptop with Toolbox to the vehicle. See Toolbox (Connect and Disconnect).
  6. In Toolbox, click the Actions/Autodiag tab, and then type "TEST-SELF_VCUSB_X_HVAC-ACTUATOR" into the search field.
  7. Click TEST-SELF_VCUSB_X_HVAC-ACTUATORvia Toolbox:(link), click Run, and allow the routine to complete.
  8. Disconnect the laptop with Toolbox from the vehicle. See Toolbox (Connect and Disconnect).
  9. Exit the Service Mode Plus. See Service Mode Plus.
  10. Raise all four windows and close all four doors.
