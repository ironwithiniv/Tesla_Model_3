Retractor - Seatbelt - Driver (Remove and Replace)

Correction code 2005010062 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-04-13: Updated the specs of the bolt securing the LH front seat belt retractor to the base of the LH B-pillar from 15 mm to 13 mm.
CAUTION
Supplemental Restraint System (SRS) components can be hazardous if not serviced and handled correctly. See Airbag and Supplementary Restraint System (SRS) Precautions
CAUTION
In the event of an airbag or seatbelt pretensioner deployment, certain components must be replaced, and other components must be inspected for damage. Refer to the Collision Repair Manual for a specific list of items that must be inspected and replaced.

Remove

  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Remove the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  3. Disconnect the LV battery. See LV Power (Disconnect and Connect) (Modify).
  4. Insert the seat belt release tool (1133787-00-A) into the bottom of the seatbelt pretensioner coupling to release the seatbelt from the pretensioner.
  5. Remove the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  6. Remove the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  7. Remove the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  8. Remove the LH lower B-pillar trim. See Trim - B-Pillar - Lower - LH (Remove and Replace).
  9. Remove the LH middle B-pillar trim. See Trim - B-Pillar - Middle - LH (Remove and Replace).
  10. Remove the LH upper B-pillar trim. See Trim - B-Pillar - Upper - LH (Remove and Replace).
  11. Remove the LH 1st row seatbelt webbing guide bar. Webbing Guide Bar - Seatbelt - 1st Row (Single Side) (Remove and Replace).
  12. Remove and discard the patchbolt that attaches the LH upper D-ring to the adjustable top loop.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 3 in extension
    • Torx T50 socket
    • Ratchet/torque wrench
  13. Disconnect the electrical harness from the LH front seat belt retractor connector (x2).
    Note
    Slide the orange locking tabs on the both sides of the connector at the same time to release the connectors.
  14. Remove and discard the patch bolt that attaches the LH front seat belt retractor to the base of the LH B-pillar.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 13 mm deep socket
    • Ratchet/torque wrench
  15. Remove the LH front seatbelt retractor from the vehicle.

Install

  1. Connect the electrical harness to the seatbelt retractor connectors (x2).
    Note
    An audible click will be heard when the connectors are fully seated.
  2. Install the LH front seatbelt retractor into the vehicle.
    Note
    Make sure to engage the T-tab on the retractor with the slot on the base of the B-pillar.
  3. Install a new patch bolt to attach the LH front seat belt retractor to the base of the LH B-pillar.
    40 Nm (29.5 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 13 mm deep socket
    • Ratchet/torque wrench
  4. Install a new patchbolt to attach the LH upper D-ring to the top loop.
    30 Nm (22.1 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 3 in extension
    • Torx T50 socket
    • Ratchet/torque wrench
  5. Install the LH 1st row seatbelt webbing guide bar. Webbing Guide Bar - Seatbelt - 1st Row (Single Side) (Remove and Replace).
  6. Install the LH upper B-pillar trim. See Trim - B-Pillar - Upper - LH (Remove and Replace).
  7. Install the LH middle B-pillar trim. See Trim - B-Pillar - Middle - LH (Remove and Replace).
  8. Install the LH lower B-pillar trim. See Trim - B-Pillar - Lower - LH (Remove and Replace).
  9. Install the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  10. Install the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  11. Install the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  12. Install the 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  13. Install the LH front seatbelt pretensioner coupling onto the LH front seat pretensioner.
    Note
    Perform a pull-push-pull test to verify the pretensioner and coupling are fully seated.
    Note
    Perform a pull test on the webbing to make sure it is properly installed. It should be able to be pulled out smoothly at normal speeds and locked when pulled on quickly.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  14. Connect the LV battery. See LV Power (Disconnect and Connect) (Modify).
  15. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
