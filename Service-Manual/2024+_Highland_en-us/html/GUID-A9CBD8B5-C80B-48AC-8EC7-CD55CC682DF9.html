Brake Line Assembly - Side Sill (Remove and Replace)

Correction code 3303010032 3.84 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-08-18: Released new procedure.
Parent topic: 3303 - Brake Pipes and Hoses

Remove

  1. Remove the front and rear wheels. See Wheel Assembly (Remove and Install).
  2. Remove the HV battery. See HV Battery (RWD) (Remove and Replace) or HV Battery (AWD) (Remove and Replace).
    Note
    Do not follow the steps to discharge the HV battery outlined in the referenced procedures.
  3. Position an oil drain container under the LH front brake line area.
  4. Remove the LH front wheel arch liner. See Wheel Arch Liner - Front - LH (Remove and Replace).
  5. Remove the top and bottom side sill brake line tube nuts from the front brake pipe junction block.
  6. Remove the clip from the LH front junction block.
  7. Release the brake lines from the LH front junction block.
  8. Remove the LH rear wheel arch liner. See Wheel Arch Liner - Rear - LH (Remove and Replace).
  9. Place an oil drain container under the rear brake line junction box.
  10. Remove the LH and RH rear brake line tube nuts from the rear brake pipe junction block.
  11. Remove the clip from the LH rear junction block.
  12. Remove nut that attaches the LH rear junction block to the vehicle.
  13. Remove the LH rear junction block from the vehicle.
  14. Remove the clips that attache the side sill brake pipe assembly to the body.
  15. Remove the side sill brake pipe assembly.

  1. Position the side sill brake pipe assembly to the vehicle for installation.
  2. Install the clips (x4) that attach the side sill brake pipe assembly to the vehicle.
  3. Install the LH rear junction block to the vehicle.
    Note
    Put the LH and RH rear brake pipes in the connector.
  4. Install the nut that attaches the LH rear junction block to the vehicle.
  5. Install the black clip that attaches the brake lines at the LH rear junction block.
  6. Install the LH and RH rear brake line tube nuts to the LH rear brake pipe junction block.
  7. Install the LH rear wheel arch liner. See Wheel Arch Liner - Rear - LH (Remove and Replace).
  8. Install the brake lines into the LH front junction block.
  9. Install the clip that attaches the brake lines at LH front junction block.
  10. Install the side sill brake line tube nuts to the LH front brake pipe junction block.
  11. Install the LH front wheel arch liner. See Wheel Arch Liner - Front - LH (Remove and Replace).
  12. Install a new penthouse engagement seal onto the HV battery pack.
    Note
    This seal is a one time use item and should be replaced each time a HV battery pack is removed from the vehicle.
  13. Install the HV battery. See HV Battery (RWD) (Remove and Replace) or HV Battery (AWD) (Remove and Replace).
  14. Install the LH front and rear wheel arch liners. See Wheel Arch Liner - Front - LH (Remove and Replace).
  15. Install the front and rear wheels. See Wheel Assembly (Remove and Install).
