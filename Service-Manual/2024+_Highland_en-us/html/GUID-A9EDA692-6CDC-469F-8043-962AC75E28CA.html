Sensor - Impact Accelerator - Front Bumper - LH (Remove and Replace)

Correction code 2020010022 FRT 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
Make sure 12V/LV power has been disconnected for at least 1 minute before disconnecting the electrical harness from Supplementary Restraint System (SRS) components, such as Restraint Control Module, sensors, airbags, etc. Disconnect the 12V/LV battery and the First Responder Loop. Failure to do so can result in unintended safety system behaviors. For more information on SRS precautions, see Airbag and Supplementary Restraint System (SRS) Precautions.
Parent topic: 2020 - Sensors

Torque Specifications

Table 1. Torque Specifications: Sensor - Impact Accelerator - Front Bumper - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolt that attaches the LH front impact accelerometer sensor to the body
10 Nm (7.4 lbs-ft)
  • Cordless Ratchet/Impact Driver
  • 10 mm deep socket
  • Ratchet/torque wrench (for installation only)
 Reuse

Remove

  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Disconnect the LV power. See LV Power (Disconnect and Connect) (Modify).
  3. Remove the cabin intake duct. See Assembly - Fresh Air Gutter - HVAC (Remove and Replace).
  4. Remove the access panel. See Cover - Hood Latch (Remove and Replace).
  5. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  6. Disconnect the electrical connector from the LH front impact accelerometer sensor.
  7. Remove the bolt that attaches the LH front impact accelerometer sensor to the body.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 10 mm deep socket
    • Ratchet/torque wrench (for installation only)
  8. Remove the clip that attaches the sensor to the vehicle.

Install

  1. Install the clip that attaches the sensor to the vehicle.
  2. Install the bolt that attaches the LH front impact accelerometer sensor to the body.
    10 Nm (7.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 10 mm deep socket
    • Ratchet/torque wrench (for installation only)
  3. Connect the electrical connector to the LH front impact accelerometer sensor.
  4. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  5. Install the access panel. See Cover - Hood Latch (Remove and Replace).
  6. Install the cabin intake duct. See Assembly - Fresh Air Gutter - HVAC (Remove and Replace).
  7. Connect the LV power. See LV Power (Disconnect and Connect) (Modify).
  8. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
