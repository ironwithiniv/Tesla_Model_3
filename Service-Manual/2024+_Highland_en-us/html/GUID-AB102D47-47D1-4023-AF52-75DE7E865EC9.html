Cover - Footwell - Front Passenger (Remove and Replace)

Correction code 1405010062 FRT 0.06 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2024-07-25: Added steps for NA vehicles.
Parent topic: 1405 - Instrument Panel

Remove

  1. Open the RH front door and lower the RH front window.
  2. Move the RH front seat backward.
  3. Release the passenger footwell cover from the vehicle.
    • For APAC and EMEA vehicles: Release the clips that attach the passenger footwell cover to the vehicle.
    • For NA vehicles: Release the magnets (x2) that attach the passenger footwell cover to the vehicle.
  4. Disconnect the electrical connector from the puddle light, and then remove the footwell cover from the vehicle.

Install

  1. Connect the electrical connector to the puddle light, and then install the footwell cover to the vehicle.
  2. Install the passenger footwell cover to the vehicle.
    • For APAC and EMEA vehicles: Secure the clips that attach the passenger footwell cover to the vehicle.
    • For NA vehicles: Secure the magnets (x2) that attach the passenger footwell cover to the vehicle.
  3. Move the RH front seat to original position.
  4. Raise the RH front window and close the RH front door.
