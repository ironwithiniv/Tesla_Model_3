Phone Dock (Screw) - Center Console (Remove and Replace)

Correction code 1519011222 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-03-10: Added the firmware reinstallation step.
Note
There are 2 types of phone docks on the 2024+ Model 3: a clip-secured type on vehicles built before March 3rd, 2024, and a screw-secured type on vehicles built on or after March 3rd, 2024.
Parent topic: 1519 - Center Console

Torque Specifications

Table 1. Torque Specifications: Phone Dock (Screw) - Center Console (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Screws (x2) that attach the phone dock to the center console assembly
1.2 Nm (.9 lbs-ft)
  • Torx T20 bit
 Reuse
Screws (x3) that attach the inductive charger to the phone dock.
1 Nm (.7 lbs-ft)
  • Torx T20 bit
 Reuse

Remove

  1. Tilt the rear of the center console upwards, and pull the center console towards the rear of the vehicle. See Center Console (Remove and Replace).
  2. Remove the screws (x2) that attach the phone dock to the center console assembly.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 bit
  3. Disconnect the electrical connector, and then remove the phone dock from the instrument panel.
  4. Release the clips (x2), screw gaskets (x2), and guide tabs (x6) that attach the phone dock to the center console.
    Note
    Pull the phone dock assembly out from the bottom side along the tilt angle of the phone dock.
  5. Remove the screws (x3) that attach the inductive charger to the phone dock.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 bit
  6. Release the tabs (x2), datums (x2) and clips (x2) that attach the inductive charger to the phone dock, and then remove the inductive charger from the phone dock.
    Note
    Angle the inductive charger up and slide out of the phone dock.

Install

  1. Fasten the tabs (x2), datums (x2) and clips (x2) that attach the inductive charger to the phone dock.
    Note
    Slide the inductive charger datums into the phone dock, and then fully engage the tabs at the top of the phone dock.
  2. Install the screws (x3) that attach the inductive charger to the phone dock.
    1 Nm (.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 bit
  3. Fasten the clips (x2), screw gaskets (x2), and guide tabs (x6) that attach the phone dock to the center console.
    Note
    Press the phone dock from the bottom up to the inside along the tilt angle of the phone dock assembly.
  4. Connect the electrical connector, and then install the phone dock to the instrument panel.
  5. Install the screws (x2) that attach the phone dock to the center console assembly.
    1.2 Nm (.9 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 bit
  6. Install the center console. See Center Console (Remove and Replace).
  7. Reinstall the vehicle firmware. See Software Reinstall - Touchscreen.
