Knee Impact Foam - LH (NA) (Remove and Replace)

Correction code 1405010101 1405010102 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
  1. Open LH front door
  2. Lower LH front window
  3. Move LH front seat backward
  4. Open hood
  5. Remove rear underhood apron
    Note
    14x clips
  6. Power off vehicle from center display
    Note
    Via Controls > Safety > Power Off, Select Power Off button at warning dialogue box
  7. Disconnect LV battery and First Responder Loop
    Note
    2x connectors, Release green locking tab, Press black tab then pull black connector lock outwards to release connection, Release red lock tab on FRL, Allow 2 minutes for all electrical circuits to fully discharge
  8. Partially release LH front primary door seal
    Note
    Release lower section of LH front primary door seal
  9. Remove LH IP end cap
    Note
    5x clips, 2x guide tabs
  10. Release LH footwell cover
    Note
    2x magnets,1x guide tab
  11. Remove connectors from LH footwell cover
    Note
    1x connector, 1x OBDII connector, Release OBDII connector by depressing tabs from front side
  12. Remove LH knee airbag bolt covers
    Note
    2x covers
  13. Remove LH knee air bag bolts
    Note
    4x bolts, EP10, 8.5 Nm, Discard bolts after removal
  14. Remove LH knee airbag assembly
    Note
    1x connector, Peel back plastic film, Release by pulling back both white tabs simultaneously, Avoid straining harness, Only one tab visible in image matching tab is on opposite side
  15. Remove screws securing IP lower assembly to IP carrier
    Note
    1x screw, T20, 2.3 Nm
  16. Remove IP lower assembly from IP carrier
    Note
    13x tabs
  17. Remove screws securing IP carrier to cross car beam on lower LH side
    Note
    3x screws, T20, 2.3 Nm, 2x datums
  18. Remove screws securing IP carrier to cross car beam at lower center
    Note
    3x screws, T20, 2.3 Nm, 3x datums
  19. Remove LH Knee Impact Foam
    Note
    Carefully pull the IP carrier outwards to remove LH Knee Impact Foam
  20. Install LH Knee Impact Foam
    Note
    Carefully pull the IP carrier outwards to install LH Knee Impact Foam
  21. Install screws securing IP carrier to cross car beam at lower center
    Note
    3x screws, T20, 2.3 Nm, 3x datums
  22. Install screws securing IP carrier to cross car beam on lower LH side
    Note
    3x screws, T20, 2.3 Nm, 2x datums
  23. Install IP lower assembly to IP carrier
    Note
    13x tabs
  24. Install screws securing IP lower assembly to IP carrier
    Note
    1x screw, T20, 2.3 Nm
  25. Install LH knee airbag assembly
    Note
    1x connector, Ensure airbag connector is fully engaged, Apply knee airbag label over squib assembly
  26. Install LH knee air bag bolts
    Note
    4x bolts, EP10, 8.5 Nm, Install new bolts
  27. Install LH knee airbag bolt covers
    Note
    2x covers
  28. Install connectors to LH footwell cover
    Note
    1x connector, 1x OBDII connector, Ensure tabs engage on OBDII connector
  29. Install LH footwell cover
    Note
    2x magnets,1x guide tab
  30. Install LH IP end cap
    Note
    5x clips, 2x guide tabs
  31. Install LH front primary seal
    Note
    Verify seal is seated properly on all trim panels
  32. Connect First Responder Loop and LV battery
    Note
    2x connectors, Secure FRL first, Seat LV battery connection and push black connector lock inwards to secure, Engage green locking tab when fully seated
  33. Install rear underhood apron
    Note
    14x clips, Hold rear wall of frunk to keep from flexing while engaging front clips
  34. Close hood
  35. Move LH front seat to original position
  36. Raise LH front window
  37. Close LH front door
