Airvent Assembly - Center Console (Model 3 Standard) (Remove and Replace)

Correction code 15190401002 15190401001 FRT 0.54 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-09-05: Released new procedure.
Parent topic: 1519 - Center Console

Remove

  1. Remove the USB Panel assembly from the center console. See USB Panel Assembly - Center Console (Model 3 Standard) (Remove and Replace).
  2. Remove the screws (x6) that secure the rear end module assembly to the center console.
    Note
    Use of the following tool is recommended:
    • Torx T20 socket
  3. Remove the rear end module from the center console.
  4. Remove the screws (x2) from the rear vent cover panel, then remove the rear vent cover panel from air vent assembly
    Note
    Use of the following tool is recommended:
    • Torx T20 socket

Install

  1. Install the air vent assembly onto the rear vent cover panel. Tighten the screws (x2).
    1 Nm (.7 lbs-ft)
    Note
    Use of the following tool is recommended:
    • Torx T20 socket
  2. Position rear module onto center console. Align the datums (x2).
  3. Install the screws (x6) that secure the rear end module assembly to the center console.
    1 Nm (.7 lbs-ft)
    Note
    Use of the following tool is recommended:
    • Torx T20 socket
  4. Install the USB Panel assembly onto the center console. See USB Panel Assembly - Center Console (Model 3 Standard) (Remove and Replace).
