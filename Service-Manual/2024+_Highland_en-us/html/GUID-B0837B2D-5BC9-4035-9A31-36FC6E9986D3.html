Module - BLE - Interior (Remove and Replace)

Correction code 1745020022 FRT 0.90 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1137568-00-A Ethernet Cable, Diagnostics, Model 3
  • 1773092-00-A Diagnostic Harness Adapter - All Models
  • 1773595-00-A RJ45 Ethernet Cable

Remove

  1. Open all doors and lower all windows.
    Note
    If the vehicle is powered down, latch the rear doors to prevent accidental closure.
  2. Remove the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  3. Remove the LH upper A-pillar trim. See Trim - A-Pillar - Upper - LH (Remove and Replace).
  4. Remove the LH sun visor. See Sun Visor Assembly - LH (Remove and Replace).
  5. Remove the lower camera cover. See Camera Cover - Lower (Remove and Replace).
  6. Remove the rear view mirror. See Mirror - Rear View (Remove and Replace).
  7. Repeat step 2 through step 4 for the RH side of the vehicle.
  8. Remove the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  9. Remove the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  10. Remove the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  11. Remove the LH lower B-pillar trim. See Trim - B-Pillar - Lower - LH (Remove and Replace).
  12. Remove the LH middle B-pillar trim. See Trim - B-Pillar - Middle - LH (Remove and Replace).
  13. Remove the LH upper B-pillar trim. See Trim - B-Pillar - Upper - LH (Remove and Replace).
  14. Repeat step 8 and step 10 through step 13 for the RH side of the vehicle.
  15. Release the clips (x6) and locator pin that attach the front of the headliner to the vehicle.
    Note

    Take care not to bend the headliner when releasing the clips.

    If the metal clips are damaged during releasing, replace them with new metal clips.

  16. Disconnect the LV battery power. See LV Power (Disconnect and Connect) (Modify).
  17. Pull the red locking tab to disengage the lock, and then hold and pull it again to release the connector.
  18. Remove the bolt that attaches the BLE module to the vehicle, and then release the clip and remove the BLE module.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket

Install

  1. Seat the BLE module at the proper position, secure the clip, and then secure the bolt that attaches the BLE module to the vehicle.
    10 Nm (7.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  2. Engage the red locking tab to connect the connector.
  3. Align the locating pin of the front of the headliner to the slot, and then install the clips (x6) that attach the front of the headliner to vehicle.
    Note
    Make sure that the door seal correctly overlaps the LH upper B-pillar trim.
  4. Install the rear view mirror. See Mirror - Rear View (Remove and Replace).
  5. Install the lower camera cover. See Camera Cover - Lower (Remove and Replace).
  6. Install the LH sun visor. See Sun Visor Assembly - LH (Remove and Replace).
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  7. Install the LH upper A-pillar trim. See Trim - A-Pillar - Upper - LH (Remove and Replace).
  8. Repeat step 7 and step 6 for the RH side of the vehicle.
  9. Connect the LV battery power. See LV Power (Disconnect and Connect) (Modify).
  10. Move both front seats forward.
  11. Install the LH upper B-pillar trim. See Trim - B-Pillar - Upper - LH (Remove and Replace).
  12. Install the LH middle B-pillar trim. See Trim - B-Pillar - Middle - LH (Remove and Replace).
  13. Install the LH lower B-pillar trim. See Trim - B-Pillar - Lower - LH (Remove and Replace).
  14. Install the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  15. Install the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  16. Repeat step 11 through step 15 for the RH side of the vehicle.
  17. Install the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  18. Install the 2nd row LH and RH seat side bolsters. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  19. Move both front seats back to the original position.
  20. Locally connect a laptop with Toolbox to the vehicle. See Toolbox (Connect and Disconnect).
  21. Run the BLE Endpoint Communication Check routine: TEST-SELF_VCSEC_X_ENDPOINT-COMMvia Toolbox:(link)
  22. Disconnect the laptop with Toolbox from the vehicle. See Toolbox (Connect and Disconnect).
  23. Verify that network connectivity is available to the vehicle by the words "3G", "4G", "LTE", or the WiFi icon appearing in the upper right corner of the touchscreen.
  24. Enable Service Mode. See Service Mode.
  25. Reinstall the software through service UI. See Software Reinstall - Touchscreen.
  26. Disable Service Mode. See Service Mode.
  27. Raise all windows and close all doors.
