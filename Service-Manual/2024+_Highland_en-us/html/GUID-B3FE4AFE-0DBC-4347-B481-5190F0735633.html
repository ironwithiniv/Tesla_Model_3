Module - BLE - Rear (Remove and Replace)

Correction code 1745020032 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1745 - Keyless Entry and Security

Remove

  1. Remove the rear fascia. See Fascia Assembly - Rear (Remove and Install).
  2. Disconnect the rear BLE module electrical connector.
  3. Release the tab and datums (x2) that attach the BLE module to the rear fascia, and then remove the BLE module from the vehicle.

Install

  1. Fasten the tab and datums (x2) that attach the BLE module to the rear fascia.
  2. Connect the rear BLE module electrical connector.
  3. Install the rear fascia. See Fascia Assembly - Rear (Remove and Install).
  4. Connect a laptop with Toolbox to the vehicle. See Toolbox (Connect and Disconnect).
  5. In Toolbox, click the Actions/Autodiag tab, type "Endpoint" in the search field.
  6. Click on TEST-SELF_VCSEC_X_ENDPOINT-COMMvia Toolbox:(link), and then click Run Networkand allow the routine to complete.
  7. Disconnect the laptop with Toolbox from the vehicle. See Toolbox (Connect and Disconnect).
  8. Reinstall the vehicle firmware. See Software Reinstall - Touchscreen.
