Fluid Coupling (90 Degrees) - Front Drive Inverter (Remove and Replace)

Correction code 3920010052 FRT 2.64 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:

Parent topic: 3920 - Front Drive Inverter

Remove

  1. Remove the front subframe assembly. See Subframe Assembly - Front (RWD) (Remove and Replace).
  2. Release the spring clip that attaches the front drive unit inverter inlet hose to the 90 degrees fluid coupling.
    Tip
    Use of the following tool(s) is recommended:
    • Foldable Funnel (1463565-00-A)
    • Medium flat head screwdriver
    • Coolant hose plug kit (1135762-00-A)
  3. Remove the LH front drive unit mount from the front drive unit. See Mount Assembly - Front Drive Unit - LH (3DU) (Remove and Replace).
  4. Remove and discard the bolt that attaches the 90 degrees fluid coupling to the front drive inverter assembly, and then remove and discard the 90 degrees fluid coupling.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Drill
    • Torx T25 socket
    • Flex head ratchet/flex head torque wrench
    • Ratchet/torque wrench
    • Torx T25 bit

Install

  1. Install a new bolt to attach the 90 degrees fluid coupling to the front drive inverter assembly.
    6 Nm (4.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Drill
    • Torx T25 socket
    • Flex head ratchet/flex head torque wrench
    • Ratchet/torque wrench
    • Torx T25 bit
  2. Perform a coolant pressure test:
    1. Install the coolant pressure test plug adapter to the straight fluid coupling.
    2. Install the coolant pressure adapter to the 90 degrees fluid coupling.
    3. Attach the coolant pressure tester to the pressure fitting adapter.
    4. Attach the coolant pressure tester to the compressed air line.
    5. Set pressure to 50 psi, and then slowly open the valve on the pressure regulator. Allow the pressure to reach 50 psi.
    6. Close the valve, and wait for 16 seconds for the pressure to settle, and then record the pressure reading.
    7. Wait for another 12 seconds, and then record the reading.
      Note
      Pressure may not have dropped by more than 0.1 psi. If pressure test fails, confirm that fluid couplings are fully seated, and then redo the pressure test.
    8. Remove the coolant pressure test components from the inverter.
  3. Secure the spring clip that attaches the front drive unit inverter inlet hose to the 90 degrees fluid coupling.
    Note
    Perform a push-pull-push test to make sure that the hose is fully secured.
    Tip
    Use of the following tool(s) is recommended:
    • Foldable Funnel (1463565-00-A)
    • Medium flat head screwdriver
    • Coolant hose plug kit (1135762-00-A)
  4. Install the LH front drive unit mount to the front drive unit. See Mount Assembly - Front Drive Unit - LH (3DU) (Remove and Replace).
  5. Install the front subframe assembly. See Subframe Assembly - Front (RWD) (Remove and Replace).
