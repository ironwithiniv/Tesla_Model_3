Motor - Seat Height - Front Passenger Seat (Remove and Replace)

Correction code 1301020152 FRT 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-08-31: Released new procedure.

  • Torx T50 socket
 Replace 1109796-00-C
Rear bolt that attaches the motor to the frame
18 Nm (13.3 lbs-ft)
  • Torx T45 socket
 Replace 1106615-00-C

Remove

  1. Open the front doors and lower the front windows.
  2. Open the RH rear door and lower the RH rear window.
  3. Remove the front passenger seat outboard side shield. See Side Shield - Outboard - LH (Remove and Replace).
  4. Disconnect the height motor electrical connector.
  5. Remove and discard the foremost bolt that attaches the driver seat height motor to the seat frame.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket
  6. Remove and discard the rear bolt that attaches the driver seat height motor to the seat frame, and then remove the motor from the assembly.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T45 socket

Install

  1. Install the driver seat height motor to the seat frame, and then install a new foremost bolt that attaches the driver seat height motor to the seat frame.
    23 Nm (17.0 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket
  2. Install a new rear bolt that attaches the motor to the frame.
    18 Nm (13.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T45 socket
  3. Connect the height motor electrical connector.
  4. Install the front passenger seat outboard side shield. See Side Shield - Outboard - LH (Remove and Replace).
  5. Raise the RH rear window and close the RH rear door.
  6. Enable Service Mode. See Service Mode.
  7. Unlock the vehicle gateway. See Gateway Unlock.
  8. Perform the following routine to calibrate the RH front seat: PROC_VCRIGHT_SEAT-CALIBRATEvia Service Mode:Low Voltage ➜ Seats ➜ Calibrate Seatvia Toolbox:(link)
  9. Disable Service Mode. See Service Mode.
  10. Move the RH front seat to its original position.
  11. Raise the front windows and close the front doors.
