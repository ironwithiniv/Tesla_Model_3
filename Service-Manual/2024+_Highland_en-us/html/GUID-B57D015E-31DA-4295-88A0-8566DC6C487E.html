NVH Pad - Door - Front - LH (Remove and Replace)

Correction code 1513010072 FRT 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1513 - Door Trim

Remove

  1. Open the LH front door, and then lower the LH front window.
  2. Remove the LH front door reflector. See Reflector - Door - Front - LH (Remove and Replace).
  3. Remove the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
  4. Remove the LH front door puddle light. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  5. Remove the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  6. Release the LH front door NVH pad from the tabs (x4), and then remove it from the LH front door trim panel.

Install

  1. Install the LH front door NVH pad onto the LH front door trim panel.
  2. Install the LH front door puddle light. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  3. Install the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  4. Install the LH front door reflector. See Reflector - Door - Front - LH (Remove and Replace).
  5. Install the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
  6. Raise the LH front window, and then close the LH front door.
