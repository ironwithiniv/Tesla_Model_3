Harness - Front End Module (Remove and Replace)

Correction code 1710030042 FRT 0.78 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-03-30: Updated the removal method.
Parent topic: 1710 - Harnesses

Remove

  1. Disconnect the LV power. See LV Power (Disconnect and Connect) (Modify).
  2. Remove the windshield washer reservoir. See Assembly - Reservoir - Windshield Washer (Remove and Replace).
  3. Disconnect the front acceleration sensor connector.
    CAUTION
    Do not push down on the red tab. Pull the red tab to release the connector lock.
  4. Disconnect the active grille shutter electrical connector.
    CAUTION
    Do not push down on the red tab. Pull the red tab to release the connector lock.
  5. Disconnect the electrical harness connector from the hood latch actuator.
  6. Disconnect the electrical harness connector from the hood latch switch.
    CAUTION
    Do not push down on the red tab. Pull the red tab to release the connector lock.
  7. Remove the ambient temperature sensor cover from the active griller shutter, and then disconnect the sensor electrical connector.
  8. Disconnect the LH and RH front end module electrical harness connectors.
  9. Release the clips that attach the front end module electrical harness connectors to the front end carrier.
  10. Release the clips (x4) that attach the front end module harness to the vehicle, then remove the harness from the vehicle.

Install

  1. Position the FEM electrical harness into the vehicle, and then install the clips (x4) that attach the electrical harness to the front end carrier.
  2. Install the clips that attach the front end module electrical harness connectors to the front end carrier.
  3. Connect the LH and RH front end module electrical harness connectors.
  4. Connect the ambient sensor electrical connector, and then install the sensor cover onto the active grille shutter.
  5. Connect the electrical harness connector to the hood latch switch.
  6. Connect the electrical harness connector to the hood latch actuator.
  7. Connect the active grille shutter electrical connector.
  8. Connect the front acceleration sensor connector.
  9. Install the windshield washer reservoir. See Assembly - Reservoir - Windshield Washer (Remove and Replace).
  10. Connect the LV power. See LV Power (Disconnect and Connect) (Modify).
