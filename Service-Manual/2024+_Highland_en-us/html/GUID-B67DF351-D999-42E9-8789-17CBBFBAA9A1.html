USB Module - Glove Box (Remove and Replace)

Correction code 1405021112 FRT 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2024-07-16: Added knee airbag steps for NA vehicles.
Parent topic: 1405 - Instrument Panel

Torque Specifications

Table 1. Torque Specifications: USB Module - Glove Box (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x2) that attach the glove box USB module to the glove box
1.5 Nm (1.1 lbs-ft)
  • Torx T20 socket
  • Ratchet/torque wrench
  • Torque Wrench 1/4in Dr Hexagon - 1060071-00-A (for installation only)
 Reuse

Remove

  1. Remove the passenger footwell cover. See Cover - Footwell - Front Passenger (Remove and Replace).
  2. For NA vehicles only: Remove the RH knee airbag assembly. See Airbag - Knee - RH (Remove and Replace).
  3. Remove the clips (x2) that attach the passenger footwell duct to the vehicle.
  4. Disconnect the glove box USB cable from the car computer.
    Note
    Release the locking tab first, and then disconnect the connector.
  5. Remove the bolts (x2) that attach the glove box USB module to the glove box, and then remove the glove box USB module from the glove box.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
    • Ratchet/torque wrench
    • Torque Wrench 1/4in Dr Hexagon - 1060071-00-A (for installation only)

Install

  1. Install the bolts (x2) that attach the glove box USB module to the glove box.
    1.5 Nm (1.1 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
    • Ratchet/torque wrench
    • Torque Wrench 1/4in Dr Hexagon - 1060071-00-A (for installation only)
  2. Connect the glove box USB cable to the car computer.
    Note
    Engage the locking tab after connecting the connector.
  3. Install the clips (x2) that attach the passenger footwell duct to the vehicle.
  4. For NA vehicles only: Install the RH knee airbag assembly. See Airbag - Knee - RH (Remove and Replace).
  5. Install the passenger footwell cover. See Cover - Footwell - Front Passenger (Remove and Replace).
  6. Connect a laptop with Toolbox to the vehicle. See Toolbox (Connect and Disconnect).
  7. In Toolbox, select the Actions/Autodiag tab, and then search for "TEST-BASH_CID_X_USB3-GLOVEBOX".
  8. Click TEST-BASH_CID_X_USB3-GLOVEBOXvia Toolbox:(link), and then click Run.
    Note
    After the routine ends, click the "X" at the upper right corner of the prompt.
  9. Disconnect the laptop with Toolbox from the vehicle. See Toolbox (Connect and Disconnect).
  10. Close the LH front door.
