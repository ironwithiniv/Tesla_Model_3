Handle - Exterior Release - Trunk (Remove and Replace)

Correction code 1120010012 FRT 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-12-26: Added the trunk latch cover steps.
Parent topic: 1120 - Trunk

Remove

  1. Remove the trunk latch cover. See Cover - Latch - Trunk (Remove and Replace).
  2. Remove the trunk lid trim. See Trim - Lid - Trunk (Remove and Replace).
  3. Use masking tape to mark the location of the trunk striker.
  4. Disconnect the electrical connectors from the trunk exterior release switch and the rear facing camera.
  5. Release the clips that attach the trunk exterior release switch to the liftgate.
  6. Remove the switch from the vehicle.

Install

  1. Install the switch to the vehicle.
  2. Install new clips that attach the trunk exterior release switch to the trunk.
  3. Connect the electrical connectors to the trunk exterior release switch and the rear facing camera.
  4. Install the trunk lid trim. See Trim - Lid - Trunk (Remove and Replace).
  5. Install the trunk latch cover. See Cover - Latch - Trunk (Remove and Replace).
  6. Locally connect a laptop with Toolbox 3 to the vehicle. See Toolbox (Connect and Disconnect).
  7. In Toolbox, perform the following steps.
    1. Click the Actions tab, type "Calibration Mode" into the search field, click PROC_DAS_X_ENTER-CALIBRATION-MODEvia Toolbox:(link), click Run, and allow the routine to complete.
    2. Click the Actions tab, type "Back Up" into the search field, click PING-HTTP_DAS_X_BACKUP-CAMERA-SCRIPTvia Toolbox:(link), change the timeout to 100, click Run, and allow the routine to complete.
    3. Click the Actions tab, type "Calibration Mode" into the search field, click PROC_DAS_X_EXIT-CALIBRATION-MODEvia Service Mode Plus:Driver Assist ➜ Cameras ➜ Exit Factory Calibration Modevia Toolbox:(link), click Run, and allow the routine to complete.
  8. On the touchscreen, tap the Service Mode "wrench" (at the bottom of the touchscreen UI), and then tap Driver Assist > Cameras > Clear Camera Calibration, select RearView in the Camera Selection drop list, click Run, and allow the routine to complete.
  9. Disconnect the laptop.
  10. Press and hold the Exit Service Mode button on the UI to exit Service Mode Plus.
  11. Verify that the rear facing camera works properly.
  12. Raise the LH front window and close the LH front door.
