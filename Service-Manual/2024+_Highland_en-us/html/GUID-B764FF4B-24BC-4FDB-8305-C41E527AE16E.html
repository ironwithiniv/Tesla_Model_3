Coax Cable - Side Repeater - Front - LH and RH (Overlay) (Remove and Replace)

Correction code 17403032 2.88 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.

Parent topic: 1710 - Harnesses

Overlay

  1. Raise and support vehicle
    Note
    Ensure vehicle is not charging
  2. Open LH front door
  3. Lower LH front window
  4. Open RH front door
  5. Lower RH front window
  6. Move RH front seat backward
  7. Remove the wiper module. See Wiper Module (LHD) (Remove and Replace).
  8. Remove fresh air intake assembly
    Note
    2x studs, Lift cowl as needed
  9. Remove RH front wheel center cap
    Note
    1x cap, Pull the inner side of the adjacent 2 claws on the wheel center cap by hands
  10. Loosen RH front wheel nuts
    Note
    5x nuts, 21mm, 175 Nm
  11. Remove LH front wheel center cap
    Note
    1x cap, Pull the inner side of the adjacent 2 claws on the wheel center cap by hands
  12. Loosen LH front wheel nuts
    Note
    5x nuts, 21mm, 175 Nm
  13. Raise vehicle partially and lower lift onto locks
    Note
    Set vehicle to a comfortable working height, Make sure there's an audible click of the locks on both sides before lowering, Otherwise vehicle may tilt to the side
  14. Remove RH front wheel
    Note
    5x nuts, 21mm, 175 Nm
  15. Partially remove RH front wheel liner
    Note
    8x clips, 1x bolt, 10mm, 5 Nm
  16. Disconnect the front harness connectors for the RH side repeater and camera
    Note
    2x connectors, Release locking tabs
  17. Remove LH front wheel
    Note
    5x nuts, 21mm, 175 Nm
  18. Partially remove LH front wheel liner
    Note
    8x clips, 1x bolt, 10mm, 5 Nm
  19. Disconnect the front harness connectors for the LH side repeater and camera
    Note
    2x connectors, Release locking tabs
  20. Lower vehicle partially and set lift onto locks
    Note
    Raise lift off locks, then hold lock release lever to keep locks free while vehicle is lowered, Set vehicle to comfortable working height
  21. Power off vehicle from center display
    Note
    Via Controls > Safety > Power Off, Select Power Off button at warning dialog box
  22. Disconnect LV battery and first responder loop
    Note
    2x connectors, Ensure that one minute has passed after window movement before performing the power-off, Release green locking tab, Press black tab then pull black connector lock outwards to release connection, Release red lock tab on FRL, Allow 2 minutes for all electrical circuits to fully discharge
  23. Disconnect thermal sub-harness from front controller
    Note
    1x connector, Depress locking tab and rotate to release
  24. Remove bolts securing front controller shield assembly and remove from vehicle
    Note
    2x bolts, 10mm, 8.5 Nm
  25. Disconnect front controller harness connectors
    Note
    5x connectors, 1x harness guide, Release locking tab if equipped
  26. Remove bolt securing ground cable to front controller
    Note
    1x bolt, 10mm, 8.5 Nm,
  27. Remove bolts securing front controller
    Note
    3x bolts, 10mm, 10 Nm
  28. Tilt front controller forward for access
    Note
    Lift cowl screen up appropriately
  29. Release LV negative harness clip from front controller
    Note
    1x clip
  30. Remove front controller from vehicle
    Note
    1x tab
  31. Release RH footwell cover
    Note
    2x magnets, 1x guide tab, 1x connector
  32. Partially release RH front primary door seal
    Note
    Release lower section of RH front primary door seal
  33. Remove RH IP end cap
    Note
    5x clips, 2x guide tabs
  34. Remove RH lower A-pillar trim
    Note
    4x clips, 2x guide tabs, Pull rear of lower A-pillar upward to release clip then pull rearward to release front tabs from carpet
  35. Remove RH knee airbag bolt covers
    Note
    2x covers
  36. Remove RH knee airbag bolts
    Note
    4x bolts, EP10, 8.5 Nm, Discard bolts after removal, brake loose e10 by hand then use e-ratchet to back off hardware
  37. Remove RH knee air bag assembly
    Note
    1x air bag connector, 1x connector, Peel back plastic film, Release by pulling back both white tabs simultaneously, Avoid straining harness, Only one tab visible in image matching tab is on opposite side
  38. Remove clips securing passenger footwell duct
    Note
    2x clips
  39. Disconnect glove box USB cable connector from car computer
    Note
    1x connector, Release locking tab then release connector
  40. Remove screws securing glove box to IP
    Note
    4x screws, T20, 2.3 Nm
  41. Release glove box from IP assembly
    Note
    10x clips, 3x locator pins, 1x datum, Avoid damage to electromagnetic switch
  42. Remove glove box
    Note
    2x connectors
  43. Remove RH passenger footwell duct from HVAC module
  44. Disconnect RH IP air wave duct thermistor connector
    Note
    1x connector
  45. Remove RH IP air wave duct from HVAC module
  46. Unfold RH front main cabin carpet back to original position
    Note
    1x locator clip
  47. Release windshield heater connecter
    Note
    1x connector
  48. Release RH grommet from body
  49. Remove electrical tape securing harness bundle to rubber dust boot
    Note
    Use a razor blaze, carefully cut electrical tape away to expose rubber dust boot
  50. Remove locking pin from connector
    Note
    Carefully pry pin out of connector and fully remove locking pin
  51. Remove coax cable needed for the side repeater overlay terminal 2 (LHS)
    Note
    Inspect all components for damage
  52. Remove coax cable needed for the side repeater overlay terminal 1 (RHS)
    Note
    Inspect all components for damage
  53. Apply harness tape onto LH coax overlay cable before installation
    Note
    Use Anti-abrasion tape and wrap the entire length of the coax cable to protect the cable for damage when it is in the vehicle
  54. Apply harness tape onto RH coax overlay cable before installation
    Note
    Use Anti-abrasion tape and wrap the entire length of the coax cable to protect the cable for damage when it is in the vehicle
  55. Release frunk harness cover
    Note
    3x tabs
  56. Position M3 LH coax overlay cable into place, Place through LH wheel liner
    Note
    Pull till you have roughly 12 inches of cable towards the interior of the vehicle
  57. Pull LH coax overlay cable through frunk harness
    Note
    Pull harness towards car computer, Route under brake booster lower connector
  58. Tape coax overlay onto fish nylon tape
  59. Release frunk harness cover
    Note
    3x tabs
  60. Position M3 LH coax overlay cable into place, Place through LH wheel liner
    Note
    Pull till you have roughly 12 inches of cable towards the interior of the vehicle
  61. Pull LH coax overlay cable through frunk harness
    Note
    Pull harness towards car computer, Route under brake booster lower connector
  62. Tape coax overlay onto fish nylon tape
  63. Pull LH coax overlay cable through bulkhead and into interior cabin
  64. Remove nylon fish tape
    Note
    Remove tape the pull nylon fish tape out of vehicle
  65. Pull RH coax overlay cable through RH grommet harness
    Note
    Pull harness toward car computer under RH grommet main harness
  66. Position RH coax overlay cable into place, Place through RH wheel liner
    Note
    Pull till you have roughly 6 inches of cable towards the interior of the vehicle
  67. Tape coax overlay onto fish nylon tape
  68. Pull RH coax overlay cable through bulkhead and into interior cabin
  69. Remove nylon fish tape
    Note
    Remove tape the pull nylon fish tape out of vehicle
  70. Disconnect side repeater cameras connector from car computer
    Note
    1x locking connector
  71. Remove locking pin from side repeater cameras connector
    Note
    Carefully pry pin out of connector and fully remove locking pin
  72. Remove coax terminal 2 (LHS) cable from connector
    Note
    Inspect all components for damage
  73. Remove coax terminal 1 (RHS) cable from connector
    Note
    Inspect all components for damage
  74. Insert new side repeater coax terminal 1 (RHS) cable onto side repeater cameras connector
    Note
    Ensure both coax cables are fully seated into connector, Audible locking and flush mounting to confirm
  75. Insert new side repeater coax terminal 2 (LHS) cable onto side repeater cameras connector
    Note
    Ensure both coax cables are fully seated into connector, Audible locking and flush mounting to confirm
  76. Secure locking pin to connector
    Note
    Align tabs of lock in connector housing, Ensure flush installation of locking pin to connector housing
  77. Connect side repeater cameras connector onto car computer
    Note
    1x locking connector
  78. Position LH coax overlay cable onto frunk main harness, Secure cable onto harness using zip ties
    Note
    7x zip-ties, Trim off excess material after harness has been secured
  79. Cut off the vehicle side repeater coax terminal and tape to vehicle harness
    Note
    Cut the coax connector only
  80. Connect front harness connectors for LH side repeater and camera
    Note
    2x connectors, Secure locking tabs
  81. Position RH coax overlay cable onto frunk main harness grommet, Secure cable onto harness using zip ties
    Note
    3x zip-ties, Trim off excess material after harness has been secured
  82. Cut off the vehicle side repeater coax terminal and tape to vehicle harness
    Note
    Cut the coax connector only
  83. Connect front harness connectors for the RH side repeater and camera
    Note
    2x connectors, Secure locking tabs
  84. Secure RH grommet from body
    Note
    Use electrical tape to wrap the end of the dust boot
  85. Secure frunk harness cover
    Note
    3x tabs
  86. Secure windshield heater connector
    Note
    1x connector
  87. Install LH front wheel liner to vehicle
    Note
    8x clips, 1x bolt, 10mm, 5 Nm
  88. Install LH front wheel
    Note
    5x nuts, 21mm, 175 Nm, Start lug nuts by hand before using power tool
  89. Install RH front wheel liner to vehicle
    Note
    8x clips, 1x bolt, 10mm, 5 Nm
  90. Install RH front wheel
    Note
    5x nuts, 21mm, 175 Nm, Start lug nuts by hand before using power tool, Torque at later step
  91. Lower vehicle until tires are touching ground
    Note
    Raise lift off locks, then hold lock release lever to keep locks free while vehicle is lowered
  92. Torque LH front wheel
    Note
    5x nuts, 21mm, 175 Nm
  93. Install LH front wheel center cap
    Note
    1x cap, Ensure that the cap is installed in place
  94. Torque RH front wheel
    Note
    5x nuts, 21mm, 175 Nm
  95. Install RH front wheel center cap
    Note
    1x cap, Ensure that the cap is installed in place
  96. Place front controller into vehicle for installation
    Note
    1x tab
  97. Secure LV negative harness clip from front controller
    Note
    1x clip
  98. Tilt front controller backward for installation
    Note
    Lift cowl screen up appropriately
  99. Install bolts securing front controller
    Note
    3x bolts, 10mm, 10 Nm
  100. Install bolt securing ground cable to front controller
    Note
    1x bolt, 10mm, 8.5 Nm,
  101. Connect front controller harness connectors
    Note
    5x connectors, 1x harness guide, Secure locking tab, if equipped
  102. Install front controller shield to front controller
    Note
    2x bolts, 10mm, 8.5 Nm
  103. Connect thermal sub-harness to front controller
    Note
    1x connector, Rotate fully to secure locking tab
  104. Install the wiper module. See Wiper Module (LHD) (Remove and Replace).
  105. Install fresh air intake assembly
    Note
    2x studs, Lift cowl as needed
  106. Position frunk assembly to vehicle
    Note
    8x clips, 3x locator pins, Ensure clips are aligned at thermal beam, Replace any clips if broken or missing
  107. Install bolts securing frunk assembly
    Note
    4x bolts, 10mm, 5 Nm, Number of bolts may vary depending on build date
  108. Install access panel to frunk assembly
    Note
    3x clips, 1x connector, Frunk safety switch, 3x guide tabs, Align 3x tabs then push forward to secure clips
  109. Install fresh air gutter assembly
    Note
    3x clips
  110. Install RH IP air wave duct to HVAC module
  111. Install clips securing RH IP air wave duct
    Note
    2x push clips
  112. Connect thermistor connector RH IP air wave duct
    Note
    1x connector
  113. Install RH passenger footwell duct to HVAC module
  114. Position glove box assembly
    Note
    2x connectors
  115. Install glove box into IP assembly
    Note
    10x clips, 3x locator pin, 1x datum, If necessary, Replace any clips that are broken
  116. Install screws securing glove box assembly to IP assembly
    Note
    4x screws, T20, 2.3 Nm
  117. Connect glove box USB cable to car computer
    Note
    1x connector, Engage locking tab
  118. Install clips securing passenger footwell duct
    Note
    2x push clips, Ensure that the footwell duct is installed in place
  119. Install RH IP end cap
    Note
    5x clips, 2x guide tabs
  120. lnstall seat lower section of RH front primary seal
    Note
    Verify seal is seated properly on all trim panels
  121. Install RH knee air bag assembly
    Note
    1x air bag connector, 1x connector, Ensure airbag connector is fully engaged, Place plastic film back over squib assembly
  122. Install RH knee airbag bolts
    Note
    4x bolts, EP10, 8.5 Nm, use socket wrench to start hardware by hand to avoid cross threading. Avoid Over tightening Hardware during installation avoid using power tools
  123. Install RH knee air bag bolt covers
    Note
    2x covers
  124. Install RH footwell cover
    Note
    2x magnets, 1x guide tab, 1x connector
  125. Connect first responder loop and LV battery
    Note
    2x connectors, Secure FRL first, Seat LV battery connection and push black connector lock inwards to secure, Engage green locking tab when fully seated
  126. Install rear apron
    Note
    14x clips, Hold rear wall of frunk to keep from flexing while engaging front clips
  127. Close hood
  128. Move RH front seat to original position
  129. Raise RH front window
  130. Close RH front door
  131. Verify operation of windshield washers and wipers
  132. Clear DAS Calibration through UI
    Note
    Controls > Service > Camera Calibration, Select Clear Calibration, Verify calibration was cleared successfully, Wait for prompt to disappear automatically before continuing, Calibration in Progress message and progress icon will appear during the next drive cycle
  133. Raise LH front window
  134. Close LH front door
  135. Remove lift arms from below vehicle
    Note
    Lower rack arms fully and remove them from under vehicle
  136. Vehicle will need to be driven by customer to complete calibration procedure. During this time DAS functions will be completely unavailable
