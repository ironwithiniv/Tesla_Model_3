Latch - Cinch - Trunk (Remove and Replace)

Correction code 1120020012 FRT 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-12-23: Added the trunk lid trim steps.
Parent topic: 1120 - Trunk

Torque Specifications

Table 1. Torque Specifications: Latch - Cinch - Trunk (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x3) that attach trunk cinch latch assembly
8 Nm (5.9 lbs-ft)
  • 10 mm socket
 Reuse

Remove

  1. Remove the trunk latch cover. See Cover - Latch - Trunk (Remove and Replace).
  2. Remove the trunk lid trim. See Trim - Lid - Trunk (Remove and Replace).
  3. Disconnect the electrical connector from the latch.
  4. Remove the bolts that attach the latch to the trunk lid, and then remove the latch from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket

Install

  1. Position the latch and loosely install the bolts that attach the latch to the trunk lid.
    8 Nm (5.9 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  2. Connect the electrical connector to the latch.
  3. Install the trunk lid trim. See Trim - Lid - Trunk (Remove and Replace).
  4. Install the trunk latch cover. See Cover - Latch - Trunk (Remove and Replace).
