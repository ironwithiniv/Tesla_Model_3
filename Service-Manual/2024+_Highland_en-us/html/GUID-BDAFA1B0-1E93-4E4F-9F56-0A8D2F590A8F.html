Duct - Floor - 2nd Row - LH (Remove and Replace)

Correction code 1810010132 FRT 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1060071-00-A Torque Wrench 1/4in Dr Hexagon
Parent topic: 1810 - Cabin HVAC

Remove

  1. Open all the doors and lower all the windows.
  2. Remove the center console rear end panel. See Panel - Rear End - Center Console (Remove and Replace).
  3. Remove the bolt that attaches the LH rear of the center console to the body. Repeat this step for the RH rear of the center console.
    Note
    Use of the following tool(s) is recommended:
    • 10 mm socket
  4. Remove the RH center console front side panel. See Carpet - Side - Center Console - RH (Remove and Replace).
  5. Remove the bolts (x2) that attach the RH front of the center console to the body.
    Note
    Use of the following tool(s) is recommended:
    • 10 mm socket
  6. Remove the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  7. Remove the LH lower A-pillar assembly. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  8. Remove the LH front seat assembly. See Seat Assembly - 1st Row - LH (Remove and Replace).
  9. Remove the LH front footwell cover. See Cover - Footwell - Driver (Remove and Replace).
  10. Remove the LH center console front side panel. See Carpet - Side - Center Console - LH (Remove and Replace).
  11. Remove the bolts (x2) that attach the LH front of the center console to the body.
    Note
    Use of the following tool(s) is recommended:
    • 10 mm socket
  12. Disconnect the electrical connector from the rear of the center console.
    Note
    After disconnecting the electrical harness, release the clip that attaches the electrical connector to the center console with a clip prytool.
  13. Remove the center console assembly. See Center Console (Remove and Replace).
  14. Remove the LH front carpet. See Carpet - Front - LH (Remove and Replace).
  15. Release the clip that attaches the main 2nd row floor duct to the vehicle.
  16. Release the main 2nd row floor duct from the HVAC assembly and RH duct, and then remove it from the vehicle.

Install

  1. Install the main 2nd row floor duct into the HVAC assembly and RH duct.
  2. Fasten the clip that attaches the main 2nd row floor duct to the vehicle.
  3. Install the LH front carpet. See Carpet - Front - LH (Remove and Replace).
  4. Install the center console assembly. See Center Console (Remove and Replace).
  5. Connect the electrical connector in the rear of the center console.
    Note
    Install the clip that attaches the electrical connector to the center console first and then connect the electrical harness.
    CAUTION
    Ensure the connector is properly installed. Perform a push-pull test before continuing this procedure.
  6. Install the bolts (x2) that attach the LH front of the center console to the body.
    7 Nm (5.2 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • 10 mm socket
  7. Install the LH center console front side panel. See Carpet - Side - Center Console - LH (Remove and Replace).
  8. Install the LH front footwell cover. See Cover - Footwell - Driver (Remove and Replace).
  9. Install the LH front seat assembly. See Seat Assembly - 1st Row - LH (Remove and Replace).
  10. Install the LH lower A-pillar assembly. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  11. Install the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  12. Install the bolts (x2) that attach the RH front of the center console to the body.
    7 Nm (5.2 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • 10 mm socket
  13. Install the RH center console front side panel. See Carpet - Side - Center Console - RH (Remove and Replace).
  14. Install the bolt that attaches the RH rear of the center console to the body. Repeat this step for the LH rear of the center console.
    7 Nm (5.2 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • 10 mm socket
  15. Install the center console rear end panel. See Panel - Rear End - Center Console (Remove and Replace).
  16. Raise all the windows and close all the doors.
