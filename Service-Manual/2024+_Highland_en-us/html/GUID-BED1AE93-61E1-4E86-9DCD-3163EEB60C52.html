Underhood Storage Unit (Remove and Replace)

Correction code 1224010112 FRT FRT 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2024-03-12: Added worklight LED as a tool when installing the clips.
Parent topic: 1224 - Luggage Compartment Trim

Torque Specifications

Table 1. Torque Specifications: Underhood Storage Unit (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x4) that secure the underhood storage unit
5 Nm (3.7 lbs-ft)
  • 10 mm 12-point deep socket
 Reuse

Remove

  1. Open the LH front door and lower the LH front window.
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Remove the fresh air gutter assembly. See Assembly - Fresh Air Gutter - HVAC (Remove and Replace).
  4. Release the clips (x3), the guide tabs (x3) and the connector that attach the access panel to the vehicle.
    Note
    Grasp the access panel at the top and pull it back to release the clips.
  5. Remove the bolts (x4) that secure the underhood storage unit.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm 12-point deep socket
  6. Release the clips (x8) and locator pins (x3) that attach the underhood storage unit to the vehicle, and then remove the underhood storage unit from the vehicle.
    Note
    Replace any clips if broken or missing.

Install

  1. Align the locator pins (x3) to the holes on the vehicle, and then install the clips (x8) that attach the underhood storage unit to the vehicle.
    Note
    Replace any clips if broken or missing.
  2. Install the bolts (x4) that secure the underhood storage unit.
    5 Nm (3.7 lbs-ft)
    Note
    The number of bolts may vary.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm 12-point deep socket
  3. Connect the connector, and then install the clips (x3) and the guide tabs (x3) that attach the access panel to the vehicle.
    Note
    Align the guide tabs, and then push forward to secure the clips.
  4. Install the fresh air gutter assembly. See Assembly - Fresh Air Gutter - HVAC (Remove and Replace).
  5. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  6. Raise the LH front window and close the LH front door.
