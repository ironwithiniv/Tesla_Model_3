Bracket - C-Pillar - LH (Remove and Replace)

Correction code 1518010212 FRT 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1518 - Pillar and Sill Trim

Torque Specifications

Table 1. Torque Specifications: Bracket - C-Pillar - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolt that attaches the LH C-pillar bracket to the body
2.5 Nm (1.8 lbs-ft)
  • 10 mm socket
  • Cordless hex driver
 Reuse

Remove

  1. Remove the LH side rail trim. See Trim - Side Rail - LH (Remove and Replace).
  2. Remove the LH side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  3. Remove the LH C-pillar trim. See Trim - C-Pillar - LH (Remove and Replace).
  4. Remove the bolt and locator pin that attach the LH C-pillar bracket to the body.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
    • Cordless hex driver
  5. Remove the LH C-pillar bracket.

Install

  1. Install the LH C-pillar bracket.
  2. Install the bolt and locator pin that attach the LH C-pillar bracket to the body.
    2.5 Nm (1.8 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
    • Cordless hex driver
  3. Install the LH C-pillar trim. See Trim - C-Pillar - LH (Remove and Replace).
  4. Install the LH side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  5. Install the LH side rail trim. See Trim - Side Rail - LH (Remove and Replace).
