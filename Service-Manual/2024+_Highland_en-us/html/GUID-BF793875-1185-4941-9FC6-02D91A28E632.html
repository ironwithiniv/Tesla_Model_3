Frame - Back Rest - Front Seat (Remove and Replace)

Correction code 1301010132 FRT 1.14 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Table 1. Torque Specifications: Frame - Back Rest - Front Seat (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Inboard and outboard bolts (x4) that attach the seat back frame to the seat cushion frame
43 Nm (31.7 lbs-ft)
  • Torx Plus T50 socket
 Replace 1128435-00-C
Parent topic: 1301 - Front Seat Tracks and Motors

Remove

  1. Open both LH doors and lower both LH windows.
  2. Remove the LH front seat. See Seat Assembly - 1st Row - LH (Remove and Replace).
  3. Remove the headrest from the LH front seat. See Headrest - Front Seat - LH (Remove and Replace).
  4. Rotate the seat to gain access to underside.
    CAUTION
    Protect the seat cushion from damage.
  5. Remove the LH front seatback shell assembly. See Shell - Seat Back - Front Seat - LH (Remove and Replace).
  6. Disconnect the LH front seatback heater connector, and remove it from the seat bottom.
    Note
    Slide the connector forward to release it from the seat bottom.
  7. Return the seat to upright position.
  8. Remove the flaps that cover the outboard and inboard corners of the seatback frame.
    Note
    Pull the flaps out of the metal tabs to release.
  9. Release the seatback trim retainers (x7) and a lock sheet from the seatback frame.
  10. Remove the backrest ventilation fan. See Blower - Backrest - Front Seat - LH (Remove and Replace).
  11. Pull the seat upholstery away from the side air bag to gain access to the air bag electrical connector, and then disconnect the seat side air bag connector.
    Note
    Press and hold the black tabs on both sides and pull down to release the connector.
  12. Pull the seat upholstery away from FSAB to gain access to the air bag electrical connector, and then disconnect the seat FSAB connector.
    Note
    Press and hold the black tabs on both sides and pull down to release the connector.
  13. Remove the power lumbar assembly from the seatback frame. See Lumbar Support - Backrest - Driver Seat (Remove and Replace).
  14. Remove the seat upholstery trim from the seatback frame. See Trim - Seat Back - Front Seat - LH (Remove and Replace).
  15. Release the bayonets (x4) on the both sides of the two headrest post guides, and then pull the two headrest post guides upward to remove them from the seat back frame.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  16. Release tabs (x4) to remove the suspension plastic bases from the seatback frame.
    Note
    Use a small flat head screwdriver to release the tabs on the bases. If the bases are damaged, replace them.
  17. Remove the 1st row outboard sideshield. See Side Shield - Outboard - LH (Remove and Replace).
  18. Remove the 1st row outboard sideshield carrier. See Carrier - Side Shield - Outboard - 1st Row (Remove and Replace).
  19. Remove the 1st row inboard sideshield. See Side Shield - Inboard - LH (Remove and Replace).
  20. Remove the 1st row inboard sideshield carrier. See Carrier - Side Shield - Outboard - 1st Row (Remove and Replace).
  21. Remove and discard the inboard and outboard bolts (x4) that attach the seatback frame to the seat cushion frame.
    Tip
    Use of the following tool(s) is recommended:
    • Torx Plus T50 socket
  22. Rotate the seatback frame away from the cushion frame, and lift the seatback frame straight up to remove it from the cushion frame.

Install

  1. Place the seatback frame onto the cushion frame for installation.
  2. Install new inboard and outboard bolts (x4) (1128435-00-C) to attach the seatback frame to the seat cushion frame.
    43 Nm (31.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx Plus T50 socket
  3. Install the 1st row outboard sideshield carrier. See Carrier - Side Shield - Outboard - 1st Row (Remove and Replace).
  4. Install the 1st row outboard sideshield. See Side Shield - Outboard - LH (Remove and Replace).
  5. Install the 1st row inboard sideshield carrier. See Carrier - Side Shield - Outboard - 1st Row (Remove and Replace).
  6. Install the 1st row inboard sideshield. See Side Shield - Inboard - LH (Remove and Replace).
  7. Secure the tabs (x4) to attach the suspension plastic bases to the seatback frame.
    Note
    Ensure that the tabs are installed in place. If the bases are damaged, replace them.
  8. Install the bayonets (x4) that attach the headrest post guides to the seat back frame.
  9. Install the driver seat seatback and foam onto the seatback frame. See Trim - Seat Back - Front Seat - LH (Remove and Replace).
  10. Install the power lumbar assembly to the seatback frame. See Lumbar Support - Backrest - Driver Seat (Remove and Replace).
  11. Connect the LH front seat side air bag connector.
  12. Connect the LH front seat FSAB connector.
  13. Install the backrest ventilation fan. See Blower - Backrest - Front Seat - LH (Remove and Replace).
  14. Install the flaps that cover the outboard and inboard corners of the seatback frame.
    Note
    Pull the flaps out of the metal tabs to release.
  15. Secure the lock sheet and the seatback trim retainers (x7) onto the seatback frame.
  16. Position the driver seat back shell onto the seat back, and then fasten the clips that attach the seat back shell to the seat back.
    Note
    Install the lower clips first, and then rotate the shell up into position. Apply light pressure to ensure the seat back shell is fully seated.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  17. Install the headrest to the LH front seat. See Headrest - Front Seat - LH (Remove and Replace).
  18. Rotate the seat to gain access to underside.
    CAUTION
    Protect the seat cushion from damage.
  19. Install the front seatback heater connector to the seat bottom and connect the connector.
    Note
    Slide the connector onto the seat frame clip to secure.
  20. Hook the strap clips (x2) onto the driver seatback shell assembly.
    Note
    Ensure the straps are tight for proper fit and installation.
  21. Return the seat to upright position.
  22. Install the LH front seat. See Seat Assembly - 1st Row - LH (Remove and Replace).
    Note
    No need to reinstall the firmware.
  23. Raise both LH windows and close both LH doors.
