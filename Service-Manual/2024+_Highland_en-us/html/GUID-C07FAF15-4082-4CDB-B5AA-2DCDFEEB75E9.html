Fascia - Front - Lower (Remove and Replace)

Correction code 1001020112 FRT 0.72 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1001 - Bumper / Fascia

Remove

  1. Remove the front fascia assembly. See Fascia - Front (Remove and Replace).
  2. Remove the front fascia valance assembly. See Valance - Front Fascia (Remove and Replace).
    Note
    It is not necessary to remove the pedestrian warning speaker from the valance.
  3. Remove the lower grille. See Grille - Fascia - Front (Remove and Replace).
  4. Remove the clips (x10) that attach the front lower fascia to the front fascia, and then remove it from the vehicle.

Install

  1. Install the clips (x10) that attach the front lower fascia to the front fascia.
    Note
    Make sure that all clips are fully secured.
  2. Install the lower grille. See Grille - Fascia - Front (Remove and Replace).
  3. Install the front fascia valance assembly. See Valance - Front Fascia (Remove and Replace).
  4. Install the front fascia assembly. See Fascia - Front (Remove and Replace).
