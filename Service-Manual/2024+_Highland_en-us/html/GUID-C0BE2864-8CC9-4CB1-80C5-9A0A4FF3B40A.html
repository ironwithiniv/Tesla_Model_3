Latch - Seat Back - 2nd Row - RH (Remove and Replace)

Correction code 1305020122 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1305 - 2nd Row Seat Assemblies and Hardware

Torque Specifications

Table 1. Torque Specifications: Latch - Seat Back - 2nd Row - RH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x2) that attach the RH 2nd row seat back latch bracket to the seat back frame
40 Nm (29.5 lbs-ft)
  • 15 mm socket
 Reuse
Bolts (x2) that attach the RH 2nd row seat back handle to the seat back frame
2 Nm (1.5 lbs-ft)
  • Torx T25 socket
 Reuse

Remove

  1. Remove the RH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  2. Remove the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  3. Remove the RH 2nd row seat back. See Seatback - 2nd Row - RH (Remove and Replace).
  4. Remove the RH 2nd row seat back hinge bracket. See Bracket - Hinge - Seat Back - 2nd Row (Remove and Replace).
  5. Remove the RH 2nd row seat back handle bezel. See Bezel - Handle - Seat Back - 2nd Row - LH (Remove and Replace).
  6. Remove the RH 2nd row seat back latch release bezel. See Bezel - Handle - Seat Back - 2nd Row - RH (Remove and Replace).
  7. Unzip the RH 2nd row seat back trim cover and release the lower section of the seat back from the pivot bar.
  8. Remove the bolts (x2) that attach the RH 2nd row seat back handle to the seat back frame.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket
  9. Remove the RH 2nd row seat back trim cover and foam from the seat back frame.
  10. Remove the clips (x2) that attach the RH 2nd row seat back handle cable to the latch bracket.
  11. Remove the bolts (x2) that attach the RH 2nd row seat back latch bracket to the seat back frame.
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm socket
  12. Remove the RH 2nd row seat back latch bracket.

Install

  1. Install the bolts (x2) that attach the RH 2nd row seat back latch bracket to the seat back frame.
    40 Nm (29.5 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm socket
  2. Install the clips (x2) that attach the RH 2nd row seat back handle cable to the latch bracket.
  3. Install the RH 2nd row seat back trim cover and foam to the seat back frame.
  4. Install the bolts (x2) that attach the RH 2nd row seat back handle to the seat back frame.
    2 Nm (1.5 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket
  5. Zip the RH 2nd row seat back trim cover up and install the lower section of the seat back to the pivot bar.
  6. Install the RH 2nd row seat back latch release bezel. See Bezel - Handle - Seat Back - 2nd Row - RH (Remove and Replace).
  7. Install the RH 2nd row seat back handle bezel. See Bezel - Handle - Seat Back - 2nd Row - LH (Remove and Replace).
  8. Install the RH 2nd row seat back hinge bracket. See Bracket - Hinge - Seat Back - 2nd Row (Remove and Replace).
  9. Install the RH 2nd row seat back. See Seatback - 2nd Row - RH (Remove and Replace).
  10. Install the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  11. Install the RH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
