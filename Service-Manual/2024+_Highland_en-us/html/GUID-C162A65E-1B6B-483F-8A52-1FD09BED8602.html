Steering Column (Manual Adjust) (Model 3 Standard) (Remove and Replace)

Correction code 32050200002 32050200001 FRT 1.08 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
  • 2025-10-08: Released new procedure.
CAUTION
If performing this procedure as a result of a collision, see the Collision Repair Manual to verify whether the steering gear must be replaced as well.
Parent topic: 3205 - Upper Column, Steering Wheel

Remove

  1. Open the LH front door.
  2. Lower the LH front window.
  3. Remove the frunk assembly from the vehicle. See Underhood Storage Unit (Remove and Replace).
  4. Move the LH front seat fully backwards.
  5. Disconnect LV power. See LV Power (Disconnect and Connect) (Modify)
  6. Partially release LH front primary door seal
    Note
    Release lower section of LH front primary door seal
  7. Remove LH instrument panel end cap
    Note
    5x clips, 2x guide tabs
  8. Release LH footwell cover
    Note
    5x clips, 1x guide tab
  9. Remove LH footwell cover
    Note
    2x connectors
  10. Remove LH knee airbag bolt covers
    Note
    2x covers
  11. Remove LH knee air bag bolts
    Note
    4x bolts, EP10, 8.5 Nm, Discard bolts after removal
  12. Remove LH knee airbag assembly
    Note
    1x connector, Peel back plastic film, Release by pulling back both white tabs simultaneously, Avoid straining harness, Only one tab visible in image matching tab is on opposite side
  13. Remove footwell duct securing clips from instrument bracket
    Note
    1x push clip，1x tree clip
  14. Remove LH footwell duct from HVAC module
  15. Remove screw securing instrument panel lower assembly to instrument panel assembly
    Note
    1x screw, T20, 2.3 Nm
  16. Remove instrument panel lower assembly from instrument panel assembly
    Note
    13x tabs
  17. Remove the steering wheel from the steering column. See Steering Wheel (Remove and Replace).
    Note
    Mark steering wheel to steering column. Align the marking during installation
  18. Remove the steering column control module. See Steering Column Control Module (Model 3 Standard) (Remove and Replace).
  19. Remove the bolt that secures the upper gap hider to the steering column.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket
  20. Remove the bolts (x2) that secure the lower gap hider to the steering column.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket
  21. Remove the screws that secure the instrument panel assembly to the cross car beam on the lower LH side.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket
  22. Remove the screws (x3) that secure the instrument panel assembly to the cross car beam at the lower center. Partially remove the RH side of the instrument panel.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 bit
  23. Tape around the instrument panel to prevent cosmetic damage.
  24. Remove the lower gap hider from the upper gap hider.
    Note
    Disengage clips (x6)
  25. Release the steering shaft boot from the bulkhead and pull it into the vehicle
    Tip
    Release from one point and work your way around.
  26. Remove the bolt that secures the steering column to the steering gear assembly.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
    Note
    Discard the fastener after removal.
  27. Disconnect the steering column from the steering gear assembly.
    Note
    Slide the steering column upward from the steering gear assembly to disconnect.
  28. Remove the nuts (x2) that secure the manual steering column to the cross car beam.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  29. Remove the upper gap hider.
  30. Remove the lower nuts (x2) that secure the manual steering column to the cross car beam.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  31. Remove the manual steering column from the vehicle.
    Tip
    Pull the instrument panel slightly outward to give extra access for manual steering column removal.

Install

  1. Position manual steering column through instrument panel and into place for installation
  2. Position upper gap hider to steering column for installation
    Note
    Partially rotate upper gap hider in order to position into place for installation
  3. Install lower nuts securing steering column to cross car beam
    Note
    2x nuts, 13mm, 15 Nm
  4. Install nuts securing steering column to cross car beam
    Note
    2x nuts, 13mm, 15 Nm
  5. Connect steering column to steering gear assembly
    Note
    Slide steering column downward to install steering gear assembly, Ensure the intermediate shaft is aligned and fully seated
  6. Install bolt securing steering column to steering gear assembly
    Note
    1x bolt, 13mm, 18 Nm, Install new bolt
  7. Secure steering shaft boot into position on bulkhead
    Note
    Apply pressure along seal to verify it is fully seated
  8. Tighten bolt securing upper gap hider to steering column
    Note
    1x bolt, T25, 1.2 Nm
  9. Install lower gap hider onto upper gap hider
    Note
    2x location clips, 4x tabs
  10. Install bolts securing gap hider lower to steering column
    Note
    2x bolts, T25, 1.2 Nm
  11. Install screws securing instrument panel assembly to cross car beam on lower LH side
    Note
    3x screws, T20, 2.3 Nm, 2x datums
  12. Install screws securing instrument panel assembly to cross car beam at lower center
    Note
    3x screws, T20, 2.3 Nm, 3x datums
  13. Remove tape around instrument panel
  14. Position SCCM with stalk onto steering column
  15. Tighten bolt securing SCCM with stalk to steering column
    Note
    1x bolt, T20, 2.4 Nm
  16. Connect SCCM assembly connector
    Note
    1x connector, Install new orange retaining clip to connector then install SCCM connector, Perform push-pull-push to make sure connector is seated properly
  17. Install upper shroud to steering column
    Note
    2x screws, T20, 1.5 Nm, 1x location slot
  18. Install lower shroud onto upper shroud
    Note
    2x location clips, 5x guide tabs
  19. Position steering wheel to steering column
    Note
    Align the marking and keyed part of steering wheel and column, the steering wheel and column are keyed
  20. Install bolt securing steering wheel to steering column
    Note
    1x patch bolt, 10mm hex, 80 Nm, Install new patch bolt
  21. Connect steering wheel connector
    Note
    1x connector
  22. Connect driver airbag connector
    Note
    1x connector, Make sure that the driver air bag harness doesn’t get caught between the driver air bag and the horn mechanism
  23. Install driver air bag assembly to steering wheel
    Note
    2x spring clips, 2x datums, Position driver air bag onto steering wheel, Align datums onto clips, Press down on one side of air bag until clip is fully seated, then repeat on other side, You should hear an audible click, Perform pull test on each side of driver air bag assembly, Confirm the gap and space between driver air bag assembly to steering wheel is symmetrical
  24. Install instrument panel lower assembly to instrument panel assembly
    Note
    13x tabs
  25. Install screw securing instrument panel lower assembly to instrument panel assembly
    Note
    1x screw, T20, 2.3 Nm
  26. Install LH footwell duct into HVAC module
  27. Install footwell duct securing clips
    Note
    1x push clip，1x tree clip
  28. Install LH knee airbag assembly
    Note
    1x connector, Ensure airbag connector is fully engaged, Apply knee airbag label over squib assembly
  29. Install LH knee air bag bolts
    Note
    4x bolts, EP10, 8.5 Nm, Install new bolts
  30. Install LH knee airbag bolt covers
    Note
    2x covers
  31. Position LH footwell cover
    Note
    2x connectors
  32. Install LH footwell cover
    Note
    5x clips, 1x guide tab
  33. Install LH instrument panel end cap
    Note
    5x clips, 2x guide tabs
  34. Install LH front primary seal
    Note
    Verify seal is seated properly on all trim panels
  35. Reconnect LV power. See LV Power (Disconnect and Connect) (Modify)
  36. Install the frunk assembly into the vehicle. See Underhood Storage Unit (Remove and Replace).
  37. Move RH front seat to original position
  38. Raise RH front window
  39. Close RH front door
  40. Move LH front seat to original position
  41. Raise LH front window
  42. Close LH front door
