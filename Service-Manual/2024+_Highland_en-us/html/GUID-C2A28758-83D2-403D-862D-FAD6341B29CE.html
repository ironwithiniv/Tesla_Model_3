Airbag - Front Passenger (Remove and Replace)

Correction code 2001010212 FRT 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-02-20: Added note on using PROC_RCM_DISARM if using this procedure to diagnose the SRS.
  • 2024-07-10: Separated the knee airbag steps and added the recommended tool list.
Warning
If using this procedure to diagnosis the vehicle's Supplemental Restraint Systems (SRS), disarm the RCM, which will prevent all airbags and pretensioners from deploying. Re-arm the RCM after all of the vehicle's SRS components are re-installed.
  • Disarm RCM:PROC_RCM_DISARMvia Service Mode Plus:
    • Safety & Restraints ➜ Airbags ➜ Disarm RCM
    • Safety & Restraints ➜ Seats ➜ Disarm RCM
    via Toolbox:(link)
  • Re-arm RCM:PROC_RCM_ARMvia Service Mode Plus:
    • Safety & Restraints ➜ Airbags ➜ Re-Arm RCM
    • Safety & Restraints ➜ Seats ➜ Re-Arm RCM
    via Toolbox:(link)
Warning
Make sure LV power has been disconnected for at least 2 minutes before disconnecting the electrical harness from Supplementary Restraint System (SRS) components, such as Restraint Control Module, sensors, airbags, etc. Failure to do so can result in unintended safety system behaviors. For more information on SRS precautions, see Airbag and Supplementary Restraint System (SRS) Precautions.
Warning
Supplementary Restraint System (SRS) components can be hazardous if not handled properly. For more information on SRS precautions, see Airbag and Supplementary Restraint System (SRS) Precautions.
CAUTION
Supplemental Restraint System (SRS) components can be hazardous if not serviced and handled correctly. See Airbag and Supplementary Restraint System (SRS) Precautions
CAUTION
In the event of an airbag or seatbelt pretensioner deployment, certain components must be replaced, and other components must be inspected for damage. Refer to the Collision Repair Manual for a specific list of items that must be inspected and replaced.

Torque Specifications

Table 1. Torque Specifications: Airbag - Front Passenger (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x6) that attach the passenger airbag to the cross car beam
8 Nm (5.9 lbs-ft)
  • External Torx E10
  • ¼ in to 3/8 in adapter
  • 6 in extension
  • Ratchet/torque wrench
 Replace 1116594-00-B

Remove

  1. Disconnect LV power. See LV Power (Disconnect and Connect) (Modify).
  2. Remove the RH air wave duct. See Duct - Air Wave - RH (Remove and Replace).
  3. Disconnect the connector that connect the passenger airbag to the vehicle.
  4. Remove and discard the bolts (x6) that attach the passenger airbag to the cross car beam.
    Tip
    Use of the following tool(s) is recommended:
    • External Torx E10
    • ¼ in to 3/8 in adapter
    • 6 in extension
    • Ratchet/torque wrench
  5. Remove the airbag from the vehicle.

Install

  1. Install the new bolts (x6) that attach the passenger airbag to the cross car beam.
    8 Nm (5.9 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • External Torx E10
    • ¼ in to 3/8 in adapter
    • 6 in extension
    • Ratchet/torque wrench
  2. Connect the connector that connect the passenger airbag to the vehicle.
  3. Install the RH air wave duct. See Duct - Air Wave - RH (Remove and Replace).
  4. Connect LV power. See LV Power (Disconnect and Connect) (Modify).
