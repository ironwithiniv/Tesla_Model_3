Service Mode

Refer to these sections to enable and disable Service Mode.

Note
If vehicle touchscreen operation is not feasible, or if providing Mobile Service, enable Service Mode via Toolbox.
  • Enable Service Mode Via Vehicle Touchscreen
  • Enable Service Mode Via Toolbox
  • Disable Service Mode
Note
For advanced diagnostics, see Service Mode Plus.
Parent topic: 0005 - Service Modes

Enable Service Mode Via Vehicle Touchscreen

  1. On the vehicle touchscreen, touch CONTROLS (vehicle icon) > SOFTWARE .
    Note
    An image of the vehicle and badge is displayed.
  2. Touch and hold the large word "MODEL" for 2 seconds, and then release.
  3. Use the on screen keyboard to type "service" into the access code field, and then touch OK.
    Note
    The touchscreen is overlaid with the words "SERVICE MODE" in red. Newer firmware versions have a red border around the edges of the touchscreen UI.

Enable Service Mode Via Toolbox

  1. Connect a laptop with Toolbox 3 to the vehicle.
  2. Select Actions/Autodiag, and then search for "Service".
  3. Select the "PROC_ICE_X_ENTER-SERVICE-MODE" routine, and then click Run.

Disable Service Mode

  1. Disable Service Mode using either a laptop with Toolbox or the vehicle touchscreen.
    • Touchscreen: On the vehicle touchscreen, touch CONTROLS (vehicle icon) > SERVICE MODE > EXIT SERVICE MODE at the top of the Service Mode menu.
      Note
      The red "SERVICE MODE" overlay or red touchscreen border is removed.
    • Laptop with Toolbox: Run the "PROC_ICE_X_EXIT-SERVICE-MODE" routine, and then disconnect the laptop from the vehicle.
