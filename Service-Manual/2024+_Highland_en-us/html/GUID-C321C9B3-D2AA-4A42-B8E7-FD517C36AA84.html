Radiator (Remove and Replace)

Correction code 1830010012 FRT 1.20 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-09-01: Added steps for radiator health value reset routine
  • 2026-02-04: Added steps related to the stone guard.
Parent topic: 1830 - Cooling System

Remove

  1. Remove the active grille shutter. See Active Grille Shutter (Remove and Replace).
  2. Release the locking tabs that attach the radiator to the condenser fan assembly, and then slide the radiator out of the holding mounts.
  3. Remove the stone guard. See Stone Guard (Remove and Replace).
    Note
    Perform this step only if the following conditions are met:
    • the old radiator is equipped with a stone guard.
    • the new radiator does not include a stone guard.

Install

  1. If removed, install the stone guard onto the radiator. See Stone Guard (Remove and Replace).
  2. Install the radiator to the cooling fan and shroud assembly, and install the locking tabs (x2) and holding mounts (x2) that attach the radiator to the cooling fan and shroud assembly.
  3. Install the active grille shutter. See Active Grille Shutter (Remove and Replace).
  4. Perform the routine PROC_VC_X_RESET-RADIATOR-UA-INDEXvia Toolbox:(link)
    Note
    Perform this step for firmware versions develop/2026.14.3 and later.
  5. Perform the routine using Service Mode or Toolbox: TEST-SELF_VCFRONT_X_THERMAL-PERFORMANCEvia Service Mode:Thermal ➜ Actions ➜ Test Thermal Performancevia Service Mode Plus:
    • Drive Inverter ➜ Front Drive Inverter Replacement ➜ Thermal System Test
    • Drive Inverter ➜ Rear Drive Inverter Replacement ➜ Thermal System Test
    • Drive Inverter ➜ Rear Left Drive Inverter Replacement ➜ Thermal System Test
    • Drive Inverter ➜ Rear Right Drive Inverter Replacement ➜ Thermal System Test
    • Drive Unit ➜ Front Drive Unit Replacement ➜ Thermal System Test
    • Drive Unit ➜ Rear Drive Unit Replacement ➜ Thermal System Test
    via Toolbox:(link)
  6. Exit Service Mode or disconnect the laptop. See 0005 - Service Modes.
  7. Raise the LH front window and close the LH front door.
  8. Remove the vehicle from the lift.
