Map Light - Rear - Pair (Remove and Replace)

Correction code 1520010602 FRT 0.48 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1520 - Headliner

Remove

  1. Remove the LH and RH rear map lamp. See Map Light - Rear - LH (Remove and Replace).

Install

  1. Install the LH and RH rear map lamp. See Map Light - Rear - LH (Remove and Replace).
  2. Connect a laptop with Toolbox to the vehicle. See Toolbox (Connect and Disconnect).
  3. In Toolbox, click the Actions tab, and then search for "TEST-SELF_VCLEFT_REAR-DOME-LIGHTS".
  4. Click TEST-SELF_VCLEFT_REAR-DOME-LIGHTSvia Toolbox:(link), and then click Run and allow the routine to complete.
  5. Disconnect Toolbox and remove the laptop from the vehicle. See Toolbox (Connect and Disconnect).
  6. Reinstall the vehicle firmware. See Software Reinstall - Touchscreen.
