Handle - Exterior Release - Door - Rear - LH (Remove and Replace)

Correction code 1145010132 FRT 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
The side impact airbag deployment depends on the rear door sensor's ability to detect a side impact from air pressure. Make sure that there are no uncovered holes in the rear door shells. Additionally, always reinstall plugs or tape when servicing or inspecting the rear doors and their components.
Parent topic: 1145 - Exterior Door Handles

Torque Specifications

Table 1. Torque Specifications: Handle - Exterior Release - Door - Rear - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Nuts (x3) that attach the exterior door handle to the door panel
7 Nm (5.2 lbs-ft)
  • 10 mm socket
 Replace

Remove

  1. Open the LH front door and lower the LH front window.
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Remove the LH rear door puddle light. See Puddle Lamp - Rear Door (Remove and Replace).
  4. Remove the LH rear door trim panel. See Panel - Door Trim - Rear - LH (Remove and Replace).
  5. Remove the clip retainers (x3) from the LH rear door.
    Note
    The number of retainers may vary, and replace any damaged retainers.
  6. Remove the LH rear door glass. See Glass - Door - Rear - LH (Remove and Replace).
  7. Disconnect LV power. See LV Power (Disconnect and Connect) (Modify).
  8. Remove the LH rear window motor regulator assembly. See Window Motor / Regulator Assembly - Rear - LH (Remove and Replace).
  9. Disconnect the electrical connector from the LH rear door handle sensor.
  10. Remove the plugs (x3) that cover access to the LH rear door exterior release handle nuts.
  11. Remove the nuts (x3) that attach the exterior door handle to the door panel, and then remove the handle from the door.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket

Install

  1. Hand tighten the nuts (x3) that attach the exterior door handle to the door panel.
  2. Use the gap and flush tool to check the gap and flush of the handle to the door surface.
  3. Torque the nuts (x3) that attach the exterior door handle to the door panel.
    7 Nm (5.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  4. Connect the electrical connector to the LH rear door handle sensor.
  5. Install the plugs (x3) that cover access to the LH rear door exterior release handle nuts.
  6. Install the LH rear window motor regulator assembly. See Window Motor / Regulator Assembly - Rear - LH (Remove and Replace).
  7. Connect LV power. See LV Power (Disconnect and Connect) (Modify).
  8. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  9. Install the LH rear door glass. See Glass - Door - Front - LH (Remove and Replace).
  10. Install the LH rear door puddle light. See Puddle Lamp - Rear Door (Remove and Replace).
  11. Install the LH rear door trim panel. See Panel - Door Trim - Rear - LH (Remove and Replace).
  12. Calibrate the LH rear window regulator. See Window Regulator (Recalibrate) (Maintenance).
  13. Raise the LH front window and close the LH front door.
