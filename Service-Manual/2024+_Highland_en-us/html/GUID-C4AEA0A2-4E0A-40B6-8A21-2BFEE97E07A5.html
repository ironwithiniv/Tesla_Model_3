Bracket - License Plate - Rear (EMEA) (Remove and Replace)

Correction code 1207010212 FRT 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1453028-00-A KIT, BADGE REMOVAL
  • 1049517-00-A Seam Roller, Silicone, 5"
Parent topic: 1207 - License Plate Mountings

Remove

  1. Prepare the badge removal tool with approximately 60 centimeters of monofilament line.
  2. Tie slip knots at both ends of the monofilament line and attach them each to the center groove of a handle.
  3. Remove the screws that attach the rear license plate bracket to the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
    • 2 in extension
    • Cordless Ratchet/Impact Driver
  4. Position the wire of the badge removal tool behind the license plate bracket, and then move the tool in a sawing motion to separate the bracket from the vehicle.
  5. Clean all adhesive residue from the vehicle, using an eraser wheel and IPA wipes.
    Note
    Allow 1 minute to dry.

Install

  1. Verify the thread inserts were not damaged during removal, and clean the surface area with IPA wipes.
  2. Position the rear license plate bracket onto the vehicle, and then install the screws that attach the bracket to the vehicle.
    1.2 Nm (.9 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
    • Wiha TorqueVario-S 0.8 Nm - 2.0 Nm screwdriver (installation only)
    • Wiha torque setter
  3. Remove the backing from the double-sided tape of the rear of the license plate bracket.
  4. Apply pressure on the licence plate where the double-sided tape is installed.
