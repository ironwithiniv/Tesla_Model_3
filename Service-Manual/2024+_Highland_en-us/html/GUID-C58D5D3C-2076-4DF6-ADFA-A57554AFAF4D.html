Panel - Rear End - Center Console (Remove and Replace)

Correction code 1519010042 FRT 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1519 - Center Console

Remove

  1. Open all doors and fully lower all windows.
  2. Move the LH and RH front seat forward.
  3. Remove the clips (x6) and tabs (x2) that attach the center console end panel to the console, and then remove the end panel form the console.
    Note
    Release the upper clips first, and then work toward to release the lower tabs.

Install

  1. Install the clips (x6) and tabs (x2) that attach the center console end panel to the console.
    Note
    Fasten the lower tabs first, and then work toward to fasten the upper clips.
  2. Move the LH and RH front seat back to their original positions.
  3. Raise all the windows and close all the doors.
