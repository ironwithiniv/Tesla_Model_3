Module - Restraint Control - Universal (Remove and Replace)

Correction code 2020010032 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-01-27: Added steps to disarm the RCM.
  • 2025-11-04: Added step to perform headlight adjustment and verify vehicle operation.
  • 2024-05-14: Replaced Toolbox routines by routines using the touchscreen.
CAUTION
Supplemental Restraint System (SRS) components can be hazardous if not serviced and handled correctly. See Airbag and Supplementary Restraint System (SRS) Precautions
CAUTION
In the event of an airbag or seatbelt pretensioner deployment, certain components must be replaced, and other components must be inspected for damage. Refer to the Collision Repair Manual for a specific list of items that must be inspected and replaced.
Equipment:
  • 1060071-00-A Torque Wrench 1/4in Dr Hexagon
Warning
Make sure 12V/LV power has been disconnected for at least 1 minute before disconnecting the electrical harness from Supplementary Restraint System (SRS) components, such as Restraint Control Module, sensors, airbags, etc. Disconnect the 12V/LV battery and the First Responder Loop. Failure to do so can result in unintended safety system behaviors. For more information on SRS precautions, see Airbag and Supplementary Restraint System (SRS) Precautions.
Warning
Supplementary Restraint System (SRS) components can be hazardous if not handled properly. For more information on SRS precautions, see Airbag and Supplementary Restraint System (SRS) Precautions.
Warning
While performing any Supplementary Restraint System (SRS) related repairs, it is important to disconnect 12V/LV power, by disconnecting the 12V/LV battery and the First Responder Loop. If the vehicle’s 12V/LV power is NOT disconnected and the Restraint Control Module is removed or disturbed, this can result in the deployment of the vehicle’s airbags.

Torque Specifications

Table 1. Torque Specifications: Module - Restraint Control - Universal (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Nuts (x3) that attach the restraint control module to the body
8 Nm (5.9 lbs-ft)
  • Cordless Drill
  • 10 mm deep nutsetter
 Replace

Remove

  1. Remove the center console. See Center Console (Remove and Replace).
    Note
    Before disconnecting LV power in this procedure, perform the following steps:
    1. Enable Service Mode Plus. See Service Mode Plus.
    2. On the touchscreen, touch Controls > Safety & Restraints > Airbags > RCM > Disarm RCM, click Run, and allow the routine to complete.
    Note
    Make sure that airbags are disarmed after the routine has completed.
  2. Disconnect LV power. See LV Power (Disconnect and Connect) (Modify).
  3. Disengage the locking levers, and then disconnect the electrical connectors from the restraint control module.
    Warning
    Make sure LV power has been disconnected for at least 2 minutes before disconnecting the electrical harness from the restraint control module. Failure to do so can result in unintended safety system behaviors.
  4. Remove and discard the nuts (x3) that attach the restraint control module to the body, and then remove the module from the vehicle.
    • Cordless Drill
    • 10 mm deep nutsetter

Install

  1. Install the restraint control module to the body, and then install new nuts (x3) to attach the module to the body.
    8 Nm (5.9 lbs-ft)
    Note
    Verify part number on the new module is correct.
    Note
    Use of the following tool(s) is recommended:
    • Cordless Drill
    • 10 mm deep nutsetter
  2. Connect the electrical connectors to the restraint control module and then engage the connector locking levers.
  3. Connect LV power. See LV Power (Disconnect and Connect) (Modify).
  4. Install the center console. See Center Console (Remove and Replace).
  5. Park the vehicle on a level surface.
  6. Reinstall the vehicle firmware. See Software Reinstall - Touchscreen.
  7. Enter Service Mode Plus. See Service Mode Plus
  8. On the touchscreen, touch Service Mode > Safety and Restraints > Airbags > RCM > Post Replacement Tasks.
  9. On the next screen, touch Run, and allow the routine to complete.
  10. Exit Service Mode Plus. See Service Mode Plus
  11. Adjust the headlights as needed and verify vehicle operation.
    • Headlights - Adjust - NA (Tool Method) (Test/Adjust)
    • Headlights - Adjust - Global (Wall Method) (Test/Adjust)
    • Headlights - Global - Adjust (EMEA with LET Tool)
    Note
    Add the corresponding correction code as a separate activity to the Service Visit.
