Camera Cover - Upper (Remove and Replace)

Correction code 1505010022 FRT 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-05-20: Updated the torque values of the bolts (x2) from 1 Nm to 0.8 Nm, which must be replaced with new ones after removal.
Parent topic: 1505 - Interior Mirror and Sun Visors

Torque Specifications

Table 1. Torque Specifications: Camera Cover - Upper (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x2) that attach the interior camera to the camera upper cover
0.8 Nm (7 lbs-in)
  • Torx T10 bit
  • Wiha Torque Screwdriver 0.8-5 Nm (for installation only)
 Replace 1919198-00-A

Remove

  1. Remove the lower camera cover. See Camera Cover - Lower (Remove and Replace).
  2. Remove the rear view mirror. See Mirror - Rear View (Remove and Replace).
  3. Release the clips (x4) that attach the upper camera cover, disconnect the interior camera connectors (x3), and then remove the upper camera cover and interior camera assembly from the vehicle.
    CAUTION
    Do not pull the upper camera cover with excessive force, as the electrical harness is still attached to the interior camera.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  4. Remove and discard the bolts (x2) that attach the interior camera to the upper camera cover, and then remove the interior camera from the upper camera cover.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T10 bit
    • Wiha Torque Screwdriver 0.8-5 Nm (for installation only)

Install

  1. Position the interior camera onto the upper camera cover, and then install new bolts (x2) that attach the interior camera onto the upper camera cover.
    0.8 Nm (7 lbs-in)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T10 bit
    • Wiha Torque Screwdriver 0.8-5 Nm (for installation only)
  2. Connect the interior camera connectors (x3), and then install the clips (x4) that attach the upper camera cover to the vehicle.
  3. Install the rear view mirror. See Mirror - Rear View (Remove and Replace).
  4. Install the lower quad camera cover. See Camera Cover - Lower (Remove and Replace).
