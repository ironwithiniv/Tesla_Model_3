Gap Hider - Lower - Steering Column (Model 3 Standard) (Remove and Replace)

Correction code 32050200402 32050200401 FRT 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
  • 2026-10-09: Removed steps to remove the steering column control module.
  • 2025-09-05: Released new procedure.
Parent topic: 3205 - Upper Column, Steering Wheel

Remove

  1. Open the LH front door and lower the LH front window.
  2. Move the LH front seat backward.
  3. Pull the lever fown to manually adjust the steering column fully outward and downward.
    Note
    Lock the lever in place once adjusted.
  4. Disconnect the LV power. See LV Power (Disconnect and Connect) (Modify).
  5. Remove the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  6. Remove the driver footwell cover. See Cover - Footwell - Driver (Remove and Replace).
  7. Remove the LH knee air bag if equipped. See Airbag - Knee - LH (Remove and Replace).
  8. Remove the lower instrument panel. See Assembly - Instrument Panel - Lower (Remove and Replace).
  9. Remove the driver air bag. See Airbag - Driver (Remove and Replace).
  10. Remove the steering wheel. See Steering Wheel (Remove and Replace).
  11. Release the steering column lower shroud from the upper shroud.
    Note
    1x alignment clip,2x retention holes
  12. Remove the upper shroud from the steering column.
    Note
    2x screws, T20, 1.5 Nm, 6x clips
  13. Remove the bolts (x2) that secure the lower gap hider to the steering column.
    Note
    2x bolts, T25, 1.2 Nm
  14. Remove the lower gap hider from the steering column.
    Note
    2x locator clips, 4x retention holes

Install

  1. Install the lower gap hider to the steering column.
    Note
    2x locator clips ,4x retention holes
  2. Install the bolts (x2) that secure the lower gap hider to the steering column.
    Note
    2x bolts, T25, 1.2 Nm
  3. Install the upper shroud to the steering column.
    Note
    2x screws, T20, 1.5 Nm, 6x clips
  4. Install the steering column lower shroud to the upper shroud.
    Note
    1x alignment clip,2x retention holes
  5. Install the steering wheel. See Steering Wheel (Remove and Replace).
  6. Install the driver air bag. See Airbag - Driver (Remove and Replace).
  7. Install the lower instrument panel. See Assembly - Instrument Panel - Lower (Remove and Replace).
  8. Install the LH knee air bag if equipped. See Airbag - Knee - LH (Remove and Replace).
  9. Install the driver footwell cover. See Cover - Footwell - Driver (Remove and Replace).
  10. Install the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  11. Connect the LV power. See LV Power (Disconnect and Connect) (Modify).
  12. Move the steering column back to its original position.
    Note
    Lock the lever in place once adjusted.
  13. Move the LH front seat back to its original position.
  14. Raise the LH front window and close the LH front door.
