Microswitch - Hood Latch and Release (Remove and Replace)

Correction code 11351100302 FRT 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Torque Specifications

Description Torque Value Recommended Tools Reuse/Replace Notes
Screw that attaches the hood latch microswitch to the vehicle
0.7 Nm (6 lbs-in)
  • BIT, T8 TORX, 25MM
Reuse

Remove

  1. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  2. Disconnect the hood latch connector.
    Note
    Pull the tab to release the lock then pull again to release the connector. Do not press down on the red tab.
  3. Remove the screw that attaches the hood latch microswitch to the vehicle, then release the location pins (x3) to remove it.
    Tip
    Use of the following tool(s) is recommended:
    • BIT, T8 TORX, 25MM

Replace

  1. Align the location pins (x3), then install the screw that attaches the hood latch microswitch to the vehicle.
    0.7 Nm (6 lbs-in)
    Note
    Do not touch the spring clips on the top of the microswitch.
    Tip
    Use of the following tool(s) is recommended:
    • BIT, T8 TORX, 25MM
  2. Engage the locking tab, then connect the latch connector.
  3. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  4. Enable Service Mode and unlock the gateway. See Gateway Unlock.
  5. Perform the following routine using Service Mode or Toolbox: PROC_VCFRONT_X_RESET-FRUNK-OPEN-FAIL-METRICvia Service Mode Plus:Closures ➜ Frunk ➜ Frunk Latch Metric Resetvia Toolbox:(link)
  6. Exit Service Mode.
