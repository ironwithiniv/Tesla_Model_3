Brace - Shock Tower (Remove and Replace)

Correction code 1010055312 FRT 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1115212-00-A Fender Cover

Parent topic: 1010 - Body Panels

Remove

  1. Open the LH front door and lower the LH front window.
  2. Disconnect the LV battery power. See LV Power (Disconnect and Connect) (Modify).
  3. Remove the fresh intake duct. See Fresh Air Intake - HVAC (Remove and Replace).
  4. Remove the LV battery. See LV Battery (Remove and Replace).
  5. Release the clips (x2) that attach the HV battery return hose to the LV battery bracket.
  6. Remove the retaining clip that attaches the LV battery and First Responder Loop to the shock tower brace.
  7. Remove the retaining clips (x5) that attach the A/C compressor HV harness to the shock tower brace.
    Note
    Pull upward on each clip to assist with removal. Do not pull on the HV cable.
  8. Disconnect the HVIL connector.
    Note
    Do not push down on the red tab. Pull it to disengage the lock, and pull it again to release the connector.
  9. Release the connector locking tab, then disconnect the A/C logic electrical connector from the A/C compressor.
    Note
    DO NOT push down on the red locking tab. Pull the tab away from the connector until the connector is unlocked, and then continue pulling to release the connector.
    Tip
    Use of the following tool(s) is recommended:
    • Pick Miniature Soft Grip, 90 degree tip, 6 in
  10. Use a clip pry tool to release the retaining clip that attaches the A/C compressor logic harness to the A/C compressor HV harness bracket.
  11. Remove the bolt that secures the A/C compressor ground strap.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket
  12. Install bungee cord to the RH hood strut bracket, route bungee cord around accumulator housing and secure the cord to the RH body to support the supermanifold with bungee cord.
    Note
    Do not secure bungee cord around coolant pumps or plastic housing on the supermanifold. Use a mirror as needed to visual check bungee cord around the accumulator housing.
  13. Remove the bolts (x2) that attach the supermanifold to the shock tower brace.
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm socket
  14. Loosen the bolts (x2, 15mm) that attach the compressor to the shock tower brace.
  15. Remove the bolts (x6) that secure the both sides of the shock tower brace.
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm socket
  16. With assistance, remove the bolts (x2) that attach the compressor to the shock tower brace, and release the A/C compressor and the A/C compressor bracket assembly from the shock tower brace.
    CAUTION
    Do not rest the A/C compressor on the HV connector.
    Tip
    Use of the following tool(s) is recommended:
    • Flex head ratchet/flex head torque wrench
    • 15 mm socket
    • Cordless Ratchet/Impact Driver
    • Fender Cover - 115212-00-A
  17. Remove the shock tower brace from the vehicle.

Install

  1. With assistance, loosely install the bolts (x2, 15mm) that attach the compressor to the shock tower brace.
    Note
    Torque at later step.
  2. Move the A/C compressor assembly and the shock tower brace to installation position.
  3. Install the bolts (x6) that secure the both sides of the shock tower brace.
    55 Nm (40.6 lbs-ft)
    62 Nm (45.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm socket
  4. With assistance, install the bolts (x2) that attach the supermanifold to the shock tower brace.
    31 Nm (22.9 lbs-ft)
    CAUTION
    Hand tighten the bolts first to avoid cross threading.
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm socket
  5. Torque the bolts (x2) that attach the compressor to the shock tower brace.
    31 Nm (22.9 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm socket
  6. Release bungee cord from the supermanifold.
  7. Install the retaining clip that attaches the LV battery and First Responder Loop to the shock tower brace.
    Note
    Pull upward on the clip to assist with removal.
  8. Install the retaining clips (x5) that attach the A/C compressor HV harness to the shock tower brace.
  9. Connect the HVIL connector.
    Note
    Engage the locking tab.
  10. Install the clip that attaches the coolant hose to the A/C compressor bracket.
  11. Install the retaining clip that attaches the A/C compressor logic harness to the A/C compressor HV harness bracket.
  12. Connect the A/C compressor logic electrical connector to the A/C compressor, and then engage the locking tab.
    Note
    Push the red locking tab into the connector to engage the locking mechanism. DO NOT push down or pull up on the red locking tab.
  13. Install the bolt that secures the A/C compressor ground strap.
    7 Nm (5.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket
  14. Install the clips (x2) that attach the coolant hose to the A/C compressor bracket.
  15. Install the LV battery. See LV Battery (Remove and Replace).
  16. Connect the LV battery power. See LV Power (Disconnect and Connect) (Modify).
  17. Install the fresh intake duct. See Fresh Air Intake - HVAC (Remove and Replace).
  18. Raise the LH front window and close the LH front door.
