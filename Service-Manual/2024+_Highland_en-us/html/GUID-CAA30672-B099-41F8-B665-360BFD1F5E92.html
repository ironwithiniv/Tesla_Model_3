Mirror - Door - LH (Remove and Replace)

Correction code 1209034012 FRT 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Table 1. Torque Specifications: Mirror - Door - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x3) that attach the LH door mirror assembly to the LH front door
15 Nm (11.1 lbs-ft)
  • Nutsetter Magnetic Deep 10mm
 Reuse
Parent topic: 1209 - Exterior Mirrors

Remove

  1. Open the LH front door and lower the LH front window.
  2. Remove the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  3. Use a small flat head screwdriver to disconnect the LH exterior mirror connector.
  4. Remove the LH exterior mirror wiring harness clip.
  5. Release the clips (x3) that attach the LH front glass run seal to the door.
  6. Remove the bolts (x3) that attach the LH door mirror assembly to the LH front door.
    Tip
    Use of the following tool(s) is recommended:
    • Nutsetter Magnetic Deep 10mm
  7. Push the grommet through the LH front door, and route the mirror harness through as lifting up on the mirror assembly to fully remove the LH front door mirror assembly from the LH front door.

Install

  1. Route the mirror harness through door, and position the LH front exterior mirror assembly into the LH front door for installation.
  2. Install the bolts (x3) that attach the LH door mirror assembly to the LH front door.
    15 Nm (11.1 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Nutsetter Magnetic Deep 10mm
  3. Install the clips (x3) that attach the LH front glass run seal to the door.
  4. Install the LH exterior mirror wiring harness clip.
  5. Connect the LH exterior mirror connector.
  6. Install the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  7. Raise the LH front window and close the LH front door.
