HVAC Assembly (Remove and Replace)

Correction code 1810010012 FRT 2.82 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-10-26: Added steps for vehicle configuration safe set, blower identification and HVAC system performance test, firmware redeployment and cabin air filter maintenance record reset.
  • 2026-08-26: Added step to open glove box before LV disconnect.
  • 2025-10-20: Updated the routines per the latest validation.
Note
This procedure requires the A/C Refrigerant (Recovery and Recharge) procedure to be performed. If not already automatically added to the Service Visit, add correction code 18200102 as a separate correction within the same activity to the Service Visit.
Parent topic: 1810 - Cabin HVAC

Remove

  1. Set up the A/C machine.
  2. Open the glove box.
  3. Enable Service Mode through the touchscreen. See Service Mode.
  4. Unlock the vehicle gateway. See Gateway Unlock.
  5. On the touchscreen, touch Thermal > Refrigerant System > Start Refrigerant Fill/Drain (Refrigerant Only) to start the routine, and allow the routine to complete.
  6. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  7. Remove and discard the bolts (x4) that attach the front and rear of the LH 1st row seat to the body. See Seat Assembly - 1st Row - LH (Remove and Replace).
    Note
    Only remove and discard the bolts (x4) and no need to remove other components at this moment.
  8. On the touchscreen, tap Controls > Steering, and then use the left steering wheel roll to adjust the steering column to middle height and most outward position.
    Note
    13 clicks makes the steering column to the middle height from the lowest/highest position.
  9. Disconnect the LV power. See LV Power (Disconnect and Connect) (Modify).
  10. Remove the cabin intake duct. See Assembly - Fresh Air Gutter - HVAC (Remove and Replace).
  11. Remove the fresh air duct. See Fresh Air Intake - HVAC (Remove and Replace).
  12. Remove the access panel. See Cover - Hood Latch (Remove and Replace).
  13. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  14. Recover the A/C refrigerant. See A/C Refrigerant (Recovery and Recharge) (Restore).
  15. Remove the bolts (x2) that attach the supermanifold to HVAC A/C line to the HVAC assembly.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  16. Remove the LH and RH wiper arms and blades. See Wiper Arm - Driver Side (Remove and Replace).
  17. Remove the LH and RH shock tower covers. See Cover - Shock Tower - LH (Remove and Install).
  18. Remove the cowl screen panel. See Panel - Cowl Screen (Remove and Replace).
  19. Remove the wiper module. See Wiper Module (LHD) (Remove and Replace).
  20. Remove the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  21. Remove the LH upper A-pillar trims. See Trim - A-Pillar - Upper - LH (Remove and Replace).
  22. Remove the LH lower A-pillar assembly. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  23. Remove the LH 1st row seat assembly. See Seat Assembly - 1st Row - LH (Remove and Replace).
  24. Remove the driver footwell cover. See Cover - Footwell - Driver (Remove and Replace).
  25. Remove the LH footwell duct. See Duct - Footwell - LH (Remove and Replace).
  26. Remove the center console end panel. See Panel - Rear End - Center Console (Remove and Replace).
  27. Remove the LH center console front side panel. See Carpet - Side - Center Console - LH (Remove and Replace).
  28. Remove the RH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  29. Remove the RH upper A-pillar trims. See Trim - A-Pillar - Upper - LH (Remove and Replace).
  30. Remove the passenger footwell cover. See Cover - Footwell - Front Passenger (Remove and Replace).
  31. Remove the glove box. See Glove Box (Remove and Replace).
    Note
    No need to remove the glove box USB cable.
  32. Remove the RH footwell duct. See Duct - Footwell - RH (Remove and Replace).
  33. Disconnect the RH airwave duct thermistor connector.
  34. Remove the RH air wave duct. See Duct - Air Wave - RH (Remove and Replace).
  35. Remove the RH center console front side panel. See Carpet - Side - Center Console - RH (Remove and Replace).
  36. Remove the bolts (x2) that attach the LH and RH rear of the center console to the body.
    Note
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 10 mm socket
    • 2 in extension
    • Ratchet/torque wrench
  37. Remove the bolts (x2) that attach the LH front of the center console to the body.
    Note
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 10 mm socket
    • 2 in extension
    • Ratchet/torque wrench
  38. Remove the bolts (x2) that attach the RH front of the center console to the body.
    Note
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 10 mm socket
    • 2 in extension
    • Ratchet/torque wrench
  39. Disconnect the electrical connector from the rear of the center console.
  40. Release the clip and disconnect the electrical connector from the front of the center console.
  41. Remove the center console assembly from the vehicle.
  42. Remove the lower instrument panel. See Assembly - Instrument Panel - Lower (Remove and Replace).
  43. Remove the driver airbag. See Airbag - Driver (Remove and Replace).
  44. Remove the steering wheel. See Steering Wheel (Remove and Replace).
  45. Remove the steering column upper shroud. See Shroud - Upper - Steering Column (Remove and Replace).
  46. Remove the steering column lower shroud. See Shroud - Lower - Steering Column (Remove and Replace).
  47. Remove the steering column control module. See Module - Steering Column Control (Remove and Replace)
  48. Remove the instrument panel service panel. See Service Panel - Instrument Panel (Remove and Replace).
    Note
    No need to remove the cabin temperature sensor from the service panel.
  49. Remove the touchscreen. See Touchscreen - Front (Remove and Replace).
  50. Remove the instrument panel speaker grille. See Speaker Grille - Instrument Panel (Remove and Replace).
  51. Remove the LH and RH dash speakers. See Speaker - Dash - LH (Remove and Replace).
  52. Remove the center dash speaker. See Speaker - Dash - Center (Remove and Replace).
  53. Remove the IP carrier. See IP Carrier (Remove and Replace)
  54. Remove the LH air wave duct. See Duct - Air Wave - LH (Remove and Replace).
  55. Release the clips (x2) that attach the headliner electrical harness to the LH lower A-pillar trim.
  56. Disconnect the HVAC connector from the LH body controller.
  57. Disconnect the IP harness J10 connector from the LH body controller.
  58. Release the clips (x2) that attach the blower motor electrical harness to the cross car beam.
  59. Disconnect the blower motor connector.
  60. Release the clips (x4) that attach the IP electrical harness to the body.
  61. Disconnect the IP electrical harness connector from the RCM.
  62. Disconnect the IP harness J10 connector from the RH body controller.
  63. Disconnect the J11 dash connector from the RH body controller.
  64. Release the clips (x2) that attach the headliner electrical harness to the RH lower A-pillar trim.
  65. Remove the LH front carpet. See Carpet - Front - LH (Remove and Replace).
  66. Remove the LH 2nd row floor duct. See Duct - Floor - 2nd Row - LH (Remove and Replace).
  67. Remove the nuts (x4) that attach the steering column to the cross car beam.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 13 mm socket
    • 3 in extension
    • Ratchet/torque wrench
    • Flex head ratchet/flex head torque wrench
  68. Lower the steering column and set it aside.
  69. Remove the clip that attaches the RH side of the main carpet to the footwell area.
  70. Remove the LH and RH cross beam bar brackets. See Riser Bracket - Instrument Panel - RH (Remove and Replace).
  71. Remove the bolts (x2) that attach the LH corners of the cross car beam to the body.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 15 mm socket
    • 3 in extension
    • Ratchet/torque wrench
  72. Remove the bolts (x2) that attach the RH corners of the cross car beam to the body.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 15 mm socket
    • 3 in extension
    • Ratchet/torque wrench
  73. Remove the bolt that attaches the cross car beam to the HVAC assembly.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
    • Ratchet/torque wrench
  74. Loosen the bolt that attaches the cross car beam to the upper side of the cowl.
    Tip
    Use of the following tool(s) is recommended:
    • 13mm 12-point combination wrench
    • Flex head ratchet/flex head torque wrench
    • Ratchet/torque wrench
    • 13 mm socket
  75. Remove the bolts (x4) that attach the cross car beam to the HVAC assembly.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 10 mm socket
    • 3 in extension
    • Ratchet/torque wrench
  76. Remove the bolts (x2) that attach the steering column to the body.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 13 mm socket
    • 3 in extension
    • Ratchet/torque wrench
    • Flex head ratchet/flex head torque wrench
  77. With an assistant, remove the cross car beam along with harness attached to the beam from the vehicle and place it on a support stand or table.
  78. Remove the bolt that attaches the HVAC module to the body.
    Note
    Recommend assistance to support the HVAC assembly during removal.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 10 mm deep socket
    • 3 in extension
    • Ratchet/torque wrench
  79. With assistance, remove the HVAC assembly from the vehicle.

Install

  1. With an assistant, position the HVAC assembly into the vehicle.
    Note
    Align the drain hose and TXV housing.
  2. Install the bolt that attaches the HVAC module to the body.
    5.5 Nm (4.1 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  3. With an assistant, install the cross car beam along with harness attached to the beam to the vehicle.
    Note
    Take care not to damage the interior components during installation.
  4. Install the bolts (x2) that attach the RH corners of the cross car beam to the body.
    29 Nm (21.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 15 mm socket
    • 3 in extension
    • Ratchet/torque wrench
  5. Install the bolts (x2) that attach the LH corners of the cross car beam to the body.
    29 Nm (21.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 15 mm socket
    • 3 in extension
    • Ratchet/torque wrench
  6. Install the bolts (x2) that attach the steering column to the body.
    25 Nm (18.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 13 mm socket
    • 3 in extension
    • Ratchet/torque wrench
    • Flex head ratchet/flex head torque wrench
  7. Install the bolt that attaches the cross car beam to the upper side of the cowl.
    25 Nm (18.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13mm 12-point combination wrench
    • Flex head ratchet/flex head torque wrench
    • Ratchet/torque wrench
    • 13 mm socket
  8. Install the bolt that attaches the cross car beam to the HVAC assembly.
    5.5 Nm (4.1 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
    • Ratchet/torque wrench
  9. Install the bolts (x4) that attach the cross car beam to the HVAC assembly.
    Tip
    Use of the following tool(s) is recommended:
  10. Install the LH and RH cross beam bar brackets. See Riser Bracket - Instrument Panel - RH (Remove and Replace).
  11. Fasten the clips (x2) that attach the headliner electrical harness to the LH lower A-pillar trim.
  12. Connect the HVAC connector to the LH body controller.
  13. Connect the IP harness J10 connector to the LH body controller.
  14. Fasten the clips (x2) that attach the blower motor electrical harness to the cross car beam.
  15. Connect the blower motor connector.
  16. Fasten the clips (x4) that attach the IP electrical harness to the body.
  17. Connect the IP electrical harness connector to the RCM.
  18. Fasten the clips (x2) that attach the headliner electrical harness to the RH lower A-pillar trim.
  19. Connect the J11 dash connector to the RH body controller.
  20. Connect the IP harness J10 connector to the RH body controller.
  21. Position the steering column for installation.
  22. Install the nuts (x4) that attach the steering column to the cross car beam.
    15 Nm (11.1 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 13 mm socket
    • 3 in extension
    • Ratchet/torque wrench
    • Flex head ratchet/flex head torque wrench
  23. Install the LH 2nd row floor duct. See Duct - Floor - 2nd Row - LH (Remove and Replace).
  24. Install the LH front carpet. See Carpet - Front - LH (Remove and Replace).
  25. Fasten the clip that attaches the RH side of the main carpet to the footwell area.
  26. Install the LH air wave duct. See Duct - Air Wave - LH (Remove and Replace).
  27. Install the IP carrier. See IP Carrier (Remove and Replace)
  28. Install the LH and RH dash speakers. See Speaker - Dash - LH (Remove and Replace).
  29. Install the center dash speaker. See Speaker - Dash - Center (Remove and Replace).
  30. Install the instrument panel speaker grille. See Speaker Grille - Instrument Panel (Remove and Replace).
  31. Install the touchscreen. See Touchscreen - Front (Remove and Replace).
  32. Install the instrument panel service panel. See Service Panel - Instrument Panel (Remove and Replace).
    Note
    No need to install the cabin temperature sensor to the service panel.
  33. Install the steering column control module. See Module - Steering Column Control (Remove and Replace)
  34. Install the steering column lower shroud. See Shroud - Lower - Steering Column (Remove and Replace).
  35. Install the steering column upper shroud. See Shroud - Upper - Steering Column (Remove and Replace).
  36. Install the steering wheel. See Steering Wheel (Remove and Replace).
  37. Install the driver airbag. See Airbag - Driver (Remove and Replace).
  38. Install the lower instrument panel. See Assembly - Instrument Panel - Lower (Remove and Replace).
  39. Install the center console assembly to the vehicle.
  40. Fasten the clip and connect the electrical connector to the front of the center console.
  41. Connect the electrical connector from the rear of the center console.
  42. Install the bolts (x2) that attach the RH front of the center console to the body.
    7 Nm (5.2 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 10 mm socket
    • 2 in extension
    • Ratchet/torque wrench
  43. Install the bolts (x2) that attach the LH front of the center console to the body.
    7 Nm (5.2 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 10 mm socket
    • 2 in extension
    • Ratchet/torque wrench
  44. Install the bolts (x2) that attach the LH and RH rear of the center console to the body.
    7 Nm (5.2 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 10 mm socket
    • 2 in extension
    • Ratchet/torque wrench
  45. Install the RH center console front side panel. See Carpet - Side - Center Console - RH (Remove and Replace).
  46. Install the LH center console front side panel. See Carpet - Side - Center Console - LH (Remove and Replace).
  47. Install the center console end panel. See Panel - Rear End - Center Console (Remove and Replace).
  48. Install the LH footwell duct. See Duct - Footwell - LH (Remove and Replace).
  49. Install the driver footwell cover. See Cover - Footwell - Driver (Remove and Replace).
  50. Install the RH air wave duct. See Duct - Air Wave - RH (Remove and Replace).
  51. Connect the RH airwave duct thermistor connector.
  52. Install the RH footwell duct. See Duct - Footwell - RH (Remove and Replace).
  53. Install the glove box. See Glove Box (Remove and Replace).
    Note
    No need to install the glove box USB cable.
  54. Install the passenger footwell cover. See Cover - Footwell - Front Passenger (Remove and Replace).
  55. Install the LH and RH upper A-pillar trims. See Trim - A-Pillar - Upper - LH (Remove and Replace).
  56. Install the LH 1st row seat assembly. See Seat Assembly - 1st Row - LH (Remove and Replace).
    Note
    Do not install new bolts (x4) that attach the front and rear of the LH 1st row seat to the body at this moment.
  57. Install the LH lower A-Pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  58. Install the LH and RH instrument panel end caps. See End Cap - Instrument Panel - LH (Remove and Replace).
  59. Replace the seal washers on the supermanifold to HVAC A/C line to the HVAC assembly.
    Note
    Lube the seal washers with ND-11 oil.
  60. Install the bolts (x2) that attach the supermanifold to HVAC A/C line to the HVAC assembly.
    28 Nm (20.6 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  61. Install the wiper module. See Wiper Module (LHD) (Remove and Replace).
  62. Install the cowl screen panel. See Panel - Cowl Screen (Remove and Replace).
  63. Install the LH and RH shock tower covers. See Cover - Shock Tower - LH (Remove and Install).
  64. Install the LH and RH wiper arms and blades. See Wiper Arm - Driver Side (Remove and Replace).
  65. Perform the vacuum leak test and oil injection procedure. See Vacuum Leak Test and Oil Injection.
  66. Recharge the A/C refrigerant. See A/C Refrigerant (Recovery and Recharge) (Restore).
  67. Connect LV power. See LV Power (Disconnect and Connect) (Modify).
  68. Connect a laptop with Toolbox to the vehicle. See Toolbox (Connect and Disconnect).
  69. In toolbox, click Action tab, type "Actuator" in the search field, and select HVAC Case Test, click Run, and allow the routine to complete.
  70. On the touchscreen, touch Thermal > Refrigerant System > Run Heat Pump Commissioning and select Run to start the routine.
  71. Run the routine: PROC_ICE_X_SAFE-SET-VEHICLE-CONFIGSvia Service Mode Plus:HVAC Blower ➜ HVAC Blower Replacement ➜ Set Blower Motor Type to Identifiedvia Toolbox:(link)
    Note
    Firmware must be on develop/2026.32.3 and factory/2026.26.200 or later.
  72. Reinstall firmware through service UI. See Software Reinstall - Touchscreen.
  73. Run the routine: TEST_VC_X_HVAC-BLOWER-IDENTIFICATION-AND-HVAC-PERFORMANCEvia Service Mode Plus:
    • HVAC Blower ➜ HVAC Blower Replacement ➜ Test HVAC Performance + Blower Identification
    • Thermal ➜ Actions ➜ Test HVAC Performance + Blower Identification
    via Toolbox:(link)
  74. On the vehicle touchscreen, touch Controls > Service > Maintenance > Cabin Air Filter Replacement > Record maintenance details > Confirm to reset the cabin air filter maintenance record.
  75. Disconnect the laptop from the vehicle.
  76. Exit Service Mode through UI. See Service Mode.
  77. Install the fresh air duct. See Fresh Air Intake - HVAC (Remove and Replace).
  78. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  79. Install the access panel. See Cover - Hood Latch (Remove and Replace).
  80. Install the cabin intake duct. See Assembly - Fresh Air Gutter - HVAC (Remove and Replace).
  81. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  82. Install new bolts (x4) that attach the front and rear of the LH 1st row seat to the body. See Seat Assembly - 1st Row - LH (Remove and Replace).
  83. Move the steering column to its original position.
