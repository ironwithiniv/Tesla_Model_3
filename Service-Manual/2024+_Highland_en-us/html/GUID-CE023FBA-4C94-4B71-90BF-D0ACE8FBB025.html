Harness - Front Door Trim - Driver (Remove and Replace)

Correction code 1710020052 FRT 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1710 - Harnesses

Remove

  1. Open the LH front door, and then lower the LH front window.
  2. Remove the LH front door reflector. See Reflector - Door - Front - LH (Remove and Replace).
  3. Remove the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
  4. Remove the LH front door puddle light. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  5. Remove the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  6. Remove the LH front door NVH pad. See NVH Pad - Door - Front - LH (Remove and Replace).
  7. Disconnect the LH front door electric release switch connector from the LH front door trim panel.
  8. Disconnect the LH front door window switch connector from the LH front door trim panel.
  9. Disconnect the LH front door LED light connector from the LH front door trim panel.
  10. Disconnect the LH front door atmosphere light connector from the LH front door trim panel.
  11. Disconnect the LH front door speaker connector from the LH front door trim panel.
  12. Release the clips (x9) that attach the LH front door harness to the LH front door trim panel, and then remove the harness from the vehicle.

Install

  1. Install the clips (x9) that attach the LH front door harness to the LH front door trim panel.
  2. Connect the LH front door speaker connector to the LH front door trim panel.
  3. Connect the LH front door atmosphere light connector to the LH front door trim panel.
  4. Connect the LH front door LED light connector to the LH front door trim panel.
  5. Connect the LH front door window switch connector from the LH front door trim panel.
  6. Connect the LH front door electric release switch connector to the LH front door trim panel.
  7. Install the LH front door NVH pad. See NVH Pad - Door - Front - LH (Remove and Replace).
  8. Install the LH front door puddle light. See Puddle Lamp - Front Door (LH) (Remove and Replace).
  9. Install the LH front door trim panel. See Panel - Door Trim - Front - LH (Remove and Replace).
  10. Install the LH front door reflector. See Reflector - Door - Front - LH (Remove and Replace).
  11. Install the LH front door tweeter. See Tweeter - Front Door - LH (Remove and Replace).
  12. Raise the LH front window, and then close the LH front door.
