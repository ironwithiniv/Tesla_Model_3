Check Strap - Door - Rear (Remove and Replace)

Correction code 1133050012 FRT 0.54 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1133 - Closure Assist Mechanisms and Hinges

Torque Specifications

Table 1. Torque Specifications: Check Strap - Door - Rear (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolt that attaches the LH rear door check strap to the body
24 Nm (17.7 lbs-ft)
  • Torx T40 socket
 Reuse
Nuts (x2) that attach the LH rear door check strap to the LH rear door
10 Nm (7.4 lbs-ft)
  • 10 mm deep socket
 Reuse

Remove

  1. Open the LH front door and lower the LH front window.
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Remove the LH rear door puddle light. See Puddle Lamp - Rear Door (Remove and Replace).
  4. Remove the LH rear door trim panel. See Panel - Door Trim - Rear - LH (Remove and Replace).
  5. Remove the LH rear door glass. See Glass - Door - Rear - LH (Remove and Replace).
  6. Disconnect LV power. See LV Power (Disconnect and Connect) (Modify).
  7. Remove the LH rear window regulator assembly. See Window Motor / Regulator Assembly - Rear - LH (Remove and Replace).
  8. Remove the bolt that attaches the LH rear door check strap to the body.
    Note
    Unbolting the door check allows the door to swing freely beyond opening limits.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T40 socket
  9. Remove the nuts (x2) that attach the LH rear door check strap to the LH rear door.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  10. Reach inside the door opening and remove the check strap from the door.

Install

  1. Position the check strap through the door opening.
  2. Install the nuts (x2) that attach the LH rear door check strap to the LH rear door.
    10 Nm (7.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  3. Install the bolt that attaches the LH rear door check strap to the body.
    24 Nm (17.7 lbs-ft)
    Note
    Unbolting the door check allows the door to swing freely beyond opening limits.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T40 socket
  4. Install the LH rear window regulator assembly. See Window Motor / Regulator Assembly - Rear - LH (Remove and Replace).
  5. Connect LV power. See LV Power (Disconnect and Connect) (Modify).
  6. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  7. Install the LH rear door glass. See Glass - Door - Front - LH (Remove and Replace).
  8. Install the LH rear door puddle light. See Puddle Lamp - Rear Door (Remove and Replace).
  9. Install the LH rear door trim panel. See Panel - Door Trim - Rear - LH (Remove and Replace).
  10. Calibrate the window. See Window Regulator (Recalibrate) (Maintenance).
