Fascia - Rear - Lower (Base) (Remove and Replace)

Correction code 1001040022 FRT 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1001 - Bumper / Fascia

Torque Specifications

Table 1. Torque Specifications: Fascia - Rear - Lower (Base) (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x4) that attach the lower rear fascia to the upper rear fascia
3 Nm (2.2 lbs-ft)
  • 10 mm socket
 Reuse

Remove

  1. Remove the rear fascia assembly. See Fascia Assembly - Rear (Remove and Install)
  2. Remove the rear fascia diffuser. See Diffuser - Rear Fascia (Remove and Replace).
  3. Remove the bolts (x4) that attach the lower rear fascia to the upper rear fascia.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  4. Remove the LH and RH rear fascia lamp assemblys. See Rear Fascia Light - LH (Remove and Replace).
  5. Remove the tabs (x19) that attach the lower fascia to the upper fascia.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  6. Remove the lower fascia.

Install

  1. Install the tabs (x19) that attach the lower fascia to the upper fascia from either side.
  2. Install the LH and RH rear fascia lamp assemblys. See Rear Fascia Light - LH (Remove and Replace).
  3. Install the bolts (x4) that attach the lower rear fascia to the upper rear fascia.
    3 Nm (2.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  4. Install the rear fascia diffuser. See Diffuser - Rear Fascia (Remove and Replace).
  5. Install the rear fascia assembly. See Fascia Assembly - Rear (Remove and Install).
