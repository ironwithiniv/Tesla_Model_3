Fresh Air Intake - HVAC (Remove and Replace)

Correction code 1810010042 FRT 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1810 - Cabin HVAC

Remove

  1. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  2. Remove the RH clips (x2) that attach the cowl screen to the vehicle.
  3. Release the fresh intake duct from the studs (x2) on the bulkhead, and then remove the duct from the vehicle.
    Note
    Lift the cowl screen as needed.

Install

  1. Align the fresh intake duct to the studs (x2) on the bulkhead, and then install the duct to the vehicle.
    Note
    Lift the cowl screen as needed.
  2. Install the RH clips (x2) that attach the cowl screen to the vehicle.
  3. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
