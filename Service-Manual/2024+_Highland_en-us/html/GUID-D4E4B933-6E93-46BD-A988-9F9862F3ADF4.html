Ball Joint - Knuckle - Rear Upper - LH (Inspect) (Test/Adjust)

Correction code 31030110 FRT 0.36 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1064697-00-B - KIT, BRAKE ROTOR RUN OUT
Note
This procedure specifies to measure the axial clearance, as studies have shown that this axial clearance is typically larger than the radial clearance, and it is therefore the leading value.
Parent topic: 3103 - Rear Suspension (Including Hubs)

Procedure

  1. Remove the LH rear wheel. See Wheel Assembly (Remove and Install).
  2. Remove the bolt that attaches the LH rear rotor to the LH rear hub.
  3. Install the nuts (x5) that attach the brake rotor run out clamping plate onto the LH rear rotor.
    100 Nm (73.7 lbs-ft)
    Note
    This simulates the wheel being installed, preventing inaccurate measurements.
  4. Install tape onto the LH rear upper aft link.
  5. Install the brake rotor runout tool onto the LH rear upper aft link and set it up for reading.
    Note
    Pay attention to the clamp location and the routing of the flex bar. Firmly connect the indicator rod to the lowest friction part of brake rotor. Align the measurement rod with the upper aft link and make sure that the indicator rod is properly depressed, allowing travel in both directions without bottoming out. Set the measurement to zero. Make sure the flex bar is free of the brake rotor and shield.
  6. Install vise grips onto the rear knuckle.
  7. Inspect the LH rear upper knuckle ball joint play.
    Note
    Move the vise grips in parallel to the AFT link. Record the values shown on the analog indicator. Replace the LH rear upper knuckle ball joint if the play exceeds 1.00 mm (0.039 inch).
  8. Remove the vice grips from the rear knuckle.
  9. Remove the brake rotor runout tool from the rear upper aft link.
  10. Remove the tape from the rear upper aft link.
  11. Remove the brake rotor runout clamping plate from the LH rear rotor.
  12. Install the bolt that attaches the LH rear rotor to the LH rear hub.
    5 Nm (3.7 lbs-ft)
  13. Install the rear wheel. See Wheel Assembly (Remove and Install).
