Duct - Defrost - LH (Remove and Replace)

Correction code 1405030092 FRT 1.44 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-02-10: Updated the screw torque value securing the duct to the IP carrier.
Parent topic: 1405 - Instrument Panel

Remove

  1. Remove the IP carrier. See IP Carrier (Remove and Install).
  2. Remove the screws (x2) that attach the LH air wave duct to the IP carrier, and then remove the duct from the IP carrier.

Install

  1. Install the LH air wave duct to the IP carrier, and then install the screws (x2) that attach the duct to the IP carrier.
    0.9 Nm (8 lbs-in)
  2. Install the IP carrier. See IP Carrier (Remove and Install).
