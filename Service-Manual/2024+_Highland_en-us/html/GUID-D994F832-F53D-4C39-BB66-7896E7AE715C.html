Seat Assembly - 1st Row - LH (Remove and Replace)

Correction code 1304010022 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2024-12-10: Added mini-tilt motor configuration information.
CAUTION
Supplemental Restraint System (SRS) components can be hazardous if not serviced and handled correctly. See Airbag and Supplementary Restraint System (SRS) Precautions
CAUTION
In the event of an airbag or seatbelt pretensioner deployment, certain components must be replaced, and other components must be inspected for damage. Refer to the Collision Repair Manual for a specific list of items that must be inspected and replaced.
Parent topic: 1304 - Front Seat Assemblies and Hardware

Torque Specifications

Table 1. Torque Specifications: Seat Assembly - 1st Row - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Front seat to body bolts (X4)
33.5 Nm (24.7 lbs-ft)
  • Torx Plus T45 socket
 Replace 1458818-00-B

Remove

  1. Remove rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Remove the LH IP end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  3. Remove the LH lower A-pillar assembly. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  4. Insert the seat belt release key (1133787-00-A) into the bottom of the seatbelt pretensioner coupling to release the seatbelt from the pretensioner.
  5. Move the seat fully forward.
  6. Remove and discard the bolts (x2) that attach the rear of the 1st row LH seat to the body.
    CAUTION
    Use only the Torx Plus T45 bit to remove the seat bolts.
    Tip
    Use of the following tool(s) is recommended:
    • Torx Plus T45 socket
    Note
    Use the torchless heat induction tool to ease the removal of patch bolts, if necessary.
  7. Move the seat fully rearward.
  8. Remove and discard the bolts (x2) that attach the front of the 1st row LH seat to the body.
    CAUTION
    Use only the Torx Plus T45 bit to remove the seat bolts.
    Tip
    Use of the following tool(s) is recommended:
    • Torx Plus T45 socket
    Note
    Use the torchless heat induction tool to ease the removal of patch bolts, if necessary.
  9. Adjust the LH front seat to the middle of the seat tracks, and then raise the seat fully.
  10. Disconnect the LV battery power. See LV Power (Disconnect and Connect) (Modify).
  11. Locate the LH front seat electrical connector on the LH body controller module.
  12. Release the LH front seat connector lock, and then remove the connector from the LH body controller.
    Note
    Squeeze the release tab on the LH front seat connector lock, and then swing the lock away from the connector to release the lock.
    CAUTION
    Do not pull on the connector too hard. If the connector does not easily disconnect from the LH body controller, the lock is still engaged.
  13. Release the clips (x2) that attach the LH front seat harness to the LH footwell support bracket near the LH side of the LH footwell.
  14. Release the clips that attach the LH front seat harness to the LH front seat harness guide.
  15. Pull the LH front seat harness out from under the LH front carpet.
  16. With assistance, remove the seat from the vehicle.
    Note
    Lift the seat, tilt the seat back, rotate the cushion toward the front door, and remove the seat from the vehicle, cushion first.
    CAUTION
    Take care not to damage the upholstery or trim while removing the seat.
    CAUTION
    If reinstalling the seat, place the seat in an area where it is not likely to be tipped over or otherwise damaged.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.

Install

  1. Align the posts of the headrest with the holes in the driver seatback.
    Note
    The detents in the headrest posts are to the LH side.
  2. Press the headrest in firmly so that it is fully seated with a click.
  3. Pull up on the headrest to confirm that it is secure in the driver seatback.
  4. Return the driver seatback to its original position.
  5. With assistance, position the 1st row LH seat in the vehicle.
    CAUTION
    Take care not to damage the upholstery or trim while positioning the seat.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  6. Route the 1st row LH seat harness under the LH front carpet, position the harness in the harness guide, and then install the clips that attach the harness to the harness guide.
  7. Install the clips (x2) that attach the LH front seat harness to the LH footwell support bracket near the LH side of the LH footwell.
  8. Install the LH front seat harness connector on the LH body controller, and then engage the connector lock.
    Note
    Perform a push-pull test to ensure that the connector is fully seated and locked.
  9. Connect 12V power. See LV Power (Disconnect and Connect) (Modify).
  10. Move the LH front seat fully rearward.
  11. Install the new bolts (x2) that attach the front of the 1st row LH seat to the body.
    33.5 Nm (24.7 lbs-ft)
    CAUTION
    Use only the Torx Plus T45 bit to install the seat bolts.
    Tip
    Use of the following tool(s) is recommended:
    • Torx Plus T45 socket
  12. Move the LH front seat fully forward.
  13. Install the new bolts (x2) that attach the rear of the 1st row LH seat to the body.
    33.5 Nm (24.7 lbs-ft)
    CAUTION
    Use only the Torx Plus T45 bit to install the seat bolts.
    Tip
    Use of the following tool(s) is recommended:
    • Torx Plus T45 socket
  14. Install the LH 1st row seatbelt retractor onto the pretensioner.
    Note
    After reinstalling the seatbelt pretensioner into the seatbelt pretensioner coupling, perform a pull test to make sure that the seatbelt and pretensioner are securely engaged.
  15. Reinstall the vehicle firmware. See Software Reinstall - Touchscreen.
  16. Install the LH lower A-Pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  17. Install the LH IP end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  18. Replacement front seat assemblies and seat cushion frame assemblies are equipped with a newly-designed "mini-tilt" motor, and replacing these parts (or the tilt motor itself) might require a configuration change. Review the configuration information in the table and perform the following substeps if a configuration update is needed.
    1. Access the Vehicle Configuration section of the Infotainment Dashboard. See Gateway Configuration (Display and Change).
    2. Update cfg_frontSeattype according to the combination of tilt motors described in the table.
  19. Run PROC_VCLEFT_SEAT-CALIBRATEvia Service Mode:Low Voltage ➜ Seats ➜ Calibrate Seatvia Toolbox:(link).
    CAUTION
    The seat will move automatically during this routine. Prior to execution, make sure there is nothing (including objects and aftermarket accessories) behind or underneath the related seat to prevent component damage.
  20. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  21. Move the LH front seat to its original position.
