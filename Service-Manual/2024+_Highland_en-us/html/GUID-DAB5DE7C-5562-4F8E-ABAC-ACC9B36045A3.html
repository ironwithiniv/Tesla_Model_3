Strut Reinforcement - Active Hood (Remove and Replace)

Correction code 1133030052 FRT 0.06 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1080562-00-A Telescoping Hood Prop
Parent topic: 1133 - Closure Assist Mechanisms and Hinges

Torque Specifications

Table 1. Torque Specifications: Strut Reinforcement - Active Hood (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Nuts (x2) that attach the LH strut reinforcement to the hood
15 Nm (11.1 lbs-ft)
  • 13 mm socket
 Reuse

Remove

  1. Open the hood and support it with a hood prop.
  2. Release the clip that attaches the hood strut to the hood mount.
  3. Remove the nuts (x2) that attach the LH strut reinforcement to the hood, and then remove the strut reinforcement from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket

Install

  1. Install the the nuts (x2) that attach the LH strut reinforcement to the hood.
    15 Nm (11.1 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  2. Install the clip that attaches the hood strut to the hood mount.
  3. Remove the hood prop and close the hood.
