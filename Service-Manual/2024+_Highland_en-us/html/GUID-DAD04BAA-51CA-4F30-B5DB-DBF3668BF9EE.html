Remove

  1. Remove the rear fascia. See Fascia Assembly - Rear (Remove and Install)
  2. Remove the rear center bracket. See Bracket - Rear - Center (Remove and Replace).
  3. Remove the bumper beam. See Bumper Beam - Rear (Remove and Replace).

Install

  1. For EU (ECE) trailer hitch only: Perform these sub-steps to prevent water ingress and assemble the trailer hitch.
    1. Install the trailer hitch ECU to the trailer hitch assembly.
      6 Nm (4.4 lbs-ft)
      Tip
      Use of the following tool(s) is recommended:
      • 10 mm deep socket
      Note
      Verify that the stud on the trailer hitch assembly has a >0.8mm shoulder. If not, install a washer to prevent ECU damage during installation.
    2. Release the fir tree clip that attaches the trailer hitch jumper harness to the trailer hitch assembly, and then cut and remove the fir tree clip from the harness.
    3. Apply tape to the trailer hitch harness, from the trailer socket towards the trailer hitch ECU connector, keeping short overlaps to ensure no gaps are present.
      Note
      Tape the corner of the label, but keep it visible.
    4. Install a new fir tree clip onto the trailer jumper harness at approximately 23 cm (9 in) from the trailer hitch ECU connector, and then trim the excess zip tie.
    5. Route the trailer harness through the bracket, and then install the bolts (x3) that attach the trailer harness to the trailer hitch assembly.
      2.5 Nm (1.8 lbs-ft)
      Tip
      Use of the following tool(s) is recommended:
      • Wiha Torque Screwdriver 0.8-5 Nm screwdriver (installation only)
      • Torx T25 socket
    6. Attach the fir tree clip of the trailer jumper harness to the trailer hitch, and then connect the trailer hitch jumper harness electrical connector to the trailer hitch ECU.
  2. Install the trailer hitch onto the vehicle, and then install the nuts (x6) that attach the trailer hitch to the vehicle.
    60 Nm (44.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm deep socket
  3. Install the rear center bracket. See Bracket - Rear - Center (Remove and Replace).
  4. Remove the grey body harness connector from the dummy plug, and then connect the grey connector to the trailer hitch ECU.
  5. Install the rear fascia. See Fascia Assembly - Rear (Remove and Install).
  6. Connect a laptop with Toolbox 3 to the vehicle. See Toolbox (Connect and Disconnect).
  7. Select the Dashboards tab, and then select the Infotainment Dashboard and Vehicle Configuration.
  8. Select Read Config, and then click RUN to load the configuration values.
  9. Scroll down to "towPackage" and select "TESLA_REV1" from the drop-down menu.
    Note
    Although the selections in the Configuration Dashboard may suggest to select "TESLA_REV2", do not use this selection from the drop-down menu. Selecting "TESLA_REV2" for now will set the alert "VCLEFT_a318_trailerIncorrectConfig", until this issue is fixed.
  10. Select Apply Changes, and then click RUN to save the updated configuration.
  11. Disconnect the laptop from the vehicle. See Toolbox (Connect and Disconnect).
  12. Reinstall the firmware. See Software Reinstall - Touchscreen.
  13. On the touchscreen, navigate to Controls > Dynamics. Verify that the Trailer Mode toggle is present and is set to Off if no trailer is connected.
    Note
    If the toggle is not present, restart the UI.
