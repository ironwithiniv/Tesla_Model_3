Armrest - Inner - Center Console(with a Screw-secured Phone Dock) (Remove and Replace)

Correction code 1519010202 FRT 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Note
For clip-secured phone dock, use correction code 1519011202.
Parent topic: 1519 - Center Console

Remove

  1. Remove the center console phone dock assembly. See Phone Dock (Clip) - Center Console (Remove and Replace) or Phone Dock (Screw) - Center Console (Remove and Replace).
    Note
    It is not necessary to remove the inductive charger from the phone dock.
  2. Remove the rear end panel. See Panel - Rear End - Center Console (Remove and Replace).
  3. Remove the LH and RH rear side panels. See Panel - Rear Side - Center Console - LH (Remove and Replace).
  4. Remove the LH and RH front side panels. See Carpet - Side - Center Console - LH (Remove and Replace).
  5. Remove the LH and RH décor trims. See Hockey Stick Assembly -LH (with a Clip-secured Phone Dock) (Remove and Replace).
  6. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  7. Disconnect LV battery power. See LV Power (Disconnect and Connect) (Modify)
  8. Remove the rear end module assembly. See Module - Rear End - Center Console (Remove and Install)
    Note
    It is not necessary to remove the rear end module from the assembly.
  9. Remove the armrest assembly. See Armrest - Center Console (Remove and Install).
  10. Release the clips that attach the inner armrest to the armrest, then remove the inner armrest.
    Note
    Use a trim tool and start from the top of the armrest to release the clips, then work towards the bottom. If the clip is attached too tight, use a screwdriver and avoid damaging the clips.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.

Install

  1. Position the inner armrest onto the armrest.
  2. Align all clips and engage them in place.
  3. Install the armrest assembly. See Armrest - Center Console (Remove and Install).
  4. Install the rear end module assembly. See Module - Rear End - Center Console (Remove and Install)
  5. Connect LV battery power. See LV Power (Disconnect and Connect) (Modify)
  6. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  7. Install the LH and RH décor trims. See Hockey Stick Assembly -LH (with a Clip-secured Phone Dock) (Remove and Replace).
  8. Install the LH and RH front side panels. See Carpet - Side - Center Console - LH (Remove and Replace).
  9. Install the LH and RH rear side panels. See Panel - Rear Side - Center Console - LH (Remove and Replace).
  10. Install the rear end panel. See Panel - Rear End - Center Console (Remove and Replace).
  11. Install the center console phone dock assembly. See Phone Dock (Clip) - Center Console (Remove and Replace) or Phone Dock (Screw) - Center Console (Remove and Replace).
