Seal - Secondary - Front Door - LH (Remove and Replace)

Correction code 1170020032 FRT 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1170 - Seals Body Closures

Remove

  1. Open the LH front door and lower the LH front window.
  2. Release the clips (x2) that attach the rear of the LH front door inner belt seal to the LH front door.
  3. Release the clip that attaches the LH front door glass run seal to the LH front door.
  4. Slowly peel the length of the secondary seal from the perimeter of the LH front door.
    Note
    Discard the seal as it can not be reused.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  5. Clean any remaining adhesive or residue from the LH front door.
    Note
    If needed, carefully use the following tools to clean adhesive or residue:
    • 1071510-00-AWHEEL, STRIPE OFF
    • 1076972-00-A4 Piece Non-Marring Scraper Set
    • 2151853-00-A3M PN38180 Glue Cleaner_230G
    • 2150371-00-AIPA Wipers

Install

  1. Ensure the area where the secondary seal will be installed is clean.
  2. Peel a short section of the seal backing on each end of the seal and position the ends into the door assembly.
    Note
    Make sure that the open edge of the seal is facing the inside of the door.
    Note
    Make sure the front edge of the seal is under the cutout for the glass run seal, and the rear edge is under the cutout for the inner belt seal.
    Note
    Make sure that the drain holes of the seal are at the bottom of the door.
  3. Firmly press the remaining portion of the seal into place while removing the film from the double sided tape.
    Note
    Make sure that the seal is evenly distributed around the perimeter of the door.
    Note
    Do not stretch the seal as it is applied to the door.
  4. Install the clips (x2) that attach the rear of the LH front door inner belt seal to the LH front door.
  5. Install the clip that attaches the LH front door glass run seal to the LH front door.
  6. Raise the LH front window and close the LH front door.
