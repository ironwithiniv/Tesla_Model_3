Float Wing - Instrument Panel (Remove and Replace)

Correction code 1405020522 FRT 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-10-27: Added a note to turn on the A/C heater to assist with removal if necessary.
Parent topic: 1405 - Instrument Panel

Remove

  1. Open both front doors and lower both front windows.
  2. Remove the clips (x17) that secure the float wing assembly.
    CAUTION
    When disassembling, pay attention to the buckle area and place the tool at the bottom of the buckle to prevent damage to other components.
    Note
    Replace damaged fixing clips as needed.
    Note
    If necessary, turn on the A/C heater to assist with removal.
  3. Remove the damaged U-clips from the float wing substrate if any.
    Note
    Use of the following tool(s) is recommended:
    • 4-piece Mini Soft Grip Awl, Hook & Picks Set

Install

  1. Install the new U-clips (1090280-00-A) onto the float wing substrate if any clips are damaged.
    Note
    Ensure the clips are fully seated when installing.
  2. Align the datum and install the clips (x17) to secure the float wing assembly.
  3. Raise both front windows and close both front doors.
