Brake Caliper - Front (Sport Brakes) - LH (Remove and Replace)

Correction code 3301010012 FRT 0.54 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2024-06-14: Revised last step to either do a road test or perform brake pad burnishing procedure.
Parent topic: 3301 - Brake Discs and Calipers

Remove

  1. Place the vehicle on the 2-post lift.
    Tip
    Ensure the vehicle is not charging.
  2. Open the LH front door and lower the LH front window.
  3. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  4. Remove the LH front wheel. See Wheel Assembly (Remove and Install).
  5. Position an oil drain receiver under the LH front brake hose area.
  6. Release the bolt that attaches the LH front brake hose bracket to the knuckle.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  7. Remove the nut that attaches the LH front brake line to the LH front brake hose.
    Tip
    Use of the following tool(s) is recommended:
    • 12 mm socket
  8. Remove the nut that attaches the LH front brake hose to body.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  9. Remove and discard the bolt that attaches the LH front brake hose to the LH front brake caliper.
    Tip
    Use of the following tool(s) is recommended:
    • 11 mm deep socket
  10. Remove and discard the bolts (x2) that attach the LH front brake caliper to the LH front knuckle, and then remove the front brake caliper.
    Tip
    Use of the following tool(s) is recommended:
    • External Torx E18
    • Breaker bar

Install

  1. Install new bolts (x2) (1088969-00-B) that attach the LH front brake caliper to the LH front knuckle.
    94 Nm (69.3 lbs-ft)
    CAUTION
    Make sure the brake caliper and hoses are not twisted when hanging the caliper or during reinstallation, as this can damage the brake hose.
    Note
    Mark with a paint pen. If used, remove the S-hook from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • External Torx E18
    • Breaker bar
  2. Install the bolt that attaches the new LH front brake hose to the LH front brake caliper.
    42 Nm (31.0 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 11 mm deep socket
  3. Install the nut that attaches the LH front brake hose to body.
    6 Nm (4.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  4. Install the nut that attaches the LH front brake line to the LH front brake hose.
    16 Nm (11.8 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 12 mm socket
  5. Install the bolt that attaches the LH front brake hose bracket to the knuckle.
    5 Nm (3.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  6. Remove the oil drain receiver from underneath the vehicle.
  7. Bleed the LH front caliper. See Brake Fluid Bleed - One Caliper (Maintenance).
  8. Install the LH front wheel. See Wheel Assembly (Remove and Install).
  9. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  10. Raise the LH front window and close the LH front door.
  11. Remove the lift arms from below the vehicle.
  12. Perform a road test and burnish the brakes.
  13. Perform one of the following:
    • If the brake pads were not replaced in this procedure, perform a road test using a series of aggressive stops and make sure that there is proper brake pedal feel and brake performance.
      Note
      Add test drive correction code 00040100 as a separate activity to the Service Visit.
    • If the brake pads were replaced in this procedure, perform the brake pad burnishing procedure. See Brake Pads - Burnishing.
      Note
      Add the correction code for brake pad burnishing 33013000 as a separate activity to the Service Visit.
