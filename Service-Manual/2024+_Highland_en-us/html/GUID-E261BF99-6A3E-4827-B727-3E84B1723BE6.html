Link - Aft - Lower - Rear - LH (Remove and Replace)

Correction code 3103030112 FRT 0.72 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1137855-00-A TOOL, REAR RIDE HEIGHT TORQUE, MODEL 3
  • 1081765-00-A 3/4 TON UNDERHOIST STAND
  • 1459409-00-A ADAPTER, HUB JACK, MODEL 3
Parent topic: 3103 - Rear Suspension (Including Hubs)

Remove

  1. Inspect the vehicle for abnormal tire wear that might indicate the need for a wheel alignment. Note any findings.
  2. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  3. Remove the LH rear wheel. See Wheel Assembly (Remove and Install).
  4. Remove the rear aero shield panel. See Panel - Aero Shield - Rear (Remove and Replace).
  5. Remove the bolts (x2) that attach the front of the diffuser to the body.
    Note
    Use of the following tool(s) is recommended:
    • 10 mm socket
  6. Remove the LH rear suspension cover. See Cover - Rear Suspension - LH (Remove and Replace).
  7. Remove the LH rear suspension spring. See Coil Spring - Rear - LH (Remove and Replace).
  8. Remove the bolt and nut that attach the LH rear lower aft link to the rear subframe.
    Note
    Use of the following tool(s) is recommended:
    • 21 mm socket
    • 21 mm combination wrench
  9. Remove the LH rear lower aft link from the subframe.

Install

  1. Install the LH rear lower aft link to the rear subframe, then install and hand-tighten the bolt and nut that attach the link to the subframe.
    Note
    The step of tightening this bolt is included in the installation of the LH rear suspension spring.
    Note
    Use of the following tool(s) is recommended:
    • 21 mm socket
    • 21 mm combination wrench
  2. Install the LH rear suspension spring. See Coil Spring - Rear - LH (Remove and Replace).
  3. Install the bolts (x2) that attach the front of the diffuser to the body.
    4 Nm (2.9 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • 10 mm socket
  4. Install the LH rear suspension cover. See Cover - Rear Suspension - LH (Remove and Replace).
  5. Install the rear aero shield panel. See Panel - Aero Shield - Rear (Remove and Replace).
  6. Install the LH rear wheel. See Wheel Assembly (Remove and Install).
  7. Refer to the Alignment Requirement tables to determine whether an EPAS alignment check (EC) or four wheel alignment check (AC) is necessary. If performed, add the alignment check/adjust as a separate activity. See Alignment Requirement - Suspension.
