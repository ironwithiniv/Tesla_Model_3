Headlights (Check Aiming)

  • Tesla's factory specification for headlight inclination is -1%. Check local regulations for individual country's tolerances on this value. The factory headlight aiming specification Is stamped onto the headlight housing, but not always easy to see. See images below for reference.
  • When checking headlight/fog light aiming, do not set the vehicle to the Adjust Headlights mode through the touchscreen. Doing so via Controls > Service > Adjust Headlights creates a non standard headlight beam pattern. This function should not be used for the aiming check and should only be used by trained personnel for aiming adjustment.
  • Details on Tesla's headlight and fog light aiming check procedures can be found in following section.
