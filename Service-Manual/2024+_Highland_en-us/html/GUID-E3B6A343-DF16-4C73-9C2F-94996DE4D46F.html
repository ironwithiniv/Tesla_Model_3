Height Adjuster - Seatbelt - LH (Remove and Replace)

Correction code 1518010152 FRT 0.36 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2024-11-14: Updated the torque information of the bolt that attaches the D-ring to the height adjuster from 20 Nm to 30 Nm.
Parent topic: 2005 - Seatbelts

Torque Specifications

Table 1. Torque Specifications: Height Adjuster - Seatbelt - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolt that attaches the D-ring to the height adjuster
30 Nm (22.1 lbs-ft)
  • Torx T50 socket
  • 3 in extension
  • Cordless Ratchet/Impact Driver
  • Flex head ratchet/flex head torque wrench (for installation only)
 Replace The bolt is patched
Bolt that attaches the height adjuster to the body
20 Nm (14.7 lbs-ft)
  • Torx T50 socket
  • 3 in extension
  • Cordless Ratchet/Impact Driver
  • Flex head ratchet/flex head torque wrench (for installation only)
 Replace The bolt is patched

Remove

  1. Remove the LH side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  2. Remove the seat cushion. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  3. Remove the end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  4. Remove the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  5. Remove the lower B-pillar trim. See Trim - B-Pillar - Lower - LH (Remove and Replace).
  6. Remove the middle B-pillar trim. See Trim - B-Pillar - Middle - LH (Remove and Replace).
  7. Remove and discard the bolt that attaches the D-ring to the height adjuster.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket
    • 3 in extension
    • Cordless Ratchet/Impact Driver
    • Flex head ratchet/flex head torque wrench (for installation only)
  8. Remove and discard the bolt that attaches the height adjuster to the body.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket
    • 3 in extension
    • Cordless Ratchet/Impact Driver
    • Flex head ratchet/flex head torque wrench (for installation only)
  9. Remove the adjustable top loop.

Install

  1. Install the adjustable top loop.
  2. Install a new bolt to attach the height adjuster to the body.
    20 Nm (14.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket
    • 3 in extension
    • Cordless Ratchet/Impact Driver
    • Flex head ratchet/flex head torque wrench (for installation only)
  3. Install a new bolt to attach the D-ring to the height adjuster.
    30 Nm (22.1 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket
    • 3 in extension
    • Cordless Ratchet/Impact Driver
    • Flex head ratchet/flex head torque wrench (for installation only)
  4. Install the middle B-pillar trim. See Trim - B-Pillar - Middle - LH (Remove and Replace).
  5. Install the lower B-pillar trim. See Trim - B-Pillar - Lower - LH (Remove and Replace).
  6. Install the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  7. Install the end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  8. Install the seat cushion. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  9. Install the LH side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
