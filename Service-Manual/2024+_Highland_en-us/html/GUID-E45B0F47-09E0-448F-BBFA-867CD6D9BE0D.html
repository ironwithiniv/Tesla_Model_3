Trim - Seat Back - 2nd Row - LH (Remove and Replace)

Correction code 1308010072 FRT 0.66 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1501599-00-A, Pliers, Hog Ring
Parent topic: 1308 - 2nd Row Seat Covers Pads and Trims

Remove

  1. Remove the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  2. Remove the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  3. Remove the LH 2nd row seat back. See Seatback - 2nd Row - LH (Remove and Replace).
  4. Remove the LH 2nd row seat back hinge bracket. See Bracket - Hinge - Seat Back - 2nd Row (Remove and Replace).
  5. Remove the LH 2nd row seat back handle bezel. See Bezel - Handle - Seat Back - 2nd Row - LH (Remove and Replace).
  6. Remove the 2nd row center escutcheon. See Escutcheon - Seat Belt - Center (Remove and Replace).
  7. Remove the 2nd row armrest closeout. See Closeout - Armrest - 2nd Row (Remove and Replace).
  8. Remove the 2nd row armrest. See Armrest - 2nd Row (Remove and Replace).
  9. Remove the clips (x2) that attach the cover plate to the seat assembly.
  10. Unhook the LH seat back armrest upholstery wire that attach the LH seat back upholstery cover to the seat back frame.
  11. Put the electrical harness through the LH 2nd row seat back upholstery cover.
  12. Release the lower portion of the LH 2nd row seat back upholstery cover from the pivot bar, and then remove the seat back assembly from the seat back frame.
    Note
    Start from the LH of seat back and to the RH.
  13. Gently separate the LH 2nd row seat back upholstery cover from the foam starting from the bottom of the cover.
    Note
    Make sure the Velcro does not damage the foam pad.
  14. Use diagonal cutters to cut the hog rings (x3) at the center of the seat back, and then release the cover from the hog rings.
    Note
    Push down on the foam to gain access to the rings.
    Note
    Remove any excess hog ring pieces.
  15. Gently release the remaining Velcro that attach the LH 2nd row seat back upholstery cover to the foam pad.
    Note
    Make sure the Velcro does not damage the foam pad.
  16. Feed the seat belt through the upholstery cover, and then remove the cover from the foam pad.

Install

  1. Starting from the upper seat back, feed the seat belt through the upholstery cover, and then install the LH 2nd row seat back upholstery cover.
    Note
    Massage the Velcro while working downward toward the center of the seat back.
  2. Use hog ring pliers to crimp new hog rings (1566544-00-A x3) to the LH 2nd row seat back upholstery cover at the center of the seat back.
    Note
    Place the hog ring into the hog ring pliers prior to installation.
    Note
    Push down on the foam to gain access to the rings.
  3. Attach the remaining portion of the LH 2nd row seat back upholstery cover to the seat back.
  4. Install the lower portion of the LH 2nd row seat back upholstery cover to the pivot bar.
  5. Put the electrical harness through the LH 2nd row seat back upholstery cover.
  6. Hook the LH seat back armrest upholstery wire that attach the LH 2nd row seat back upholstery cover to the seat back frame.
  7. Install the clips (x2) that attach the cover plate to the seat assembly.
  8. Install the 2nd row armrest. See Armrest - 2nd Row (Remove and Replace).
  9. Install the 2nd row armrest closeout. See Closeout - Armrest - 2nd Row (Remove and Replace).
  10. Install the 2nd row center escutcheon. See Escutcheon - Seat Belt - Center (Remove and Replace).
  11. Install the LH 2nd row seat back handle bezel. See Bezel - Handle - Seat Back - 2nd Row - LH (Remove and Replace).
  12. Install the LH 2nd row seat back hinge bracket. See Bracket - Hinge - Seat Back - 2nd Row (Remove and Replace).
  13. Install the LH 2nd row seat back. See Seatback - 2nd Row - LH (Remove and Replace).
  14. Install the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  15. Install the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
