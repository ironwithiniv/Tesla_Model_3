Super Horn (Remove and Replace)

Correction code 2121010812 FRT 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 2121 - Audio System - Speakers Subwoofer Amplifier

Torque Specifications

Table 1. Torque Specifications: Super Horn (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Screws (x3) that attach the super horn to the valance
1.8 Nm (1.3 lbs-ft)
  • Torx T25 socket
 Reuse

Remove

  1. Remove the RH front wheel. See Wheel Assembly (Remove and Install).
  2. Release the push clips (x9) that attach the RH front wheel arch liner to the vehicle, and then partially remove the RH front wheel arch liner.
  3. Release the clip that attaches the super horn harness to the super horn, and then disconnect the super horn connector.
    Note
    The connector access may vary depending on the version of the super horn audio speaker installed on the vehicle.
  4. Remove the screws (x3) that attach the super horn to the valance, and then remove the super horn from the valance.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket

Install

  1. Install the super horn to the valance, and then install the screws (x3) that attach the super horn to the valance.
    1.8 Nm (1.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket
  2. Connect the super horn connector, and then install the clip that attaches the super horn harness to the super horn.
  3. Install the RH front wheel arch liner back to the vehicle, and then install the push clips (x9) that attach the RH front wheel arch liner to the vehicle.
  4. Install the RH front wheel. See Wheel Assembly (Remove and Install).
