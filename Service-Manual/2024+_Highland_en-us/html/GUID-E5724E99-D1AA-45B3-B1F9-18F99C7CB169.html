Bracket - Edge Support - Seat Cushion - 2nd Row - LH (Remove and Replace)

Correction code 1302010012 FRT 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • Hexagon - 1060071-00-A
Parent topic: 1302 - 2nd Row Seat Tracks and Motors

Torque Specifications

Table 1. Torque Specifications: Bracket - Edge Support - Seat Cushion - 2nd Row - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x2) that attach the 2nd row seat cushion bracket to the vehicle
10 Nm (7.4 lbs-ft)
  • 10 mm socket
  • Hexagon - 1060071-00-A (for installation only)
 Reuse

Remove

  1. Remove the 2nd row seat LH side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace)
  2. Remove the 2nd row seat cushion. See Seat Cushion - 2nd Row (Remove and Replace)
  3. Remove the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace)
  4. Remove the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace)
  5. Remove the LH lower B-pillar trim. See Trim - B-Pillar - Lower - LH (Remove and Replace)
  6. Remove the bolts (x2) securing the 2nd row seat cushion bracket and then remove the bracket from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
    • Hexagon - 1060071-00-A (for installation only)

Install

  1. Install the 2nd row seat cushion bracket to the vehicle and then install the bolts (x2) that secure the bracket.
    10 Nm (7.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
    • Hexagon - 1060071-00-A (for installation only)
  2. Install the LH lower B-pillar trim. See Trim - B-Pillar - Lower - LH (Remove and Replace)
  3. Install the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace)
  4. Install the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace)
  5. Install the 2nd row seat cushion. See Seat Cushion - 2nd Row (Remove and Replace)
  6. Install the 2nd row seat LH side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace)
