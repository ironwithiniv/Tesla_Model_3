Wheel Arch Liner - Rear - LH (Remove and Replace)

Correction code 1201020032 FRT 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1201 - Wheel Arch Liners

Remove

  1. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  2. Remove the LH rear wheel. See Wheel Assembly (Remove and Install).
  3. Release the push clips (x8) and fan clips (x7) that attach the LH rear wheel arch liner to the vehicle, and remove the liner from the vehicle.

Install

  1. Position the LH rear wheel arch liner into the vehicle.
  2. Install the push clips (x8) and fan clips (x7) that attach the LH rear wheel arch liner to the vehicle.
  3. Install the LH rear wheel. See Wheel Assembly (Remove and Install).
  4. Remove the vehicle from the lift.
