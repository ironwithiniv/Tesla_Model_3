Trunk (Remove and Replace)

Correction code 1010025012 FRT 0.84 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2024-10-23: Added a reminder for technicians to install all badges that are equipped with the working vehicle.
Equipment:

  • 1967007-00-A - REAR GRAPHIC BADGE JIG (PERFORMANCE BADGE)
  • 1967006-00-A - REAR LEFT BADGE JIG (FOR CHINA)
  • 1985785-00-A - REAR RIGHT BADGE JIG (DUAL MOTOR LETTERING)
  • 1054720-00-A - PORTABLE BENCH

Remove

  1. Remove the rear license plate bracket. See Bracket - License Plate - Rear (China) (Remove and Replace).
  2. Open the trunk from the exterior switch.
  3. Open the LH front door and lower the LH front window.
  4. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  5. Disconnect the LV power. See LV Power (Disconnect and Connect) (Modify).
  6. Remove the trunk lid trim. See Trim - Lid - Trunk (Remove and Replace).
  7. Disconnect the LH and RH tail lamp electrical connectors.
  8. Disconnect the trunk latch electrical connector.
  9. Release the locking tab and then disconnect the trunk exterior release switch electric connector.
  10. Disconnect the backup camera electric connector.
  11. Disconnect the LH and RH rear licence plate lamp electric connectors.
    Note
    Be careful not to pull on the wires.
  12. Remove the LH and RH rear license plate lamps. See License Plate Light (Remove and Replace).
  13. Remove the trunk exterior release switch. See Handle - Exterior Release - Trunk (Remove and Replace).
  14. Remove the trunk cinch latch. See Latch - Cinch - Trunk (Remove and Replace).
  15. Remove the LH and RH tail lamps. See Light - Trunk Lid - LH (Remove and Replace).
  16. Remove the trunk upper overslam bump stops.
  17. Remove the trunk lower overslam bump stops.
    Note
    Count and record the number of turns to remove bump stop.
  18. Remove and discard the bolt that attaches the trunk harness ground strap to the trunk lid.
    Note
    Inspect the bolt: if it is a self tapping tri-lobular bolt (1128269-00-A) then discard. If it is a normal bolt (1447438-00-A) then it can be reused.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  19. Release the clips (x7) that attach the trunk harness to the trunk lid.
  20. Release grommet from the trunk, and then push the trunk harness through the access hole out of the trunk lid.
  21. Release the clips (x2) that attach the trunk harness along the RH side of the decklid.
  22. Remove the bolts (x4) that attach the hinges to the trunk lid.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  23. With an assistant, remove the trunk lid from the vehicle, and then place it on a padded surface.

Install

CAUTION
If using this procedure to install an unpainted part, make sure to apply seam sealer to all seams prior to installing and painting the part. Refer to the Collision Repair manual for more information.
  1. With an assistant, position and align the trunk lid to the trunk hinges, and then install the bolt washers to the previous installation positions and hand-tighten the bolts that attach the hinges to the trunk lid.
  2. Install the clips (x2) that attach the trunk harness along the RH side of the decklid.
  3. Feed the trunk harness through the access hole of the trunk lid, and then secure the grommet to the trunk.
  4. Install the clips (x7) that attach the trunk harness to the trunk lid.
  5. Install a new bolt that attaches the trunk harness ground strap to the trunk lid.
    8 Nm (5.9 lbs-ft)
    Note
    Inspect the bolt: if it is a self tapping tri-lobular bolt (1128269-00-A) then discard. If it is a normal bolt (1447438-00-A) then it can be reused.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  6. Install the trunk lower overslam bump stops to the number of turns recorded earlier.
  7. Install the trunk upper overslam bump stops.
  8. Install the LH and RH tail lamps. See Light - Trunk Lid - LH (Remove and Replace).
  9. Install the trunk cinch latch. See Latch - Cinch - Trunk (Remove and Replace).
  10. Install the trunk exterior release switch. See Handle - Exterior Release - Trunk (Remove and Replace).
  11. Install the LH and RH rear license plate lamps. See License Plate Light (Remove and Replace).
  12. Connect the LH and RH rear licence plate lamp electric connectors.
    Note
    Be careful not to pull on the wires.
  13. Connect the backup camera electric connector.
  14. Connect the trunk exterior release switch electric connector and then engage the locking tab.
  15. Connect the trunk latch electrical connector.
  16. Connect the LH and RH tail lamp electrical connectors.
  17. Connect the LV power. See LV Power (Disconnect and Connect) (Modify).
  18. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  19. With an assistant, perform the gap and flush measurement of the trunk assembly.
    Note
    See Panel Alignment Specifications
  20. Torque the bolts (x4) that attach the hinges to the trunk lid.
    24 Nm (17.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  21. Install the trunk lid trim. See Trim - Lid - Trunk (Remove and Replace).
  22. Use IPA wipes to clean both trunk hinge bolts, washers, and surrounding area prior to paint touch up.
    Note
    Allow to dry for 1 minute.
  23. Use IPA wipes to thoroughly clean these locations on the trunk lid:
    • Hinge bolts, washers and surrounding area
    • Area between the trunk lid lower lip and trunk latch
    • Trunk lid badge area above license plate location
  24. Vigorously shake the vehicle color touch-up paint applicator for several minutes.
  25. Apply a coat of touch-up paint to the discolored areas of the hinge bolts and washers, and allow at least 20 minutes to dry.
    Note
    Perform the remainder of this procedure while the touch-up paint dries.
  26. If equipped, install the rear Tesla badge (China). See Tesla Badge - Rear (China) (Remove and Replace).
  27. Install the rear license plate bracket. See Bracket - License Plate - Rear (China) (Remove and Replace).
  28. Install the rear Tesla badge. See Tesla Badge - Rear (Remove and Replace).
    Note
    If the removed trunk/liftgate had additional badges due to vehicle configuration or regional badges, make sure that all badges are installed on the replacement trunk/liftgate.
  29. Raise the LH front window and close the LH front door.
