Hood Assembly (Remove and Replace)

Correction code 10100302 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1080562-00-A Telescoping Hood Prop
This procedure assumes the hood striker, hinges, bump stops, and plugs are undamaged. Inspect these components from the old hood and if necessary, replace with new parts.

Remove

  1. Open the LH front door and lower the LH front window.
  2. Open the hood and support it in an open position.
    Tip
    Use of the following tool(s) is recommended:
    • Telescoping Hood Prop - 1080562-00-A
  3. Release the clips (x2) that attach the LH and RH hood gas struts to the LH and RH hood strut brackets, and then set the struts aside.
  4. Remove the nuts (x4) that attach the LH and RH hood strut brackets to the old hood, and then remove the brackets.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  5. Remove the LH and RH bump stops from the old hood.
  6. With assistance, remove the nuts (x4) that attach the hood to the LH and RH hood hinges.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  7. With assistance, remove the hood from the vehicle, and then place it on a padded surface.
  8. Remove the bolts (x2) that attach the hood striker to the hood.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket

Install

CAUTION
If using this procedure to install an unpainted part, make sure to apply seam sealer to all seams prior to installing and painting the part. Refer to the Collision Repair manual for more information.
  1. Loosely install the bolts (x2) that attach the hood striker to the hood.
  2. With assistance, install the hood onto the vehicle and align with the hood hinges.
  3. Loosely install the nuts (x4) that attach the hood to the LH and RH hood hinges.
  4. Support the hood in an open position.
    Tip
    Use of the following tool(s) is recommended:
    • Telescoping Hood Prop - 1080562-00-A
  5. Install the LH and RH bump stops to the new hood.
  6. Install the nuts (x4) that attach the LH and RH hood strut brackets to the new hood.
    15 Nm (11.1 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  7. Install the clips (x2) that attach the LH and RH hood gas struts to the LH and RH hood strut brackets.
  8. Remove the hood prop, close the hood and check hood fitment.
  9. Open hood and make adjustments, if necessary.
  10. Torque the nuts (x4) that attach the hood to the LH and RH hood hinges.
    15 Nm (11.1 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  11. Torque the bolts (x2) that attach the hood striker to the hood.
    18 Nm (13.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  12. Clean the LH and RH hood hinge bolts and the surrounding area with isopropyl alcohol (IPA), and then let dry for at least 1 minute.
  13. If necessary, apply touch up paint matching the vehicle's body color to the LH and RH hood hinge studs/nuts.
  14. Clean the front of the hood with IPA, and then install a front Tesla badge. See Tesla Badge - Front (Remove and Replace).
  15. Close the hood, raise the LH front window and close the LH front door.
