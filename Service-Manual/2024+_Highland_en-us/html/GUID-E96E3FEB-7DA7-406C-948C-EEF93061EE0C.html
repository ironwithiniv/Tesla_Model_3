Door - Rear - LH (Remove and Replace)

Correction code 1010025042 FRT 1.08 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2024-01-24: Added a note in case that the shouldered / tapered bolts are not allowing for successful adjustment.
Parent topic: 1010 - Body Panels

Torque Specifications

Table 1. Torque Specifications: Door - Rear - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x4) that attach the LH rear door to the vehicle
24 Nm (17.7 lbs-ft)
  • 10 mm socket
 Reuse

Remove

  1. Open the LH front door and lower the LH front window.
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Remove the LH rear door outer belt seal. See Seal - Outer Belt - Rear Door - LH (Remove and Replace).
  4. Remove the LH rear door puddle light. See Puddle Lamp - Rear Door (Remove and Replace).
  5. Remove the LH rear door trim panel. See Panel - Door Trim - Rear - LH (Remove and Replace).
  6. Remove the LH rear door glass. See Glass - Door - Rear - LH (Remove and Replace).
  7. Disconnect LV power. See LV Power (Disconnect and Connect) (Modify).
  8. Remove the LH rear window regulator assembly. See Window Motor / Regulator Assembly - Rear - LH (Remove and Replace).
  9. Remove the LH rear door latch. See Latch - Door - Rear - LH (Remove and Replace).
  10. Remove the LH rear door outer handle. See Handle - Exterior Release - Door - Rear - LH (Remove and Replace).
  11. Remove the LH rear door harness. See Harness - Rear Door - LH (Remove and Replace).
  12. Remove the LH rear door check strap. See Check Strap - Door - Rear (Remove and Replace).
  13. With assistance, remove the bolts (x4) that attach the LH rear door assembly to the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket

Install

CAUTION
If using this procedure to install an unpainted part, make sure to apply seam sealer to all seams prior to installing and painting the part. Refer to the Collision Repair manual for more information.
  1. With assistance, hand-tighten the bolts (x4) that attach the LH rear door assembly to the vehicle.
  2. Install the LH rear door check strap. See Check Strap - Door - Rear (Remove and Replace).
  3. Install the LH rear door harness. See Harness - Rear Door - LH (Remove and Replace).
  4. Install the LH rear door outer handle. See Handle - Exterior Release - Door - Rear - LH (Remove and Replace).
  5. Install the LH rear door latch. See Latch - Door - Rear - LH (Remove and Replace).
  6. Close the LH rear door and check for gap/flushness.
    Note
    If the shouldered / tapered bolts are not allowing for successful adjustment, replace the selected shouldered / tapered bolts with 1063260-00-C. Adjust the door, if necessary. Refer to CVIS for current specifications.
  7. Tighten the bolts (x4) that attach the LH rear door assembly to the vehicle.
    24 Nm (17.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  8. Install the LH rear window regulator assembly. See Window Motor / Regulator Assembly - Rear - LH (Remove and Replace).
  9. Connect LV power. See LV Power (Disconnect and Connect) (Modify).
  10. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  11. Install a new LH rear door secondary seal. See Seal - Secondary - Rear Door - LH (Remove and Replace).
  12. Install the LH rear door glass. See Glass - Door - Rear - LH (Remove and Replace).
  13. Install the LH rear door puddle light. See Puddle Lamp - Rear Door (Remove and Replace).
  14. Install the LH rear door trim panel. See Panel - Door Trim - Rear - LH (Remove and Replace).
  15. Install the LH rear door outer belt seal. See Seal - Outer Belt - Rear Door - LH (Remove and Replace).
  16. Calibrate the window. See Window Regulator (Recalibrate) (Maintenance).
  17. Raise the LH front window and close the LH front door.
