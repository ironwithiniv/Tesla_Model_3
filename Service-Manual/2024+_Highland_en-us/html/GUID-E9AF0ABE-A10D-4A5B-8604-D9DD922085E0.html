Isolator - Rear Spring - Lower - LH (Remove and Replace)

Correction code 3115020022 FRT 0.72 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 3115 - Coil Suspension System

Remove

  1. Remove the LH rear wheel. See Wheel Assembly (Remove and Install).
  2. Remove the rear aero shield panel. See Panel - Aero Shield - Rear (Remove and Replace).
  3. Remove the LH rear suspension cover. See Cover - Rear Suspension - LH (Remove and Replace).
  4. Remove the LH rear suspension spring. See Coil Spring - Rear - LH (Remove and Replace).
  5. Remove the LH rear suspension spring lower isolator.

Install

  1. Install the LH rear suspension spring lower isolator to the spring.
    Note
    Align the stop of the spring lower isolator to the end of the spring, as illustrated.
  2. Install the LH rear suspension spring. See Coil Spring - Rear - LH (Remove and Replace).
  3. Install the LH rear suspension cover. See Cover - Rear Suspension - LH (Remove and Replace).
  4. Install the rear aero shield panel. See Panel - Aero Shield - Rear (Remove and Replace).
  5. Install the LH rear wheel. See Wheel Assembly (Remove and Install).
