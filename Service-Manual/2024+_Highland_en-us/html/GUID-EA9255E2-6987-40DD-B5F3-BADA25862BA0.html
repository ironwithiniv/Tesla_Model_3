Module - Steering Column Control (Remove and Replace)

Correction code 3205010072 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-01-13: Added step to move steering wheel away from dashboard for easier access.
  • 2025-08-15: Added the step of removing and discarding the steering module rotation retainer.
  • 2024-03-26: Removed ODIN routines from procedure as per latest validation.
CAUTION
Supplemental Restraint System (SRS) components can be hazardous if not serviced and handled correctly. See Airbag and Supplementary Restraint System (SRS) Precautions
CAUTION
In the event of an airbag or seatbelt pretensioner deployment, certain components must be replaced, and other components must be inspected for damage. Refer to the Collision Repair Manual for a specific list of items that must be inspected and replaced.

Torque Specifications

Table 1. Torque Specifications: Module - Steering Column Control (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolt that attaches the steering column control module to the steering column
2.4 Nm (1.8 lbs-ft)
  • Torx T20 socket
  • Digital Torque Screwdriver 0.10Nm - 2.0Nm
 Reuse

Remove

  1. Open the LH front door and lower the LH front window.
  2. On the touchscreen, touch Controls > Steering, use the left scroll wheel to adjust the steering column to its fully outward and fully downward position, and then touch Save.
  3. Disconnect the LV battery power. See LV Power (Disconnect and Connect) (Modify).
  4. Remove the driver airbag. See Airbag - Driver (Remove and Replace).
  5. Remove the steering wheel. See Steering Wheel (Remove and Replace).
  6. Remove the upper shroud of steering column. See Shroud - Upper - Steering Column (Remove and Replace).
  7. Remove the lower shroud of the steering wheel. See Shroud - Lower - Steering Column (Remove and Replace).
  8. Remove and discard the retaining clip from the steering column control module connector, and then disconnect the electrical harness from the steering column control module connector.
    CAUTION
    Check for broken clip pieces on the connector, and remove if present.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  9. Make sure that the clockspring tape indicator is visible in the inspection window in the upper left of the steering column control module.
  10. Remove the bolt that attaches the steering column control module to the steering column.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
    • Digital Torque Screwdriver 0.10Nm - 2.0Nm

Install

  1. Install the bolt that attaches the steering column control module to the steering column.
    2.4 Nm (1.8 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
    • Digital Torque Screwdriver 0.10Nm - 2.0Nm
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  2. Install the retaining clip to the steering column control module connector, and then connect the electrical harness to the steering column control module connector.
    CAUTION
    Check for broken clip pieces on the connector, and remove if present.
  3. Install the lower shroud of the steering wheel. See Shroud - Lower - Steering Column (Remove and Replace).
  4. Install the upper shroud of steering column. See Shroud - Upper - Steering Column (Remove and Replace).
  5. Remove and discard the steering module rotation retainer.
  6. Install the steering wheel. See Steering Wheel (Remove and Replace).
  7. Install the driver airbag. See Airbag - Driver (Remove and Replace).
  8. Connect the LV battery power. See LV Power (Disconnect and Connect) (Modify).
  9. Verify that the network connectivity is available by checking the "3G" "4G" "LTE" or Wifi icon at the upper right corner of the touchscreen.
  10. Enable Service Mode. See Service Mode.
  11. Reinstall the vehicle firmware. See Software Reinstall - Touchscreen.
  12. Disable Service Mode. See Service Mode.
  13. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  14. Adjust the steering column to its original location.
  15. Raise the LH front window and close the LH front door.
