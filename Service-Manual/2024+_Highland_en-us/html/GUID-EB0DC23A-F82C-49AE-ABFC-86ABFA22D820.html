Halfshaft - Front Drive Unit - LH (Remove and Replace)

Correction code 3930010012 FRT 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1459409-00-A ADAPTER, HUB JACK, MODEL 3
  • 1498673-00-A KIT, CABLE AXLE REMOVER, MS/MX/M3
  • 1096075-00-A Tool, Hub Puller, Hydraulic
CAUTION
If performing this procedure as a result of a collision, see the Collision Repair Manual to verify whether the steering gear must be replaced as well.
Parent topic: 3930 - Front Gearbox and Halfshafts

Remove

  1. Loosen the LH front wheel lug nuts, but do not remove the wheel at this time. See Wheel Assembly (Remove and Install).
  2. Loosen the LH front drive unit halfshaft nut.
    Note
    Use of the following tool(s) is recommended:
    • Long Breaker Bar
    • 32 mm deep impact socket
  3. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  4. Remove the LH front wheel. See Wheel Assembly (Remove and Install).
  5. Remove the bolt that attaches the LH front brake hose bracket to the LH front knuckle.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  6. Remove the bolt that attaches the LH front ABS wheel speed sensor to the knuckle.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  7. Release the clips (x2) that attach the LH front ABS wheel speed sensor to the knuckle, and then set the sensor aside.
  8. Remove and discard the LH front drive unit halfshaft nut and washers.
    Note
    The washers are attached to the nut.
  9. Remove and discard the nut that attaches the LH front tie rod end to the LH front suspension knuckle, and then remove the tie rod end from the knuckle.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 22 mm socket
    • Ratchet/torque wrench
  10. Remove the bolt and nut that attach the LH front upper control arm to the knuckle, and then discard the nut.
    Note
    Compress the upper control arm ball joint downwards to help release the bolt.
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm combination wrench
    • Torx T50 socket
    • Cordless Ratchet/Impact Driver
    • Flex head ratchet/flex head torque wrench
  11. Remove the bolt and nut that attach the strut to the lower control arm.
    Note
    Note the direction of the bolt and nut before removal.
    Note
    Use of the following tool(s) is recommended:
    • 21 mm combination wrench
    • 21 mm socket
    • Flex head ratchet/flex head torque wrench
  12. Remove the bolt that attaches the LH front brake rotor to the knuckle.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  13. Install the hydraulic hub puller onto the LH front hub, and then install and hand-tighten the nuts (x5) and washers (x5) that attach the puller to the hub.
  14. With assistance, separate the LH front drive unit halfshaft from the LH front hub, and set the halfshaft aside.
    Warning
    To reduce the risk of personal injury, wear cut resistant gloves and proper personal protective equipment (PPE) as required when removing the halfshaft. Keep hands clear from other components to prevent injury when the halfshaft releases from the Drive Unit.
  15. Remove the nuts (x5) and washers (x5), and then remove the hydraulic hub puller from the LH front hub.
  16. Install the axle removal tool between the front drive unit and the inner joint of the LH front halfshaft.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  17. With assistance, use a dead blow hammer to release the LH front halfshaft from the front drive unit, and then remove the halfshaft from the vehicle.
    Note
    Move the LH front knuckle assembly aside to provide enough clearance to safely remove the LH front drive unit halfshaft.

Install

  1. With assistance, install the LH front drive unit halfshaft into the front drive unit.
    Note
    Move the LH front knuckle assembly aside to provide enough clearance to safely install the LH front drive unit halfshaft.
    Note
    Carefully push the halfshaft into the drive unit until there is an audible "click" from the halfshaft stub contacting the pinion shaft.
    Note
    There will be a slight pulling sensation on the halfshaft as the halfshaft circlip locks into place.
    Note
    Pull on the inner halfshaft cup to confirm that the circlip is locked into place. If the halfshaft detaches from the drive unit then reinstall the halfshaft and then test that it is fully seated.
  2. Apply Molykote M-77 Lubricant Paste to the outboard side of the LH front halfshaft assembly.
    Note
    Clean the halfshaft before applying if necessary.
    Note
    Apply no more than 1 gram to axle only.
  3. Hand tighten the bolt and nut that attach the strut to the lower control arm.
  4. Position the LH front control arm to the knuckle, and then install the nut and a new bolt that attach the LH front upper control arm to the knuckle.
    56 Nm (41.3 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm combination wrench
    • Torx T50 socket
    • Cordless Ratchet/Impact Driver
    • Flex head ratchet/flex head torque wrench
  5. Position the LH front tie rod end to the LH front knuckle, and then install a new nut that attaches the LH front tie rod end to the LH front suspension knuckle.
    180 Nm (132.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 22 mm socket
    • Ratchet/torque wrench
  6. Install the bolt that attaches the LH front brake rotor to the knuckle.
    5 Nm (3.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  7. Install the bolt that attaches the LH front brake hose bracket to the LH front knuckle.
    5 Nm (3.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  8. Install the clips (x2) that attach the LH front ABS wheel speed sensor to the knuckle.
  9. Install the bolt that attaches the LH front ABS wheel speed sensor to the knuckle.
    5 Nm (3.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  10. Install the hub jack adapter onto the LH front hub and hand-tighten the lug nuts (x5).
  11. Position and raise the underhoist stand to simulate the suspension at ride height.
  12. Measure the distance between the bottom of the fender and the center of the front axle to make sure that the front suspension is set to ride height. The distance should measure 423 mm.
  13. Tighten the bolt and nut that attach the strut to the lower control arm.
    106 Nm (78.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 21 mm combination wrench
    • 21 mm socket
    • Flex head ratchet/flex head torque wrench
  14. Remove the underhoist stand from underneath the LH front suspension.
  15. Remove the lug nuts (x5) that attach the hub jack adapter, and then remove the hub jack adapter from the vehicle.
    Note
    Gently tap with a dead blow to aid
  16. Install the bolt that attaches the LH front brake rotor to the knuckle.
    5 Nm (3.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  17. Install the LH front wheel lug nuts, but do not install the wheel at this time. See Wheel Assembly (Remove and Install).
  18. Install the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  19. Install the LH front wheel. See Wheel Assembly (Remove and Install).
  20. Fully tighten the new LH front drive unit halfshaft nut.
    300 Nm (221.2 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • 32 mm deep impact socket
  21. Remove the vehicle from the lift. See Raise Vehicle - 2 Post Lift.
