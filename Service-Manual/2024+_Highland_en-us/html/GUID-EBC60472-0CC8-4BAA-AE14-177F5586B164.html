Clip - Cushion - 2nd Row Seat - LH (Remove and Replace)

Correction code 1305111002 FRT 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1305 - 2nd Row Seat Assemblies and Hardware

Remove

  1. Remove the 2nd row seat cushion. See Seat Cushion - 2nd Row (Remove and Replace)
  2. Release the tabs (x2) that attach the clip to the body, and then remove it from the vehicle.
    Note
    A plastic wedge can be used if needed.

Install

  1. Secure the tabs (x2) that attach the clip to the body.
    Note
    Once the tabs are installed properly, an audible click will be heard.
  2. Install the 2nd row seat cushion. See Seat Cushion - 2nd Row (Remove and Replace)
