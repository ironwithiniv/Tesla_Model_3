Headrest - Front Seat - LH (Sport Seat) (Remove and Replace)

Correction code 1304020302 FRT 0.06 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-03-11: Specified that bottom clip must be pressed to release headrest.
  • 2025-03-17: Added tips for the headrest removal.
  • 2024-11-18: Corrected removal step to pull headrest towards the front of the vehicle for removal.
  • 2024-10-28: Added a note specifying headrest build dates and serviceability.
Equipment:
  • Headlight Aimer - 1133367-00-A
Note
Front seat (sport seat) headrests built before June 29, 2024, are not serviceable and the 1st row seat assembly must be replaced. See Seat Assembly - 1st Row - LH (Remove and Replace).
Parent topic: 1304 - Front Seat Assemblies and Hardware

Remove

  1. Open the LH doors and lower LH windows.
  2. Partially recline the driver seatback to provide more working room for headrest removal.
  3. With assistance, pull the headrest forward to access the clips.
  4. Use a plastic trim tool to press the upper clip downwards and press the lower clip upwards to release them.
  5. Remove the headrest.

Install

  1. Align the posts of the headrest with the holes in the driver seatback, and secure the clips (x2).
    Note
    The detentes in the headrest posts are to the LH side.
    Note
    Ensure the headrest is fully seated. An audible click will be heard when installing the headrest. Ensure the headrest is seated by tugging up on the headrest.
  2. Return the driver seatback to its original position.
  3. Raise the LH windows and close the LH doors.
