Sideshield - Outboard - 1st Row Seat - LH (Model 3 Standard) (Remove and Replace)

Correction code 13070103702 13070103701 13070103802 13070103801 FRT 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-10-08: Released new procedure.
Parent topic: 1307 - Front Seat Covers Pads and Trims

Remove

  1. Open the LH front door.
  2. Lower the LH front window.
  3. Move the LH front seat forward
    Note
    Select Seat Controls on the touchscreen.
  4. Release the seat belt retractor from the LH front seat.
    Note
    Insert the special removal tool into the bottom of the retractor to release it.
  5. Raise the LH front seat cushion to the maximum height.
    Note
    Select Seat Controls on the touchscreen.
  6. Remove the bolt that secures the outer side cover to the seat.
    Note
    1x bolt, 8mm, 5 Nm, Ensure the front of the seat is high enough to access the 8mm bolt
    Tip
    Use of the following tool(s) is recommended:
  7. Release the LH outboard sideshield assembly from the LH front seat.
    Note
    Release the clips (x3) on the front portion, release the clips (x3) on the rear of the trim by pulling outwards, then lift up out of the seat so that it clears the cushion and pretensioner.

Install

  1. Install the outboard sideshield on LH front seat and engage the clips (x6).
  2. Install the screw that secures the LH 1st row outboard sideshield to the LH front seat.
    Tip
    Use of the following tool(s) is recommended:
    • 8 mm socket
    5 Nm (3.7 lbs-ft)
  3. Install the LH front seat belt retractor into the seat.
    Note
    Insert the retractor into the seat pre tensioner, then perform a push-pull-push test.
  4. Move the LH front seat to the original position.
  5. Raise the LH front window.
  6. Close the LH front door.
