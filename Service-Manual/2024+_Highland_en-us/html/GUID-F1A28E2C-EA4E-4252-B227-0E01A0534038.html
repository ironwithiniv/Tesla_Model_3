Pretensioner - Driver (Remove and Replace)

Correction code 2010010022 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

CAUTION
Supplemental Restraint System (SRS) components can be hazardous if not serviced and handled correctly. See Airbag and Supplementary Restraint System (SRS) Precautions
CAUTION
In the event of an airbag or seatbelt pretensioner deployment, certain components must be replaced, and other components must be inspected for damage. Refer to the Collision Repair Manual for a specific list of items that must be inspected and replaced.
Parent topic: 2010 - Pretensioners

Torque Specifications

  • 2026-02-20: Added note on using PROC_RCM_DISARM if using this procedure to diagnose the SRS.
Warning
If using this procedure to diagnosis the vehicle's Supplemental Restraint Systems (SRS), disarm the RCM, which will prevent all airbags and pretensioners from deploying. Re-arm the RCM after all of the vehicle's SRS components are re-installed.
  • Disarm RCM:PROC_RCM_DISARMvia Service Mode Plus:
    • Safety & Restraints ➜ Airbags ➜ Disarm RCM
    • Safety & Restraints ➜ Seats ➜ Disarm RCM

  • Re-arm RCM:PROC_RCM_ARMvia Service Mode Plus:

Description Torque Value Recommended Tools Reuse/Replace Notes
Bolt that attaches the pretensioner to the seat track
40 Nm (29.5 lbs-ft)
  • Cordless Ratchet/Impact Driver
  • Internal Torx Plus IP50 socket
  • Flex head ratchet/flex head torque wrench (for installation only)
 Replace

Remove

  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Remove the LH side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  3. Remove the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  4. Remove the end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  5. Remove the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  6. Remove the LH lower B-pillar trim. See Trim - B-Pillar - Lower - LH (Remove and Replace).
  7. Release the seatbelt retractor from the driver seat.
  8. Move the driver seat cushion all way up.
    Note
    Adjust the seat back if necessary to avoid contact with the headliner.
  9. Disconnect the LV battery. See LV Power (Disconnect and Connect) (Modify).
  10. Remove the driver seat outboard side shield. See Side Shield - Outboard - LH (Remove and Replace).
  11. Disconnect the electrical connector from the pretensioner.
  12. Remove and discard the bolt that attaches the pretensioner to the seat track.
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • Internal Torx Plus IP50 socket
    • Flex head ratchet/flex head torque wrench (for installation only)
  13. Remove the 1st row outboard lap pretensioner from the seat track.

Install

  1. Install the bolt that attaches the pretensioner to the seat track.
    40 Nm (29.5 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • Internal Torx Plus IP50 socket
    • Flex head ratchet/flex head torque wrench (for installation only)
  2. Connect the electrical connector to the pretensioner.
  3. Install the driver seat outboard side shield. See Side Shield - Outboard - LH (Remove and Replace).
  4. Connect the LV battery. See LV Power (Disconnect and Connect) (Modify).
  5. Install the seatbelt retractor to the driver seat.
  6. Install the LH lower B-pillar trim. See Trim - B-Pillar - Lower - LH (Remove and Replace).
  7. Install the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  8. Install the end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  9. Install the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  10. Install the LH side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  11. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
