Armrest Inner Assembly - Center Console (Model 3 Standard) (Remove and Replace)

Correction code 15190103702 15190103701 FRT 0.54 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-09-05: Released new procedure.
Parent topic: 1519 - Center Console

Remove

  1. Remove the USB panel assembly from the rear center console. See USB Panel Assembly - Center Console (Model 3 Standard) (Remove and Replace)
  2. Remove the screws (x6) that secure the rear end module assembly to the center console.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 bit
  3. Remove the rear end module from the center console.
  4. Remove the screws (x8) that secure the armrest hinge to the center console.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 bit
  5. Remove the armrest assembly from the center console.
  6. Release the clips (x14) on the armrest inner assembly, then remove it from the armrest assembly.
    Tip
    Use the trim tool to release the all clips from the top starting of the armrest assembly. If the clips are too tight, remove clips by gently prying with a screwdriver. Be careful not to damage the clips.

Install

  1. Install the armrest inner assembly to the armrest assembly.
    Note
    Align all clips (x14) and press the armrest inner assembly into place.
  2. Position the armrest assembly onto the center console using the alignment pins (x4).
  3. Install the screws (x8) that secure the armrest hinge to the center console.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 bit
  4. Position the rear module onto the center console using the alignment tabs (x2).
  5. Install the screws (x6) that secure the rear end module assembly to the center console.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 bit
  6. Install the USB panel assembly into the rear center console. See USB Panel Assembly - Center Console (Model 3 Standard) (Remove and Replace)
