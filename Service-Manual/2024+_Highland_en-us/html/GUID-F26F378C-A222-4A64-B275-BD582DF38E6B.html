Isolator - Motor Mount - Front - LH (Remove and Replace)

Correction code 3901010122 FRT 2.64 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Table 1. Torque Specifications: Isolator - Motor Mount - Front - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts that attach the LH motor mount isolators to the body
62 Nm (45.7 lbs-ft)
  • External Torx 3/8 in E14 Socket
  • 3 in extension
  • Flex head ratchet/flex head torque wrench
 Replace
Parent topic: 3901 - Front Drive Unit Assembly

Remove

  1. Remove the front subframe assembly. See Subframe Assembly - Front (RWD) (Remove and Replace).
  2. Remove and discard the bolts (x3) that attach the LH motor mount isolator to the body, and then remove the isolator from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • External Torx 3/8 in E14 Socket
    • 3 in extension
    • Flex head ratchet/flex head torque wrench

Install

  1. Install an O-ring to the end of each new bolt which is used to attach the LH motor mount isolator to the body.
  2. Hand-tighten the new bolts that attach the motor mount isolator to the body.
  3. Tighten the new bolts (x3) that attach the LH motor mount isolator to the body.
    62 Nm (45.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • External Torx 3/8 in E14 Socket
    • 3 in extension
    • Flex head ratchet/flex head torque wrench
  4. Install the front subframe assembly. See Subframe Assembly - Front (RWD) (Remove and Replace).
  5. Check the vehicle wheel alignment, and adjust if necessary. See Four Wheel Alignment Check (No Adjustment Needed) (Test/Adjust).
