Sensor - Exterior Door Handle - Rear - LH (Remove and Replace)

Correction code 1145010162 FRT 0.60 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1145 - Exterior Door Handles

Torque Specifications

Table 1. Torque Specifications: Sensor - Exterior Door Handle - Rear - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Screws (x2) that attach the sensor to the LH rear door exterior handle
1.2 Nm (.9 lbs-ft)
  • Torx T20 socket
 Reuse

Remove

  1. Open the LH front door and lower the LH front window.
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Remove the LH rear door puddle light. See Puddle Lamp - Rear Door (Remove and Replace).
  4. Remove the LH rear door trim panel. See Panel - Door Trim - Rear - LH (Remove and Replace).
  5. Remove the LH rear door glass. See Glass - Door - Rear - LH (Remove and Replace).
  6. Disconnect LV power. See LV Power (Disconnect and Connect) (Modify).
  7. Remove the LH rear window motor regulator assembly. See Window Motor / Regulator Assembly - Rear - LH (Remove and Replace).
  8. Remove the LH rear door outer handle. See Handle - Exterior Release - Door - Rear - LH (Remove and Replace).
  9. Remove the screws (x2) that attach the sensor to the LH rear door exterior handle, and then remove the sensor from the handle.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket

Install

  1. Install the screws (x2) that attach the sensor to the LH rear door exterior handle.
    1.2 Nm (.9 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T20 socket
  2. Install the LH rear door exterior handle. See Handle - Exterior Release - Door - Rear - LH (Remove and Replace).
  3. Install the LH rear window motor regulator assembly. See Window Motor / Regulator Assembly - Rear - LH (Remove and Replace).
  4. Connect LV power. See LV Power (Disconnect and Connect) (Modify).
  5. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  6. Install the LH rear door glass. See Glass - Door - Front - LH (Remove and Replace).
  7. Install the LH rear door puddle light. See Puddle Lamp - Rear Door (Remove and Replace).
  8. Install the LH rear door trim panel. See Panel - Door Trim - Rear - LH (Remove and Replace).
  9. Calibrate the LH rear window regulator. See Window Regulator (Recalibrate) (Maintenance).
  10. Raise the LH front window and close the LH front door.
