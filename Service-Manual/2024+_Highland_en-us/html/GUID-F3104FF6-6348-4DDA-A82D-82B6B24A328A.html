Rear End Panel - Center Console (Model 3 Standard) (Remove and Replace)

Correction code 15190402202 15190402201 FRT 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
  • 2025-09-05: Released new procedure.
  1. Open all four doors
  2. Lower all four windows
  3. Move LH front seat forward
    Note
    Via UI > Seat Controls
  4. Move RH front seat forward
    Note
    Via UI > Seat Controls
  5. Remove rear end panel assembly
    Note
    7x clips, 2x tabs, release upper clips then lower tabs
  6. Install rear end panel assembly
    Note
    7x clips, 2x tabs
  7. Move RH front seat to original position
    Note
    Via UI > Seat Controls
  8. Move LH front seat to original position
    Note
    Via UI > Seat Controls
  9. Raise all four windows
  10. Close all four doors
