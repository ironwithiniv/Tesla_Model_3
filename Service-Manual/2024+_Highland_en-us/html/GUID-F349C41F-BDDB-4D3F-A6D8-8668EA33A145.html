Trim - Lower Closeout - Armrest - 2nd Row (Remove and Replace)

Correction code 1305011312 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1305 - 2nd Row Seat Assemblies and Hardware

Remove

  1. Remove the 2nd row armrest. See Armrest - 2nd Row (Remove and Replace).
  2. Release the clips (x2) that attach the lower closeout to the LH 2nd row seat back, and then remove the closeout.

Install

  1. Secure the clips (x2) and install the lower closeout to the LH 2nd row seat back.
  2. Install the 2nd row armrest. See Armrest - 2nd Row (Remove and Replace).
