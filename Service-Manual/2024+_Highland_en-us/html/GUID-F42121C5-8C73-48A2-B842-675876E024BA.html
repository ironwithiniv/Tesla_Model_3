Harness - Trunk Lid (Remove and Replace)

Correction code 1710020082 FRT 0.66 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-12-29: Added the trunk latch cover steps and the torque table.
Parent topic: 1710 - Harnesses

Torque Specifications

Table 1. Torque Specifications: Harness - Trunk Lid (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes

Bolt that attaches the trunk ground strap to the body

Bolt that attaches the ground straps to the trunk lid
8 Nm (5.9 lbs-ft)
  • 10 mm socket
 Reuse

Remove

  1. Open all 4 doors and lower all 4 windows.
  2. Move both front seats forward.
  3. Remove the LH side rail trim. See Trim - Side Rail - LH (Remove and Replace).
  4. Remove the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  5. Remove the LH C-pillar trim. See Trim - C-Pillar - LH (Remove and Replace).
  6. Repeat step 3 through step 5 on the RH side of the vehicle.
  7. Remove the package tray trim. See Trim - Package Tray (Premium) (Remove and Replace).
  8. Remove the bolt that attaches the trunk ground strap to the body.
    CAUTION
    Take care when using hand tools near the backlight glass and defroster grid.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  9. Disconnect the trunk harness connectors (x2) .
  10. Use a clip pry tool to release the clip from the trunk harness.
  11. Use a plastic trim tool to release the trunk harness grommet and pull the trunk harness through the bulkhead.
  12. Remove the trunk latch cover. See Cover - Latch - Trunk (Remove and Replace).
  13. Remove the trunk lid trim. See Trim - Lid - Trunk (Remove and Replace).
  14. Disconnect the LH and RH taillight connectors.
  15. Disconnect the trunk latch connector.
  16. Disconnect the trunk handle connector, the backup camera connector, and the LH and RH license plate light connectors.
  17. Remove the bolt that attaches the ground straps to the trunk lid.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  18. Use a clip pry tool to release the clips (x7) that attach the trunk harness to the trunk lid.
  19. Release the grommet and pull the harness through the trunk bulkhead.
  20. Use a clip pry tool to release the clips (x2) that attach the trunk harness to the RH side of the trunk, then remove the trunk harness.

Install

  1. Position the trunk harness onto the trunk and fasten the clips (x2) that attach the trunk harness to the RH side of the trunk
  2. Fasten the grommet and move the trunk electrical harness in through the trunk bulkhead.
  3. Fasten the clips that attach the trunk electrical harness to the trunk lid.
  4. Install the bolt that attaches the trunk electrical harness ground straps to the trunk lid.
    8 Nm (5.9 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  5. Connect the trunk electrical harness to the RH and LH license plate light connectors, the trunk handle connector, and the backup camera connector.
  6. Connect the trunk electrical harness to the trunk latch connector.
  7. Connect the trunk electrical harness to the RH and LH taillight connectors.
  8. Install the trunk lid trim. See Trim - Lid - Trunk (Remove and Replace).
  9. Install the trunk latch cover. See Cover - Latch - Trunk (Remove and Replace).
  10. Fasten the grommet and move the trunk harness in through the bulkhead.
  11. Install the bolt that attaches the trunk ground strap to the body.
    8 Nm (5.9 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  12. Connect the trunk electrical harness connectors (x2).
  13. Install the package tray trim. See Trim - Package Tray (Premium) (Remove and Replace).
  14. Install the LH C-pillar trim. See Trim - C-Pillar - LH (Remove and Replace).
  15. Install the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  16. Install the LH side rail trim. See Trim - Side Rail - LH (Remove and Replace).
  17. Repeat step 14 through step 16 on the RH side of the vehicle.
  18. Move both front seats to their original positions.
