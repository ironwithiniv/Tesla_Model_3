Hinge - Door - Front - Lower - LH (Remove and Replace)

Correction code 1133010132 FRT 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Equipment:
  • 1079485-00-A Crowfoot Open End Set
Parent topic: 1133 - Closure Assist Mechanisms and Hinges

Torque Specifications

Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x2) that attach the LH front lower door hinge to the door
27 Nm (19.9 lbs-ft)
  • 10mm 12pt combination wrench

 Reuse
Bolts (x2) that attach the LH front lower door hinge to body
27 Nm (19.9 lbs-ft)
  • 13mm 12pt combination wrench
  • Crowfoot Open End Set - 1079485-00-A (for installation only)
 Reuse

Remove

  1. Open the LH front door and lower the LH front window.
  2. Use a jack to support the LH front door from the bottom.
    Note
    Make sure to use soft material to protect the door paint.
  3. Apply masking tape to the area surrounding the LH front door lower hinge on the body and door to aid in alignment during installation.
  4. Remove the bolts (x2) that attach the LH front lower door hinge to the door.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm combination wrench
  5. Remove the bolts (x2) that attach the LH front lower door hinge to the body.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm combination wrench
  6. Lift up on the door slightly, and then rotate the LH lower front door hinge and pull it out to remove it.

Install

  1. Position the LH lower front door hinge into the vehicle.
    Note
    Lift the door slightly and insert the hinge.
  2. Hand-tighten the bolts (x2) that attach the LH front lower door hinge to the body.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm combination wrench
  3. Hand-tighten the bolts (x2) that attach the LH front lower door hinge to the door.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm combination wrench
  4. Remove the floor jack from underneath the LH front door.
  5. Close the LH front door and check for gap and flushness. Adjust as necessary.
    Note
    See Panel Alignment Specifications
  6. Tighten the bolts (x2) that attach the LH front lower door hinge to the body.
    27 Nm (19.9 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13mm 12pt combination wrench
    • Crowfoot Open End Set - 1079485-00-A (for installation only)
  7. Tighten the bolts (x2) that attach the LH front lower door hinge to the door.
    27 Nm (19.9 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10mm 12pt combination wrench
    • Crowfoot Open End Set - 1079485-00-A (for installation only)
  8. Remove the masking tape that surrounds the LH front door lower hinge on the body and door.
  9. Use IPA wipes to clean the lower hinge bolts and wait at least 1 minute to allow it to completely dry.
  10. Apply touch up paint to the LH front lower door hinge bolts as needed.
    Note
    Shake the touch up paint before applying. Allow the first coat to dry for 20 minutes before applying and second coat.
  11. Raise the LH front window and close the LH front door.
