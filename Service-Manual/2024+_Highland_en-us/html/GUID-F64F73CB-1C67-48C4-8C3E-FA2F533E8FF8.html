Fluid Coupling (Straight) - Rear Drive Inverter (Remove and Replace)

Correction code 4020010052 FRT 2.40 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 4020 - Rear Drive Inverter

Torque Specifications

Table 1. Torque Specifications: Fluid Coupling (Straight) - Rear Drive Inverter (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolt that attaches the straight fluid coupling to the rear drive unit inverter
6 Nm (4.4 lbs-ft)
  • 4 in extension
  • Torx T25 socket
  • Ratchet/torque wrench
 Reuse

Remove

  1. Remove the LH rear drive unit mount. See Mount - Rear Drive Unit - LH (3DU) (Remove and Replace).
  2. Remove the bolt that attaches the straight fluid coupling to the rear drive unit inverter.
    Tip
    Use of the following tool(s) is recommended:
    • 4 in extension
    • Torx T25 socket
    • Ratchet/torque wrench
  3. Remove the straight fluid coupling.

Install

  1. Lubricate the straight fluid coupling O-ring with coolant.
    CAUTION
    Do not install the fluid coupling with the O-ring dry.
  2. Install the straight fluid coupling to the rear drive unit inverter, and then install a new bolt to attach the coupling to the inverter.
    6 Nm (4.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 4 in extension
    • Torx T25 socket
    • Ratchet/torque wrench
  3. Install the LH rear drive unit mount. See Mount - Rear Drive Unit - LH (3DU) (Remove and Replace).
  4. Perform an inverter coolant leak test. See Inverter Air Leak Test (Inspection).
  5. Refill the coolant. See Powertrain Coolant - Rear (Drain and Refill).
