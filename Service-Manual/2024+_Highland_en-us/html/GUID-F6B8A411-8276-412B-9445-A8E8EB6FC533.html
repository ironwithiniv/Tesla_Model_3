Performance Badge - Rear (Remove and Replace)

Correction code 1205010082 FRT 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2024-11-26: Added 1967007-00-A - REAR GRAPHIC BADGE JIG 2024+ Model 3 part number and note.
Equipment:
  • 1453028-00-A - KIT, BADGE REMOVAL
  • 1967007-00-A - REAR GRAPHIC BADGE JIG 2024+ Model 3
Parent topic: 1205 - Badges and Films

Remove

Note
The badge cannot be reinstalled if removed. If the badge is removed for any reason, it must be replaced with a new part.
Note
The REAR GRAPHIC BADGE JIG 2024+ Model 3 (1967007-00-A) can be used as an alternative installation method for the replacement rear performance badge.
  1. Mark the position of the original performance badge.
  2. Prepare the badge removal tool (1453028-00-A) with approximately 60 centimeters of monofilament line.
  3. Tie slip knots at both ends of the monofilament line and attach them each to the center groove of a handle.
  4. With the trunk lid closed, position the badge removal tool so that the monofilament line cuts under a corner of the dual motor badge.
  5. Move the badge removal tool in a sawing motion to separate the dual motor badge from the trunk lid.
  6. Use IPA wipes to clean all adhesive residue and debris from the trunk lid surface, and allow 1 minute to dry.

Install

  1. Peel the adhesive backing from the dual motor badge, and install the dual motor badge onto the trunk lid.
  2. Re-apply the adhesive backing to protect the dual motor badge and use a pressure roller to fully adhere the badge to the trunk lid.
    Note
    Be careful not to damage the dual motor badge during the rolling process.
  3. Remove the adhesive backing from the badge, and then remove the masking tape from the trunk lid.
  4. Use an IPA wipe to clean the badge and any remaining debris.
    Note
    Make sure that all edges of the badge are securely affixed to the trunk lid surface.
