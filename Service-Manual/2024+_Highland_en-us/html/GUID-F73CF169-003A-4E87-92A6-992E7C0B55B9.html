Link - Stabilizer Bar - Front - LH (Remove and Replace)

Correction code 3101062022 FRT 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

CAUTION
If performing this procedure as a result of a collision, see the Collision Repair Manual to verify whether the steering gear must be replaced as well.
Parent topic: 3101 - Front Suspension (Including Hubs)

Torque Specifications

Table 1. Torque Specifications: Link - Stabilizer Bar - Front - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Nuts that attach the front stabar link to the LH front stabar and the LH strut
98 Nm (72.3 lbs-ft)
  • 18 mm socket
 Replace 1111543-00-A

Remove

  1. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  2. Remove and discard the nut that attaches the front stabar link to the LH front stabar.
    Tip
    Use of the following tool(s) is recommended:
    • 18 mm socket
  3. Move LH front stabar link assembly aside.
    Note
    Move the stabar up or down as needed to get the correct angle to remove the end link.
  4. Remove and discard the nut that attaches the front stabar link to the LH strut assembly, and then remove the LH front stabar link from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • 18 mm socket

Install

  1. Position the LH front stabar link assembly to the vehicle.
  2. Install a new nut (1111543-00-A) to attach the front stabar link to the LH strut assembly.
    98 Nm (72.3 lbs-ft)
    Note
    Mark after torque.
    Tip
    Use of the following tool(s) is recommended:
    • 18 mm socket
  3. Position the LH front stabar link assembly to the front stabar.
    Note
    Pull down the stabar as needed to allow the end link to engage.
  4. Install a new nut (1111543-00-A) to attach the front stabar link to the LH front stabar.
    98 Nm (72.3 lbs-ft)
    Note
    Mark after torque.
    Tip
    Use of the following tool(s) is recommended:
    • 18 mm socket
  5. Lower the vehicle and remove the lift arms from below the vehicle.
