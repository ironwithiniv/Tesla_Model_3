A/C Compressor (Remove and Replace)

Correction code 1820020012 FRT 0.96 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2026-06-03: Moved LV battery connection to before connecting the LV maintainer.
  • 2026-01-13: Revised procedure to flush the system and eliminate oil weighing and correction steps.
  • 2024-02-06: Remove the Flush steps and updated the routines and the amount of oil in the replacement compressor.
Special tools required for this procedure:
  • 1600279-00-A A/C OIL FLUSH ADAPTER SET, MODEL Y or 1600279-N0-BHEAT PUMP VEHICLE A/C FLUSHING FOR UNKNOWN OIL CONDITIONS
  • 1711245-00-A - Snap On Ecotechnics Dual Gas A/C Machine, includes Flush Adapter Kit R134A & R1234YF
  • 1120026-01-A A/C SERVICE MACHINE, WAECO, ASC5500 RPA
Warning

Only technicians who have completed all required certification courses are permitted to perform this procedure. Tesla recommends third party service provider technicians undergo equivalent training before performing this procedure. For more information on Tesla Technician requirements, or descriptions of the subject matter for third parties, see HV Certification Requirements. Proper personal protective equipment (PPE) and insulating HV gloves with a minimum rating of class 0 (1000V) must be worn at all times a high voltage cable, busbar, or fitting is handled. Refer to Tech Note TN-15-92-003, High Voltage Awareness Care Points for additional safety information.

CAUTION
Thermal management components operate under very tight specifications and can malfunction if Service procedures are not carefully followed. DO NOT rely on past experience with other thermal management systems; read through the Service Manual and do not deviate from the instructions.
CAUTION
The desiccant bag in the receiver dryer must be checked when replacing the A/C compressor to determine if debris resulting from failure of the compressor has entered the system.
Note
This procedure requires the A/C Refrigerant (Recovery and Recharge) procedure to be performed. If not already automatically added to the Service Visit, add correction code 18200102 as a separate correction within the same activity to the Service Visit.

Remove

  1. Set up the A/C machine.
  2. Unlock the vehicle gateway. See Gateway Unlock.
  3. On the touchscreen, tap the Service Mode "wrench" (at the bottom of the touchscreen UI), and then tap Thermal > Refrigerant System > Start Thermal Fill Drain (Refrigerant only) > Run, and allow the routine to complete.
  4. Disconnect the LV battery. See LV Power (Disconnect and Connect) (Modify).
  5. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  6. Recover the A/C refrigerant. See A/C Refrigerant (Recovery and Recharge) (Restore).
    Note
    Recover the refrigerant while continuing this procedure.
  7. Remove the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  8. Perform the Vehicle HV Disablement Procedure. See Vehicle HV Disablement Procedure.
  9. Remove the LV battery. See LV Battery (Remove and Replace).
  10. Release the connector locking tab, then disconnect the A/C logic electrical connector from the A/C compressor.
    Note
    DO NOT push down on the red locking tab. Pull the tab away from the connector until the connector is unlocked, and then continue pulling to release the connector.
    Tip
    Use of the following tool(s) is recommended:
    • Pick Miniature Soft Grip, 90 degree tip, 6 in
  11. Use a clip pry tool to release the retaining clip that attaches the A/C compressor logic harness to the A/C compressor HV harness bracket.
  12. Disconnect the HV harness electrical connector from the A/C compressor.
    Tip
    Use of the following tool(s) is recommended:
    • Pick Miniature Soft Grip, 90 degree tip, 6 in
  13. Remove the bolt that attaches the A/C compressor HV harness bracket to the A/C compressor.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm 12-point deep socket
  14. Remove the A/C compressor HV harness from the A/C compressor and move it aside.
  15. Remove the bolt that attaches the ground strap to the A/C compressor, and then move the ground strap aside.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket
  16. Use a clip pry tool to release the clip that attaches the coolant hose to the A/C compressor bracket.
  17. Use a clip pry tool to release the clips (x2) that attach the coolant hose to the A/C compressor bracket.
  18. After refrigerant recovery is complete, carefully depress the Schrader valves (x2) to level out any pressure difference between the A/C system pressure and the actual ambient atmospheric pressure.
  19. Remove the nut that attaches the low pressure fitting to the A/C compressor.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  20. Remove the nut that attaches the high pressure fitting to the A/C compressor, and then set the hose assembly aside.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  21. With an assistant, remove the bolts (x2) that attach the A/C compressor assembly to the strut tower brace, and then carefully maneuver the assembly towards the front of the vehicle, under the strut tower support brace. Rest the A/C compressor assembly on the front underhood storage unit reinforcement beam.
    CAUTION
    Do not rest the A/C compressor on the HV connector.
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm socket
  22. With an assistant, remove the bolts (x3) that attach the A/C compressor bracket to the A/C compressor, and then remove the bracket from the compressor.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  23. Remove the HV harness cover from the A/C compressor.
  24. Remove the desiccant, see Desiccant (Remove and Replace).
  25. Install the new cap into the accumulator, and then install the new snap ring into the accumulator.
  26. Install A/C flush adapters onto the A/C manifold to compressor line.
  27. Connect A/C machine hoses to A/C flush adapters.
  28. On the A/C machine touchscreen, select Menu > Flushing Kit, and enter 25 mins vacuum time. Follow the machine guide to start the flush, and then allow the process to complete.
    Note
    System flush procedure runs for approximately 90 minutes.
  29. Note the part numbers and serial numbers of the old and new A/C compressors.

Install

CAUTION
The new A/C compressor is pre-filled with oil. DO NOT add any additional oil to the new A/C compressor.
  1. Install the NVH acoustic cover onto the new compressor.
  2. Install the HV harness cover to the A/C compressor.
  3. Position the A/C compressor bracket on the A/C compressor, and then install the bolts (x3) that attach the bracket to the compressor.
    9 Nm (6.6 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  4. With an assistant supporting the A/C compressor assembly under the strut tower brace, hand-start the bolts (x2) that attach the A/C compressor assembly to the brace, and then torque the bolts.
    31 Nm (22.9 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm socket
  5. Replace the O-rings on the high pressure and low pressure supermanifold to A/C compressor hose fittings.
    Note
    O-ring for high pressure line: 1111737-00-A WASHER, 3/8,STL ZN, SEAL.
    Note
    O-ring for low pressure line: 1111740-00-A WASHER, 3/4,STL ZN, SEAL.
    Note
    Lubricate O-rings with ND-11 oil prior to installation.
  6. Remove the transport plugs from the new compressor.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  7. Position the supermanifold to A/C compressor high pressure fitting on the A/C compressor, and then install the nut that attaches the fitting to the A/C compressor.
    22 Nm (16.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm deep socket
  8. Position the supermanifold to A/C compressor low pressure fitting on the A/C compressor, and then install the nut that attaches the fitting to the A/C compressor.
    22 Nm (16.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm deep socket
  9. Install a new desiccant. See Desiccant (Remove and Replace).
    Note
    Reuse the accumulator cap and the snap ring used during flushing.
  10. Perform the vacuum leak test and refill A/C refrigerant. See A/C Refrigerant (Recovery and Recharge) (Restore).
  11. Install the clips (x2) that attach the coolant hose to the A/C compressor bracket.
  12. Install the clip that attaches the coolant hose to the A/C compressor bracket.
  13. Position the ground strap on the A/C compressor, and then install the bolt that attaches the ground strap to the A/C compressor.
    7 Nm (5.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket
  14. Position the A/C compressor HV harness to the A/C compressor.
  15. Install the bolt that attaches the A/C compressor HV harness bracket to the A/C compressor.
    9 Nm (6.6 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm 12-point deep socket
  16. Connect the HV harness electrical connector to the A/C compressor.
  17. Install the retaining clip that attaches the A/C compressor logic harness to the A/C compressor HV harness bracket.
  18. Connect the A/C compressor logic electrical connector to the A/C compressor, and then engage the locking tab.
    Note
    Push the red locking tab into the connector to engage the locking mechanism. DO NOT push down or pull up on the red locking tab.
  19. Install the LV battery. See LV Battery (Remove and Replace).
  20. Install the 2nd row lower seat cushion. See Seat Cushion - 2nd Row (Remove and Replace).
  21. Connect LV power. See LV Power (Disconnect and Connect) (Modify).
  22. Connect a LV maintainer. See LV Maintainer (Connect and Disconnect) (Maintenance).
  23. Enable Service Mode. See Service Mode.
  24. Unlock the vehicle gateway. See Gateway Unlock.
  25. Set the compressor Type using the touchscreen:
    • For vehicles that run firmware version 2026.2.3 or later (NA/EMEA) or 2025.44.32 or later (APAC), touch Thermal > Actions > Configure Compressor, and then touch Run to start the routine.
    • For vehicles that run earlier firmware versions, touch Thermal > Actions > Thermal Configurations > compressorType, and then select and save the correct compressor type
    Note
    In case the routine did not complete successfully, refer to Toolbox article 5696900 for compressor configuration.
    Note
    Check the Gateway configuration for compressorType and make sure it shows as intended.
  26. Reinstall the software. See Software Reinstall - Touchscreen.
  27. On the touchscreen, perform the following steps:
    1. Touch Controls > Thermal > Sensors and Valves > Reset Compressor P-Metric, click Run to start the routine.
      Note
      Make sure the routine is passed, then touch Close to close it.
    2. Touch Thermal > Refrigerant System > Run Heat Pump Commissioning and select Run to start the routine.
      Note
      Make sure the routine is passed, then touch Close to close it.
    3. Touch Thermal > Actions > Test HVAC Performance and select Run to start the routine.
      Note
      Make sure the routine is passed, then touch Close to close it.
    4. Touch Thermal > Actions > Test Thermal Performance and select Run to start the routine.
      Note
      Make sure the routine is passed, then touch Close to close it.
  28. Disable Service Mode. See Service Mode.
  29. Disconnect LV maintainer. See LV Maintainer (Connect and Disconnect) (Maintenance).
  30. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  31. Raise all windows and close the doors.
