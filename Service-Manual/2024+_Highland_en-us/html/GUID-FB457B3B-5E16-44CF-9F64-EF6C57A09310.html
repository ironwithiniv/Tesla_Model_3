Parking Brake - Caliper - Rear - LH (Release)

Correction code 33051005 0.15 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2024-10-02: Added information for Performance brakes and updated section title.
Equipment:
  • 1134520-00-A Electronic Parking Brake Release Tool
Parent topic: 3305 - Parking Brake

Release Parking Brake Using Service Mode

  1. If needed, chock the wheels.
  2. Enable Service Mode through the touchscreen. See Service Mode.
  3. Unlock the vehicle gateway for diagnostic communication. See Gateway Unlock.
  4. On the touchscreen, under Vehicle Info, touch Chassis, under Chassis, touch Brakes, and then in the diagram, touch EPB Service Mode.
  5. Read the text displayed, and under Parameters, from the Action target drop-down menu, select BOTH, from the Action type drop-down menu, select START, and touch Run.
    Note
    To release the parking brake on one side of the vehicle, select LEFT or RIGHT.
    CAUTION
    The vehicle may roll freely.
  6. The vehicle is now in EPB Service Mode.
  7. To disable EPB Service Mode, shift the vehicle into Park.

Release Parking Brake Using Toolbox

  1. If needed, chock the wheels.
  2. Connect a laptop with Toolbox 3 to the vehicle. See Toolbox (Connect and Disconnect).
  3. Using Toolbox 3:
    1. Select the Actions tab and search for "EPB Service Mode".
    2. Select the ODIN routine PROC_EPB_X_SERVICE-MODEvia Service Mode:
      • Chassis ➜ Brakes ➜ EPB Service Mode
      • Chassis ➜ Brakes ➜ EPB Service Mode
      via Service Mode Plus:Drive Unit ➜ Rear Drive Unit Replacement ➜ Release / Re-Engage Emergency Parking Brakevia Toolbox:(link)      , and then click the link of the routine.
    3. Under "Action_Target" select BOTH, and under "Action_Type" select START.
    4. Click RUN, and allow the routine to complete.
      Note
      Press and hold the brake pedal while performing this routine.
      Note
      To release the parking brake on one side of the vehicle, select LEFT or RIGHT under "Action_Target".
      CAUTION
      The vehicle may roll freely.
  4. The vehicle is now in EPB Service Mode.
  5. To disable EPB Service Mode, shift the vehicle into Park.

Release Parking Brake Using Special Tool

  1. Remove the LH rear wheel. See Wheel Assembly (Remove and Install).
  2. Disconnect the LH rear EPB caliper connector.
  3. Connect the electronic parking brake release tool to the LH rear EPB caliper connector.
    Note
    For the Performance version, use adapter 2068008-00-A.
  4. Press the release button in the electronic parking brake release tool to release the LH rear parking brake.
  5. Disconnect the electronic parking brake release tool from the LH rear EPB caliper connector.
  6. Connect the LH rear EPB caliper connector.
  7. Install the LH rear wheel. See Wheel Assembly (Remove and Install).
