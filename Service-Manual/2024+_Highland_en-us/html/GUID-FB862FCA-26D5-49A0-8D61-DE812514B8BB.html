Insulators - HV Battery (Remove and Install)

Correction code 16302001 0.06 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning

Only technicians who have completed all required certification courses are permitted to perform this procedure. Tesla recommends third party service provider technicians undergo equivalent training before performing this procedure. For more information on Tesla Technician requirements, or descriptions of the subject matter for third parties, see HV Certification Requirements. Proper personal protective equipment (PPE) and insulating HV gloves with a minimum rating of class 0 (1000V) must be worn at all times a high voltage cable, busbar, or fitting is handled. Refer to Tech Note TN-15-92-003, High Voltage Awareness Care Points for additional safety information.

Warning
Make sure to wear HV insulating gloves and leather over gloves when performing this procedure.
Special tools required for this procedure:
  • 1467483-00-C KIT, ANCILLARY BAY HV INSULATORS, 3Y
Parent topic: 1630 - HV Battery Electrical Components

Install

  1. Note
    This procedure supplements the procedure to remove the ancillary bay cover when HV insulators are not present. After completing the insulator installation procedure, continue to the procedure that required the ancillary bay cover to be removed.
    Note
    HV insulators are not consumables and need to be removed prior to the installation of the ancillary bay cover.
  2. Install the squarish insulator caps onto the pyrotechnic battery disconnect busbar bolt heads.
  3. Install the round insulator caps onto the HV battery positive contactor busbar bolt heads.
  4. Install the round insulator caps onto the HV battery negative contactor busbar bolt heads.
  5. Raise the high voltage controller, install the fuse access insulator onto the RH ancillary bay bus cover, fasten the clips that attach the insulator to the cover, and lower the high voltage controller.
  6. Install the special insulator onto the DC input assembly busbar bolt heads.
  7. Install the AC inlet terminal covers over the positive and negative ring terminal bolts, and fasten the clips that attach the AC inlet terminal covers to the HV battery fast charge contactor cover.
  8. Continue to the procedure that required the ancillary bay cover to be removed.

Remove

Removal procedure is the reverse of installation.
