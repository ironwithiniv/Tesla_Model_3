Light - Brake - Center High Mounted (CHMSL) (Remove and Replace)

Correction code 1511010032 FRT 0.54 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1511 - Trunk Trim

Remove

  1. Remove the LH and RH side rail trims. See Trim - Side Rail - LH (Remove and Replace).
  2. Remove the LH and RH side bolsters. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  3. Remove the LH and RH C-pillar trims. See Trim - C-Pillar - LH (Remove and Replace).
  4. Remove the package tray. See Trim - Package Tray (Premium) (Remove and Replace).
  5. Remove the screws (x2) that attach the stop lamp to the package tray.
    Tip
    Use of the following tool(s) is recommended:
    • Phillips screwdriver bit
    • Cordless hex driver
  6. Disconnect the electrical connector from the stop lamp.
    Tip
    Use of the following tool(s) is recommended:
    • Pick Miniature Soft Grip, Straight tip, 6 in
  7. Release the tabs (x6) that attach the stop lamp to the vehicle and the tabs (x2) that attach the stop lamp to the package tray.
    Note
    Carefully release the two tabs on the package tray to avoid damage.
  8. Remove the stop light.

Install

  1. Install the tabs (x6) that attach the stop lamp to the vehicle and the tabs (x2) that attach the stop lamp to the package tray.
  2. Install the screws (x2) that attach the stop lamp to the package tray.
    0.5 Nm (4 lbs-in)
    Tip
    Use of the following tool(s) is recommended:
    • Phillips screwdriver bit
    • Wiha Torque 0.8 Nm - 5 Nm screwdriver
  3. Connect the electrical connector to the stop lamp.
  4. Install the package tray. See Trim - Package Tray (Premium) (Remove and Replace).
  5. Install the LH and RH C-pillar trims. See Trim - C-Pillar - LH (Remove and Replace).
  6. Install the LH and RH side bolsters. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  7. Install the LH and RH side rail trims. See Trim - Side Rail - LH (Remove and Replace).
