Harness - Trunk Lid Trim (Remove and Replace)

Correction code 1710020092 FRT 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

  • 2025-12-23: Added the trunk latch cover steps.
Parent topic: 1710 - Harnesses

Remove

  1. Remove the trunk latch cover. See Cover - Latch - Trunk (Remove and Replace).
  2. Remove the trunk lid trim. See Trim - Lid - Trunk (Remove and Replace).
  3. Disconnect the electrical connector from the interior liftgate switch.
  4. Disconnect the electrical connector from the liftgate chime.
  5. Remove the liftgate trim harness.

Install

  1. Install the liftgate trim harness.
  2. Connect the electrical connector to the liftgate chime.
  3. Connect the electrical connector to the interior liftgate switch.
  4. Install the trunk lid trim. See Trim - Lid - Trunk (Remove and Replace).
  5. Install the trunk latch cover. See Cover - Latch - Trunk (Remove and Replace).
