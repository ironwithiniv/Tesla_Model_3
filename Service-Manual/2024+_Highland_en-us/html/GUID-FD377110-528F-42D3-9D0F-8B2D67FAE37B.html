Suspension - Cushion - Front Seat - LH (Remove and Replace)

Correction code 1301010142 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Table 1. Torque Specifications: Suspension - Cushion - Front Seat - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
LH front seat fasteners (x4)
33.5 Nm (24.7 lbs-ft)
  • Torx T45 socket
  • Torx Plus T45 socket
 Replace 1458818-00-B
Warning
Seat base edges are sharp and can cause personal injury. Wear cut resistant gloves when removing the seat from the vehicle, and while performing procedures that involve work on or near the seat base.
Parent topic: 1301 - Front Seat Tracks and Motors

Remove

  1. Open both LH doors and lower both LH windows.
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Remove the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  4. Remove the lower A-pillar assembly. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  5. Release the LH front seat harness from the sill trim clips (x5).
  6. Move the LH front seat forward, and then remove and discard the LH front seat rear fasteners (x2).
    Tip
    Use of the following tool(s) is recommended:
    • Torx T45 socket
    • Torx Plus T45 socket
  7. Move the LH front seat backward, and then remove and discard the LH front seat front fasteners (x2).
    Tip
    Use of the following tool(s) is recommended:
    • Torx T45 socket
    • Torx Plus T45 socket
  8. Tilt the LH front seat rearward to gain access to the underside of the LH front seat.
    Note
    It is not necessary to disconnect the LH seat harness from the body controller. Take care when moving the seat. Ensure the carpet is not damaged.
  9. Remove the clip that attaches the LH front seat harness to the outboard seat track.
  10. Move the LH front seat most forward.
  11. Disconnect the LV battery power. See LV Power (Disconnect and Connect) (Modify).
  12. Unhook the straps (x2) from the LH front seat harness bracket.
  13. Release the tabs (x2) to remove the seat occupancy sensor connector from the LH front seat harness bracket.
  14. Disconnect the LH front seat occupancy sensor connector and set the harness aside.
  15. Release the clips (x3) to remove the seat harness bracket from the LH front seat assembly.
    Note
    Use a 90 degree tip to release the clips from the back of the bracket.
  16. Disconnect the seatback heater connector, and then separate the connector from the seat underside.
    Note
    Slide the connector forward to release it from the seat assembly.
  17. Disconnect the seat cushion heater connector, and then separate the connector from the seat underside.
    Note
    Slide the connector forward to release it from the seat assembly.
  18. Depress the retaining clip and remove the seat occupancy sensor from the seat underside.
  19. Remove the clip which is next to the cushion heater connector and attaches the harness to the bottom of the LH front seat.
  20. With assistance, remove the seat cushion retaining clips (x2) from the LH front seat suspension.
  21. With assistance, remove the upper part of the LH front seat cushion suspension from the seat frame.
    Note
    Reversely use the clip prytool to remove the seat suspension. Press the seat suspension down with appropriate force to completely separate it from the seat frame.
  22. With assistance, remove the LH front seat cushion suspension from the seat frame.
    Note
    Rotate the seat suspension downwards to a horizontal position and lift it upwards to remove the lower part of the seat suspension.

Install

  1. With assistance, install the lower part of the LH front seat cushion suspension to the seat frame.
    Note
    Clip the seat suspension to the seat frame in a horizontal position and then rotate upwards.
  2. With assistance, install the upper part of the LH front seat cushion suspension to the seat frame.
    Note
    Reversely use the clip prytool to install the seat suspension. Press the seat suspension down with appropriate force to install it to the inside of the seat frame.
  3. Install the seat cushion retaining clips (x2) to the LH front seat suspension.
    Note
    Pull the clips tight till the seat suspension is at a proper position for installation.
  4. Install the clip which is next to the cushion heater connector and attaches the harness to the bottom of the LH front seat.
  5. Fasten the clip that attaches the seat cushion heater connector to the seat underside, and then connect the connector.
    Note
    Slide the connector onto the seat frame clip to secure.
  6. Install the retaining clip that attaches the seat occupancy sensor to the seat underside.
  7. Fasten the clip that attaches the seatback heater connector to the seat underside, and then connect the connector.
    Note
    Slide the connector onto the seat frame clip to secure.
  8. Secure the clips (x3) to install the seat harness bracket to the LH front seat assembly.
  9. Connect the seat occupancy sensor connector, then secure the tabs (x2) to install the connector to the LH front seat harness bracket.
  10. Install the straps (x2) to the LH front seat harness bracket.
  11. Connect the LV battery power. See LV Power (Disconnect and Connect) (Modify).
  12. Move the LH front seat to most rearward.
  13. Install the clip that attaches the LH front seat harness to the outboard seat track.
  14. Return the LH front seat to the vertical position.
    Note
    Take care when moving the seat. Ensure the carpet is not damaged.
  15. Secure the LH front seat harness to the sill trim clips (x5).
    Note
    Tuck excess harness between the harness bracket and the body.
  16. Install new LH front seat front fasteners (x2) (1458818-00-B).
    33.5 Nm (24.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T45 socket
    • Torx Plus T45 socket
  17. Move the LH front seat forward, and then install new LH front seat rear fasteners (x2) (1458818-00-B).
    33.5 Nm (24.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T45 socket
    • Torx Plus T45 socket
  18. Raise the LH rear window and close the LH rear door.
  19. Install the lower A-pillar assembly. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  20. Install the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  21. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  22. Move the LH front seat to original position.
  23. Raise the LH front window and close the LH front door.
