Jumper Harness - B2B - Ethernet (Remove and Replace)

Correction code 1710070012 FRT 0.36 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Parent topic: 1710 - Harnesses

Remove

  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Disconnect the LV battery power. See LV Power (Disconnect and Connect) (Modify).
  3. Remove the RH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  4. Remove the RH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  5. Remove the passenger footwell cover. See Cover - Footwell - Front Passenger (Remove and Replace).
  6. Remove the glove box. See Glove Box (Remove and Replace).
    Note
    No need to remove the glove box USB cable.
  7. Disconnect the jumper harness connectors (x2) from the car computer.
  8. Disconnect the harness connectors (x4) from the car computer.
  9. Disconnect the jumper harness connectors (x2) from the right side of the car computer.
  10. Release the clip that attaches the harness to the car computer, and then remove the harness from the vehicle.

Install

  1. Fasten the clip that attaches the harness to the car computer.
  2. Connect the jumper harness connectors (x2) to the right side of the car computer.
  3. Connect the harness connectors (x4) to the car computer.
  4. Connect the jumper harness connectors (x2) to the car computer.
  5. Install the glove box. See Glove Box (Remove and Replace).
    Note
    No need to install the glove box USB cable.
  6. Install the passenger footwell cover. See Cover - Footwell - Front Passenger (Remove and Replace).
  7. Install the RH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  8. Install the RH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  9. Connect the LV battery power. See LV Power (Disconnect and Connect) (Modify).
  10. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
