Cover Panel - Rear Vent - Center Console (Model 3 Standard) (Remove and Replace)

Correction code 15190402502 15190402501 FRT 0.54 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See Ergonomic Precautions for safe and healthy working practices.

Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
  • 2025-09-05: Released new procedure.
Parent topic: 1519 - Center Console

Remove

  1. Remove the LH and RH center console hockey sticks. See Hockey Stick - Center Console - LH (Model 3 Standard) (Remove and Replace).
  2. Remove USB panel assembly from rear center console module
    Note
    10x tabs, 1x connector, Pull the top of the USB cover outwards, Release USB connector and remove USB panel assembly
  3. Remove screws securing rear end module assembly to center console
    Note
    6x screws, T20, 1 Nm
  4. Remove rear end module from center console
    Note
    2x datums
  5. Remove rear vent cover panel from air vent assembly
    Note
    2x screws, T20, 1Nm, push vent assembly out from rear vent cover panel

Install

  1. Install rear vent cover panel onto rear air vent assembly
    Note
    2x screws, T20, 1Nm, push vent assembly into rear vent cover panel
  2. Position rear module onto center console
    Note
    2x datums
  3. Install screws securing rear end module assembly to center console
    Note
    6x screws, T20, 1 Nm
  4. Install USB panel assembly to rear center console module
    Note
    8x tabs, 1x connector, Connect USB connector, Install USB panel flush with rear center console module
  5. Install the LH and RH hockey sticks. See Hockey Stick - Center Console - LH (Model 3 Standard) (Remove and Replace).
