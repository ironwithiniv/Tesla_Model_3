Hose - Powertrain Supply - Supermanifold (Heat Pump) (Remove and Replace)

Correction code 18300012 0.54 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

Remove

  1. Open the LH front door and lower the LH front window.
  2. Remove the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  3. Disconnect the 12V battery. See 12V/LV Power (Disconnect and Connect).
  4. Raise vehicle fully and lower lift onto locks.
  5. Remove the front areo shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  6. Release the clisp that attach the wheel liner to the HV battery.
  7. Use bungee strap to pull back RH front wheel liner.
  8. Drain the cooling system. See Cooling System (Partial Refill and Bleed).
  9. Disconnect powertrain supply tube and plug both hose ends.
  10. Release powertrain supply hose from body.
  11. Disconnect the sensor for the powertrain supply hose.
  12. Disconnect powertrain supply hose from supermanifold.
  13. Remove powertrain supply hose from vehicle.

Install

  1. Install powertrain supply hose from vehicle.
  2. Connect powertrain supply hose from supermanifold.
  3. Connect the sensor for the powertrain supply hose.
  4. Connect powertrain supply tube and plug both hose ends install powertrain supply hose to body.
  5. Refill the cooling system. See Cooling System (Partial Refill and Bleed).
  6. Install the clisp that attach the wheel liner to the HV battery.
  7. Install the front areo shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  8. Lower vehicle fully and lower lift onto locks.
  9. Connect the 12V battery. See 12V/LV Power (Disconnect and Connect).
  10. Remove the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
