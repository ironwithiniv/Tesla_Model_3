Sensor - Ride Height - Rear - LH (Remove and Replace)

Correction code 31036102 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

Torque Specifications

Table 1. Torque Specifications: Sensor - Ride Height - Rear - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Nut that attaches the LH rear ride height sensor to the LH rear upper aft link
10 Nm (7.4 lbs-ft)
  • 10 mm deep socket
Reuse
Nut that attaches the LH rear ride height sensor to the rear subframe
10 Nm (7.4 lbs-ft)
  • 10 mm deep socket
Reuse

Remove

  1. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  2. Remove the LH rear wheel. See Wheel (Remove and Replace).
  3. Remove the nut that attaches the LH rear ride height sensor to the LH rear upper aft link.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  4. Remove the nut that attaches the LH rear ride height sensor to the rear subframe.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  5. Disconnect the electrical connector from the LH rear ride height sensor, and then remove the sensor from the vehicle.

Install

  1. Connect the electrical connector to the LH rear ride height sensor.
  2. Install the nut that attaches the LH rear ride height sensor to the rear subframe.
    10 Nm (7.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  3. Install the nut that attaches the LH rear ride height sensor to the LH rear upper aft link.
    10 Nm (7.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  4. Install the LH rear wheel. See Wheel (Remove and Replace).
  5. Remove the vehicle from the lift.
