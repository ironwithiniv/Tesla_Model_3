Wheel Assembly (Remove and Install)

Correction code 34015001 0.15 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

Remove

  1. Remove the wheel cap, if equipped. See Cap - Wheel (Remove and Replace).
  2. Loosen the lug nuts.
    CAUTION
    Use only hand tools to break the lug nuts loose. Power tools should only be used to remove the lug nuts after they have been loosened.
    CAUTION
    Use a 6 point socket. Do not use a 12 point socket or a specialty socket.
  3. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift/.
  4. Remove the lug nuts from the wheel, and then remove the wheel from the vehicle.

Install

CAUTION
Do not install base wheels onto vehicles with performance brakes, or install performance wheels onto vehicles with base brakes. Base and performance wheels have different offsets to accommodate base and performance brakes. Refer to #GUID-6B20CACF-C224-4B28-9592-7BEB02E9AEB6 for offset information.
  1. Position the wheel to the vehicle, and then hand-tighten the lug nuts.
    Warning
    Wear appropriate personal protective equipment (PPE) when performing this procedure to prevent personal injury.
  2. Use a power tool to tighten the lug nuts (x5) of the wheel to the initial torque in a criss-cross star pattern.
  3. Lower the vehicle. See Raise Vehicle - 2 Post Lift/.
  4. Fully tighten the lug nuts in a criss-cross star pattern.
    175 Nm (129.1 lbs-ft)
  5. Install the wheel cap, if equipped. See Cap - Wheel (Remove and Replace).
