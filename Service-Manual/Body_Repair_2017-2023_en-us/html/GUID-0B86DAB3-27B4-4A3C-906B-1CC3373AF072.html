Link - Lateral - Lower - Front - LH (Remove and Replace)

Correction code 31013402 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

  • 2025-09-24: Updated guidance for the lower lateral link to subframe bolts.
  • 2025-07-22: Updated the torque of the bolts that attach the LH front lower lateral link to the front subframe to 190 Nm.
  • 2024-04-15: Added instructions for replacing the bolts that attach the front lower lateral link to the subframe on RH side, if not yet replaced.
  • 2024-01-05: Added new bolts (x2) that attach the front lower lateral link to the subframe. These bolts are one time use and are now torqued to 135 Nm.
  • 2024-01-11: Updated the information about the bolts (x2) that attach the front lower lateral link to the subframe. The bolts without nylon must be replaced while the bolts with nylon can be reused.
CAUTION
If performing this procedure as a result of a collision, see the Collision Repair Manual to verify whether the steering gear must be replaced as well.

Remove

  1. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  2. Remove the LH front wheel. See Wheel Assembly (Remove and Install).
  3. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  4. Remove and discard the bolts (x2) that attach the LH front lower lateral link to the subframe.
    Tip
    Use of the following tool(s) is recommended:
  5. Remove the bolt and nut that attach the LH strut to the LH front lower lateral link, and then remove the LH front lower lateral link from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • 21 mm socket
  6. Remove and discard the nut that attaches the LH front lower lateral link to the knuckle.
    Tip
    If the impact gun does not remove the nut, use a 3/8 in ratchet with a Torx T45 socket to counter-hold the inner bolt, and then remove the nut with a 22 mm combination wrench.
    Tip
    Use of the following tool(s) is recommended:
    • 22 mm socket

Install

  1. Position the LH front lower lateral link into the vehicle, and then hand-tighten new bolts (x2) that attach the LH front lower lateral link to the front subframe.
    Note

    EMEA/APAC: Use 2123635-00-A. If 2123635-00-A is unavailable, use 1109912-00-B.

    NA: Use 1109912-00-B.

    Tip
    Use of the following tool(s) is recommended:
  2. Install a new nut that attaches the LH front lower lateral link to the knuckle.
    180 Nm (132.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 22 mm socket
  3. Hand-tighten the bolt and nut that attach the LH strut to the LH front lower lateral link.
    Tip
    Use of the following tool(s) is recommended:
    • 21 mm socket
  4. Tighten the bolts that attach the LH front lower lateral link to the front subframe.
    Note

    EMEA/APAC: Use 2123635-00-A and torque to 190 Nm. If 2123635-00-A is unavailable, use 1109912-00-B and torque to 135 Nm.

    NA: Use 1109912-00-B and torque to 135 Nm.

    Tip
    Use of the following tool(s) is recommended:
  5. Install the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  6. Remove the bolt that attaches the LH front brake rotor to the knuckle.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  7. Install a hub jack adapter onto the LH front hub, and then use a support stand to support the LH front suspension at ride height (423 mm).
    Note
    Measure from bottom of fender to center of axle as a check to make sure LH suspension is set close to ride height.
    Tip
    Use of the following tool(s) is recommended:
    • Hub Jack Adapter - 1459409-00-A
  8. Tighten the bolts that attach the LH strut to LH front lower lateral link, and then mark the bolt and nut with a paint pen.
    106 Nm (78.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 21 mm socket
  9. Remove the support stand and hub jack adapter from the vehicle.
  10. Install the bolt that attaches the LH front brake rotor to the knuckle.
    5 Nm (3.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  11. Install the LH front wheel. See Wheel Assembly (Remove and Install).
  12. Refer to the Alignment Requirement tables to determine whether an EPAS alignment check (EC) or four wheel alignment check (AC) is necessary. If performed, add the alignment check/adjust correction code as a separate activity to the SV. See Alignment Requirement - Suspension.
