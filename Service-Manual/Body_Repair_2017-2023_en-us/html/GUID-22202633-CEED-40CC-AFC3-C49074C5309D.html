Duct - Air Wave - LH (LHD) (Non-Heat Pump) (Remove and Replace)

Correction code 18108002 2.40 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

Remove

  1. Remove the IP carrier. See IP Carrier (LHD) (Remove and Replace).
  2. Remove the screws (x2) that attach the LH air wave duct to the cross bar beam, and then remove the duct from the vehicle.

Install

  1. Install the LH air wave duct to the cross car beam, and then install the screws (x2) that attach the duct to the beam.
    2.3 Nm (1.7 lbs-ft)
  2. Install the IP carrier. See IP Carrier (LHD) (Remove and Replace).
