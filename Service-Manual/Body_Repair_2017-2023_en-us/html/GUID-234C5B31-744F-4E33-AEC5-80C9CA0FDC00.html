Link - Fore - Lower - Rear - LH (Remove and Replace)

Correction code 31031412 0.54 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

Equipment:
  • 1135103-00-A Tool, Spring Compressor, Hook, Model 3
  • 1137855-00-A TOOL, REAR RIDE HEIGHT TORQUE, MODEL 3
  • 1081765-00-A 3/4 TON UNDERHOIST STAND
  • 1459409-00-A ADAPTER, HUB JACK, MODEL 3

    Remove

    1. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
    2. Inspect the vehicle for abnormal tire wear that might indicate the need for a wheel alignment. Note any findings.
    3. Remove the LH rear wheel. See Wheel Assembly (Remove and Install).
    4. Remove the LH rear suspension cover.
    5. Remove the mid aero shield panel. See Panel - Aero Shield - Rear (Remove and Replace).
    6. Place a support stand underneath the middle of the rear subframe.
    7. Remove the clips that attach the coolant hose to the LH shear plate.
    8. Remove the smaller bolts that attach the LH shear plate to the HV battery.
    9. Loosen the larger bolt that attaches the LH shear plate to the subframe, move the shear plate away, and then retighten the bolt.
      Note
      Moving the shear plate away creates the required space for removal of the subframe bolt of the rear lower fore link.
    10. Remove the bolt and nut that attach the LH rear lower fore link to the knuckle.
    11. Remove the bolt that attaches the LH rear lower fore link to the subframe.
    12. Remove the LH rear lower fore link from the vehicle.

    Install

    1. Install the LH rear lower fore link to the subframe, and then hand-tighten the bolt that attaches the LH rear lower fore link to the subframe.
    2. Hand-tighten the bolt and the nut that attaches the LH rear lower fore link to the knuckle.
    3. Loosen the larger bolt that attaches the LH shear plate to the subframe, move the shear plate to its original position, and then hand-tighten the bolt.
    4. Install and hand-tighten the smaller bolts that attach the LH shear plate to the HV battery.
    5. Torque the larger bolt that attaches the LH shear plate and subframe to the body.
      130 Nm (95.9 lbs-ft)
    6. Torque the smaller bolts (x2) that attach the LH shear plate to the HV battery.
      35 Nm (25.8 lbs-ft)
    7. Install the clips that attach the coolant hose to the LH shear plate.
    8. Remove the support stand from underneath the vehicle.
    9. Install a spring compressor onto the LH rear coil spring. Line up the hooks per image and verify that the spindle goes through the body opening when the suspension is compressed.
    10. Remove the bolt that attaches the brake rotor to the hub.
      Note
      Use of the following tool(s) is recommended:
      • 10 mm socket
      • 2 in extension
    11. Install the hub jack adapter onto the LH rear hub and hand-tighten the lug nuts.
    12. Use an underhoist stand to support the hub jack adapter.
      Note
      Use the rear ride height torque gauge to verify that the rear suspension is set to ride height specifications and adjust the support stand or spring compressor tool , if necessary.
    13. Measure the distance between the bottom of the quarter panel to the center of the rear axle to make sure that the rear suspension is set to ride height: The distance should measure 378 mm.
    14. Tighten the bolts that attach the LH rear lower fore link bolt to the knuckle and to the subframe. Mark the bolt with a paint pen.
      76 Nm (56.0 lbs-ft)
    15. Remove the underhoist stand from underneath the LH rear suspension.
    16. Remove the lug nuts that attach the hub jack adapter, and then remove the hub jack adapter from the vehicle.
    17. Install the bolt that attaches the LH rear brake rotor to the hub.
      5 Nm (3.7 lbs-ft)
      Note
      Use of the following tool(s) is recommended:
      • 10 mm socket
      • 2 in extension
    18. Remove the spring compressor from the LH rear suspension coil spring.
    19. Install the mid aero shield panel. See Panel - Aero Shield - Rear (Remove and Replace).
    20. Install the LH rear wheel. See Wheel Assembly (Remove and Install).
    21. Refer to the Alignment Requirement tables to determine whether an EPAS alignment check (EC) or four wheel alignment check (AC) is necessary. If performed, add the alignment check/adjust correction code as a separate activity to the SV. See Alignment Requirement - Suspension.
