Amplifier - Audio - External (Remove and Replace)

Correction code 21213502 0.36 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

Torque Specifications

Table 1. Torque Specifications: Amplifier - Audio - External (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Screws (x3) that attach the audio amplifier to the subwoofer assembly
4.3 Nm (3.2 lbs-ft)
  • Torx T30 socket
 Reuse

Remove

  1. Remove the subwoofer assembly. See Subwoofer (Remove and Replace).
    CAUTION
    Make sure 12V power is disconnected before disconnecting the electrical connectors. Failure to disconnect 12V power before removal can result in damage.
  2. Remove the screws (x3) that attach the audio amplifier to the subwoofer assembly, and remove the amplifier from the subwoofer.
    4.3 Nm (3.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T30 socket

Install

Installation procedure is the reverse of removal.
