Cover - Hood Latch (Remove and Replace)

Correction code 15241102 0.06 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

Remove

  1. Open the hood.
  2. Release the clips that attach the hood latch cover to the body.
    Tip
    Grab the cover from the bottom, and then pull it upward to release the clips.
  3. Disconnect the electrical harness from the child safety switch connector, and then remove the cover from the vehicle.

Install

Installation procedure is the reverse of removal, except for the following:

  1. Prior to installation of the hood latch cover, use a torch light to inspect the inside of the hood latch housing for any foreign object that may have dropped in. If any object is found, remove it and confirm that the hood latch is operating as intended.
  2. Inspect the clips (x4) of the hood latch cover that attach the cover to the vehicle body for any damage. If damage is found or when any clip is dislodged or missing, replace the hood latch cover with a new one since the hood latch panel clips are non serviceable parts.
