Link - Compliance - Lower - Front - LH (Remove and Replace)

Correction code 31013602 0.36 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

  • 2026-09-07: Adjusted the torquing sequence of the link-to-knuckle nut to ensure stress relief.
  • 2024-01-15: Expanded the installation section since the fasteners' installation order is different from the removal order.
CAUTION
If performing this procedure as a result of a collision, see the Collision Repair Manual to verify whether the steering gear must be replaced as well.

Torque Specifications

Table 1. Torque Specifications: Link - Compliance - Lower - Front - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Nut that attaches the front LH lower compliance link to the knuckle
180 Nm (132.7 lbs-ft)
  • Torx T45 socket
  • 22 mm socket
Replace 1109263-00-B
Bolt and nut that attach the link to the front subframe
115 Nm (84.8 lbs-ft)
  • Combination Wrench 12pt 21mm
 Reuse

Remove

  1. Remove the LH front wheel. See Wheel Assembly (Remove and Install).
  2. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  3. Remove and discard the nut that attaches the front LH lower compliance link to the knuckle.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T45 socket
    • 22 mm socket
  4. Remove the bolt and nut that attach the link to the front subframe, and then remove the link from the subframe and knuckle.
    Tip
    Use of the following tool(s) is recommended:
    • Combination Wrench 12pt 21mm

Install

  1. Install the LH front lower compliance link to the front subframe.
  2. Hand-tighten the bolt and nut that attach the link to the front subframe.
  3. Hand-tighten a new nut to attach the front LH lower compliance link to the knuckle.
    Note
    Counter hold the nut with a T45 socket.
  4. Torque the bolt and nut that attach the link to the front subframe.
    115 Nm (84.8 lbs-ft)
    Note
    Mark with a paint pen.
    Tip
    Use of the following tool(s) is recommended:
    • Combination Wrench 12pt 21mm
  5. Torque the nut that attaches the front LH lower compliance link to the knuckle.
    180 Nm (132.7 lbs-ft)
    Note
    Counter hold the nut with a T45 socket. Mark with a paint pen.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T45 socket
    • 22 mm socket
  6. Install the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  7. Install the LH front wheel. See Wheel Assembly (Remove and Install).
