Carpet - Underhood Storage (Remove and Install)

Correction code 15302002 0.06 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

Remove

  1. Open the hood.
  2. Remove the carpet from the underhood storage unit.

Install

  1. Install the carpet into the underhood storage unit.
  2. Close the hood.
