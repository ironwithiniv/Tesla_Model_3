Knuckle - Suspension - Front - LH (Dual Motor) (Remove and Replace)

Correction code 31010112 0.72 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

  • 2023-09-11: Update bolts that attach the LH front ABS wheel speed sensor and electrical harness to the LH front suspension knuckle from replace to be reuse.
CAUTION
If performing this procedure as a result of a collision, see the Collision Repair Manual to verify whether the steering gear must be replaced as well.

Remove

  1. If equipped, remove the LH front wheel center cap. See Cap - Wheel (Remove and Replace).
  2. Loosen the LH front wheel lug nuts.
    CAUTION
    Use only hand tools to remove or install the fasteners. Do not use impact or power tools.
    CAUTION
    Use a 6 point socket. Do not use a 12 point socket or a specialty socket.
  3. Loosen the LH front drive unit halfshaft nut.
  4. Raise the vehicle, and then remove the LH front wheel. See Wheel Assembly (Remove and Install).
  5. Remove and discard the LH front drive unit halfshaft nut and washers.
    Note
    The washers are attached to the nut.
  6. Position the hub puller tool onto the LH front wheel studs, and then hand-tighten the wheel lug nuts (x5).
  7. Remove the LH front drive unit halfshaft from the LH front hub assembly, and then set the halfshaft aside.
    Note
    While holding the hub in position, turn the hydraulic hub puller tool handle clockwise to separate the LH front drive unit halfshaft from the hub assembly.
  8. Remove the hub puller tool from the LH front wheel studs.
  9. Remove the bolt that attaches the LH front brake hose bracket to the LH front suspension knuckle.
  10. Remove and discard the bolts that attach the LH front brake caliper to the LH front suspension knuckle, and then use an S-hook to hang the caliper off of the vehicle.
    CAUTION
    Make sure the brake caliper and hoses are not twisted when hanging the caliper or during reinstallation, as this can damage the brake hose.
  11. Remove the LH front brake rotor. See Brake Rotor - Front - LH (Remove and Replace).
  12. Remove the bolts that attach the LH front hub to the LH front knuckle.
  13. Remove the LH front hub from the vehicle.
  14. Remove the LH front brake dust shield. See Shield - Dust - Brake - Front - LH (Remove and Replace).
  15. Remove the bolts that attach the LH front ABS wheel speed sensor and electrical harness to the LH front suspension knuckle.
  16. Release the clip that attaches the LH front ABS wheel speed sensor electrical harness to the LH front suspension knuckle.
  17. Remove and discard the nut that attaches the LH tie rod end to the LH front suspension knuckle, and then remove the tie rod end from the knuckle.
  18. Remove the bolt and discard the nut that attach the LH upper control arm to the LH front suspension knuckle.
  19. Remove and discard the nut that attaches the LH front lower compliance link to the front suspension knuckle.
  20. Remove and discard the nut that attaches the LH front lower lateral link to the LH front suspension knuckle.
  21. Remove the LH front suspension knuckle from the vehicle.

Install

  1. Rest the LH front drive unit half shaft in the LH front suspension knuckle, and then install a new nut that attaches the knuckle to the lower lateral link.
    180 Nm (132.7 lbs-ft)
  2. Install a new nut that attaches the LH front lower compliance link to the LH front suspension knuckle.
    180 Nm (132.7 lbs-ft)
    Note
    Use a T45 bit to hold the LH front lower compliance link in position.
  3. Install the bolt and new nut that attach the LH upper control arm to the LH front suspension knuckle.
    56 Nm (41.3 lbs-ft)
    56 Nm (41.3 lbs-ft)
  4. Install a new nut that attaches the LH tie rod end to the LH front suspension knuckle.
    180 Nm (132.7 lbs-ft)
  5. Install bolts that attach the LH front ABS wheel speed sensor and electrical harness to the LH front suspension knuckle.
    5 Nm (3.7 lbs-ft)
  6. Install the clip that attaches the LH front ABS wheel speed sensor electrical harness to the LH front suspension knuckle.
  7. Install the LH front brake dust shield. See Shield - Dust - Brake - Front - LH (Remove and Replace).
  8. Use a magnetic field viewing card to check the LH front hub's tone ring. For more information, see https://toolbox.teslamotors.com/articles/28542.
  9. Apply approximately 1 gram of Molykote M-77 Lubricant Paste only to the hub mating face on the outboard side of the LH front drive unit halfshaft.
    CAUTION
    Do not apply any lubricant to the halfshaft splines. If lubricant is mistakenly applied, wipe the splines clean with a shop towel.
  10. Pull on the inner halfshaft cup to confirm that the circlip is locked into place. If the halfshaft detaches from the drive unit then reinstall the halfshaft and then test that it is fully seated.
    CAUTION
    If reinstalling the halfshaft to the drive unit:
    • Take care not to damage or displace the oil seals.
    • Make sure that the opening of the snap rings are facing towards the bottom of the drive unit.
    • Carefully push the halfshaft into the drive unit until there is an audible "click" from the halfshaft stub contacting the pinion shaft.
    • There will be a slight pulling sensation on the halfshaft as the halfshaft circlip locks into place.
    • Pull on the inner halfshaft cup to confirm that the circlip is locked into place. If the halfshaft detaches from the drive unit then reinstall the halfshaft and then test that it is fully seated.
  11. Position the LH front hub on the LH front suspension knuckle, and then insert the LH front halfshaft in the hub.
  12. Install the bolts that attach the LH front hub to the LH front knuckle.
    85 Nm (62.7 lbs-ft)
  13. Install the LH front brake rotor. See Brake Rotor - Front - LH (Remove and Replace).
  14. Remove the S-hook, and then install the new bolts that attach the LH front brake caliper to the LH front suspension knuckle.
    94 Nm (69.3 lbs-ft)
    CAUTION
    Make sure the brake caliper and hoses are not twisted when hanging the caliper or during reinstallation, as this can damage the brake hose.
  15. Install the bolt that attaches the LH front brake hose bracket to the LH front suspension knuckle.
    5 Nm (3.7 lbs-ft)
  16. Hand-tighten the new front drive unit halfshaft nut and washers.
  17. Position the LH front wheel on the vehicle, and then hand-tighten the LH front wheel lug nuts.
  18. Lower the vehicle until the tires are touching the ground, and then fully tighten the LH front wheel lug nuts. See Wheel Assembly (Remove and Install).
  19. Fully tighten the new front drive unit halfshaft nut and washers.
    300 Nm (221.2 lbs-ft)
  20. If equipped, install the LH front wheel center cap. See Cap - Wheel (Remove and Replace).
  21. Refer to the Alignment Requirement tables to determine whether an EPAS alignment check (EC) or four wheel alignment check (AC) is necessary. If performed, add the alignment check/adjust correction code as a separate activity to the SV. See Alignment Requirement - Suspension.
