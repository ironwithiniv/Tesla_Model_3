A/C Compressor, Supermanifold and Compressor to Supermanifold A/C Line (Heat Pump) (Remove and Replace)

Correction code 18204012 1.92 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. Note
This is the procedure to replace the supermanifold, compressor and supermanifold to compressor A/C line, using the Heat Pump HVAC Debris Flush Adapter 1838504-C0-A, 1838504-E0-A or 1838504-N0-A. By flushing the supermanifold to HVAC A/C line and the HVAC assembly, the supermanifold to HVAC A/C line and the HVAC assembly can be reused. This procedure is used when the compressor failed due to a mechanical issue which lead to debris in the A/C system.If the Debris Flush Adapter 1838504-00-B is available, use the procedure described in A/C Compressor and Supermanifold (Remove and Replace).
Note
This procedure requires the A/C Refrigerant (Recovery and Recharge) procedure to be performed. If not already automatically added to the Service Visit, add correction code 18200102 as a separate correction within the same activity to the Service Visit.
Equipment:
  • 1600279-00-A A/C Oil Flush Adapter Set
  • 1838504-C0-A, 1838504-E0-A, 1838504-N0-A Debris Flush Adapter
  • 1711245-00-A - Snap On Ecotechnics Dual Gas A/C Machine, includes Flush Adapter Kit R134A & R1234YF or
  • 1120026-01-A A/C SERVICE MACHINE, WAECO, ASC5500 RPA

Remove

  1. Set up the A/C machine.
  2. Raise and support the vehicle.
  3. Open all four doors and lower the windows.
    Note
    Latch rear doors to prevent accidental closing when 12V/LV power is disconnected.
  4. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  5. Place the vehicle in Service Mode. See Service Mode.
  6. Check the thermal alerts via the touchscreen by pressing the alert icon.
    If one or more of the following alerts are present, perform a full flush later in the procedure.
    • VCFRONT_a161_compressorSelfFault
    • VCFRONT_a163_compressorDisabledFSR
    • VCFRONT_a460_hardIsentropicTdFailed
    • VCFRONT_a467_lowPowerIndexFlagged
    • VCFRONT_a531_lowPowerIndexFlaggedUserFacing
    • VCFRONT_a543_compressorLowFlowDeliveryDetected
    If none of the alerts listed above are present, perform a fast flush later in the procedure.
  7. On the touchscreen, touch Service Mode > Thermal > Refrigerant System > Start Thermal Fill Drain (Coolant + Refrigerant) and select Run to start the "Start Thermal Fill Drain (Coolant & Refrigerant)" routine.
  8. Disconnect 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  9. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  10. Recover the refrigerant from the vehicle. See A/C Refrigerant (Recovery and Recharge).
  11. Remove the fresh intake duct. See Duct - Fresh Intake (Remove and Replace).
  12. Perform Vehicle HV Disablement Procedure. See Vehicle HV Disablement Procedure.
  13. Position a coolant drain container underneath the front of the vehicle.
  14. Remove the coolant bottle cap.
  15. Disconnect the powertrain bypass hose from the Supermanifold.
    Note
    This will drain the coolant reservoir.
  16. Disconnect the radiator outlet hose from the Supermanifold.
  17. Disconnect the radiator inlet hose from the Supermanifold.
  18. Install three male plugs into the coolant ports at the front of the Supermanifold.
  19. Before performing the next two steps, inspect the coolant hose temperature sensors and connectors.
    Note
    If the vehicle is equipped with an earlier model temperature sensor (left image), the new super manifold connectors may not fit. In this case the electrical connector cover must be swapped from the old supermanifold to the new supermanifold. Perform #TASK_REWORK_CONNECTOR before installation.
  20. Disconnect the sensor for the chiller to battery hose.
  21. Disconnect the sensor for the powertrain supply hose.
  22. Disconnect the chiller to battery hose from the supermanifold.
  23. Disconnect the powertrain supply hose from the supermanifold.
  24. Disconnect the HV battery return hose from the Supermanifold.
  25. Install three male plugs into the coolant ports at the rear of the Supermanifold.
  26. Disconnect the supermanifold harness connector from the front controller.
  27. Remove the clip that attaches the thermal sub assembly harness to the front harness guide cover.
  28. Remove the 12V/LV battery. See 12V/LV Battery (Remove and Replace).
  29. Release the clips (x2) that attach the coolant hose to the A/C compressor bracket.
  30. Remove the clip that attaches the A/C compressor logic harness to the A/C compressor HV harness bracket.
  31. Release the connector locking tab, and then disconnect the low voltage electrical connector from the A/C compressor.
    CAUTION
    DO NOT push down on the red locking tab. Pull the tab away from the connector until the connector is unlocked, and then continue pulling the main body of the connector to fully disconnect it.
  32. Remove the bolt that attaches the HV harness bracket to the A/C compressor.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
    • Cordless Ratchet/Impact Driver
    • Ratchet/torque wrench
  33. Remove the bolt that attaches the ground strap to the A/C compressor, and then set the ground strap aside.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket
    • Cordless Ratchet/Impact Driver
    • Ratchet/torque wrench
  34. Release the clip that attaches the coolant hose to the A/C compressor bracket, near the ground strap attachment point.
  35. Pull the A/C compressor HV connector black locking tab away from the A/C compressor.
  36. Using a 45-degree pick, simultaneously push on the central locking tab while pulling on the outer locking tab, and remove the HV connector from the A/C compressor.
  37. Disconnect the HVIL electrical connector.
  38. After A/C recovery is completed, remove the A/C hoses from the vehicle.
  39. Remove the nut that attaches the supermanifold to compressor suction line to the compressor.
    Note
    Use of the following tool(s) is recommended:
    • 13 mm deep socket
    • Flex head ratchet/flex head torque wrench
  40. Remove the nut that attaches the supermanifold to compressor discharge line to the compressor.
    Note
    Use of the following tool(s) is recommended:
    • 13 mm deep socket
    • Flex head ratchet/flex head torque wrench
  41. Remove the bolt on the A/C manifold to compressor line from the Supermanifold, and then remove the A/C manifold line from the vehicle.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
    • 6 in extension
    • Flex head ratchet/flex head torque wrench
  42. Remove the bolts (x2) that attach the supermanifold to HVAC A/C line to the HVAC assembly.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  43. Remove the rear battery tie down strap from the 12V/LV battery bracket.
    Note
    The 12V/LV battery bracket also functions as the A/C compressor bracket.
  44. Release the clip that attaches the 12V/LV battery vent tube to the battery bracket.
  45. Release the clip that attaches the A/C compressor low voltage harness to the A/C compressor HV harness bracket.
  46. Move the HV harness bracket forward and up to release the bracket from the A/C compressor, and then carefully set the bracket aside.
  47. Remove the retaining clips that attach the A/C compressor HV harness to the shock tower support brace.
    Note
    Pull upward on clip to assist with removal, Do not pull on HV cable.
  48. Remove the LH and RH bolts that attach the shock tower brace to the body.
    55 Nm (40.6 lbs-ft)
    55 Nm (40.6 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm socket
    • Flex head ratchet/flex head torque wrench
  49. Remove the LH and RH outer bolts that attach the shock tower brace to the body, and then remove the shock tower brace from the vehicle.
    62 Nm (45.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm socket
    • Flex head ratchet/flex head torque wrench
  50. With assistance, remove the shock tower brace along with Supermanifold and compressor from the vehicle.
    Note
    Mind the connectors and A/C lines, then slowly lift the brace. Put it on a cardboard pad.
  51. Remove the nut that attaches the supermanifold to HVAC A/C line assembly to the supermanifold, and remove the supermanifold to HVAC A/C line assembly.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
    • Cordless Ratchet/Impact Driver
    • Flex head ratchet/flex head torque wrench
  52. Document the old and new part numbers and serial numbers.
    Note
    Label is located in front of accumulator.
  53. Remove the bolts (x2) that attach the supermanifold to the shock tower brace, and then remove the supermanifold.
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm socket
    • Cordless Ratchet/Impact Driver
    • Flex head ratchet/flex head torque wrench
  54. Remove the bolts (x2) that attach the A/C compressor bracket to the shock tower brace, and then remove the A/C compressor and A/C compressor bracket assembly.
    Note
    Use of the following tool(s) is recommended:
    • 15 mm socket
    • Flex head ratchet/flex head torque wrench
  55. Remove A/C compressor bracket from the A/C compressor.
    Note
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
    • Flex head ratchet/flex head torque wrench
  56. Document the part numbers of the new and old compressors to update the configuration in a later step.

Flush HVAC system and prepare components for Snap-On A/C Machine

  1. Temporarily install the old Supermanifold to HVAC A/C line, and install the bolts (x2) (Torque 28 Nm) that attach the line to the HVAC assembly
  2. Install the flush adapter 1838504-E0-A to the Supermanifold to HVAC A/C line.
    Note
    1x nut, 13mm, 36 Nm
  3. Connect the HVAC case flush adapter to the A/C machine.
    Note
    Connect the red pressure line to the left side of the adapter, bolt the blue line coming from the flush kit to the right side of the adapter.
  4. Connect Snap on A/C machine hoses to the A/C flush adapters and run the flush procedure by selecting Menu > > Num 4 > OK > OK.
    Note
    The flush procedure runs for approximately 90 minutes, a minimum of 3.2 kg of refrigerant is needed in the tank to run the system flush procedure.
  5. Disconnect the flush adapter from the A/C machine.
  6. Remove the coolant drain container from underneath the vehicle.
  7. Remove the A/C line plugs from the new Supermanifold.
  8. Install the plug into the old Supermanifold to HVAC lines holes.
    Note
    Try to avoid oil leakage as much as possible.
  9. Install the plug into the old Supermanifold to A/C compressor lines hole.
    Note
    Try to avoid oil leakage as much as possible.
  10. Prepare the part for MRB shipment as a special interest.
    Note
    Unplug all the Coolant Only plugs from the Supermanifold and drain as much coolant as you can to the Low Profile Fluid Receiver. Carefully pack it to the box in the same way how the new one was there. Write down the Toolbox Session number, Tesla Model, and the last 6 digits of the VIN.
  11. Remove the existing supermanifold to HVAC A/C line from the HVAC.
  12. Install new seal washers to the existing supermanifold to HVAC A/C line at the supermanifold side.
    Note
    1111740-00-A WASHER,3/4,STEEL ZN,SEAL (x1), 1111738-00-A WASHER,1/2,STEEL ZN,SEAL (x1), 1111737-00-A WASHER, 3/8, STL ZN, SEAL (x3).
  13. Install the supermanifold to HVAC A/C line assembly to the supermanifold and install the nut hand tight.
    Note
    1x nut, 13mm, 36 Nm. Torque at a later step.
  14. Remove the A/C compressor bracket from the A/C compressor
    Note
    3x bolts, 10mm, 9 Nm
  15. Remove transportation plugs from the new A/C compressor
  16. Prepare the part for MRB shipment as a special interest
    Note
    Install transportation plugs from the new A/C compressor to the old compressor to avoid oil leakage during the transportation
  17. Install the A/C compressor bracket to the A/C compressor
    Note
    3x bolts, 10mm, 9 Nm
  18. Overlap from A/C system flush procedure
    Note
    Subtract time spent on other operations while waiting for A/C system flush, fast flush is 40 minutes, full flush is 1 hour and 40 minutes
  19. Disconnect the low pressure hose from the A/C machine to the quick connector of the filter
  20. Disconnect HVAC case flush adapter from A/C machine
    Note
    Disconnect the red pressure line to the left side of the adapter, unscrew the blue line coming from the flush kit to the right side of the adapter
  21. Remove adapter from vehicle
    Note
    1x nut, 13mm, 36 Nm
  22. Remove the bolts (x2) that attach the supermanifold to HVAC A/C line to the HVAC assembly, and then remove the A/C line from the vehicle.

Flush HVAC system and prepare components for Waeco A/C Machine

  1. Temporarily install the old Supermanifold to HVAC A/C line, and install the bolts (x2) (Torque 28 Nm) that attach the line to the HVAC assembly
  2. Install the flush adapter to the Supermanifold to HVAC A/C line.
    Note
    1x nut, 13mm, 36 Nm
  3. Set up flush kit to A/C machine.
    Note
    Attach the flush kit to the Waeco A/C machine. 2x bolts, 8mm, 1x Nyloc nut
  4. Inspect the liquid line filter drier marking.
    Note
    Mark the filter before every flush with paint marker, replace the filter after 10 flushes.
    Note
    If replacement of the filter is not yet necessary, go to step 7.
  5. Remove the liquid inline filter drier
    Note
    Remove the filter from the container (the grey filter attached to the flush unit) PR052FM, Good to re-use copper o-ring, use hand force no tools
  6. Replace the liquid inline filter drier (the grey filter attached to the flush unit) PR052FM
    Note
    1x new filter, 2x new copper sealing rings, Wear appropriate PPE, Swap the nipple from old to new filter, Install copper sealing ring between connections, Do not over tighten, hand tight, due to copper line Ensure old sealing was removed before installing new filter, use pick tool to remove copper ring if needed
  7. Connect the low pressure hose from the A/C machine to the quick connector of the filter
  8. Connect the HVAC case flush adapter to A/C machine
    Note
    Connect the red pressure line to the left side of the adapter, bolt the blue line coming from the flush kit to the right side of the adapter
  9. Connect A/C machine hoses to A/C flush adapters and flush the HVAC case.
    Note
    If one or more of the alerts mentioned in step 6 of the 'Remove' section are present, choose Full flushing. If no alerts are present, choose Fast flushing.
    Note
    Fast flush procedure runs for approximately 40 minutes. If one of the Illustrated alerts are present, run full flush. This takes around 1 hours and 40 minutes. Must use A/C Service Machine WAECO ASC 5500G RPA R1234YF. A minimum of 6 kg of refrigerant is needed in the tank to run the system flush procedure. Press Enter => Other Selections => Enter => Flushing => Enter => Enter => Enter =>=> Full Flushing => Enter
  10. Remove the coolant drain container from underneath the vehicle.
  11. Remove the A/C line plugs from the new Supermanifold
  12. Install plug into the old Supermanifold to HVAC lines holes
    Note
    Try to avoid oil leakage as much as possible
  13. Install plug into the old Supermanifold to A/C compressor lines holes
    Note
    Try to avoid oil leakage as much as possible
  14. Prepare the part for MRB shipment as a special interest
    Note
    Unplug all the Coolant Only plugs from the Supermanifold and drain as much coolant as you can to the Low Profile Fluid Receiver,Carefully pack it to the box in the same way how the new one was there, Write down the Toolbox Session number,Tesla Model, last 6 digits of VIN
  15. Install supermanifold to HVAC A/C line assembly to supermanifold and install nut hand tight
    Note
    1x nut, 13mm, 36 Nm, Torque at later step
  16. Remove the A/C compressor bracket from the A/C compressor
    Note
    3x bolts, 10mm, 9 Nm
  17. Remove transportation plugs from the new A/C compressor
  18. Prepare the part for MRB shipment as a special interest
    Note
    Install transportation plugs from the new A/C compressor to the old compressor to avoid oil leakage during the transportation
  19. Install the A/C compressor bracket to the A/C compressor
    Note
    3x bolts, 10mm, 9 Nm
  20. Overlap from A/C system flush procedure
    Note
    Subtract time spent on other operations while waiting for A/C system flush, fast flush is 40 minutes, full flush is 1 hour and 40 minutes
  21. Disconnect the low pressure hose from the A/C machine to the quick connector of the filter
  22. Disconnect HVAC case flush adapter from A/C machine
    Note
    Disconnect the red pressure line to the left side of the adapter, unscrew the blue line coming from the flush kit to the right side of the adapter
  23. Remove adapter from vehicle
    Note
    1x nut, 13mm, 36 Nm

Install

  1. Install the NVH acoustic cover onto the new compressor.
    Note
    Install a new cover or reuse the old cover if the adhesive is in usable condition and a new cover is not available.
    Note
    Remove the adhesive backing, and then lay the cover down with the adhesive side facing up. Align the cutouts to the suction port on the compressor, install the cover around the suction port, and then continue to wrap the cover around the compressor.
  2. Position the A/C compressor bracket on the A/C compressor, and then install the bolts that attach the bracket to the compressor.
    9 Nm (6.6 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
    • Flex head ratchet/flex head torque wrench
  3. Position the A/C compressor and A/C compressor bracket assembly to the strut shock tower brace, and then hand-tighten the bolts (x2) to secure.
  4. Remove the bolts (x2) that attach the supermanifold to HVAC A/C line to the HVAC assembly, and then remove the A/C line from the vehicle.
  5. Replace the seal washers of the existing supermanifold to HVAC A/C line at the supermanifold side.
    Note
    1111740-00-A WASHER,3/4,STEEL ZN,SEAL (x1), 1111738-00-A WASHER,1/2,STEEL ZN,SEAL (x1), 1111737-00-A WASHER, 3/8, STL ZN, SEAL (x3).
    Note
    Lubricate seal washers with ND-11 oil.
  6. Remove the A/C line plugs from the new supermanifold.
  7. Replace the seal washers on supermanifold to HVAC A/C line assembly on the HVAC side.
    Note
    1111740-00-A WASHER,3/4,STEEL ZN,SEAL (x1), 1111738-00-A WASHER,1/2,STEEL ZN,SEAL (x1), 1111737-00-A WASHER, 3/8, STL ZN, SEAL (x3).
    Note
    Lubricate seal washers with ND-11 oil.
  8. Hand-tighten the nut that attach the supermanifold to HVAC A/C line assembly to the supermanifold.
  9. Torque the nut that attach the supermanifold to HVAC A/C line assembly to the supermanifold.
    36 Nm (26.5 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • 13 mm socket
    • Flex head ratchet/flex head torque wrench
    • 6 in extension
  10. Position the supermanifold assembly to the shock tower brace, and then hand-tighten the bolts that attach the supermanifold assembly to the brace.
  11. Tighten the bolts that attach the supermanifold assembly to the shock tower brace.
    31 Nm (22.9 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • 15 mm socket
    • Flex head ratchet/flex head torque wrench
    • 6 in extension
  12. Tighten the bolts (x2) that attach the compressor to the strut shock tower brace.
    31 Nm (22.9 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • 15 mm deep socket
    • Flex head ratchet/flex head torque wrench
  13. With assistance, install the supermanifold and compressor along with shock tower brace to the vehicle.
    Note
    2 technicians are required for this step, Mind the connectors and A/C lines, slowly lift the brace.
  14. Install the LH and RH bolts that attach the shock tower brace to the body.
    55 Nm (40.6 lbs-ft)
    55 Nm (40.6 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • 15 mm socket
    • Flex head ratchet/flex head torque wrench
  15. Install the LH and RH outer bolts that attach the shock tower brace to the body.
    62 Nm (45.7 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • 15 mm socket
    • Flex head ratchet/flex head torque wrench
  16. Install the bolts (x2) that attach the supermanifold to HVAC A/C line to the HVAC assembly.
    28 Nm (20.6 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm socket
  17. Install the radiator inlet hose to the Supermanifold.
    Note
    Perform a push-pull-push test to make sure the hose is fully seated. Do not wiggle the hose at the connection.
  18. Install the radiator outlet hose to the Supermanifold.
    Note
    Perform a push-pull-push test to make sure the hose is fully seated. Do not wiggle the hose at the connection.
  19. Install the powertrain bypass hose to the Supermanifold.
    Note
    Perform a push-pull-push test to make sure the hose is fully seated. Do not wiggle the hose at the connection.
  20. Connect the HV battery return hose to the Supermanifold.
    Note
    Perform a push-pull-push test to make sure the hose is fully seated. Do not wiggle the hose at the connection.
  21. Connect the powertrain supply hose to the Supermanifold.
    Note
    Perform a push-pull-push test to make sure the hose is fully seated. Do not wiggle the hose at the connection.
  22. Connect the chiller to battery hose to the Supermanifold.
    Note
    Perform a push-pull-push test to make sure the hose is fully seated. Do not wiggle the hose at the connection.
  23. Connect the sensor for the powertrain supply hose.
    Note
    Harness and coolant hose are color coded. Match harness color to coolant hose color.
  24. Connect the sensor for the chiller to battery hose.
    Note
    Harness and coolant hose are color coded. Match harness color to coolant hose color.
  25. Install the clip that secures the thermal sub assembly harness to the front harness guide cover.
  26. Connect the thermal sub-harness connector to the front controller.
  27. Position the A/C compressor HV harness bracket on the A/C compressor.
    Note
    Make sure the HV harness bracket engages with the harness mount on the top of the A/C compressor.
  28. Install the bolt that attaches the HV harness bracket to the A/C compressor.
    9 Nm (6.6 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm deep socket
    • Ratchet/torque wrench
    Tip
  29. Connect the HVIL electrical connector.
  30. Fully seat the A/C compressor HV connector on the A/C compressor, and then engage the locking tab by pushing it toward the A/C compressor.
    Note
    Perform a push-pull test to verify that the connector is fully attached.
  31. Install the retaining clips that secure the A/C compressor HV harness to the shock tower brace.
  32. Install the clip that attaches the coolant hose to the A/C compressor bracket, near the ground strap attachment point.
  33. Position the ground strap on the A/C compressor, and then install the bolt that attaches the ground strap to the A/C compressor.
    7 Nm (5.2 lbs-ft)
    Note
    This bolt is self-tapping. It is not necessary to tap the compressor bolt hole.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket
    • Cordless Ratchet/Impact Driver
    • Ratchet/torque wrench
  34. Install the clip that attaches the A/C compressor low voltage harness to the A/C compressor HV harness bracket.
  35. Connect the low voltage electrical connector to the A/C compressor, and then engage the locking tab.
    CAUTION
    Push the red locking tab towards the connector to engage the locking mechanism. DO NOT push down or pull up on the red locking tab.
  36. Remove transportation plugs from the new A/C compressor.
  37. Lubricate the O-rings on the high pressure and low pressure supermanifold to A/C compressor hose fittings of the new A/C line with the appropriate A/C oil. See Fluids and Capacities for A/C oil specifications.
  38. Position the supermanifold to A/C compressor high pressure fitting on the A/C compressor, and then install the nut that attaches the fitting to the A/C compressor.
    22 Nm (16.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm deep socket
    • Flex head ratchet/flex head torque wrench
  39. Position the supermanifold to A/C compressor low pressure fitting on the A/C compressor, and then install the nut that attaches the fitting to the A/C compressor.
    22 Nm (16.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm deep socket
  40. Position the supermanifold to compressor A/C line onto the supermanifold, and then hand tighten the bolt that attaches the A/C line to the supermanifold.
  41. Torque the bolt that attaches the supermanifold to compressor A/C line to the supermanifold.
    22 Nm (16.2 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • 13 mm socket
    • Flex head ratchet/flex head torque wrench
    • 6 in extension
  42. Install the clips (x2) that attach the coolant hose to the A/C compressor bracket.
  43. Install the rear battery tie down strap on the 12V battery bracket.
  44. Install the clip that attaches the 12V battery vent tube to the 12V battery bracket.
  45. Install the 12V/LV auxiliary battery. See 12V/LV Battery (Remove and Replace).
  46. Connect first responder loop and LV battery.
  47. On the touchscreen, touch Service Mode > Thermal > Refrigerant System > Start Thermal Fill Drain (Coolant & Refrigerant) and select Run to start the "Start Thermal Fill Drain (Coolant & Refrigerant)" routine.
  48. Disconnect 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  49. Perform A/C vacuum leak test. See A/C Refrigerant (Recovery and Recharge).
  50. Perform A/C refrigerant recharge. See A/C Refrigerant (Recovery and Recharge).
  51. Perform a cooling system vacuum refill. See Cooling System (Vacuum Refill).
  52. Connect 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  53. Connect a LV maintainer. See LV Maintainer (Connect and Disconnect).
  54. Enable Service Mode Plus. See Service Mode Plus.
  55. Set the compressor Type using the touchscreen:
    • For vehicles that run firmware version 2026.2.3 or later (NA/EMEA) or 2025.44.32 or later (APAC), touch Thermal > Actions > Configure Compressor, and then touch Run to start the routine.
