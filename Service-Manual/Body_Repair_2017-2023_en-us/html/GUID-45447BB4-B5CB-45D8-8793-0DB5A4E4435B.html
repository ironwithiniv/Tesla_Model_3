Defrost Cover - Instrument Panel - LH (Remove and Replace)

Correction code 14051502 1.68 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

Remove

  1. Remove the IP carrier from the cross car beam. See IP Carrier (Remove and Install).
  2. Release the tabs that attach the LH defrost cover to the IP carrier, and then remove the cover from the assembly.

Install

  1. Install the LH instrument panel defrost cover onto the IP carrier.
  2. Install the IP carrier into the cross car beam. See IP Carrier (Remove and Install).
