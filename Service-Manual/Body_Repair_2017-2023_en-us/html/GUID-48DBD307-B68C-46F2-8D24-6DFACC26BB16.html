Window Regulator (Recalibrate)

Correction code 11500010 0.06 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

  • 2024-06-05: Updated calibration steps using the touchscreen.
  1. Get into the driver seat, and then close the door.
  2. Use the touchscreen to enable Service Mode. See Service Mode.
  3. Unlock the vehicle gateway. See Gateway (Unlock)
  4. On the touchscreen, touch Controls > Service Mode > Closures > Windows, and then tap each window's Calibrate button to calibrate the windows.
    Note
    During window calibration, the selected window(s) will roll up and down until window calibration is complete.
    CAUTION
    Pinch detection is disabled during window calibration.
  5. Exit Service Mode. See Service Mode.
