Vent - Front - LH (Remove and Replace)

Correction code 14053102 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

  • 2026-04-07: Added toolbox steps for HVAC routines.

Torque Specifications

Table 1. Torque Specifications: Vent - Front - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Screw that attaches the LH front vent to the IP carrier
2.3 Nm (1.7 lbs-ft)
  • Torx T20 socket
  • 4 in extension
  • Ratchet/torque wrench
Reuse

Remove

  1. Remove the vent finisher. See Finisher - Vent (Remove and Replace).
  2. Remove the screw that attaches the LH front vent to the Instrument Panel (IP).
    2.3 Nm (1.7 lbs-ft)
  3. Carefully release the LH front vent from the IP, and then disconnect the vent electrical connector.
    CAUTION
    Do not use excessive force to remove the vent from the IP.
  4. Remove the LH front vent from the vehicle.

Install

  1. Position the LH front vent on the vehicle, and then connect the vent electrical connector.
  2. Carefully place the LH front vent into the IP, and then install the screw that attaches the vent to the IP.
    2.3 Nm (1.7 lbs-ft)
    CAUTION
    If the vehicle is left hand drive, make sure not to dislodge the foam block in the cavity where the front LH vent installs.
  3. Install the vent finisher. See Finisher - Vent (Remove and Replace).
  4. Locally connect a laptop with Toolbox 3 to the vehicle. See Toolbox (Connect and Disconnect).
  5. Run ODIN routine PROC_ICE_X_ENTER-SERVICE-MODE-PLUSvia Toolbox:(link)
  6. In Toolbox, click on the Actions tab, and then search for "Actuator".
  7. Run ODIN routine TEST-SELF_VCRIGHT_X_HVAC-CASE-ACTUATORSvia Toolbox:(link)
  8. Run ODIN routine TEST-SELF_VCRIGHT_L_HVAC-VANE-ACTUATORvia Toolbox:(link)
  9. Disable Service Mode using either a laptop with Toolbox 3 or the vehicle touchscreen. See Service Mode.
