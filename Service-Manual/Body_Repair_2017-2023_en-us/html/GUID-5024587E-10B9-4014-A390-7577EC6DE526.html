Trim - Side - Trunk - LH (Remove and Replace)

Correction code 15245002 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

  • 2026-02-25: Added tip for more clearance on 7-seat vehicles.
  • 2024-02-19: Added a note about production differences.

Remove

  1. Remove the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
    Note
    It is not necessary to remove the 2nd row lower seat cushion in 7-seater vehicles. Tilt the LH 2nd row seat forward instead.
  2. Remove the LH lower C-pillar trim. See GUID-DB75BFBB-980C-4767-844D-DD5FC4AEE1F0.html.
  3. Remove the rear trunk load floor. See GUID-D937E149-8C0B-486F-A555-376066BE8144.html.
  4. For 7-seater vehicles, fold the 3rd row seat backs to the down position.
  5. Remove the front trunk load floor. See GUID-EFA5DE2D-2C91-48BC-94B0-8B596AB74B95.html.
  6. Remove the trunk sill trim. See Trim - Sill - Trunk (Remove and Replace).
  7. Remove the LH trunk load floor bracket. See GUID-4EEFF013-172F-4129-B716-FF6D07036C59.html.
  8. Remove the LH trunk pocket bracket. See GUID-D01DCDF3-22A5-4406-8014-AB3DBF61A39A.html.
  9. Release the clips (x6) that attach the top edge of the LH trunk side trim to the vehicle, and then carefully pull back the top edge of the trim.
    Note
    The trim part and the number of clips in the following steps may slightly differ by vehicle build date and location.
    Note
    Do not pull the trim too far from the body, as harnesses are still connected to the trim.
    Tip
    For more clearance on 7-seat vehicles, release and prop up the 3rd row seat assembly, and then remove the LH 3rd row seat bolster.
  10. Reach behind the LH trunk side trim and disconnect the electrical connectors (x3) from the trim.
    CAUTION
    Do not touch the terminals at the rear of the auxiliary low voltage connector as they are still powered.
    Note
    7-seater vehicles have 2 connectors.
  11. Release the remaining clips (x6) that attach the LH trunk side trim to the vehicle, and then remove the trim from the vehicle.
    Note
    For 7-seater vehicles, guide the front clip stanchions around the LH C-pillar, pull the top of the trunk side trim all the way down flat so that it clears the edge of the folded down LH 3rd row seatback, and then pull the trim straight out.

Install

  1. Position the LH trunk side trim into the vehicle, and then install the clips (x5) that attach the lower portion of the trim to the vehicle.
    Note
    Guide the front clip stanchions around the LH C-pillar.
    Note
    For 7-seater vehicles, start by tucking the lower portion of the trim around the edge of the LH 3rd row seat back.
  2. Connect the electrical connectors (x3), and then install the clips (x6) that attach the upper portion of the LH trunk side trim to the vehicle..
    Note
    7-seater vehicles have 2 connectors.
  3. Install the LH trunk pocket bracket. See GUID-D01DCDF3-22A5-4406-8014-AB3DBF61A39A.html.
  4. Install the LH trunk load floor bracket. See GUID-4EEFF013-172F-4129-B716-FF6D07036C59.html.
  5. Install the trunk sill trim. See Trim - Sill - Trunk (Remove and Replace).
  6. Install the front trunk load floor. See GUID-EFA5DE2D-2C91-48BC-94B0-8B596AB74B95.html.
  7. For 7-seater vehicles, raise the 3rd row seatbacks to the original positions.
  8. Install the rear trunk load floor. See GUID-D937E149-8C0B-486F-A555-376066BE8144.html.
  9. Install the LH lower C-pillar trim. See GUID-DB75BFBB-980C-4767-844D-DD5FC4AEE1F0.html.
  10. Install the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
