Sill Insert (Front Section)

Correction code: 10100122202 NOTE: Unless explicitly stated in the procedure, the above correction code includes all Collision Repair and Service repair work required to perform this procedure, including the linked Collision Repair procedures and linked Service procedures. Do not stack Collision Repair correction codes unless explicitly told to do so. Depending on the damage to the vehicle, additional repairs may be required.

Parent topic: Body Side Panels

Repair Information

  • Review all collision repair general practices and safety documentation and wear the appropriate PPE (Personal Protective Equipment) before beginning this procedure.
  • This procedure can be completed without using a frame bench.

When ordering parts, refer to the Parts Catalog and enter the VIN of the vehicle being repaired to find the correct parts (and the part numbers) for the vehicle. Alternatively, use the search function in the Parts Catalog to find a specific part for the vehicle.

Repair Procedure

  1. Remove the Fender Assembly - Front - LH (Remove and Install).
  2. Remove the Brake Lines - LH Sill (Remove and Replace).
  3. Remove the Seal - Body - Side - Front - Primary - LH (Remove and Replace).
  4. Remove the Door - Front - LH (Remove and Install).
  5. Remove the Door - Rear - LH (Remove and Install).
  6. Remove the Hinge - Door - Front - Lower - LH (Remove and Replace).
  7. Remove the Hinge - Door - Front - Upper - LH (Remove and Replace).
  8. Remove the Seat Assembly - 1st Row - LH (Remove and Replace).
  9. Remove the Steering Column (LHD) (Remove and Replace).
  10. Remove the IP Carrier (Remove and Install).
  11. Remove the Beam - Cross Car (LHD) (Remove and Replace).
  12. Remove the Module - Body Controller - RH (LHD) (Heat Pump) (Remove and Replace).
  13. Remove the Module - Body Controller - LH (LHD) (Heat Pump) (Remove and Replace).
  14. Remove the Center Console (Remove and Install).
  15. Remove the Trim - B-Pillar - Lower - LH (Remove and Replace).
  16. Remove the Sill Outer (Front Section).
  17. Cut the original component at the indicated locations.

    Cut Line

    Reference Line/Point

    • A = 186 mm

  18. Remove the original component.
  19. Cut the new component in the indicated location.

    Cut Line

    Reference Line/Point

    • B = 645 mm
    • C = 738 mm
  20. Mark the mounting position for the Sill Insert Mounting Bracket on the Sill Insert section in the indicated location.

    Reference Line/Point

    • D = 12 mm
    • E = 167 mm
    • F = 260 mm
  21. Mark the rivet locations on the Sill Insert Mounting Bracket using the measurements provided.

    High Strength Structural Rivet, 6.5 mm

    Reference Line/Point

    • G = 66 mm
    • H = 23 mm
  22. Apply structural adhesive to the mating surfaces on the Sill Insert Mounting Bracket and the new Sill Insert.
  23. Install the Sill Insert Mounting Bracket on the new Sill Insert.
  24. Remove the weld nuts from the Sill Inner.
  25. Drill 8 mm holes for bolts in the Sill Insert section.
    Note
    Using the existing holes in the outer Cell 3 reinforcement plate as guides, drill 8 mm holes for bolts through the Sill Insert portion still in the vehicle.
  26. Enlarge the holes in one of the Cell 3 Reinforcement Insert Plates to 12 mm to allow for SPAC nut installation.
    Note
    SPAC nuts will be mounted on this Reinforcement Plate, which is installed inside the Sill Insert.
  27. Use structural adhesive to install the SPAC nuts in the enlarged holes of the Cell 3 Reinforcement Insert Plate.
    Note
    Refer to Install the new component or components for instructions on installing the SPAC nuts on the inner reinforcement plate.
    Note
    After the adhesive is cured, inspect the threads of the SPAC nuts on the inner Cell 3 Reinforcement Insert Plate and use a thread chaser to remove any dried adhesive.
  28. Prepare for installation.
    • I = 114 mm

    Reference Line/Point

    Bolt
    Note
    Using the existing holes in the outer Cell 3 reinforcement plate as guides, drill 8 mm holes for bolts through the Sill Insert portion still in the vehicle (do not damage the SPAC nuts on the inner Cell 3 reinforcement plate).

    High Strength Structural Rivet, 6.5 mm

  29. Apply structural adhesive to the mating surfaces on the vehicle and the new component or components.
  30. Install the new component or components.
    Note
    Torque the bolts to 25 Nm.
  31. Install the new weld nuts.
    GMA Weld
  32. Perform GMA welding.
    GMA Weld
    Warning
    Failure to follow all welding safety precautions, including the use of personal protective equipment, could result in serious injury or property damage. Only technicians who have completed Tesla’s approved welding training are authorized to weld structural components on Tesla vehicles.
    Warning
    To maintain vehicle crash integrity, use only approved welding wire and an approved GMA welder to perform GMA welding on Tesla vehicles. Refer to Approved Gas Metal Arc (GMA) Welders and Welding Wire for information on approved GMA welders and welding wire.
    CAUTION
    Do not weld on a Tesla vehicle before performing the Vehicle HV Disablement Procedure (refer to the vehicle-specific Service Manual for more information on the Vehicle HV Disablement Procedure). Welding on a Tesla vehicle with an energized high or low voltage system might damage vehicle components.
    Note
    Before GMA welding, a test weld using material of the same gauge and type should be performed to make sure that the welding equipment settings produce a satisfactory joint.
  33. Install the new Sill Outer (Front Section).
  34. Perform any necessary post-repair operations.
  35. Install the Trim - B-Pillar - Lower - LH (Remove and Replace).
  36. Install the Center Console (Remove and Install).
  37. Install the Module - Body Controller - LH (LHD) (Heat Pump) (Remove and Replace).
  38. Install the Module - Body Controller - RH (LHD) (Heat Pump) (Remove and Replace).
  39. Install the Beam - Cross Car (LHD) (Remove and Replace).
  40. Install the IP Carrier (Remove and Install).
  41. Install the Steering Column (LHD) (Remove and Replace).
  42. Install the Seat Assembly - 1st Row - LH (Remove and Replace).
  43. Install the Hinge - Door - Front - Upper - LH (Remove and Replace).
  44. Install the Hinge - Door - Front - Lower - LH (Remove and Replace).
  45. Install the Door - Rear - LH (Remove and Install).
  46. Install the Door - Front - LH (Remove and Install).
  47. Install the Seal - Body - Side - Front - Primary - LH (Remove and Replace).
  48. Install the Brake Lines - LH Sill (Remove and Replace).
  49. Install the Fender Assembly - Front - LH (Remove and Install).
