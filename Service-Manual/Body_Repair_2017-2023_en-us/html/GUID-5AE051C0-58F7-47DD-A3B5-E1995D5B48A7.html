NVH Pads - HV Battery (Install)

Correction code 16103101 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

Install

Note
The labor time for installing the NVH pads does not take into account the time it takes to remove and install the HV battery. The correction code for removing and replacing/installing the HV battery should be added to the Repair Order separately.
  1. Use alcohol wipes to clean the top surface of the HV battery, and then allow to dry for 1 minute.
  2. Measure 180 mm from the base of the base of the Ancillary Bay and apply masking tape to mark the location.
  3. Place the NVH pad so that it is exactly centered between the raised portions of the HV battery top surface, and then apply masking tape to mark the location.
  4. Install the NVH pads (x4) onto the top surface of the HV battery:
    1. Starting from the end closest to the Ancillary Bay, slowly release the NVH pad backing and apply the NVH pad.
      CAUTION
      Make sure the NVH pad remains centered as it is installed.
    2. Wet out the entire NVH pad with a silicon roller.
    3. Perform steps 4a and 4b on the remaining NVH pads.
  5. Remove the masking tape from the top surface of the HV battery.
