Antenna - Bluetooth Passive Entry - Rear (Remove and Replace)

Correction code 17451802 0.78 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

  • 2026-09-17: Add a note of bolt securing rear BLE to center bracket for earlier Model 3 vehicles.
  • 2023-07-31: Moved software reinstall step to before Toolbox self test step.

Torque Specifications

Table 1. Torque Specifications: Antenna - Bluetooth Passive Entry - Rear (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolt that attaches the Bluetooth passive entry module to the body
3.5 Nm (2.6 lbs-ft)
  • T30 socket
 Replace Patch bolt

Remove

  1. Remove the rear fascia. See Fascia - Rear (Remove and Install).
  2. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  3. Disconnect the electrical wiring harness connector from the rear Bluetooth passive entry module.
  4. Remove and discard the bolt and release the clip that attach the Bluetooth passive entry module to the body, and then remove the module from the bracket.
    Note
    When releasing the module from the bracket, rotate the left side away from the bracket to release the tab.
    Note
    Earlier model year vehicles may have been equipped with T30 bolt, This T30 bolt is disposable and should be discarded after removal.
    Note
    Use of the following tool(s) is recommended:
    • T30 socket
    • 2 in extension

Install

  1. Install the new bolt that attaches the Bluetooth passive entry module to the body.
    3.5 Nm (2.6 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • T30 socket
    • 2 in extension
    Note
    Earlier model year vehicles may have been equipped with T30 bolt, Install new T30 patch bolt (1030788-00-A).
  2. Connect the electrical wiring harness connector to the rear Bluetooth passive entry module.
  3. Connect 12V power. See 12V/LV Power (Disconnect and Connect).
  4. Reinstall the vehicle firmware. See Software Reinstall - Touchscreen.
  5. Perform the self-test routine in Toolbox:
    1. Connect a laptop with Toolbox 3.
    2. Click Actions/Autodiag, and then search for "Endpoint".
    3. Select TEST-SELF_VCSEC_X_ENDPOINT-COMMvia Toolbox:(link), and then click Run and allow routine to complete.
      Note
      Once complete, click the X on the window to close it.
  6. Disconnect the laptop from the vehicle.
  7. Install the rear fascia. See Fascia - Rear (Remove and Install).
