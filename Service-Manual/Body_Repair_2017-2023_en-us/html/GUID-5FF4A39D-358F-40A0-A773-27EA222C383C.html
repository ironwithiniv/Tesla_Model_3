Rear Subframe Lower Crossmember

Correction code: 10101814102 NOTE: Unless explicitly stated in the procedure, the above correction code includes all Collision Repair and Service repair work required to perform this procedure, including the linked Collision Repair procedures and linked Service procedures. Do not stack Collision Repair correction codes unless explicitly told to do so. Depending on the damage to the vehicle, additional repairs may be required.

Parent topic: Rear End Panels

Repair Information

  • Review all collision repair general practices and safety documentation and wear the appropriate PPE (Personal Protective Equipment) before beginning this procedure.
  • This procedure can be completed without using a frame bench.

Parts List

Quantity Description Image / Notes
1 Cross Member-Rr Subframe Lower (Rear Subframe Lower Crossmember)
14 High Strength Structural Rivet, 6.5 mm
When ordering parts, refer to the Parts Catalog and enter the VIN of the vehicle being repaired to find the correct parts (and the part numbers) for the vehicle. Alternatively, use the search function in the Parts Catalog to find a specific part for the vehicle.

Repair Procedure

  1. Remove the Plenum - Inlet - HVAC (Remove and Replace).
  2. Remove the Wheel Arch Liner - Rear - LH (Remove and Replace).
  3. Remove the Stabilizer Bar - Rear (Remove and Replace).
  4. Remove the Skid Plate - HV Battery - Rear (Remove and Replace).
  5. Remove the Subframe Assembly - Rear (Remove and Install).
  6. Remove the Cooling System (Vacuum Refill).
  7. Remove the Cooling System (Check and Fill).
  8. Remove the Trim - Side - Trunk - RH (Remove and Replace).
  9. Remove the Trim - Side - Trunk - LH (Remove and Replace).
  10. Remove the Carpet - Rear Trunk (1-Piece) (Remove and Replace).
  11. Remove the Fascia - Rear (Remove and Install).
  12. Remove the Rear Subframe Upper Crossmember.
  13. Remove the original component.
    Factory SPR
  14. Prepare for installation.

    High Strength Structural Rivet, 6.5 mm

  15. Apply structural adhesive to the mating surfaces on the vehicle and the new component or components.
  16. Install the new component or components.
  17. Install the Rear Subframe Upper Crossmember.
  18. Perform any necessary post-repair operations.
  19. Install the Fascia - Rear (Remove and Install).
  20. Install the Carpet - Rear Trunk (1-Piece) (Remove and Replace).
  21. Install the Trim - Side - Trunk - LH (Remove and Replace).
  22. Install the Trim - Side - Trunk - RH (Remove and Replace).
  23. Install the Cooling System (Check and Fill).
  24. Install the Cooling System (Vacuum Refill).
  25. Install the Subframe Assembly - Rear (Remove and Install).
  26. Install the Skid Plate - HV Battery - Rear (Remove and Replace).
  27. Install the Stabilizer Bar - Rear (Remove and Replace).
  28. Install the Wheel Arch Liner - Rear - LH (Remove and Replace).
  29. Install the Plenum - Inlet - HVAC (Remove and Replace).
