Rear Body Panel

Correction code: 10101802002 NOTE: Unless explicitly stated in the procedure, the above correction code includes all Collision Repair and Service repair work required to perform this procedure, including the linked Collision Repair procedures and linked Service procedures. Do not stack Collision Repair correction codes unless explicitly told to do so. Depending on the damage to the vehicle, additional repairs may be required.

Parent topic: Rear End Panels

Repair Information

  • Review all collision repair general practices and safety documentation and wear the appropriate PPE (Personal Protective Equipment) before beginning this procedure.
  • This procedure can be completed without using a frame bench.

Repair Procedure

  1. Remove the Panel - Aero Shield - Rear (Remove and Replace).
  2. Remove the Carpet - Rear Trunk (1-Piece) (Remove and Replace).
  3. Remove the Trim - Side - Trunk - LH (Remove and Replace).
  4. Remove the Subwoofer (Remove and Replace).
  5. Remove the Trim - Side - Trunk - RH (Remove and Replace).
  6. Remove the Bumper Beam - Rear (Remove and Replace).
  7. Remove the Striker - Trunk (Remove and Replace).
  8. Remove the Seal - Trunk (Remove and Replace).
  9. Remove the original component.
    or Factory Spot Welds
    Note
    Some vehicles have an SPR instead of a spot weld in some locations.
    or Drill through factory spot welds
    Note
    When drilling out spot welds, use a drill bit that creates a hole correctly sized for the fastener that will replace the spot weld.

    or Factory SPRs

    Stud

  10. Prepare for installation.
    Note
    A red X indicates a location where a factory-installed fastener is not being replaced. Secure this location using structural adhesive only.
    or Structural Bulb Rivets, 6.5 mm
    Note
    Make sure that the rivet in the highlighted area connects all underlying panels.

    or Flow Form Rivets, S18

    Bolt

  11. Apply structural adhesive to the mating surfaces on the vehicle and the new component or components.
  12. Install the new component or components.
    Torque the bolts to 60 Nm.
    Note
    To clamp the panel while structural adhesive cures, install a nut (part number 1047337-00-A) on each of the six bolts (part number 1044009-00-A) that secure the Rear Body Panel to the Rear Frame Rail End Plate.
  13. Perform any necessary post-repair operations.
  14. Install the Seal - Trunk (Remove and Replace).
  15. Install the Striker - Trunk (Remove and Replace).
  16. Install the Bumper Beam - Rear (Remove and Replace).
  17. Install the Trim - Side - Trunk - RH (Remove and Replace).
  18. Install the Subwoofer (Remove and Replace).
  19. Install the Trim - Side - Trunk - LH (Remove and Replace).
  20. Install the Carpet - Rear Trunk (1-Piece) (Remove and Replace).
  21. Install the Panel - Aero Shield - Rear (Remove and Replace).
