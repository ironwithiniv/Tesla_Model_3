Trim - Side - Trunk - LH (Remove and Replace)

Correction code 15245002 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

Remove

  1. Remove the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  2. Inspect the LH side of the trunk carpet, under the LH 2nd row seat back.
    • If the frontmost edge of the carpet is mounted on body studs (Figure A), the LH 2nd row seat back must be removed. Skip to step 3.
    • If the frontmost edge of the carpet is not mounted to datums (Figure B), skip to step 6.
  3. Remove the LH 2nd row seat back. See Seat Back - 2nd Row - LH (Remove and Replace).
  4. Working in the 2nd row area, release the clips that attach the LH side of the trunk carpet.
  5. Lift the LH side of the trunk carpet off of the ISOFIX bars.
  6. Remove the trunk garnish. See Garnish - Trunk (Remove and Replace).
  7. Remove the trunk floor trim. See Trim - Floor - Trunk (Remove and Replace).
  8. Remove the trunk sill trim panel. See Trim - Sill - Trunk (Remove and Replace).
  9. Release the push clips that attach the LH trunk side trim to the vehicle.
  10. Disconnect the electrical connector from the puddle lamp.
  11. Remove the LH trunk side trim from the vehicle.

Install

  1. Connect the electrical connector to the puddle lamp.
  2. Install the push clips that attach the LH trunk side trim to the vehicle.
  3. Install the trunk sill trim panel. See Trim - Sill - Trunk (Remove and Replace).
  4. Install the trunk floor trim. See Trim - Floor - Trunk (Remove and Replace).
  5. Install the trunk garnish. See Garnish - Trunk (Remove and Replace).
  6. Install the LH side of the trunk carpet on the ISOFIX bars and if necessary, install the carpet clips on the body studs.
  7. If necessary, install the LH 2nd row seat back. See Seat Back - 2nd Row - LH (Remove and Replace).
  8. Install the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
