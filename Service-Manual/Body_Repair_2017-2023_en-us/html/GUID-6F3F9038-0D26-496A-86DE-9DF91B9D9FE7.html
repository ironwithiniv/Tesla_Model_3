Trim - C-Pillar - Rear - LH (Remove and Replace)

Correction code 15185102 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

Remove

  1. Remove the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  2. Remove the LH side rail trim. See Trim - Side Rail - LH (Remove and Replace).
  3. Remove the LH upper C-pillar trim. See Trim - C-Pillar - Upper - LH (Remove and Replace).
  4. Release the clip and tabs that attach the LH rear C-pillar trim to the body, and then set the trim aside.
  5. Remove and discard the bolt that attaches the lower seatbelt anchor to the vehicle.
  6. Release the bezel clips that attach the seatbelt bezel to the LH rear C-pillar trim, and then slide the bezel off of the seatbelt.
  7. Move the seatbelt through the LH rear C-pillar trim, and then remove the trim from the vehicle.
    Note
    Remove any remaining LH rear C-pillar trim clips from the LH C-pillar, and if the LH rear C-pillar trim is to be later installed, remove all clips from the trim.

Install

  1. If reusing the same LH rear C-pillar trim, install new clips onto the trim.
  2. Move the seatbelt through the LH rear C-pillar trim.
  3. Slide the seatbelt bezel onto the seat belt, and then fasten the bezel clips that attach the seatbelt bezel to the LH rear C-pillar trim.
  4. Install a new bolt to attach the lower seatbelt anchor to the vehicle.
    30 Nm (22.1 lbs-ft)
  5. Slide the rearmost tabs of the LH rear C-pillar trim into the body first, push the frontmost tabs toward the rear, and then fasten the clip and tabs that attach the LH rear C-pillar trim to the body.
  6. Install the LH upper C-pillar trim. See Trim - C-Pillar - Upper - LH (Remove and Replace).
  7. Install the LH side rail trim. See Trim - Side Rail - LH (Remove and Replace).
  8. Install the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  9. Install the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
