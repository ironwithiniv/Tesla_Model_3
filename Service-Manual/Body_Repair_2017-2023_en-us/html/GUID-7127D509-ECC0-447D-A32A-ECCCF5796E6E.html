Bracket - C-Pillar - LH (Remove and Replace)

Correction code 15186402 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

Remove

  1. Release the clips that attach the LH upper c-pillar trim to the vehicle and set it aside, but do not separate the trim from the seat belt. See Trim - C-Pillar - Upper - LH (Remove and Replace).
  2. Release the harness clip from the LH C-Pillar bracket.
  3. Release the clips (x3) that attach the LH C-Pillar bracket to the vehicle, and then carefully pull the bracket away from the vehicle.
    Note
    The bracket is still attached to the charge port manual release cable.
  4. Release the charge port manual release barrel from the LH C-Pillar bracket, and then remove the bracket from the vehicle.

Install

  1. Position the LH C-Pillar bracket on the vehicle, and then install the charge port manual release barrel on the bracket.
  2. Install the clips (x3) that attach the LH C-Pillar bracket to the vehicle.
  3. Install the harness clip on the LH C-Pillar bracket.
  4. Install the LH C-Pillar trim. See Trim - C-Pillar - Upper - LH (Remove and Replace).
