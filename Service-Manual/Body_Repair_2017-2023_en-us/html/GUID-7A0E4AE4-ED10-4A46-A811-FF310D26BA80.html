ABS Modulator (Heat Pump) (Remove and Replace)

Correction code 33100112 2.94 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See for safe and healthy working practices.

  • 2026-01-19: Corrected torque figures in Installation section.
  • 2025-04-29: Corrected torque figures for shock tower brace and cleaned up procedure.
  • 2023-12-05: Updated brake stiffness routine.

Remove

  1. Prepare the vehicle for lifting. See Raise Vehicle - 2 Post Lift.
  2. Loosen the wheel lug nuts of all wheels.
  3. Open all doors and lower the windows.
    Note
    Latch rear doors to prevent accidental closure after 12V/LV power is disconnected.
  4. Disconnect 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  5. Lock the steering wheel into position.
  6. Perform the vehicle HV disablement procedure. See Vehicle HV Disablement Procedure.
  7. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  8. Remove the 12V/LV battery. See 12V/LV Battery (Remove and Replace).
  9. Remove the bolt that attaches the steering gear assembly to the intermediate shaft assembly.
  10. Slide the electric steering column upward to remove it from the steering gear assembly.
    Note
    May need to wiggle or use dead blow to help separate.
  11. Disconnect the hydraulic control unit connector.
    Note
    Disengage the locking tab and pull up on the connector to release it.
  12. Remove and discard the nuts (x2) that attach the hydraulic control unit to the hydraulic control unit bracket.
  13. Disconnect the harness from the LH front rail bracket.
    Note
    Release lock from opposite side of bracket, then release the connector towards the front of the vehicle.
  14. Release the clips (x2) that attach the front harness and coolant hose to the brackets.
  15. Release the front harness clip from the LH frame rail.
  16. Disconnect the steering gear assembly connectors (x2).
    Note
    Two stage connectors. Move the red locking tab to the left, then depress the connector release to disconnect the connector.
  17. Disconnect the logic connectors (x2) from the steering gear.
    Note
    Do not push down on red tab. Pull the red tab to disengage the lock. Pull again to release the connector.
  18. Disconnect the HVIL connector.
    Note
    Do not push down on the red tab. Pull the red tab to disengage the lock. Pull tab again to release the connector.
  19. Release the clip that attaches the HVIL connector harness onto the body.
  20. Disconnect the LH front headlamp connector.
  21. Remove the bolts (x2) that attach the grounds G098 and G099 to the LH side of the body.
    Note
    Discard thread-cutting tri-lobular bolts after removal. If equipped with new bolts (1447438-00-A), bolts can be reused.
  22. Remove the bolts (x2) that attach the grounds G011 and G013 to the LH frame rail.
    Note
    Discard thread-cutting tri-lobular bolts after removal. If equipped with new bolts (1447438-00-A), bolts can be reused.
  23. Release the front harness clips (x3) from the LH frame rail.
  24. Remove the inner bolts that attach the shock tower brace to the RH shock tower.
  25. Remove the outer bolt that attaches the shock tower brace to the RH shock tower.
  26. Remove the inner bolts that attach the shock tower brace to the LH shock tower.
  27. Remove the outer bolt that attaches the shock tower brace to the LH shock tower.
  28. Shift shock tower brace assembly forward to gain clearance.
    Note
    Shift shock tower brace forward, but do not fully remove it.
  29. Release the master cylinder brake lines from the clip at the rear of the hydraulic control unit bracket.
  30. Remove all wheels. See Wheel Assembly (Remove and Install).
  31. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  32. Remove the bolt that attaches the FDU HV harness to the FDU.
  33. Disconnect the FDU HV harness connector.
  34. Remove the FDU HV harness connector from the FDU and move it aside.
  35. Slide the intermediate shaft towards the rear of the vehicle.
  36. Release the front harness clips (x2) from the hydraulic control unit bracket.
  37. Lower the front harness away from the hydraulic control unit.
    Note
    Lower front harness to gain enough clearance to the hydraulic control unit.
  38. Remove the lower bolt that attaches the hydraulic control unit bracket to the frame rail.
  39. Partially lower the vehicle.
  40. Position a fluid catcher underneath the vehicle.
  41. Remove the nut that attaches the RH front brake line to the hydraulic control unit.
  42. Remove the nut that attaches the LH rear brake line to the hydraulic control unit
  43. Remove the nut that attaches the RH rear brake line to the hydraulic control unit.
  44. Remove the nut that attaches the LH front brake line to the hydraulic control unit.
  45. Remove the nut that attaches the master cylinder secondary brake line to the hydraulic control unit.
  46. Remove the nut that attaches the master cylinder primary brake line to the hydraulic control unit.
  47. Move the master cylinder brake lines out of the way to allow the ABS ECU to be removed.
  48. Remove the upper bolt that attaches the hydraulic control unit bracket to the frame rail.
  49. Remove the hydraulic control unit with bracket from the vehicle.
    Note
    2x tabs. Slide the HCU toward the 12V battery area to remove it.
  50. Loosen the nuts (x2) that attach the hydraulic control unit to the hydraulic control unit bracket.
  51. Pry the hydraulic control unit from the bracket.

Install

  1. Install the hydraulic control unit onto the hydraulic control unit bracket.
  2. Install the nuts (x2) that attach the hydraulic control unit to the hydraulic control unit bracket.
    8 Nm (5.9 lbs-ft)
  3. Remove the tape that covers the hydraulic control unit brake line orifices.
  4. Position the hydraulic control unit and bracket into the vehicle for installation.
    Note
    2x tabs. Align hydraulic control unit bracket datums into body.
  5. Move the master cylinder lines into position for installation.
  6. Position the master cylinder brake lines to the clip at the rear of the hydraulic control unit bracket.
  7. Install the nut that attaches the master cylinder primary brake line to the hydraulic control unit.
    16 Nm (11.8 lbs-ft)
  8. Install the nut that attaches the master cylinder secondary brake line to the hydraulic control unit.
    16 Nm (11.8 lbs-ft)
  9. r
  10. Install the nut that attaches the LH front brake line to the hydraulic control unit.
    16 Nm (11.8 lbs-ft)
  11. Install the nut that attaches the RH rear brake line to the hydraulic control unit.
    16 Nm (11.8 lbs-ft)
  12. Install the nut that attaches the LH rear brake line to the hydraulic control unit.
    16 Nm (11.8 lbs-ft)
  13. Install the nut that attaches the RH front brake line to the hydraulic control unit.
    16 Nm (11.8 lbs-ft)
  14. Remove the fluid catcher from underneath the vehicle.
  15. Install the upper bolt that attaches the hydraulic control unit bracket to the frame rail.
    10 Nm (7.4 lbs-ft)
  16. Fully raise the vehicle.
  17. Install the lower bolt that attaches the hydraulic control unit bracket to the frame rail.
    10 Nm (7.4 lbs-ft)
  18. Raise the front harness into position for installation.
  19. Install the clips (x2) that attach the front harness to the hydraulic control unit bracket.
  20. Slide the intermediate shaft towards the front of the vehicle.
  21. Install the FDU HV harness connector to the FDU.
    Note
    Make sure that the connector is installed far enough on the FDU manifold so the manifold alignment tooth is making contact with the connector lever.
  22. Connect the FDU HV harness connector to the FDU.
    Note
    Verify lever is in the upright and open position. Carefully seat the connector and allow the lever to engage. Fully secure the lever and engage the red locking tab. Do not damage the connector or header.
  23. Install the bolt that attaches the FDU HV harness to the FDU.
    10 Nm (7.4 lbs-ft)
  24. Fully lower the vehicle.
  25. Install the nuts that attach the hydraulic control unit to the hydraulic control unit bracket.
    8 Nm (5.9 lbs-ft)
  26. Position the master cylinder brake lines to the clip at the rear of the hydraulic control unit bracket.
  27. Connect the hydraulic control unit connector.
    Note
    Gently push connector downward, then engage the locking tab.
  28. Slide the intermediate shaft assembly downward to install it to the steering gear assembly.
    Note
    Make sure that the intermediate shaft is aligned and fully seated.
  29. Install bolt that attaches the intermediate shaft assembly to the steering gear assembly.
    18 Nm (13.3 lbs-ft)
  30. Install the clips (x3) that attach the front harness to the LH frame rail.
  31. Connect the LH front headlamp connector.
  32. Install the clip that attaches the HVIL connector harness onto the body.
  33. Connect the HVIL connector.
  34. Install the bolts (x2) that attach grounds G011 and G013 to LH frame rail.
    10 Nm (7.4 lbs-ft)
    Note
    Install new bolts if thread-cutting tri-lobular bolts were installed previously. Hand-start bolts at least 6 rotations before applying torque to avoid damaging the weld nut.
  35. Install the bolts that attach grounds G098 and G099 to the body.
    10 Nm (7.4 lbs-ft)
    Note
    Install new bolts if thread-cutting tri-lobular bolts were installed previously. Hand-start bolts at least 6 rotations before applying torque to avoid damaging the weld nut.
  36. Connect the logic connectors (x2) on the steering gear.
  37. Connect the steering gear assembly connectors (x2).
  38. Install the clip that attaches the front harness bracket to the LH frame rail.
  39. Connect the harness connector located at the LH front rail bracket./
    Note
    Connect from front of bracket and lock from opposite side of bracket.
  40. Install the clips (x2) that attach the front harness and coolant hose onto the brackets.
  41. Position the shock tower brace assembly back for installation.
  42. Install the outer bolt that attaches the shock tower brace to the LH shock tower.
    62 Nm (45.7 lbs-ft)
  43. Install the inner bolts (x2) that attach the shock tower brace to the LH shock tower.
    55 Nm (40.6 lbs-ft)
  44. Tighten the outer bolt that attaches the shock tower brace to the RH shock tower.
    62 Nm (45.7 lbs-ft)
  45. Tighten the inner bolts (x2) that attach the shock tower brace to the RH shock tower.
    55 Nm (40.6 lbs-ft)
  46. Install the 12V battery into the vehicle. See 12V/LV Battery (Remove and Replace).
  47. Connect 12V/LV power. See 12V/LV Power (Disconnect and Connect).
  48. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  49. Remove the steering wheel holder.
  50. Move LH front seat forward.
  51. Connect 2nd row seat cushion harness and install 2nd row seat cushion.
  52. Move the front seats to their original positions.
  53. Reinstall the vehicle software. See Software Reinstall - Touchscreen.
  54. Bleed the brakes. See Brake Fluid Bleed/Flush.
  55. Install the rear apron.
  56. Close the hood.
  57. Install the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  58. Install all wheels. See Wheel Assembly (Remove and Install).
  59. Perform a test drive.
    Note
    Make sure that brake pedal feel and performance are adequate. Add correction code 00040100 as a separate activity to the service visit as needed.
