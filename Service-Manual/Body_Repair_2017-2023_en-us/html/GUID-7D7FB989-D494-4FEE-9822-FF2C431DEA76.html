Parcel Shelf Crossmember Assembly (Without Center Trough)

Correction code: 10101922102 NOTE: Unless explicitly stated in the procedure, the above correction code includes all Collision Repair and Service repair work required to perform this procedure, including the linked Collision Repair procedures and linked Service procedures. Do not stack Collision Repair correction codes unless explicitly told to do so. Depending on the damage to the vehicle, additional repairs may be required.

Parent topic: Rear Quarter Inner Panels

Repair Information

  • Review all collision repair general practices and safety documentation and wear the appropriate PPE (Personal Protective Equipment) before beginning this procedure.
  • This procedure can be completed without using a frame bench.

Parts List

Quantity Description Image / Notes
1 M3 ASY, PARCEL SHELF CROSSMEMBER (Parcel Shelf Crossmember Assembly)
36 Structural Bulb Rivet, 6.5 mm
1 Countersunk Rivet, 4.8 mm Short
4 Flow Form Rivet S18

When ordering parts, refer to the Parts Catalog and enter the VIN of the vehicle being repaired to find the correct parts (and the part numbers) for the vehicle. Alternatively, use the search function in the Parts Catalog to find a specific part for the vehicle.

Repair Procedure

  1. Remove the Seat Back - 2nd Row - RH (Remove and Replace).
  2. Remove the Seat Back - 2nd Row - LH (Remove and Replace).
  3. Remove the Carpet - Rear Trunk (1-Piece) (Remove and Replace).
  4. Remove the Trim - Package Tray (Remove and Replace).
  5. Remove the Trim - Side - Trunk - RH (Remove and Replace).
  6. Remove the Trim - Side - Trunk - LH (Remove and Replace).
  7. Remove the Power Trunk (Remove and Install).
  8. Remove the Trim - Package Tray (Remove and Replace).
  9. Remove the Glass - Backlight (Heat Pump) (Remove and Install).
  10. Remove the Rear Center Trough.
  11. Remove the original component.

    Factory Spot Weld

    Factory Spot Weld (2 layers)

  12. Prepare for installation.

    Structural Bulb Rivet, 6.5 mm

    Flow Form Rivet S18

    Countersunk Rivet, 4.8 mm Short

    Note
    The countersunk rivet is for the LH side only to avoid interference with the TPMS module.
  13. Apply structural adhesive to the mating surfaces on the vehicle and the new component or components.
  14. Install the new component or components.
  15. Install the Rear Center Trough.
  16. Perform any necessary post-repair operations.
  17. Install the Glass - Backlight (Heat Pump) (Remove and Install).
  18. Install the Trim - Package Tray (Remove and Replace).
  19. Install the Power Trunk (Remove and Install).
  20. Install the Trim - Side - Trunk - LH (Remove and Replace).
  21. Install the Trim - Side - Trunk - RH (Remove and Replace).
  22. Install the Trim - Package Tray (Remove and Replace).
  23. Install the Carpet - Rear Trunk (1-Piece) (Remove and Replace).
  24. Install the Seat Back - 2nd Row - LH (Remove and Replace).
  25. Install the Seat Back - 2nd Row - RH (Remove and Replace).
