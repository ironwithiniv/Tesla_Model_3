HVAC Assembly (Heat Pump) (Remove and Replace)

Correction code 18101012 3.84 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

  • 2026-10-27: Added steps to run HVAC Case Test routine and reset cabin air filter maintenance record.
  • 2026-03-19: Added steps to disconnect/connect LV power.
  • 2025-10-24: Updated the A/C line HVAC side torque from 22Nm to 28Nm.
  • 2023-08-23: Updated EPB Service Mode reference.
  • 2023-04-04: Updated A/C oil type to be used with reference to Fluids and Capacities for A/C oil specifications.
  • 2024-04-29: Updated the way of performing the routines from using Toolbox to using the touchscreen.
Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
Note
This procedure requires the A/C Refrigerant (Recovery and Recharge) procedure to be performed. If not already automatically added to the Service Visit, add correction code 18200102 as a separate correction within the same activity to the Service Visit.

Remove

  1. Set up the A/C machine.
  2. Place the vehicle on the 2-post lift.
    Tip
    Ensure the vehicle is not charging.
  3. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  4. Remove the fresh intake duct. See Duct - Fresh Intake (Remove and Replace).
  5. Remove the wiper arms. See Wiper Arms (Remove and Replace).
  6. Remove the wiper module. See Wiper Module (Remove and Replace).
  7. Release the harness clip from the LH side of the washer tank inlet.
  8. Remove the LH front wheel. See Wheel Assembly (Remove and Install).
  9. Partially remove LH front wheel liner
    Note
    6x clips, 1x bolt, 10mm, 5 Nm, Newer vehicles may be equipped with 2x push clips securing lower portion of liner to body
  10. Remove the lower bolt that attaches the washer tank to vehicle.
    Note
    1x bolt, 10mm, 3 Nm
  11. Partially install LH front wheel liner
    Note
    2x clips, Partially install LH front wheel liner, Wheel liner will be removed again later, Install 2 clips to secure LH front wheel liner
  12. Install the LH front wheel. See Wheel Assembly (Remove and Install).
  13. Lower vehicle until tires are touching the ground
    Note
    Raise lift off locks, then hold lock release lever to keep locks free while vehicle is lowered.
  14. Remove the washer reservoir. See Reservoir - Windshield Washer (Remove and Replace).
  15. Remove vehicle from lift
    Note
    Recommend assistance to push the vehicle backward, Note this vehicle can only be safely pushed for a very short distance and at very slow speed
  16. Enable the EPB Service Mode. See Parking Brake - Caliper - Rear - LH (Release)
  17. Move the vehicle to a non-lift Working Position.
  18. Open all doors and lower all windows.
  19. On the touchscreen, tap Controls > Service > Towing to exit the tow mode.
  20. Place the vehicle in Service Mode by using the touchscreen. See Service Mode.
  21. Unlock the vehicle gateway. See Gateway (Unlock).
  22. On the touchscreen, tap the Service Mode "wrench" (at the bottom of the touchscreen UI), and then tap Thermal > Refrigerant System > Start Thermal Fill/Drain (Refrigerant only), tap Run, and allow the routine to complete.
  23. Disconnect LV power. See 12V/LV Power (Disconnect and Connect).
  24. Remove the center console. See:
