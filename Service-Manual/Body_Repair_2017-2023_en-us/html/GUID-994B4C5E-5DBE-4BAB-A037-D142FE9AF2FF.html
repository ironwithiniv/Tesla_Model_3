Connectivity Board - Car Computer (HW3) (Remove and Replace)

Correction code 21152902 1.08 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
  1. Open LH front door
  2. Lower LH front window
  3. Open RH front door
  4. Lower RH front window
  5. Move RH front seat backward
  6. Open hood
  7. Remove rear apron
    Note
    14x clips
  8. Power off vehicle from center display
    Note
    Via Controls > Safety & Security > Vehicle Power > Power Off
  9. Disconnect 12V negative terminal and first responders loop
    Note
    1x nut, 10mm, 6 Nm, 1x connector, Ensure vehicle is in park, climate control system is off, and vehicle is not charging before disconnecting 12V, Negative terminal should be disconnected before FRL, Allow 2 minutes for all electrical circuits to fully discharge
  10. Remove fresh air intake duct
    Note
    1x bolt, 10mm, 4 Nm, 2x clips, 1x pin, Remove bolt, Gently pry pin out from thermal beam, then remove from bulkhead studs
  11. Place absorbent material below car computer coolant hose connection points to collect any spilled coolant
  12. Release coolant hoses from car computer
    Note
    2x spring clips
  13. Install coolant plugs into coolant outlets of car computer that is being removed from vehicle
  14. Install coolant plugs in hoses
    Note
    2x plugs, Do not need to engage spring clips
  15. Remove nuts securing car computer to bulkhead
    Note
    5x nyloc nuts, 13mm, 7.1 Nm, Discard nuts after removal
  16. Remove LH IP end cap
    Note
    3x clips
  17. Remove LH air wave bezel cap from main decor assembly
    Note
    2x clips
  18. Remove RH mid A-pillar assembly
    Note
    1x clip, 1x tab, Release the upper clip then pull mid A-pillar upward to remove
  19. Remove RH air wave bezel cap from main decor assembly
    Note
    2x clips
  20. Remove main decor assembly
    Note
    15x clips, 1x center clip, Replace securing clips as needed
  21. Remove clips securing RH footwell assembly
    Note
    4x push clips
  22. Disconnect RH footwell assembly connectors and remove from vehicle
    Note
    2x connectors
  23. Remove fasteners securing passenger knee air bag to vehicle
    Note
    2x screws, T20, 2 Nm, 1x push clip, 4x patch bolts, E10, 8 Nm, Discard patch bolts after removal, Support the knee air bag while lowering, The connector / harness length is very short
  24. Remove the passenger knee air bag from vehicle
    Note
    1x connector, Release locking tab
  25. Disconnect glove box USB cable from car computer
    Note
    1x connector, Depress latch on top of USB cable to release internal latches, then release from car computer
  26. Remove screws securing glove box assembly to IP carrier
    Note
    6x screws, T20, 2.3 Nm
  27. Remove the glove box from IP carrier
    Note
    3x clips
  28. Disconnect glove box assembly connectors
    Note
    3x connectors
  29. Remove the passenger footwell air duct
    Note
    1x push clip
  30. Remove the RH IP air wave duct
    Note
    2x push clips
  31. Release ground strap from car computer
    Note
    1x bolt, T25, 1x nut, 8mm, 3.5 Nm, Nut located on backside, Discard nut after removal
  32. Disconnect connectors on front side of car computer
    Note
    3x connectors, If equipped, release locking tab, then remove connector body
  33. Release harness guide clip
    Note
    1x clip, Pinch release tabs with needle nose pliers
  34. Slide car computer inward to allow access to connectors and harness clips
    Note
    Be careful not to strain harness and connectors
  35. Remove car computer shroud
    Note
    4x clips
  36. Release harness clips from top of car computer
    Note
    2x clips
  37. Remove fasteners securing car computer cover to car computer body
    Note
    3x bolts, T25, 3x nuts, 8mm, 3.5 Nm, Discard nyloc nuts after removal
  38. Remove the top cover fasteners
    Note
    4x screws, T10, 1.4 Nm, Discard after removal
  39. Remove the connectivity board mounting screws
    Note
    5x screws, T10, 0.7 Nm, Discard after removal
  40. Slide the connectivity board down to separate connector and remove
    Note
    1x connector
  41. Slide the connectivity board in to the PCB connector
    Note
    1x connector
  42. Install mounting screws to secure connectivity board
    Note
    5x screws, T10, 0.7 Nm, Install new fasteners
  43. Slide top cover onto car computer assembly
    Note
    Top cover must be underneath top gasket seal
  44. Install top cover mounting screws
    Note
    4x screws, T10, 1.4 Nm, Install new screws
  45. Install fasteners securing car computer covers to car computer body bracket
    Note
    3x bolts, T25, 3x nuts, 8mm, 3.5 Nm, Install new nyloc nuts
  46. Secure harness to top of car computer
    Note
    2x clips
  47. Install car computer shroud onto car computer
    Note
    4x clips
  48. Slide car computer into position on bulkhead
    Note
    Use caution during installation due to minimal clearance between shroud and passenger airbag connectors and harness
  49. Secure harness guide clip
    Note
    1x clip
  50. Connect connectors on the front side of car computer
    Note
    3x connectors, If equipped, fully seat connector, then engage locking tab
  51. Secure ground cable to car computer
    Note
    1x bolt, T25, 1x nut, 8mm, 3.5 Nm, Install new nyloc nut
  52. Install nuts securing car computer to the bulkhead
    Note
    5x nyloc nuts, 13mm, 7.1 Nm, Install new nyloc nuts
  53. Verify there are no coolant plugs in the car computer coolant necks
  54. Remove plugs from hoses
    Note
    2x plugs, Engage spring clips after removal
  55. Secure hoses to car computer coolant inlet/outlet
    Note
    2x spring clips, Perform push-pull-push test to ensure the hoses are fully seated
  56. Remove coolant bottle cap
  57. Fill coolant bottle to base of neck as indicated
  58. Remove absorbent material from below car computer coolant hose connection points
  59. Install the RH IP air wave duct
    Note
    2x push clips
  60. Install the passenger footwell air duct
    Note
    1x push clip
  61. Connect glove box assembly connectors
    Note
    3x connectors, New puddle lamp harness routing prevent blocking movement of pawls
  62. Install the glove box into IP carrier
    Note
    3x clips
  63. Install screws securing glove box assembly to IP carrier
    Note
    6x screws, T20, 2.3 Nm
  64. Connect glove box USB cable to car computer
    Note
    1x connector
  65. Install the passenger knee air bag into vehicle
    Note
    1x connector, Engage locking tab, Use caution not to damage the connector/harness, Support the knee air bag while connecting the connector
  66. Install fasteners securing passenger knee air bag to vehicle
    Note
    4x patch bolts, E10, 8 Nm, 2x screws, T20, 2 Nm, 1x push clip, Install new patch bolts
  67. Connect the RH footwell assembly connectors
    Note
    2x connectors
  68. Install clips securing RH footwell assembly
    Note
    4x push clips
  69. Install main decor assembly
    Note
    15x clips, 1x center clip
  70. Install LH air wave bezel cap to main decor assembly
    Note
    2x clips
  71. Install LH IP end cap
    Note
    3x clips
  72. Install RH air wave bezel cap to main decor assembly
    Note
    2x clips
  73. Install RH IP end cap
    Note
    3x clips
  74. Connect first responder loop and 12V negative terminal
    Note
    1x nut, 10mm, 6 Nm, 1x connector, Engage locking tab, Connect FRL first before connecting 12V to avoid damage to car computer
  75. Connect to vehicle using Toolbox 3.0
  76. Select ‘TEST_VCFRONT_X_THERMAL-COOLANT-AIR-PURGEvia Service Mode:
    • Thermal ➜ Actions ➜ Coolant Purge Stop or Coolant Purge Start
    • Thermal ➜ Coolant System ➜ Coolant Purge Start
    via Service Mode Plus:
    • Drive Inverter ➜ Front Drive Inverter Replacement ➜ Coolant Air Purge
    • Drive Inverter ➜ Rear Drive Inverter Replacement ➜ Coolant Air Purge
    • Drive Inverter ➜ Rear Left Drive Inverter Replacement ➜ Coolant Air Purge
    • Drive Inverter ➜ Rear Right Drive Inverter Replacement ➜ Coolant Air Purge
    • Drive Unit ➜ Front Drive Unit Replacement ➜ Coolant Air Purge
    • Drive Unit ➜ Rear Drive Unit Replacement ➜ Coolant Air Purge
    via Toolbox:(link)     ’, click ‘Run’, and allow routine to complete
    Note
    Make sure vehicle is not in drive state, Plan is still running despite the stop message, Coolant pumps will be audible, Test lasts approximately 10 mins, Idle speed = ~1500 RPM, Test will vary speeds from 3500-6500 RPM and actuate valve between SERIES and PARALLEL, Putting vehicle into drive state will stop this routine, If speeds hover at 7000 RPM, that means the pumps are air locked, perform vacuum fill again, Continue to add coolant and purge until the coolant level reaches between the NOM and MAX Lines on the bottle, Select ‘X’ at top right of window to close once complete
  77. Install fresh air intake duct
    Note
    1x bolt, 10mm bolt, 4 Nm, 2x clips, 1x pin, Set clips on bulkhead studs, Secure to thermal bar
  78. Install rear apron
    Note
    14x clips, Hold rear wall of frunk to keep from flexing while engaging front clips
  79. Close hood
  80. Move RH front seat to original position
  81. Raise RH front window
  82. Close RH front door
  83. Raise LH front window
  84. Close LH front door
