Booster - Brake - Electromechanical (Heat Pump) (LHD) (Remove and Replace)

Correction code 33201202 1.95 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

Equipment:
  • 1079041-00-A Flare nut crowfoot set
  • 1134520-00-A Kit, EPB Release, Handheld
  • 1129348-00-A XP-10 Power Supply, XP-10

Remove

  1. CAUTION

    Brake fluid dissolves paint. Have clean towels and plenty of water standing by to wash spilled brake fluid off painted surfaces.

    Note

    Dispose of used brake fluid in a manner consistent with local environmental codes.

  2. Open all four doors.
  3. Lower all four windows.
  4. Move LH front seat backward.
  5. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  6. Remove the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  7. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  8. Remove the LH and RH wiper arms. See Wiper Arms (Remove and Replace).
  9. Remove the LH and RH shock tower covers. See Cover - Shock Tower - LH (Remove and Replace).
  10. Remove the cowl screen panel. See Panel - Cowl Screen (Remove and Replace).
  11. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  12. Remove the 12V auxiliary battery. See 12V/LV Battery (Remove and Replace).
  13. Remove the front body controller module. See Module - Body Controller - Front (Heat Pump) (Remove and Replace)
  14. Remove the wiper motor. See Wiper Module (Remove and Replace).
  15. Disconnect the electrical harness from the brake fluid reservoir connector.
  16. Disconnect the harness connectors (x2) from the brake booster assembly.
  17. Place absorbent material under the reservoir and booster.
  18. Using a brake fluid syringe, remove fluid from the reservoir.
  19. Loosen the nuts that attach the brake lines to the booster, and then slide the nuts back on the brake lines.
    16 Nm (11.8 lbs-ft)
  20. Remove the driver footwell cover. See Cover - Footwell - Driver (Remove and Replace).
  21. Remove the driver knee airbag. See Airbag - Knee - Driver (Remove and Install).
  22. Remove the brake switch. See Switch - Brake Light (Remove and Replace).
    CAUTION
    Replace the brake switch if damaged during removal.
  23. Remove the cotter clip from the clevis pin on the brake pedal assembly.
  24. Remove the clevis pin from the brake pedal assembly.
  25. Remove and discard the nuts (x4) that attach the brake booster to the bulkhead.
    16.5 Nm (12.2 lbs-ft)
  26. Remove the LH bolt securing front harness bracket from the vehicle.
    9 Nm (6.6 lbs-ft)
    Note
    Make sure the harness bracket is able to move in a wide range, and the bracket and ibooster are not obstructed.
  27. Remove the brake booster assembly from the vehicle.
    CAUTION
    Handle the electromechanical brake booster only by the main housing. Do not use the pushrod, the reservoir, or the connectors to lift or manipulate the electromechanical brake booster.

Install

  1. Position the brake booster on the vehicle, and then install the new nuts (x4) that attach the booster to the bulkhead.
    16.5 Nm (12.2 lbs-ft)
    CAUTION
    Handle the electromechanical brake booster only by the main housing. Do not use the pushrod, the reservoir, or the connectors to lift or manipulate the electromechanical brake booster.
  2. Align the brake pedal with the brake booster rod, and then install the clevis pin to the brake pedal assembly.
  3. Install the cotter clip to the clevis pin on the brake pedal assembly.
  4. Install the brake switch. See Switch - Brake Light (Remove and Replace).
  5. Install the driver knee airbag. See Airbag - Knee - Driver (Remove and Install).
  6. Install the driver footwell cover. See Cover - Footwell - Driver (Remove and Replace).
  7. Install the nuts that attach the brake lines to the booster.
    16 Nm (11.8 lbs-ft)
  8. Clean the area around the brake fluid reservioir and then remove the cap.
  9. Fill the brake fluid reservoir to the "MAX" level.
    CAUTION
    Make sure not to get any brake fluid on any painted surface. Clean residual brake fluid with a shop towel.
  10. Remove the absorbent material from underneath the brake booster and reservoir area.
  11. Connect the electrical harness connectors (x2) to the electromechanical brake booster connector.
  12. Connect the electrical harness to the brake fluid reservoir connector.
  13. Install the LH bolt securing the front harness bracket of the vehicle.
    9 Nm (6.6 lbs-ft)
  14. Install the wiper motor. See Wiper Module (Remove and Replace).
  15. Install the front body controller module. See Module - Body Controller - Front (Heat Pump) (Remove and Replace).
  16. Install the 12V Battery. See 12V/LV Battery (Remove and Replace).
  17. Install the cowl screen panel. See Panel - Cowl Screen (Remove and Replace).
  18. Install the LH and RH shock tower covers. See Cover - Shock Tower - LH (Remove and Replace).
  19. Install the LH and RH wiper arms. See Wiper Arms (Remove and Replace).
  20. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  21. Install the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  22. Reconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  23. Reinstall the vehicle firmware. See Software Reinstall - Touchscreen.
  24. Bleed the braking system. See Brake Fluid Bleed/Flush.
  25. Install the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  26. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  27. Open all four doors.
  28. Move LH front seat to original position.
  29. Raise all windows.
  30. Remove lift arms from below vehicle.
  31. Close all four doors.
  32. Perform a road test using a series of panic stops to make sure there is proper pedal feel and brake performance.
