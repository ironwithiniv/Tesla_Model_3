Retractor - Seatbelt - 1st Row - LH (Remove and Replace)

Correction code 20054102 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

Equipment:
  • 1133787-00-A Key, Seat Belt Release, Model 3
  • 2026-10-27: Added SRS safety note. Added note to refer to Collision Repair Manual for list of components to inspect or replace after a collision.
CAUTION
Supplemental Restraint System (SRS) components can be hazardous if not serviced and handled correctly. See
CAUTION
In the event of an airbag or seatbelt pretensioner deployment, certain components must be replaced, and other components must be inspected for damage. Refer to the Collision Repair Manual for a specific list of items that must be inspected and replaced.

Remove

  1. Remove the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
  2. Remove the LH middle A-pillar trim. See Trim - A-Pillar - Middle - LH (Remove and Replace).
  3. Remove the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  4. Insert the seat belt release key (1133787-00-A) into the bottom of the seatbelt pretensioner coupling to release the seatbelt from the pretensioner.
  5. Remove the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  6. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  7. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  8. Remove the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  9. Remove the LH rear sill panel trim. See Trim - Sill Panel - Rear - LH (Remove and Replace).
  10. Release the clips that attach the LH upper B-pillar trim to the vehicle.
    Tip
    Release the clips at the bottom of the LH upper B-pillar trim first, and then release the clips at the top of the trim.
  11. Slide the seatbelt out through the hole in the LH upper B-pillar trim, and then set the trim aside.
  12. Remove the LH lower B-pillar trim. SeeTrim - B-Pillar - Lower - LH (Remove and Replace).
  13. Remove and discard the bolts that attach the seat belt webbing guide to the B-pillar, and then remove the guide from the B-pillar.
    Tip
    Use of the following tool(s) is recommended:
    • 8 mm socket
  14. Remove and discard the patchbolt that attaches the upper D-ring to the top loop.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket
  15. Remove and discard the patchbolt that attaches the seat belt retractor to the base of the B-pillar.
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm 12-point deep socket
  16. Disconnect the electrical harness from the seat belt retractor connectors (x2).
    Note
    For better access to the connectors, the retractor can be removed from the B-pillar first.
  17. Remove the LH front seatbelt from the vehicle.

Install

  1. Install the LH front seatbelt into the vehicle.
  2. Connect the electrical harness to the seat belt retractor connectors (x2).
  3. Install a new patchbolt to attach the seat belt retractor to the base of the B-pillar.
    40 Nm (29.5 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 13 mm 12-point deep socket
  4. Install a new patchbolt to attach the upper D-ring to the top loop.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T50 socket
  5. Install the seat belt webbing guide to the B-pillar, and then install new bolts that attach the guide to the B-pillar.
    Tip
    Use of the following tool(s) is recommended:
    • 8 mm socket
  6. Slide the seatbelt in through the hole in the LH upper B-pillar trim.
  7. Install the LH lower B-pillar trim. SeeTrim - B-Pillar - Lower - LH (Remove and Replace).
  8. Fasten the clips that attach the LH upper B-pillar trim to the vehicle.
    Tip
    Fasten the clips at the top of the LH upper B-pillar trim first, and then fasten the clips at the bottom of the trim.
  9. Install the LH rear sill panel trim. See Trim - Sill Panel - Rear - LH (Remove and Replace).
  10. Install the LH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  11. Connect 12V power. See 12V/LV Power (Disconnect and Connect).
  12. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  13. Install the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  14. Install the LH front seatbelt pretensioner coupling onto the LH front seat pretensioner.
    Note
    Perform a pull-push-pull test to verify the pretensioner and coupling are fully engaged.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  15. Install the LH lower A-pillar trim. See Trim - A-Pillar - Lower - LH (Remove and Replace).
  16. Install the LH middle A-pillar trim. See Trim - A-Pillar - Middle - LH (Remove and Replace).
  17. Install the LH instrument panel end cap. See End Cap - Instrument Panel - LH (Remove and Replace).
