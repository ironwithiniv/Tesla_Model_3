To determine which battery your vehicle uses, touch Controls > Software > Additional Vehicle Information.

Remove Lead Acid Battery

Note
If replacing a Clarios (Varta) 12V battery with an AtlasBX 12V battery, or vice-versa, make sure the vehicle is running software version 2023.32 or newer. Update the vehicle software if necessary; see Software Update.
  1. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  2. Remove the cabin intake duct. See Duct - Upper - Cabin Intake (Remove and Replace).
  3. Disconnect 12V power. See 12V/LV Power (Disconnect and Connect).
  4. Remove the cover for the 12V positive terminal.
  5. Loosen the nut that attaches the positive lead to the battery, and then remove the lead from the battery.
    6 Nm (4.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  6. Remove the 12V battery strap. See Strap - 12V Battery (Remove and Replace).
  7. Disconnect the hose from the LH side of the battery, and then remove the battery from the vehicle.
  8. Write the last 6 digits of the vehicle VIN clearly onto the removed battery so that it can be identified if later needed.

Remove Li-Ion Battery

Note
The Li-Ion LV battery may not need to be replaced. Attempt to recover the LV battery first before determining that the LV battery needs replacement. Refer to Toolbox article 6249900 for more information.
  1. Open the LH front door and fully lower the LH front window.
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Disconnect LV power. See 12V/LV Power (Disconnect and Connect).
  4. Wait 2 minutes for the electrical system to fully discharge.
  5. Release positive jump post.
  6. Remove LV battery cable stand off.
  7. Remove the bolts (x3) that attach the LV battery to the vehicle.
  8. Remove the LV battery from the vehicle.

Install Lead Acid Battery

Installation procedure is the reverse of removal, except for the following:

CAUTION
Before installing the new 12V battery, make sure that the new battery's Open Circuit Voltage (OCV) is above 12.6V. If the OCV is between 12.4V and 12.6V, recharge the new battery. Any battery below 12.4V must be discarded.
  • If replacing a Clarios (Varta) 12V battery with an AtlasBX 12V battery, or vice-versa, update the vehicle configuration.
    Note
    The configuration update can only be performed on vehicles with vehicle software version 2023.32 and newer.
    Note
    If a configuration update is required, separately add Correction Code 91022407 (Vehicle Configuration Update) to the Service Visit.
    1. Connect a laptop with Toolbox to the vehicle. See Toolbox (Connect and Disconnect).
    2. Select Actions, search for "TEST-SELF_VCFRONT_X_FIVE-WAY-VALVE" and run the routine.
    3. In the Service Mode menu, go to Low Voltage > Power Distribution > Change Battery Type.
    4. Select the type of battery that was installed, and then touch Change Battery Type to Selected.
    5. Read the prompt, touch Run, and allow the routine to complete.
    6. Disconnect Toolbox from the vehicle. See Toolbox (Connect and Disconnect).
    7. Exit Service Mode Plus.

Install Li-Ion Battery

  1. Install the bolts (x3) that attach the LV battery to the vehicle.
    6 Nm (4.4 lbs-ft)
  2. Install positive jump post.
    5 Nm (3.7 lbs-ft)
  3. Install LV battery cable stand off.
  4. Connect LV power. See 12V/LV Power (Disconnect and Connect).
    Note
    If the vehicle does not power up after the LV battery is connected, power up the vehicle with an approved external power supply.
  5. Enter Service Mode. See Service Mode.
  6. Unlock vehicle gateway. See Gateway (Unlock).
  7. On the vehicle touchscreen, touch Low Voltage > Power Distribution > Battery Icon > Learn New Battery, and click Run to start the routine.
    CAUTION
    Vehicle software must be FW 2023.44 or later version.
    Note
    Once the routine is completed, the Mosfet and ECPA will be Closed.
  8. Reinstall the vehicle firmware. See Software Reinstall - Touchscreen.
  9. Exit Service Mode.
  10. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  11. Raise the LH front window and close the LH front door.
