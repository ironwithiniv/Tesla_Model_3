Steering Wheel (Remove and Install)

Correction code 32051801 0.24 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

Torque Specifications

Table 1. Torque Specifications: Steering Wheel (Remove and Install)
Description Torque Value Recommended Tools Reuse/Replace Notes
Steering wheel to steering column bolt
80 Nm (59.0 lbs-ft)
  • 10 mm hex
Replace PN - 1036655-00-A

Remove

  1. Set the vehicle's front wheels straight and the steering wheel centered.
  2. Remove the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
  3. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  4. Disconnect LV power. See 12V/LV Power (Disconnect and Connect).
  5. Remove the driver airbag. See Airbag - Driver (Remove and Replace).
  6. Disconnect the steering wheel electrical wiring harness connector.
  7. Remove and discard the bolt that attaches the steering wheel to the steering column.
    80 Nm (59.0 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm hex
  8. Remove the steering wheel from the steering column.

Install

  1. Position the steering wheel into the vehicle, and then install a new bolt that attaches the steering wheel to the steering column.
    80 Nm (59.0 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm hex
  2. Connect the steering wheel electrical wiring harness connector.
  3. Install the driver airbag. See Airbag - Driver (Remove and Replace).
  4. Reconnect LV power. See 12V/LV Power (Disconnect and Connect).
  5. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  6. Install the 2nd row lower seat cushion. See Seat Cushion - Lower - 2nd Row (Remove and Replace).
