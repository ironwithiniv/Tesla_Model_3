Front Carpet - Trunk (2-Piece) (Remove and Replace)

Correction code 15302602 15302601 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See for safe and healthy working practices.

Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
  • 2025-12-01: Released new procedure.
  1. Open all four doors
    Note
    If vehicle is being powered down, Latch rear doors to prevent accidental closure
  2. Lower all four windows
  3. Move LH front seat forward
  4. Move RH front seat forward
  5. Remove 2nd row seat cushion
    Note
    2x tabs, 2x connectors, Slide locking tabs to left of vehicle while lifting up seat bench. Newer models have connectors on both sides of bench, Older models have 2x connectors on one side of bench
  6. Open liftgate from exterior switch
  7. Remove load floor
    Note
    Use pull tab located at rear edge of panel
  8. Remove trunk sill trim assembly
    Note
    4x clips, 1x location pin, Pull corner upward release clip on the end the away from body for remaining clips
  9. Remove clips securing rear trunk carpet
    Note
    2x push clips
  10. Remove rear trunk carpet from vehicle
    Note
    4x velcro strips
  11. Remove LH rear seat belt buckle
    Note
    1x patch bolt, 15mm, 40 Nm, If the bolt is difficult to remove, Use an inductive heating tool to melt the adhesive patch material, Position the inductive heating tool coil around the bolt, then heat the bolt for 20 seconds, Allow the bolt to cool for 2 minutes, Discard after removal
  12. Fold 60 seat in down position
    Note
    Protect the seat cushion
  13. Remove LH side bolster
    Note
    1x clip, 2x location pins, Pull outward then slightly upward to remove
  14. Remove and discard bolster plastic bracket from RH side
    Note
    2x clips, If necessary, depress the clips from behind, this bracket may come out with bolster. Discard after removal
  15. Fold 60 seat into vertical position
    Note
    Remove seat protection
  16. Disconnect 60 seat back seat heater harness
    Note
    1x connector
  17. Remove nuts securing 60 seat back hinge bracket to body
    Note
    2x nuts, 13mm, 18 Nm
  18. Remove 60 seat back by lifting up on LH side and pulling inner pivot out of 40 seat back and set onto padded work surface
  19. Fold 40 seat in down position
    Note
    Protect the seat cushion
  20. Remove RH side bolster
    Note
    1x clip, 1 tab, Pull outward then slightly upward to remove
  21. Remove and discard bolster plastic bracket from LH side
    Note
    2x clips, If necessary, depress the clips from behind, This bracket may come out with bolster, Discard after removal
  22. Disconnect 40 seat back seat heater harness
    Note
    1x connector
  23. Remove nuts securing 40 seat back hinge bracket to body
    Note
    2x nuts, 13mm, 18 Nm
  24. Remove 40 seat back from vehicle
    Note
    Lift bracket from studs and slide outward
  25. Remove front trunk carpet from vehicle
    Note
    2x clips, Lift trunk carpet off of isofix bars
  26. Install front trunk carpet into vehicle
    Note
    2x clips, Align the trunk carpet to isofix bars
  27. Install 60 seat back to vehicle
    Note
    Align center and outer pivot locations
  28. Install nuts securing 60 seat back hinge bracket to body
    Note
    2x nuts, 13mm, 18 Nm
  29. Connect 60 seat back seat heater harness
    Note
    1x connector
  30. Install bolt securing LH seat belt catch and center seat belt to vehicle
    Note
    1x patch bolt, 15mm, 40 Nm, Install new patch bolt, Position center seat belt under buckle, Make sure the guide pin is aligned
  31. Fold 60 seat in down position
    Note
    Protect the seat cushion if necessary
  32. Install bolster plastic bracket to LH side bolster
    Note
    2x tabs, Install new bolster bracket
  33. Install LH side bolster
    Note
    1x clip, 2x location pins, Align the bottom tab then push inward to install
  34. Fold 60 seat into vertical position
    Note
    Remove seat cushion protection, Be careful not to pinch the seat belt
  35. Install 40 seat back to vehicle
    Note
    Align center and outer pivot locations
  36. Install nuts securing 40 seat back hinge bracket to body
    Note
    2x nuts, 13mm, 18 Nm
  37. Connect 40 seat back seat heater harness
    Note
    1x connector
  38. Fold the 40 seat in down position
    Note
    Protect the seat cushion if necessary
  39. Install bolster plastic bracket to RH side bolster
    Note
    2x tabs, Install new bolster bracket
  40. Install RH side bolster
    Note
    1x clip, 1x tab, Align the bottom tab then push inward to install
  41. Fold seat into vertical position
    Note
    Remove seat cushion protection
  42. Install rear trunk carpet into vehicle
    Note
    4x velcro strips, Fully seat carpet at velcro strips
  43. Install clips securing trunk carpet
    Note
    2x push clips
  44. Install trunk sill trim assembly
    Note
    4x clips, 1x location pin, Align the latch with center slot then 2 locator to their slot and then press to secure the clips, Adjust the seal to overlap the trim
  45. Install load floor
  46. Close trunk
  47. Connect 2nd row seat cushion harness and install 2nd row seat cushion
    Note
    2x connectors, 2x clips, Insert the seat belt buckles through the holes, Slide rear cushion inward then align front guide tabs to locking tabs, Make sure cushion is fully seated with push pull test near clips
  48. Move RH front seat to original position
  49. Move LH front seat to original position
  50. Raise all four windows
  51. Close all four doors
