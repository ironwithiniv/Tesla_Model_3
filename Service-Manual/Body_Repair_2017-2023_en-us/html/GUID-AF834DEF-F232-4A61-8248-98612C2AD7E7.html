Service Mode Plus

Correction code 00050000 0.05 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

Procedure

  1. Connect a laptop with Toolbox 3 to the vehicle. See Toolbox (Connect and Disconnect).
    Note
    Upon successful connection, Service Mode Plus will be enabled, and the "Service Mode Plus" watermark will appear on the touchscreen.
  2. When finished performing the tasks that required Service Mode Plus, touch the Exit Service Mode button at the top of the Service Mode menu.
    Note
    If the Exit Service Mode button is not visible, touch and hold the Tesla "T" at the top of the touchscreen, and then type "service" into the prompt.
  3. Disconnect the laptop from the vehicle. See Toolbox (Connect and Disconnect).
