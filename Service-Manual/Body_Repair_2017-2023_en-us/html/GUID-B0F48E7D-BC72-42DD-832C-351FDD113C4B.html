Cowl Lower

Correction code: 10101014702 NOTE: Unless explicitly stated in the procedure, the above correction code includes all Collision Repair and Service repair work required to perform this procedure, including the linked Collision Repair procedures and linked Service procedures. Do not stack Collision Repair correction codes unless explicitly told to do so. Depending on the damage to the vehicle, additional repairs may be required.

Parent topic: Front Inner Panels

Repair Information

  • Review all collision repair general practices and safety documentation and wear the appropriate PPE (Personal Protective Equipment) before beginning this procedure.
  • This procedure can be completed without using a frame bench.

Repair Procedure

  1. Remove the Module - Body Controller - RH (Remove and Replace).
  2. Remove the IP Carrier (Remove and Install).
  3. Remove the Brace - Shock Tower (Non-Heat Pump) (Remove and Replace).
  4. Remove the Hood (Remove and Install).
  5. Remove the Windshield (Reuse Humidity and Temperature Sensor) (Remove and Replace).
  6. Remove the A/C Compressor and Supermanifold (Remove and Replace).
  7. Remove the Wiper Module (Remove and Replace).
  8. Remove the HVAC Assembly (Heat Pump) (Remove and Replace).
  9. Remove the Booster - Brake - Electromechanical (Heat Pump) (LHD) (Remove and Replace).
  10. Remove the Brake Pedal (Remove and Replace).
  11. Remove the Module - Body Controller - Front (Dual Motor) (Non-Heat Pump) (Remove and Replace).
  12. Remove the Module - Body Controller - LH (LHD) (Heat Pump) (Remove and Replace).
  13. Remove the Cowl Top.
  14. Remove the original component.

    or Factory Spot Welds

    or Drill through factory spot welds
    Note
    When drilling out spot welds, use a drill bit that creates a hole correctly sized for the fastener that will replace the spot weld.
  15. Prepare for installation.
    or Rivets, 4.8 mm

    or Structural Bulb Rivets, 6.5 mm

  16. Apply structural adhesive to the mating surfaces on the vehicle and the new component or components.
  17. Install the new component or components.
  18. Install the Cowl Top.
  19. Perform any necessary post-repair operations.
  20. Install the Module - Body Controller - LH (LHD) (Heat Pump) (Remove and Replace).
  21. Install the Module - Body Controller - Front (Dual Motor) (Non-Heat Pump) (Remove and Replace).
  22. Install the Brake Pedal (Remove and Replace).
  23. Install the Booster - Brake - Electromechanical (Heat Pump) (LHD) (Remove and Replace).
  24. Install the HVAC Assembly (Heat Pump) (Remove and Replace).
  25. Install the Wiper Module (Remove and Replace).
  26. Install the A/C Compressor and Supermanifold (Remove and Replace).
  27. Install the Windshield (Reuse Humidity and Temperature Sensor) (Remove and Replace).
  28. Install the Hood (Remove and Install).
  29. Install the Brace - Shock Tower (Non-Heat Pump) (Remove and Replace).
  30. Install the IP Carrier (Remove and Install).
  31. Install the Module - Body Controller - RH (Remove and Replace).
