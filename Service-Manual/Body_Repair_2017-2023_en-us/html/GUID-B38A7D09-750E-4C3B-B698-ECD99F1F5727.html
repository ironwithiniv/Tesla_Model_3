Rear Wheelhouse Front Stiffener

Correction code: 10101910902 10101911002 NOTE: Unless explicitly stated in the procedure, the above correction code includes all Collision Repair and Service repair work required to perform this procedure, including the linked Collision Repair procedures and linked Service procedures. Do not stack Collision Repair correction codes unless explicitly told to do so. Depending on the damage to the vehicle, additional repairs may be required.

Parent topic: Rear Quarter Inner Panels

Repair Information

  • Review all collision repair general practices and safety documentation and wear the appropriate PPE (Personal Protective Equipment) before beginning this procedure.
  • This procedure can be completed without using a frame bench.

Repair Procedure

  1. Remove the Wheel Arch Liner - Rear - LH (Remove and Replace).
  2. Remove the Knuckle - Suspension - Rear - LH (Remove and Replace).
  3. Remove the Damper - Rear - LH (Remove and Replace).
  4. Remove the Subwoofer (Remove and Replace).
  5. Remove the Spring - Rear Suspension - LH (Remove and Replace).
  6. Remove the Drop Link - Stabilizer Bar - Rear - LH (Remove and Replace).
  7. Remove the Link - Aft - Upper - Rear - LH (Remove and Replace).
  8. Remove the Link - Fore - Lower - Rear - LH (Remove and Replace).
  9. Remove the Link - Fore - Upper - Rear - LH (Remove and Replace).
  10. Remove the Carpet - Rear Trunk (1-Piece) (Remove and Replace).
  11. Remove the Busbars - Charge Port to HV Battery (NACS) (Remove and Replace).
  12. Remove the Trim - Side - Trunk - RH (Remove and Replace).
  13. Remove the Rear Damper Mount Upper.
  14. Remove the original component.

    Bolt

    Factory Spot Weld

    Factory SPR

  15. Prepare for installation.

    Bolt

    or High Strength Structural Rivets, 6.5 mm

  16. Apply structural adhesive to the mating surfaces on the vehicle and the new component or components.
  17. Install the new component or components.
    Torque the bolt to 24 Nm.
  18. Install the Rear Damper Mount Upper.
  19. Install the Trim - Side - Trunk - RH (Remove and Replace).
  20. Install the Busbars - Charge Port to HV Battery (NACS) (Remove and Replace).
  21. Install the Carpet - Rear Trunk (1-Piece) (Remove and Replace).
  22. Install the Link - Fore - Upper - Rear - LH (Remove and Replace).
  23. Install the Link - Fore - Lower - Rear - LH (Remove and Replace).
  24. Install the Link - Aft - Upper - Rear - LH (Remove and Replace).
  25. Install the Drop Link - Stabilizer Bar - Rear - LH (Remove and Replace).
  26. Install the Spring - Rear Suspension - LH (Remove and Replace).
  27. Install the Subwoofer (Remove and Replace).
  28. Install the Damper - Rear - LH (Remove and Replace).
  29. Install the Knuckle - Suspension - Rear - LH (Remove and Replace).
  30. Install the Wheel Arch Liner - Rear - LH (Remove and Replace).
