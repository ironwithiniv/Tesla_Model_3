Breathers - HV Battery (Remove and Replace)

Correction code 16102302 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

Remove

  1. Remove the mid aero shield panel. See Panel - Aero Shield - Rear (Remove and Replace).
  2. Release the fir tree clips that attach the coolant hoses to the LH shear plate.
  3. Remove and discard the HV battery breather from the LH HV battery vent shroud assembly.
  4. Release the fir tree clips that attach the coolant hoses to the RH shear plate.
  5. Remove and discard the HV battery breather from the RH HV battery vent shroud assembly.

Install

  1. Use an IPA wipe to clean the holes where the breathers will install.
  2. Install a new HV battery breather into the LH HV battery vent shroud assembly.
    Note
    Press at the center of the breather, and then press at 3 points forming a triangle pattern on the breather, to make sure that the HV battery breather is fully seated.
    Note
    Use force gauge to apply 200N of force to secure the breather valve into the vent shroud assembly.
    Note
    When using the force gauge, make sure to press perpendicular to the vent shroud.
  3. Apply sideways pressure on the HV battery breather at several locations to verify that it is attach in the LH HV battery vent shroud.
  4. Fasten the fir tree clips that attach the coolant hoses to the LH shear plate.
  5. Install a new HV battery breather into the RH HV battery vent shroud assembly.
    Note
    Press at the center of the breather, and then press at 3 points forming a triangle pattern on the breather, to make sure that the HV battery breather is fully seated.
    Note
    Use force gauge to apply 200N of force to secure the breather valve into the vent shroud assembly.
    Note
    When using the force gauge, make sure to press perpendicular to the vent shroud.
  6. Apply sideways pressure on the HV battery breather at several locations to verify that it is attach in the RH HV battery vent shroud.
  7. Fasten the fir tree clips that attach the coolant hoses to the RH shear plate.
  8. Install the mid aero shield panel. See Panel - Aero Shield - Rear (Remove and Replace).
