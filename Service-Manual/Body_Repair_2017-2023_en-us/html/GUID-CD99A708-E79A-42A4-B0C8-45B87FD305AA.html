Actuator - Pedestrian Protection - LH (Remove and Replace)

Correction code 20300102 0.36 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

Warning
Make sure 12V/LV power has been disconnected for at least 1 minute before disconnecting the electrical harness from Supplementary Restraint System (SRS) components, such as Restraint Control Module, sensors, airbags, etc. Disconnect the 12V/LV battery and the First Responder Loop. Failure to do so can result in unintended safety system behaviors. For more information on SRS precautions, see .
CAUTION
Supplemental Restraint System (SRS) components can be hazardous if not serviced and handled correctly. See
CAUTION
In the event of an airbag or seatbelt pretensioner deployment, certain components must be replaced, and other components must be inspected for damage. Refer to the Collision Repair Manual for a specific list of items that must be inspected and replaced.
Note
Some vehicle versions are not equipped with this part.

Torque Specifications

Table 1. Torque Specifications: Actuator - Pedestrian Protection - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Nut Pyrotechnic actuator to vehicle body nuts.
6 Nm (4.4 lbs-ft)
  • Torx T30 socket
Reuse

Remove

  1. Remove the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
  2. Disconnect the 12V power. See 12V/LV Power (Disconnect and Connect).
  3. Remove the wheel arch liner. See Wheel Arch Liner - Front - LH (Remove and Replace).
  4. Disconnect pyrotechnic actuator connector(x1).
  5. Remove the nuts (x2) that attach the pyrotechnic actuator to the body, and then remove the actuator from the vehicle.
    6 Nm (4.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T30 socket

Install

  1. Install the nuts (x2) that attache the pyrotechnic actuator to the body, and then install the actuator to the vehicle.
    6 Nm (4.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T30 socket
  2. Connect pyrotechnic actuator connector(x1).
  3. Install the wheel arch liner. See Wheel Arch Liner - Front - LH (Remove and Replace).
  4. Connect the 12V power. See 12V/LV Power (Disconnect and Connect).
  5. Install the underhood storage unit. See Underhood Storage Unit (Remove and Replace).
