Correction code

Remove

  1. Remove the rear trunk load floor. See GUID-D937E149-8C0B-486F-A555-376066BE8144.html.
  2. Remove the front trunk load floor. See GUID-EFA5DE2D-2C91-48BC-94B0-8B596AB74B95.html.
  3. Remove the trunk sill trim. See Trim - Sill - Trunk (Remove and Replace).
  4. Remove the trunk load floor bracket. See GUID-4EEFF013-172F-4129-B716-FF6D07036C59.html.
  5. Release the push clip and alignment tabs (x5) that attach the LH trunk pocket bracket to the vehicle, and then remove the bracket from the vehicle.

Install

Installation procedure is the reverse of removal.
