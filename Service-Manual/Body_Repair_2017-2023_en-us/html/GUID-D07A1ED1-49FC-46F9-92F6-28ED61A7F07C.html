Link - Aft - Lower - Rear - LH (Remove and Replace)

Correction code 31031102 0.66 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

Equipment:
  • 1135103-00-A Tool, Spring Compressor, Hook, Model 3
  • 1137855-00-A TOOL, REAR RIDE HEIGHT TORQUE, MODEL 3
  • 1081765-00-A 3/4 TON UNDERHOIST STAND
  • 1459409-00-A ADAPTER, HUB JACK, MODEL 3

    Remove

    1. Inspect the vehicle for abnormal tire wear that might indicate the need for a wheel alignment. Note any findings.
    2. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
    3. Remove the LH rear wheel. See Wheel Assembly (Remove and Install).
    4. Remove the mid aero shield panel. See Panel - Aero Shield - Rear (Remove and Replace).
    5. Remove the LH rear suspension cover. See Cover - Rear Suspension - LH (Remove and Replace).
    6. Install the Gedore spring compressor onto the LH rear spring.
    7. Position a support stand underneath the LH rear suspension.
    8. Losen the nut that attaches the LH rear lower aft link to the subframe.
    9. Remove the bolt and nut that attach the rear damper to the LH rear lower aft link.
    10. Remove the bolt and nut that attach the LH rear lower aft link to the knuckle.
    11. With the help of an assistant, lower the support stand and keep the LH rear spring with the LH rear lower aft link, as the link swings down and away from the LH rear knuckle.
    12. Remove the Gedore spring compressor.
    13. Release the grommets (x2) that attach the LH rear spring to the LH rear lower aft link, and remove the spring from the link.
    14. Remove the bolt and nut that attach the LH rear lower aft link to the rear subframe, and then remove the link from the subframe.

    Install

    1. Install the LH rear lower aft link to the rear subframe, then install and hand-tighten the bolt and nut that attach the link to the subframe.
    2. Install the LH rear spring to the LH rear lower aft link, and fasten the grommets (x2) that attach the spring to the link.
    3. Install the Gedore spring compressor onto the LH rear spring.
    4. Swing the LH rear lower aft link up and onto the support stand, and then raise the support stand until the link and LH rear knuckle merge.
      Note
      It might be necessary to compress the spring further so that the link and knuckle holes align.
    5. Install and hand-tighten the bolt and nut that attach the LH rear lower aft link to the LH rear knuckle.
    6. Install and hand-tighten the bolt and nut that attach the LH rear damper to the LH rear lower aft link.
    7. Remove the bolt that attaches the LH rear brake rotor to the LH rear hub.
      Note
      Use of the following tool(s) is recommended:
      • 10 mm socket
      • 2 in extension
    8. Install the hub jack adapter onto the LH rear hub and hand-tighten the lug nuts.
    9. Move the support stand to support the hub jack adapter.
      Note
      Use the rear ride height torque gauge to verify that the rear suspension is set to ride height specifications and adjust the support stand or spring compressor tool , if necessary.
    10. Measure the distance between the bottom of the LH rear quarter panel to the center of the LH rear axle to make sure that the rear suspension is set to ride height: The distance should measure 378 mm.
    11. Tighten the bolt that attaches the LH rear lower aft link to the rear subframe. Mark the bolt with a paint pen after the bolt is tightened.
      115 Nm (84.8 lbs-ft)
      115 Nm (84.8 lbs-ft)
    12. Tighten the bolt that attaches the LH rear lower aft link to the LH rear knuckle. Mark the bolt with a paint pen after the bolt is tightened.
      115 Nm (84.8 lbs-ft)
      115 Nm (84.8 lbs-ft)
    13. Tighten the bolt and nut that attach the LH rear damper to the LH rear lower aft link. Mark the bolt with a paint pen after the bolt is tightened.
      115 Nm (84.8 lbs-ft)
      115 Nm (84.8 lbs-ft)
    14. Remove the support stand from the hub jack adapter.
    15. Remove the lug nuts that attach the hub jack adapter, and then remove the hub jack adapter from the LH rear hub.
    16. Install the bolt that attaches the LH rear brake rotor to the LH rear hub.
      5 Nm (3.7 lbs-ft)
      Note
      Use of the following tool(s) is recommended:
      • 10 mm socket
      • 2 in extension
    17. Remove the Gedore spring compressor from the LH rear spring.
    18. Install the LH rear suspension cover. See Cover - Rear Suspension - LH (Remove and Replace).
    19. Install the mid aero shield panel. See Panel - Aero Shield - Rear (Remove and Replace).
    20. Install the LH rear wheel. See Wheel Assembly (Remove and Install).
    21. Refer to the Alignment Requirement tables to determine whether an EPAS alignment check (EC) or four wheel alignment check (AC) is necessary. If performed, add the alignment check/adjust correction code as a separate activity to the SV. See Alignment Requirement - Suspension.
