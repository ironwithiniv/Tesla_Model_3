Grille - Speaker - Instrument Panel (Remove and Replace)

Correction code 14054702 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

Remove

  1. Remove the LH and RH instrument panel end caps. See End Cap - Instrument Panel - LH (Remove and Replace).
  2. Remove the LH and RH middle A-pillar trims. See Trim - A-Pillar - Middle - LH (Remove and Replace).
  3. Remove the LH and RH upper A-Pillar trims. See Trim - A-Pillar - Upper - LH (Remove and Replace).
  4. Release the clips that attach the speaker grille to the body. Rotate the rear of the speaker grille upwards, and then pull the grille towards the rear of the vehicle to remove it.

Install

  1. Replace any damaged clips on the instrument panel speaker grille.
  2. Position the instrument panel speaker grille into position on the instrument panel.
  3. Attach the clips that secure the instrument panel grille to the vehicle. Use a plastic pry stick to press the vertical clips forward to assist with inserting them into the IP carrier.
    Note
    Make sure of the following:
    • The instrument panel speaker grille forward hooks are fully engaged into the IP carrier.
    • There is no gap at the bottom of the windshield.
  4. Install the LH and RH upper A-Pillar trims. See Trim - A-Pillar - Upper - LH (Remove and Replace).
  5. Install the LH and RH middle A-pillar trims. See Trim - A-Pillar - Middle - LH (Remove and Replace).
  6. Install the LH and RH instrument panel end caps. See End Cap - Instrument Panel - LH (Remove and Replace).
