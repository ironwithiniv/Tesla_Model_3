Parking Brake - Caliper - Rear - LH (Release)

Correction code 33051005 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

  • 2024-05-27: Added method using Service Mode.
  • 2023-08-24: Updated EPB Service Mode routine.
Equipment:
  • 1134520-00-A Kit, EPB Release, Handheld (Manual release)
  • 1129348-00-A XP-10 Power Supply, XP-10 (Manual release)

Release Parking Brake Using Service Mode

  1. If needed, chock the wheels.
  2. Enable Service Mode from the touchscreen. See Service Mode.
  3. Unlock the Gateway. See Gateway (Unlock).
  4. On the touchscreen, under Vehicle Info, touch Chassis, under Chassis, touch Brakes, and then in the diagram, touch EPB Service Mode.
  5. Read the text displayed, and under Parameters, from the Action target drop-down menu, select BOTH, from the Action type drop-down menu, select START, and touch Run.
    Note
    To release the parking brake on one side of the vehicle, select LEFT or RIGHT.
    CAUTION
    The vehicle may roll freely.
  6. The vehicle is now in EPB Service Mode.
  7. To disable EPB Service Mode, shift the vehicle into Park.

Release Parking Brake Using Toolbox

  1. If needed, chock the wheels.
  2. Connect a laptop with Toolbox 3 to the vehicle. See Toolbox (Connect and Disconnect).
  3. Using Toolbox 3:
    1. Select the Actions tab and search for "EPB Service Mode".
    2. Select the ODIN routine PROC_EPB_X_SERVICE-MODEvia Service Mode:
      • Chassis ➜ Brakes ➜ EPB Service Mode
      • Chassis ➜ Brakes ➜ EPB Service Mode
      via Service Mode Plus:Drive Unit ➜ Rear Drive Unit Replacement ➜ Release / Re-Engage Emergency Parking Brakevia Toolbox:(link)      , and then click the link of the routine.
    3. Under "Action_Target" select BOTH, and under "Action_Type" select START.
    4. Click RUN, and allow the routine to complete.
      Note
      Press and hold the brake pedal while performing this routine.
      Note
      To release the parking brake on one side of the vehicle, select LEFT or RIGHT under "Action_Target".
      CAUTION
      The vehicle may roll freely.
  4. The vehicle is now in EPB Service Mode.
  5. To disable EPB Service Mode, shift the vehicle into Park.

Release Parking Brake Using Special Tool

  1. Raise and support the vehicle. See Raise Vehicle - 2 Post Lift.
  2. Remove the LH rear wheel. See Wheel Assembly (Remove and Install).
  3. Disconnect the electrical harness from the LH rear brake caliper connector.
  4. Remove the bolt that attach the electrical harness bracket to the LH rear brake caliper.
  5. Connect the EPB release tool to the LH rear brake caliper connector.
  6. Use the EPB release tool to fully release the parking brake.
  7. If the parking brake:
    • Released, go to step 12.
    • Did not release, go to step 8.
  8. Position an oil drain underneath the LH rear brake caliper.
  9. Remove the bolts that attach the parking brake motor to the LH rear brake caliper, and remove the motor from the caliper.
  10. Manually rotate the shaft in the caliper to fully release the parking brake.
  11. Replace the LH rear brake caliper. See Brake Caliper - Rear - LH (Remove and Replace).
  12. Disconnect the EPB release tool from the LH rear brake caliper connector.
  13. Repeat step 2 through step 12 for the RH rear brake caliper if necessary.

Install

  1. Install the bolt that attaches the electrical harness bracket to the LH rear brake caliper.
    5 Nm (3.7 lbs-ft)
  2. Connect the electrical harness to the LH rear brake caliper connector.
  3. Install the LH rear wheel. See Wheel Assembly (Remove and Install).
  4. Repeat step 1 and step 3 for the RH rear brake caliper if necessary.
  5. Lower the vehicle. See Raise Vehicle - 2 Post Lift.
  6. Verify the operation of the parking brake.
