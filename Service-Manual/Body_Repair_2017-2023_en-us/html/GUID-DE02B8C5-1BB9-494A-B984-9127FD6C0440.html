Dash Crossmember

Correction code: 10101016302 NOTE: Unless explicitly stated in the procedure, the above correction code includes all Collision Repair and Service repair work required to perform this procedure, including the linked Collision Repair procedures and linked Service procedures. Do not stack Collision Repair correction codes unless explicitly told to do so. Depending on the damage to the vehicle, additional repairs may be required.

Parent topic: Front Inner Panels

Repair Information

  • Review all collision repair general practices and safety documentation and wear the appropriate PPE (Personal Protective Equipment) before beginning this procedure.
  • This procedure can be completed without using a frame bench.

Repair Procedure

  1. Remove the A/C Compressor, Supermanifold and Compressor to Supermanifold A/C Line (Heat Pump) (Remove and Replace).
  2. Remove the Fascia - Front (Remove and Install).
  3. Remove the Hood (Remove and Install).
  4. Remove the Wiper Module (Remove and Replace).
  5. Remove the HVAC Assembly (Heat Pump) (Remove and Replace).
  6. Remove the Booster - Brake - Electromechanical (Heat Pump) (LHD) (Remove and Replace).
  7. Remove the Brake Pedal (Remove and Replace).
  8. Remove the Carpet - Interior Complete (Remove and Replace).
  9. Remove the Beam - Cross Car (LHD) (Remove and Replace).
  10. Remove the HV Battery (AWD) (Remove and Install).
  11. Remove the Subframe Assembly - Front (Dual Motor) (Remove and Install).
  12. Remove the original component.
    or Factory Spot Welds
  13. Prepare for installation.
    Note
    A red X indicates a location where a factory-installed fastener is not being replaced. Secure this location using structural adhesive only.
    or High Strength Structural Rivets, 6.5 mm
    • A = 127 mm.
    • B = 8 mm.

    or Structural Bulb Rivets, 6.5 mm

  14. Apply structural adhesive to the mating surfaces on the vehicle and the new component or components.
  15. Install the new component or components.
  16. Install the Subframe Assembly - Front (Dual Motor) (Remove and Install).
  17. Install the HV Battery (AWD) (Remove and Install).
  18. Install the Beam - Cross Car (LHD) (Remove and Replace).
  19. Install the Carpet - Interior Complete (Remove and Replace).
  20. Install the Brake Pedal (Remove and Replace).
  21. Install the Booster - Brake - Electromechanical (Heat Pump) (LHD) (Remove and Replace).
  22. Install the HVAC Assembly (Heat Pump) (Remove and Replace).
  23. Install the Wiper Module (Remove and Replace).
  24. Install the Hood (Remove and Install).
  25. Install the Fascia - Front (Remove and Install).
  26. Install the A/C Compressor, Supermanifold and Compressor to Supermanifold A/C Line (Heat Pump) (Remove and Replace).
