Sill Inner (Front Section)

Correction code: RH: 10102900902 LH: 10102901102 NOTE: Unless explicitly stated in the procedure, the above correction code includes all Collision Repair and Service repair work required to perform this procedure, including the linked Collision Repair procedures and linked Service procedures. Do not stack Collision Repair correction codes unless explicitly told to do so. Depending on the damage to the vehicle, additional repairs may be required.

Parent topic: Center Under Body Panels

Repair Information

  • Review all collision repair general practices and safety documentation and wear the appropriate PPE (Personal Protective Equipment) before beginning this procedure.
  • Properly mount the vehicle on a frame bench when performing this procedure.

Repair Procedure

  1. Remove the HV Battery (AWD) (Remove and Install).
  2. Remove the Brake Lines - LH Sill (Remove and Replace).
  3. Remove the Beam - Cross Car (LHD) (Remove and Replace).
  4. Remove the Steering Column (LHD) (Remove and Replace).
  5. Remove the Brake Pedal (Remove and Replace).
  6. Remove the Module - Body Controller - RH (LHD) (Heat Pump) (Remove and Replace).
  7. Remove the Module - Body Controller - LH (LHD) (Heat Pump) (Remove and Replace).
  8. Remove the Fender Assembly - Front - LH (Remove and Install).
  9. Remove the Carpet - Interior Complete (Remove and Replace).
  10. Remove the Brightwork - Upper - LH (Remove and Replace).
  11. Remove the Seal - Body - Side - Front - Primary - LH (Remove and Replace).
  12. Remove the Door - Front - LH (Remove and Install).
  13. Remove the Hinge - Door - Front - Upper - LH (Remove and Replace).
  14. Remove the Hinge - Door - Front - Lower - LH (Remove and Replace).
  15. Remove the Door - Rear - LH (Remove and Install).
  16. Remove the Trim - A-Pillar - Upper - LH (Remove and Replace).
  17. Remove the Sill Insert (Front Section).
  18. Cut the original component at the indicated locations.

    Cut Line

    Reference Line/Point

    • A = 135 mm
  19. Remove the original component.

    Factory Spot Weld Area

    or Factory Spot Welds

  20. Cut the new component in the indicated location.

    Cut Line

    Reference Line/Point

    • B = 390 mm
  21. Create 80 mm reinforcement plates from the remaining pieces of the new Sill Inner Assembly.
    CAUTION
    Make sure that the reinforcement plates will not interfere with the Sill Insert (Front Section) installation.
    Note
    Make sure that the upper reinforcement plate does not obstruct trim clip holes in the Sill Inner. Create holes in the reinforcement plate if necessary.
  22. Prepare for installation.

    Installation Spot Weld Area

    Installation Spot Weld

  23. Apply structural adhesive to the mating surfaces on the vehicle and the new component or components.
  24. Install the new component or components.
  25. Perform resistance spot welding.
    or Installation Spot Welds
    Warning
    Failure to follow all welding safety precautions, including the use of personal protective equipment, could result in serious injury or property damage. Only technicians who have completed Tesla’s approved welding training are authorized to weld structural components on Tesla vehicles.
    CAUTION
    Do not weld on a Tesla vehicle before performing the Vehicle HV Disablement Procedure (refer to the vehicle-specific Service Manual for more information on the Vehicle HV Disablement Procedure). Welding on a Tesla vehicle with an energized high or low voltage system might damage vehicle components.
  26. Install the new Sill Insert (Front Section).
  27. Perform any necessary post-repair operations.
  28. Install the Trim - A-Pillar - Upper - LH (Remove and Replace).
  29. Install the Door - Rear - LH (Remove and Install).
  30. Install the Hinge - Door - Front - Lower - LH (Remove and Replace).
  31. Install the Hinge - Door - Front - Upper - LH (Remove and Replace).
  32. Install the Door - Front - LH (Remove and Install).
  33. Install the Seal - Body - Side - Front - Primary - LH (Remove and Replace).
  34. Install the Brightwork - Upper - LH (Remove and Replace).
  35. Install the Carpet - Interior Complete (Remove and Replace).
  36. Install the Fender Assembly - Front - LH (Remove and Install).
  37. Install the Module - Body Controller - LH (LHD) (Heat Pump) (Remove and Replace).
  38. Install the Module - Body Controller - RH (LHD) (Heat Pump) (Remove and Replace).
  39. Install the Brake Pedal (Remove and Replace).
  40. Install the Steering Column (LHD) (Remove and Replace).
  41. Install the Beam - Cross Car (LHD) (Remove and Replace).
  42. Install the Brake Lines - LH Sill (Remove and Replace).
  43. Install the HV Battery (AWD) (Remove and Install).
