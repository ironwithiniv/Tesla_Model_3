Carpet - Front - RH (Remove and Replace)

Correction code 15303102 0.66 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

Warning
Seat base edges are sharp and can cause personal injury. Wear cut resistant gloves when removing the seat from the vehicle, and while performing procedures that involve work on or near the seat base.

Remove

  1. Remove the front passenger seat. See Seat Assembly - 1st Row - LH (Remove and Replace).
  2. Remove the center console. See Center Console (Remove and Install).
  3. Release the clips that attach the RH front carpet to the body, and then remove the RH front carpet from the vehicle.

Install

  1. Install the RH front carpet into the vehicle, and then fasten the clips that attach the RH front carpet to the body.
  2. Install the center console. See Center Console (Remove and Install).
  3. Install the front passenger seat. See Seat Assembly - 1st Row - LH (Remove and Replace).
