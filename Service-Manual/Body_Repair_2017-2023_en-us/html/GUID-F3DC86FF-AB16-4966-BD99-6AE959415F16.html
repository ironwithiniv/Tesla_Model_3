Shotgun Inner

Correction code: 10101016602 10101015802 NOTE: Unless explicitly stated in the procedure, the above correction code includes all Collision Repair and Service repair work required to perform this procedure, including the linked Collision Repair procedures and linked Service procedures. Do not stack Collision Repair correction codes unless explicitly told to do so. Depending on the damage to the vehicle, additional repairs may be required.

Parent topic: Front Inner Panels

Repair Information

  • Review all collision repair general practices and safety documentation and wear the appropriate PPE (Personal Protective Equipment) before beginning this procedure.
  • This procedure can be completed without using a frame bench.

Repair Procedure

  1. Remove the Bracket - Active Hood Strut - LH (Remove and Replace).
  2. Remove the Hinge - Hood - LH (Remove and Replace).
  3. Remove the Cover - Hinge - Active Hood - LH (Remove and Replace).
  4. Remove the Cover - Shock Tower - LH (Remove and Replace).
  5. Remove the Hood (Remove and Install).
  6. Remove the Fender Support - Front - LH (Remove and Replace).
  7. Remove the Fender Assembly - Front - LH (Remove and Install).
  8. Remove the Windshield (Reuse Humidity and Temperature Sensor) (Remove and Replace).
  9. Remove the Wiper Module (Remove and Replace).
  10. Remove the Reservoir - Windshield Washer (Remove and Replace).
  11. Remove the Shotgun Outer.
  12. Remove the original component.
    or Factory Spot Welds
    or Drill through factory spot welds
    Note
    When drilling out spot welds, use a drill bit that creates a hole correctly sized for the fastener that will replace the spot weld.
  13. Prepare for installation.
    Note
    A red X indicates a location where a factory-installed fastener is not being replaced. Secure this location using structural adhesive only.

    or High Strength Structural Rivets, 6.5 mm

    Structural Bulb Rivet, 6.5 mm
    • A = 74 mm
    • B = 54 mm
    • C = 14 mm
    • D = 22 mm

    or Countersunk Rivets, 4.8 mm Short

    or Structural Countersunk Rivets, 6.5 mm

    or Flow Form Rivets, S18

  14. Apply structural adhesive to the mating surfaces on the vehicle and the new component or components.
  15. Install the new component or components.
  16. Install the new Shotgun Outer.
  17. Install the new Fender Support Bracket.
  18. Install the fastener as indicated.
    or Flow Form Rivets, S48
  19. Perform any necessary post-repair operations.
  20. Install the Reservoir - Windshield Washer (Remove and Replace).
  21. Install the Wiper Module (Remove and Replace).
  22. Install the Windshield (Reuse Humidity and Temperature Sensor) (Remove and Replace).
  23. Install the Fender Assembly - Front - LH (Remove and Install).
  24. Install the Fender Support - Front - LH (Remove and Replace).
  25. Install the Hood (Remove and Install).
  26. Install the Cover - Shock Tower - LH (Remove and Replace).
  27. Install the Cover - Hinge - Active Hood - LH (Remove and Replace).
  28. Install the Hinge - Hood - LH (Remove and Replace).
  29. Install the Bracket - Active Hood Strut - LH (Remove and Replace).
