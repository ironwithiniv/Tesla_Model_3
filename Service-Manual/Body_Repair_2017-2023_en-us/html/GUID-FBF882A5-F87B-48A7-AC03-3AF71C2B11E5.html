Alignment Requirement - Suspension

Use the following tables to determine the suspension alignment requirement according to the service performed on the component.

  • 2025-09-18: Added note to not use EPAS to check for damage from collision.
  • 2025-07-02: Added rear knuckle upper ball joint.
  • 2025-04-07: Added instructions in cases where EPAS alignment check is infeasible.
  • 2024-10-31: Removed alignment check from rear upper fore link, as a new service procedure for the link, which does not release the rear subframe, has been validated.
  • 2024-09-26: Added instruction to perform an alignment check when servicing the RH rear upper fore link.
EC (EPAS Check)
Indicates that an EPAS alignment check (correction code 31001500) is to be performed. Add the EPAS alignment check as a separate correction in the same activity. If the vehicle passes the EPAS check, an alignment is not necessary. If the vehicle fails the EPAS check, perform an alignment check (correction code 31002100).
Note
If unable to perform EPAS alignment check due to service center location/layout or other reasons, perform the four wheel alignment check (correction code 31002100, described below).
Note
EPAS should not be used to check for potential suspension component damage as a result of a collision.
AC ( Alignment Check)
Indicates that a four wheel alignment check is to be performed in order to determine whether an alignment adjustment is necessary. Add the alignment check (correction code 31002100) or adjustment (correction code 31002300) as a separate correction in the same activity.
Note
When performing a suspension adjustment on Model 3, always add correction code 31002300 first, which accounts for toe adjustment. If camber/caster adjustments are performed, also add correction code 31000200.
  • Toe adjustment: 31002300
  • Toe and camber/caster adjustment: 31002300 + 31000200
NA
Indicates that No Alignment is necessary, or not applicable.
