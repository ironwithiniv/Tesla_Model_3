Foam - Seat Back - 2nd Row - RH (Remove and Replace)

Correction code 1308010052 FRT 0.58 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See to learn more about FRTs and how they are created. Torque Specifications

2 Nm (1.5 lbs-ft)
  • Torx T25 socket
 Reuse

Remove

  1. Remove the RH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  2. Remove the 2nd row lower seat cushion. See .
  3. Remove the RH 2nd row seat back. See .
  4. Remove the RH 2nd row seat back hinge bracket. See .
  5. Remove the RH 2nd row escutcheon. See .
    Note
    There are 2 clips in the RH 2nd row escutcheon.
  6. Remove the RH 2nd row seat back latch release bezel. See .
  7. Remove the RH 2nd row seat back cover. See .
  8. Remove the bolts (x2) that attach the RH 2nd row seat back handle to the seat back frame.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket
  9. Remove the RH 2nd row seat back foam from the seat back frame.

Install

  1. Install the RH 2nd row seat back foam to the seat back frame.
  2. Install the bolts (x2) that attach the RH 2nd row seat back handle to the seat back frame.
    2 Nm (1.5 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket
  3. Install the RH 2nd row seat back cover. See .
  4. Install the RH 2nd row seat back latch release bezel. See .
  5. Install the RH 2nd row escutcheon. See .
    Note
    There are 2 clips in the RH 2nd row escutcheon.
  6. Install the RH 2nd row seat back hinge bracket. See .
  7. Install the RH 2nd row seat back. See .
  8. Install the 2nd row lower seat cushion. See .
  9. Install the RH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
