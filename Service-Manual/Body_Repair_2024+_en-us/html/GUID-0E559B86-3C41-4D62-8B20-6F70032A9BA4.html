Wheel Arch Liner - Front - LH (Remove and Replace)

Correction code 1201020012 FRT 0.30 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See for safe and healthy working practices.

Torque Specifications

Table 1. Torque Specifications: Wheel Arch Liner - Front - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolt that attaches the strut bracket to the wheel arch, from inside the wheel arch
5 Nm (3.7 lbs-ft)
  • 10 mm deep socket
 Reuse

Remove

  1. Raise and support the vehicle. See .
  2. Remove the LH front wheel. See Wheel Assembly (Remove and Install).
  3. Remove the bolt that attaches the LH front wheel arch liner to the vehicle.
    Note
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  4. Release the push clips (x17) that attach the LH front wheel arch liner to the vehicle, and remove the liner from the vehicle.

Install

  1. Position the LH front wheel arch liner into the vehicle.
  2. Install the push clips (x17) that attach the LH front wheel arch liner to the vehicle.
  3. Install the bolt that attaches the LH front wheel arch liner to the vehicle.
    5 Nm (3.7 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  4. Install the LH front wheel. See Wheel Assembly (Remove and Install).
  5. Remove the vehicle from the lift.
