Brake Pedal (Remove and Replace)

Correction code 33251002 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See Flat Rate Times to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure wearing proper PPE when performing the below procedure. NOTE: See for safe and healthy working practices.

    Remove

    1. Remove the rear underhood apron. See #GUID-513C83FE-1D5B-4FC1-B3EA-FA796E158252.
    2. Disconnect 12V power. See #GUID-E11A35CC-1803-41C5-87F0-D7868FA3E51F.
    3. Disconnect the brake pedal electrical connector.
    4. Remove the brake light switch from the pedal assembly. See #GUID-DE004FA8-A2D6-4E84-B56B-E8CF8BD20DB5.
    5. Remove the brake clevis pin cotter pin.
    6. Remove the brake clevis pin that attaches the brake pedal to the electromechanical brake booster.
    7. Release the clips that attach the electrical harness to the brake pedal assembly.
    8. Remove and discard the that attach the brake pedal assembly to the vehicle.
    9. Remove the brake pedal and the accelerator pedal as an assembly from the vehicle.

    Install

    1. Install the brake pedal assembly onto the studs of the body.
    2. Install new nyloc nuts that attach the brake pedal assembly to the vehicle.
      16.5 Nm (12.2 lbs-ft)
    3. Fasten the clips that attach the electrical harness to the brake pedal assembly.
    4. Install the brake clevis pin that attaches the brake pedal to the electromechanical brake booster.
    5. Install the brake clevis pin cotter pin.
    6. Install the brake light switch. See #GUID-DE004FA8-A2D6-4E84-B56B-E8CF8BD20DB5.
      Note
      Install a new brake switch if the existing one was damaged during removal.
      Note
      Confirm that the brake pedal is in the home position: Push the brake pedal switch into the clip until it stops, and then twist the brake switch clockwise 45 degrees to set the brake switch in position. Do not push the brake pedal switch too hard as to move the brake pedal.
    7. Connect the brake pedal electrical connector.
    8. Connect 12V power. See #GUID-E11A35CC-1803-41C5-87F0-D7868FA3E51F.
    9. Install the rear underhood apron. See #GUID-513C83FE-1D5B-4FC1-B3EA-FA796E158252.
