Crush Can - Upper - Front - LH (Remove and Replace)

Correction code 1001030052 FRT 1.20 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See for safe and healthy working practices.

  • 2024-04-17: Added steps of removing/installing the front fascia.

Remove

  1. Remove the front fascia. See .
  2. Remove the cooling fan module. See Cooling Fan Module (Remove and Replace).
  3. Lower the vehicle.
  4. Use a clip prytool to release the clips (x3) that attach the harness to the LH front crush can.
  5. Remove the bolt that attaches the LH front fender support to the LH front crush can.
    35 Nm (25.8 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Ratchet/torque wrench
    • Cordless Ratchet/Impact Driver
    • 10 mm hex socket
  6. Remove the bolts (x4) that attach the LH front crush can to the LH front inner rail.
    90 Nm (66.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Breaker bar
    • 18 mm socket
    • Cordless Ratchet/Impact Driver
  7. Remove the LH front crush can from the LH front inner rail.

Install

  1. Install the LH front crush can into the LH front inner rail.
    Note
    Lightly tap the crush can with a dead blow harmer to assist with installation into the inner rail.
  2. Install the bolts (x4) that attach the LH front crush can to the LH front inner rail.
    90 Nm (66.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 18 mm socket
    • Cordless Ratchet/Impact Driver
    • Ratchet/torque wrench
  3. Install the bolt that attaches the LH front fender support to the LH front crush can.
    35 Nm (25.8 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Cordless Ratchet/Impact Driver
    • 10 mm hex socket
    • Flex head ratchet/flex head torque wrench
  4. Install the clips (x3) that attach the harness to the LH front crush can.
  5. Install the cooling fan module. See Cooling Fan Module (Remove and Replace).
  6. Install the front fascia. See .
