Active Grille Shutter (Remove and Replace)

Correction code 1850010012 FRT 0.66 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See for safe and healthy working practices.

  • 2026-09-17: Reorganized the procedure as the active grille shutter can be removed without removing the cooling fan module.
  • 2026-05-11: Added the PROC_VCFRONT_X_LOUVER-CALIBRATION routine.

Remove

  1. Raise and support the vehicle. See .
  2. Disconnect the LV power. See .
  3. Remove the underhood storage unit. See .
  4. Remove the bolts (x3) that secure the washer tank to the front end carrier and move the washer tank aside.
    Note
    Use of the following tool(s) is recommended:
    • 2 in extension
    • 10 mm socket
  5. Carefully remove the ambient temperature sensor cover from the active grille shutter.
  6. Disconnect the ambient temperature sensor electrical connector and remove the sensor from the active grille shutter.
  7. Release the connector lock, and then disconnect the active grille shutter actuator electrical connector.
    CAUTION
    Do not push down on the red tab. Pull the red tab to release the connector lock.
  8. Release the upper and middle locking tabs (x8) that attach the active grille shutter to the cooling fan module.
  9. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  10. Remove the front valance. See Valance - Front Fascia (Remove and Replace).
  11. Place a towel to the front of the subframe to protect the cooling fan.
  12. Remove the LH and RH bolts that attach the bottom of the condenser fan module to the ankle catcher.
    Note
    Use of the following tool(s) is recommended:
    • 8 mm socket
    • Ratchet/torque wrench
    Note
    Hold the condenser fan module to ease the removal of the bolts.
  13. Release the lower locking tabs (x6) that attach the active grille shutter to the cooling fan module.
  14. Lower the vehicle fully.
  15. Remove the active grille shutter from the vehicle.
    CAUTION
    Be careful not to damage the radiator.

Install

  1. Install the active grille shutter onto the cooling fan module, then fasten the upper and middle locking tabs (x8).
  2. Raise the vehicle fully and lower the lift onto locks.
  3. Fasten the lower locking tabs (x6) that attach the active grille shutter to the cooling fan module.
  4. Install and hand-tighten the LH and RH bolts (x2) that attach the bottom of the condenser fan module to the ankle catcher.
    Note
    Gently lift the condenser fan module to position into place and install the bolts.
  5. Torque the bolts that attach the bottom of the condenser fan module to the ankle catcher.
    10 Nm (7.4 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • 8 mm socket
    • Ratchet/torque wrench
  6. Remove the towel from the front of the subframe.
  7. Install the front valance. See Valance - Front Fascia (Remove and Replace).
  8. Install the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  9. Lower the vehicle fully.
  10. Install the ambient temperature sensor into the active grill shutter and connect the electrical connector.
  11. Install the ambient temperature sensor cover to the active grille shutter.
  12. Connect the active grille shutter actuator electrical connector, then engage the connector lock.
  13. Connect the LV power. See .
    Note
    Do not install the rear underhood apron at this time.
  14. Install the bolts (x3) that secure the washer tank to the front end carrier.
    3 Nm (2.2 lbs-ft)
    Note
    Use of the following tool(s) is recommended:
    • 2 in extension
    • 10 mm socket
  15. Install the underhood storage unit. See .
  16. Perform the following routine using Service Mode or Toolbox (see ): PROC_VCFRONT_X_LOUVER-CALIBRATIONvia Toolbox:(link)
  17. Perform the following routine using Service Mode or Toolbox: TEST-SELF_VCFRONT_X_THERMAL-PERFORMANCEvia Service Mode:Thermal ➜ Actions ➜ Test Thermal Performancevia Service Mode Plus:
    • Drive Inverter ➜ Front Drive Inverter Replacement ➜ Thermal System Test
    • Drive Inverter ➜ Rear Drive Inverter Replacement ➜ Thermal System Test
    • Drive Inverter ➜ Rear Left Drive Inverter Replacement ➜ Thermal System Test
    • Drive Inverter ➜ Rear Right Drive Inverter Replacement ➜ Thermal System Test
    • Drive Unit ➜ Front Drive Unit Replacement ➜ Thermal System Test
    • Drive Unit ➜ Rear Drive Unit Replacement ➜ Thermal System Test
    via Toolbox:(link)
  18. Exit Service Mode or disconnect the laptop if applicable (see ).
  19. Raise the windows and close the doors.
  20. Remove the vehicle from the lift.
