Seal - Body - Side - Front - Primary - LH (Remove and Replace)

Correction code 1170010052 FRT 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See for safe and healthy working practices.

Remove

  1. Remove the LH B-pillar applique. See Applique - B-Pillar - LH (Remove and Replace).
  2. Release the clip that attaches the LH primary front side body seal to the upper B-pillar.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  3. Release the clip that attaches the LH primary front side body seal to the mid B-pillar.
  4. Release the clip that attaches the LH primary front side body seal to the A-pillar.
  5. Pull on the LH primary front side body seal to remove it from the vehicle.

Install

  1. Loosely install the LH primary front side body seal to the body.
  2. Align the joint line of the LH primary front side body seal to the marking on the B-pillar.
    Note
    Make sure the seal strings are positioned towards the interior of the vehicle when aligning the primary seal.
  3. Install the clip that attaches the LH primary front side body seal to the upper B-pillar.
    Note
    Make sure the edge of the seal are parallel with and above the marking on the upper B-pillar.
  4. Align the outer edge of the LH primary front side body seal to the bottom of the LH upper brightwork.
  5. Install the clips (x2) that attach the LH primary front side body seal to the mid B-pillar and the A-pillar.
  6. Pull the seal strings from the new seal.
  7. Tuck the seal into the bright molding, and make sure that it fits properly to the trim panels and the headliner.
  8. Press the seal into the lower corners, and then install the rest of the seal to the body.
    Note
    Stretch and tuck the seal so that it is evenly distributed around the perimeter.
  9. Install the LH B-pillar applique. See Applique - B-Pillar - LH (Remove and Replace).
