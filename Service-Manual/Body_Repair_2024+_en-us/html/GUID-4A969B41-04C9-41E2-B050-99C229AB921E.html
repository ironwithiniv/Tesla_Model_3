Brake Hydraulic Control Unit (Remove and Replace)

Correction code 3310007012 3310007011 FRT 2.10 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See for safe and healthy working practices.

Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
  1. Raise and support vehicle
    Note
    Ensure vehicle is not charging
  2. Open LH front door
  3. Lower LH front window
  4. Open hood
  5. Remove rear underhood apron
    Note
    14x clips
  6. Remove fresh air gutter assembly
    Note
    3x clips
  7. Remove access panel from frunk assembly
    Note
    3x clips, 1x connector, 3x guide tabs, Frunk safety switch, Grasp access panel at top and pull it back to release clips, Disconnect switch
  8. Release frunk assembly
    Note
    4x bolts, 10mm, 5 Nm
  9. Remove frunk assembly from vehicle
    Note
    8x clips, 3x locator pins, Replace any clips if broken or missing
  10. Power off vehicle from center display
    Note
    Via Controls > Safety > Power Off, Select Power Off button at warning dialogue box
  11. Disconnect LV battery and First Responder Loop
    Note
    2x connectors, Release green locking tab, Press black tab then pull black connector lock outwards to release connection, Release red lock tab on FRL, Allow 2 minutes for all electrical circuits to fully discharge
  12. Verify operation of multimeter
    Note
    Set multimeter to DC voltage, Confirm multimeter is properly measuring voltage by testing the 16v battery
  13. Remove all items from pockets and ensure not wearing metal items
  14. Release 2nd row seat cushion and disconnect harness
    Note
    2x clips, 2x connectors, Press tabs backward then pull front edge up
  15. Inspect HV insulating gloves
    Note
    Check gloves for damage prior to use, Refer to service document TN-15-92-003, for information on inspecting HV gloves. https://service.teslamotors.com/documents?model=&keys=TN-15-92-003&vehicle_system=&sort_by=field_date_submitted&sort_order=DESC
  16. Put on HV insulating gloves and leather over gloves
    Note
    Make sure to wear Electrical Protective Gloves any time Hioki tester is used
  17. Remove bolts securing ancillary bay probe lid cover to ancillary bay cover
    Note
    2x bolts, EP10 5-Lobe, 6 Nm, Discard after removal
  18. Remove ancillary bay probe lid cover from ancillary bay cover
  19. Verify no high voltage
    Note
    Make sure to wear PPE (HV gloves, safety glasses) when working on high voltage component, Measure B+ to Ground, B- to Ground, B+ to B-, If voltage is greater than 10V, Pack contactors are not open or welded, Stop work and reach out to Service Engineering
  20. Inspect ancillary bay probe lid cover gasket then position onto ancillary bay cover
    Note
    Confirm no visual damage present,Wipe ancillary bay with IPA to clean surface,Allow to 1 minute dry time
  21. Install bolts securing ancillary bay probe lid cover to ancillary bay cover
    Note
    2x bolts, EP10 5-Lobe, 6 Nm, Install new fasteners
  22. Remove HV insulating gloves
  23. Release positive jump post
    Note
    1x bolt, 8mm, 5 Nm
  24. Remove clip securing negative terminal cable to AC compressor bracket
    Note
    1x clip
  25. Remove LV battery
    Note
    3x bolts, 8mm, 6 Nm, Raise LV battery vertically from bracket to remove
  26. Remove LH front wheel center cap
    Note
    1x cap
  27. Remove RH front wheel center cap
    Note
    1x cap
  28. Remove RH rear wheel center cap
    Note
    1x cap
  29. Remove LH rear wheel center cap
    Note
    1x cap
  30. Loosen LH front wheel nuts
    Note
    5x nuts, 21mm, 175 Nm
  31. Loosen RH front wheel nuts
    Note
    5x nuts, 21mm, 175 Nm
  32. Loosen RH rear wheel nuts
    Note
    5x nuts, 21mm, 175 Nm
  33. Loosen LH rear wheel nuts
    Note
    5x nuts, 21mm, 175 Nm
  34. Raise vehicle partially and lower lift onto locks
    Note
    Set vehicle to a comfortable working height, Make sure there's an audible click of the locks on both sides before lowering, otherwise vehicle may tilt to the side
  35. Remove LH rear wheel
    Note
    5x nuts, 21mm, 175 Nm
  36. Remove RH rear wheel
    Note
    5x nuts, 21mm, 175 Nm
  37. Remove RH front wheel
    Note
    5x nuts, 21mm, 175 Nm
  38. Remove LH front wheel
    Note
    5x nuts, 21mm, 175 Nm
  39. Lower vehicle partially and set lift onto locks
    Note
    Raise lift off locks, then hold lock release lever to keep locks free while vehicle is lowered, Set vehicle to comfortable working height
  40. Position fluid catcher underneath front of vehicle
  41. Position protective fender cover over fan shroud and support
  42. Disconnect AC compressor logic connector
    Note
    1x locking electrical connector, Do not push down on red tab, pull to disengage lock, pull again to release connector
  43. Remove retaining clip securing AC compressor logic harness to AC compressor HV harness bracket
    Note
    1x fir tree clip
  44. Disconnect HV harness connector from AC compressor
    Note
    1x locking electrical connector
  45. Remove fastener securing AC compressor HV harness bracket to AC compressor
    Note
    1x bolt, 13mm, 9 Nm,
  46. Remove AC compressor HV harness from AC compressor and set aside
    Note
    Move AC compressor HV harness bracket toward front of vehicle, lift bracket up to clear upper bracket mount and carefully set harness and bracket aside
  47. Remove AC compressor ground strap
    Note
    1x bolt, T25, 7 Nm
  48. Remove clips securing coolant hose to AC compressor bracket
    Note
    2x clips
  49. Remove AC compressor and AC compressor bracket assembly from strut tower support brace
    Note
    2x bolts, 15mm, 31 Nm, Recommend assistance, Support the AC compressor while removing the fasteners, Carefully remove the AC compressor and AC compressor bracket towards the front of the vehicle, under the strut tower support brace and rest on fender cover
  50. Disconnect HCU connector
    Note
    1x connector, Release red locking tab, Press black release tab and rotate lever upward to remove
  51. Release HCU connector harness
    Note
    1x clip
  52. Remove 4-tube bundle brake lines from HCU
    Note
    4x nuts, 12mm, 16 Nm
  53. Release 4-tube bundle brake lines from LH top spacer
    Note
    4x clips, Do not bend pipes
  54. Remove master cylinder secondary pipe from HCU
    Note
    1x nut, 12mm, 16 Nm
  55. Remove master cylinder primary pipe from HCU
    Note
    1x nut, 12mm, 16 Nm
  56. Remove LH top spacer from master cylinder brake pipes
    Note
    2x clips, Do not bend pipes
  57. Release the master cylinder brake lines from clip at rear of hydraulic control unit bracket
    Note
    1x harness clip
  58. Remove the bolts securing the hydraulic control unit to frame rail
    Note
    2x bolts, 10mm, 10 Nm
  59. Remove HCU and bracket assembly from vehicle
    Note
    2x tabs, Negotiate HCU around brake lines, Take care not to damage bracket tabs
  60. Loosen the fasteners securing the hydraulic control unit to the hydraulic control unit bracket
    Note
    2x nuts, 10mm, 8 Nm
  61. Pry hydraulic control unit from the bracket
  62. Install hydraulic control unit into hydraulic control unit bracket
  63. Install the fasteners securing hydraulic control unit to the hydraulic control unit bracket
    Note
    2x nuts, 10mm, 8 Nm
  64. Position HCU and bracket assembly onto vehicle
    Note
    2x tabs, Negotiate HCU around brake lines, Align bracket tabs with body holes
  65. Install the bolts securing the hydraulic control unit to frame rail
    Note
    2x bolts, 10mm, 10 Nm
  66. Position the master cylinder brake lines to clip at rear of hydraulic control unit bracket
    Note
    1x harness clip
  67. Install LH top spacer onto master cylinder brake pipes
    Note
    2x clips, Do not bend pipes
  68. Install master cylinder primary pipe onto HCU
    Note
    1x nut, 12mm, 16 Nm, Start nut by hand to avoid cross threading
  69. Install master cylinder secondary pipe onto HCU
    Note
    1x nut, 12mm, 16 Nm, Start nut by hand to avoid cross threading
  70. Secure 4-tube bundle brake lines onto LH top spacer
    Note
    4x clips, Do not bend pipes
  71. Install 4-tube bundle brake lines onto HCU
    Note
    4x nuts, 12mm, 16 Nm, Clean lines with brake cleaner before mating as needed
  72. Secure HCU connector harness
    Note
    1x clip
  73. Connect HCU connector
    Note
    1x connector, Seat connection and rotate lever downward, Secure red locking tab
  74. Position the AC compressor and AC compressor bracket assembly into the vehicle for assembly and install the fasteners securing the AC compressor assembly to the strut tower support brace
    Note
    2x bolts, 15mm, 31 Nm, Recommend assistance, Support the AC compressor while installing the fasteners, Carefully install the AC compressor and AC compressor bracket towards the rear of the vehicle, under the strut tower support brace
  75. Install AC compressor ground strap
    Note
    1x bolt, T25, 7 Nm
  76. Position AC compressor HV harness onto AC compressor for installation
    Note
    Ensure HV harness bracket engages upper bracket mount on AC compressor
  77. Install fastener securing AC compressor HV harness bracket to AC compressor
    Note
    1x bolt, 13mm, 9 Nm
  78. Connect HV harness connector to AC compressor
    Note
    1x locking electrical connector, Fully seating connector onto AC compressor engage black locking tab by pushing toward AC compressor
  79. Install retaining clip securing AC compressor logic harness to AC compressor HV harness bracket
    Note
    1x fir tree clip
  80. Connect AC compressor logic connector
    Note
    1x locking electrical connector, Engage locking tab
  81. Install clips securing coolant hose to AC compressor bracket
    Note
    2x clips
  82. Install LV battery
    Note
    3x bolts, 8mm, 6 Nm, Lower LV battery vertically into bracket
  83. Secure positive jump post
    Note
    1x bolt, 8mm, 5 Nm
  84. Install clip securing negative terminal cable to AC compressor bracket
    Note
    1x clip
  85. Connect First Responder Loop and LV battery
    Note
    2x connectors, Secure FRL first, Seat LV battery connection and push black connector lock inwards to secure, Engage green locking tab when fully seated
  86. Remove protective fender cover over fan shroud and support
  87. Remove fluid catcher from underneath vehicle
  88. Connect 2nd row seat harness and secure cushion
    Note
    2x clips, 2x connectors, Insert buckles through holes, Slide rear inward then align front clips, Perform push-pull-push test
  89. Reinstall Firmware via service UI
    Note
    Controls > Service Mode > Software Reinstall, Installation will begin immediately
  90. Once firmware redeploy is complete, Verify on center display release notes are present
    Note
    If the redeploy fails you may receive an error message on UI
  91. Clean area around brake fluid reservoir and remove brake reservoir cap
  92. Fill brake bleeder reservoir to full level
  93. Top off brake fluid reservoir
    Note
    If necessary
  94. Install pressure bleeder adapter onto reservoir
  95. Setup brake bleeder
    Note
    Connect power supply to bleeder and turn on the power to set pressure to 30 psi, Attach the brake reservoir hose to the brake adapter at this time
  96. Remove bleeding valve covers and install the fluid catching bottle to LH front brake caliper outer bleeding valve before starting the ESP
    Note
    2x covers
  97. Manually bleed LH front brake caliper by opening LH front brake caliper outer and inner bleeding valves
    Note
    2x bleeding valves, 11mm, Begin with the outer valve first then move on to the inner valve then conclude with the outer valve again, Repeat step till clear fluid and no air bubbles come out of LH front brake caliper bleeding outer and inner valves
    Mando brake calipers
    10 Nm (7.4 lbs-ft)
    Brembo brake calipers
    18.5 Nm (13.6 lbs-ft)
    ZF brake calipers
    11 Nm (8.1 lbs-ft)
  98. Remove bleeding valve covers and install the fluid catching bottle to RH front brake caliper outer bleeding valve before starting the ESP
    Note
    2x covers
  99. Manually bleed RH front brake caliper by opening RH front brake caliper outer and inner bleeding valves

    Brembo brake calipers
    18.5 Nm (13.6 lbs-ft)
    ZF brake calipers
    11 Nm (8.1 lbs-ft)
  100. Remove bleeding valve cover and install the fluid catching bottle to RH rear brake caliper bleeding valve before starting the ESP
    Note
    1x cover
  101. Manually bleed RH rear brake caliper by opening RH rear brake caliper outer and inner bleeding valves
    Note
    1x bleeding valve, 11mm, Repeat step till clear fluid and no air bubbles come out of RH rear brake caliper bleeding valve
    Mando brake calipers
    10 Nm (7.4 lbs-ft)
    Brembo brake calipers
    18.5 Nm (13.6 lbs-ft)
    ZF brake calipers
    11 Nm (8.1 lbs-ft)
  102. Remove bleeding valve cover and install the fluid catching bottle to LH rear brake caliper bleeding valve before starting the ESP
    Note
    1x cover
  103. Manually bleed LH rear brake caliper by opening LH rear brake caliper outer and inner bleeding valves
    Note
    1x bleeding valve, 11mm, Repeat step till clear fluid and no air bubbles come out of LH rear brake caliper bleeding valve
    Mando brake calipers
    10 Nm (7.4 lbs-ft)
    Brembo brake calipers
    18.5 Nm (13.6 lbs-ft)
    ZF brake calipers
    11 Nm (8.1 lbs-ft)
  104. Connect to vehicle using Toolbox
    Note
    Vehicle OBD-II connection is integrated into drivers footwell cover, Navigate to https://toolbox.teslamotors.com and establish connection to vehicle, Select connection status icon at top right corner then select connect locally, Icon will turn green when connected, Successful connection will automatically unlock vehicle gateway and place UI in Service Mode Plus, For local connection issues with Toolbox refer to https://toolbox.teslamotors.com/articles/43695
  105. Remove front LH caliper bleed valve covers then install fluid catcher to outer bleed valve
    Note
    2x covers
  106. Bleed LH front caliper
    Note

Run the PROC_ESP_FRONT-L-REAR-R_BRAKE-BLEEDvia Service Mode:Chassis ➜ Brakes ➜ Brake Bleed FL-RRvia Toolbox:(link) routine. Close bleed valve when pump stops running, Repeat process for inner bleeding valve then once again for outer bleeding valve

  107. Repeat bleed process until LH front caliper fluid is free of air bubbles
    Note
    2x bleed valves, 11mm,
    Mando brake calipers
    10 Nm (7.4 lbs-ft)
    Brembo brake calipers
    18.5 Nm (13.6 lbs-ft)
    ZF brake calipers
    11 Nm (8.1 lbs-ft)
  108. Remove fluid catcher then torque LH front caliper bleed valves
    Note

    Mando brake calipers
    10 Nm (7.4 lbs-ft)

    18.5 Nm (13.6 lbs-ft)

    11 Nm (8.1 lbs-ft)

    2x covers

  126. Remove diagnostic cable from port to disconnect Toolbox from vehicle

  130. Install RH front wheel

  138. Install LH front wheel center cap

  141. Install rear underhood apron

  143. Raise LH front window
