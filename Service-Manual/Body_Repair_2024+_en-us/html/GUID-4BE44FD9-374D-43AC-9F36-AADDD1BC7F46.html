Diffuser - Rear Fascia (Remove and Replace)

Correction code 1203020022 FRT 0.48 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See for safe and healthy working practices.

Torque Specifications

Table 1. Torque Specifications: Diffuser - Rear Fascia (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x2) that attach rear fascia diffuser to the inside of the rear fascia
3 Nm (2.2 lbs-ft)
  • 10 mm socket
 Reuse
Bolts (x6) that attach the rear fascia diffuser to the outer edge of the rear fascia
3 Nm (2.2 lbs-ft)
  • 10 mm socket
 Reuse

Remove

  1. Remove the rear fascia. See Fascia Assembly - Rear (Remove and Install).
  2. Remove the pedestrian warning speaker. See .
  3. Remove the bolts (x2) that attach the rear fascia diffuser to the inside of the rear fascia.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  4. Remove the bolts (x6) that attach the rear fascia diffuser to the outer edge of the rear fascia.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  5. Release the location hooks (x2) that attach the rear fascia harness to the rear fascia diffuser.
  6. Release the tabs (x10) that attach the rear fascia diffuser to the rear fascia, and then remove the diffuser.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.

Install

  1. Position the rear fascia diffuser to the vehicle, and then fasten the tabs (x10) that attach the rear fascia diffuser to the rear fascia.
  2. Secure the location hooks (x2) that attach the rear fascia harness to the rear fascia diffuser.
  3. Install the bolts (x2) that attach the rear fascia diffuser to the inside of the rear fascia.
    3 Nm (2.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  4. Install the bolts (x6) that attach the rear fascia diffuser to the outer edge of the rear fascia.
    3 Nm (2.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
  5. Install the pedestrian warning speaker. See .
  6. Install the rear fascia. See Fascia Assembly - Rear (Remove and Install).
