Striker - Door - LH (Remove and Replace)

Correction code 1133020012 FRT 0.06 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See for safe and healthy working practices.

Torque Specifications

Table 1. Torque Specifications: Striker - Door - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x2) that attach the LH front door striker to the body
26 Nm (19.2 lbs-ft)
  • Torx T40 socket
 Reuse

Remove

  1. Open the LH front door.
  2. Mark the position of the LH front door striker using masking tape.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  3. Remove the bolts (x2) that attach the LH front door striker to the body.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T40 socket
  4. Remove the LH front door striker from the vehicle.

Install

  1. Hand-tighten the bolts (x2) that attach the LH front door striker to the body.
  2. Close the LH front door and verify the door position; adjust the position of the striker and verify fitment, if necessary.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  3. Tighten the bolts (x2) that attach the LH front door striker to the body.
    26 Nm (19.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T40 socket
  4. Remove the masking tape from the body.
  5. Close the LH front door.
