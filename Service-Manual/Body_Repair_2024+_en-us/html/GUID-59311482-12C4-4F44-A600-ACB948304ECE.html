Rear Quarter Inner (Panel)

Correction code: 10101911702 10101910702 NOTE: Unless explicitly stated in the procedure, the above correction code includes all Collision Repair and Service repair work required to perform this procedure, including the linked Collision Repair procedures and linked Service procedures. Do not stack Collision Repair correction codes unless explicitly told to do so. Depending on the damage to the vehicle, additional repairs may be required.

Parent topic: Rear Quarter Inner Panels

Repair Information

  • Review all collision repair general practices and safety documentation and wear the appropriate PPE (Personal Protective Equipment) before beginning this procedure.
  • This procedure can be completed without using a frame bench.

Repair Procedure

  1. Remove the Bumper Beam - Rear (Remove and Replace).
  2. Remove the Cover - Rocker Panel - Lower - LH (Remove and Replace).
  3. Remove the Wheel Arch Liner - Rear - LH (Remove and Replace).
  4. Remove the Glass - Backlight (Remove and Replace).
  5. Remove the Glass - Body - Rear Quarter - LH (Remove and Replace).
  6. Remove the Foam - Seat Back - 2nd Row - RH (Remove and Replace).
  7. Remove the Trim - Package Tray (Premium) (Remove and Replace).
  8. Remove the Retractor - Seatbelt - 2nd Row - Outboard (Single Side) (Remove and Replace).
  9. Remove the Busbar - Charge Port to HV Battery (GB) (Remove and Replace).
  10. Remove the Door Assembly - Charge Port (EU) (Remove and Replace).
  11. Remove the Reflex Assembly - Electrical - Exterior Lights - Tail Lights - RH (Remove and Replace).
  12. Remove the Seal - Body - Side - Rear - Primary - LH (Remove and Replace).
  13. Remove the Cable Kit - Charge Port (3 Phase) (EU) (Remove and Replace).
  14. Remove the Trim - B-Pillar - Lower - LH (Remove and Replace).
  15. Remove the Tub Carpet - Rear Trunk (Remove and Replace).
  16. Remove the Rear Wheel Arch (Complete).
  17. Remove the original component.

    or Factory Spot Welds

    or Factory SPRs

  18. Prepare for installation.
    Note
    A red X indicates a location where a factory-installed fastener is not being replaced. Secure this location using structural adhesive only.

    or Structural Flange Rivets, 6.5 mm

  19. Apply structural adhesive to the mating surfaces on the vehicle and the new component or components.
  20. Install the new component or components.
  21. Install the new Rear Wheel Arch (Complete).
  22. Install the fastener as indicated.

    or Flow Form Rivets, S28

  23. Perform any necessary post-repair operations.
  24. Install the Tub Carpet - Rear Trunk (Remove and Replace).
  25. Install the Trim - B-Pillar - Lower - LH (Remove and Replace).
  26. Install the Cable Kit - Charge Port (3 Phase) (EU) (Remove and Replace).
  27. Install the Seal - Body - Side - Rear - Primary - LH (Remove and Replace).
  28. Install the Reflex Assembly - Electrical - Exterior Lights - Tail Lights - RH (Remove and Replace).
  29. Install the Door Assembly - Charge Port (EU) (Remove and Replace).
  30. Install the Busbar - Charge Port to HV Battery (GB) (Remove and Replace).
  31. Install the Retractor - Seatbelt - 2nd Row - Outboard (Single Side) (Remove and Replace).
  32. Install the Trim - Package Tray (Premium) (Remove and Replace).
  33. Install the Foam - Seat Back - 2nd Row - RH (Remove and Replace).
  34. Install the Glass - Body - Rear Quarter - LH (Remove and Replace).
  35. Install the Glass - Backlight (Remove and Replace).
  36. Install the Wheel Arch Liner - Rear - LH (Remove and Replace).
  37. Install the Cover - Rocker Panel - Lower - LH (Remove and Replace).
  38. Install the Bumper Beam - Rear (Remove and Replace).
