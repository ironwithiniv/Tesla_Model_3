Handle - Seat Back - 2nd Row - RH (Remove and Replace)

Correction code 1305020072 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See for safe and healthy working practices.

Torque Specifications

Table 1. Torque Specifications: Handle - Seat Back - 2nd Row - RH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x2) hat attach the RH 2nd row seat back handle to the seat back frame
2 Nm (1.5 lbs-ft)
  • Torx T25 socket
 Reuse

Remove

  1. Remove the RH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  2. Remove the 2nd row lower seat cushion. See .
  3. Remove the RH 2nd row seat back. See .
  4. Remove the RH 2nd row seat back hinge bracket. See .
  5. Remove the RH 2nd row escutcheon. See .
    Note
    There are 2 clips in the RH 2nd row escutcheon.
  6. Remove the RH 2nd row seat back latch release bezel. See .
  7. Unzip the RH 2nd row seat back upholstery cover.
  8. Put the electrical harness through the RH 2nd row seat back upholstery cover.
  9. Release the lower portion of the RH 2nd row seat back upholstery trim cover from the pivot bar.
  10. Remove the bolts (x2) that attach the RH 2nd row seat back handle to the seat back frame.
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket
  11. Remove the RH 2nd row seat back assembly from the frame.
  12. Release the clips (x2) that attach the RH 2nd row seat back latch control cable to the RH 2nd row seat frame.
    Note
    Release the clips based on the marked order.
  13. Remove the clip that attaches the RH 2nd row seat back handle assembly to the frame, and then remove the handle assembly from the frame.

Install

  1. Install the clip that attaches the RH 2nd row seat back handle assembly to the frame.
  2. Install the clips (x2) that attach the RH 2nd row seat back latch control cable to the RH 2nd row seat frame.
    Note
    Install the clips based on the marked order.
  3. Install the RH 2nd row seat back assembly to the frame.
  4. Install the bolts (x2) that attach the RH 2nd row seat back handle to the seat back frame.
    2 Nm (1.5 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • Torx T25 socket
  5. Install the lower portion of the RH seat back upholstery cover to the pivot bar.
  6. Put the electrical harness through the RH seat back upholstery cover.
  7. Zip the RH 2nd row seat back cover.
  8. Install the RH 2nd row seat back latch release bezel. See .
  9. Install the RH 2nd row escutcheon. See .
    Note
    There are 2 clips in the RH 2nd row escutcheon.
  10. Install the RH 2nd row seat back hinge bracket. See .
  11. Install the RH 2nd row seat back. See .
  12. Install the 2nd row lower seat cushion. See .
  13. Install the RH 2nd row seat side bolster. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
