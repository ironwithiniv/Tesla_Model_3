Cover - Rocker Panel - Lower - LH (Remove and Replace)

Correction code 1220020012 FRT 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See for safe and healthy working practices.

Torque Specifications

Table 1. Torque Specifications: Cover - Rocker Panel - Lower - LH (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Bolts (x4) that attach the LH lower rocker panel cover to the body
5 Nm (3.7 lbs-ft)
  • 10 mm deep socket
 Reuse

Remove

  1. Release the LH lower rocker panel bolt covers (x4).
  2. Remove the bolts (x4) that attach the LH lower rocker panel cover to the body.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  3. Release the clips (x4) that attach the LH lower rocker panel cover to the front and rear wheel arch liners.
  4. Release the clips (x10) that attach the LH lower rocker panel cover to the rocker panel, and then remove the cover from the panel.

Install

  1. Install the clips (x10) that attach the LH lower rocker panel cover to the rocker panel.
  2. Install the clips (x4) that attach the LH lower rocker panel cover to the front and rear wheel arch liners.
  3. Install the bolts (x4) that attach the LH lower rocker panel cover to the body.
    5 Nm (3.7 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm deep socket
  4. Install the LH lower rocker panel bolt covers (x4).
    Note
    The number of bolts on newer vehicles may vary.
