Trim - Package Tray (Premium) (Remove and Replace)

Correction code 1511010022 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See for safe and healthy working practices.

Remove

  1. Remove the LH and RH side rail trims. See .
  2. Remove the LH and RH side bolsters. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  3. Remove the LH and RH C-pillar trims. See Trim - C-Pillar - LH (Remove and Replace).
  4. Remove the clips (x2) that attach the package tray harness to the body.
  5. Disconnect the package tray harness connector from the RH body harness.
  6. Remove the tabs (x5) that attach the package tray trim to the vehicle.
  7. Remove the package tray trim.

Install

  1. Install the tabs (x5) that attach the package tray trim to the vehicle.
    Warning
    The video(s) included in this procedure are meant as an overview for supplemental purposes only. Follow all of the steps listed in the procedure to avoid damage to components and/or personal injury.
  2. Connect the package tray harness connector to the RH body harness.
  3. Install the clips (x2) that attach the package tray harness to the body.
  4. Install the LH and RH C-pillar trims. See Trim - C-Pillar - LH (Remove and Replace).
  5. Install the LH and RH side bolsters. See Bolster - Side - Seat - 2nd Row - LH (Remove and Replace).
  6. Install the LH and RH side rail trims. See .
