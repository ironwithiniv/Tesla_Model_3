Noise Absorber - Motor Bay - Front (Remove and Replace)

Correction code 1201010012 FRT 1.50 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See for safe and healthy working practices.

  • 2024-06-14: Added step to perform test drive and add correction code 00040100 as a separate activity to the Service Visit.
Equipment:
  • 1135762-00-A Kit, Svc Plug, Cooling Hose, Model 3
  • 1773092-00-A Diagnostic Harness Adapter - All Models
  • 1065131-00-A Kit, Battery Coolant Drain

Remove

  1. Remove the brake booster. See Assembly - Brake Booster and Master Cylinder (LHD) (Remove and Replace).
  2. Place absorbent material below the car computer coolant hose connection points.
  3. Disconnect the inner and the outer coolant hose to the car computer mount, and plug the ends of fittings as soon as possible.
  4. Release the clips (x3) that attach the coolant hoses to the bulkhead.
  5. Release the clips (x2) that attach the motor bay noise absorber to the bulkhead.
  6. Remove the motor bay noise absorber from the bulkhead.
    Note
    Cut a slit into the motor bay noise absorber to slip over the steering column during removal.

Install

  1. Install the new motor bay noise absorber to the bulkhead.
    Note
    Cut a slit into the new motor bay noise absorber to slip over the steering column during installation. Be careful not to cut the inner foam.
  2. Install the clips (x2) that attach the motor bay noise absorber to the bulkhead.
  3. Install the clips (x3) that attach the coolant hoses to the bulkhead.
  4. Remove the plugs on the ends of fittings, and connect the outer and the inner coolant hose to the car computer mount.
  5. Install the brake booster. See Assembly - Brake Booster and Master Cylinder (LHD) (Remove and Replace).
  6. Partial refill the cooling system. See .
  7. Move the LH front seat to the original position.
  8. Raise the LH front window and close the LH front door.
  9. Perform a road test using a series of aggressive stops to make sure there is proper pedal feel and brake performance.
    Note
    Add test drive correction code 00040100 as a separate activity to the Service Visit.
