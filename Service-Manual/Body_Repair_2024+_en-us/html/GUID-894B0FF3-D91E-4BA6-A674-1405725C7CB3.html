Door Assembly - Charge Port (NA) (Remove and Replace)

Correction code 4401010102 0.66 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See for safe and healthy working practices.

  • 2025-06-04: Added instruction to zero adjust the Hioki resistance meter prior to measurement.
Warning
This procedure is a DRAFT. Although it has been validated, Warnings and Cautions might be missing. Follow safety requirements and use extreme caution when working on or near High Voltage systems and components.
  1. Open trunk from exterior switch
  2. Open all four doors
  3. Lower all four windows
  4. Move LH front seat forward
  5. Move RH front seat forward
  6. Open hood
  7. Remove rear underhood apron
    Note
    14x clips
  8. Place vehicle in service mode
    Note
    Via UI > Controls > Software, Touch and hold "Model 3" for 4 seconds then release, Use screen keyboard to type "service" into dialog box then select OK
  9. Power off vehicle from center display
    Note
    Via Controls > Safety > Power Off, Select Power Off button at warning dialogue box
  10. Disconnect LV battery and First Responder Loop
    Note
    2x connectors, Release green locking tab, Press black tab then pull black connector lock outwards to release connection, Release red lock tab on FRL, Allow 2 minutes for all electrical circuits to fully discharge
  11. Verify operation of multimeter
    Note
    Set multimeter to DC voltage, Confirm multimeter is properly measuring voltage by testing the 16v battery
  12. Remove all items from pockets and ensure not wearing metal items
  13. Inspect HV insulating gloves
    Note
    Check gloves for damage prior to use, Refer to service document TN-15-92-003 R1, for information on inspecting HV gloves. https://service.teslamotors.com/protected-doc/ServiceBulletins/External/TN/TN-15-92-003_High_Voltage_Awareness_Care_Points_R4.pdf
  14. Put on HV insulating gloves and leather over gloves
    Note
    Make sure to wear Electrical Protective Gloves any time Hioki tester is used
  15. Verify there is no high voltage present at the charge port
    Note
    Make sure to wear PPE (HV gloves, safety glasses) when working on high voltage components, Measure B+ to B-, B- to Ground, and B+ to Ground (use rear left door striker as a ground for the isolation check), If voltage is greater than 10V, Pack contactors are not open or welded, Stop work and reach out to Service Engineering
  16. Remove HV insulating gloves
  17. Remove load floor
    Note
    Use pull tab located at rear edge of panel
  18. Remove trunk sill trim assembly
    Note
    4x clips, Pull corner upward to release clip on end then pull away from body for remaining clips
  19. Remove LH load floor bracket
    Note
    4x clips, 2x locators, Release bracket front clips, then release clips at rear
  20. Remove trunk garnish assembly
    Note
    6x clips, 4x locating tabs
  21. Remove clip for LH trunk side trim
    Note
    1x clip
  22. Disconnect LH trunk task light
    Note
    1x connector
  23. Move LH trunk side trim to aside
    Note
    Take care not to cause excessive creasing
  24. Remove LH trough trim
    Note
    3x clips, 1x bolt, T20, 1.2Nm
  25. Release connectors from chargeport assembly
    Note
    1x clip, 2x connectors, Remove white locking tab before disconnecting, Pull red locking tab to release lock, pull again to release from connector
  26. Remove charge port safety cap
    Note
    2x tabs
  27. Remove charge port busbar leads from charge port assembly
    Note
    2x nuts, 10mm, 9 Nm, Nuts have captured washers
  28. Release charge port manual release cable from body clip
  29. Remove charge port assembly
    Note
    3x bolts, 10mm, 5.5 Nm
  30. Disconnect charge port harness from charge port ECU
    Note
    1x connector
  31. Release charge port door harness grommet from body
    Note
    1x grommet
  32. Remove charge port door from vehicle
    Note
    2x tabs, 1x datum, Pull from the bottom rear to release, Pull the assembly towards the rear of the vehicle, when the door actuator reaches to the rear of the quarter panel pull the charge port down to clear the actuator mechanism then pull out and away from the body, Manipulating the charge door may be necessary to fully remove the assembly
  33. Install charge port door onto vehicle
    Note
    2x clips, 1x datum, Install the part by pivoting the assembly so the actuator mechanism clears underneath the quarter panel, then slide the charge door forward toward the rear door, When in position push down on bottom rear to engage clips, Manipulating the charge door may be necessary to fully align the assembly to the body
  34. Secure charge port door harness grommet to body
    Note
    1x grommet
  35. Connect charge port door connector to charge port ECU
    Note
    1x connector
  36. Install charge port assembly
    Note
    3x bolts, 10mm, 5.5 Nm
  37. Secure charge port manual release cable to body clip
  38. Clean charge port assembly busbar contact surface of residual penetrox
    Note
    Use plastic trim tool to push IPA wipe down between plastic divider, Allow 1 minute dry time
  39. Verify charge port studs are torqued to proper specification
    Note
    2x studs, T10, 2 Nm
  40. Apply Penetrox to backside of busbar leads
    Note
    Apply 2 drops of Penetrox A-13 about 5mm in diameter to either side of the hole on both leads, Spread evenly to verify the contact surface is fully covered
  41. Install charge port busbar leads to charge port assembly
    Note
    2x nuts, 10mm, 9 Nm, Nuts have captured washers
  42. Remove all items from pockets and ensure not wearing metal items
  43. Inspect HV insulating gloves
    Note
    Check gloves for damage prior to use, Refer to service document TN-15-92-003 R1, for information on inspecting HV gloves. https://service.teslamotors.com/protected-doc/ServiceBulletins/External/TN/TN-15-92-003_High_Voltage_Awareness_Care_Points_R4.pdf
  44. Put on HV insulating gloves and leather over gloves
    Note
    Make sure to wear Electrical Protective Gloves any time Hioki tester is used
  45. Perform zero adjust to Hioki meter. See .
  46. Perform Hioki resistance test at each HV joint from HV busbar lead to charge port stud
    Note
    2x HV joints, The acceptable resistance is between 0.050 mΩ (50 μΩ) and 0.270 mΩ (270 μΩ).If the resistance is greater than 0.270 mΩ (270 μΩ), there is too much resistance in the High Voltage joint. Remove the fastener, clean areas with isopropyl alcohol, install fastener back and test again. If the resistance is lower than 0.050 mΩ (50 μΩ), reposition the probes and measure again. If the resistance is repeatedly between 0.00 mΩ and 0.050 mΩ (50 μΩ), hioki test passed, proceed to next step.
  47. Remove HV insulating gloves
  48. Install charge port safety cap
    Note
    2x tabs
  49. Connect chargeport assembly connectors
    Note
    1x clip, 2x connectors, Engage locking tab, Install white locking tab once connected,
  50. Install LH trough trim
    Note
    3x clips, 1x bolt, T20, 1.2Nm
  51. Connect LH trunk task light
    Note
    1x connector
  52. Move LH trunk side trim to original position
  53. Install clip for LH trunk side trim
    Note
    1x clip
  54. Install trunk garnish assembly
    Note
    6x clips, 4x locating tabs, Align locating tabs to slot, Verify trunk seal is fully seated along garnish
  55. Install LH load floor bracket
    Note
    4x clips, 2x locators
  56. Install trunk sill trim assembly
    Note
    4x clips, Align striker with center slot then 2 locators to slots then press to secure clips, Manipulate seal to overlap trim
  57. Install load floor
  58. Close trunk via interior switch
  59. Connect 2nd row seat harness and secure cushion
    Note
    2x clips, 2x connectors, Insert buckles through holes, Slide rear inward then align front clips, Perform push-pull-push test
  60. Connect First Responder Loop and LV battery
    Note
    2x connectors, Secure FRL first, Seat LV battery connection and push black connector lock inwards to secure, Engage green locking tab when fully seated
  61. Install rear underhood apron
    Note
    14x clips, Hold rear wall of frunk to keep from flexing while engaging front clips
  62. Close hood
  63. Reinstall Firmware via service UI
    Note
    Controls > Service Mode > Software Reinstall, Installation will begin immediately
  64. Close LH rear door
    Note
    Release latch before closing if manually latched
  65. Close RH rear door
    Note
    Release latch before closing if manually latched
  66. Move RH front seat to original position
  67. Close RH front door
  68. Move LH front seat to original position
  69. Raise all windows
  70. Close LH front door
