Cooling Fan Module (Remove and Replace)

Correction code 1830036012 FRT 0.89 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See for safe and healthy working practices.

  • 2026-05-11: Added coolant vacuum refill.

Remove

  1. Raise and support the vehicle. See .
  2. Remove the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
  3. Unlock the vehicle gateway. See .
  4. On the touchscreen, touch Service Mode > Thermal > Coolant System > Coolant Fill/Drain and select Run to start the "Start Thermal Fluid Fill/Drain (Coolant Only)" routine.
  5. Disconnect the LV power. See .
  6. Remove the cabin intake duct. See .
  7. Remove the access panel. See .
  8. Remove the underhood storage unit. See .
  9. Carefully remove the ambient temperature sensor cover from the active grille shutter.
  10. Disconnect the ambient temperature sensor electrical connector.
  11. Release the connector lock, and then disconnect the active grille shutter actuator electrical connector.
    CAUTION
    Do not push down on the red tab. Pull the red tab to release the connector lock.
  12. Remove the bolts (x2) that attach the underhood storage unit reinforcement bracket to the cooling fan, and then slide the bracket rearward for clearance.
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
    • 2 in extension
    • Cordless hex driver
  13. Remove the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  14. Remove the front valance. See Valance - Front Fascia (Remove and Replace).
  15. Place a coolant drain container underneath the LH front of the vehicle.
  16. Release the spring clip, disconnect the radiator inlet hose from the radiator, and then plug the hose and radiator.
  17. Place the coolant drain container underneath the RH front of the vehicle.
  18. Release the spring clip, disconnect the radiator outlet hose from the radiator, and then plug the hose and radiator.
  19. Remove the coolant drain container from underneath the vehicle.
  20. Disconnect the cooling fan module electrical connector.
  21. Remove the LH bolt that attaches the bottom of the condenser fan module to the ankle catcher, then repeat this step on the RH side.
    Note
    Hold the condenser fan module up to ease removal of the bolts.
    Tip
    Use of the following tool(s) is recommended:
    • 8 mm socket
    • Cordless Ratchet/Impact Driver
  22. Remove the cooling fan module assembly from the vehicle.

Install

  1. With assistance, position the cooling fan module assembly into the vehicle, and then loosely install the bolts that attach the module assembly to the vehicle.
  2. Torque the LH bolt that attaches the bottom of the condenser fan module to the ankle catcher, then repeat this step on the RH side.
    10 Nm (7.4 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 8 mm socket
    • Cordless Ratchet/Impact Driver
    • Ratchet/torque wrench (for installation only)
  3. Remove the plugs from the radiator and radiator outlet hose, immediately connect the radiator outlet hose to the radiator, and then fasten the clip.
    Note
    Perform a push-pull-push test on the fittings to make sure that they are secure.
  4. Remove the plugs from the radiator and radiator inlet hose, immediately connect the radiator inlet hose to the radiator, and then fasten the clip.
    Note
    Perform a push-pull-push test on the fittings to make sure that they are secure.
  5. Connect the cooling fan module electrical connector, and then engage the connector lock.
  6. Install the front valance. See Valance - Front Fascia (Remove and Replace).
  7. Install the front aero shield panel. See Panel - Aero Shield - Front (Remove and Replace).
  8. Lower the vehicle fully.
  9. Position the underhood storage unit reinforcement bracket onto the cooling fan, and then install the bolts (x2) that attach the bracket to the fan.
    16 Nm (11.8 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 10 mm socket
    • Cordless Ratchet/Impact Driver
    • Ratchet/torque wrench (for installation only)
  10. Connect the ambient temperature sensor electrical connector.
  11. Install the ambient temperature sensor cover to the active grille shutter.
  12. Connect the active grille shutter actuator electrical connector, then engage the connector lock.
  13. Perform a coolant vacuum refill. See .
  14. Connect the LV power. See .
  15. On the touchscreen, perform the following steps.
    1. Touch Service Mode > Thermal > Coolant System > Stop Thermal Fill Drain to complete the routine.
    2. Touch Service Mode > Thermal > Coolant System > Coolant Purge and select Run to start the "Coolant Air Purge" routine, and allow the routine to complete.
      Note
      Make sure vehicle is not in Drive, shifting the vehicle into Drive will stop this routine. The test will last approximately 10 mins. The test will vary speeds from 3500-6500 RPM (idle speed = ~1500 RPM) and actuate the valve between series and parallel. If speed hovers at 7000 RPM, it indicates the pump is air locked, perform the vacuum fill again. Continue to add coolant and purge until the coolant level reaches between the NOM and MAX Lines on the bottle.
  16. Inspect the coolant level and top off as necessary, and then install the coolant bottle cap.
    Note
    Ensure that the coolant level is at the "Max" line.
  17. On the touchscreen, touch Service Mode > Thermal > Actions > Test Thermal Performance and select Run to start the "Thermal System Performance Test" routine, and allow the routine to complete.
  18. On the touchscreen, touch Service Mode > Thermal > Actions > Test HVAC Performance and select Run to start the "HVAC System Performance Test" routine, and allow the routine to complete.
  19. Disable Service Mode. See .
  20. Install the underhood storage unit. See .
  21. Install the access panel. See .
  22. Install the fresh air duct. See .
  23. Install the rear underhood apron. See Underhood Apron - Rear (Remove and Replace).
