Bumper Beam - Rear (Remove and Replace)

Correction code 1001050012 FRT 0.42 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See for safe and healthy working practices.

Torque Specifications

Table 1. Torque Specifications: Bumper Beam - Rear (Remove and Replace)
Description Torque Value Recommended Tools Reuse/Replace Notes
Nuts (x6) that attach the rear bumper beam or trailer hitch to the vehicle.
60 Nm (44.2 lbs-ft)
  • 15 mm deep socket
 Reuse

Remove

  1. Remove the rear fascia. See Fascia Assembly - Rear (Remove and Install).
  2. Remove the rear center bracket. See Bracket - Rear - Center (Remove and Replace).
  3. Remove the LH nuts (x3) that attach the rear bumper beam to the vehicle, then repeat this step on the RH side.
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm deep socket
  4. With an assistant, remove the rear bumper beam.

Install

  1. Install the LH nuts (x3) that attach the rear bumper beam to the vehicle, then repeat this step on the RH side..
    60 Nm (44.2 lbs-ft)
    Tip
    Use of the following tool(s) is recommended:
    • 15 mm deep socket
  2. Install the rear center bracket. See Bracket - Rear - Center (Remove and Replace).
  3. Install the rear fascia. See Fascia Assembly - Rear (Remove and Install).
