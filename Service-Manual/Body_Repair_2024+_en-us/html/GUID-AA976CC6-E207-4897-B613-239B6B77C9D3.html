Reflex Assembly - Electrical - Exterior Lights - Tail Lights - RH (Remove and Install)

Correction code 1740010091 FRT 0.18 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See for safe and healthy working practices.

Remove

  1. Remove the trunk load floor. See .
  2. Remove the trunk sill trim. See Trim - Trunk Sill (Remove and Replace)
  3. Remove the RH load floor bracket. See Bracket - Trunk Load Floor - LH (Remove and Replace).
  4. Remove the trunk garnish. See Garnish - Trunk (Remove and Replace).
  5. Use a pry tool to remove the clip that attaches the RH trunk side trim to the vehicle.
  6. Disconnect the RH trunk task light connector.
  7. Fold the RH trunk side trim aside to provide access to the working area.
  8. Hold the reflector on the outside with one hand while using a pry bar or a small flat head screwdriver to release the tabs (x3) and push the reflector outwards with the other hand, and then remove the reflector from the vehicle.

Install

  1. Install the clips (x3) that attach the reflector to the vehicle.
    Note
    Make sure clips are fully seated.
  2. Use the gap and flush tool to check the gap and flush of the reflector to the vehicle.
  3. Move the RH trunk side trim back to its original position.
  4. Connect the RH trunk task light connector.
  5. Install the clip that attaches the RH trunk side trim to the vehicle.
  6. Install the trunk garnish. See Garnish - Trunk (Remove and Replace).
  7. Install the RH load floor bracket. See Bracket - Trunk Load Floor - LH (Remove and Replace).
  8. Install the trunk sill trim. See Trim - Trunk Sill (Remove and Replace)
  9. Install the trunk load floor. See .
