Toolbox Labor Times

Describes Toolbox; Tesla’s diagnostic and repair software, which is used during some repairs of Tesla vehicles.

Toolbox is Tesla’s diagnostic and repair software. Some procedures use Toolbox operations to reset controllers, program newly-installed components, perform functional tests of newly-installed components, and/or update firmware.

CAUTION
Performing Toolbox operations is a necessary procedural step. The vehicle does not function properly without Toolbox operations being performed. Refer to the Service Manual procedure for all the steps to perform a procedure.
Note
Please see https://toolbox.teslamotors.com/articles/47962 for instructions on using Toolbox to connect to the vehicle.
Note
The time to perform Toolbox operations are included in the FRT specified in the Service Manual.
