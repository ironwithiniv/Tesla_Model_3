Cowl Lower

Correction code: 10101014702 NOTE: Unless explicitly stated in the procedure, the above correction code includes all Collision Repair and Service repair work required to perform this procedure, including the linked Collision Repair procedures and linked Service procedures. Do not stack Collision Repair correction codes unless explicitly told to do so. Depending on the damage to the vehicle, additional repairs may be required.

Parent topic: Front Inner Panels

Repair Information

  • Review all collision repair general practices and safety documentation and wear the appropriate PPE (Personal Protective Equipment) before beginning this procedure.
  • This procedure can be completed without using a frame bench.

Repair Procedure

  1. Remove the Fender Assembly - Front - LH (Remove and Install).
  2. Remove the Hinge - Active Hood - LH (Remove and Replace).
  3. Remove the Hood Assembly (Remove and Replace).
  4. Remove the Windshield (LHD) (Remove and Replace).
  5. Remove the A/C Compressor and Supermanifold (Remove and Replace).
  6. Remove the Beam - Cross Car (LHD) (Remove and Replace).
  7. Remove the Assembly - Brake Booster and Master Cylinder (LHD) (Remove and Replace).
  8. Remove the Brake Hydraulic Control Unit (Remove and Replace).
  9. Remove the Module - Body Controller (Remove and Replace).
  10. Remove the Shield - Body Controller - Front (Remove and Replace).
  11. Remove the Carpet - Front - LH (Remove and Replace).
  12. Remove the Carpet - Front - RH (Remove and Replace).
  13. Remove the Insulator - Dash (Remove and Replace).
  14. Remove the Cowl Top.
  15. Remove the original component.

    or Factory Spot Welds

    or Drill through factory spot welds
    Note
    When drilling out spot welds, use a drill bit that creates a hole correctly sized for the fastener that will replace the spot weld.
  16. Prepare for installation.
    or Rivets, 4.8 mm
  17. Apply structural adhesive to the mating surfaces on the vehicle and the new component or components.
  18. Install the new component or components.
  19. Install the Cowl Top.
  20. Perform any necessary post-repair operations.
  21. Install the Insulator - Dash (Remove and Replace).
  22. Install the Carpet - Front - RH (Remove and Replace).
  23. Install the Carpet - Front - LH (Remove and Replace).
  24. Install the Shield - Body Controller - Front (Remove and Replace).
  25. Install the Module - Body Controller (Remove and Replace).
  26. Install the Brake Hydraulic Control Unit (Remove and Replace).
  27. Install the Assembly - Brake Booster and Master Cylinder (LHD) (Remove and Replace).
  28. Install the Beam - Cross Car (LHD) (Remove and Replace).
  29. Install the A/C Compressor and Supermanifold (Remove and Replace).
  30. Install the Windshield (LHD) (Remove and Replace).
  31. Install the Hood Assembly (Remove and Replace).
  32. Install the Hinge - Active Hood - LH (Remove and Replace).
  33. Install the Fender Assembly - Front - LH (Remove and Install).
