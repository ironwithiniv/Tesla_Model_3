Cantrail Inner Assembly

Correction code: 10100117202 10100117302 NOTE: Unless explicitly stated in the procedure, the above correction code includes all Collision Repair and Service repair work required to perform this procedure, including the linked Collision Repair procedures and linked Service procedures. Do not stack Collision Repair correction codes unless explicitly told to do so. Depending on the damage to the vehicle, additional repairs may be required.

Parent topic: Body Side Panels

Repair Information

  • Review all collision repair general practices and safety documentation and wear the appropriate PPE (Personal Protective Equipment) before beginning this procedure.
  • Properly mount the vehicle on a frame bench when performing this procedure.

Parts List

Quantity Description Image / Notes
1 M3 ASY CANTRAIL (Cantrail Inner Assembly)
11 Structural Bulb Rivet, 6.5 mm

When ordering parts, refer to the Parts Catalog and enter the VIN of the vehicle being repaired to find the correct parts (and the part numbers) for the vehicle. Alternatively, use the search function in the Parts Catalog to find a specific part for the vehicle.

Repair Procedure

  1. Remove the Fascia Assembly - Rear (Remove and Install).
  2. Remove the Windshield (LHD) (Remove and Replace).
  3. Remove the Glass - Roof - Fixed (Remove and Replace).
  4. Remove the Glass - Backlight (Remove and Replace).
  5. Remove the Door - Front - LH (Remove and Install).
  6. Remove the Hinge - Door - Front - Lower - LH (Remove and Replace).
  7. Remove the Hinge - Door - Front - Upper - LH (Remove and Replace).
  8. Remove the Door - Rear - LH (Remove and Install).
  9. Remove the Hinge - Door - Rear - Upper - LH (Remove and Replace).
  10. Remove the Hinge - Door - Rear - Lower - LH (Remove and Replace).
  11. Remove the Fender Assembly - Front - LH (Remove and Install).
  12. Remove the Wheel Arch Liner - Front - LH (Remove and Replace).
  13. Remove the Cover - Rocker Panel - Lower - LH (Remove and Replace).
  14. Remove the Hood Assembly (Remove and Replace).
  15. Remove the Trunk (Remove and Install).
  16. Remove the Hinge - Power Trunk - LH (Remove and Replace).
  17. Remove the Door Assembly - Charge Port (NA) (Remove and Replace).
  18. Remove the Seal - Body - Side - Front - Primary - LH (Remove and Replace).
  19. Remove the Seal - Body - Side - Rear - Primary - LH (Remove and Replace).
  20. Remove the Carpet - Rear (Remove and Replace).
  21. Remove the Carpet - Front - LH (Remove and Replace).
  22. Remove the Seat Assembly - 1st Row - LH (Remove and Replace).
  23. Remove the Module - Body Controller - LH (Remove and Replace).
  24. Remove the Airbag - Curtain - RH (RHD) (Remove and Replace).
  25. Remove the A-Pillar Outer Reinforcement.
  26. Remove the original component.

    or Factory Spot Welds

  27. Position the new component and secure it in place.
    Note
    Refer to the Dimensional Specifications to make sure that the component and adjacent components are properly located and aligned.
  28. Prepare for installation.

    or Structural Bulb Rivets, 6.5 mm

    or Installation Spot Welds

  29. Apply structural adhesive to the mating surfaces on the vehicle and the new component or components.
  30. Install the new component or components.
  31. Perform resistance spot welding.
    or Installation Spot Welds
    Warning
    Failure to follow all welding safety precautions, including the use of personal protective equipment, could result in serious injury or property damage. Only technicians who have completed Tesla’s approved welding training are authorized to weld structural components on Tesla vehicles.
    CAUTION
    Do not weld on a Tesla vehicle before performing the Vehicle HV Disablement Procedure (refer to the vehicle-specific Service Manual for more information on the Vehicle HV Disablement Procedure). Welding on a Tesla vehicle with an energized high or low voltage system might damage vehicle components.
  32. Install the A-Pillar Outer Reinforcement.
  33. Perform any necessary post-repair operations.
  34. Install the Airbag - Curtain - RH (RHD) (Remove and Replace).
  35. Install the Module - Body Controller - LH (Remove and Replace).
  36. Install the Seat Assembly - 1st Row - LH (Remove and Replace).
  37. Install the Carpet - Front - LH (Remove and Replace).
  38. Install the Carpet - Rear (Remove and Replace).
  39. Install the Seal - Body - Side - Rear - Primary - LH (Remove and Replace).
  40. Install the Seal - Body - Side - Front - Primary - LH (Remove and Replace).
  41. Install the Door Assembly - Charge Port (NA) (Remove and Replace).
  42. Install the Hinge - Power Trunk - LH (Remove and Replace).
  43. Install the Trunk (Remove and Install).
  44. Install the Hood Assembly (Remove and Replace).
  45. Install the Cover - Rocker Panel - Lower - LH (Remove and Replace).
  46. Install the Wheel Arch Liner - Front - LH (Remove and Replace).
  47. Install the Fender Assembly - Front - LH (Remove and Install).
  48. Install the Hinge - Door - Rear - Lower - LH (Remove and Replace).
  49. Install the Hinge - Door - Rear - Upper - LH (Remove and Replace).
  50. Install the Door - Rear - LH (Remove and Install).
  51. Install the Hinge - Door - Front - Upper - LH (Remove and Replace).
  52. Install the Hinge - Door - Front - Lower - LH (Remove and Replace).
  53. Install the Door - Front - LH (Remove and Install).
  54. Install the Glass - Backlight (Remove and Replace).
  55. Install the Glass - Roof - Fixed (Remove and Replace).
  56. Install the Windshield (LHD) (Remove and Replace).
  57. Install the Fascia Assembly - Rear (Remove and Install).
