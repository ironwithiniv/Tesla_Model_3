Ground Strap - Rear Defrost (Remove and Replace)

Correction code 1710040062 FRT 0.12 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See for safe and healthy working practices.

Remove

  1. Remove the side rail trim. See .
  2. Remove tether hooks from LH body.
  3. Fold the LH 2nd row seatback down.
  4. Disconnect the LH antenna filter harness connector
  5. Disconnect the LH antenna filter harness connector from the LH C-pillar ground.
  6. Disconnect LH antenna filter harness fixing clip, and then remove the filter antenna.

Install

  1. Connect LH antenna filter harness fixing clip to install the filter antenna.
  2. Connect the LH antenna filter harness connector to the LH C-pillar ground.
  3. Connect the LH antenna filter harness connector.
  4. Raise the 2nd row seatback.
  5. Install the side rail trim. See .
