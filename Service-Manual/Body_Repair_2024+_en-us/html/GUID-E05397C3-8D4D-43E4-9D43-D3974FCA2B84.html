Carpet - Front - RH (Remove and Replace)

Correction code 1530020022 FRT 0.35 NOTE: Unless otherwise explicitly stated in the procedure, the correction code and its associated FRT reflect all of the work required to perform this procedure, including the linked procedures. Do not stack correction codes unless explicitly told to do so. NOTE: See to learn more about FRTs and how they are created. NOTE: See Personal Protection to make sure you are wearing proper PPE when performing the procedure below. NOTE: See for safe and healthy working practices.

Warning
Seat base edges are sharp and can cause personal injury. Wear cut resistant gloves when removing the seat from the vehicle, and while performing procedures that involve work on or near the seat base.

Remove

  1. Remove the front passenger seat. See Seat Assembly - 1st Row - No Lumbar - RH (Remove and Replace).
  2. Remove the RH front footwell cover. See .
  3. Remove the RH front floor mat. See Kit - Floor Mat - LHD (Remove and Replace).
  4. Remove the RH center console front side panel. See .
  5. Remove the RH center console rear side panel. See
  6. Release the clips (x2) that attach the RH front carpet to the body, and then remove the RH front carpet from the vehicle.

Install

  1. Install the RH front carpet into the vehicle, and then fasten the clips (x2) that attach the RH front carpet to the body.
  2. Install the RH center console rear side panel. See
  3. Install the RH center console front side panel. See .
  4. Install the RH front floor mat. See Kit - Floor Mat - LHD (Remove and Replace).
  5. Install the RH front footwell cover. See .
  6. Install the front passenger seat. See Seat Assembly - 1st Row - No Lumbar - RH (Remove and Replace).
