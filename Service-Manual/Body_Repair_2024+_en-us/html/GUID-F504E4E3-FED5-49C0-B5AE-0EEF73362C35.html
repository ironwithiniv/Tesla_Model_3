Rear Wheelhouse Inner Complete Assembly

Correction code: 10101907802 10101907702 NOTE: Unless explicitly stated in the procedure, the above correction code includes all Collision Repair and Service repair work required to perform this procedure, including the linked Collision Repair procedures and linked Service procedures. Do not stack Collision Repair correction codes unless explicitly told to do so. Depending on the damage to the vehicle, additional repairs may be required.

Parent topic: Rear Quarter Inner Panels

Repair Information

  • Review all collision repair general practices and safety documentation and wear the appropriate PPE (Personal Protective Equipment) before beginning this procedure.
  • Properly mount the vehicle on a frame bench when performing this procedure.

Repair Procedure

  1. Remove the Trim - Package Tray (Premium) (Remove and Replace).
  2. Remove the Front Carpet - Rear Trunk (Remove and Replace).
  3. Remove the Tub Carpet - Rear Trunk (Remove and Replace).
  4. Remove the Busbar - Charge Port to HV Battery (GB) (Remove and Replace).
  5. Remove the ECU - Charge Port (Gen4) (Remove and Replace).
  6. Remove the Retractor - Seatbelt - 2nd Row - Outboard (Single Side) (Remove and Replace).
  7. Remove the Damper - Rear - LH (Remove and Replace).
  8. Remove the Link - Aft - Lower - Rear - LH (Remove and Replace).
  9. Remove the Link - Aft - Upper - Rear - LH (Remove and Replace).
  10. Remove the Link - Fore - Lower - Rear - LH (Remove and Replace).
  11. Remove the Link - Fore - Upper - Rear - LH (Remove and Replace).
  12. Remove the Link - Fore - Upper - Rear - RH (Remove and Replace).
  13. Remove the Parcel Shelf Extension (Front).
  14. Remove the original component.
    or Factory Spot Welds

    or Factory SPRs

    or Bolts

  15. Prepare for installation.
    or Structural Bulb Rivets, 6.5 mm

    or Bolts

  16. Apply structural adhesive to the mating surfaces on the vehicle and the new component or components.
  17. Install the new component or components.
    Torque the bolts to 24 Nm.
  18. Install the new Parcel Shelf Extension (Front).
  19. Perform any necessary post-repair operations.
  20. Install the Link - Fore - Upper - Rear - RH (Remove and Replace).
  21. Install the Link - Fore - Upper - Rear - LH (Remove and Replace).
  22. Install the Link - Fore - Lower - Rear - LH (Remove and Replace).
  23. Install the Link - Aft - Upper - Rear - LH (Remove and Replace).
  24. Install the Link - Aft - Lower - Rear - LH (Remove and Replace).
  25. Install the Damper - Rear - LH (Remove and Replace).
  26. Install the Retractor - Seatbelt - 2nd Row - Outboard (Single Side) (Remove and Replace).
  27. Install the ECU - Charge Port (Gen4) (Remove and Replace).
  28. Install the Busbar - Charge Port to HV Battery (GB) (Remove and Replace).
  29. Install the Tub Carpet - Rear Trunk (Remove and Replace).
  30. Install the Front Carpet - Rear Trunk (Remove and Replace).
  31. Install the Trim - Package Tray (Premium) (Remove and Replace).
